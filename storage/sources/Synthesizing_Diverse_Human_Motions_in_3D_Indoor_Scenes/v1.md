# Synthesizing Diverse Human Motions in 3D Indoor Scenes
> Kaifeng Zhao, Yan Zhang, Shaofei Wang, Thabo Beeler, Siyu Tang · 2023 · IEEE International Conference on Computer Vision · 引用 117 · DOI 10.1109/iccv51070.2023.01354

## 一句话
用强化学习训练"场景感知的移动策略"+"细粒度物体交互策略",驱动虚拟人在 3D 室内场景里自主行走避障、并真实地坐到椅子/躺到沙发上,且无需采集"人-场景配对"的动作捕捉数据。

## 解决了什么问题
- 让虚拟人"住进"任意 3D 室内场景:既能在杂乱家具间导航避免穿模碰撞,又能与多样物体做细粒度交互(坐、躺、起身),并把这些行为串成连续活动序列。
- 痛点是:既有的人-场景交互合成方法(如 SAMP)依赖昂贵且稀缺的"人体动作 + 对应 3D 场景"配对数据,数据谱系窄,难覆盖复杂场景与未见物体,合成质量也受限。
- 既有的 RL 动作合成方法(如 GAMMA)虽不需配对数据、能生成自然移动,但只感知简单场景、只会"走到目标点",不会坐/躺,且经常与场景几何穿插。本文要兼得两者之长。

## 用什么方法解决的(含直觉:为什么 work)
- **核心套路:把深度生成模型的隐变量当作 RL 的"动作"。** 直接用 GAMMA 的 CVAE 生成式"运动基元(motion primitive)"作为运动模型:它在 1–2 帧运动种子条件下,把一个隐变量 `z` 解码成约 0.25 秒的短动作片段。策略网络在每个时间步输出 `z`,环境推进、给奖励。直觉:动作空间不是低层关节角,而是"一段自然动作的隐编码",所以采样出来的每一步天然像真人动作,RL 只需在这个"动作流形"上挑选方向,既保自然度又可被目标/场景信号引导。
- **把场景信息塞进 state + 用碰撞当惩罚,治穿模。** 移动策略用一张以盆骨为中心、对齐身体朝向的 `16×16` 二值"可走性地图(walkability map)"覆盖 1.6m×1.6m 局部区域(红=不可走/障碍,蓝=可走)感知周边,并对身体包围盒落入不可走格子施加穿透惩罚。直觉:像"怕踩陷阱的人"一样,主动绕开障碍、放慢速度。
- **用身体表面 marker 作为细粒度交互目标,治"只会走不会坐"。** 用 COINS 根据"动作-物体"语义先生成一个静态的目标交互人体,取其 `SSM_67` 表面 marker 作为目标;交互策略被引导把当前 marker 逼近目标 marker。直觉:坐/躺这种交互对全身姿态要求高,单给一个盆骨目标点不够,给"整副身体 marker"才能精确控制最终姿态。
- **用 SDF 编码人-物邻近关系。** 交互 state 里放入每个 marker 到物体表面的符号距离(SDF 值)及其梯度方向,让策略"感知"身体离物体表面多近、往哪个方向是穿入。直觉:SDF 提供了连续可微的"贴而不穿"信号。
- **导航网格做路径规划补全长程移动。** 用 A*/navigation mesh 在可走区生成中间 waypoints,移动策略逐段走到;再与交互策略交替 rollout,就能合成"走到凳子→坐下→起身→走到椅子→坐→走到沙发→躺"这样的连续序列(Fig.1)。

## 动机 & 背景
- 传统角色动画能产出高质量动画但难自主、难自发地"像真人那样"与环境互动;学习式交互合成方法 [13,45,61] 需同时捕捉人体动作与场景,成本高、谱系窄、对未见场景泛化差。
- RL 式动作合成(GAMMA [64]、MoVAE [29]、ASE [36])能生成自然自主动作,但多只面向简单场景、只做到达目标的移动,不懂坐/躺,且常与场景穿插。
- 本文定位:"最像 GAMMA 和 SAMP",但取二者之长——GAMMA 的可泛化运动基元+策略(无需配对数据)、SAMP 的物体交互(坐/躺),并补上"场景感知避障"和"细粒度 marker 引导"。

## 方法细节
- **人体表示:** SMPL-X [34],形状 `β∈R^10`、姿态 `θ∈R^63`、根平移 `r∈R^3`、朝向 `φ∈so(3)`;运动用 `SSM_67` 表面 marker 序列表示,`X={x_1,...,x_N}`,`x_i∈R^{67×3}`,坐标相对首帧盆骨的规范系。
- **动作:** GAMMA 的 CVAE 运动基元隐变量 `z`,在 SAMP+AMASS 上训练以覆盖人-场景交互的运动技能。
- **状态:** `s_t=(X_s, I, G)`(式1),`X_s∈R^{M×67×3}` 为 M 帧运动种子;`I` 为人-场景交互特征,`G` 为目标到达特征,移动与交互任务各自定义。
- **奖励:** `r = r_goal + r_contact + r_pene`(式2)。
  - 足地接触:`r_contact = e^{-(|min x_z|−0.05)_+} · e^{-(min‖x_vel‖_2−0.075)_+}`(式3),`F` 为足部 marker,容差阈值 0.05m(足地距)/0.075 m/s(防滑步),沿用 GAMMA。
- **移动策略:** 可走性地图 `M∈{0,1}^{16×16}`;`I=vec(M)`(式5);`G=(ḡ_p−X_s)_n`(式6,指向目标盆骨的归一化向量);`r_pene=e^{−|M_0∩B_xy(X)|}`(式7,`M_0`不可走格、`B_xy`身体 2D 包围盒);`r_goal=r_dist+r_ori`(式8),`r_dist=1−(‖p−g_p‖_2−0.05)_+`(式9),`r_ori=⟨o, g_p−p⟩/2`(式10,鼓励朝向目标)。
- **交互策略:** `I=[Ψ_O(X_s), ∇Ψ_O(X_s)]`(式11,SDF 值 `R^{M×67}` + 梯度 `R^{M×201}`);`G=[(ḡ_m−X_s)_n, ‖ḡ_m−X_s‖_2]`(式12,到目标 marker 的方向+距离);`r_goal=1−(‖x−g_m‖_2−0.05)_+`(式13);穿透惩罚 `r_pene=e^{−(1/|V|)(1/T)ΣΣ|(Ψ_O(v_ti))_−|}`(式14,惩罚 SMPL-X 网格顶点的负 SDF,即穿入物体)。交互策略用"坐/躺下 + 起身"混合训练(0.25 概率交换初始与目标体),从而能在交互后回到移动。
- **网络与训练:** actor-critic,策略输出对角高斯;联合最小化 `L = L_PPO + E[(r_t−V(s_t))^2] + α·KL-div(π(z|s)‖N(0,I))`(式4),第三项在隐空间正则化,使动作贴近运动先验、保自然。
- **测试期树搜索采样:** 每步采多个隐动作、按训练所用奖励作为筛选准则只保留最优 K 个基元,丢弃低质样本以提质(沿用 GAMMA)。
- **实现(附录):** 用 pynavmesh 造导航网格(粗半径 0.2 做寻路、细半径 0.02 做可走性地图);用 mesh-to-sdf 预计算每个交互物体 `128×128×128` 的 SDF 网格,trilinear 插值查询;COINS 仅重训 PelvisNet 以改善对 ShapeNet/ScanNet 物体的泛化。

## 数据集 & 实验设置
- **运动基元训练:** AMASS [32] + SAMP [13];选 BABEL 标注为 'sit'/'lie' 的 AMASS 序列 + SAMP 全部数据;40 FPS、每片 10 帧。作者强调"用 AMASS 扩充 SAMP 是让交互策略 work 的关键"。
- **移动策略训练环境:** ShapeNet [6] 随机摆放的合成杂乱场景 + 导航网格采样的碰撞自由 waypoints。
- **交互策略训练环境:** PROX [14] 静态人-物交互(经 LEMO/COINS 处理)重定向到 ShapeNet 物体做增广。
- **评测:** 移动在合成测试场景比 SAMP、GAMMA;交互在 10 个未见 ShapeNet 物体(3 扶手椅/3 直背椅/3 沙发/1 L 形沙发)比 SAMP,分坐/躺;序列在真实 Replica [47] 扫描场景比 SAMP,含感知用户研究(并排二选一选更自然者)。指标:完成时间、平均到达距离、足接触分、移动/交互穿透分(穿入比例/均值/最大)、感知偏好率。

## 主要结果 & 结论(写方向,不堆精确数字)
- 移动任务:本文足接触分最高、移动穿透分最高,意味更好的足地贴合、更少穿模——但代价是移动更慢、用时更长("像怕踩陷阱的人")(observed,见 Table 1)。GAMMA 到达更快更准但会撞进场景(Fig.5)。
- 坐/躺交互任务:本文足接触分更高、穿透(均值与最大)更低、且完成更快;原因是 SAMP 对随机初始姿态泛化差、需更长时间才开始交互(supported,见 Table 2)。
- 交互序列(真实场景):本文在足接触、移动穿透、交互穿透(均值/最大)上均优于 SAMP,且感知研究中被jud格为"更自然"的比例远高(约 0.85 vs 0.15,见 Table 3)(supported)。
- 消融:去掉穿透惩罚→穿模显著增大;去掉足地接触奖励→接触与穿透都变差且出现"悬空/穿地"的怪异动作。说明这两项奖励对交互策略都关键(supported,见 Table 4)。
- 泛化:能在与训练场景差异很大的真实重建场景(巴黎街景、室内房间、公交长椅、床)上合成自然动作(Fig.7)(observed,定性为主)。
- 附录补充对比:对 Wang 等 [55] 移动(Table S1)、COUCH [61] 坐下(Table S2)也在接触/穿透/速度上更优(observed)。

## 适用边界(什么时候管用 / 什么时候不管用)
- **管用:** 静态 3D 室内场景;平地行走 + 坐/躺/起身这类交互;对未见物体形状、随机初始位置与朝向有一定泛化;无"人-场景配对"训练数据也能训出策略。
- **不太管用:** 需要硬保证零穿模的场合(本文只用软奖励鼓励避碰,不施加硬约束,穿透仍可见,Fig.8 左);"躺"类动作自然度明显不如"坐"(因 AMASS 躺卧数据仅约 167 秒,远少于坐的约 5000 秒,运动基元学不全躺的动作空间,Fig.8 右);非平地场景(楼梯、不平户外地形、多层建筑)因依赖 2D 可走性地图而受限;动态场景(可移动物体、其他人/动物/车辆)不支持。
- **比的是强基线还是弱基线:** 主对比 SAMP、GAMMA 都是当时该任务的代表性 SOTA,属较强基线;但移动只比了这两者,交互只比了 SAMP(序列也只比 SAMP),对比面偏窄。

## 核心贡献
- 提出"用生成式运动基元隐变量作动作"的 RL 框架,在复杂室内场景生成多样、自然、可永续的虚拟人动作,且免去人-场景配对数据。
- 用身体表面 marker(由 COINS 生成)作为细粒度交互目标,把坐/躺等交互的全身姿态变得可控、语义可指定。
- 设计"场景与交互感知"的策略:2D 可走性地图 + 碰撞惩罚做避障移动,SDF 特征做人-物邻近建模,并能把移动与交互交替组合成连续活动序列。

## 局限与我的质疑
1. **穿模治标不治本(作者自述+我的强调):** 全靠软奖励"鼓励"避碰,无硬约束,穿透分虽优于基线但绝对值仍不小(躺的最大穿透仍达约 44,见 Table 2),离"物理可信"还有距离;作者也承认需结合物理仿真才能真正解决。
2. **"躺"是明显短板,且暴露方法对数据量的依赖:** 接触分(约 0.78)和自然度都弱于坐;说明这套方法本质仍受运动基元训练数据覆盖度制约——一旦某类动作 mocap 数据稀缺,RL 也救不回来。这与"无需配对数据"的卖点形成张力:它只是把数据依赖从"人-场景配对"转移到"足量单人动作 mocap"。
3. **对比面偏窄、且部分指标此消彼长:** 移动只比 GAMMA/SAMP,交互序列只比 SAMP;且本文移动"更慢更耗时"被解释为"像谨慎的人",但这也可能是避碰过保守导致的效率损失,作者把劣势(用时 6.43s 最长)叙述成拟人优点,有过度解读之嫌。
4. **感知研究细节单薄:** 序列任务"更自然偏好 0.85"很亮眼,但参与者人数、样本数、统计显著性等未在正文充分给出(可能在补充材料/项目网站),仅凭此难判断鲁棒性。
5. **依赖外部模块的复合系统,误差会传导:** 目标姿态由 COINS 生成、路径由导航网格规划、SDF 预计算——任一环节(尤其 COINS 对域外物体的泛化,作者已重训 PelvisNet 说明原版不够用)出问题都会影响最终动作,端到端可控性与可复现性成本较高。
6. **与本研究主题(感知-决策-动作闭环、人-场景交互)契合度高,但"决策"层偏弱:** 这里的"决策"主要是低层运动控制 + 预先规划的 waypoints,缺少真正的高层任务规划/长程目标推理;场景也限于静态,离"自主智能体在动态真实环境中长程交互"还有距离(作者亦将动态交互列为未来工作)。
