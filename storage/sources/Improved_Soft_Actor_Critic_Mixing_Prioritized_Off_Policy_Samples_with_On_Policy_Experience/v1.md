# Improved Soft Actor-Critic: Mixing Prioritized Off-Policy Samples with On-Policy Experience
> Chayan Banerjee, Zhiyong Chen, Nasimul Noman · 2021 · arXiv · 引用 0 · DOI arxiv:2109.11767

## 一句话
本文提出 ISAC（=SAC+SDP+MO/O），在不改 SAC 网络与损失的前提下，靠"对均匀采样出的小批做二次优选（按回合回报）+ 把最新 on-policy 转移直接掺进训练批 + 延迟把新数据灌进回放池"三件小事，在 3 个 MuJoCo 连续控制任务上比 vanilla SAC / SAC+PER / SAC+PER+ERE 更稳、更省样本（observed）。

## 解决了什么问题
- SAC 是 off-policy 算法，靠经验回放池（ER buffer）里**均匀采样**的数据更新策略与价值网络；作者认为均匀采样没有区分样本好坏，样本效率有提升空间。
- 目标：更高效地利用 ER buffer，使 SAC 用**更少的环境-智能体交互**更快收敛到接近最优、且训练更稳定。
- 作者明确把目标限定在"换一种用 buffer 的方式"，而不是改 SAC 的策略分布或 critic 结构（与 [43] 用 normalizing flow、[44] 给 critic 加带限滤波那类工作相区分）。

## 用什么方法解决的（含直觉：为什么 work）
三个组件叠加，核心直觉是"**先均匀采、再优选**"而非"一上来就带优先级地采"，并把最新经验即时喂给网络。

- **SDP（Sampled Data Prioritization，采样后优选）**：给每条转移元组额外存一个分数——它所属回合的**回合回报 ρ**（cumulative episodic return），同一回合内所有转移共享同一 ρ，作为该转移的"好坏分"。训练时**先均匀采** l 个大小为 k 的小批（论文用 l=2），合并成 k_eff=l×k 条，再从中按 ρ 取前 k 条作为优选批 C_prior。
  - 直觉：与 PER（[28]，直接按 TD 误差做非均匀采样、需优先级树数据结构）不同，ISAC 在均匀采样的子集上做"事后优选"，实现简单、无需特殊数据结构；用 l=2 而非更大的 l，是为了避免反复抓到重复数据、保住数据多样性（作者称"l=2 给出更优的数据多样性"）。
  - **防过拟合的开关**：只学高回报样本会导致网络过拟合（引 [40]）；且随训练进行回合回报趋同，按 ρ 优选会失效。于是用两小批回报分数向量的**余弦相似度 ζ** 作闸：`ζ = cos⁻¹( v_B1·v_B2 / (‖v_B1‖‖v_B2‖) )`，其中 v_B1、v_B2 是两批的回报分数向量。规则：`C = C_prior 若 ζ ≤ ζth；否则 C = 随机取 B1 或 B2 之一`。即两批太相似就不做优选、退回均匀批。ζth=0.5 在所有环境上最好；ζth=0.9 会导致过拟合/短视（见 Fig.2a，observed）。
- **MO/O（Mixing On/Off-policy）**：在优选批 C 里**随机替换一条**为当前最新的 on-policy 转移 q_t，得到训练批 `M = (C\{y}) ∪ {q_t}`，用 M 做这一步的梯度更新。
  - 直觉：SDP 需要等一个回合结束才能算出 ρ 并入库，于是在一个回合长度内 buffer 不进新数据、网络只在"相对旧"的样本上学；把最新 on-policy 转移即时掺进训练批，正好补上这个"新鲜度缺口"，加速学习。作者称去掉 MO/O（仅 SAC+SDP）会"学得很慢"（observed，Fig.2b）。
- **延迟灌入（Delayed infusion）**：最新经验先攒进临时 buffer D_temp，攒满 ξ 个回合再整体推进 ER buffer（每 ξ 回合一次，推完清空）。论文取 ξ=10。
  - 直觉一：等一个回合才能算 ρ（必须有回合回报才能打分），延迟灌入天然配合 SDP 打分。直觉二：MO/O 已经把最新经验喂进训练批，若同时又把同一批最新数据立刻入库，网络会反复见到相同数据（尤其 buffer 早期较空时），损害多样性、导致过拟合；延迟入库可保住 off-policy 样本多样性。作者讨论了两个极端：ξ=1 会过拟合，ξ>20 会因长期不进新数据而学得很慢。

## 动机 & 背景
- SAC（[17][41]）= off-policy actor-critic + 最大熵正则；目标函数为 `φ* = argmax_φ E[Σ_t γ^t (R(a_t,s_{t+1}) + α H(π_φ(·|s_t)))]`，熵系数 α 在本文用**自适应**版本（[41]，α 训练中变化，非固定）。SAC 学两个 Q 网络 Q_ψ1、Q_ψ2 + 共享目标网络对，策略输出高斯分布的均值与标准差。
- 相关工作脉络（作者据此定位自己）：PER（[28]，按 |TD误差| 非均匀采样）、ERE（[45]，更激进地采近期经验，SAC+PER+ERE 组合表现好）、Sinha 等（[46]，双 buffer + 密度比估计加权，但引入额外超参与密度估计网络、增加计算量）、用回合回报/回合记忆做优先级的工作（[37]–[40]，含异步回合式 DDPG [40] 用双 buffer 存"史上最佳分"回合，但作者指出这会降低样本多样性、引入偏置）。
- 作者自述两点"首次"主张（strength=作者声称，未给证明）：①首次在 SAC 语境做 on-/off-policy 数据**直接混合**；②首次对"已均匀采出的数据"做优先级，而非一开始就做优先级采样。

## 方法细节
- 增广元组 `d̂ = (s_t, a_t, r(a_t,s_t), s_{t+1}, ρ)`；ρ 为父回合的回合回报。
- SDP：B1、B2 各 k 条 → 合并 Ĉ（2k 条）→ 取 ρ 最大的 k 条为 C_prior，其余为 C_rest，满足 C_prior 中任意元组 ρ 都大于 C_rest 中任意元组。
- 优选闸：余弦相似度 ζ（公式见上）；ζ ≤ ζth 才优选，否则用一条均匀小批。ζth 越高 → 越多地优选 → 网络学到更高比例的高回报样本。
- MO/O：`M = (C\{y}) ∪ {q_t}`，y 为 C 中随机一条，q_t 为最新 on-policy 转移。
- 延迟灌入：`D_temp ← {回合1..回合ξ的转移}`，每 ξ 回合一次 `D ← D_temp` 并清空 D_temp。
- 关键超参（Table I）：学习率 5×10⁻⁴、Adam、隐层 256、ER buffer 10⁶、软更新 10⁻²、batch=50、γ=0.99、gradient step=1；ζth=0.5、ξ=10；PER 的 β1=0.6/β2=0.4（初始），ERE 的 η0=0.996/η1=1.0。所有对比算法共用同一网络结构/超参/buffer 大小以求公平，实现基于公开仓库 [49]。

## 数据集 & 实验设置
- 三个 MuJoCo（[47]）+ OpenAI Gym（[48]）连续控制任务：**InvertedPendulum-v2、Reacher-v2、Swimmer-v2**（均为低维：状态 4/11/10 维，动作 1/2/2 维）。
- 对比基线：vanilla SAC [41]、SAC+PER [28]、SAC+PER+ERE [45]（即把 ISAC 与"SAC 本体 + 两个较强的 SAC 改进"比）。
- 评估协议：每训练若干步（"一个 training unit"）后，用确定性（均值）策略跑 5 个回合评估取平均回报；总训练单元 N=100/400/500（对应 0.1/0.2/0.5 百万步，分别给三任务）。每算法 5 个随机种子重复，三算法在同一环境用**同一组 5 个种子**。曲线为 5 次均值 + 标准差阴影，且做了 20 单元滑动平均平滑。
- 两个量化指标：R̄max（5 次重复的峰值平均回报，衡量峰值能力）、σ̄（全程标准差的平均，衡量稳定性/鲁棒性）；以及 T^w（达到设定目标分所需训练步数，目标分=SAC 基线末段 N_f 个单元的平均回报，衡量样本效率）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **稳定性**：在三任务里 ISAC 的全程平均标准差 σ̄ 普遍更小——InvertedPendulum 上 ISAC σ̄ 最低、明显优于次好的 SAC+PER+ERE（见 §IV-A、Table II，supported）。但 **Swimmer 上 ISAC 的 σ̄（19.119）反而比 vanilla SAC（11.821）大**，作者自己也点明这一点（observed）。
- **样本效率（达标步数 T^w）**：ISAC 在 InvertedPendulum、Swimmer 上达标步数最少、且标准差更小（Table III，supported）；**但 Reacher 上 SAC+PER 在平均步数上略胜 ISAC**（作者称 "marginally beats ISAC in average, but with a higher standard deviation"，observed）——即 ISAC 并非每个任务每个指标都第一。
- **峰值回报 R̄max**：Swimmer 上 ISAC 峰值最高（108.969 vs 次好 SAC 的 87.751，§IV-C，observed）；InvertedPendulum 上四者都能到上限 1000、R̄max 无区分度（作者明说），区分主要体现在稳定性与达标速度。
- **消融**（仅在 InvertedPendulum 上，Fig.2b，observed）：仅 SAC+SDP（无 MO/O）学得慢；加上 MO/O（SAC+SDP+MO/O）显著加速；仅 SAC+MO/O（无 SDP）也"表现不高"——作者据此论证两组件需配合。
- 总体方向性结论（作者，strength=supported 但仅限这三个低维任务）：ISAC 比所列基线**更稳、更省样本、收敛更快**；且实现简单，不像 SAC+PER 需要优先级树这类特殊数据结构。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：经测的三个**低维连续控制**任务（状态 ≤11 维、动作 ≤2 维）；环境带明确的回合结构、回合回报能区分好坏（SDP 依赖回合回报作信号）。在这些设定下相对 vanilla SAC / SAC+PER / SAC+PER+ERE 有稳定性与样本效率优势。
- **可能不管用/未验证**：高维状态/动作空间（作者把"更具挑战的高维环境"明确列为**未来工作**，本文未测，如 Humanoid/Ant 等常见困难基线均缺席）；稀疏奖励或回合回报区分度差的任务（此时 ρ 信号弱、ζ 闸会频繁退回均匀采样，SDP 增益存疑）；ξ、ζth 等需调（ζth=0.9 即过拟合，说明对该超参敏感）。
- 即使在测过的任务里，优势也**非全项第一**（Reacher 的平均达标步数、Swimmer 的稳定性各有基线胜过 ISAC）。

## 核心贡献
1. **SDP**：对从 ER buffer **均匀采出**的多小批做"事后按回合回报优选"，配余弦相似度闸防优选失效/过拟合——区别于"一开始就优先级采样"的 PER。
2. **MO/O**：把最新 on-policy 转移直接随机替换进优选 off-policy 训练批，补足回合内"无新数据"的新鲜度缺口；作者称这是 SAC 语境下首次做直接 on-/off-policy 数据混合。
3. **延迟灌入**：新经验攒 ξ 回合再整体入库，既配合 SDP 打分、又保住 off-policy 样本多样性。
4. 工程上简单、无需优先级树等特殊数据结构，可直接加在现有 SAC 上。

## 局限与我的质疑
1. **预印本，未经同行评审**（arXiv 2021，引用 0）：所有结论应保留看待；缺少独立复现验证。
2. **实验规模与任务难度都偏弱**：仅 3 个低维 MuJoCo 任务（最高 11 维状态/2 维动作），且都属相对简单环境。SAC 类工作通常报告 HalfCheetah/Ant/Humanoid 等高维任务——本文恰恰回避了这些，使"更省样本/更稳"的主张**泛化性证据不足**。作者自己也把高维留作未来工作。
3. **优势并不一致，叙述有择优倾向**：Reacher 的平均达标步数被 SAC+PER 反超、Swimmer 的稳定性被 vanilla SAC 反超，但摘要/结论统一宣称"outperforms / superior"，有把 observed 结果讲成普遍优越之嫌。读者应以 Table II/III 的逐项数字为准，而非结论句。
4. **公式与文字疑似内部不一致（接地存疑）**：相似度写作 ζ = cos⁻¹(余弦)（即两向量夹角，单位弧度），但正文又称"ζ 越接近 1 越相似"——夹角度量在向量相同时应为 0 而非 1，二者矛盾；ζth=0.5 究竟是余弦值还是弧度阈值，文中未澄清，可能是表述/实现细节笔误。这影响对 SDP 闸门机制的精确理解，需回看代码/原文确认。
5. **消融不完整**：MO/O 与 SDP 的消融**只在 InvertedPendulum 一个任务上做**（Fig.2b），就断言"两组件需配合"，证据面太窄；延迟灌入（ξ）除两极端定性讨论外，未见跨任务的系统消融，ξ=10 的选取依据偏弱。
6. **与"强基线"比较有限**：选了 SAC+PER、SAC+PER+ERE 算较强基线，但未对比 Sinha 等 [46]（likelihood-free importance weights）这类作者自己引为同类的方法，"我们更简单且更好"中的"更好"未对最相关竞品验证。
7. **计算/时间开销未报告**：每步要均匀采 l 批再优选、算余弦相似度、维护临时 buffer，相比 vanilla SAC 的 per-step 开销增量未给出；"省样本"是否以"费计算"为代价未量化。
8. **"首次"主张未给证明**：两条"to the best of our knowledge"式的首创声明属作者主张，本文无系统性文献证据支撑，引用时不宜当作既定事实。
