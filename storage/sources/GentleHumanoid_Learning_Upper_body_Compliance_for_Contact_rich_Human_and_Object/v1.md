# GentleHumanoid: Learning Upper-body Compliance for Contact-rich Human and Object Interaction
> Qingzhou Lu, Yao Feng, Baiyu Shi, Michael Piseno, Zhenan Bao, C. Karen Liu · 2025 · arXiv.org · 引用 8 · DOI 10.48550/arxiv.2511.04679

## 一句话
把"阻抗控制"以一套统一的弹簧公式塞进**全身动作跟踪 RL 策略**,让人形机器人(Unitree G1)的整条上肢链(肩-肘-腕)对外部接触**柔顺(compliant)**而非僵硬抵抗,从而能安全完成拥抱、扶人起立、抓气球等接触丰富的人/物交互。

## 解决了什么问题
- 多数动作跟踪 RL 策略追求"刚性"位置/速度跟踪,把外力当成要**抑制的扰动**;这与拥抱、扶起等需要"顺从"的任务相冲突。
- 已有把阻抗/导纳控制并入 RL 的工作,通常只作用于**底座或末端执行器**,且重点在**抵抗极端外力**,而不是主动产生柔顺。
- 真实交互(拥抱、扶起)往往**多个连杆(肩、肘、手)同时接触**,力需要在整条运动链上协调一致;且柔顺程度要可调(从轻柔抱人到稳固托举),同时不超过安全力阈。
- 由此两大挑战:(1) 跨运动链多连杆协调力响应;(2) 适配从轻触到强支撑的多样接触场景。

## 用什么方法解决的（含直觉：为什么 work）
核心是**一套统一的虚拟弹簧公式 + 阻抗参考动力学**,让策略去"复现"一个本就柔顺的参考行为:
- 每个连杆受两种力驱动(Eq 1):`M ẍ_i = f_drive,i + f_interact,i`,虚拟质量 `M=0.1 kg`。
  - **驱动力(driving force)**:把连杆拉向目标轨迹的虚拟弹簧-阻尼器(Eq 2)`f_drive = K_p(x_tar−x_cur)+K_d(v_tar−v_cur)`,取临界阻尼 `K_d=2√(MK_p)`——负责跟踪目标动作。
  - **交互力(interaction force)**:同一弹簧形式建模接触(Eq 3)`f_interact = K_spring(x_anchor−x_cur)`,锚点 `x_anchor`(Eq 4)分两类:**resistive contact**(机器人主动压向人/物→锚点固定在初始接触点,产生抵抗位移的恢复力)、**guiding contact**(被人推/拉→锚点取自人类动作数据集中的采样姿态 `x_sample`)。
- **为什么 work(关键直觉)**:guiding contact 的锚点不是逐 link 独立随机给,而是**从完整人体姿态里整体采样**——这保证了肩/肘/腕上的力**运动学一致、相互协调**(原文:"sampling complete postures ensures forces remain coordinated across the kinematic chain"),而不是各 link 各拉各的、产生物理上不合理的力分布。这是相对物理引擎碰撞力(噪声大、局部、不协调)的核心优势。
- **力的多样化(训练覆盖)**:刚度随机 `K_spring~U(5,250)`;激活连杆集合按概率抽样(40% 无外力 / 15% 双臂全 6 link / 30% 单臂 3 link / 15% 单 link);锚点与选择每 5 秒重采样并留过渡窗。Fig 3 显示生成的力覆盖球面各方向、幅值 0–25 N。
- **安全力阈值机制**:设阈值范围 `F1≤τ_safe≤F2`(取 `F1=5N, F2=15N`),分段常数、每 5 秒重采样且作为观测喂给策略;当驱动力超阈则按 Eq 5 缩放 `f_drive_limited = min(1, τ_safe/‖f_drive‖)·f_drive`。**阈值直接调柔顺度**:小阈值→更软更安全(轻柔拥抱),大阈值→更稳固支撑(扶起)。
- **RL 落地**:策略 50 Hz 输出 29 维关节位置目标 `a_t∈R^29`,底层 PD 跟踪;参考动力学用半隐式欧拉积分(Eq 6–7,步长 0.005s)。Teacher-student 两阶段做 sim-to-real,PPO 训练。学生观测 `o=(τ_safe, m_tar, ω, g, q_hist, a_{t-3:t-1})`;教师额外拿特权观测(参考动力学的 `x_ref/ẋ_ref/f_interact`、仿真实测 `f_interact_sim`、连杆高度、上步力矩、累计跟踪误差)。

## 动机 & 背景
- 人形机器人要进入以人为中心的环境,**安全且自然的物理交互**是刚需;RL 已能做出强动作跟踪与运动操作,但"刚性跟踪"范式不适合需要顺从的接触任务。
- 相关工作三块:(A) 人形全身控制(MPC 类需大量人工调参;从人类动作数据学习能出高动态技能与通用策略);(B) 力自适应控制(经典阻抗/导纳已扩到全身;RL 类近期也引入阻抗,但多聚焦末端、且重在**抵抗**极端力/扰动);(C) 人-人形交互(早期 human-in-the-loop、针对单一任务如 sit-to-stand,**难跨场景泛化**)。本文定位:一个**能处理多种交互场景**的通用、覆盖全上肢链的柔顺动作跟踪策略。

## 方法细节
- **参考动力学(附录 Eq 8)**:实际用 `M ẍ = f_drive + f_interact − D ẋ`,比正文 Eq 1 多了稳定用阻尼项 `D ẋ`;显式欧拉、每仿真步 4 个子步,并对加速度/速度做 clip。参数(Table III):`M=0.1kg, D=2.0, K_p=τ_safe/0.05, K_d=2√(MK_p), Δt=0.02s, 4 substeps, 速度上限 4 m/s, 加速度上限 1000 m/s²`。
- **外力施加逻辑(附录)**:激活连杆用二值 mask `m∈{0,1}^M`,每区间抽五种模式之一(无力/全 link/仅左/仅右/随机部分子集);弹簧增益分段线性平滑变化(渐增-保持-降回 0)。
  - **单边投影(one-sided projection)**:接触是**单边**的——只有当连杆**压向锚点**时才产生交互力,离开接触侧时力降为 0,避免非物理的"被拉回"。
  - **躯干净力矩约束**:对躯干总力/力矩封顶(Table II:每 link 力上限 `F_max=30N`,每 link 安全阈 `τ_safe=5–15N`默认 10N,躯干净力限 30N,净力矩限 20 N·m,弹簧增益 5–250);超限则在躯干注入反向残差。
- **奖励设计(Table I)**:柔顺奖励 `r_compliance = w_dyn r_dyn + w_force r_force + w_pen r_pen`。
  - 参考动力学跟踪:`r_dyn = exp(−‖x_sim−x_ref‖²/σ_x) + exp(−‖ẋ_sim−ẋ_ref‖²/σ_v)`(权 2.0)。
  - 参考力跟踪:`r_force = exp(−‖f_interact−f_interact_sim‖²/σ_f)`(权 2.0)——显式让仿真实测接触力对齐参考力。
  - 不安全力惩罚:`r_pen = −𝟙(‖f_interact‖ > τ_safe + δ_tol)`,容忍带 `δ_tol=10N`(权 6.0,最高权重)。
  - 另含动作跟踪(root 0.5、joint 1.0)与运动稳定(survival 5.0、feet air time 10.0、impact 4.0、slip 2.0 等)。

## 数据集 & 实验设置
- **动作数据**:用 GMR 把 AMASS、InterX、LAFAN 重定向到 G1,滤掉不符合交互场景的高动态动作,最终约 **25 小时、50Hz** 数据(含人-人、人-物交互)。
- **硬件**:Unitree G1;自制腰部贴合**压力传感垫(40 个标定电容 taxel)**测分布接触力;另用手持力计(Mark-10 M5-10)测峰值。
- **基线(均为作者实现,代表两类先验思路)**:**Vanilla-RL**(无力扰动训练,代表常规全身跟踪);**Extreme-RL**(训练时加最大 30N 末端力扰动,代表力自适应类方法)。
- 评测:仿真(拥抱+外力拉拽试图挣脱)+ 真机三场景(静态姿态受外力 / 抱人体模型 / 抓气球)。

## 主要结果 & 结论（写方向，不堆精确数字）
- **仿真**:面对挣脱式拉力,GentleHumanoid 在手/肘/肩三处都维持**更低且更稳定**的接触力;基线很快饱和到刚性高位。量级上,手部本方法约稳定在 ~10N,Vanilla-RL 稳在 20N 以上、Extreme-RL 超 13N;肩肘处基线饱和在 15–20N 而本方法约 7–10N(见 §IV-A 图4)。supported
- **真机·静态受外力**:两基线都僵硬抵抗、躯干被带偏甚至失衡;移动手臂所需峰值力,Extreme-RL 约 51N、Vanilla-RL 约 25N,而 GentleHumanoid 用**低得多的力**即可顺移且保持平衡(具体值见 §IV-B)。observed
- **姿态无关柔顺(posture-invariant compliance)**:同一外力即可在不同姿态下调动手臂,且柔顺度匹配用户设定的力阈(阈设 10N 时有效区间约 5–15N)。observed
- **真机·抱人体模型**:τ_safe 设 10N;**即使刻意错位接触**,GentleHumanoid 仍维持有界稳定的接触压力,基线则产生更高、更不可预测的局部高压或无法维持动作(见图6)。observed
- **真机·抓气球(阈值 5N)**:GentleHumanoid 能稳抱不破;两基线施力过大,把气球挤变形直至 G1 失衡掉落。observed
- **更多应用**:joystick 遥操作行走+触发预定义动作;基于 BEDLAM 人体网格估计+动捕身高的**自主"按体型定制"拥抱**流水线;以及单目 RGB 视频经 PromptHMR→SMPL-X→GMR 重定向后由策略执行(对带脚滑的噪声参考动作仍稳健,能处理枕头/气球/不同筐)。observed
- 总体方向性结论:相比基线,本方法在多场景下**一致地降低峰值接触力、交互更平滑可调**。supported(覆盖多任务但多为定性+少量孤立数值)

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:上肢、接触力大致在 **0–25N** 量级、需要柔顺/可调安全力阈的人/物交互(拥抱、扶起、抓易碎/可变形物、被人推拉引导);需要多连杆协调顺从、且要保持自身平衡的场景。
- **不(太)管用 / 未覆盖**:**下肢/行走过程中的全身柔顺**(本文只做上肢,全身遥操作柔顺列为未来工作);**大负载/重物托举**(力范围只到 ~25N);需要精确到 N 以下力控的场景(真机有 1–3N 过冲);依赖动捕做人定位/身高的自主流程,无动捕时自主性受限。
- **基线强度**:对比的是作者自实现的 Vanilla-RL / Extreme-RL(称"代表性"先验思路),**并非直接复现已发表 SOTA 力自适应方法**;且这些基线目标本就是"抵抗"而非"柔顺",故"更柔顺"一定程度是**目标设定差异**的体现,读者评估时需留意。

## 核心贡献
1. 提出 GentleHumanoid:把阻抗控制并入全身动作跟踪、实现**上肢级柔顺**的框架;核心是**统一弹簧公式**同时覆盖 resistive 与 guiding 两类接触,并从**完整人体姿态采样**保证跨链运动学一致。
2. 设计**力阈值机制**:训练中维持可调安全力限(可在部署时改),既调柔顺度又保安全。
3. 设计带**自制压力传感垫**的拥抱评测装置,提供可靠的分布接触力测量;在仿真与真机 G1 上验证拥抱/扶起/物体操作。

## 局限与我的质疑
**作者自述局限**:
1. 用人类动作数据保证运动学一致,但**数据本身约束了力分布**——例如施加到肩部的力因录制动作变化有限而偏小;引入更多样数据(如舞蹈)可改善覆盖。
2. 交互建模依赖**仿真弹簧力**,结构化、运动学一致,但**不能完全刻画真实人体接触**(摩擦、人体组织的黏弹性)。
3. 安全策略虽约束了力,真机仍因 sim-to-real 差异出现 **1–3N 偶发过冲**;可能需要额外触觉传感做更精细力调节。
4. 人的定位与身高目前来自**动捕**;换成纯视觉流水线可提升自主性与实用性(尤其长时任务)。

**我的额外质疑**:
5. **量化证据偏薄**:主结论多为定性描述 + 少量**孤立峰值力数字**(如 51.14N / 24.59N),缺成功率/多次重复的统计(样本量、方差)与跨多姿态的系统量化,"posture-invariant compliance"主要靠定性支撑,强度宜按 observed 读。
6. **"柔顺"几乎是被设计出来的,而非学出来的物理理解**:策略本质是去复现一个本就柔软的虚拟弹簧-阻尼参考 + 力阈缩放;真正的新意在"统一公式 + 整姿态采样保证跨链一致",而"比刚性基线更软"在目标层面近乎构造性结论(见适用边界对基线的说明)。
7. **缺(我未读到)对核心设计的消融**:如"整姿态采样 vs 逐 link 独立采样""统一公式 vs 分别建模""力阈机制有无"对协调性/安全性的单独贡献,正文与附录我都未见对应消融,故"整姿态采样带来跨链一致"这一关键卖点更多是机制论证而非实验隔离验证(若有遗漏可回 PDF 核对)。
8. **力量程窄**:0–25N 决定它适合轻柔/中等支撑,扶起体重级负载、或下肢承力等真正"强支撑"场景未被实测,标题"upper-body"已自限,但对"扶人起立"这类宣称任务的负载真实性需谨慎。
9. **压力垫测量的近似**:把每 taxel 有效接触面积近似为 6mm×6mm 来反推力,叠加 PDMS 标定,绝对力值有系统不确定性;真机峰值力的精确数值不宜当结论卖点。
10. **相对本研究主题(RL 做 humanoid 运动跟踪+阻抗控制)**:方法新颖性集中在交互力建模与采样策略,RL 算法本身沿用 PPO + teacher-student(承自先前工作),在 RL 方法论层面增量有限;贡献更偏"如何把柔顺接触可控地注入既有跟踪框架"。
