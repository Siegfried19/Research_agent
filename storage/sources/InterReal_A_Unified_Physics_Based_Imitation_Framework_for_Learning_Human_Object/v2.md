# InterReal: A Unified Physics-Based Imitation Framework for Learning Human-Object Interaction Skills

## 一句话
InterReal 是一个把"人-物交互(HOI)参考动作"作为模仿目标、训练真实人形机器人(Unitree G1)学会搬箱/推箱等全身交互技能的物理仿真模仿框架,靠两件事撑起来:① 用 IK 保持手-物接触一致、只挪物体位置来做动作增广,提升对物体扰动的鲁棒性;② 用一个元策略自动学习/动态分配底层 RL 的奖励权重,绕开人工调大堆奖励权重的难题。

## 解决了什么问题
- 现有人形机器人全身控制框架大多只做**非交互**技能(走、跳、跳舞),缺乏与物体交互的能力,难以落地工业等需要人-物交互的场景(作者动机段)。
- 已有的 HOI 模仿学习研究(如 InterMimic、CooHOI、RMD、TokenHSI)主要停留在**动画领域**,即使考虑物理也只是引入"小质量、摩擦"等理想化属性,与真实物理差距大,难以直接部署到真实机器人(Related Work 段)。
- 机器人侧的交互方案主要依赖**上半身遥操作**,限制了人形机器人的自主性(作者指出)。
- 作者自己的实测发现:真实部署时,人和物体轨迹的**传感扰动(尤其二者相对位置扰动)**容易把学到的策略推出分布甚至导致崩溃;而针对交互泛化的研究稀缺(引言)。
- 奖励设计是带复杂交互的人形 DRL 的长期瓶颈:多路异构奖励信号难以平衡、逼近最优奖励函数很难(引言,引用 [14])。

## 用什么方法解决的(含直觉:为什么 work)
- 把 HOI 任务建模成 MDP `(S,A,P,f_t,γ)`,动作空间 `A∈R^23`(机器人自由度),用 **PPO** 优化期望累计折扣奖励;策略输出 PD 控制器的目标关节角,再转成电机力矩(§III、§IV-B)。
- **两大核心组件**:HOI 动作增广 + 自动奖励学习器(引言明确为本文两个关键组件)。
- **动作增广(为什么 work)**:真实部署的主要扰动是物体相对位置变化。作者沿世界系 XY 给物体加一个偏移 `Δp_xy`,然后**用 IK 反解机械臂关节角、强制保持手 link 与物体的接触细节不变**,从同一条"锚动作"派生出一批"任务相同、只是物体起始位置不同"的多动作轨迹(§IV-B,式(2)(3))。直觉:让策略在训练期就见过"物体摆在不同位置、但抓取/接触关系一致"的大量变体,从而学会对物体位置扰动鲁棒、并能按检测到的物体位置实时调整手臂行为。
- **自动奖励学习(为什么 work)**:作者的洞察是——无论底层模仿奖励项设计得多复杂,其最终目的都是**最小化机器人轨迹与参考轨迹之间的跟踪误差**;而且奖励的侧重点会随 HOI 任务阶段(phase)变化,固定权重既繁琐又次优(§IV-C/D)。于是他们用一个外层**元策略 `μ^meta`** 在 PPO 训练过程中**动态构造奖励权重 `Θ`**,并把"关键跟踪误差"本身作为引导元策略探索的信号。直觉:与其人工把几十路奖励权重调到死,不如让元策略根据训练进度和真实跟踪误差,自动把奖励信号分配到"当前阶段最该改进的地方"。

## 动机 & 背景
- 现有真实世界全身控制器(CLONE、TWIST、OpenWBT 等)能跟踪通用动作,但**没有显式设计面向交互的反馈控制器**,难以支撑精确的人-物交互(Related Work)。
- 作者目标:把"基于动作模仿的 HOI 学习"从动画扩展到**基于真实世界的人形机器人**(Related Work 末)。
- 与遥操作/普通全身控制器不同,本框架**同时跟踪人和物体的轨迹、并把二者观测一起喂进 DRL**,以实现准确且平滑的闭环交互(引言)。

## 方法细节
- **状态构成(§III-A)**:`s_t=[s^h_t, s^o_t, s^int_t, p]`。人形特征 `s^h_t=[q_t, q̇_t, ω^root_t, g_t, a_{t-1}]`(关节位置 `q_t∈R^23`、关节速度、根角速度、重力投影、上一步动作);物体特征 `s^o_t=[p^o_t, ṗ^o_t, ϑ^o_t]`(全局位置/速度/朝向);交互特征 `s^int_t=[h^o_t, s^ig_t]`(接触布尔状态 + 交互图)。详细参数指向 Appendix B(本 PDF 未含)。
- **三步动作预处理(§IV-A)**:
  - HOI 动作重定向:把 SMPL 格式 mocap 重定向到 G1 机器人形态,优化"人形-物体-地面"接触自然度;作者注明"该具体方法将在后续发表"(`will be published later`)。
  - 物理校验:借用基于物理的 InterMimic,在 IsaacGym 中对重定向动作施加物理约束,剔除穿模、碰撞、非法参考等,得到"已校验 HOI 动作"。
  - 动作增广:把一条已校验动作增广成多条(见上文"为什么 work")。
- **多动作训练(§IV-A-2)**:在 ASAP 框架基础上扩展两点——i) 让其跟踪 HOI 动作;ii) 加入面向增广动作的多动作 HOI 跟踪学习器。内层学任务专属策略 `π^hoi`,外层优化元策略 `μ^meta`"学会怎么学 `π^hoi`"。
- **IK 增广公式(§IV-B)**:给物体偏移后 `p̂^(w)(t)=p^(w)(t)+Δp_xy`、`p̂^(w)_{L/R}(t)=p^(w)_{L/R}(t)+Δp_xy`(式2);经躯干、骨盆变换矩阵把腕(末端执行器)位置转到骨盆系 `p̂^(p)_{L/R}(t)=T_{(p←t)}T_{(t←w)}p̂^(w)_{L/R}(t)`(式3);在骨盆系用 **Ipopt** 非线性优化器、以原关节角 `q_arm(t)` 为初值反解新臂关节角;偏移 `Δx,Δy∈linspace(-ε,ε,√c3)`,生成 `{M^j}_{j=1}^{c3}` 多动作(参数 ε、c3 指向 Appendix B)。
- **内层 PPO 目标(§IV-C)**:最大化 `Σ_t γ^t f_t(Θ)`,其中加权奖励 `f_t(Θ)=Σ_{k=1}^K θ^k_t r^k(t)`,各子奖励是"机器人-物体状态与参考的差异(关节/link 位置)"加上力矩、质心投影等惩罚项(细节指向 Appendix A)。简化后的 PPO 目标见式(4),梯度更新式(5)`φ←φ+β∇_φ L^hoi, v←v+β∇_v L_v`。
- **交互感知奖励(§IV-C)**:沿用 InterMimic,引入交互图跟踪奖励 `r^ig_t=exp(-θ^ig_t·e^ig_t)`,误差 `e^ig_t=||s^ig_t - s^ig_{ref,t}||²`,其中 `s^ig` 是"机器人关键 link 位置与物体关键点之间的距离表征",权重 `θ^ig_t` 由元策略预测。直觉:用接触级的距离图来直接奖励"接触是否准"。
- **非对称 Actor-Critic(§IV-C)**:critic 拿**完美状态**(本体感知、重力投影、交互图、物体特征);actor 只拿**不完美状态**(去掉交互图、物体速度与旋转),只保留 FoundationPose 检测到的物体**位置**特征。直觉:物体速度/旋转这类不稳定特征会放大 sim-to-real gap、增大策略脆弱性,所以把它们只留给训练期可用的 critic,做"特权信息蒸馏"。
- **外层自动奖励学习(§IV-D)**:每 N 个内层 PPO epoch 定义为一个潜在子任务 `T_i`,共享同一参数化奖励函数;学习参数化规则 `U_ψ`,在测试子集上最小化策略损失(式6)。用 **SAC** 优化 `U_ψ`,内层 PPO 训练任务充当交互环境:每步观测 `u_t`、执行权重动作 `Θ_t`、收到奖励 `G_t`;SAC 目标式(7)`min U_ψ = min E[-log μ^meta(Θ_t|u_t) G_t]`;权重更新式(8)`Θ'=Θ^0·σ(t)μ^meta(Θ_t|u_t)`,`σ(t)=clip(1 - c4/t, δ, 1)`(初值 Θ^0、截断 epoch c4、最小因子 δ 指向 Appendix B)。熵项温度 α=0.1。
- **元策略奖励 `G_t`(§IV-D,式9/10)**:`G_t=∇_t E_t = Δ(e_jp+e_op+e_lp)/Δt`,即关节位置误差 `e_jp=||q_t-q_{ref,t}||²`、物体位置误差 `e_op=||q^o_t-q^o_{ref,t}||²`、link 位置误差 `e_lp=||q^{link}_t-q^{link}_{ref,t}||²` 三者之和在时间窗 `Δt` 内的**变化率(梯度)**;图2 把元目标标注为"最小化位置误差梯度 `min ∇pos_error/v_t`"。换言之,元策略的奖励/目标直接锚定在"关键跟踪误差的动态"上,而非那一堆复杂的人工奖励项。*(我按 PDF 原样转写式子与图标注,不替作者补"误差降得越快奖励越高"这类符号方向的解读。)*
- **部署(§IV-A-3 / §V-D)**:先在 Mujoco 做 sim-to-sim 校验(更接近真实),再在 Unitree G1 上 sim-to-real;真实部署用 **FoundationPose** 从目标网格做位姿估计,提取物体观测。PD 控制 200 Hz(见 Fig.2)。

## 数据集 & 实验设置
- 任务:**box-picking**(取自作者自建 mocap 数据集)与 **box-pushing**(取自 Omomo 数据集)。
- 仿真:训练用 IsaacGym,部署评估用 Mujoco;均开统一域随机化(DR 细节指向 Appendix B)。
- 真实机器人:Unitree G1(Fig.1 实拍)。
- **基线兼消融**:ASAP\* 与 InterMimic\*,都对齐了 InterReal 的 DR、噪声、关键超参。ASAP\* 在原 ASAP 上加了物体跟踪;InterMimic\* 保留其主框架但统一设置。作者明确把二者视作"从 InterReal 逐步剥掉自动奖励组件、再剥掉交互图"的对照消融(§V-B)。
- 指标(§V):每关节位置误差 E_mpjpe(rad)、下肢 link 位置误差 E_mllpe、上肢 link 位置误差 E_mulpe、三关键 link 位置误差 E_m3lpe、物体位置误差 E_mope、物体旋转角误差 E_morae、交互图误差 E_mige、link 旋转角误差 E_mlrae;任务成功率由 100 次推理测试统计;成功=完成整段 HOI 任务且不摔倒。各指标计算细节指向 Appendix A。

## 主要结果 & 结论(写方向,不堆精确数字)
- 训练 5e4 个 PPO epoch 后,InterReal 在两个任务的**多数(并非全部)**跟踪指标上误差最低(见 Table I)。supported
  - 注意反例:box-pushing 的下肢 link 误差 E_mllpe 上,ASAP\* 略优于 InterReal(约 0.0015 对 0.0018,见 §V-A Table I)——所以不能说"全指标最优"。observed
- 训练曲线(Fig.3,box-picking)显示 InterReal 能较快把跟踪误差压下去并取得整体最优;InterMimic\*(固定初始奖励权重)跟踪误差明显更高,说明固定/手工奖励难达最优;ASAP\*(缺交互图特征)在物体误差上最差,因为无法感知物体细节、难以据参考准确控物。supported
- 任务成功率(Mujoco,Table II):InterReal 在两任务上成功率均最高(box-picking 96.41%、box-pushing 87.45%),高于 InterMimic\*(84.72% / 79.10%)与 ASAP\*(77.38% / 70.63%);box-pushing 整体比 box-picking 更难。supported
- 消融:自动奖励组件与交互图设置都显著提升基框架性能(由 ASAP\*/InterMimic\* 阶梯对照得出)。supported
- 内部元学习系数 δ(Fig.4,δ∈{0.0,0.1,0.25,0.50}):δ=0.1 跟踪表现最好,两端都退化,δ=0.0(即去掉自动奖励组件)最差;δ 起到缩放元策略/奖励权重更新幅度的作用。supported
- 自动奖励可视化(Fig.5):元策略预测的各奖励权重随 phase 自适应变化,在不同子任务阶段调整各奖励分量的相对重要性。observed
- 真实部署(Fig.1 / §V-D):配合训练期模拟的物体位置丢失、延迟、扰动 + 多动作增广,策略能按不同初始物体位置调整手臂、并据 FoundationPose 检测结果动态调整动作。observed(实拍演示,定性)

## 适用边界(什么时候管用 / 什么时候不管用)
- **管用**:把"已有 HOI mocap 参考动作"迁到真实人形机器人、做箱体级抓取/推动这类**接触明确、可用 IK 维持手-物接触**的全身交互技能;物体起始位置会变、需要对物体位置扰动鲁棒的场景。
- **比的是较强基线**:对照对象是 ASAP / InterMimic 经统一对齐后的真实化版本,且二者本身就是 InterReal 的逐级消融,属"自家强对照",不是弱基线;但论文未与遥操作方案做端到端对比。
- **不一定管用 / 证据不足**:仅在 box-picking、box-pushing 两类箱体任务上验证,未覆盖更广的物体形态/交互类型;真实机器人结果以单机 G1 的定性演示为主,未见大样本真实成功率统计。
- **依赖前置条件**:依赖高质量重定向(其重定向方法"后续才发表")、IsaacGym 物理校验、以及真实部署时 FoundationPose 的物体位姿估计质量。

## 核心贡献
- 提出统一的物理仿真 HOI 模仿框架 InterReal,把人-物交互模仿从动画推进到真实人形机器人部署(作者主张)。
- 提出基于 IK、保持手-物接触一致、仅改物体位置的 HOI 动作增广方案,提升对物体扰动的鲁棒性与泛化(§IV-B)。
- 提出由"关键跟踪误差"引导的元策略自动奖励学习器,用 SAC 在 PPO 训练中动态分配奖励权重,绕开大规模人工奖励调参(§IV-D)。
- 设计非对称 Actor-Critic,把不稳定的物体速度/旋转与交互图作为特权信息只给 critic,缓解 sim-to-real gap(§IV-C)。
- 在两类箱体任务上系统验证跟踪精度与成功率,并在 Unitree G1 上真实部署演示(§V)。

## 局限与我的质疑
- **预印本未经同行评审**:本文为 arXiv v1(2026-03),引用数仅 2,结论(尤其真实世界鲁棒性)应保留;对其"最佳/最高"等表述按 observed/supported 看待,勿当定论。
- **作者自述局限**:物体位置扰动仍是主要难点,根因是"被动的物体跟踪训练模式 + 真实物体检测的高方差与高延迟"(§VI),作者承认留待后续解决。
- **任务覆盖窄**:仅箱体取/推两任务,且 box-picking 用自建数据集——泛化到不同物体几何、不同接触模式(如工具使用、双物体协作)未证明,不能据此外推到"通用 HOI"。
- **真实结果偏定性**:真实机器人部分主要是 Fig.1 实拍与描述,核心定量(跟踪误差、成功率)均在仿真(IsaacGym/Mujoco)得出;sim-to-real 的真实成功率缺大样本统计。
- **方法依赖未公开环节**:HOI 重定向方法明确"后续才发表",且 Appendix A/B/C(奖励项细节、超参、PD、DR 设置)不在本 PDF 内,关键复现细节缺失,难以独立核验。
- **元奖励机制的细节存疑(我的质疑)**:元策略奖励 `G_t` 写成跟踪误差和的时间梯度(式9),而图2 元目标是"最小化该梯度",同时式(7)是 SAC 形式的 `min U_ψ`;论文未把"最小化梯度"与"SAC 最大化奖励"之间的符号/方向关系讲透,读者若要复现需回原文(及补充材料)确认 `G_t` 的确切符号约定,不宜想当然。
- **基线即消融的双重身份**:把 ASAP\*/InterMimic\* 同时当强基线和消融虽巧妙,但也意味着对照基本来自"自家组件的逐级删减",缺少与同期独立真实 HOI 方案的横向对比,优势幅度的外部参照有限。
