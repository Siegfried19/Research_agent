# InterReal: A Unified Physics-Based Imitation Framework for Learning Human-Object Interaction Skills
> D. Liang, Yuhang Lin, Xinzhe Liu, Jiyuan Shi, Yunlong Liu, Chenjia Bai · 2026 ·  · 引用 2 · DOI arxiv:2603.07516

## 一句话
InterReal 是一个物理仿真下的"运动模仿"框架,让人形机器人(Unitree G1)跟踪人-物交互(HOI)参考动作,靠 **IK 动作增广** + **自动学习奖励权重的元策略**两个组件,在搬箱、推箱两个任务上把跟踪精度和任务成功率做到优于改造后的 ASAP/InterMimic 基线,并真机落地。

## 解决了什么问题
- 已有的人形全身控制框架大多聚焦**非交互**的运动(走/跳/舞),缺少对人-物交互(HOI)的精确、反馈驱动控制能力,难以直接落到真实机器人(原文 §I)。
- 真实部署中,人和物的轨迹会有传感器扰动,**尤其是两者之间的相对位置扰动**容易把学到的策略带出分布甚至导致崩溃(原文 §I 经验观察)。
- DRL 中**奖励设计是长期瓶颈**:HOI 涉及多路异质奖励信号要平衡,手工设权"繁琐且次优",且权重应随任务阶段(phase)变化而非固定(原文 §I、§IV-C)。

## 用什么方法解决的（含直觉：为什么 work）
两个核心组件 + 一套训练/部署架构:

**1. HOI 动作增广(IK-based augmentation)——解决物体位置扰动下的泛化。**
- 直觉:真机中物体初始位置会偏,若只用一条参考动作,策略对位置偏移很脆。于是人为给物体在 XY 平面注入偏移 `Δp_xy`,**再用逆运动学(IK)重解手臂关节角**,使手-物接触细节("hand-object contact details")与原始锚定动作保持一致,从而批量造出"同一任务、不同物体位置"的多条参考动作(原文 §IV-B)。
- 关键是**先把世界系动作转到骨盆系再解 IK**,再用 Ipopt 非线性优化器迭代求解手臂关节角;偏移在 `linspace(-ε, ε, √c₃)` 上取离散网格生成多条动作 `{Mʲ}`(原文 §IV-B)。
- 公式(式2):`p̂^(w)(t)=p^(w)(t)+Δp_xy`、左右末端 `p̂_{L/R}^(w)(t)=p_{L/R}^(w)(t)+Δp_xy^j`;式3 把腕/末端位置经变换矩阵转到躯干与骨盆系 `p̂_{L/R}^(p)(t)=T_(p←t)T_(t←w)p̂_{L/R}^(w)(t)`。
- 为什么 work:训练时就见过多种初始物体位置 + 保持接触一致,策略学会"按当前物体位置调整手臂行为",对真机的物体姿态偏差更鲁棒(原文 §V-D)。

**2. 自动奖励学习(outer-loop 元策略)——解决奖励配权难题。**
- 直觉来源(原文明确点出):作者观察到"基于运动模仿的 DRL 任务有一个清晰的高层目标——最小化机器人轨迹与参考轨迹的若干关键位置跟踪误差"。于是不去手调一堆子奖励权重,而是**用一个元策略 μ^meta 把若干关键跟踪误差作为学习信号,动态调整奖励权重 Θ**(原文 §IV-C/D)。
- 元策略奖励(式9):`G_t = ∇_t E_t = Δ(e_jp + e_op + e_lp)/Δt`,即一个时间窗内"关节位置误差 + 物体位置误差 + link 位置误差"之和的**变化量**(误差下降得快 → 奖励高)。式10:`e_jp=‖q_t−q_ref,t‖²`,`e_op=‖q_t^o−q_ref,t^o‖²`,`e_lp=‖q_t^link−q_ref,t^link‖²`。
- 外层用 **SAC** 优化(式7):`min E[−log μ_ψ^meta(Θ_t|u_t)·G_t]`;权重更新(式8)`Θ'=Θ⁰·σ(t)μ_ψ^meta(Θ_t|u_t)`,`σ(t)=clip(1−c₄/t, δ, 1.)`,其中 `δ` 是缩放下限。每 N 个内层 PPO epoch 才更新一次外层,开销轻量。
- 为什么 work:奖励权重随训练进度/任务阶段自适应。论文举例——搬箱早期元策略能识别"平衡是首要目标",给平衡相关奖励更大信号(原文 §IV-C);Fig.5 展示各奖励权重确实随 phase 自适应变化。

**3. 内层 HOI 策略学习 + 非对称 Actor-Critic。**
- 内层用 PPO 优化 `π^hoi`,目标 `max Σ_t γ^t f_t(Θ)`,加权奖励 `f_t(Θ)=Σ_k θ_t^k r^k(t)`(原文 §IV-C)。引入借鉴 InterMimic 的**交互图(interaction-graph)跟踪奖励** `r^ig=exp(−θ^ig·e^ig)`,`e^ig=‖s_t^ig−s_ref,t^ig‖²`,鼓励机器人 link 与物体关键点之间的接触准确。
- **非对称 Actor-Critic**(关键工程点):critic 用"完美/特权状态"(本体 + 重力投影 + 交互图 + 物体速度/旋转),actor 只用"不完美状态"——**故意排除交互图、物体速度和旋转**,actor 只吃 FoundationPose 检测出的物体**位置**特征。直觉:物体速度/旋转在真机里不稳,会放大 sim-to-real gap 和策略脆性,所以训练时让 critic 蒸馏特权信息、actor 只依赖真机能稳拿到的量(原文 §IV-C)。

**4. 部署。** 训练在 IsaacGym(域随机化),先 sim-to-sim 到 MuJoCo 验证,再 sim-to-real 到 Unitree G1;真机用 FoundationPose 从目标 mesh 做位姿估计提取物体观测,PD 控制 200Hz(原文 §IV-A、Fig.2)。

## 动机 & 背景
- 物理仿真模仿学习近年在人形机器人(走/跳/舞)上进展显著,但**交互能力缺失**限制了工业等真实 HOI 场景应用(原文 §I)。
- 现有机器人交互方案多依赖**上半身遥操作**,约束了人形机器人自主性;近期 CLONE/TWIST/OpenWBT 等全身控制器虽能通用运动跟踪,但**没有显式设计面向交互的反馈驱动控制器**(原文 §I、§II)。
- 动画领域的 HOI 模仿(RMD、TokenHSI、InterMimic 等)成果丰富,但即便像 InterMimic 考虑了物理(小质量/摩擦),仍是"理想化物理世界",难直接迁移真机(原文 §II)。
- 本文把动画域的 HOI DRL 模仿**扩展到基于真实世界的人形机器人**。

## 方法细节
- **问题建模**:HOI 任务建为 MDP `(S,A,P,f_t,γ)`,动作空间 `A∈R²³`(对应机器人自由度),用 PPO 优化期望折扣回报。状态 `s_t=[s_t^h, s_t^o, s_t^int, p]`:本体 `s_t^h=[q_t, q̇_t, ω_t^root, g_t, a_{t-1}]`(关节位/速、root 角速、重力投影、上一动作),物体 `s_t^o=[q_t^o, q̇_t^o, ϑ_t^o]`(全局位置/速度/朝向),交互特征 `s_t^int=[h_t^o, s_t^ig]`(接触布尔状态 + 交互图),`p` 为任务阶段(原文 §III-A、§IV-A)。详细参数指向 Appendix B。
- **运动预处理三步**(原文 §IV-A、Fig.2a):① HOI 运动重定向(把 SMPL mocap 重定向到 G1,优化人/物/地接触自然度,"该方法将另文发表");② 物理验证(借 InterMimic 在 IsaacGym 用物理约束验证重定向动作,滤除穿模/碰撞/无效参考);③ HOI 动作增广。
- **双层训练**(原文 §IV-A-2、Fig.2c):内层 multi-env PPO 学任务专属 `π^hoi`,外层元策略 `μ^meta` 学"如何学" `π^hoi`(学奖励权重)。框架在 ASAP 之上扩展为 HOI 跟踪,并叠加多动作训练。
- **PPO 目标**(式4):`L^hoi=E[−(π_φ(a|s^im)/π_φ_old(a|s^im))(Σ_t Σ_k θ_t^k r^k(t)−V_v(s_t))]`,梯度更新式5 `φ←φ+β∇_φL^hoi`、`v←v+β∇_v L_v`;注意 critic 用完美状态 `s_t`、actor 用不完美状态 `s_t^im`,replay buffer 在 t-epoch 视界内构建。
- **元学习设定**(原文 §III-C、§IV-D):每 N 个内层 PPO epoch 视为一个 latent subtask `T_i~p(T)`,各 subtask 共享 P 但奖励函数不同;用 SAC 作为元学习器学这些 latent subtask 的奖励函数(式6/7/8)。还引入熵项 `H=−αE[log μ^meta]`,初始温度 `α=0.1`。
- 注:Appendix A(奖励项细节/指标计算)、Appendix B(参数/DR 设置)、Appendix C(电机 PD 列表)在正文被多次引用,但**本 PDF 副本只到参考文献页、未含这些附录正文**(可能在 supplementary 材料中)。

## 数据集 & 实验设置
- 任务:**搬箱(box-picking,来自作者自采 mocap)** 和 **推箱(box-pushing,来自 Omomo 数据集)**(原文 §V)。
- 仿真:训练 IsaacGym(统一域随机化),评估 MuJoCo;真机 Unitree G1。
- 基线:**ASAP\*** 和 **InterMimic\***——把两者改造对齐 InterReal 的一致设置(DR/噪声/关键超参);ASAP\* 在原 ASAP 基础上**额外加了物体跟踪**,InterMimic\* 保留原框架但用一致设置(原文 §V Baselines)。作者强调现有开源 HOI 跟踪多在动画域、几乎不支持真机,故需自行改造做公平比较。
- 指标:多种跟踪误差——`E_mpjpe`(每关节位置误差,rad)、`E_mllpe`(下肢 link 位置)、`E_mulpe`(上肢 link 位置)、`E_m3lpe`(三关键 link 位置)、`E_mope`(物体位置)、`E_morae`(物体旋转角)、`E_mige`(交互图误差)、`E_mlrae`(link 旋转角);以及**任务成功率**(100 次测试、不摔倒且完成整个 HOI 任务记为成功)(原文 §V、表I/II)。
- 消融:自动奖励组件、交互图、元学习内系数 `δ∈{0.0,0.1,0.25,0.5}`(原文 §V-B、Fig.4)。

## 主要结果 & 结论（写方向，不堆精确数字）
- **跟踪精度**:在搬箱、推箱两任务、训练约 5e4 PPO epoch 后,InterReal 在**多数跟踪指标上误差最低**(表I);例如上肢 link 位置误差 `E_mulpe` 和三关键 link 误差 `E_m3lpe` 上最低。supported(系统对比两任务多指标)。
- **任务成功率**:InterReal 搬箱约 96%、推箱约 87%,均高于 ASAP\*(约77%/71%)与 InterMimic\*(约85%/79%)(表II,§V-A)。supported。推箱比搬箱更难成功(原文明确指出)。observed→supported(两任务都验证)。
- **趋势**(Fig.3):InterReal 能"快速降低跟踪误差并最终取得最优";InterMimic\* 用**固定初始奖励权重**导致跟踪误差明显更高——佐证"固定/手调奖励难得最优";ASAP\* 因缺交互图特征、无法直接感知物体细节,物体误差最差(原文 §V-A)。observed。
- **消融-自动奖励**:把 ASAP\*/InterMimic\* 视作"逐步剥离自动奖励组件与交互图设置"的对照,可见两者都显著提升基础框架性能(原文 §V-B)。supported。
- **消融-δ**:`δ=0.1` 跟踪最好,两端(0.0 与 0.5)退化,**`δ=0.0`(即去掉自动奖励)最差**(Fig.4,§V-B)。supported。
- **自适应权重**(Fig.5):元策略预测的各奖励权重随完整 HOI phase 自适应变化,引导底层 PPO 在不同子阶段采用不同控制策略。observed(可视化层面)。
- **真机**(Fig.1、§V-D):G1 能实时感知箱子姿态,边走边搬/持续推箱,并能依 FoundationPose 检测到的物体位置实时调整手臂行为;模拟了物体位置丢失/延迟/扰动来保证部署稳定。observed(真机演示,无成功率统计)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:刚性物体的全身 HOI 任务(搬箱、推箱这类抓取/推动),物体可由位姿估计(FoundationPose)从已知 mesh 稳定检测出**位置**;初始物体位置在训练注入的偏移网格 `[-ε, ε]` 覆盖范围内。
- **依赖前提**:需要 mocap 参考动作 + 重定向 + 物理验证流水线;需特权状态(交互图/物体速度旋转)做 critic 蒸馏,真机只靠物体位置驱动 actor。
- **可能不管用 / 未验证**:物体**速度、旋转**抖动大或位姿估计高方差/高延迟时,作者自述这是主要遗留难点(§VI);对非刚性物体、多物体、需精细力控或与原箱体差异很大的物体,论文未涉及;只在两个箱子类任务上验证,**跨任务/跨物体类别的泛化未证明**。
- **基线强度**:对比的是作者**自行改造**的 ASAP\*/InterMimic\*(为公平对齐设置),非各方法原版最优配置——需注意这点。

## 核心贡献
1. 提出统一的物理仿真 HOI 模仿框架 InterReal,把动画域 HOI 模仿扩展到真实人形机器人并真机落地(Unitree G1)。
2. **IK 驱动的 HOI 动作增广**:注入物体位置偏移 + IK 重解手臂、保持手-物接触一致,造多动作训练以增强对物体扰动的鲁棒性。
3. **自动奖励学习的元策略**:以关键跟踪误差的变化为信号(SAC 外层),动态分配大规模奖励权重,免去手工配权。
4. 非对称 Actor-Critic 设计:critic 用特权状态、actor 只用真机可稳得的物体位置,降低 sim-to-real 脆性。
5. 在搬箱/推箱上系统比较,取得最优跟踪精度与最高成功率,并做 δ/组件消融。

## 局限与我的质疑
1. **预印本、未经同行评审**(arXiv v1,2026-03-08,引用仅 2);所有结论按未验证看待保留。
2. **作者自述局限**(§VI):对物体位置扰动的鲁棒性仍不足,根因是"被动的物体跟踪训练模式"+真机物体检测的高方差与高延迟——这恰恰是 HOI 真机落地最关键的环节,说明当前方案在最难处仍未解决。
3. **只在两个任务、刚性箱子上验证**,且都是"搬/推箱"同族;论文未给跨物体类别、跨任务、变箱体形状的泛化实验,却在结论用"promote the application of humanoid robots in specific complex interactive tasks"等措辞,有过度外推之嫌——其证据只支持"在这两个任务上更好"。
4. **基线是自行改造的 ASAP\*/InterMimic\***,改造细节(对齐了哪些超参、ASAP\* 加物体跟踪是否充分调优)对结论很关键,但量化设置散落在未含于本 PDF 的附录,**无法核验公平性**;"ASAP\* 物体误差最差"可能部分源于改造而非方法本质差异。
5. **真机部分只有定性演示(Fig.1)**,没有真机的成功率/失败率/重复次数统计,96%/87% 成功率都是 **MuJoCo 仿真**里测的,真机有效性的强度被图文叙述放大了。
6. **元策略奖励 `G_t` 只用误差的瞬时变化(Δerror/Δt)**作信号,可能偏向短期下降快的方向、对长期稳定性/局部最优的处理论文未讨论;δ 消融显示对该缩放系数较敏感(0.1 最优、两端退化),暗示自动奖励机制本身仍需手工调一个关键超参,"自动"并不彻底。
7. **关键依赖 FoundationPose 与已知物体 mesh**:遇到未知/无 mesh 物体或遮挡严重时如何退化,论文未给。
8. 与本研究主题(物理仿真模仿学习训 humanoid 学 HOI 全身技能)高度契合,但**重定向方法"另文发表"、奖励项/参数/PD 表全在附录**,本副本未含,复现性受限;`E_mige` 等指标单位(e-7)量级异常,缺附录定义难判读。
