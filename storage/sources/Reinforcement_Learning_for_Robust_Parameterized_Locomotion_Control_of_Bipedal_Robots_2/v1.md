# Reinforcement Learning for Robust Parameterized Locomotion Control of Bipedal Robots
> Zhongyu Li, Xuxin Cheng, Xue Bin Peng, Pieter Abbeel, Sergey Levine, Glen Berseth, Koushil Sreenath · 2021 · arXiv · 引用 12 · DOI 10.48550/arxiv.2103.14295

## 一句话
用 model-free RL（PPO）在仿真里训练一个**参数化**步行策略，让它去模仿一个 HZD 步态库里的大量参考步态，并配合带课程的域随机化，最终把策略**零额外真机训练**地迁移到真实 Cassie 双足机器人，能在线指定行走速度/高度/转向并对扰动、电机损坏、地面变化保持鲁棒。

## 解决了什么问题
- 传统基于模型的双足控制（ZMP、capturability、HZD 等）依赖精确建模与简化假设，难以适应环境变化，且生成的动作偏慢、偏保守（作者综述其 related work 的论断）。
- 此前在 Cassie 上的 RL 工作多用**残差控制（residual control）**：在一个已有 model-based 控制器输出的参考动作上学小幅修正，作者指出这会限制策略只能贴着参考动作、行为多样性受限、且仍需一个 model-based 控制器在场（作者对 [4][5] 的评述）。
- 目标：得到一个**单一策略**，能在线切换/过渡多种步态（不同前进/侧向速度、不同行走高度、转向），同时比 model-based 与残差方法更鲁棒。

## 用什么方法解决的（含直觉：为什么 work）
- **参数化 + 模仿步态库**：先用 HZD 优化离线生成一个步态库 G，每个步态由 5 阶 Bézier 曲线编码 10 个驱动关节的周期轨迹；步态参数 `p = [q̇x, q̇y, qz]^T ∈ R³`（前进速度、侧向速度、行走高度）。在线给一个期望参数 `p^d`，对步态库插值得到参考步态 `g^r`，RL 策略去**跟踪/模仿**它。直觉：步态库提供"长什么样才像走路"的密集参考信号，让 RL 不必从零探索周期步态；而把参数 `p` 暴露成可调输入，使一个策略覆盖一族行为而非单一动作。
- **不是残差、是端到端**：策略直接输出 10 维目标电机位置（`a_t = q_m^d`），不在 model-based 输出上加修正。直觉（作者解释）：非残差给了策略**更大的自由度去偏离参考动作**来完成恢复，这正是它比残差更鲁棒的原因（supported，见下文实验）。
- **域随机化 + 课程**：训练时随机化质量、质心、关节阻尼、地面摩擦、传感器噪声、通信延迟等（Table II），覆盖 sim-to-real 的不确定性；且**课程式**地在前 2000 次迭代里把随机化范围从默认值线性退火放大到最大范围。直觉：一上来就全量随机化，策略会退化成"原地站着最稳"这种保守次优解；先易后难能避开这个陷阱（作者明确举此例）。
- **非对称 actor-critic**：value 网络额外拿到真值状态 `s^{gt}` 和随机化的动力学参数 `μ`，而 policy 只拿带噪声/延迟的可观测状态。直觉：让 critic"看得见"真实动力学以给出更准的价值估计，policy 仍只用真机可得的信息——便于迁移。

## 动机 & 背景
- 平台 Cassie：人体尺寸、欠驱动双足，20 DoF，其中 10 个驱动转动关节 `q_m`，还有对应小腿/tarsus 的被动关节；浮动基座 pelvis 有 3 平动 + 3 转动 DoF。可观测状态 `q^o ∈ R¹⁷` 不含 pelvis 平动位置 `q_{x,y,z}`（真机无外部仪器测不到）。
- 作者把工作定位为 HZD 与 RL 的结合：HZD 用来**离线造参考步态库**，RL 用来**在线学鲁棒跟踪**——RL 这边不受"精确模型 + 收敛到周期轨道"的约束，因此能产生比纯 HZD 更多样的行为（作者主张）。
- sim-to-real 路线：用低保真但快的 MuJoCo 训练 → 高保真 MATLAB SimMechanics 评测 → 真机部署，全程靠域随机化跨越 reality gap，**不在真机上做任何额外训练**。

## 方法细节
- **动作空间**：`a_t = q_m^d` 为 10 个电机的目标位置；先过一个低通滤波器（LPF）再送到 2000 Hz 的关节级 PD 控制器生成力矩 `u`。LPF 的作用是让动作更平滑。
- **状态空间**：`s_t = (q^o_{t-4:t}, a_{t-4:t-1})`——当前及过去 4 步的可观测状态（共 5 帧）+ 过去 4 步的动作。这段历史让策略能**推断系统动力学**（部分可观下的隐式系统辨识）。
- **目标（goal）**：时间相关 `g_t`，由参考动作的若干目标帧给出：`g_t = (c(t), g^r(t), g^r(t+1), g^r(t+4), g^r(t+7))`，含 1) 当前用户命令，2) 当前与采样的未来若干步的参考电机位置 `q_m^r` 与速度 `q̇_m^r`。
- **奖励函数**（鼓励复现步态库参考动作）：
  - 总奖励 `r_t = ω · r_t^o`（式1），`r_t^o = [r_t^m, r_t^p, r_t^p, r_t^r, r_t^t, r_t^u, r_t^f]^T`（式2），权重 `ω = [0.3, 0.24, 0.15, 0.13, 0.06, 0.06, 0.06]`（式3，手工设定）。
  - 电机跟踪 `r_t^m = exp[-ρ1 ||q_m^d - q̂_m||²]`（式4）；`r_t^p`、`r_t^p`、`r_t^t` 同样形式分别鼓励跟踪 pelvis 平动位置、平动速度、机器人局部系下的速度。
  - pelvis 转动 `r_t^r = exp[-ρ4 ||q_r^d ⊖ q̂_r||²]`，`⊖` 为两旋转间的测地距离。
  - 力矩 `r_t^u = exp[-ρ6 ||u||²]`（省能）；地面反力 `r_t^f = exp[-ρ7 ||q̂_f||²]`（减小竖直方向地反力）。
  - 关键设计：期望 roll/pitch 速度恒为 0（稳住 pelvis），期望 yaw 速度由用户命令给；位置项（pelvis 平/转位置）不显式给目标，由速度积分得到。注意——**参考步态库本身不编码转向 yaw**，所以在奖励里放非零转向 yaw，是在鼓励策略学出步态库没有的行为（这是它能转向的来源之一）。
- **学习模型**：目标 `J(θ) = E_{τ~p_θ(τ)}[Σ_{t=0}^T γ^t r_t]`（式5），用 **PPO** 训练。policy 与 value 网络各 2 隐层、每层 512 个 tanh 单元；policy 输出 10 维高斯 `N(m_π, Σ_π)`，**学习均值、固定标准差 `Σ_π = 0.1 I`**。
- **频率/回合**：policy 30 Hz、PD 2000 Hz；每回合 `T=2500` 步 ≈ 83 s；每 8 s 重新均匀采样一个命令 `c(t)`，命令范围 `[-2, -0.8, 0.65, -π/6]` 到 `[2, 0.8, 1.0, π/6]`（含转向 yaw），每回合首命令恒为随机的"前进行走"。提前终止：pelvis 高度 < 0.55 m 或 tarsus 关节触地。
- 注意：**训练命令范围比步态库参数范围更大**（Table I 步态库前进速度仅到 1.0 m/s，训练命令到 2 m/s），意图让策略学到超出步态库能提供的行为。

## 数据集 & 实验设置
- **步态库 G**（Table I，via CFROST 优化）：`q̇x ∈ [-1, …, 1.0]`、`q̇y ∈ [-0.3, …, 0.3]`、`qz ∈ [0.65, …, 1.0]`，11×11×11 = **1331 个步态**。
- **域随机化范围**（Table II）：连杆质量/质心/关节阻尼均 `[0.75, 1.15]×default`，地面摩擦比 `[0.5, 3.0]`，电机转动噪声/角速度噪声 `[-0.1, 0.1]`，加速度计噪声 `[-0.4, 0.4]`，陀螺噪声 `[-0.1, 0.1]`，通信延迟 `[0, 0.03] s`。
- **三套域**：MuJoCo（训练，开源 cassie-mujoco-sim）；MATLAB SimMechanics（高保真测试，比实时慢约一个数量级）；真实 Cassie（部署验证）。
- 课程总样本量约 `6.6e7`。
- **评测指标**：Feasible command set（不会让控制器失败的输入参数 `p^d` 集合）与 Safe set（控制器在真机/仿真实际能稳住 15 s 的步态参数集合，并记录实际达到的 `p̃`）。两集合形状越接近，说明跟踪误差越小。

## 主要结果 & 结论（写方向，不堆精确数字）
- **课程有效**：带随机化课程（CR）比无课程（NCR）学得更快、收敛回报更高；NCR 一开始就全量随机化会被逼成"过度保守"的次优策略（supported，Fig 3a）。
- **非残差 > 残差（鲁棒性）**：无扰动时残差（RC）与非残差（NRC）性能相近、RC 略好；但**在扰动/鲁棒性测试中非残差更鲁棒**，作者归因于非残差有更大自由度偏离参考动作来恢复（supported，Fig 3b 及后续扰动实验）。
- **比 HZD 基线覆盖更广**：RL 控制器的 feasible command set 比 HZD 基线 [17] **大 4 倍以上**；safe set 也更广，尤其在前进速度与行走高度方向（observed/supported，Fig 4）。RL 可做约 -1.2~1.2 m/s 的前后行走，HZD 基线低于 1 m/s；HZD 能走到更低高度（约 0.6 m）但其跟踪误差不可忽略，RL 最低约 0.65 m（具体数值见 §IV-B 与 Fig 4）。
- **RL 不严格跟命令、而是找"接近且更稳"的步态**：给 2 m/s 命令时实际约到 1.2 m/s（超出步态库范围），即它在可行性与稳定性间折衷（observed，§IV-B）。
- **扰动鲁棒性排序**：施加 6-DoF 随机推力时，`NRC+步态库(GL) > NRC+单步态(SG) > RC+单步态(SG)`，且在**大扰动**（β∈{0.8,1}）下本文方法优势更明显（observed，Fig 6，每点为 32 次 roll-out 平均）。
- **真机鲁棒性（定性）**：快速前后行走、侧走、转向、踩到滑动物/脚下被扰、未知负载、不同地面摩擦、防滑/打滑均能稳住（observed，Fig 5，视频）。
- **电机损坏仍能走（亮点案例）**：真机实验中右侧 rotation `q_2^R` 与右膝 `q_4^R` 两个电机部分损坏、出力不足，工厂默认控制器与 HZD 基线都无法稳定产生步态；而本文策略（因训练时随机化了各关节阻尼）**首次部署、无需额外调参**即能驱动受损机器人行走并能从降高恢复（observed，§IV-C）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：Cassie 这类欠驱动双足、有可离线生成的 HZD 步态库、在线需要可调速度/高度/转向、且面对建模误差/外扰/地面变化/部分电机失效的场景；快速仿真训练 + 域随机化 + 零真机训练迁移。
- **边界/不确定**：
  - 强烈依赖一个**已有的 HZD 步态库**提供参考——没有这套 model-based 工具链时方法不能直接照搬（虽然 RL 用步态库而非精确模型，但步态库本身要先造出来）。
  - 在**低行走高度**这一方向，HZD 基线反而能到更低（约 0.6 m，但跟踪误差大），RL 在该极端不占优。
  - 转向 yaw 是靠奖励"逼"出来的（步态库不含），其能力上界与质量主要靠定性展示，未见系统量化。
  - 命令被故意设得超出步态库范围，导致**不严格跟踪命令**——需要精确速度/高度跟踪的应用要注意这点。
  - 所有结论均在 Cassie 单一平台上验证，未在其它形态机器人上证明泛化。

## 核心贡献
- 提出一个**结合 HZD 步态库 + model-free RL（PPO）** 的参数化双足步行控制框架，单策略可在线指定并过渡多种步态（速度/高度/转向）。
- 主张并以实验支撑**非残差**控制 + **带课程的域随机化**，相比此前 Cassie 上的残差控制方法获得更大可行命令集、更大安全集、更好跟踪与更强鲁棒性。
- 真机零额外训练迁移，展示对建模误差（含两个电机损坏）、外部推力、负载、地面摩擦变化的鲁棒恢复（作者自称"据其所知是首个用参数化 RL 在 Cassie 上实现可走/转/蹲的多样且鲁棒步态"）。

## 局限与我的质疑
1. **预印本、未经同行评审确认**：本总结基于 arXiv v1（2021-03），结论应保留；引用数也偏低，外部验证有限。
2. **结果多为定性 / 单平台**：真机鲁棒性（侧走、转向、负载、打滑、电机损坏）几乎都是图+视频的定性展示，缺成功率、统计、可复现的量化指标；扰动量化实验（Fig 6）只在 MuJoCo 里做、不在真机，且每点仅 32 次 roll-out，误差棒提示方差不小。"更鲁棒"的强度我判为 observed/supported，不宜读成普适结论。
3. **基线对比的公平性存疑**：与之比较的 HZD 基线和残差方法都来自作者团队此前工作（[17][5]），调参充分度、是否在相同随机化/扰动预算下比较，文中交代不足；"feasible set 大 4 倍"这类数字依赖各自集合的测试网格与判定阈值，敏感于设置。
4. **奖励权重与缩放因子全靠手工设定**（`ω` 与各 `ρ_i`），未给消融或敏感性分析，难判断结果对这些超参的依赖程度；"课程/非残差更好"虽有学习曲线支撑，但只各一对曲线，样本量（随机种子数）未明确。
5. **"不严格跟踪命令"既是特性也是隐患**：把命令范围故意放大到步态库之外，使策略折衷出更稳但不达标的步态——这让"覆盖更大命令集"的说法需要打折，因为部分命令是"能不摔"而非"能准确执行"。
6. **与本研究主题（可交互数字人 / 通用 RL 工具箱）的距离**：这是高度领域定制的双足 locomotion 工作，许多 trick（HZD 步态库、Cassie 专属状态/奖励设计）迁移性有限；可复用的通用经验主要是**域随机化课程退火、非残差给恢复自由度、非对称 actor-critic（critic 喂真值+动力学参数）、动作 LPF + 历史观测做隐式系统辨识**这几条，而非整套管线。
