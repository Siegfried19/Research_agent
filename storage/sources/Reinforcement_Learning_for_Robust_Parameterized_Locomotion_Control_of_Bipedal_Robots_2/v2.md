# Reinforcement Learning for Robust Parameterized Locomotion Control of Bipedal Robots
> ["Zhongyu Li", "Xuxin Cheng", "Xue Bin Peng", "Pieter Abbeel", "Sergey Levine", "Glen Berseth", "Koushil Sreenath"] · 2021 · arXiv · 引用 12 · DOI 10.48550/arxiv.2103.14295

## 一句话
用 model-free 强化学习（PPO）让策略去**模仿一个 HZD 生成的步态库**，再配上**课程式域随机化**，训练出一个能在线调速度/朝向/身高、且能 sim-to-real 迁移到真实 Cassie 双足机器人的鲁棒行走控制器。

## 解决了什么问题
- 传统 model-based 双足控制（ZMP、capturability、HZD 等）依赖精确建模与简化假设，难以适应环境变化、运动偏保守、可调行为有限。(supported)
- 此前 Cassie 上的 RL 多采用**残差控制**（在 model-based 参考轨迹上学小幅修正，见 [4][5]），需要一个预先存在的控制器、且学到的行为被限制在贴近原始参考轨迹附近，行为多样性受限。(supported)
- 作者要的是：一个端到端、不依赖运行时 model-based 控制器、能同时调"行走速度 + 行走高度 + 转向偏航"，并且对建模误差/扰动/环境变化鲁棒的参数化行走控制器。(supported)

## 用什么方法解决的（含直觉：为什么 work）
- **核心思路**：不直接在真机上学（危险），而是在 MuJoCo 仿真里训练策略去**模仿一个离线优化好的 HZD 步态库**，外加域随机化，再迁移到真机。直觉：步态库提供了"什么是合理双足步态"的丰富参考，避免 RL 从零乱探索；域随机化覆盖了仿真与真实的动力学不确定性，使策略迁移时不崩。(supported)
- **为什么用步态库而非单一参考运动**：用一整个低维参数化步态库当参考，扩大了机器人能学到的行为多样性——既支持在线低维参数化控制不同步态，又通过让机器人见过更多潜在运动来提升鲁棒性。(supported)
- **为什么不用残差控制（这是本文相对前作的关键区别）**：非残差（NRC）策略能更自由地偏离参考运动，从而在受扰时有更大空间去恢复；作者推测这正是非残差策略比残差策略更鲁棒的原因（"the non-residual policy's greater flexibility to deviate from the behaviors prescribed by the reference motion in order to recover from perturbations"）。(supported)
- **为什么用课程**：一上来就开满域随机化，策略容易学到"原地站着不摔"这种过度保守的次优策略（站立比行走更稳更易学但没用）；因此把随机化范围在训练前期逐步放大，逼策略先学会走再学会抗扰。(supported)

## 动机 & 背景
- 双足 locomotion 的难点：高自由度、混合非线性动力学、难以建模的地面冲击。(supported)
- Related work 把方法分为：基于步态稳定性概念的传统法（ZMP/capturability/约束优化）、HZD（基于输入-输出线性化生成稳定周期步态）、以及 RL 类方法（含多足/低维双足上的成果，和近期 Cassie 上的 model-based RL [29][30] 与残差 RL [4][5]）。(supported)
- 作者定位：本文基于 RL，**不受"精确模型 + 稳定到周期轨道"约束**（HZD 需要这个），因而能产生更多样的行为。(supported)

## 方法细节
- **机器人**：Cassie，人体大小、欠驱动双足，20 自由度。10 个驱动转动关节 q_m（外展/旋转/髋俯仰/膝/脚趾电机），另有被动的小腿与跗骨关节。浮动基 pelvis 有 3 平动 + 3 转动自由度。完整状态 q∈R^20；可观测状态 q^o∈R^17（**排除了 pelvis 平动位置 q_{x,y,z}**，因真机无外部仪器测不到）。(supported)
- **步态库**：用 5 阶 Bézier 曲线表示 10 个驱动关节的平滑轨迹；步态参数 p=[q̇_x, q̇_y, q_z]^T∈R^3（前进速度、横向速度、行走高度）。步态库在 CFROST 里优化得到，规模为 11×11×11=1331 个步态（见 Tab.I）。(supported)
- **参考步态 g^r**：给定期望步态参数 p^d，对步态库按 p^d 插值得到参考步态。(supported)
- **动作空间**：a_t = q_m^d，即 10 个电机的**目标位置**（策略输出）；先过低通滤波（LPF）再交给关节级 PD 控制器算出力矩 u。(supported)
- **状态空间**：s_t=(q^o_{t-4:t}, a_{t-4:t-1})，即当前+过去 4 步的可观测状态，加上过去 4 步的动作。直觉：这段历史让策略能推断系统动力学（如延迟、噪声）。(supported)
- **目标 g_t（时变）**：g_t=(c(t), g^r(t+1), g^r(t+4), g^r(t+7))，含当前用户命令 + 当前与若干未来采样时刻的参考电机位置 q_m^r 与速度 q̇_m^r。用户命令 c=[p^d, q̇_φ^d]=[q̇_x^d, q̇_y^d, q_z^d, q̇_φ^d]（期望步态参数 + 期望转向偏航速度）。(supported)
- **奖励**：r_t = ω·r_t^o，其中 r_t^o 含 7 项，权重 ω=[0.3, 0.24, 0.15, 0.13, 0.06, 0.06, 0.06]（见式(3)）。(supported)
  - **电机跟踪奖励**：`r_t^m = exp[−ρ1 ||q_m^r − q̂_m||²]`，鼓励实际电机位置 q̂_m 逼近**参考运动 q_m^r**（注意：参考是 q_m^r；q_m^d 是策略输出的目标电机位置，二者不同）。见式(4)。(supported)
  - pelvis 平动位置、平动速度、转动 三项跟踪奖励与式(4)同形；其中 pelvis 转动奖励 `r_t^r = exp[−ρ4 ||q_p^r ⊖ q̂_p||²]`，⊖ 表示两旋转角间的测地距离。(supported)
  - 力矩奖励 `r_t^τ = exp[−ρ6 ||u||²]`（省能耗）；地面反作用力奖励 `r_t^f = exp[−ρ7 ||q̂_f||²]`（压低竖直方向力）。(supported)
  - 期望 roll/pitch 速度恒设 0（稳住 pelvis），期望 yaw 速度由用户命令给。无显式位置项，位置由速度积分得到。注意：步态库不含转向偏航信息，所以在奖励里放非零转向偏航能促使策略学出步态库未提供的行为。(supported)
- **域随机化（Tab.II）**：连杆质量/质心/关节阻尼 ×[0.75,1.15]、地面摩擦比 [0.5,3.0]、电机角/角速度噪声与陀螺噪声 [-0.1,0.1]、加速度计噪声 [-0.4,0.4]、通信延迟 [0,0.03]s。针对三类不确定性：建模误差、传感噪声、策略与关节控制器间的通信延迟。(supported)
- **课程**：前 2000 次训练迭代内，把随机化参数的上下界从默认值**线性退火到 Tab.II 的最大范围**。(supported)
- **学习模型**：PPO；策略与价值网络各 2 隐层 × 512 tanh 单元。策略输出 10 维高斯 N(m_π, Σ_π)，**标准差固定 Σ_π=0.1I**、只学均值。价值网络可访问 ground-truth 状态 s^gt 且把随机化的动力学参数 μ 也作为输入（即不对称/特权信息 critic）。(supported)
- **训练设置**：策略 30 Hz、关节级 PD 2000 Hz；每回合最多 T=2500 步（约 83 s）；命令 c(t) 每 8 s 均匀重采样一次，范围 [-2, -0.8, 0.65, -π/6] 到 [2, 0.8, 1.0, π/6]；每回合首命令固定为某个前进行走、0 偏航、身高>0.9m。**训练命令范围比步态库参数范围更大**（Tab.I），因此能学到超出步态库的命令跟踪。早停条件：pelvis 高度 < 0.55 m，或跗骨关节触地。(supported)
- **三个评测域**：MuJoCo（训练域）→ MATLAB SimMechanics（高保真，比实时慢约一个数量级，主要用于测试）→ 真实 Cassie。(supported)

## 数据集 & 实验设置
- 无外部数据集；"数据"= MuJoCo 仿真 rollout。参考运动来自 CFROST 离线优化的 HZD 步态库。(supported)
- 鲁棒性定量评估靠两个集合（在 SimMechanics 里测）：**feasible command set**（不会导致控制器失败的命令集）与 **safe set**（控制器在真机上实际达成的稳定步态参数集）。测试范围 p^d 从 [-1.1,-0.6,0.65] 到 [2,0.6,1.0]，分辨率 [0.1,0.1,0.05]（见 §IV-B）。(supported)
- 扰动实验（Fig.6）在 MuJoCo：对 pelvis 以概率 0.15%·β、每步施加持续随机时长 [0,0.8β]s 的 6-DoF 力，β∈[0,1] 为扰动强度；Normalized Return = 每模型每个 β 取 32 次 rollout 的平均奖励。(supported)

## 主要结果 & 结论（写方向，不堆精确数字）
- **课程有效**：带课程（CR）比不带课程（NCR，从头开满随机化）学得更快、收敛回报更高；NCR 因一开始随机化太强而学出过度保守的次优行为。(supported)
- **残差 vs 非残差（无扰动时）**：在无外部扰动下两者性能相近，但**非残差（NRC）略好于残差（RC）**（"the non-residual policy performing marginally better than the residual policy"，见 §IV-A、Fig.3b）。(supported)
- **残差 vs 非残差（有扰动时）**：在后续实验中，带域随机化的非残差策略比残差策略**更鲁棒**。(supported)
- **相对 HZD/model-based 基线（Fig.4）**：本文 RL 控制器相比此前的 **HZD 变高行走控制器 [17]（基于 [16]）**，feasible command set 大 4 倍以上、safe set 更广、跟踪性能更好；RL 能做更快的前进/后退（约 -1.2~1.2 m/s）而 HZD 在 1 m/s 以下；RL 还能处理超出步态库范围的命令（如矢状方向 2 m/s 命令下实际达到约 1.2 m/s，已超 Tab.I 范围），说明 RL 不是严格跟命令、而是找一个"既接近命令又保持稳定"的更优步态。(supported)
  - 注意方向细节：在更低身高上 **HZD 反而能达到更低高度（约 0.6 m）**，RL 约 0.65 m；但 HZD 在低高度的跟踪误差不可忽略（其最小可行身高命令实际只到约 0.7 m），所以综合看 RL 跟踪更准。(supported)
- **扰动鲁棒性（Fig.6，三模型：NRC+步态库 GL / NRC+单步态 SG / RC+单步态 SG，均无域随机化）**：在小/无扰动（β≈0~0.4）下三者回报相近；当施加较大扰动（β∈{0.8,1}）时，**本文方法 NRC+GL 明显优于其余两者**。两个单步态模型（NRC+SG 与 RC+SG）之间并无稳定的高下顺序——在 β=1 时 RC+SG 反而高于 NRC+SG，故不能概括为"NRC+SG 始终优于 RC+SG"。(observed)
- **真机模型误差恢复**：实验期间右侧两个电机（右旋转 q_2^R、右膝 q_4^R）部分损坏、出力不足；出厂默认与 HZD 基线 [17] 都无法可靠产生步态（HZD 因右腿变弱无法在降高后恢复正常高度），而本文策略**因训练时随机化了各关节阻尼比等动力学**，首次部署即能在电机半损坏下行走、无需额外调参。(observed)
- **真机其它鲁棒性（Fig.5）**：变高、快速前进/后退、横向行走、转向、脚下打滑恢复、未知负载、不同/低摩擦地面、被杆推扰恢复——均展示出对机器人自身与环境变化的鲁棒性。(observed)

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：在 Cassie 这类有现成 HZD 步态库可作参考的欠驱动双足上，需要在线可调速度/身高/转向、并对扰动与建模误差鲁棒的行走任务；命令甚至可略超步态库范围。(supported)
- **依赖前提**：方法需要一个离线优化好的 HZD 步态库作为模仿参考（虽然运行时不再需要 model-based 控制器）。无此步态库时本文流程不直接适用。(supported)
- **域随机化是迁移关键**：作者明确指出"额外的动力学随机化技术是产生鲁棒控制器的必要条件"；不做随机化（如 Fig.6 中的对照模型）抗扰能力差。(supported)
- **任务范围限定在行走类**：评测集中在前进/后退/横走/变高/转向/抗扰恢复；更敏捷的行为（跑、跳等）被列为未来工作，未验证。(supported)

## 核心贡献
- 据作者所述，这是**首个用参数化 RL 让双足机器人同时能走、转、下蹲（变高）的多样且鲁棒 locomotion 策略**。(作者自述 first，supported as claim)
- 提出一个把 **HZD 步态库 + model-free RL** 结合的端到端参数化行走控制框架，运行时不需 model-based 控制器。(supported)
- **不用残差控制项**，换取更大的偏离参考自由度，从而获得更好的灵活性与受扰恢复能力。(supported)
- 用**单纯域随机化**完成 sim-to-real，无需在真机上做任何额外训练；并实测到电机损坏下仍可控。(observed)

## 局限与我的质疑
1. **预印本（arXiv v1，未经同行评审）**：本文为 2021-03 的 arXiv 预印本，结论应保留，尤其那些只有定性视频/图片支撑的真机能力（Fig.5）缺乏量化与对照，属 observed 级证据，不宜外推为普适结论。
2. **真机量化对照偏弱**：feasible/safe set 与扰动回报这些定量对比都在仿真（SimMechanics/MuJoCo）里做；真机部分以"做到了"的演示为主，缺乏真机上的统计指标与重复次数，"sim 里更优"未必等比例迁移到真机。
3. **Fig.6 对照设了双重变量**：本文最优模型是 NRC+GL（非残差 + 步态库），而对照是 NRC+SG 与 RC+SG（单步态）。把"步态库 vs 单步态"和"非残差 vs 残差"两个因素混在一起比，难以干净归因到底是步态库还是非残差带来的鲁棒性；且这组实验全部关掉域随机化，与主推流程不同条件。另外这几个模型间在小扰动下几乎并列，优势只在大扰动段显现，应据此克制措辞（observed，仅大 β）。
4. **关键超参/常数未在正文给全**：奖励缩放系数 ρ_i 仅以符号出现、未给数值（"specified manually"），ρ_i、PD 增益等需读者另查；复现需要的若干细节散落或需依赖代码/视频。这是给"可提取性"打了折扣的地方（仅指我在正文未读到具体数值，非断言其不存在）。
5. **"不严格跟踪命令反而更优"是双刃剑**：作者把 RL 不精确跟踪（如 2 m/s 命令只到约 1.2 m/s）解释为"找到更优更稳的步态"，但这也意味着**命令跟踪精度本身是被牺牲的**；对需要精确速度/高度跟踪的下游任务，这套控制器的命令-实际偏差需另行评估。
6. **机制解释多为推测**："非残差更鲁棒"被归因于"偏离参考的自由度更大"，但文中是作者推断（"may be due to"）而非通过受控消融直接证明该因果，属合理但未坐实的假设。
