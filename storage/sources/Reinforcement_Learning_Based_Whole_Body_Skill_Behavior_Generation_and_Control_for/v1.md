# Reinforcement Learning-Based Whole Body Skill Behavior Generation and Control for Humanoid Robots
> Longxiang Li, Qin Zhang, Boyang Xing, Hui Chai, Yunpeng Yin, Benhang Liu · 2025 · Cyber .. · 引用 0 · DOI 10.1109/cyber67662.2025.11168186

## 一句话
把人体动捕数据在 Blender 里重定向成 31 自由度人形机器人(青龙)的关节参考轨迹,再用 FLD(傅里叶潜动力学)给轨迹加上物理动力学约束,然后用 PPO + Actor-Critic + 底层 PD 控制器学习跟踪策略,在仿真里复现挥手/深蹲/踏步三个全身技能。

## 解决了什么问题
- 作者声称要解决两件事:人形机器人"运动技能获取效率低"与"动态控制稳定性不足"(摘要)。
- 具体痛点一:3D 动画引擎(Blender)生成的人体重定向轨迹"缺乏重力和物理引擎的真实约束",动力学不真实,直接喂给 RL 质量不够(§II-2、§III-B)。
- 具体痛点二:人体与机器人关节自由度不一致,需要做高维到低维的人机映射(贡献 1)。
- 具体痛点三:复杂奖励函数设计导致 RL 收敛慢、策略收敛轨迹不稳——作者把这归为现有方法的效率瓶颈(§I 对 [9][11] 的评述)。

## 用什么方法解决的（含直觉：为什么 work）
三个串联模块(Fig.1):
- **动作重定向(Blender)**:把 URDF 转成 fbx 动画模型,导入惯性动捕的 BVH 文件;BVH 用 ZXY 欧拉角记录子关节相对父关节的局部旋转。因动捕坐标系与机器人动画坐标系差异大,作者改用关节节点的**绝对空间位置**来匹配,再对四肢末端(左右腕、左右踝)+ 躯干做**逆运动学(IK)**求各肢关节角(Algorithm 1)。直觉:用末端世界坐标对齐 + IK,可以绕开人/机器人骨架拓扑不同的问题,把高维人体动作压成机器人可执行的低维关节轨迹。
- **轨迹优化(FLD,沿用 [14] 的运动表征阶段)**:用周期自编码器把高维运动序列压到低维潜空间,再用傅里叶级数在频域刻画运动趋势,然后解码回原空间得到"带动力学约束"的重构轨迹(Fig.4)。直觉:运动本质是周期性的,把它投到傅里叶频域后,重构出的轨迹自然平滑、符合周期动力学规律,相当于给动画轨迹"补上"物理合理性,作为 RL 的先验。
- **RL + 部署(增强 PPO)**:高层 Actor-Critic 网络出动作,底层 PD 控制器出力矩稳定。Actor 只用本体感知(90 维)做毫秒级响应;Critic 用 140 维特权观测(含质心运动、轨迹跟踪误差)指导优化。直觉:把 FLD 优化后的参考轨迹嵌进观测和奖励里,RL 就从"纯探索"变成"模仿 + 探索",收敛更快更稳。

## 动机 & 背景
- 传统机器人控制依赖精确动力学模型,在未知/非结构化环境适应性差(§I,引 CMU 的非线性 MPC [8] 在楼梯上稳定但非结构地形差)。
- RL 路线已有进展但各有短板(作者的 related-work 评述):DeepMind 用 RL 训双足平衡 [9][10] 但预训练要"数万次仿真迭代";Berkeley 多目标奖励调参反复、收敛不稳 [11];Xie 等用动捕驱动 RL [12] 但设备贵、对数据噪声敏感;Li 等用预训练动作片段加速 [13] 但泛化受限。
- 本文定位:人机映射 + 轨迹优化 + RL 三者结合,既解决自由度差异,又用优化后的参考轨迹简化奖励设计、加速收敛。

## 方法细节
- **观测/动作空间**:本体观测 90 维(躯干速度指令 v_r、重力向量 g_t、关节位置 q_t、速度 q̇_t、上一时刻动作 a_t);特权观测 140 维(在本体观测基础上加"重构轨迹相对反馈数据的偏差")。动作为 31 维**关节位置增量** a_t = Δq_t,输出相对初始姿态 q_i 的增量,目标关节 q̂_t = Δq_t + q_i(§III-C-1)。
- **网络结构**(Fig.5):Actor 90 维输入 → 512/256/128 隐层(ELU)→ 31 维动作分布;Critic 140 维输入 → 同样隐层 → 标量值。动作从正态分布 a~N(μ_θ(o), σ²) 采样,σ 为可训练标准差。
- **底层 PD**:τ = K_p(q̂_t − q_t) + k_d(q̂̇_t − q̇_t)(式 7;式 14 同形)。
- **FLD 关键公式**:编码 z_linear = BN(FC(Conv1D(s_t)))(式1),Atan2 激活得稳定潜空间 z_t(式2);对 z_t 做 FFT 提取相位 φ_t、频率 f_t、幅值 a_t、偏置 b_t(式3),重构 ẑ_t = b_t + a_t·sin(2π(f_t·t + φ_t))(式4),再转置卷积解码回原空间 ŝ_t(式5);损失为多次迭代的重构 MSE 加权和 L_FLD^N = Σ α^i L_i, L_i = MSE(ŝ_t, s_t),α∈(0,1) 为衰减因子(式6)。原始轨迹 s_t ∈ R^{T×D}(图中标 77×51)。
- **复合奖励**(式8):r_t = w_joint·r_joint + w_vel·r_vel + w_com·r_com + w_end·r_end。四项均为 exp(−α·Σ误差²) 形式:关节位置跟踪(式9)、关节速度跟踪(式10)、质心线/角速度+位置跟踪(式11)、末端相对质心位置跟踪(式12)。直觉:指数形式让误差越小奖励越接近 1,误差大时迅速衰减,鼓励精确跟踪参考轨迹。
- **PPO 训练**:Critic 最小化时序差分损失 L_Critic(式15,γ=0.99);GAE 优势 A_t^GAE(式16,β=0.95;δ_t 式17);Actor 用带裁剪的 PPO 损失 L_Actor(式18,ε=0.2)。Rollout Buffer 容量 N_min 在 2048–8192 之间。
- **训练终止条件**:连续 10 个测试 episode 满足 (1/T_max)Σ‖q_t − q_ref,t‖² ≤ 0.02·‖q_max − q_min‖²(式19)。即平均跟踪误差小于关节量程的 2%。
- **部署**(Fig.7):PyTorch 加载模型,通过共享内存(Solved/Sensor Joint Data Buffer)与仿真器交换数据。

## 数据集 & 实验设置
- 机器人:31 自由度青龙(Qinglong)人形机器人 [15]。
- 任务:三个动作——挥手(wave)、深蹲(deep squat)、踏步(step)。
- 轨迹生成:挥手与深蹲各 7 秒,50 帧/秒映射;深蹲深度 0.328 m(§IV-B,作者称深蹲最难、需全身协调)。
- **平台注意点**:摘要/标题说在 **MuJoCo** 验证,但 §IV-A 明确写"RL 策略在 **Isaac Gym** 平台训练,仿真步长 0.005 s",§III-C-4/Fig.7 又说在 MuJoCo 部署验证——即**训练在 Isaac Gym、部署验证在 MuJoCo** 两个仿真器(原文这点表述不一致,需注意)。
- 硬件:Intel i9-13900F + RTX 4090。优化器 Adam,学习率 0.001。
- 奖励权重/归一化因子(Table 1,仅给出 wave 一列):w = [0.5, 0.1, 0.3, 0.1](joint/vel/com/end),α = [50, 10, 100, 150];每周期归一化后最大可得奖励为 1。

## 主要结果 & 结论（写方向，不堆精确数字）
- 动作重定向能逐帧复现挥手/深蹲/踏步,机器人末端相对躯干的位置轨迹能跟随人体 BVH(Fig.8、Fig.9 实线=机器人/虚线=人体)——验证了 IK 关节角求解的正确性(observed,定性轨迹对比,无量化误差指标)。
- 挥手策略约 **4000 次训练收敛**;跟踪"FLD 优化后轨迹"相比"原始轨迹",奖励值显著提升、收敛更快(Fig.10,"optimized vs original trajectory"两条曲线;作者另称相比 [9] 收敛速度有明显改善)(observed,这是本文最接近"消融"的证据)。
- 仿真中挥手(右臂关节角跟踪 Fig.12a)、深蹲(躯干 z 向位置跟踪 Fig.12b)、踏步(右膝关节跟踪 Fig.13)均能跟上参考轨迹;作者称踏步因高频步态最考验动态稳定,策略能实时补偿重心偏移(observed,踏步 Fig.13 跟踪曲线可见明显噪声/偏差)。
- 总结论:方法在仿真中实现了"稳定且准确的人形动作模仿",为人形全身复杂行为生成与控制提供新思路(作者措辞为"验证可行性 feasibility",并非强泛化主张)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:有动捕 BVH 数据、目标是让特定人形机器人在**仿真**里模仿少数预定义全身周期性动作(挥手/蹲/踏步这类),且能接受 Blender+IK+FLD+PPO 这套离线流程时。
- **管用的机制前提**:动作具周期性(FLD 频域表征才有效)、参考轨迹质量好、奖励项围绕"跟踪参考"设计。
- **未验证/可能不管用**:真实物理机器人(全文只在仿真,无实机部署,尽管文中提到"虚实协同 virtual-real");未见过的新动作/非周期动作的泛化;外部扰动恢复、地形变化等鲁棒性(未做相关实验);多动作统一策略(本文是每个动作单独训一个策略,"trained three action control strategies")。

## 核心贡献
1. 一套通用人机映射方法:Blender 里用绝对位置匹配 + IK,把人体动捕转成适配人形机器人的低维关节参考轨迹(贡献 1)。
2. 把 FLD 傅里叶潜动力学接入流程,给动画轨迹补动力学约束并简化奖励设计,提升 RL 收敛速度(贡献 2)。
3. 端到端的"训练→共享内存→仿真部署"验证框架,声称简化了传统控制器的复杂逻辑(贡献 3)。

## 局限与我的质疑
1. **几乎没有真正的对照基线**。全文唯一的定量对比是 Fig.10 的"优化轨迹 vs 原始轨迹"奖励曲线,以及一句"相比 [9] 收敛更快"——没有与 [11][12][13] 等同类方法在同一任务上的横向对比,也没有消融拆出 FLD / 复合奖励 / 特权观测各自的贡献。"显著提升收敛速度"的强主张证据偏弱(只看了奖励曲线,没报最终跟踪误差数值)。
2. **全程仿真、无实机**。标题/摘要谈"控制人形机器人",但只在 Isaac Gym 训练、MuJoCo 验证;"虚实协同部署"只是架构图(Fig.7),没有真实青龙机器人的结果。仿真里的"稳定"不能外推到真实硬件。
3. **结果几乎全是定性**。Fig.9/12/13 都是轨迹跟踪曲线的肉眼对比,没有给出 RMSE、成功率、跟踪误差均值等量化指标(式19 定义了 2% 量程的终止阈值,但正文未报实际达到的误差),"high-precision""high stability"缺数字支撑;Fig.13 踏步曲线本身可见明显噪声。
4. **训练/部署平台表述自相矛盾**。摘要说 MuJoCo 验证,§IV 说 Isaac Gym 训练 + MuJoCo 部署,Fig.7 又画 MuJoCo——读者无法确定哪些结果在哪个仿真器,影响可复现性。
5. **超参/权重只给了挥手一档**。Table 1 仅列 w_wave 一列,深蹲/踏步的奖励权重与 α 未给;3 个任务是否各自调参、怎么调,不清楚,削弱"方法通用"的说法。
6. **泛化与规模都很小**。只有 3 个短时(7 秒)、单人来源的周期动作,每个动作单独训一个策略;对"全身技能行为生成"这个大标题而言覆盖面很窄,谈不上通用技能库。
7. **公式转写存在 OCR 噪声/笔误**(如式3、式15、式18 的部分符号),方法主干可懂,但若要精确复现需回原文逐项核对(原文式子本身也有排版瑕疵)。
8. **相对本研究主题(RL+动作重定向、强调动作真实性)的不足**:它把"真实性"主要寄托在 FLD 频域平滑上,但没有任何对抗式/判别式的真实感度量,也没和 AMP 类对抗模仿方法比较;"真实性"更多是"轨迹平滑可跟踪",而非人类感知意义上的自然度,证据链较短。
