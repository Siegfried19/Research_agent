# VCSAP: Online reinforcement learning exploration method based on visitation count of state-action pairs
> Ruikai Zhou, Wenbo Zhu, Shuai Han, Meng Kang, Shuai Lü · 2025 · Neural Networks · 引用 8 · DOI 10.1016/j.neunet.2024.107052

## 一句话
VCSAP 是一种用于在线 RL 的计数式内在奖励探索方法,在 RND 的"数状态新颖度"之上**同时再数"状态-动作对(决策)的新颖度"**,让 agent 不仅去新状态、也去做新决策,从而更好地跳出局部最优;在 MuJoCo / 稀疏 MuJoCo 上挂在 PPO 和 TRPO 上,相对 RND 有小幅但较一致的提升(observed)。

## 解决了什么问题
- 计数式探索(以 RND 为代表)**只衡量状态的新颖度,忽略了策略/决策(动作)的新颖度**——这是本文要补的缺口。
- 作者论点:一个状态即使被访问过很多次,当 agent 在该状态选了一个**新动作**时,这个决策仍然是新颖的、可能引出新路径;但纯数状态的方法会给频繁访问的状态一律低内在奖励,导致"对某些状态-动作对过度探索、陷入局部最优"(原文 abstract:"over-exploration of a certain state-action pair and falling into a locally optimal solution")。
- 针对连续/高维动作空间(如多足机器人),每个状态可选动作"不可数",决策序列质量差异大,因此"忽略动作选择"是 RND 这类方法的实质短板。

## 用什么方法解决的（含直觉：为什么 work）
- **核心机制**:沿用 RND 的"随机网络蒸馏"框架(一个固定不训练的 target 网络 + 一个被训练去拟合它的 predictor 网络,预测误差大=该输入罕见=新颖),但 VCSAP 把"被计数的对象"从单纯的状态扩展为**同时计数状态 s_{t+1} 和状态-动作对 (s_t, a_t)**。
- **直觉(为什么 work)**:状态计数衡量"去没去过新地方",状态-动作对计数衡量"做没做过新决策"。把两者叠加,使得**即便处在熟悉状态,只要选了新颖动作也能拿到内在奖励**,从而鼓励在老状态上尝试新动作 → 发现新路径 → 跳出局部最优(原文称这帮助 agent "escape from the dilemma of local optimal solution")。这正是纯状态计数做不到的"动态过程中的新颖性"。
- **理论依据——在线 RL 的"强纠错能力"**:离线 RL 里 OOD(分布外)的状态-动作对会损害性能,所以离线方法用计数去**回避** OOD 动作;但在线 RL 与环境实时交互,"会降低性能的 OOD 动作会被及时修正、有益的动作被保留"(§6.3),因此鼓励尝试新动作(含一些 OOD)在线上是安全且有益的。这是作者为"敢于数动作并奖励之"给出的合法性论证。
- **内在奖励构成**:
  - 状态侧预测误差 r_{s+1} = (f̂_{s+1} − f_{s+1})²(状态新颖度)。
  - 状态-动作对侧预测误差 r_{sa} = (f̂_{sa} − f_{sa})²(决策新颖度)。
  - 总内在奖励 r_t^i 由两者联合构成;总奖励 r_t = r_t^e + β·r_t^i,其中 r_t^e 为环境外在奖励,β 为内在奖励占比。
- **两种实现(原文给了 4 个算法伪代码)**:
  1. **单对网络版**(Algorithm 1 PPO / Algorithm 3 TRPO):一对 predictor/target **同时吃 (s,a,s′)**,预测误差直接当内在奖励 r_{sas′}。对应 Table 1 中 VCSAP 的形式 "||f_predictor(s_{t+1},a_t,s_t) − f_target(s_{t+1},a_t,s_t)||"。
  2. **两对网络版**(Algorithm 2 PPO / Algorithm 4 TRPO):predictor_s/target_s 数下一状态 s_{t+1},predictor_sa/target_sa 数状态-动作对 (s_t,a_t),分别得 r_{s′} 与 r_{sa};新奖励 **r′ = r + β·r_{sa}·r_{s′}**(两个内在奖励**相乘**)。predictor 网络用各自的 MSE 经梯度下降更新。
- **四种情形的设计逻辑(§4.2 Condition I–IV)**:按"状态新不新 × 状态-动作对新不新"组合给出 4 档内在奖励——两者都新→最高(I);状态-动作对新但状态旧→次高(II,即"状态去过、但这次的决策是新的"仍被奖励,这是 VCSAP 相对 RND 的关键增量);状态新但动作不新→较低(III);两者都旧→最低(IV)。

## 动机 & 背景
- 探索是 DRL 在高维/连续动作空间跳出策略限制、访问未知状态的关键;真实任务(自动驾驶、机器人操作)奖励常稀疏或具欺骗性。
- 谱系:动作空间加噪(ε-greedy、pink/Gaussian/OU 噪声)→ 参数/隐空间加噪、熵正则 → 进化/类脑、多样性、乐观、分布式等高级探索 → 内在动机(好奇心 ICM、计数 RND、信息增益等)。VCSAP 归属**计数式内在奖励**这一支。
- 对比好奇心方法(ICM,用前向预测误差):VCSAP 不需要深入理解或精确预测环境动态,因此**探索过程更稳定**(原文:好奇心法若动态预测不准则效率下降)。对比信息增益法:相邻状态差异做奖励可能放大环境噪声、把微小变化触发成大奖励而影响学习稳定性。
- 基线选择:RND、ICM、RIDE(均为已应用于 PPO 等策略梯度算法的计数/内在奖励方法)。

## 方法细节
- 网络框架借自 RND:target 随机初始化且**全程不更新**(作为固定参考点),predictor 用 MSE 去拟合 target;某输入被访问多→predictor 拟合得好→误差小→内在奖励低;罕见输入→误差大→奖励高。
- VCSAP 把这套"误差即新颖度"的计数机制**分别施加到状态和状态-动作对上**(单对版则合在一个网络里吃 (s,a,s′))。
- 训练时(on-policy):predictor 网络在训练策略阶段同步更新,使其计数始终准确;数据从与环境交互的 (S,A,S′,R) 中收集。
- 超参(Table 2):PPO-VCSAP——buffer 4000、γ=0.995、λ=0.97(GAE)、batch 256、lr=0.0003、clip 0.2、β=0.5;TRPO-VCSAP——buffer 5000、γ=0.995、λ=0.97、max_kl=0.01、L2 正则、β=0.5。具体值以 §6.1/Table 2 为准。

## 数据集 & 实验设置
- 环境:4 个 MuJoCo 连续控制任务(Hopper-v2、Walker2d-v2、Ant-v2、HalfCheetah-v2),外加**稀疏奖励版 MuJoCo**(Han & Sung 2021;沿 x 轴位移超阈值才 +1,否则 0)。Tables 3/4 还含对应的 v1 任务。
- 所有算法训练 **3M 步**,**5 个随机种子**,报告均值±标准差。
- 对照:PPO、TRPO(裸基线) + RND、ICM、RIDE(内在奖励基线);VCSAP 分别挂到 PPO 与 TRPO。
- 额外分析实验:动作多样性(§6.2,Fig 3 用饼图比 VCSAP vs RND 在 s_0 处 5 个 agent、3000 步内的动作采样分布)、β/学习率/max_kl/网络复杂度敏感性(§6.6,Fig 6–10)、内在奖励组合方式(§6.7,Fig 11)。

## 主要结果 & 结论（写方向，不堆精确数字）
- **挂 PPO**:在 8 个环境上,相对 RND 平均提升约 18%(abstract;Table 3 "Improvement Over RND" 平均 1.18);相对裸 PPO 平均提升约 67%(Table 3)。各环境相对 RND 的提升幅度差异大(从约 2% 到约 72%,见 §6.4 / Table 3),Ant-v2、Walker2d-v2、HalfCheetah-v2 较明显,Hopper-v2 较小(约 4%)。(supported)
- **挂 TRPO**:在 8 个环境上,相对 RND 平均提升约 8%(abstract;Table 4 平均 1.08);相对裸 TRPO 平均约 44%(Table 4)。(supported)
- **欺骗性奖励(HalfCheetah-v2)**:加 ICM/RIDE/RND 后 PPO 性能反而下降,而加 VCSAP 仍能稳定提升——作者归因于"同时考虑状态与状态-动作对的新颖度,帮助跳出局部最优"(§6.4)。(observed)
- **稀疏奖励 MuJoCo**:VCSAP 在各稀疏环境上能有效探索;PPO+VCSAP 提升幅度跨环境从约 1% 到 159% 不等,TRPO 从约 9% 到 238%(§6.5 / Tables 3–4)。幅度跨度极大,说明强弱依环境而定。(observed)
- **动作多样性(Fig 3)**:VCSAP 采到的新颖动作比 RND 多、动作分布更分散;RND 的采样行为更集中,作者称这会削弱其在状态内发现新动作的能力。(observed,基于 HalfCheetah-v2 / Walker2d-v2 两环境、初始状态附近的可视化)
- **内在奖励组合方式(§6.7,Fig 11)**:加/减/乘/除/指数五种里,**乘法整体最好**(作者推测乘法显著放大内在奖励、同时鼓励能拿到两类奖励的动作),唯一例外是 TRPO-VCSAP 在 Hopper-v2 上乘法落入次优解。(observed)
- **代价**:VCSAP 因多算了状态-动作对计数,**时间复杂度高于 RND**——作者在结论中称约高 10%(PPO)与 21%(TRPO)(§7;另见 Tables 3/4 的 Time Complexity 行)。(supported)

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:在线(on-policy)RL + 连续/高维动作空间 + MuJoCo 类机器人运动控制;尤其在**欺骗性奖励**和**稀疏奖励**环境下,相对纯数状态的 RND 有增量,因为"在老状态上尝试新动作"是其独有的奖励来源。
- **依赖在线设定**:其合法性建立在"在线 RL 能纠正坏动作"这一前提(§6.3);该机制不适用于离线 RL(那里 OOD 动作要回避而非鼓励)。
- **β 需调**:§6.6 指出随环境复杂度上升,β 对性能影响显著、需仔细调(稠密奖励下 β≈0.5 近最优);TRPO-VCSAP 对 max_kl 也较敏感。
- **比的是强基线还是弱基线**:RND/ICM/RIDE 都是公认的强计数/内在奖励基线,裸 PPO/TRPO 是弱基线;相对强基线(RND)的提升是真实但**幅度温和**(PPO≈18%、TRPO≈8% 的均值,单环境最小仅 2%~4%),不应读成"大幅碾压"。
- **未验证的扩展**:多智能体 RL 仅列为未来工作(§7),本文未做。

## 核心贡献
- 提出**同时计数状态与状态-动作对**的内在奖励设计(原文贡献①②),把计数式探索的关注点从"状态新颖"扩展到"状态新颖 + 决策新颖"。
- 给出基于 RND 框架的两种实现(单对 / 两对网络)及在 **PPO 与 TRPO** 上的完整算法(Algorithm 1–4)。
- 在 MuJoCo 与稀疏 MuJoCo 上对 PPO/TRPO × {RND, ICM, RIDE, VCSAP} 做系统横比,并验证在稠密/稀疏/欺骗三类奖励下均有效(§6)。

## 局限与我的质疑
1. **相对强基线(RND)提升幅度温和且高方差**:PPO 均值约 18%、TRPO 约 8%,但单环境低至 2%~4%(Hopper),且 MuJoCo 学习曲线(Fig 4)各方法置信带高度重叠、5 个种子;在这种重叠+小样本下,部分"提升"的统计显著性存疑,作者未报告显著性检验或置信区间分析。
2. **"动作多样性更优"的证据较弱**:Fig 3 仅在 2 个环境、初始状态 s_0 附近、3000 步、用饼图定性展示采样动作分布,并据此推断"探索能力更强"。这是间接、可视化层面的证据,未给"更多样的动作 → 更高回报"的因果量化,存在过度解读风险。
3. **时间复杂度增加但分析粗略**:多一套状态-动作对计数网络必然增成本,作者给了约 10%/21% 的数字却把降复杂度全推给未来工作(简化网络/近似/SVD),当前版本在算力敏感场景的实用性打折。
4. **设计选择缺消融解释**:为何"两对网络 + 乘法组合"最好,只给了实验现象(§6.7)与一句"乘法放大内在奖励"的推测,缺机制层面的论证;且乘法在 Hopper-v2 上 TRPO 反而次优,说明该组合并不稳健,论文未深究这个反例。
5. **只在 MuJoCo 系列上验证**:全部实验局限于 MuJoCo 运动控制,未涉及离散动作(如 Atari,而 RND 原本就在 Atari 验证过)或更高维感知任务;对"连续/高维动作空间"这一卖点的泛化性,横向覆盖不足。
6. **与本研究主题(RL 通用工具箱/探索)的契合度**:作为可插拔的内在奖励模块,VCSAP 思路清晰、易挂在任意 on-policy 算法上,这点适配工具箱定位;但它本质是 RND 的增量改良而非范式突破,且未与近年更强的探索方法(如基于互信息/后验采样的新方法)对比,基线集偏经典(ICM 2017/RND 2019/RIDE 2020)。
