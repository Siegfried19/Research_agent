# FRoM-W1: Towards General Humanoid Whole-Body Control with Language Instructions
> Peng Li, Zihan Zhuang, Yangfan Gao, Yi Dong, Sixian Li, Changhao Jiang, Shihan Dou, Zhiheng Xi, Enyu Zhou, Jixuan Huang, Hui Li, Jingjing Gong, X. Ma, Tao Gui, Zuxuan Wu, Qi Zhang, Xuanjing Huang, Yu-Gang Jiang, Xipeng Qiu · 2026 · arXiv.org · 引用 6 · DOI 10.48550/arxiv.2601.12799

## 一句话
FRoM-W1 是一个开源框架,把"自然语言指令 → 含手部的全身人体运动生成(H-GPT)→ 重定向到人形机器人并经 RL 训练的控制器在物理世界稳定执行(H-ACT)"串成一条两阶段流水线,目标是让 Unitree H1/G1 等真机听懂开放式语言指令并做出对应全身动作。

## 解决了什么问题
- 人形机器人现有花式动作(打招呼、跳舞、后空翻)多靠硬编码轨迹或针对单任务的 RL、并常用手柄遥控,缺乏"听懂任意自然语言→自主做全身动作"的通用能力。
- 作者把核心问题定为:"人形机器人如何理解多样的自然语言指令并在真实物理世界中执行对应的全身动作?"(原文 §1)。
- 两大障碍:其一,缺少"语言↔人形全身动作"配对的大规模机器人数据集(原文称 such paired data is scarce);其二,即便能从语言生成机器人动作,在重力与动力学不确定性下直接上双足真机会失稳摔倒。

## 用什么方法解决的(含直觉:为什么 work)
核心直觉(类脑分工):把"语义理解+运动规划"类比大脑、把"稳定运动执行"类比小脑,拆成两个阶段;并且关键地**用"人体运动"作为语言与机器人之间的中间表示**——因为人形机器人与人体形态相似,可借此绕开缺失的机器人配对数据,直接吃海量带语言标注的人体动作捕捉/视频数据。
- **H-GPT(语言→人体全身动作)**:先用 VQ-VAE 把含手部的 SMPL-X 全身动作序列离散化成"运动 token",与文本 token 拼成统一词表;再用 LLaMA-3.1 基座(LoRA 微调)做自回归生成。为弥合"抽象指令↔具体动作"的语义鸿沟,用 GPT-4o 给每条样本生成思维链(CoT),把指令分解成显式、带时序结构的低层动作原语;推理时先生成 CoT 再据此生成运动 token。直觉:CoT 把开放/抽象指令(如"扮演一头大象")翻译成模型更容易对齐到动作空间的具体描述,借 LLM 的世界知识做泛化。
- **H-ACT(人体动作→真机执行)**:① 重定向 R:用 HybrIK 思路从 3D 关键点重建 SMPL-X,再解优化把人体姿态映射到机器人关节角(身体对齐 + 手腕旋转 loss + 手部指尖位置对齐);② RL 控制器:在 IsaacGym 里先做 **RPT 预训练**(教师-学生蒸馏,OmniH2O 式,大规模 AMASS 数据训通用 tracker),推理时再对**目标动作做 RFT 微调**(针对单条目标动作专门蒸馏,提升跟踪保真度与稳定性);③ 模块化部署框架 RoboJuDo,把控制器/环境/策略抽象成统一接口,支持上下肢解耦、遥操作式、全身跟踪等多种策略即插即用。

## 动机 & 背景
- 现有人形能力多为硬编码/单任务 RL/手柄遥控,限制了机器人自主感知与人机交互(原文 §1)。
- 文本到人体动作生成(T2M、MotionGPT、MDM、MoMask 等)已较成熟,但 HumanML3D 数据规模偏小、且基于无手的 SMPL,而手部对人形表达力和操作至关重要(原文 Related Work)。
- 人形全身跟踪/遥操作线(ExBody、H2O、OmniH2O、HumanPlus、TWIST、HugWBC 等)解决"跟人体动作"的执行问题;语言驱动全身控制(Harmon、UH-1、LangWBC、LeVERB 等)较新,但多从零训小模型、或为每个机器人单独训生成模块、或不含手部/不含 CoT。FRoM-W1 主张复用大模型能力 + 人体动作做统一中间表示来获得更强泛化与跨平台迁移。

## 方法细节
- **任务形式化**:学映射 Π(I)=A_H-ACT(G_H-GPT(I)),即指令 I → 人体动作 M_h → 机器人动作 A_r(原文 §2.1)。
- **运动 tokenizer**:编码器 E 做时空降采样 R^{T×D}→R^{L×d}(L=⌊T/l⌋),向量量化 Q 把每个隐向量映到可学习码本最近邻 ĉ_i=argmin‖z_i−ẑ_k‖₂,解码器 D 重建;训练用重建+commitment+codebook 三项加权 loss,加 EMA 与 code reset 防码本坍塌(原文 §2.2.2)。HumanML3D-X 配置 K=512、l=4;Motion-X 配置码本数 1024、维度 2048。
- **生成器训练**:序列结构 "[Instruction] I [CoT] CoT [Motion Tokens] Ĉ",冻结基座参数 Θ、只训 LoRA(ΔΘ);loss 为标准 LM 目标 L_lm=−Σ_i log p(token_i | token_{<i}, I; Θ+ΔΘ)(原文式(1))。LoRA rank=32、scaling=16、dropout=0.05,embedding 与 LM head 全可训。
- **概率分解**:p(M_h, CoT | I)=p(M_h | I, CoT)·p(CoT | I),CoT 作为语义中介把指令空间扩展到更贴近动作空间的 CoT 空间(原文 §2.2.1)。
- **重定向数学**:单子节点关节用 Rodrigues 公式 R_i=I+sinθ·K+(1−cosθ)K²(式(2));多子节点(如骨盆)解正交 Procrustes 问题 min‖R_iT−P‖_F²,经 SVD PT^T=UΣV^T 得 R_i=UV^T(式(3))。机器人关节角优化目标 min Σ[λ_p‖p(FK)−p̂‖₂² + λ_r·d(R(FK), R̂)] + R_r(式(4)),d 为 SO(3) 测地距离,R_r 为关节限位等可行性正则。
- **RL 目标**:教师策略 max E[Σγ^t(r_t^im + λ_stable·r_t^stable + λ_reg·r_t^reg)](式(5),含模仿/稳定/正则三项奖励);学生策略蒸馏 min E[‖π_θ(s_t,c_t)−π_φ(s_t,c_t)‖²](式(6))。教师跟踪人体多关键点,学生默认只跟 3 个关键点(头+双手),手部走直接重定向不进 RL。用 PPO(RSL-RL)训练,加 domain randomization;RL 框架里不给机器人加手部关节(SMPL 24 关节→H1 19-DOF / G1 21-DOF,手自由度太多会拖慢训练且对平衡影响小)。
- **部署**:每机器人 4096 并行环境;真机用 4090/双 5090 工作站跑 H-GPT,无线传给板载 PC2 执行 H-ACT;H1/G1 均无需硬件改装。

## 数据集 & 实验设置
- 自建两个 benchmark:**HumanML3D-X**(把 HumanML3D 的无手 SMPL 扩成含手 SMPL-X,保留文本标签)与 **δHumanML3D-X**(在 X 基础上加两类变换:指令"改写 rephrasing"和"加噪 noising",专测语言泛化;模型在 HumanML3D-X 上训、直接在 δ 上测)。另用 **Motion-X**(81084 条含手动作,文本由 VLM 生成)做数据 scaling。
- 指标:FID(主指标,动作质量)、R Top-k(文-动检索匹配)、MM Dist、DIV(多样性)、MModality;重训了对应特征/打分模型。
- 基线:自回归类 T2M、T2M-GPT;扩散类 MotionDiffuse、MLD——均在 HumanML3D-X 上用各自开源码重训。
- 控制实验:IsaacGym 训练、MuJoCo 评测;指标 MPJPE、VEL、ACCEL、SR(成功率)。RPT 用 AMASS;RFT 从 AMASS 随机采 30 条动作测。
- CoT 泛化评测:各 50 条复杂/抽象指令(GPT-4o 构造),无 ground truth,用**人工成对比较**判优(non-quantitative)。

## 主要结果 & 结论(写方向,不堆精确数字)
- 在 HumanML3D-X 上,H-GPT 系列把主指标 FID 从 T2M-GPT 的约 0.677 降到约 0.23–0.26(论文摘要称约 2.5 倍提升,见 §3 表1),即生成的全身动作分布更贴近真实。supported
- 有意思的反直觉:**在分布内的 HumanML3D-X 上,去掉 CoT 的 H-GPT_w.o.CoT 的 FID 反而略好于带 CoT 的 H-GPT(约 0.229 vs 0.255)**;作者解释训练/测试分布一致时学映射更容易,加 CoT 的额外文本反让拟合略难。observed
- **CoT 的价值主要体现在泛化**:在 δHumanML3D-X 的指令改写与加噪场景,加 CoT 后 FID 明显下降(改写约 0.455→0.355、加噪约 0.830→0.602,见 §3 表2),且 H-GPT 系列整体强于基线的泛化。supported
- 作者观察到 FID 改善时 R Top-1/MM Dist 这类文-动相关性指标常退化,归因于训练 loss 只拟合动作分布、未显式约束文-动相关性。observed
- Motion-X 数据 scaling:能取得"不错但不如直接用 HumanML3D-X"的表现,作者归因于 VLM 文本标注与视频估计动作的分布/质量差异;加 CoT 后整体仍有提升。observed
- CoT 复杂/抽象指令的人工成对评测:带 CoT 模型胜率更高(如 50 条复杂指令 H-GPT_w.o.CoT vs H-GPT 为 23:27),但 **H-GPT 与 H-GPT++ 两者之间未见一致优劣**。observed
- 控制器:用 filtered 数据 + 教师-学生策略一致改善 H1/G1 的 MPJPE/VEL/ACCEL/SR;**G1 比 H1 明显更稳(G1 SR 约 80–90%,H1 约 40–50%)**,作者归因 G1 结构设计更利于稳定执行。observed
- **RFT(推理期对目标动作微调)一致提升跟踪**:论文称提升运动跟踪成功率,并在 MPJPE 上约 15% 改善(原文 §1 / §3.2),约 500 步即见显著改善;部分原本不稳的动作变稳。supported
- 真机:H1/G1 上成功演示"扮大象/拉小提琴/走几步接电话"等;框架还能即插即用部署 HugWBC、TWIST 等他人控制器。observed
- 明确失败案例:半蹲、快速奔跑等极端动作即便仿真能做,真机仍因 Sim2Real gap 频繁失稳/摔倒(图15)。

## 适用边界(什么时候管用 / 什么时候不管用)
- **管用**:语言驱动、含手部的全身**表达性动作**(模仿、带情绪、与人/物/环境交互的动作),在 H1/G1 这类全尺寸双足人形上,且动作不过于极端、参考动作初始姿态稳定时;跨机器人/跨控制策略迁移(靠人体动作中间表示 + RoboJuDo 统一接口)。
- **不太管用 / 退化**:① 极端动力学动作(半蹲、快速前冲奔跑)真机易摔;② 分布外、被改写/加噪的指令上无 CoT 版本明显变差;③ H1 这类结构更难稳的平台成功率偏低;④ 当生成动作本身有噪声/自体碰撞/与指令不对齐时,下游控制器也跟不好。
- **对比基线强度**:动作生成侧与 T2M/T2M-GPT/MLD/MotionDiffuse 等主流文生动作方法在自建 X benchmark 上比(基线均重训,算较公平);但都是**作者自建的 benchmark**,非社区公认排行榜。控制侧主要是自身消融(from-scratch / RPT / RFT 对比),与他法(HugWBC/TWIST)是"兼容部署"演示而非定量胜负比较。

## 核心贡献
- 提出 H-GPT:基于 LLaMA-3.1 8B 的 9B 全身(含手)人体动作生成模型,用 CoT 增强指令理解,在自建 HumanML3D-X / δHumanML3D-X 上展示更优的质量与泛化。
- 提出 H-ACT:覆盖"人→人形重定向 → RL 预训练 + 推理期 RFT 微调 → 模块化部署"的一整套执行模块,新颖点是**两阶段 RL(通用预训练 + 针对目标动作的推理期微调)**以提升跟踪保真度。
- 提出 RoboJuDo 模块化部署框架,用统一接口支持上下肢解耦/遥操作/全身跟踪等多种控制策略即插即用、跨 H1/G1 嵌入式适配。
- 全开源:H-GPT 与 H-ACT 的训练码、checkpoint、评测 benchmark 与轻量部署模块。
- 配套建立 HumanML3D-X / δHumanML3D-X 两个含手全身动作生成评测基准。

## 局限与我的质疑
1. **"general/通用"被标题过度承诺**:实证只在 H1/G1 两台机器人、且演示性动作上;极端动力学动作真机失败、H1 成功率仅 40–50%,与"通用全身控制"的口号相比证据偏弱。作者自己也承认仍存在动作-指令不对齐、自体碰撞、Sim2Real 失稳等问题。
2. **CoT 的收益其实分裂**:在分布内 FID 上 CoT 反而略拖后腿,收益只在自造的"改写/加噪"泛化集与人工成对评测上;而泛化评测无 ground truth、靠人工主观判优、样本仅各 50 条,统计力弱、易受评判者偏差影响——"CoT 提升泛化"这一卖点的证据强度我评 observed,不宜当作硬结论。
3. **benchmark 自建、指标内部张力**:FID 改善时检索类指标(R Top-1/MM Dist)同步退化,说明"动作更真"未必"更贴合文本";作者用"loss 没约束文-动相关性"解释,但这恰恰意味着语义对齐没被直接保证,而语义对齐才是语言驱动控制的关键。FID 单点很难支撑"听懂指令"的主张。
4. **RFT 的 15% / 成功率提升缺乏与强基线的横向比较**:RFT 主要对比自身 from-scratch/RPT,属内部消融;且推理期对每条目标动作再微调,工程上昂贵(每个动作要再训约 500+ 步),论文未充分讨论其在线延迟/吞吐代价与可扩展性,真机"开放指令即时执行"的实用性存疑。
5. **手部其实被"绕过"而非真正纳入 RL**:生成侧含手,但控制侧 RL 不建模手部关节、手走直接重定向;考虑到论文反复强调"手对表达力/操作至关重要",这等于在执行端把最难的部分留在了 RL 之外,真机手部动作的稳定性与精度缺乏定量评估。
6. **与本研究主题(语言/agent 驱动全身控制)对照的不足**:CoT 由外部 GPT-4o 离线生成并蒸进训练数据,推理期模型自生 CoT 的质量/忠实度没有独立评测;也没有闭环反馈(physical feedback 优化生成),与同期 RLPF、Humanoid-LLA 等"用物理反馈回灌优化生成"的思路相比,FRoM-W1 的生成与执行基本是开环串联,生成端不知道下游能不能执行得稳。
