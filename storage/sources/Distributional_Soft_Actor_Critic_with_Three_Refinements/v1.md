# Distributional Soft Actor-Critic with Three Refinements
> Jingliang Duan, Wenxuan Wang, Liming Xiao, Jiaxin Gao, Shengbo Eben Li, Chang Liu, Ya-Qin Zhang, Bo Cheng, Keqiang Li · 2023 · arXiv (Cornell University) · 引用 55 · DOI 10.48550/arxiv.2310.05858

## 一句话
在自家提出的分布式 soft actor-critic(DSAC/DSACv1)基础上加三个改进——期望值替换、孪生值分布学习、基于方差的 critic 梯度调整——得到 DSAC-T(DSACv2),目标是治 DSACv1 的训练不稳定与对 reward scaling 的敏感、并进一步提升 Q 值估计精度;在一组连续控制任务上无需逐任务调超参即可匹配或超过 SAC/TD3/DDPG/TRPO/PPO(supported)。

## 解决了什么问题
- model-free RL 常因价值估计不准(尤其 Q 值过估计 overestimation)导致策略次优;过估计源于 Bellman 方程 max 算子作用在含噪的价值估计上(原文 §1)。
- 作者前作 DSAC(DSACv1)用"学一个连续高斯值分布"而非只学期望回报来抑制过估计,但留下三个具体毛病(原文 §1、§3.2):
  1. 把回报的随机性引入 critic 梯度,偏离传统只用期望回报的做法,易致 critic 更新不稳定。
  2. 对 reward scaling 敏感:DSACv1 用**固定的** clipping 边界 b 裁剪目标回报,且 Q 值更新幅度与值分布方差成反比,所以不同任务必须手工调 reward scale 去匹配这个固定边界。
  3. 单值分布仍有残留过估计。
- DSAC-T 就是针对这三点各上一个改进。

## 用什么方法解决的（含直觉：为什么 work）
三个改进各打一个痛点(原文 §4):

1. **期望值替换(expected value substituting)**——治 mean 梯度的高随机性。DSACv1 的 critic 梯度(式11)分成 **mean-related gradient** 与 **variance-related gradient** 两部分,DSACv1 只对 variance 部分做了裁剪降噪,mean 部分仍带由随机目标回报 y_z 引入的高方差。直觉:mean 部分本质等价于非分布式方法(如 SAC)更新 Q 期望的那一项,本不该被分布随机性污染;于是把它里头的随机目标回报 y_z 换成更"确定"的目标 Q 值 y_q = r + γ(Q_θ̄(s',a') − α·log π_φ̄(a'|s')),a'~π_φ̄(式16/18)。作者证明 y_q 与 y_z 在期望意义上相等(式17),所以替换不改目标、只降噪——使新的 mean 梯度等价于 SAC 那种稳定更新(只是被方差因子 σ² 缩放),从而稳住学习并加速收敛。

2. **孪生值分布学习(twin value distribution learning)**——clipped double Q-learning 的分布式版本。学两个独立参数化的值分布(θ₁,θ₂),按"均值较小者"选(ĩ = arg min_{i=1,2} Q_θ̄ᵢ(s',a'),式19),用被选中那个分布构造 critic 与 actor 的目标(式20–22)。直觉:取两估计较小者进一步压过估计,倾向于产生轻微低估;作者明确主张"低估优于过估"——因为过估的动作值会在学习中传播、把策略引偏,而低估的动作通常被策略绕开、其值不传播,且低估可当作性能下界,利于稳定(原文 §4.2)。

3. **基于方差的 critic 梯度调整(variance-based critic gradient adjustment)**——治 reward scaling 敏感。两件事:(a)把固定裁剪边界 b 改成自适应:b = ξ·E_{(s,a)~B}[σ_θ(s,a)](式23),取 ξ=3(对应 three-sigma 规则)。因为方差与 reward 量级直接相关,让 b 随 σ 走,边界就自动适配不同任务/不同训练阶段的 reward 量级,免去手调。(b)mean 值 Q 的更新幅度被方差 σ² 调制(式21分母),会带来对 reward scale 的额外敏感,于是引入梯度缩放权重 ω = E[σ_θ(s,a)²](式24/25),并在梯度里用移动平均的 ω、b(式26/27),抵消这种方差调制带来的尺度敏感。直觉:让裁剪边界和更新步长都随 reward 量级自动伸缩,使算法对 reward scaling "免疫"。

整体仍套在前作的 Distributional Soft Policy Iteration(DSPI)框架下(§3),DSAC-T 只在算法层加 trick,不改框架,所以**收敛性理论与 DSACv1 相同**(原文 §4.4 明示,证明见前作附录)。

## 动机 & 背景
- 价值过估计是 model-free deep RL 顽疾;double Q-learning / clipped double Q-learning(TD3 用的 min 两个 Q)是主流抑制手段(原文 §1)。
- 分布式价值函数是抑制过估计的新趋势:作者前作证明"过估计偏差与值分布方差成反比",学一个高斯值分布可借系统随机性/逼近误差去抑制过估(原文 §1、§3)。
- 本文承认前作 DSACv1 的三个具体局限(见上),DSAC-T 是其增强版;源码已并入作者自研开源 RL 工具箱 GOPS。
- 关键公式锚点:soft self-consistency(式3)、分布式 Bellman 算子(式6)、值分布更新(式7)、critic 梯度两段分解(式11)、裁剪函数 C(y_z;b):=clip(y_z, Q−b, Q+b)(式12)。

## 方法细节
- 值分布与策略都用**对角高斯**参数化:Z_θ(·|s,a)=N(Q_θ(s,a), σ_θ(s,a)²),网络同时输出均值与标准差(原文 §3.2)。
- critic 更新最小化分布间 KL(式7/8),采样版式9;目标随机回报 y_z = r + γ(Z(s',a') − α·log π_φ̄(a'|s'))(式10)。
- 期望值替换后 mean 部分用更确定的 y_q;孪生版用 y_z^min / y_q^min(式20),actor 目标也用 min 的那个分布(式22)。
- temperature α 自动调:α ← α − β_α·E[−log π(a|s) − H̄](式15),目标熵 H̄ = −dim(A)。
- 完整流程见 Algorithm 1:采样存 buffer → 更新 critic / actor / temperature / 软更新 target 网络(τ=0.005)。
- 防梯度爆炸/消失:分母加正数 ε(防 σ→0 爆炸)、权重加 ε_ω(防 σ→0 时 ω→0 致梯度消失),ε=ε_ω=0.1(式26、表1)。

## 数据集 & 实验设置
- OpenAI Gym 连续控制:11 个向量输入任务(Humanoid、Ant、HalfCheetah、Walker2d、InvertedDoublePendulum、Hopper、Pusher、Reacher、Swimmer、Bipedalwalker、Bipedalwalker-hardcore)+ 1 个图像输入任务(CarRacing)(原文 §5、Fig.1)。
- baseline:DDPG、TRPO、PPO、TD3、SAC,以及前作 DSACv1。所有算法同架构、等价超参以求公平;DSAC-T 用自适应边界 ξ=3,DSACv1 用固定 b=20(原文 §5.1)。
- 网络:MLP 三隐层各 256 单元、GELU;图像任务另加 6 层卷积编码器。每任务 5 个固定随机种子各跑一次(原文 §5、表1)。
- 评测指标:final return 取每次运行最后 10% 步内最高回报均值(表2);价值估计偏差 = estimate Q − true Q,true Q 由采样轨迹折扣累积回报(含熵项)估(表3)。

## 主要结果 & 结论（写方向，不堆精确数字）
- DSAC-T 在所有被测任务上匹配或超过全部 baseline(supported;原文称 "matches or outperforms ... in all tested environments")。以 Humanoid-v3 为例,相对 SAC/TD3/PPO/DDPG/TRPO 分别约提升 16%/92%/58%/105%/1022%(见原文 §5.2、表2;后几项主要是因为那些弱基线在 Humanoid 上本就跑得差,数值看出处别当结论卖点)。
- 相对前作 DSACv1,DSAC-T 在学习稳定性和最终回报上都有实质提升(observed,见 Fig.2 训练曲线 + 表2)。
- 价值估计偏差(表3):DSACv1 相比单 critic 的 DDPG 已显著降低过估;DSAC-T 借孪生值分布进一步降过估,部分任务转为轻微低估;在"偏差量级相近时低估优于过估"的判据下,DSAC-T 的估计精度在多数任务上优于或至少持平 off-policy 基线(supported)。与一个较新的过估抑制法 RAC-SAC 在 Humanoid/Ant 上对比,DSAC-T 估计精度更高且性能更好(observed,仅这两任务,原文 §5.2)。
- **消融**(原文 §5.3):
  - 去掉期望值替换 或 去掉孪生值分布,稳定性与性能都变差(Humanoid-v3,Fig.4)→ 证实这两个改进对稳定性/性能的贡献,且期望值替换还加速学习(observed,单任务)。
  - 去掉基于方差的梯度调整后,对 reward scale 极敏感,尤其在 0.01 和 0.1 这种更低 reward scale 下学不出有效策略;DSAC-T 则在 0.01×~5.0× 不同 reward 量级下性能稳定(observed,HalfCheetah-v3,Fig.5)→ 证实该改进确实降了 reward scaling 敏感性。
- **真实机器人**(原文 §6):Geekplus M200 移动机器人做轨迹跟踪 + 动态避障(目标速 0.28 m/s,N4200 CPU、50Hz 控制)。仿真训练后部署实机,能完成跟踪与避障(Fig.7/8)→ 展示工程可用性(observed,单一案例,无对比基线)。
- 计算成本:Humanoid-v3 上 DSAC-T 约 35.51s/千次迭代,比其它 off-policy 基线(SAC 35.02s、TD3 31.41s、DDPG 25.20s)略慢;作者认为性能提升值回这点开销(原文 §5.2)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:连续状态/动作的 model-free off-policy 控制;尤其当你不想为每个任务手调 reward scale / clipping 边界时(自适应 ξ=3 替代固定 b)。在标准 MuJoCo/Box2D 类基准 + 一个图像任务上验证过。
- **基线强度**:对比对象既有强基线(SAC、TD3——当前主流),也有相对弱的(DDPG、TRPO、PPO),所以"超过 TRPO 1022%"这类数字主要反映弱基线在难任务上的崩,别据此外推 DSAC-T 的优势幅度。
- **不管用 / 存疑**:作者自述用**单峰高斯**近似值分布与策略,在"多目标、复杂动力学、真分布多峰"的任务上,这种表达能力会限制探索效率与逼近最优策略的能力(原文 §8)→ 多峰回报场景慎用。
- 所有验证都在仿真(实机那段也是"仿真训练→部署"),未在仿真之外做系统的多任务实机对比。

## 核心贡献
1. **期望值替换**:把 critic 的 mean-related gradient 里的随机目标回报换成更稳定的目标 Q 值,降随机性、稳训练、加速收敛(式16–18)。
2. **孪生值分布学习**:clipped double Q-learning 的分布式版,取均值较小的分布构造目标,进一步压过估、倾向轻微低估(式19–22)。
3. **基于方差的 critic 梯度调整**:自适应裁剪边界 b=ξ·E[σ](ξ=3)+ 梯度缩放权重 ω=E[σ²],消除对 reward scaling 的敏感、免逐任务调超参(式23–27)。
4. 集成为 DSAC-T(DSACv2),开源进 GOPS,并给出真实轮式机器人应用。

## 局限与我的质疑
1. **作者自述**:单峰高斯表达力受限,多峰/复杂任务可能拖累探索与最优策略学习;未来拟用扩散模型等多峰近似(原文 §8)。这等于承认核心建模假设在一大类任务上是软肋。
2. **"超过所有基线"被措辞放大**:摘要/正文反复用 "outperforms ... in all tested environments",但表2里多处其实是"持平或微弱领先"(如 Pusher/Reacher/InvertedDoublePendulum 等近饱和任务几乎打平),而那些惊人百分比(TRPO 1022%)来自弱基线在难任务上的失败,不能当成方法本身的普遍优势——这是典型的"相对提升被弱基线撑大"。
3. **改进缺乏单独的理论保证**:作者强调收敛性"和 DSACv1 一样",但那是 DSPI 框架级别的结论;三个 trick(尤其孪生 min 选择、自适应边界 ξ=3)对最终策略质量/偏差的影响只有经验证据,没给针对这三项的分析或偏差界。ξ=3 援引 three-sigma 规则更像工程直觉而非推导。
4. **消融覆盖窄**:期望值替换/孪生分布的消融只在 Humanoid-v3 做(Fig.4),reward-scaling 消融只在 HalfCheetah-v3 做(Fig.5)。单任务消融难以支撑"每个改进都普遍有用"的强主张,可能存在任务挑选效应。
5. **价值偏差度量的可信度**:true Q 由采样轨迹折扣回报估,本身是有噪的近似;表3里 DSAC-T 在若干任务上并非偏差最小(如 SAC 在 HalfCheetah/Reacher/Bipedalwalker-hardcore 的偏差更小),作者靠"低估优于过估"这一规范性偏好来重新解释胜负,而非纯按偏差绝对值——这条判据本身值得怀疑是否对所有任务都成立。
6. **实机验证偏弱**:只有一台机器人、一个跟踪+避障任务、无基线对比、无失败率/统计,只能算可行性演示,不足以支撑"实用部署"的强结论。
7. **与本主题(RL 稳定性 trick + 超参敏感性)契合但成本未充分讨论**:训练比 SAC/TD3 慢、要维护两个值分布网络 + 多个移动平均量(ω、b),论文对"额外复杂度 vs. 收益"只给了一句时间对比,未讨论样本效率或调参省下的实际工时是否真的划算。
