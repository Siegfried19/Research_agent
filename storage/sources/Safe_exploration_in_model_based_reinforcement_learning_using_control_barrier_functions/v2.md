# Safe exploration in model-based reinforcement learning using control barrier functions
> Max H. Cohen, Calin Belta · 2022 · Automatica · 引用 83 · DOI 10.1016/j.automatica.2022.110684

## 一句话
提出一类"类 Lyapunov 控制屏障函数(LCBF)"构造的**最小侵入式安全护盾控制器**,把它叠加到在线学习最优值函数的 model-based RL 上,使得**安全性在所有时刻无条件成立、与学习是否收敛解耦**,从而能"安全地探索/学习一个追求性能的策略",而不是像同类工作那样只能"学一个安全策略"。

## 解决了什么问题
- 安全学习控制里的核心矛盾:RL 要靠探索逼近最优策略,但探索可能撞破安全约束。(§1)
- 作者指出同类 CBF/BLF + RL 工作(如 [6,9,11,26,27,39])的关键局限:它们把**正在被学习的值函数本身当作安全证书(BLF)**,于是"安全性被绑定在 RL 算法的收敛条件(激励/PE 条件)上",而这些条件在实践中无法验证;一旦学习未收敛,安全无保证。(§1 末段)
- 另一类基于障碍 Lyapunov 函数(BLF)的方法只能处理**矩形(超矩形)状态约束**,无法表达碰撞避免这类复杂安全集。(§1)
- 本文目标:把"学习"与"安全"**解耦**,让安全在任何时刻、独立于任何学习条件下都成立,同时仍在线学习不确定非线性系统的动力学与无限时域最优值函数。

## 用什么方法解决的(含直觉:为什么 work)
- **系统设定**:控制仿射系统 `ẋ = f(x) + g(x)u`(式1),安全集 `C = {x | h(x) ≥ 0}`(式3)。
- **新工具 LCBF(式5)**:`B(x) := (b(x) − b(0))²`,其中 `b` 是普通候选 CBF。`B` 满足 `inf B ≥ 0`、`B(0)=0`、`x→∂C 时 B→∞`。**直觉**:平方化后 `B` 在原点处归零、半正定,既保留了"逼近边界时爆到无穷→挡住越界"的屏障性质,又因为在原点取零、长得像 Lyapunov 函数,可以和把原点作为平衡点的镇定策略**自然叠加而不互相打架**。(§3)
- **护盾控制器(式6)**:`k_b(x) := −c_b · g(x)ᵀ ∇B(x)ᵀ`,`c_b>0` 是增益。沿闭环求导得 `Ḃ = ∇B·f − c_b‖∇B·g‖²`;论文证明在 Assumption 1 下,当 `x→∂C` 时 `Ḃ → −∞ < 0`(式8),从而**排除任何轨迹抵达边界**,Int(C) 前向不变(Theorem 1)。**直觉**:越靠近边界,`∇B` 越大,护盾项把状态"推"回安全区的力度越强。
- **最小侵入性(Corollary 1)**:把护盾叠加到任意标称策略 `u = k(x,t) + k_b(x)`,既保安全又保原点为平衡点;`B` 在内部半正定 ⇒ 远离边界时护盾项几乎为零,**只在快越界时才介入**(实验里有/无护盾的轨迹在接近 ∂C 前几乎重合)。
- **在线学最优策略(§4 ADP)**:无限时域代价 `J=∫(xᵀQx+uᵀRu)dτ`(式10),最优策略 `k*(x)=−½R⁻¹g(x)ᵀ∇V*(x)ᵀ`(式13)。用 **StaF(state-following)核**做值函数的**局部**参数化逼近 `V*(y)=W(x)ᵀφ(y,c(x))+ε`(式14),核中心随当前状态移动,只在当前状态邻域逼近,避免全局逼近的维度灾难。
- **系统辨识**:漂移项 `f(x)=Y(x)θ+ε_θ`(式16),`Y` 是已知基、`θ` 是未知参数;用自适应控制的参数辨识器在线估 `θ`,其权重估计误差指数收敛到一个小球(式17)。
- **"用仿真经验做安全探索"(§5,核心机制)**:实际系统跑安全策略(式19)`u = k̂ − (c_b/2)R⁻¹g(x)ᵀ∇B(x)ᵀ`;但为了让值函数学得好,需要 Bellman error 数据覆盖未访问区域。作者借助**已辨识的近似模型**,在状态空间里挑外推点 `xᵢ`,沿这些点用**不带护盾的探索策略** `uᵢ := k̂(...)`(式21)虚拟仿真出 Bellman error。**直觉**:探索发生在"想象/仿真"里,真实系统从不被推到危险点,所以既能充分探索状态空间、又不冒真实安全风险。权重用递归最小二乘(式22-23)+ 带投影算子的 actor 更新(式24)在线更新。
- **两条保证分开**:
  - **安全(Proposition 1)**:策略(式19)使 Int(C) 前向不变。值得注意——这条**不依赖任何"值函数下降"的 Lyapunov 论证**,只要 `Ŵa` 有界(投影算子保证),安全就成立 ⇒ 安全与学习收敛**彻底解耦**。
  - **学习收敛(Theorem 2)**:在 Assumption 1-3(含外推轨迹上的持续激励 PE)下,系统状态与权重估计误差**一致最终有界(UUB)**,`limsup‖Z(t)‖ ≤ η₁⁻¹∘η₂(√(2ι/κ))`(式27)。PE 条件只挂在仿真外推轨迹上,可通过多取外推点满足,而无需激励真实系统。

## 动机 & 背景
- 学习类控制(RL)缺乏可证安全保证,限制其在安全攸关场景落地;安全常形式化为安全集的前向不变性。(§1)
- CBF 是研究集合不变性的工具(类比 Lyapunov 之于平衡点),无需显式算可达集即可保证安全。(§1)
- 已有"CBF/BLF + RL"路线的两类毛病:(a) BLF 类只能处理超矩形约束;(b) 把学到的值函数当安全证书的方法,安全性被绑死在 RL 收敛/激励条件上。本文要**解耦**二者。(§1-2)
- 与 [16,17] 的 MBRL 架构相似,但关键差异:本文**探索用的策略(无护盾)与真实部署的策略(带护盾)不同**,这让收敛分析更复杂,但换来真实系统的全程安全。(§1)

## 方法细节
- Definition 1:标准 CBF;式(5):LCBF `B=(b−b(0))²`;Lemma 1:`B(x(t))<∞ ∀t ⇒ Int(C)` 前向不变。
- Assumption 1(三条):漂移在边界不"爆"(`‖f‖≤ℓ_f(‖x‖)‖x‖`)、控制方向不消失(`g̲≤‖g(x)‖`)、`∂C` 邻域内 `‖∇b·g‖≠0`(相对阶为 1;Remark 2 说此条比必要条件强、可放宽)。
- Theorem 1 + Corollary 1:护盾单独/叠加标称策略均保前向不变并保原点平衡。
- §4:HJB(式12)、最优策略(式13)、StaF 核逼近(式14-15)、漂移辨识(式16-17)、Bellman error(式18)。
- §5:安全策略(式19)、外推 Bellman error(式20-21)、RLS 与投影 actor 更新(式22-24)、Proposition 1(安全)、Theorem 2(UUB,式25-27)。
- 附录 A:Theorem 2 充分条件(式25)中各常数 `κ, ι, M` 的显式定义。

## 数据集 & 实验设置
- 纯**数值仿真**,两个低维例子,无真实机器人、无数据集。
- **例1 非线性系统**(取自 [15]):`x∈ℝ²,u∈ℝ`,`f(x)=[−0.6x₁−x₂, x₁³]ᵀ`,`g(x)=[0, x₂]ᵀ`。漂移未知但参数线性:`f=Y(x)θ`,`θ=[−0.6,−1,1]ᵀ`,在线用 integral concurrent learning 辨识。安全集 `h(x)=p·x₂²−x₁+1`,`p∈{−1,1}`:**`p=−1` 为凸安全集、`p=1` 为非凸安全集**;作者强调这类约束**不是超矩形形式**,故 [11,26,39] 无法处理。护盾用 `b(x)=1/h(x)` 构 LCBF。最优控制 `Q=I₂,R=1`;值函数用 `L=3` 个 StaF 多项式核 `φᵢ=xᵀcᵢ(x)`,核中心放在随状态移动的等边三角形顶点。学习增益 `kc1=0.1,kc2=1,ka1=1,ka2=0.1,γc=1,βc=0.001`,权重初值 `[0.5,0.5,0.5]ᵀ`,`Γ(t0)=100I₃`。凸例用式(19)、`c_b=1`;非凸例改 `c_b=0.001`、`Γ(t0)=10I₃`。
- 例1 比较三种控制:① RL+护盾(蓝)② RL 无护盾(橙,"No CBF")③ 把 CBF 当代价惩罚项 `r=‖x‖²+u²+20B(x)`(绿,"CBF Penalty",对应 [6,27] 思路);另有开环(紫)与边界 ∂C(黑)。(Fig 1)
- **例2 碰撞避免**:二维单积分器 `ẋ=u`,绕开圆形障碍(中心 `xo`、半径 `ro`)驶向原点,`h(x)=‖x−xo‖²−ro²`(非超矩形,故 [11,26,39] 不适用)。`Q=I₂,R=I₂`,权重全初始化为 1,`Γ(t0)=10I₃`;动力学平凡故不做辨识。比较式(19) RL 策略 vs 解代数 Riccati(ARE/LQR)策略,二者都叠加 `c_b=0.1` 的护盾。(Fig 3)

## 主要结果 & 结论(写方向,不堆精确数字)
- **RL+护盾在凸/非凸安全集上都能把状态镇定到原点且全程不出安全集**(Fig 1 蓝色轨迹)。observed(仅此 2 个低维例子)
- **去掉护盾的纯 RL 能镇定,但多次违反安全约束**(Fig 1 橙色);说明安全确实来自护盾、不是 RL 自带。observed
- **把 CBF 写进代价(惩罚项)的方法在本例中初期仍会冲出安全集**:系统快速逼近边界并越界进入非安全区,要等策略收敛后才变安全——而其安全没收敛前无保证。**对应 Fig 2 顶部(左上,凸例)的 `h(x(t))` 曲线**(`h` 一度跌破 0)。这正是作者的核心论点支撑:把安全编码进代价 = "学一个安全策略",安全随学习收敛而来;本文护盾 = "安全地学一个性能策略",安全全程成立。observed
- **护盾确实是最小侵入的**:有/无护盾的受控轨迹"几乎完全重合,直到 `x(t)` 逼近 ∂C 才分开"(§6 凸例描述,Fig 2 顶部)。observed
- **辨识有效**:估计的漂移参数 `θ̂`(Fig 2 底部)收敛到真值(虚线)。observed
- **例2**:RL 策略绕过障碍并收敛到原点,而 **LQR(静态时不变反馈)被卡在障碍后面**(Fig 3)。作者解释:LQR 是时不变反馈,无法在某些初值下兼顾"避障+镇定"双目标;RL 策略因权重 `Ŵa` 在线演化 ⇒ 等价于**时变/非线性动态反馈**,两条轨迹初期都被障碍卡住,但 RL 权重动态演化后收敛到能绕障的新策略。observed
- **理论结论(已证明)**:Proposition 1 证明式(19)无条件保前向不变(安全不依赖学习收敛);Theorem 2 证明闭环状态+权重误差 UUB。这两条是**定理**,非仅经验。strong(就理论本身;但前提是 Assumption 1-3 成立、`g` 已知精确)

## 适用边界(什么时候管用 / 什么时候不管用)
- **管用**:控制仿射系统;输入矩阵 `g(x)` **已知**;漂移 `f` 结构为"已知基 × 未知参数"(`f=Y(x)θ`)、参数在线可辨识;已有一个**有效的候选 CBF `b` 和已给定的安全集 `C`**;安全约束可表达为一般可微 `h(x)≥0`(**优于** BLF 类只能处理超矩形约束——这是相对碰撞避免/非凸集的真实优势)。
- **不管用 / 受限**:`g` 或安全集结构未知时(护盾 `k_b=−c_b g∇B` 直接依赖已知 `g`);需要安全保证覆盖高维/真实系统时(PE 条件挂在外推轨迹上,作者自承"随状态维数扩展性差",外推点数 `N` 随维度激增);要求安全集事先给定、本文**不学习安全集**;`c_b` 需人工细调(过小虽更不侵入,但实践中可能导致控制量过大、超出执行器限幅、变化过快)。
- **比较基线强度**:对照的是"无安全约束的纯 RL"、"CBF 当软惩罚"、"静态 LQR+护盾"——足以说明本文论点,但都不算很强的安全 RL 基线;未与 [16,17] 等同源 MBRL 在性能/最优性上做定量对比。

## 核心贡献
1. 提出 **LCBF(类 Lyapunov CBF)**:在保留 CBF 安全屏障性质的同时半正定、原点归零,便于与镇定策略叠加(式5,Theorem 1,Corollary 1)。
2. 把 [16] 的 MBRL 架构扩成**安全探索框架**:在线安全学习不确定非线性系统的漂移与无限时域最优值函数/策略,关键是**用仿真经验**让探索发生在想象中、真实系统始终走安全策略(§5,Proposition 1,Theorem 2)。
3. 数值例子表明本方法能处理比同类方法**更一般的安全约束(非超矩形、非凸、碰撞避免)**,并展示"安全与学习解耦"相对"把安全编进代价"的优势(§6)。

## 局限与我的质疑
1. **"不确定动力学"的成色有限**:`g(x)` 必须完全已知,漂移也要求已知基 `Y(x)` 只差未知参数 `θ`。这比"未知动力学"弱很多;若 `g` 有误差,护盾控制器 `k_b=−c_b g∇B` 的安全保证可能直接失效,而文中未处理 `g` 不确定的情形。
2. **只有 2 个二维玩具例子,且无定量指标**:动机大谈机器人/碰撞避免,但实验是 2D 非线性 + 2D 单积分器,无高维、无真实硬件;结果全是定性轨迹图,没有代价/遗憾/最优性差距等量化数据,难以评估学到的策略"有多优"。
3. **可扩展性是真瓶颈,作者自己也承认**:Theorem 2 的收敛依赖外推轨迹上的 PE(Assumption 3),靠多取外推点 `N` 满足,而这"随状态维数扩展性差"(脚注8/相关备注)。高维下既贵又难保证学习收敛——虽然安全(Proposition 1)不受此影响,但"安全且有用"才是目标。
4. **充分条件无法验证(作者 Remark 3 已自述)**:Theorem 2 的式(25)依赖 `ε`(逼近误差)等未知量或完全由轨迹决定的量,无法事先核验。作者辩称安全(Prop 1)已独立成立——成立,但这等于说"能保证安全、但不能事先保证学得好/学得动",对追求性能的初衷是个折扣。
5. **"CBF 当惩罚会越界"的对照略偏弱**:软约束(惩罚项)在收敛前违例几乎是显然的,这个对照更像在确认软约束的已知短板;真正有分量的是 Proposition 1 的"全程硬安全"理论保证,而非这组数值对照本身。
6. **最优性只是局部+近似**:用 StaF 核做的是**局部**值函数逼近、收敛只到 UUB(非渐近最优),所以"最优策略"是局部近似意义下的;论文证明的是有界性,不是收敛到全局最优——这点需要和"学到最优策略"区分开。
7. **安全集与 CBF 需人给**:框架学的是值函数与漂移参数,但**候选 CBF `b`、安全集 `h`、镇定结构都得事先具备**;对"安全集本身未知/需从数据学"的更现实场景没有覆盖。
