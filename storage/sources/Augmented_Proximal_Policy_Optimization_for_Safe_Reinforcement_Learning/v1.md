# Augmented Proximal Policy Optimization for Safe Reinforcement Learning
> Juntao Dai, Jiaming Ji, Yang Long, Qian Zheng, Gang Pan · 2023 · Proceedings of the AAAI Conference on Artificial Intelligence · 引用 32 · DOI 10.1609/aaai.v37i6.25888

## 一句话
APPO 把"拉格朗日乘子"和"二次惩罚项"拼成一个**增广拉格朗日(multiplier-penalty)目标**来解约束 MDP，并对 reward 与 cost 都套用 PPO 式裁剪代理目标，用一阶优化器即可训练——目标是让安全 RL 训练**收敛更稳、cost 不在阈值附近来回振荡、且只需有限惩罚系数就精确卡住约束**。

## 解决了什么问题
作者把现有安全 RL（CMDP 框架）方法归为三类，各有一个痛点，APPO 想同时治这三个：
- **拉格朗日类（PDO/FOCOPS/CPPO-PID 等）**：乘子更新比策略迭代慢一拍（"multiplier update more slowly than policy iteration"），导致乘子没生效时大量违约迭代、乘子过冲时又过度压低 cost——表现为 cost 在阈值附近**固有振荡(inherent oscillation)与过冲**，难收敛。
- **惩罚函数类（IPO/P3O 等）**：要保证惩罚函数与原问题等价，理论上需要**足够大甚至无穷大的惩罚系数**；但系数越大近似/估计误差越大，陷入"调系数"的两难，且可能收敛到次优解。
- **二次/信赖域类（CPO/PCPO 等）**：每步要算 Fisher 信息矩阵的逆，计算昂贵。

## 用什么方法解决的（含直觉：为什么 work）
核心是**给原约束问题的拉格朗日函数挂一个二次偏差项**，构造"乘子-惩罚(multiplier-penalty)"函数（即经典优化里的增广拉格朗日/method of multipliers）。

**直觉(为什么 work)**：
- 纯拉格朗日法靠乘子 λ 这一个慢变量去压 cost，λ 滞后→振荡。APPO 额外加的二次惩罚项提供**连续、即时**的 cost 控制，**补上滞后乘子的空窗期**（"complement the lagged Lagrangian multipliers"）。两套机制互补：乘子负责长期对齐 KKT 点，惩罚项负责短期阻尼波动。
- 该二次项有个**自适应缓冲带**：只有当策略进入约束违反的松弛边界（论文给出条件 `ϕ_ci(π) ≥ -λ_i/σ`）时惩罚才发力，等于"在真正违约前先预热"，比"违约后才罚"更稳（observed/机制论证）。
- 关键理论卖点：**有限惩罚系数即可做到精确(exact penalty)**。传统惩罚法要 σ→∞ 才等价于原问题，会带来数值问题和大近似误差；APPO 证明存在有限阈值即可等价（见下 Theorem 1），这是它声称"精确 cost 控制 + 不退化成次优"的根基。

## 动机 & 背景
- 框架是 **CMDP**：在 MDP 上加一组辅助 cost 函数 `c_i` 与上限 `b_i`，可行策略集 `Π_C = {π : J_ci(π) ≤ b_i, ∀i}`，目标 `π* = argmax_{π∈Π_C} J(π)`（式(2)）。
- 用 Kakade-Langford 的性能差分公式(式(3))把目标改写成**逐步迭代搜索**(式(4))：最大化优势 `A^πk`，约束写成 `J_ci(πk) + 1/(1-γ)·E[A^πk_ci] ≤ b_i`。这是 CPO/FOCOPS 一系的标准起点。
- 作者引基准评测(Ray et al. 2019)指出：简单拉格朗日法实战上不输甚至优于昂贵的二次法——所以 APPO 选择走**一阶、无 Hessian 求逆**的路线，而非信赖域路线。

## 方法细节
**1) 构造增广拉格朗日**：先把不等式约束用松弛变量 `p_i≥0` 写成等式 `h_{k,i}(π)=ϕ^πk_ci(π)+p_i=0`(式(5))，再加二次偏差项(式(6))：
`P_k(π,λ,p,σ) = -L^πk_R(π) + Σ λ_i h_{k,i}(π) + (σ/2) Σ h²_{k,i}(π)`，σ 为惩罚系数。

**2) 消掉松弛变量 p**：p 有闭式解 `p_i = max(-λ_i/σ - ϕ_ci(π), 0)`，代回得到实际优化的"乘子-惩罚函数"(式(9))：
`L(π,λ,σ) = -L^πk_R(π) + (σ/2) Σ [ max(λ_i/σ + ϕ^πk_ci(π), 0)² - λ_i²/σ² ]`（推导见原文 Appendix A.1）。

**3) 理论保证（论文真证明了的）**：
- **Theorem 1（exact penalty）**：存在有限 `σ̄<∞`，对任意 `σ>σ̄`，原约束问题(4)与增广 primal-dual 问题(8)**共享同一可行最优解集**（证明在 Appendix A.2）。作者强调"σ 有限性至关重要"，区别于需要无穷系数的传统惩罚法。
- **Proposition 1**：在最优点 `(π*,λ*)` 附近，约束违反量满足 `max(ϕ_ci(πk), -λ_i^k/σ_k) ≈ (1/σ_k)(λ*_i - λ_i^k)`(式(12))——即**增大 σ 可线性压低违约量**，直觉上"足够大的 σ 能有效阻尼振荡"。

**4) 乘子更新**：`λ_i^{k+1} = max(λ_i^k + σ ϕ_ci(πk), 0)`(式(13))——注意步长里直接带了 σ。

**5) 深度 RL 落地（关键工程点）**：直接最小化式(9)不可行（含未知未来状态、采样效率低），于是仿 PPO 对 **reward 和 cost 都用裁剪代理目标**：
- reward：`L_R(θ)=E[min(r_t(θ)A^R_t, clip(r_t(θ),1-ε,1+ε)A^R_t)]`(式(14))；
- cost：`L_ci(θ)=E[max(r_t(θ)A^ci_t, clip(...)A^ci_t)]`(式(15)，cost 用 max 即悲观上界)；
- 合成目标式(16)把 L_R、L_ci 套进式(9)的结构，`r_t(θ)` 是重要性采样比，优势用 **GAE** 估计，`b̂=J_ci(π_old)-b_i`。
- 这一步让 APPO**摆脱信赖域、避免 Hessian 求逆**，任意一阶优化器(如 Adam)即可解；式(16)几乎处处可微。

**6) 自适应惩罚系数（免去手调 σ）**：定义约束违反度 `ν(πθk)=sqrt(Σ max(J_ci-b_i, -λ_i^k/σ_k)²)`(式(17))与阈值 `ε_k=1/σ_k`；当 `ν>ε_k` 就把 `σ_{k+1}=ρσ_k` 放大。整体流程见 Algorithm 1（交替更新 critic→策略→乘子→按需放大 σ）。

## 数据集 & 实验设置
- **环境**：跨三个安全 RL 基准——Safe MuJoCo、Safety Gym、Bullet Safety Gym；4 类任务**按难度递增**：Run、Circle、Goal、Button，每类两种 agent，共 **8 个场景**（Ant/Humanoid Run、Ball/Car Circle、Point/Car Goal、Point/Car Button）。各任务 cost 阈值见 Table 1 括号（如 Run 限速=无约束 PPO 速度的 50%）。
- **基线（覆盖面较全，含强基线）**：拉格朗日类 PDO、FOCOPS、CPPO-PID；惩罚类 IPO、P3O；二次/信赖域类 CPO、TRPO-L、PCPO。这是安全 RL 里较有代表性的一组同期 SOTA。
- **评判口径**：只在**满足约束的前提下**比累计 return，违约的结果一律算"差"（"consider all constraint-violating results as poor performance"）。曲线/置信区间为多次实验的均值±95% CI / 标准差（具体 seed 数、网络结构等见原文 Appendix B，本总结未逐一核对）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **整体性能**：在 8 个场景里，APPO 在"满足约束 + 高 return"上总体优于各基线（Table 1，加粗为满足约束下的最佳 return）。作者主张这是"新 SOTA"。supported（系统跨任务实验）；但属"总体更好"，并非每格都最高（如 Point Goal/Car Goal/Button 的 return 仍是 CPO/PCPO 更高，**但那些方法违约**，按论文口径不算数）。
- 论文点名的最显著一处：在 **Car Button** 任务上相对 PDO/FOCOPS/CPPO-PID **平均 +41% 的 return 提升**（同时 IPO/CPO/PCPO 在该任务违约）。这是**单一任务**的数字，observed，勿外推成"全任务 +41%"。
- **稳定收敛/抗振荡**：学习曲线(Fig.2、Fig.3)显示 APPO 收敛到约束更快更平滑、训练中违约次数少；而 PDO/FOCOPS/CPPO-PID 的拉格朗日类在阈值附近不同程度振荡。Fig.3 还展示 PDO 乘子明显滞后于约束曲线。supported。
- **精确 cost 控制**：Fig.4 在 Ant Run 用三个不同阈值(60/103.12/140)都能贴着上限收敛；Fig.5 在 Point Goal 用阈值 50 调好的超参直接迁到阈值 25 仍精确控约，而 IPO/P3O 需重新调参。observed（少数任务/阈值上）。
- **消融**：去掉拉格朗日部分→退化为外点法 EPM；σ=0→退化为 PDO。两个消融都表明二次惩罚项与拉格朗日二者各自有贡献（Fig.5 / Robustness 节）。supported。
- **鲁棒性**：对惩罚系数 σ 和乘子学习率在较宽范围内稳定（更多见 Appendix C）。observed。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：标准 CMDP / 连续控制 + 单或多 cost 约束、想要"卡准阈值、训练少违约"的场景；想要**一阶、易实现、不调无穷惩罚系数**的实现（相对 CPO/PCPO 省去 Fisher 求逆，相对 CPPO-PID 省去 3 个敏感 PID 超参，相对 P3O 不需"大于最优对偶变量"的巨大系数）。
- **作为 PDO/PPO 的直接增强**：σ=0 即退回 PDO，σ 调大↑则更强阻尼——可视为 PDO 的"加阻尼版"，迁移成本低。
- **可能不管用/未验证**：作者自承"CMDP 与现实人机协作所需安全性之间仍有差距"，更严格的安全准则(如硬约束/零违约/状态级安全)留作未来工作；论文全是仿真基准，**无真实机器人/真实部署**验证。Theorem 1 只保证"存在有限 σ̄"，**没给如何计算 σ̄**，实际靠式(17)的启发式自适应增长来兜——理论与落地之间有缝。

## 核心贡献
1. 提出 **APPO**：用增广拉格朗日(乘子+二次惩罚)目标解 CMDP，兼顾稳定收敛、精确 cost 控制、一阶易实现三点。
2. **理论**：证明该乘子-惩罚函数是**有限系数下的精确惩罚**(Theorem 1，原问题与增广 primal-dual 同最优解集)，并用 Proposition 1 解释二次项对收敛/降违约的作用。
3. **算法实现**：基于 Actor-Critic，对 reward 与 cost **统一用 PPO 式裁剪代理目标** + 自适应惩罚系数，给出完整伪代码(Algorithm 1)，并在 8 个跨基准场景上对一组较全的安全 RL 基线显示总体领先。

## 局限与我的质疑
1. **"精确"是渐近/理论意义，落地仍是启发式**：Theorem 1 只给出"存在有限 σ̄"的存在性，不给 σ̄ 的可计算上界；实际用式(17)+`σ←ρσ` 的启发式自适应增长。所以"有限系数即精确"的卖点在**实践中并不直接可验证**——你不知道当前 σ 是否已过 σ̄。这一点论文未充分讨论。
2. **本质是经典增广拉格朗日/method of multipliers 在安全 RL 的移植**。其新意更多在"和 PPO 裁剪 + 自适应 σ 的工程组合"以及在该问题上的等价性证明，而非全新的优化机理。读者若熟悉增广拉格朗日，机制上不会意外。
3. **评比口径对自己有利**：作者把"任何违约都算差"，于是 CPO/PCPO 在 Goal/Button 上 return 更高却因违约被判负。这对安全 RL 合理，但也意味着"APPO 是 SOTA"的结论强依赖这条口径；在"允许少量违约换更高 return"的设定下结论可能不同。
4. **多 cost / 高维约束未真正压力测试**：实验基本是单约束场景；式中虽写成多约束 `Σ_i`，但没有针对多个相互冲突约束的实验，"多约束时 σ 自适应是否仍稳"未验证。
5. **超参敏感性只给定性结论**："robust to σ 与乘子学习率"主要靠曲线和 Appendix C，正文没给系统的超参网格/失败边界；自适应里的 ρ、σ_0、阈值 ε 的设定理由也较弱。
6. **数字可复现性需查附录**：Table 1 的 ±值是 95% CI，但正文未在主体交代 seed 数、训练步数、网络规模等(指向 Appendix B)。本总结未核对附录细节，若要精确复现请直接读 PDF 的 Appendix B/C。
7. **与本研究主题(可交互数字人/通用 RL)的距离**：纯仿真、纯运动控制类基准，未触及人机交互、人类反馈或真实安全后果；其"安全=cost≤阈值"的抽象离"对人安全"还有论文自承的 gap。
