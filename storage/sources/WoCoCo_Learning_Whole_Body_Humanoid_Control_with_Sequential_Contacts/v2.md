# WoCoCo: Learning Whole-Body Humanoid Control with Sequential Contacts
> [, ", C, h, o, n, g,  , Z, h, a, n, g, ", ,,  , ", W, e, n, l, i,  , X, i, a, o, ", ,,  , ", T, a, i, r, a, n,  , H, e, ", ,,  , ", G, u, a, n, y, a,  , S, h, i, ", ] · 2024 · Conference on Robot Learning · 引用 107 · DOI 10.48550/arxiv.2406.06005

## 一句话
WoCoCo 提出一套**任务无关的 RL 奖励 + sim-to-real 设计**,把"需要按顺序完成接触序列(sequential contacts)"的人形全身控制任务**按接触阶段拆解**,只需为每个任务额外指定 1–2 个直觉性任务奖励,就能端到端学出无运动先验(no motion prior)的四种真实人形任务(跑酷跳跃、箱子搬运、拍打跳舞、攀崖),并迁移到 22-DoF 恐龙机器人。

## 解决了什么问题
- 传统做"序列接触"人形交互靠 model-based 运动规划/轨迹优化,耗时且依赖简化降阶动力学模型,影响动作质量和真机表现(§1)。
- 已有 model-free RL 大多只做标准 locomotion(如走路),做带特定接触序列的任务时,需要繁琐的任务专属调参、状态机设计,且长程探索困难(§Abstract、§1)。
- 已有展示"任务感知接触序列"的 RL 工作(如踢球、loco-manipulation),每个策略都是为某个任务/状态转移单独调的,公式和奖励各不相同,难以推广到长程任务(§1)。
- 作者提炼的核心问题:"如何用一个 RL 框架达到这种简洁性与适配性?"(原文 "How can we achieve such simplicity and adaptability with an RL framework?"),并识别三大挑战:Q1 单阶段内如何达成期望接触状态、Q2 如何跨多阶段顺畅探索、Q3 如何配套 sim-to-real(§2、§1)。

## 用什么方法解决的（含直觉：为什么 work）
- **任务分解为接触阶段(contact stages)**:把任务建模为一串阶段 i∈{0,…,I},每阶段由 contact goal g^con(哪些末端执行器该接触到哪)与 task goal g^task(额外任务要求,如上身姿态)共同定义;完成一阶段(由传感器或人工确认)后,过固定时间推进到下一阶段(§2、Fig.1)。直觉:把"长程稀疏接触探索"切成若干短的子目标,降低每段的探索负担。
- **形式化为扩展 MDP**,目标 max E[Σγ^t r_t],奖励拆为三块:`r = (r_WoCoCo + r_reg) + r_task`,前两项任务无关(task-agnostic),只有 r_task 含 1–2 个任务相关项(式(1)、§2)。用 PPO + 对称增强(symmetry augmentation)、Isaac Gym 大规模并行训练,策略是端到端 MLP(actor/critic 隐层 [512,256,128],Appendix H.3),输出关节目标位置交给底层 PD 控制器(§2)。
- **WoCoCo 奖励三项**(式(2)`r_WoCoCo = w_con·r_con + w_stage·r_stage + w_curi·r_curi`):
  - **稠密接触奖励 r_con(式(3))**:`r_con = n_corr − n_con·n_wrong·𝟙(n_stage>0) + 2·n_con²·F_con·F_task`。直觉:不像 0-1 接触奖励只给"全对/全错",它**逐个**正确接触加分、逐个错误接触扣分,梯度信号更密,更好引导策略;且第一阶段(n_stage=0)屏蔽错误接触惩罚以鼓励探索、避免一开始就被罚到 reset。Appendix A 用跑酷例子(右脚踩石、左脚悬空、上身保持"hug")具体演示了各符号取值。
  - **阶段计数奖励 r_stage(式(4))**:`r_stage = n_stage·F_task`。直觉:停在当前阶段也能拿到其它正奖励,机器人会"战略性偷懒"不往前推进;用已完成阶段数 n_stage 做奖励,驱动它去探索更多阶段、最大化累计回报,缓解短视(§3.1)。F_task 条件用于防止它故意不完成任务目标来刷阶段奖励。
  - **好奇心奖励 r_curi(式(5)(6))**:用**基于计数的 hash 好奇心**而非 RND——一个随机初始化且冻结的 NN f_curi 把任务无关好奇观测 o_curi 哈希进桶,`r_curi = 1/√(该桶被访问次数)`。直觉:作者发现 RND 会"过度探索"危险但稀有的状态(如学会冒险后仰),而 hash-count 好奇心随访问次数数值衰减、能抑制随机网络过拟合,探索更稳(§3.1、Appendix I)。
- **Sim-to-real(§3.2、Appendix F/J/K)**:用域随机化 + 正则奖励(regularization rewards),且**所有人形任务共享同一套**域随机化与正则设置。三阶段课程:1) 先无域随机化训到收敛(好奇心只在此阶段开),2) 加域随机化训到收敛,3) 每 2000 迭代把正则项权重提高 20% 直到翻倍,诱导更保守的动作。还堆叠前 3 个控制步的关节状态/动作进观测以增强时序记忆。

## 动机 & 背景
- 人形要像人一样在环境中操作,常需在执行任务时完成序列接触(§1)。model-based 运动合成虽强但慢、依赖简化模型(§1)。
- 对比 model-based 求解器如 Crocoddyl 能用少量直觉代价项处理多种接触序列任务——作者想用 RL 复现这种"少量直觉项即可"的简洁与适配(§1)。
- 三大挑战明确写出:接触稀疏(尤其还要兼顾平衡/姿态维持)、机器人因复合风险而回避探索整个长程、sim-to-real 常靠任务无关正则奖励而这会妨碍探索(§1)。

## 方法细节
- 奖励权重(Appendix E, 表1):四任务的 (w_con, w_stage, w_curi) 分别为 跑酷(120,160,20000)、loco-mani(40,160,40000)、跳舞(10,5,5000)、攀崖(20,40,10000)——量级差异大,说明各任务需各自标定。
- 正则奖励(Appendix F/G,表2)含:yaw rate、torques、torque overlimit、DoF 加速度/速度、action rate、termination、foot contact forces、foot orientation、stumble、slippage 等;**仅当不需要跳跃动作时**(除跑酷外的任务)才加 "feet air time" 与 "no fly" 两个风格塑形项。
- 各任务的 task reward 公式(Appendix G):
  - 跑酷(式(8)):仅 1 项,跟踪肘部在 base frame 的旋转与位置误差(w_task=30)。
  - 箱子 loco-mani(式(9)):2 项,鼓励手靠近箱侧、箱靠近目的地(w_hand=100, w_box=200);恐龙球任务去掉方向角条件。
  - 跳舞(式(10)):2 项,鼓励双臂张开 + 精准踏点(w_hand=5, w_foot=10)。
  - 攀崖(式(11)):2 项,鼓励面向墙 + 四末端精准贴合目标区(w_base=50, w_ee=5)。
- 观测设计(Appendix H):本体感知(关节位置/速度、上一动作、base 线/角速度、投影重力,部分量堆叠 3 步)对所有任务共享;目标表示按任务不同(跑酷喂未来两阶段的 foothold 角点以便预调脚步;其余任务只喂当前阶段)。本工作不用相机/LiDAR,目标表示由动捕系统作原型提供。
- 好奇观测细节(Appendix I):o_curi = base 状态(世界系位置/四元数朝向/线角速度)+ 所有末端的世界系位置和接触状态;给了 3 种预处理方案,论文结果用方案(2)(归一化到[0,π]后取 sin/cos)。好奇 hash 网络:1 隐层、32 单元、16 维输出。
- 域随机化范围(Appendix J,表3):摩擦 U(0.2,1.1)、base 质心偏移、连杆质量 U(0.7,1.3)×默认、P/D 增益 U(0.75,1.25)×默认、Torque RFI、控制延迟 U(0,20)ms、每 5s 推一次(Δv_xy=0.25m/s)、地形 flat/unseen gravels。
- 部署(Appendix L):策略 50Hz、PD 200Hz,对 PD 目标加 4Hz Butterworth 低通滤波防抖;作者还发现官方 URDF 的躯干质量偏差大、脚几何错误,自行称重和测量做了 real-to-sim 修正。

## 数据集 & 实验设置
- 无外部数据集;在 Isaac Gym 仿真训练,PPO + 对称增强(Appendix D:对原始与镜像好奇观测各算 r_curi 取平均)。
- 四个真实人形任务 + 一个 22-DoF 恐龙机器人球操控任务(由[55]改编,六个末端:头/尾/四脚)用于验证跨本体泛化(§4.5、Fig.6)。
- 消融与分析集中在最具挑战的跑酷跳跃任务上(§5、Appendix B/C)。

## 主要结果 & 结论（写方向，不堆精确数字）
- WoCoCo 端到端 RL 策略在真实世界完成四个带不同接触序列的人形任务,且无任何运动先验/参考(§Abstract、贡献3、Fig.1–5)。observed——这些是定性真机展示,非定量对比基线。
- 跑酷:真机展示了连续动态跳跃同时跟踪上身姿态、对未见碎石等扰动的鲁棒性;真机因场地限制只测了 1–2 次连续双脚接触跳(§4.1)。observed。
- 箱子 loco-mani:真机展示 0.5s 内高效转身、走-取箱平滑过渡、边接近目的地边取箱、踩到绑带后恢复(§4.2、Fig.3)。observed。
- 跳舞/攀崖:真机成功部署;攀崖在仿真中对推力和未见碎石鲁棒,真机用人手持板代替崖面、能适应变化的接触力(§4.3/4.4、Fig.4/5)。observed。
- 消融(§5、Appendix B,Supplementary Fig.8/9 给出 baseline 行为与学习曲线):
  - 去掉稠密接触奖励(退化为 0-1 接触奖励):**无法**探索出跨石跳跃,只原地跟踪上身姿态。supported(有学习曲线)。
  - 去掉阶段计数奖励:机器人**故意不完成**接触目标以避免进入更难阶段、同时刷其它奖励,验证该项必要性。supported。
  - 去掉好奇心奖励:欠探索,原地不动。supported。
  - 用 RND 好奇心:学会"冒险后仰"这种危险行为(与 Burda 等 RND 工作 §3.7 现象一致),而 hash-count 好奇心不过拟合特定行为。supported(observed 级别的机制解释)。
- 训练稳定性(Appendix C,Supplementary Fig.10):跑酷任务 5 个随机种子学习曲线均收敛,progress 收敛到 >0.75,表明对随机网络初始化与探索的随机性稳健。supported。
- Sim-to-real 课程消融(Appendix K):把域随机化提前到 phase1(合并前两阶段)会让跑酷 progress 收敛到 <0.6(对比标准 WoCoCo 的 >0.75);去掉 phase3(渐增正则)会让真机动作变 jerky,连最不动态的攀崖也会因抖动踩出崖沿(Supplementary Fig.11)。supported。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:接触阶段**可预先定义**(启发式设计)或能接入高层接触规划器的任务;有动捕等外部传感提供目标表示与接触切换确认;在仿真大规模 PPO 训练 + 配套域随机化课程后迁真机。
- **依赖**:阶段切换需要**显式接触反馈**(接触传感器或人工观察)才能推进——这是当前框架的硬依赖。
- **跨本体**:框架不绑定人形,已在 22-DoF 恐龙机器人上验证(§4.5),作者据此主张"通用性";但这仍是单一额外本体的定性展示。
- **不直接适用/需额外处理**:接触序列长度**先验未知**时,需启发式奖励 clamping 防止机器人钻 stage count reward 的空子(§6,作者自述)。

## 核心贡献
1. 提出 WoCoCo:面向序列接触计划的通用 RL 全身人形控制框架,基于接触阶段做自然任务分解(§贡献1)。
2. 一套任务无关奖励设计(稠密接触 + 阶段计数 + hash-count 好奇心)+ 三阶段 sim-to-real 课程,使每个任务只需 1–2 个直觉任务奖励即可端到端学成(§3、§4)。
3. 真机验证四个挑战性人形任务,作者称"据我们所知,这是每个任务首次由单一端到端 RL 策略解决"(原文 "the first instances of each task being solved by a single end-to-end RL policy")(§贡献3)。strong——作者明确强主张,但属"首次"性质的主张,非对比性能优越。

## 局限与我的质疑
1. **作者自述**:控制器**不知何时会失败**(model-based 能显式判断可行性);接触序列靠启发式预定义;阶段切换需显式接触反馈;目前用动捕做原型、未上机载感知(§6)。这意味着真实自主部署还有距离。
2. **几乎全是定性真机展示,缺少定量对比基线**。论文没有给出与强 model-based 控制器(如它反复提到的 Crocoddyl)在同一任务上的成功率/精度/能耗对比;消融只在仿真里对比"自己 vs 去掉某项",证明的是"各奖励项有用",**不能**支撑"WoCoCo 比 model-based 更好"这类结论。读者切勿把它读成"RL 全面胜过 model-based"。
3. **泛化主张偏弱**:真机跑酷只测了 1–2 次连续跳(场地受限),"versatile/continuous"更多在仿真成立;跨本体只有恐龙一个例子。把"通用框架"理解为"已在多本体多任务定量验证"会过度解读。
4. **每个任务的奖励权重量级差异巨大**(如 w_curi 从 5000 到 40000,Appendix E),说明所谓"任务无关 + 只需 1–2 个直觉项"在落地时仍需可观的逐任务标定,简洁性被部分稀释。
5. **奖励设计偏工程化、缺理论保证**:稠密接触奖励里 `2n_con²F_con F_task` 的系数、阶段计数刷分的防作弊条件都靠经验设计;论文坦言序列长度未知时需手动 clamping,说明 stage count reward 存在被策略利用的结构性风险,未给通用解。
6. **与本研究主题(RL 训练具身全身控制 / 数字人交互)对照**:它强在"无运动先验、序列接触、真机落地",但**不涉及人机交互意图、语义目标或从人类示范学习**;接触目标由人工/启发式给定而非从交互中推断,若主题关心"以人为中心的交互生成",本文只提供底层控制能力,不提供交互层。
