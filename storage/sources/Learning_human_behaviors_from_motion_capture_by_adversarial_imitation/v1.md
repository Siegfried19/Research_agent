# Learning human behaviors from motion capture by adversarial imitation
> Josh Merel, Yuval Tassa, Dhruva Tb, Sriram Srinivasan, Jay Lemmon, Ziyu Wang, Greg Wayne, Nicolas Heess · 2017 · arXiv (Cornell University) · 引用 155 · DOI 10.48550/arxiv.1707.02201

## 一句话
用扩展版的对抗模仿学习（GAIL），从少量、含噪、动力学不一致的人类动捕数据中训练出拟人的 humanoid 低层技能控制器（无需动作标签、只需部分状态特征、且 demonstrator 与 imitator 身体可不同），再让一个高层控制器通过 RL 复用这些技能去解任务。

## 解决了什么问题
- 纯 RL 训练 humanoid 控制器虽可行，但产出的动作"不够拟人、过度刻板"（"non-humanlike and overly stereotyped"），要变自然需大量奖励工程/身体设计/相位变量等领域专家工作。
- 动画领域用动捕做模仿能产出好看动作，但已有方法各有硬伤：有的是纯运动学序列模型（可能违反物理约束）、有的只做特定轨迹的 tracking 控制器、有的需重度手工设计代价函数或受限的身体-环境参数化。
- 作者想要一条**通用、少领域工程**的流水线：从"很小量、含噪"的人类动捕里提取**可复用、可精炼、可灵活串接**的拟人技能。

## 用什么方法解决的（含直觉：为什么 work）
- 核心是 GAIL（Ho & Ermon 2016）：判别器 D 区分"专家 state(-action)"与"策略产生的 state(-action)"，策略 π 因"骗过判别器"获得奖励，从而隐式匹配专家的状态占用分布（state-occupancy distribution），**无需手工定义"相似性"度量**。这是相对纯 RL 奖励工程的关键好处。
- 本文对 GAIL 做三处扩展，使其能真正"从人类动捕学"（作者称 "real-to-sim"）：
  1. **判别器只看状态/状态特征、不看动作**（partial features, no actions）。直觉：对完全驱动的确定性系统，相邻两状态之间存在唯一的逆动作映射，动作可由状态变化推断；更一般地，身体与环境的约束让合理动作可被推断。而且当两身体不匹配时，硬塞动作信息反而有害（同一动作在不同身体上产生的物理效果不同）。
  2. **demonstrator 与 imitator 身体结构/物理参数可不同**（cross-body re-targeting），只要所观察的特征对身体差异足够不变。直觉：人对海豚招手、看到海豚用鳍"回招"也满意——关键是行为在某个不变特征空间里对应，而非关节逐一对齐。
  3. **给判别器一个 context 标签 c（每行为一个 context）以同时训练多个行为**，由此能学到单一低层控制器在多行为间**平滑切换**。直觉：单独训练的单技能策略在切换瞬间会落到彼此状态分布之外而崩，而多行为联合对抗训练会自发找到行为间的高效过渡。
- 算法（Algorithm 1）：策略是高斯策略（每个 actuator 输出均值与 log-std），用 **TRPO** 更新（鲁棒、超参少，省下的超参预算可投到 GAN 相关超参上）；每轮交替"收集 rollout→按 D 给的奖励更新 π→用专家+生成数据更新 D（M 步）"。
  - 判别器损失：`ℓ(φ) = Σ_{t=1..T^g} log(1 − D_φ(z^g_t, c^g_t)) − Σ_{t=1..T^d} log(D_φ(z^d_t, c^d_t))`（z 为状态特征，可不含动作）。
  - 奖励：`r_t = −log(1 − D_φ(z^g_t, c^g_t))`。作者特别指出，与 GAN 训练常规做法相反，用 `−log(1−D(·))` 作奖励**比** `log(D(·))` **更好用**（observed）。
- 分层复用：先把技能训成低层控制器（LLC），其输入是 proprioceptive 观测（可选 context）；再训高层控制器（HLC），用 RL 输出"调制信号/context"去驱动已训练好的 LLC 解新任务（见 Figure 1、Figure 2）。
- 一个关键工程经验（humanoid）：必须**去掉所有非自我中心（non-egocentric）特征**，改喂内置 MuJoCo 传感器式的**间接 egocentric 测量**——velocimeter（根坐标系下的速度）、gyroscope（自我中心角速度）、accelerometer（指示直立程度），以及从根(骨盆)到双脚/双手/头的自定义 3D end-effector 向量（见 Figure 5 左）。直觉：动捕含噪且对 imitator 身体动力学不一致，让判别器逐关节角比较会因"从躯干到手的关节角误差累积"而过约束、把手臂逼出不自然的抖动；换成对身体差异近乎不变的间接特征后，模仿质量"显著改善"（observed）。

## 动机 & 背景
- 远景目标："构造一套鲁棒流程，产出适合复用与精炼的拟人动作"，以便在新任务中灵活组合（"the goal of this paper"）。
- 纯 RL 路线的弊端：动作不拟人、刻板；要改善得靠肌肉建模、相位变量、奖励工程等大量领域知识，且每个新行为都要重来。
- 动捕路线（动画界常用）的弊端：运动学模型可能违反物理；tracking 控制器只针对特定轨迹；或需重度工程化的代价函数/身体-环境参数化。
- GAIL 是切入点：把模仿变成类 GAN 的对抗博弈，不必显式手工设计相似度度量。但 GAIL 原始设定是"同身体、同模拟器、同策略架构、有完整 state-action"的最有利情形——本文要把它推到更难的真实动捕设定。

## 方法细节
- 物理引擎：MuJoCo。研究用四种身体：①平面内只能横向运动的 bipedal walker；②two-link 平面臂；③three-link 平面臂；④自定义复杂 humanoid（**56 个关节角 DOF + 6 DOF 自由根关节；56 个被驱动维度**，作者强调比同期 RL humanoid 工作[6,7]的 21 维多一倍多）。根关节自由平移旋转、不被驱动；其余关节力矩驱动，策略输出力矩。
- 动捕数据：CMU Graphics Lab Motion Capture Database。humanoid 身体由 CMU subject 8 程序化生成（ASF 取段长，其余比例/驱动强度设为"合理值"）。作者明说："我们造的身体与产生动捕的真人身体之间几乎肯定只有有限相似度"。
- 预处理极少：跨 subject re-targeting（把一个人的关节角映射到另一身体），数据"动力学不一致、有明显物理违例（穿插/漂浮）"，因此方法必须对此鲁棒；用 CMU 整段 clip、不做额外切分。从 AMC 文件 120Hz 样条插值重采样到 30ms 步长，设静态关节角姿态、记录由身体状态算出的特征作为观测（见附录 A）。
- 训练细节（附录 B）：TRPO 时对输入和奖励做在线 z-filtering；模仿时不 filter 奖励但裁剪（max=10）；优势按迭代归一化；动作 σ（log-sigma 参数化）初值约在 e^{-1}≈.37 到 1 之间。humanoid 控制步长 30ms、仿真步长 5ms，动作被界在 [-1,1]，各关节力矩有不同增益（腿高增益、脚趾小增益）。

## 数据集 & 实验设置
- 验证实验（用简单身体，先用 RL+手工奖励训出 demonstrator，再 logging 出 demonstration 给模仿）：
  - **Walker**：10s episode，躯干低于阈值则早停；奖励 ∝ |水平速度 − 目标速度(5m/s)| 取负，减小控制代价。比较 RL baseline vs 模仿（"S&A"含动作 / "S"仅状态）。30,000 samples/iter，100 条 demonstration episodes；判别器超参做小扫（lr∈[1e-5,1e-4,1e-3]，D更新数∈[1,5,10,20]）；策略 2 隐层(200,100) tanh。
  - **Arms**：4s episode，目标位置每秒变；奖励 ∝ end-effector 到目标中心的平方距离取负，减小控制代价。考察 two-link 模仿 two-link（全观测 vs 仅看 end-effector→目标向量），以及 **three-link 模仿 two-link**（判别器只看"end-effector→目标"位移向量这一近乎身体无关的特征）。20,000 samples/iter，100 demos。
- humanoid 动捕行为（附录表 "Motion capture clips"）：simple walk（subj 8, clips 1-11）、get up（subj 77 与 140 两人数据合并）、drunk（subj 137 clip 16）、chicken（subj 137 clip 8）、running and turning（subj 16, clips 45-56 等）。humanoid 实验 100,000 samples/iter，模仿最多跑到 3000 iter（保守上限，常更早就视觉收敛）；策略 3 隐层(300,200,100) tanh；走路模仿时身体跌倒早停。
- 多行为 context 控制：单一 LLC 同时学"直跑/左偏/右偏"三 context（共 286 帧重采样数据，<10s），训练时 context 每 5s 随机切；运行时可由键盘或 HLC 调制。
- 高层任务（Figure 6）：①半场足球用键盘控制进球；②已训练 running 策略在楼梯赛道上用 RL（前向速度奖励）微调以上下两段离散坡度的台阶；③HLC 调制可跑可转的 LLC 沿赛道前进；④用两层 MLP 作 HLC，吃局部俯视深度相机（看到前方约两堵墙）输出 context，做自主导航避墙，奖励为沿 3D 直线赛道前进；墙导航用近似 TRPO（即 PPO）以便并行（附录 B）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **判别器无需动作即可成功模仿**：walker 中"仅状态(S)"与"状态+动作(S&A)"训练出的模仿策略，按原任务目标衡量表现相当，且都接近 RL baseline；加动作信息"对训练模仿策略没有好处"（supported，Figure 3 左，5 seed 平均）。
- **跨身体 re-targeting 可行**：two-link 用全观测或仅 end-effector 向量都能大致等好地模仿另一 two-link；**three-link 也能模仿 two-link**，只要判别器只看"end-effector→目标"这一近身体无关特征（observed，Figure 3 右）。机制：imitator 学会让该不变特征的统计量匹配 demonstration。
- **仅靠动捕初始化 episode 就显著改变 RL 步态自然度**：把 RL"向前跑"的 episode 初始姿态改为从动捕姿态随机采样，相比随机初始姿态，步态明显更自然（虽仍不完全拟人）；作者称此效应"戏剧性且可靠"（observed，Figure 4）。
- **humanoid 从动捕学到拟人行走与起身**：用 egocentric 间接特征后，模仿行走质量"显著改善"（Figure 5 右上）；起身行为可从多种起始姿态较鲁棒地站起（observed，Figure 5 右下）——但作者明说"并非所有 seed 都能起身后保持站立"（有的循环"起身→倒下"）。
- **从单条 clip 学风格化步态**：醉酒、鸡步等非常规步态可从单条 clip（约 10s、不同身体的人）学出"中等鲁棒"的策略捕捉其神韵（observed）；但作者坦言"单条 clip 的模仿并非每条都成功、也不产出完美行为"。
- **多技能切换与分层复用**：单一 context-conditioned LLC 能在直跑/左右偏间切换并支持键盘或 HLC 调制；可在足球、上下楼梯（RL 微调，无微调则在台阶上很快摔倒）、深度相机自主避墙导航等高层任务中复用（observed，Figure 6）。
- 总体结论方向：对抗模仿在"无动作、部分观测、跨身体、含噪动捕"这些不利条件下**确实能 work**，并能产出可分层复用的拟人技能——这是相对纯 RL 与传统动捕方法"更少假设、更少结构、更少奖励工程"的路线验证。

## 适用边界（什么时候管用 / 什么时候不管用）
- 管用：当存在对身体差异足够不变的特征空间（egocentric 速度/姿态/end-effector 向量）时，跨身体、无动作的对抗模仿能成立；用 TRPO 提供鲁棒优化、把超参预算让给 GAN 侧时训练较稳。
- 关键依赖特征工程：humanoid 上必须去掉非 egocentric 特征、改喂间接 egocentric 测量；直接逐关节角比较会因动捕噪声/动力学不一致而失败（"naive application ... did not work well"）——所以"少领域工程"是相对的，**特征选择仍是成败关键**。
- 偏弱处：单条 clip 学风格不稳定、并非每条 clip 都成；起身后不一定能保持站立；楼梯等新地形需 RL 微调而非零样本迁移。
- 比较基线偏弱/偏间接：walker/arms 的"性能"是用**当初训练 demonstrator 的 RL 任务目标**来间接衡量模仿质量（因为缺乏拟人度的客观度量）；humanoid 的拟人性主要靠视觉/视频判断，无定量拟人度指标。
- 数据规模有限：很多行为只用了极少数据（如多 context 控制 <10s、走路 <30s 人类数据），是"小数据"验证而非大规模行为库。

## 核心贡献
- 把 GAIL 扩展到三种更难设定并实证可行：**判别器无动作 + 部分/特征观测**、**demonstrator 与 imitator 身体/物理参数不匹配的跨身体 re-targeting**、**用 per-behavior context 同时学多行为并自发产生行为间鲁棒过渡**。
- 提出一条从含噪人类动捕到可复用拟人 humanoid 技能的完整流水线，且强调"很小数据量 + 不多领域工程"。
- 给出分层架构：对抗模仿训练的 LLC 技能 + RL 训练的 HLC 调制复用，在足球/楼梯/深度相机导航等任务上演示复用。
- 实用经验：奖励用 `−log(1−D)` 优于 `log(D)`；humanoid 必须用 egocentric 间接特征；动捕姿态做 episode 初始化即可显著提升 RL 步态自然度。

## 局限与我的质疑
1. **缺乏客观评估指标（作者自述）**：拟人度/行为质量基本靠人眼与视频判断，量化处又是借"原 RL 任务目标"间接衡量。这使"是否真的更拟人""收敛与否"都难以严谨断言（作者在 Discussion 把这与"评估 GAN 样本质量"的难处类比）。我据此认为论文的多数正面结论应停在 observed 级别，不宜读成定量优越。
2. **seed/成功率不稳**：起身后保持站立"并非所有 seed 成功"、单条 clip 风格学习"并非每条都成"。论文展示的是"能 work 的样例"，缺成功率/失败模式的系统统计，存在挑样例(cherry-pick)展示的风险。
3. **"少领域工程"被特征工程部分抵消**：humanoid 成败高度依赖人工挑选的 egocentric 间接特征集（velocimeter/gyro/accel/end-effector 向量）。这等于把一部分"奖励工程"挪成了"特征工程"，论文对这套特征的必要性只给了定性论证，没有系统消融说明每个特征各自贡献多少。
4. **跨身体不变性的理论依据偏直觉**：声称"动作可由状态推断、特征对身体差异不变"主要靠完全驱动/确定性的逆映射直觉与"对海豚招手"类比，缺乏对何种特征/何种身体差异下不变性成立或失效的边界刻画；three-link 模仿 two-link 也只是单一近不变特征下的演示。
5. **复用/泛化有限（作者自述）**："目前只在相对受限、虽多样但有限的行为集上演示了有限复用"。楼梯需 RL 微调、未展示零样本跨任务迁移，距"通用可复用技能库"仍远。
6. **相对本研究主题（agentic 知识合成 / 通用工具复用）的不足**：本文是低层运动控制+分层复用的经典工作，其"技能即可复用模块、由高层控制器组合"的思想可类比，但它依赖物理仿真特定特征与对抗训练，方法不直接迁移到知识/语言层面的 agent 工具复用；且其"高层控制器"非常浅（多为 2 层 MLP），谈不上复杂规划或知识合成。
