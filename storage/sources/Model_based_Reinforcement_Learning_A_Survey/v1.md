# Model-based Reinforcement Learning: A Survey
> Thomas M. Moerland, Joost Broekens, Aske Plaat, Catholijn M. Jonker · 2023 · Foundations and Trends® in Machine Learning · 引用 481 · DOI 10.1561/2200000086

## 一句话
这是一篇把"规划(planning)"与"学习(learning)"两大序列决策范式统一到 model-based RL 框架下的概念性综述,核心贡献是一套**分类法/taxonomy**:把"如何学动力学模型"和"如何整合规划与学习"拆成若干正交维度逐一梳理。

## 解决了什么问题
- 截至本文写作,model-based RL 虽成果丰硕(AlphaGo/AlphaZero、PILCO、Guided Policy Search 等)但**缺一份系统性综述**——作者明确指出"literature lacks a systematic review of the field"(§1)。
- 已有相关综述(如 Hester & Stone 2012、Hamrick 2019、Plaat et al. 2020)各有侧重,本文自陈差异:更广覆盖**神经网络近似下的模型学习**、更强调**规划与学习的整合维度**(§9 Related Work)。
- 本文的目标不是提出新算法或跑新实验,而是**提供共同语言 + 结构化文献地图 + 指出未来方向**(§11 自述三点贡献)。

## 用什么方法解决的（含直觉：为什么 work）
- 全文围绕一张总图(Figure 1.1)展开:把"模型 Model / 规划 Planning / 策略或价值 Policy-Value / 真实环境 Data"四个盒子之间的连接拆成 a–g 七条箭头,**每条箭头代表规划与学习的一种可能耦合方式**,大多数算法只实现其中一个子集。直觉:与其逐个介绍算法,不如把算法空间拆成可组合的设计选择,这样新算法都能落到坐标系里。
- **定义层面的拆解**(§3):作者用两个轴区分 planning vs RL——(1)对环境动力学是否有"可逆访问 reversible access"(能从同一状态反复前推=有 model),(2)解是"局部 local"还是"全局 global"。由此给出定义:"A model is a form of reversible access to the MDP dynamics (known or learned)";"Planning = 用 model + 存局部解";"RL = 存全局解";**"Model-based RL = 用 model + 存全局解"**(Table 3.1)。直觉:AlphaZero 既有可逆模型又学全局价值/策略,正好落在交集,所以它是 model-based RL。
- 进一步把"planning-learning 整合"分三类(Table 3.2):①学到的模型(如 Dyna)②已知模型(如 AlphaZero、动态规划)③只在学到的模型上局部规划、不学全局解(如 Embed2Control,严格说不算 model-based RL 但仍属整合)。
- 全篇主体是**两步法**:第一步"如何学动力学模型"(§4),第二步"如何整合规划与学习"(§5);再补充"隐式 model-based RL"(§6,把整个流程包成一个端到端可微图直接优化最终价值/动作)和"收益"(§7)。

## 动机 & 背景
- 序列决策常形式化为 MDP $\{\mathcal S,\mathcal A,\mathcal T,\mathcal R,p(s_0),\gamma\}$(§2)。给出动作价值与 Bellman 方程:$Q^\pi(s,a)=\mathbb E_{s'\sim\mathcal T}[\mathcal R(s,a,s')+\gamma\,\mathbb E_{a'\sim\pi}[Q^\pi(s',a')]]$,目标 $\pi^\star=\arg\max_\pi Q^\pi$(式 2.2–2.3)。
- 作者把 model-based RL 视为序列决策的**基础范式**,并指出它与分层 RL(高层动作空间=带时间抽象的模型)、迁移学习(跨任务迁移模型)、定向探索等子领域天然相连(§1)。

## 方法细节

### 一、动力学模型学习的挑战谱系(§4)
作者把模型学习当成监督学习问题,逐项拆解(读者可按需跳读):
- **模型类型**(§4.1):前向模型 $(s_t,a_t)\to s_{t+1}$(最常用,供前瞻规划)、反向模型 $s_{t+1}\to(s_t,a_t)$(用于 prioritized sweeping)、逆模型 $(s_t,s_{t+1})\to a_t$(用于表示学习)。
- **估计方法**:参数 vs 非参数;精确(表格/tabular,如最大似然计数 $T(s'|s,a)=n(s,a,s')/\sum_{s'}n(s,a,s')$,式 4.1)vs 近似(线性回归、DBN、GP、神经网络)。表格法因维度灾难不可扩展,神经网络在高维最受欢迎。
- **有效区域**:全局 vs 局部(控制界常拟合当前状态附近的局部线性模型,规划后丢弃)。
- **随机性 stochasticity**(§4.2):若真实转移是分布,用 MSE 训练确定性网络只会学到**条件均值**(Figure 4.2 给了多峰分布的反例),所以需生成式模型(VI、GAN、自回归、flow 等),作者说"哪种深度生成建模最好尚无共识"。
- **不确定性 uncertainty**(§4.3):区分**认知不确定性 epistemic**(数据有限,可减)与**偶然不确定性 aleatoric=随机性**(不可减)。前者关键,用 frequentist(bootstrap,如 PETS)或 Bayesian(GP、变分 dropout)估计。直觉:规划前要知道哪儿预测不可信(Figure 4.3 用 GP 3 次 vs 10 次观测对比外推可信度)。
- **部分可观 partial observability**(§4.4):四类应对——windowing(拼接最近 n 帧)、belief states(观测模型 $p(o|s)$+隐转移)、recurrence(RNN/LSTM,最流行)、external memory(NTM)。
- **非平稳 non-stationarity**(§4.5):partial models(平稳模型集成+检测切换)或简单地强衰减旧数据(类似高学习率,但可能不稳)。
- **多步预测**(§4.6):单步模型反复自喂会累积误差发散;两条路——把多步损失加进训练目标(unroll n 步训练),或为每个 n 步专门学一个 $T^n$。作者提醒:若最终目标是多步规划,**单步预测误差未必是好的模型性能度量**。
- **状态抽象 state abstraction**(§4.7):神经网络常分三件套——编码 $z_t=f^{\text{enc}}_\phi(s_t)$、隐动力学 $z_{t+1}=f^{\text{trans}}_\phi(z_t,a_t)$、解码 $s_{t+1}=f^{\text{dec}}_\phi(z_{t+1})$(类自编码器+隐动力学,Figure 4.1 箭头4)。要在隐空间规划须保证"预测的下一隐状态落在编码空间里",否则反复自喂会漂移(加一致性损失,如 Embed2Control)。还讨论了 grey-box(物理引擎已知+只学编码)、object-oriented(图神经网络建模物体交互,更易泛化新环境)、更好的损失(辅助损失、对比损失、预测可控因素的逆动力学损失)、value-equivalent models。
- **时间抽象 temporal abstraction**(§4.8):options 框架(每 option 有起始集 $I^u$、子策略 $\pi^u$、终止概率 $\beta^u(s)$)vs goal-conditioned value functions/GCVF(学 $Q(s,a,g)$,可链接多子目标)。子目标发现的几条路:bottleneck 状态、状态空间覆盖、信息论压缩(如 empowerment)、reward relevancy(端到端,如 Option-Critic/Feudal Networks)、先验知识。

### 二、规划与学习的整合(§5):四问 taxonomy
作者把整合拆成四个问题(Table 5.1 汇总维度):
1. **从哪个状态起规划?**(§5.1)uniform(动态规划,扫全状态,维度灾难)/ visited(Dyna)/ prioritized(prioritized sweeping)/ current(MPC、AlphaGo Zero)。
2. **预算多少?**(§5.2)两层:多少真实步后才规划(Dyna 每步后规划~100 次;PILCO 整集后重规划;batch RL 只给一批数据)、每次规划花多少。文中给的对照量级:**Dyna 每个规划周期~100 次模型调用,AlphaGo Zero 单次 MCTS 1600 traces×深~200 ≈ 320,000 次**(§5.2,作为"squeezing/挤干信息"光谱两端的示例,非性能结论)。人类做的是**自适应权衡**(何时规划、规划多久),少数工作模仿之(Pascanu 加规划代价惩罚、Hamrick 学元控制器、按 Q 方差定比例)。
3. **怎么规划?**(§5.3)Type:离散规划(MCTS、minimax、一步搜索,不需可微)vs 微分规划(value gradients,要求模型可微,如 PILCO 穿 GP 求导、Dreamer 穿隐神经网络);Direction:前向(默认)vs 反向(prioritized sweeping);Breadth/Depth:1↔自适应↔full(Figure 5.1 把各种 back-up 放进 breadth×depth 平面,MCTS 居中自适应,DP 是 full-breadth-depth-1,trace/rollout 是 breadth-1-depth-full);Uncertainty:data-close(留在见过的数据附近,如 Dyna/GPS)vs uncertainty propagation(解析传播如 PILCO / 粒子法如 Deep PILCO、PETS;STEVE 按不确定性给不同深度的价值目标加权)。
4. **怎么把规划嵌进学习-行动环?**(§5.4)输入:用学到的价值(bootstrapping 截断搜索深度)或策略(AlphaGo Zero 用策略概率当 UCB 先验)指导新一轮规划;输出→训练目标:用搜索根节点的价值/访问计数训价值网(MSE)或策略网(交叉熵);输出→选动作:贪心选(MPC/receding horizon,迭代 iLQR 等),或加探索噪声"plan to explore"。作者点明箭头 b(策略/价值→规划)与 c(规划→策略/价值)构成闭合子环,AlphaGo Zero 即此类(被称作 multi-step approximate real-time dynamic programming, MSA-RTDP)。

### 三、隐式 model-based RL(§6)
直觉:既然最终只关心"输出(最优)价值或动作",不如把模型学习+规划+整合**整个包进一张端到端可微计算图**,直接对最终目标(RL loss 或 imitation loss)优化,让"模型"自动只保留与价值相关的部分。三类(Figure 6.1):
- **value-equivalent models**(§6.1):模型在图里被展开去预测未来**价值/动作**而非未来状态——代表 MuZero(学 value-equivalent 模型再 MCTS)、VPN、Predictron;若图里含策略改进(规划)则有 Value Iteration Networks、UPN。
- **learning to plan**(§6.2):连**规划操作本身**也学(algorithmic function approximation,内部多轮迭代提升预测质量)——代表 MCTSNets、I2A、IBP。
- **full implicit MBRL**(§6.3):模型与规划联合优化——代表 TreeQN、DRC(高容量 RNN,无任何 MDP 专属结构,"model-free planning",测试时算力越多性能越高)。

## 数据集 & 实验设置
- 本文是**综述,不含作者自己的实验/数据集**;所有数字都来自被综述的工作,作为示例而非本文结论。可提取的量级示例:PILCO 在真实 Cartpole 上"少于 20 秒经验"求解(§7.1);PETS 扩到 7-DOF 动作空间、MBPO 扩到 22-DOF 仿真人形;Embed2Control 在 51×51 像素 Pendulum swing-up 上 15 次试验(每次 1000 帧)后~90% 成功率;Dyna 类在 gridworld 上报数据效率提升~20–40×、高维函数近似下约 2–5×(§7.1)。这些**均为转述他人结果,非本文测得**。

## 主要结果 & 结论（写方向，不堆精确数字）
> 本文是综述,"结果"多为对文献的**归纳性论断**,以下按强度标注。

- model-based RL 的**数据效率**潜力强:用规划(增加模型样本复杂度)换取真实环境样本复杂度的降低,这是该范式核心动机 [supported]——但作者明确说"强提升已被展示,但并不普遍(not numerous)",疑因高维下缺稳定的不确定性估计、或需大量调参 [observed]。
- **已知模型**(如 AlphaGo Zero)下,model-based RL 经显式前瞻**能在长期(渐近)经验性能上超过 model-free**;MuZero 用 value-equivalent 学到的模型进一步超过 AlphaZero,提示"好模型下 model-based RL 可达更好渐近性能" [observed,作者措辞为 "suggests"]。
- **学到的模型**下,通行认知是:数据效率↑但**渐近性能往往不如 model-free**(因模型的不确定性/近似误差带来不稳定) [supported,作者将其作为常识陈述并列为公开难题]。
- 一个被作者强调的**机制性解释**(为什么 work):全局函数近似(学习)提供泛化但必有局部误差;**局部规划(常用表格/精确表示)在价值预测更可区分的状态上前瞻,能局部"抹平"函数近似误差**,从而更稳、渐近更好——类比认知科学的"快思考(全局策略/价值)/慢思考(局部规划)"双过程理论 [observed,作者称 "we may hypothesize",属假说]。Moerland 2020a、Wang 2019 初步发现:最优性能出现在**中等规划预算**,而非"无规划(model-free)"或"穷举搜索"两端 [observed]。
- **探索**:model-based RL 支持"两阶段探索"(规划周期内用激进探索 + 真实步用保守)与"基于状态的内在动机"(novelty/不确定性等,不依赖奖励),天然适合**深度探索 deep exploration**(对未来探索目标承诺一串动作),优于 ε-greedy 的"抖动" [supported,概念论证]。知识型 IM 用总奖励 $r_t=r^e+\eta\cdot r^i$(式 7.1),典型内在奖励如 BEB 的 $r^i\propto 1/(1+n(s,a))$(式 7.2)、recency $r^i=\sqrt{l(s,a)}$(式 7.3)。
- **迁移**:同动力学换奖励(多目标 RL、successor representation)与微变动力学(sim-to-real、object/physics 表示更易泛化)是 model-based RL 的主要卖点之一 [supported,综述性论断]。
- **理论**:model-based RL 普遍能给出比 model-free **更好的 PAC/regret 界**,但代价是更差的时空复杂度(需估计并存储转移函数) [supported]。有意思的反例:Efroni 2019b 证明**一步贪心规划(如 Dyna)就能匹配 UCRL2/EULER 的 regret 界**,同时降低时空复杂度 [supported,作者明示为 "show"]。

## 适用边界（什么时候管用 / 什么时候不管用）
- **微分/梯度规划**:在动力学与奖励**平滑**的连续控制/机器人任务很有效(可穿模型求 value gradient);对**离散问题、稀疏奖励不适用**(§5.3 作者明确)。
- **离散规划(MCTS 等)**:适合离散、大分支的博弈类(Go/Chess/Shogi),不需模型可微。
- **表格/精确模型**:仅适合小型或可离散化 MDP;高维下因维度灾难失效,须换函数近似。
- **prioritized sweeping(反向规划)**:在**表格、模型易求逆**时收益大;配函数近似可能不稳(§5.3、§10)。
- **squeezing 类高数据效率法(如 PILCO 的 Bayes-adaptive 探索)**:理论上真实样本复杂度最优,但**计算昂贵、依赖正确贝叶斯推断,难直接上高维**(§7.1)。
- **强随机环境**:必须用生成式/分布式模型,确定性 MSE 模型会塌成条件均值而误导规划(§4.2)。
- **基线对照提醒**:文中 AlphaGo Zero/MuZero 超过的是**强 model-free 基线**(同领域 SOTA);而很多"学到的模型"工作只在低维或与中等基线比,作者反复强调高维下普遍提升"并不多见"——读者勿把个别强结果泛化为"model-based 普遍更强"。

## 核心贡献
- 给出 planning / RL / model-based RL 的**可操作定义**(可逆访问×局部/全局解两轴,Table 3.1),澄清了为何 AlphaZero 算 model-based RL。
- 提出**模型学习挑战谱系**(随机性/不确定性/部分可观/非平稳/多步/状态抽象/时间抽象)与**整合四问 taxonomy**(起点/预算/怎么规划/怎么嵌环,Table 5.1),并用 Table 5.2 把 Dyna、Prioritized Sweeping、PILCO、GPS、AlphaGo Zero、Embed2Control、PETS 等放进同一坐标系对比。
- 系统引入并分类**隐式(端到端可微)model-based RL**(value-equivalent / learning-to-plan / full implicit,Table 6.1),把 MuZero、VIN、MCTSNet、TreeQN、DRC 等纳入统一视角。
- 梳理 model-based RL 的**六类收益**(数据效率、探索、最优性/渐近性能、迁移、安全、可解释)+ disbenefits(额外计算、学到模型的不稳定、更多超参),并简述**收敛理论**(PAC/regret,Table 8.1)。

## 局限与我的质疑
1. **几乎无定量比较,结论多为定性归纳**。作者自己也承认"很难判断哪种整合更好,因为各算法在不同任务上评测"(§5.5),并把 benchmarking 列为公开难题(§10)。因此本文给的"谁优于谁"基本是方向性、需回原始论文核实;作为"构建工具箱的横向认知"很好,但**不能据此下选型结论**。
2. **时效性**:成文于 2019–2020 左右(2023 才在 FnT 正式刊出),引用止于 2019–2021。**Dreamer 系列、EfficientZero、offline RL、大规模 world models、Diffusion/Transformer 动力学模型等后续主流进展均未覆盖**——对当下"工具箱"而言这是明显缺口。
3. **"局部规划抹平全局近似误差→更好渐近性能"是作者的假说**(措辞 "we may hypothesize"/"suggests"),证据是少数初步工作(Moerland 2020a、Wang 2019、AlphaGo Zero/MuZero),**机制未被严格证明**;读者勿当成定论。
4. **与本研究主题(似偏 SAC/PPO 等 model-free 连续控制工具箱)契合度有限**:本文几乎不展开 SAC/PPO/TD3 等具体 model-free 算法,也不给实现细节/超参/伪代码——它是"地图册"而非"操作手册",回答"有哪些路线、各自直觉与取舍",但回答不了"某具体任务该用哪套、怎么调"。
5. **覆盖广但深度浅(作者自称 "shallow treatment")**:如 breadth/depth、不确定性传播等关键工程细节只点到为止;真要落地仍须读各专题原文。
6. **隐式 model-based RL 的代价被一笔带过**:文中承认其"计算图巨大、优化可能不稳、value-equivalent 模型只抓价值相关信息→难迁移"(§6 末),但对"何时值得用隐式 vs 显式"缺乏可操作判据,停在"人类先验 vs 黑盒优化"的哲学层面。
7. **理论与实践脱节**:§8 的 regret 界几乎都在**表格 MDP**下成立(含 $|\mathcal S|,|\mathcal A|$ 项),而全书主张的高维神经网络场景**无对应保证**;作者未充分提示这一鸿沟可能误导读者高估理论的适用范围。
