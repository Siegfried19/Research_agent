# Addressing Function Approximation Error in Actor-Critic Methods
> ["Scott Fujimoto", "Herke van Hoof", "David Meger"] · 2018 · UvA-DARE (University of Amsterdam) · 引用 414 · DOI title:7f327668611a45e6

## 一句话
本文指出 actor-critic 连续控制方法同样受函数逼近误差导致的**价值高估**与**方差累积**之害，提出 TD3（Twin Delayed DDPG），用「双 critic 取最小 + 延迟策略更新 + 目标策略平滑」三个简单改造在 DDPG 上系统性提升稳定性与性能。

## 解决了什么问题
- 离散动作 Q-learning 的高估偏差研究已久，但**连续控制 actor-critic 里同类问题此前基本没被处理**（原文："similar issues with actor-critic methods in continuous control domains have been largely left untouched"）。
- 高估偏差：对带噪声的价值估计取最大化会引入一致的正向偏差，并经 Bellman 方程在时序差分（TD）学习中**逐步累积**，使任意差状态可能被估成高值，导致次优甚至发散的策略。
- 即使估计无偏，**高方差**仍会在局部状态区域造成高估、并给策略更新提供噪声梯度，拖慢学习、损害性能。
- 作者还指出 actor-critic 里 actor 与 critic 互相强化的**反馈回路**：差的 critic 抬高次优动作 → 策略朝次优更新 → 又强化差的 critic。

## 用什么方法解决的（含直觉：为什么 work）
TD3 = DDPG + 三个改造，分别针对高估和方差：

**1. Clipped Double Q-learning（截断双 Q，治高估）**
- 维护两个 critic，目标值取两者最小：`y = r + γ · min_{i=1,2} Q_{θ'_i}(s', π(s'))`（式 10）。
- 直觉：一个高估的价值估计可当作真值的**近似上界**；取 min 偏向**低估**，而低估的动作不会在策略更新中被传播放大，故远比高估安全（原文："This favors underestimations, which do not tend to be propagated during learning"）。
- 为什么不用现成的 Double DQN：actor-critic 里策略变化慢，当前网络与目标网络**太相似**，无法给出独立估计，仍残留最大化偏差（图 2 显示 DDQN-AC 仍高估）。
- 一个**附带好处**（务必按原文理解）：把逼近误差看成随机变量时，"一组随机变量的期望最小值会随其方差增大而**降低**"，所以 min 操作会**偏好低方差的状态估计**，带来更安全的策略更新（原文："the expected minimum of a set of random variables decreases as the variance of the random variables increases ... a preference for states with low-variance value estimates"）。注意：原文**没有**主张 min 本身让方差随变量个数增加而减小。

**2. Delayed Policy Updates（延迟策略更新，治方差累积）**
- 每对 critic 更新 `d` 次才更新一次 actor 和目标网络（实验中 `d=2`），即**双时间尺度**。
- 直觉：先让价值估计在固定策略下把误差降下来、收敛得更好，再做策略更新，避免在不准的 critic 上反复更新策略放大误差（原文："delaying policy updates until the value error is as small as possible"）。

**3. Target Policy Smoothing（目标策略平滑，治确定性策略过拟合）**
- 目标动作加截断噪声：`y = r + γ Q_{θ'}(s', π_{φ'}(s') + ε)`，`ε ~ clip(N(0,σ), -c, c)`（式 14）。
- 直觉：确定性策略容易过拟合到价值估计的**窄尖峰**；对目标动作邻域的价值做平滑（拟合"目标动作周围一小片区域"的值），强制"相似动作应有相似价值"，是一种 SARSA 风格正则、形似 Expected SARSA。

## 动机 & 背景
- 基于确定性策略梯度（DPG/DDPG）：critic 学价值 `Q^π`，actor 沿 `∇_φ J = E[∇_a Q(s,a)|_{a=π(s)} ∇_φ π(s)]`（式 1）做梯度上升。
- 第 4.1 节给出**理论结果**：在基本假设下，用确定性策略梯度更新出的策略，其价值估计在期望上是**高估**的（式 5–7，证明近似策略的价值上界≥真策略价值）。
- 图 1 实证：在 Hopper-v1、Walker2d-v1 上，DDPG 的价值估计明显高于"真值"（用当前策略 1000 个 episode 的平均折扣回报估计真值），而本文方法 CDQ 的高估大幅缩小。

## 方法细节
- **截断双 Q 的实现简化**：理论形式用两套 actor-critic（`π_{φ1},π_{φ2}` 与 `Q_{θ1},Q_{θ2}`，φ1 对 Q_{θ1} 优化、φ2 对 Q_{θ2} 优化，式 9）；实现中可只用**单个 actor**（对 Q_{θ1} 优化），两个 critic 共用同一目标 `y`，省算力。
- **误差累积的刻画**（5.1 节）：函数逼近下 Bellman 方程永不精确满足，每次更新留残差 TD 误差 `δ`，`Q_θ(s,a)=r+γE[Q_θ(s',a')]-δ`（式 11）；展开后价值估计 ≈ 期望回报减去**未来 TD 误差的期望折扣和**（式 12）。故估计方差正比于未来回报与估计误差的方差，**大折扣 γ 会让误差快速放大**。
- **目标网络对方差的作用**（5.2 节，图 3）：图 3 在 Hopper-v1 上对比无目标网络（`τ=1`）与慢更新目标网络（`τ=0.1` 和 `τ=0.01`），各看固定策略与学习中策略两种情形。固定策略下各更新率收敛行为相似；**当策略随当前价值一起学习时，快更新（τ=1）导致价值高度发散**，慢更新目标网络则稳定。结论：发散源于"用高方差价值估计去更新策略"。
- **算法 1（TD3 伪代码）关键步骤**：从 replay buffer 采样 → 目标动作 `ã = clip(π_{φ'}(s')+ε, -c, c)` → `y = r + γ min_{i=1,2} Q_{θ'_i}(s', ã)` → 两 critic 都用 MSE 回归 `y` → 每 `d` 步才更新 actor（DPG）与目标网络（`θ'_i ← τθ_i+(1-τ)θ'_i`，`φ' ← τφ+(1-τ)φ'`）。
- 收敛性：作者称在**有限 MDP 设定**下给出收敛证明，细节在补充材料（原文："A proof of convergence in the finite MDP setting follows from this intuition"）。

## 数据集 & 实验设置
- 平台：OpenAI Gym 的 **MuJoCo 连续控制 7 个任务**（HalfCheetah/Hopper/Walker2d/Ant/Reacher/InvertedPendulum/InvertedDoublePendulum），环境与奖励不做任何修改。
- 对比对象：**DDPG、PPO、TRPO、ACKTR、SAC**，以及作者自己重调过的 DDPG（"our DDPG"，含架构/超参/探索改造但不含三个 trick，记 AHE）。
- 评测严谨性（针对复现性顾虑）：**10 个随机种子**，固定评测协议（每 5000 步评一次、报 10 个 episode 无探索噪声平均回报），开源代码（github.com/sfujim/TD3）。
- 关键超参：网络 400/300 隐节点 + ReLU、actor 输出 tanh；Adam，学习率 `1e-3`；batch 100；目标平滑噪声 `N(0,0.2)` 截断到 `(-0.5,0.5)`；`d=2`；**两个目标网络均用 `τ=0.005`**；探索用不相关高斯噪声 `N(0,0.1)`（实测 Ornstein-Uhlenbeck 无额外收益）；共跑 100 万步。

## 主要结果 & 结论（写方向，不堆精确数字）
- TD3 在所测 7 个任务上**最终性能与学习速度都达到或超过所有对比算法**，Table 1 中绝大多数任务 TD3 为最优（supported；10 种子 + 多基线）。原文："TD3 matches or outperforms all other algorithms in both final performance and learning speed across all tasks."
- 在多个任务上 TD3 相对 DDPG 的提升幅度很大（如 HalfCheetah、Ant 数量级方向上的提升，具体数值见 §6 Table 1）（supported）。
- 截断双 Q 把价值高估显著压下（图 1 中 CDQ 的估计远比 DDPG 贴近真值）（supported，但只在 Hopper/Walker2d 两个环境画了高估曲线 → 高估缩小这点是 observed→supported 的程度）。
- **消融**（6.2 节，Table 2）：三个组件贡献**因任务而异**；单独加某一个组件多数情况下提升不显著，**组合起来才明显更好**，完整 TD3 在多数任务上胜过各种部分组合（supported）。原文："the addition of only a single component causes insignificant improvement in most cases, the addition of combinations performs at a much higher level."
- 把 Double Q（DQ-AC）、Double DQN（DDQN-AC）也套上同样架构/超参做对比：它们对高估的抑制**弱于截断双 Q**，相对 TD3-CDQ 提升不显著（Ant 是例外，似乎特别受益于减小高估）（supported）。
- 延迟策略更新：在减少训练时间的同时普遍提升性能（observed/supported）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用场景**：连续动作、确定性策略的 actor-critic（DDPG 家族）+ off-policy + replay buffer 的标准设定；MuJoCo 类连续控制基准上验证充分。
- 改造**通用、易加**：作者强调三个 trick 实现简单，可加到任意 actor-critic 算法（原文："can be easily added to any other actor-critic algorithm"）——但这是设计主张，本文只在 DDPG 及 DQ-AC/DDQN-AC 上实证过（supported 仅限这些）。
- **未验证的边界**：离散动作、随机策略、稀疏奖励、真实机器人/真实环境、图像输入等均**未在本文测试**（`[原文未提]` 这些设定的结果）。
- 强基线对比：SAC 是当时强基线，但作者在脚注提到 SAC 复现结果存在**口径差异**（见补充材料），故与 SAC 的优劣比较需谨慎看待。

## 核心贡献
1. 证明并实证：**高估偏差也存在于 actor-critic 连续控制**，且离散 Q-learning 的现成解法（Double DQN）在此**失效**（slow-changing policy 使双网络不独立）。
2. 提出 **Clipped Double Q-learning**：取两 critic 最小作为目标，限制高估、且偏向不被传播的低估。
3. 把目标网络与误差累积联系起来，提出 **延迟策略更新**（双时间尺度）降低每步误差与方差。
4. 提出 **目标策略平滑**：SARSA 风格正则，对目标动作邻域价值做平滑，抑制确定性策略对窄尖峰的过拟合。
5. 三者合成 **TD3**，在 7 个 MuJoCo 任务上系统超越当时 SOTA，并以多种子 + 消融 + 开源强调可复现。

## 局限与我的质疑
1. **欠估计是被接受的代价、未量化**：截断双 Q 必然引入低估偏差，作者论证"低估优于高估"但**没有给低估幅度的界**；在奖励稀疏或真值本就低的区域，系统性低估是否压制了有潜力的动作，本文未深究（仅定性说"低估动作不被传播"）。
2. **三个 trick 捆绑、归因模糊**：消融显示单个组件多数情况下"提升不显著"，要靠组合才显著——这意味着性能增益的因果归属并不清晰，且组合带来了 `d`、`σ`、`c`、`τ` 等多个需调超参，增加调参负担。
3. **泛化被表述得偏强**："can be easily added to any other actor-critic algorithm"是设计主张而非证明；论文只在确定性策略连续控制上验证，对随机策略（如 SAC 路线）、离散动作并无实证支撑。
4. **高估曲线证据面窄**：直接展示高估被压低的只有图 1（Hopper、Walker2d）两个环境，把"显著降低高估"推广到全部任务属外推。
5. **收敛证明限于有限 MDP**：理论保证只在有限 MDP 设定（且在补充材料中），与真正使用的函数逼近 + 连续状态动作之间有鸿沟，理论与实践不完全对齐。
6. **与本研究主题（RL 训练可交互数字人 / RL 通用工具箱）的契合度**：TD3 是底层 off-policy 价值估计稳定性 trick，给"如何让连续控制更稳"提供了可直接复用的工程要点（双 critic 取 min、延迟更新、目标平滑），但它不涉及高层任务结构、人机交互或多目标，需配合上层方法使用。
