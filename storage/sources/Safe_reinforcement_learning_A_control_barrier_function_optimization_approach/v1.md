# Safe reinforcement learning: A control barrier function optimization approach
> Zahra Marvi, Bahare Kiumarsi · 2020 · International Journal of Robust and Nonlinear Control · 引用 229 · DOI 10.1002/rnc.5132

## 一句话
把控制屏障函数（CBF）作为一项「安全代价」直接加进最优控制的代价函数里，再用 off-policy 强化学习（actor-critic 神经网络）在不需要完整系统动力学的前提下学出一个既安全又最优的控制策略，并给出安全性、稳定性、最优性、收敛性的严格证明（连续时间，仿射控制系统）。

## 解决了什么问题
- 安全关键系统（如自动驾驶）既要保证状态永远停在安全集内，又要在此前提下最优化一个性能目标，而这两个目标常常冲突。
- 传统 CBF 安全控制需要系统模型的完整知识，且只把安全当成事后约束（违反时才介入），不考虑最优性，难以直接和 RL 结合（背景，见 §1、§2.2）。
- 目标：在**模型不完全已知**的条件下，设计一个把安全「主动规划进去」、与性能一起优化、并能迭代求解的控制器（§1）。

## 用什么方法解决的（含直觉：为什么 work）
- **核心做法**：把代价函数从 `r(x,u)=Q(x)+uᵀRu`（式3）改造成增广效用 `r_a(x,u)=Q(x)+uᵀR(x)u+B_γ(x)`（式11），其中 `B_γ(x)` 是一个 CBF 项；相应的最优控制问题变成最小化增广代价（式9）。
- **CBF 候选函数**：`B_γ(x) = -log( γh(x) / (γh(x)+1) )`（式10），其中 `h(x)≥0` 定义安全集 `𝒞={x|h(x)≥0}`（式4）。它满足：安全集内为正、在边界 `∂𝒞` 上趋于无穷、且单调递减（Assumption 1）。
- **直觉一（为什么安全）**：因为 `B_γ` 在安全边界处发散到无穷，而它被加进了代价函数里——任何让代价有界的策略都不可能让状态触到边界，于是「代价有界 ⇒ 安全」。论文正是用「序贯改进让增广值函数（从而 CBF）始终有界」来证明状态永不到达边界（Lemma 2 + Theorem 1）。
- **直觉二（前瞻 / 主动安全规划）**：传统 CBF 是先算最优控制器、只在快违反约束时才介入；这里把安全和性能放进同一个无限时域代价一起优化，因此控制器会**提前**朝远离危险的方向走，让状态在可行集内平滑过渡，减少与最优控制器的「打架」（Summary、§3.2、Remark 3）。
- **直觉三（阻尼系数 γ 调安全 vs 最优的相对权重）**：γ 决定 `B_γ` 离边界多远就快速衰减到零。γ 大 → CBF 衰减快、远离边界处几乎只剩原始性能项 `Q+uᵀRu`，更偏最优；γ 小 → 更强调安全、控制更保守（Remark 8）。例如 `h(x)=1, γ=5` 时 `B_γ≈0.08`（Remark 8 自举的数值示例）。
- **关键转折（不需要对 CBF 导数加约束）**：传统 CBF 要求满足导数不等式 `Ḃ≤α₃(h)`（式8），这需要轨迹信息 `ẋ`、从而需要完整动力学；本文把 CBF 放进代价后，靠「在边界附近 `B_γ` 成为代价主导项、最优控制器自动沿 `B_γ` 下降方向走」让 `Ḃ_γ` **隐式地**在边界附近变负，**无需显式施加导数约束**（Remark 3）——这是它能和无模型 RL 结合的关键。
- **off-policy RL 求解**：把动力学写成行为策略 `u` 与目标策略 `uⁱ` 分离的形式 `ẋ=f+g·uⁱ+g·(u-uⁱ)`（式32），导出 off-policy Bellman 方程（式35），策略更新律 `uⁱ⁺¹=-0.5R⁻¹gᵀJ_xⁱ`（式34）。
  - **直觉（为什么用 off-policy）**：行为策略可以是一个安全（甚至保守）的探索策略，被真正施加到系统上采数据；目标策略是「正在学的、可能还不安全」的策略，只在数据上评估、**不施加到真实系统**。把「学什么」和「拿什么去跑系统」分开，使得学习期间系统始终安全——这对安全关键系统至关重要（Remark 11、Remark 13）。
- **神经网络近似（actor-critic）**：critic 估值函数 `Ĵⁱ=ŴⁱΦ(x)`（式36），actor 估控制 `ûⁱ⁺¹=P̂ⁱΨ(x)`（式37），用最小二乘解 Bellman 近似误差（式38–43），可解条件 `N>l₁+ml₂`（式44）。整个学习过程**无模型**，只有行为策略需要部分动力学知识（Remark 13）。算法见 Algorithm 1（初始化网络 → 用初始带噪稳定策略采数据 → 反复用收集数据更新 Jⁱ、uⁱ⁺¹ 直到收敛）。

## 动机 & 背景
- 安全是底线但不是全部，还要在安全前提下用性能函数编码设计者意图做最优控制；且系统动力学常不确定、会变，因此想要学习型控制器（§1）。
- 综述了已有安全 RL 路线并指出局限（§1–§2）：风险度量/随机 cost-to-go（处理不确定但不处理状态/输入约束）；外部先验知识引导安全探索（需要事先知道哪里危险，对「危险信息事先不可得」的场景不构造）；可达性分析（优雅但计算量大、边界切换易抖振 chattering）；传统 CBF（需完整模型、不考虑最优性）；数据驱动 CBF（用高斯过程学扰动，但仍需名义模型）；MPC + 屏障函数（短视、不确定下难保稳定/可行）。
- 本文相对前作/同类的差异（§1 末三点）：①处理安全与性能的冲突、安全集**不必包含原点**；②用 off-policy RL，可在不施加于系统的情况下评估可能不安全的策略；③用一个「在离边界一定距离内快速阻尼到零」的函数当 CBF（而非 zeroing factor），把安全当成控制目标而不仅是约束，并用参数 γ 调安全与原目标的相对重要性。

## 方法细节
- **系统**：仿射非线性连续时间系统 `ẋ=f(x)+g(x)u`（式1），`f∈C¹, f(0)=0`，系统可镇定。
- **安全集**：`𝒞={x|h(x)≥0}`（式4），`h(x)` 连续可微；例 `-1<x<1` 时 `h=[1-x, x+1]`。
- **CBF 性质（Assumption 1）**：`B_γ>0` 于 𝒞 内；`B_γ→∞` 于边界；`B_γ` 单调递减。式10给出一个满足该性质的候选（但任何满足 Assumption 1 的函数都可用）。
- **增广 Hamiltonian / 最优控制**：`H_j=r_a+(∇W_j)ᵀ(f+gu_j)`（式15），最小化得 `u_j*=-0.5R⁻¹gᵀ∇W_j`（式16）。
- **理论结果（都给了证明）**：
  - **Proposition 1**：原问题的可容许策略当且仅当 `u∈𝒰∩𝒰_c` 时，对增广问题也可容许（𝒰_c 为安全输入集，式13）。
  - **Lemma 1/2**：序贯改进下值函数 `W_j` 单调递减且有界 ⇒ CBF `B_γʲ` 在每步有界（式18–25）。
  - **Theorem 1（安全性）**：在 Assumption 2,3 下，沿式16序贯改进，状态对所有 `t>0` 停在安全集内，安全得证（对所有 `0<γ<∞` 成立，Remark 5）。
  - **安全区域 D（Definition 6）**：定义为 `B_γ/(B_γ+Q)≤0.5` 的区域，即 Q(x) 在优化中占主导、安全与性能**不冲突**的子区域。
  - **Theorem 2（稳定性）**：序贯控制输入在安全区域 D 内一致镇定系统（借 Lemma 3 的 Lyapunov 型论证）。
  - **Theorem 3（最优性）**：在安全区域内适当选 γ，增广效用最小值可任意接近零，`lim_{γh→∞} r_a(u*)=0`，即可恢复原最优性能（Remark 9–10）。
  - **Theorem 4（收敛）**：Algorithm 1 收敛到安全最优解（依赖 Lemma 4：off-policy Bellman 式35与原 Bellman 式30等价、同一更新律）。
- **off-policy 学习关键式**：off-policy Bellman 式35同时更新策略 `uⁱ⁺¹` 与值函数 `Jⁱ`；NN 权重最小二乘解 `Ŵ_tⁱᵀ=(HⁱHⁱᵀ)⁻¹HⁱYⁱ`（式43）。Remark 12 强调采样需覆盖安全区与边界附近（CBF 起作用的区域），否则训练不可靠。

## 数据集 & 实验设置
- **唯一实验**：自动驾驶**车道保持（lane keeping）**问题——让车在弯道上保持居中，同时满足最大允许横向偏移（按路宽，`y_max=0.45 m, y_min=-0.45 m`）的安全目标（§5）。
- 用**线性**轮胎力模型、纵向速度恒定；4 维状态 `x=[y, v, φ, ψ̇]ᵀ`（横向位移、横向速度、误差偏航角、其导数），系统为线性状态方程（§5 给出 A、B 矩阵）。
- 增广效用含双侧 log 型 CBF（对 `y_min` 与 `y_max` 各一项），critic 激活 Φ 用二次/交叉项含 `(x₁-y_max)`、`x₁⁴` 等，actor 激活 `Ψ=[x₁,x₂,x₃,x₄]ᵀ`。
- 参数见 Table 1：`M=1650 kg, v₀=27.7 m/s, Q=2·I, R=1, γ₁=0.95, γ₂=2` 等。用 off-policy Algorithm 1 训练；要求在安全状态和接近危险状态都采样。

## 主要结果 & 结论（写方向，不堆精确数字）
- **加 CBF 后横向位移始终停在安全限内、未越界；不加 CBF 时会冲出 `y_min`**（Figure 1，在该车道保持任务上观察到）（observed）。
- 其余状态（横向速度、偏航率、误差偏航角）均收敛到原点（Figure 2）（observed）。
- 学习约 **6 次迭代后** actor/critic 权重收敛、学习完成（Figure 3、4，文中「After six iterations, the learning process is reliable」）（observed）。
- 在该问题中用 `γ₁=0.95, γ₂=2` 即可让状态收敛到原点，说明小 γ 也能在某些系统上达成收敛（Remark 10）（observed）。
- 理论层面（已证明，非仅实验）：方法保证安全集前向不变（安全）、安全区域内一致稳定与可恢复最优性、算法收敛到安全最优解（Theorem 1–4）（supported，数学证明）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：仿射、可镇定的连续时间系统（式1）；安全集可由 `h(x)≥0` 这类（不）等式状态约束刻画，可处理多面体型安全集、甚至状态交互导致的较复杂/非线性安全准则（§1 末、Remark）；**初始状态必须严格在安全集内部**（`x₀∈int𝒞`，Assumption 2）且存在可行的安全输入（Assumption 3）——否则任何策略都救不了，问题本身病态（Remark 4）。
- **需要部分模型**：纯无模型的只是「学习/目标策略」那部分；**行为策略仍需部分动力学知识**来构造一个安全（保守）的初始稳定探索策略（Remark 13、Algorithm 1 第3行）。
- **最优性的前提**：只有在「安全区域 D」（安全与性能不冲突、Q 主导）内才证明了一致稳定 + 最优性可恢复；安全集若不含原点或在冲突区域，方法保证的是安全优先，不保证恢复无约束最优（Remark 7–8、Definition 6）。
- **基线对比强度**：实验只与「不加 CBF」的自身消融对比（Figure 1），**未与其它安全 RL / CBF-QP / MPC 等外部方法做横向比较**（弱基线层面）。

## 核心贡献
- 把 CBF 概念与 RL 统一：将 CBF 项加入代价函数，把「带约束优化」转成「无约束优化」，从而能用数据驱动方式迭代求解安全最优策略（Summary、§1）。
- 提出用「快速阻尼到零」的 CBF（式10）+ 阻尼系数 γ，把安全当成可调权重的控制目标而非硬约束，并支持前瞻式主动安全规划、减少与最优控制器的冲突。
- 用 off-policy RL（行为/目标策略分离）实现学习期间系统始终安全、且能评估不施加到系统的（可能不安全）策略——对安全关键系统重要（Remark 11、13）。
- 给出完整理论：安全性（Theorem 1）、安全区域内稳定性（Theorem 2）与最优性可恢复（Theorem 3）、算法收敛性（Theorem 4），并证明加入 CBF 不破坏安全集内的稳定与最优。

## 局限与我的质疑
1. **实验极其单薄**：只有一个车道保持任务，且系统被设成**线性**模型（§5 的状态方程是线性的），而全文方法以非线性仿射系统立论——非线性、扰动、模型失配下的表现完全未验证。引用 229 主要应归功于理论框架，实证支撑很弱。
2. **没有与任何强基线比较**：唯一对照是「不加 CBF」的自身消融，没有和经典 CBF-QP、安全 MPC、其它安全 RL（如它综述里 Ref 22/23/26）做对比，无法判断相对优劣，「最优性」在实践中是否真优于现有方法未被实证。
3. **「无模型」被部分夸大**：行为策略需要部分动力学知识才能构造安全稳定的初始探索策略（Remark 13），且 NN 激活函数（Φ、Ψ）是按问题手工设计的多项式基——本质上仍嵌入了大量结构先验，离端到端无模型 RL 距离较远。
4. **γ 的选取缺乏指导**：γ 直接决定安全 vs 最优的权衡和能否恢复最优（Theorem 3 给的是存在性，`γ₁=eᵋ/(h(1-eᵋ))` 这类表达式需要 ε/h），但实际怎么选 γ、对不同系统怎么调参，文中只给个例数值（0.95、2、5 等），没有系统化方法或敏感性分析。
5. **安全保证依赖理想假设**：所有安全/稳定证明建立在精确连续时间动力学、值函数存在且光滑、采样充分（覆盖边界区，Remark 12）、`x₀` 严格内点等假设上；离散化、量测噪声、外部扰动 `d`（实验状态方程里有 `d` 项但安全证明未纳入扰动）下安全性是否仍成立未讨论——而这恰是安全关键场景最在意的。
6. **「不需要 CBF 导数约束」的代价**：免掉式8的导数约束确实是亮点，但它把安全的实现转嫁给「值函数被准确学到、代价确实有界」这一前提；若 NN 近似误差大或学习未收敛，理论上的「代价有界⇒安全」链条可能在有限迭代内不成立，论文未给出学习误差对安全裕度的定量影响。
7. **相对本研究主题（安全 RL）的定位**：这是连续控制 / ADP（自适应动态规划）流派的安全 RL，与深度安全 RL（如 CMDP、拉格朗日法、shielding）路线差异大；其优势是有形式化安全/稳定证明，劣势是可扩展性（高维、图像观测、复杂非线性）和大规模实证均未触及。
