# Constrained Policy Optimization with Explicit Behavior Density For Offline Reinforcement Learning
> Jing Zhang, Chi Zhang, Wenjia Wang, Bing Jing · 2023 · Neural Information Processing Systems · 引用 16 · DOI 10.52202/075280-0245

## 一句话
用 Flow-GAN 把行为策略(behavior policy)的密度**显式**估出来,据此把"安全区"定义成密度高于阈值的状态-动作集合,再把离线 RL 的策略优化约束在这个区域内——既挡住 OOD 点,又允许探索数据集里没出现过但密度高的"安全点",从而比传统策略约束法更不保守。

## 解决了什么问题
- 离线 RL 不能与环境交互,Bellman 残差在 OOD(分布外)点上估不准、会被高估的 Q 值主导,导致学到的策略被误导。
- 现有两条解法各有毛病:**价值函数约束类**(CQL/IQL/集成 Q 等)给 Q 函数加悲观项,但"价值下界/不确定性"很难估准,理论与实践都无保证;**策略约束类**(BEAR 用 MMD、BRAC 用 KL、SPOT 用密度下界)把学习策略拉近行为策略,常常**过度保守**,把"在训练分布内但数据集里没见过的安全点"也当成 OOD 排除掉,够不到最优策略(原文 Figure 1b 用橙色小圈示意:旧方法只敢在数据点的小邻域里探索)。
- 作者主张:要准确划定安全区,需要对行为策略动作空间的**条件密度做直接、显式、准确的估计**,而这正是以往方法缺的(SPOT 只估了密度的下界)。

## 用什么方法解决的（含直觉：为什么 work）
- **核心抓手 = 显式行为密度**。安全区被定义为 `S̃ × Ã = {(s,a) : −log L_θ^πβ(s,a) < ε}`,即行为策略密度高于某阈值的区域(§3.3)。有了"密度本身"而非"下界",就能把高密度但未被采样到的点(Figure 1c 的黑点)也纳入可行域 → 探索区域扩大、风险厌恶降低。
- **为什么用 Flow-GAN 估密度(关键直觉)**:
  - VAE 容易"mode covering"(摊平到所有模式),估**多峰/复杂**的行为分布不准;GAN 学复杂分布更强,但 GAN 是个采样器、**给不出显式密度**。
  - Flow-GAN 把**归一化流(normalizing flow)当 GAN 的生成器**:流是可逆映射 `f_θ`,靠换元公式直接给出显式密度 `p_θ(τ) = p_H(f(τ))·|det(∂f_θ(τ)/∂τ)|`(Eq.3);用 NICE / Real-NVP 这类雅可比为三角阵的结构,行列式可高效算。
  - 训练用**混合损失**(Eq.4):`min_θ max_φ L_G(G_θ,D_φ) − λ·E_{τ∼P_data}[log p_θ(τ)]`,即 GAN 对抗损失 + 最大似然(MLE)项。直觉(Remark 3.1):纯 MLE 倾向覆盖所有模式、对模型误设不稳健;纯 GAN 易模式崩塌;两者相加互补,得到既准又稳的密度估计。
- **与 MaxEnt IRL 等价(Proposition 3.1, 附录 B)**:用混合损失训练的 GAN,其似然函数等价于最大熵逆强化学习估出的行为密度,`L_θ^πβ(τ) = C·Z^{-1}·exp(−c_θ(τ)) ∝ p_θ^G(τ)`(Eq.5),给"用 GAN 当密度估计器"提供了理论依据。
- **Actor 目标 + 约束(Eq.7)**:`max_ψ E_{s∼P_D, a∼π_ψ(·|s), (s,a)∈S̃×Ã} [Q_η(s,a)]`,即只在安全区里最大化 Q;约束"动作密度 ≥ 阈值"用拉格朗日对偶梯度下降实现,乘子为 α(密度低于阈值就当惩罚项,见脚注2)。
- **整体框架(Algorithm 1)**:先单独预训练 Flow-GAN(约 2 万步)拿到密度估计器;之后在 **TD3** 框架下交替更新——Flow-GAN 继续更新、Q 网络用裁剪双 Q + 目标策略平滑(`y = min(Q_{η1'}, Q_{η2'})`)、Actor 按 Eq.7 带拉格朗日乘子更新、软更新目标网络。ε 取**当前 batch 似然的均值**(而非传统分位数 0),降低密度估计误差的影响。

## 动机 & 背景
- 离线 RL 的根本难点是分布漂移 / "extrapolation error":策略在迭代中可能访问到高估 Q 值的 OOD 点,Bellman 残差被这些点主导。
- 作者把已有工作梳成两谱系:价值函数约束(让 Q 悲观)与策略控制(限制学习策略与行为策略的分布距离)。批评点是:显式距离法受限于"距离只能从有限样本估"的泛化问题;隐式生成法(如直接从条件分布采动作)又过度保守。
- 关键转折:与其约束"距离"或估"密度下界",不如**直接、准确地估行为策略密度**来定义支撑集一致性(support consistency),这是更可取的处理分布漂移的角度。

## 方法细节
- 形式化离线 MDP(Definition 3.1):数据集 D 由行为策略 π_β 生成,优化必须发生在有界安全空间 `S × A` 内才可信。
- 行为密度经由 MaxEnt IRL 的玻尔兹曼分布 `p_θ(τ) = Z^{-1} exp(−c_θ(τ))`(Eq.2)建模,难点是配分函数 Z 难估;借 guided cost learning 的结论,估 Z 等价于用 GAN 训练数据集 → 引出 Flow-GAN 路线。
- 公式链(已核对):换元密度 Eq.3 → 混合损失 Eq.4 → 与 IRL 等价 Eq.5 → CPED 的密度训练目标 Eq.6(把输入从轨迹 τ 换成 (s,a))→ Actor 目标 Eq.7。
- 理论(§4,证明在附录 A/C/D):
  - **Theorem 4.1**(非正式):在生成器类、判别器类落在 Sobolev 空间且 λ 为常数等条件下,IPM 距离与 KL 散度都以 `O_P(n^{-1/2})` 收敛 → 混合损失既能当好生成器、又给出准确密度。
  - **Theorem 4.2**:概率趋于 1 时,CPED 学到的受控策略 π̃^Δ 满足 `Q*(s,a) = Q(s, π̃^Δ(·|s))`,即能在乘积空间 S×A 上找到最优 Q 值(关键假设:π̃^Δ 在 A 上处处 >0,且 GAN 能准确估 π_β 的密度使 P(Ω)→0)。
  - **Theorem 4.3**:策略迭代下,值函数以线性速率收敛 `‖V^{π̃_{k+1}^Δ} − V*‖_∞ ≤ γ^{k+1}‖V^{π̃_0^Δ} − V*‖_∞`,与在线 RL 标准速率一致。

## 数据集 & 实验设置
- 基准:**D4RL** 的 Gym-MuJoCo(halfcheetah/hopper/walker2d ×medium/medium-replay/medium-expert)与 **AntMaze**(umaze/medium/large ×play/diverse);每项 5 个随机种子报平均归一化分。
- MuJoCo 基线:BC、AWAC、DT、Onestep、TD3+BC、CQL、IQL、SPOT(均为较强的近期 model-free 离线 RL 方法)。AntMaze 基线:BCQ、BEAR、BC、DT、TD3+BC、PLAS、CQL、IQL、SPOT。
- 实现细节(附录 E.2):Flow-GAN 生成器用 NICE 的流结构(4 层 MLP),判别器 4 层 MLP;原 FlowGAN 是为图像设计,作者把卷积/残差换成全连接以适配 D4RL(Table 3 给了 DCGAN / WGAN-GP 两套超参)。Actor-Critic 用 TD3(Table 4:折扣 0.99、1e6 步、策略噪声 0.2、裁剪 0.5、更新频率 2 等)。α 用**时变(time-varying)** 分段方案。

## 主要结果 & 结论（写方向，不堆精确数字）
- **MuJoCo 上,CPED 在多数任务上优于一众强基线,总分居首** — supported(9 任务×5 种子;总分约 791.7,优于第二名 SPOT 约 773,见 §5.1 表1)。优势主要来自 **halfcheetah 与 walker2d 的 medium 系列**。
- **在 medium-expert(专家占比高、需要"贴紧行为策略"的紧控制)任务上,CPED 略逊于其它方法** — observed;作者解释为专家任务要求严格控制、CPED 偏探索反成劣势。
- **AntMaze 上 CPED 总分不及 IQL,但优于其余基线** — observed(总分约 376.8 vs IQL 约 392.4,见 §5.1 表2);CPED 在 umaze、medium-play 上拿到最好或接近最好,在 large 系列偏弱。**因此"全面超越 SOTA"的措辞站不住**:更准确说法是"MuJoCo 总分第一、AntMaze 不及 IQL"。
- **CPED 的学习曲线在 BEAR/SPOT 进入平台后仍持续上升** — observed(§5.1 Figure 2a,halfcheetah-medium 单任务);作者据此论证 CPED 因放宽安全区而"持续探索获益",与 Theorem 4.3 的方向一致。这是单任务定性观察,非系统性证据。
- **Flow-GAN 的密度估计精度显著优于 VAE** — supported(但仅 toy 实验):附录 E.6 在二维高斯混合上,生成样本的平均对数似然 Flow-GAN 远比 VAE 接近真值(Table 5,如 setting1:真值 −2.89,Flow-GAN −24.18,VAE −140.83)。
- **消融**:ε 取 batch 似然均值在多数 MuJoCo 任务上优于传统分位数 ε=0(Figure 6);时变 α 在 MuJoCo 上明显优于常数 α(Figure 7)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:中等质量数据(medium / medium-replay)、最优策略可能落在"数据见过的分布内但样本没覆盖到"的区域、需要在安全区内多探索才能逼近最优的任务——这正是 CPED 放宽可行域的设计初衷,也是实证最强处。
- **不太管用 / 优势消失**:专家数据为主、需要紧贴行为策略的任务(medium-expert),放宽探索区反而拖累;以及导航类稀疏奖励的 AntMaze-large,CPED 弱于 IQL。
- **依赖前提**:Flow-GAN 必须把行为密度估准(理论保证依赖密度准确 → P(Ω)→0)。动作维度很高时密度估计与阈值 ε 的设定都更难——作者用 batch 均值规避分位数难设的问题,但这是启发式。
- 对比的是**较强的近期基线**(IQL、SPOT、CQL、TD3+BC 等),不是弱基线;结论的可信度因此较高,但也意味着它并未在所有 setting 上一骑绝尘。

## 核心贡献
- 提出 **CPED**:首个用 Flow-GAN 对离线 RL 行为策略做**显式密度估计**、并据此定义安全区做策略约束的方法。
- 把"显式密度 + 混合损失 GAN"与 MaxEnt IRL 在理论上打通(Prop 3.1),并给出 Flow-GAN 估计的收敛速率(Thm 4.1)与 CPED 找到最优 Q / 值函数线性收敛的保证(Thm 4.2、4.3)。
- 在 D4RL MuJoCo / AntMaze 上做了较系统的实验与消融(ε 设定、时变 α、Flow-GAN vs VAE toy)。

## 局限与我的质疑
1. **"substantially outperforms SOTA" 被过度解读**:AntMaze 总分输给 IQL,medium-expert 也偏弱。论文摘要/引言的强主张与表2不符;实际是"看任务族而定",泛化性没被证明。(我的批判 + 与数据自相矛盾)
2. **额外训练与调参成本未量化**:CPED 要先训一个 Flow-GAN(流生成器+判别器+混合损失,Table 3 超参众多、还分 DCGAN/WGAN-GP 两套),再 TD3 联训。全文**没有给训练时长 / 算力 / 收敛稳定性的对比**,而 GAN 训练本身以难调著称——对一个主打"密度估准"的方法,这是明显缺口。
3. **密度估计精度只在 toy 上验证**:E.6 仅是二维高斯混合;D4RL 真实任务上 Flow-GAN 在中高维动作空间到底估得多准,没有直接的密度精度指标,只能从最终回报间接推断。理论保证又强依赖"密度估准"这一前提。
4. **理论与实际网络有差距**(作者自述,Remark 4.1):收敛性证明假设生成器/判别器落在 Sobolev 球内,真实用的是神经网,二者只能"类比",非严格覆盖。
5. **时变 α 调度偏手工**:需先找任务的"最强/最弱 α",再在 200–300k 步后衰减(E.2);且 Figure 8 显示把同一时变技巧用到 SPOT 上**没带来收益甚至更差**,提示这套调度的好处可能与 CPED 实现强绑定,而非普适技巧——削弱了"时变 α 是通用改进"的说服力。
6. **阈值 ε 的启发式**:用 batch 似然均值替代分位数,虽缓解高维难设的问题,但缺乏对 ε 敏感性的系统分析,安全区边界的稳健性存疑。
7. **未覆盖更复杂场景**(作者自述,§6):多行为策略 / 多智能体生成的数据未做,留作未来工作;对本研究关心的"约束策略优化谱系"而言,它属于离线 RL 的密度约束分支,与安全 RL(CMDP/CPO)那条约束优化线并不是同一类约束,迁移时需注意区分。
