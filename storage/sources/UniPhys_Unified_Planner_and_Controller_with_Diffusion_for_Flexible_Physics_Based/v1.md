# UniPhys: Unified Planner and Controller with Diffusion for Flexible Physics-Based Character Control
> Yan Wu, Korrawe Karunratanakul, Zhengyi Luo, Siyu Tang · 2025 · IEEE International Conference on Computer Vision · 引用 21 · DOI 10.1109/iccv51701.2025.01228

## 一句话
UniPhys 用一个扩散模型把"高层规划"和"底层物理控制"合二为一，在物理仿真里直接做行为克隆（behavior cloning），一个模型就能由文本/速度/目标/避障等多模态信号驱动出物理可行的长程角色运动，且对未见任务零样本泛化、无需逐任务微调。

## 解决了什么问题
- 物理角色控制的主流做法是"两段式"：高层 kinematic planner 生成参考运动 + 底层 RL tracker 跟踪它，但两段之间存在 domain gap，规划出的运动和物理约束不对齐，导致抖动、滑步等不自然伪影，并且往往要对每个任务单独微调（作者点名 CLoSD [53] 即此类，§1、§2）。
- 纯运动学（kinematics-based）的文本驱动方法表达力强、动作多样，但缺物理约束会产生脚滑、漂浮等物理不可行伪影（§2）。
- 物理控制器在长程自回归预测中会累积误差（compounding error），漂出训练分布后控制失稳（§4.3）。
- 已有物理多任务策略（如 MaskedMimic [51]）在动作自然度和对未见控制信号的泛化上受限（§1、§2）。

## 用什么方法解决的（含直觉：为什么 work）
核心思路：**把 planner 和 controller 塞进同一个扩散模型**，端到端同时建模"未来状态分布"和"对应动作"，从而消除两段式的中间对齐误差（§4）。
- **行为序列表示**：模型输入/输出是长度 T 的行为序列 X=x_{1:T}，每帧 x_t=(s^c_t, z_t)，由"规范化状态" s^c_t 和"潜动作" z_t 拼成（共 398 维/帧，§4.2）。
  - 潜动作 z_t∈R^32 不是原始高维 PD 目标动作，而是用 PULSE [29] 的 cVAE 编码器把 (s_t, 下一帧目标 s^g_t) 压成的潜表示，z_t~E(z_t|s_t,s^g_t)、a_t=D(s_t,z_t)（§3、§4.2）。直觉：z_t 捕获了相邻帧间的动态转移，是一个被良好正则化、对所有任务通用的"广义动作表示"，比直接学原始动作空间更易学、rollout 更稳（§4.2、§5.5 消融支持）。
- **训练范式：Diffusion Forcing [3]**——对序列里**每帧独立、随机地加不同噪声等级** k=k_{1:T}，模型 M_θ(X^k,k,c) 学习去噪还原干净行为序列，c 是 CLIP 文本嵌入（§4.2）。训练 loss 是去噪重建的 L2：
  - L(θ)=E_{k,X^0}[||X^0 − M_θ(X^k,k,c)||^2]（式1）。
  - 直觉（为什么能抗累积误差）：因为每帧噪声等级可独立，推理时可以**把"已预测的历史帧"当作带轻微噪声而非完全干净**来处理，从而显式地为"误差传播 + 物理仿真器引入的偏差"留出余量，不会像普通自回归那样过度自信地把历史当成无误差（§1、§4.3）。
- **推理：guided denoising + receding horizon 自回归**（Alg.1）：以过去行为为条件迭代去噪未来动作 token → 解码成可执行动作 → 在仿真器执行 T_a 步 → 窗口前移、循环，实现长程 rollout 并可随时响应任务/环境变化（§4.3）。
- **稳定化技巧（stabilization trick）**：去噪时把"已完全去噪帧"的噪声指示 k 设为大于 0（k>0），即告诉模型"过去状态是略带噪声的"，缓解分布漂移、提升长程 rollout 稳定性（§4.3，Alg.1 第5行；附录 A 给出经验取值：文本驱动用噪声等级 1~2~3，太大如 5 反而降稳定）。
- **多模态控制靠两类引导，无需逐任务微调**：
  - 文本：classifier-free guidance（CFG），X̂^0_c = M_θ(X^k,k,∅)+λ_c(M_θ(X^k,k,c)−M_θ(X^k,k,∅))（式2）。
  - 任务目标（达点/测速/避障）：task-specific loss-guided sampling，沿任务 loss G(X) 的梯度推动去噪：X̂^0 = M_θ(X^k,k,c)−λ_l∇_{X^k}G(X̂^0)（式3）；并用 Monte-Carlo Guidance（MCG [47]）多采样平均梯度降方差（式4）。
- **灵活的去噪日程（denoising schedule）**：除全序列去噪外，提供 (1) 自回归去噪、(2) gradual 去噪（优先去近未来、对远期保留不确定性）；配合可变历史长度 h 与预测时域 H，同一模型既能做反应式短时域控制又能做远目标长程规划（§4.3，Table 1 给各任务配置 h/H/T_a/schedule）。

## 动机 & 背景
- 物理角色控制常被表述为"在物理仿真器里跟踪参考运动"的 goal-conditioned RL，可蒸馏成接受文本/关键帧/目标关节位置等多模态信号的控制器；但鲁棒的双足多任务策略在动作自然度、跨信号泛化、行为多样性上仍受限（§1）。
- 扩散式 motion planner 能产生多模态分布、接受任意 loss 引导，被用来给 RL tracker 提供中间目标；但 planner 与 generator 集成不够紧，控制策略难以精确跟踪、需逐任务微调（§1）。
- 作者关键洞见（key insight）：长程规划+鲁棒控制的"首要难点是自回归每步的累积误差"，缓解它后单一模型即可同时规划与控制，不再需要底层 RL 执行策略（§1）。

## 方法细节
- **物理设定**：Isaac Gym 仿真器中控制类 SMPL 角色，24 个旋转关节、23 个驱动（不含 pelvis），PD 控制，动作 a_t∈R^{J×3} 是目标关节位置；s_{t+1}=SIM(s_t,a_t)（§3）。
- **数据集构造（行为克隆的专家数据）**：用 PULSE 跟踪策略在 AMASS 上跟踪 MoCap，存成对 (s_t,a_t,z_t)；再叠加 BABEL 的帧级文本标注。最终编出含文本的成对 text-state-action 数据集，4875 段、覆盖 BABEL 训练集、共 15.7 小时运动；作者称将公开（§4.1、Fig.2）。
- **状态规范化**：S^c 含全局 root 轨迹（位置/6D 朝向/线速/角速）、局部关节位置/速度/旋转(6D)/角速；root 轨迹从原点起、首帧朝 +y，局部坐标以 pelvis 在地面投影为参考（§4.1）。
- **骨干网络**：12 层 causal transformer decoder，hidden size 768，输入 32 帧，每帧特征=32 维潜动作+366 维状态=398 维；条件于 CLIP 文本嵌入（§4.2、附录 A）。
- **训练细节（附录 A）**：32 帧片段、stride 8；含多文本标注时随机选一；把 "transition to" 标注改赋给过渡段以平滑技能切换；batch 1024，lr 1.5e-4，10k warm-up + cosine 衰减，50 去噪步，单张 RTX A100 约 10 GPU·days、15k epochs。
- **推理细节（附录 A）**：DDIM 5 步采样并全任务套用稳定化技巧。

## 数据集 & 实验设置
- **训练数据**：AMASS（经 PULSE 跟踪）+ BABEL 文本，自建 text-state-action 数据集（§4.1）。
- **任务配置（Table 1）**：文本驱动 h=4/H=8/T_a=8/自回归；达点、测速、避障均 h=4/H=28/T_a=8/gradual。
- **基线**：MaskedMimic [51]（masked cVAE 蒸馏多任务控制器，能灵活条件但无规划、不能泛化到未见信号）；CLoSD [53]（扩散 planner + RL tracker 两段式，因 planner/controller 分离需在预定义任务上微调）（§5）。
- **评测指标**：物理可行性用 foot-floating（漂浮，mm）；平滑度用 motion jerk（mm/s³）；不报 foot skating（各物理法都可忽略）；文本语义保真用 SuperPADL [17] 式的四选一人评（含 Nothing/Multiple applies）；运动质量用自然度/真实度/平滑度 1–5 主观打分，每条 3 人评（§5、§5.1）。
- **应用四类**：交互文本驱动控制、稀疏目标达点（pelvis 目标高度固定 0.9m，距目标 0.3m 内算成功）、速度控制（0–2 m/s 随机方向、每 500 步更新、120 步过渡期评测）、动态障碍躲避（球形障碍约 2m 外持续逼近，拉开到≥3m 且不碰撞不摔算成功）（§5.2–5.4）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **文本驱动**：UniPhys 在自然度/真实度/平滑度人评上优于两个物理基线（MaskedMimic、CLoSD 的物理跟踪结果），且文本语义保真高于 MaskedMimic（observed，§5.1 Table 2、附录 Table C.1）。注意：CLoSD 的**运动学规划**本身在语义表现力上比物理文本控制器更强，但其"先规划后跟踪"范式产生抖动和漂浮——即 UniPhys 赢在物理落地与平滑，而非赢在 kinematic 表达力本身（observed，§5.1）。
- **达点**：UniPhys 在近/远目标都能不靠启发式中间目标地泛化到任意距离；基线（CLoSD、MaskedMimic）把目标限制在约 2 秒时域内、对远目标弱（CLoSD 设中间目标常致运动不连续，且 RL tracker 跟不动 'jogging' 风格）。UniPhys 在 jog-to-goal 这类更难设定上成功率与平滑度占优（observed，§5.2 Table 3）。
- **速度控制**：UniPhys 与 MaskedMimic 跟踪误差相近，但 UniPhys 过渡更平滑、jerk 更低；MaskedMimic 在方向切换时有突兀加速、jerk 高（observed，§5.3 Table 3）。CLoSD 不支持速度控制。
- **动态避障**：50 个 episode、不同方向障碍下成功率约 94%；失败主要发生在障碍从正前方逼近、角色后退失衡时（observed，§5.4）。
- **消融（Table 4）**：① 用 PULSE 潜动作表示比直接学原始高维动作显著更稳更高效（observed）；② 稳定化技巧无论用哪种动作空间都能靠降累积误差稳定 rollout（observed）；③ 去噪日程上，"自回归 + 稳定化"最鲁棒（平均/最长 episode 长度最大，可达 3000 步上限）但效率最低（~9.5 FPS），gradual 在鲁棒与效率间折中（18 FPS），full-sequence 最快（23 FPS）（observed）。
- **MCG 消融（附录 Table A.1）**：达点任务里，Monte-Carlo 采样数 N 从 1→3 让成功率从 26%→82%，N=5 进一步到 98%，但 FPS 略降——即多采样平滑梯度对 loss 引导任务很关键（observed）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：需要一个模型同时做长程规划与物理控制、且要由多模态信号（文本/速度/稀疏目标/动态避障）灵活驱动、并对训练时未见的控制信号零样本泛化时（§4.3、§5）。
- **管用**：行走、慢跑、跑、坐等动作 + gradual 去噪适合长程任务；交互式文本控制用自回归去噪以便随时切指令（§4.3、Table 1）。
- **不太管用 / 受限**：推理慢——文本驱动约 10 FPS（自回归去噪）/18 FPS（gradual）（附录 D），比 RL 策略低效，对高频实时控制不利。
- **不管用**：当前不含灵巧手控制，故人-物交互里的手部精细操作做不了（附录 D）。
- **受限**：缺地形特定数据，跨不同地形行走（行为克隆）暂不可行，作者建议用 RL 策略生成未见场景数据来补（附录 D）。
- **失稳点**：高动态动作或换指令时机不好会出现平衡损失/摔倒与切换失败；正前方逼近的障碍易致后退失衡（附录 D、§5.4）。

## 核心贡献
- 提出 UniPhys：**首个把规划与控制统一进单一扩散模型**的物理角色控制行为克隆框架，可由任意目标条件驱动、做长程自然鲁棒且与文本对齐的运动（§1、§4）。
- 提出针对各任务的多种引导采样技术（CFG + loss-guided + MCG）与可变历史/时域/去噪日程，同一模型零样本完成多任务、无需逐任务微调（§1、§4.3）。
- 用 Diffusion Forcing 训练 + stabilization trick，专门压制行为克隆里的长程累积误差（§4.3）。
- 构造并承诺公开一个大规模物理角色 state-action 数据集（含 BABEL 帧级文本标注，15.7 小时），供模仿学习用（§1、§4.1）。

## 局限与我的质疑
1. **作者自述局限**：推理低效（10–18 FPS，附录 D）；平衡 loss 仍会致摔、缺 fall-recovery 技能（拟后续收集起身专家数据 + 专门 RL 策略补，附录 D）；不支持地形泛化、不支持灵巧手（附录 D）。
2. **基线偏窄、缺与强 RL 多任务策略的全面横评**：定量只系统比了 MaskedMimic 和 CLoSD 两家，且各任务能比的基线还不齐（CLoSD 无速度控制、MaskedMimic 在远目标上要被人为放近到 2m 内才能比，见 Table 3 脚注）。"outperforms prior methods"（摘要）的覆盖面其实有限，更多是 observed 而非 strong 的全面超越——读者勿把它读成对所有物理多任务方法的普遍碾压。
3. **核心评测高度依赖主观人评**：文本驱动质量靠 AMT 1–5 打分和四选一，作者明言"缺乏可靠的物理文本驱动自动指标"（§5.1）；3 人评、150 caption 采样，绝对分差不大（如自然度 3.23 vs 2.86/2.82，§5.1 Table 2），统计显著性/置信区间未见报告，结论稳健性存疑。
4. **成功率口径偏松、可能高估能力**：达点判定为 pelvis 距目标 0.3m 内、且目标高度固定 0.9m（不支持高度控制，§5.2）；避障 94% 来自 50 个 episode（§5.4）。这些阈值和样本量下的高分，外推到更严苛设定时未必成立。
5. **物理可行性证据偏单薄**：物理性主要看 floating 和 jerk 两个量，foot skating 直接以"各法都可忽略"为由不报（§5.1）；对接触力、能量、足-地接触真实性等更硬的物理指标没给，"physically plausible"的主张证据维度偏窄。
6. **强依赖 PULSE 潜动作空间**：动作表示完全建立在 PULSE [29] 的 cVAE 之上，z 的质量、覆盖度、是否限制了可表达动作上界，论文未深究；这等于把"物理可行性"部分外包给了被蒸馏的跟踪策略，UniPhys 自身的边界受 PULSE 边界制约。
7. **对本研究主题（数字人全身运动与交互）的不足**：明确不做手部/灵巧操作与真正的人-物交互（附录 D），全身-物体交互、接触丰富的操作类任务超出当前范围；避障也只是"远离球形障碍"这一简化 SDF 设定，离真实场景交互尚远。
