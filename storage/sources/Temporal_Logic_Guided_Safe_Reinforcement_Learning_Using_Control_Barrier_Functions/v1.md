# Temporal Logic Guided Safe Reinforcement Learning Using Control Barrier Functions
> Xiao Li, Călin Belta · 2019 · arXiv (Cornell University) · 引用 31 · DOI 10.48550/arxiv.1903.09885

## 一句话
用时序逻辑(scTLTL)自动生成的有限状态自动机(FSA)同时给 RL 提供奖励、给控制李雅普诺夫函数(CLF)提供引导探索的目标、给控制屏障函数(CBF)提供安全集约束,再把三者拧进一个二次规划(QP)里求出"既安全又推进任务"的动作——从而在连续控制任务里做到训练全程不违反硬安全约束、同时加速探索。

## 解决了什么问题
- 针对当前 RL 的两大痛点:**复杂任务难以准确指定**(手写奖励易被 reward hacking 钻空子,如 peg insertion 的嵌套 min/max 奖励要费力调参)与**学习过程中难保证安全探索**(物理系统上不安全动作有真实代价)。
- 作者主张:把任务写成时序逻辑公式,由公式**自动**转成奖励函数,用户无需手工设计奖励;并在学习与部署全程用屏障函数把动作"修正"到安全集内,做到硬约束严格不违反。
- 关键概念区分:论文区分"未满足 φ(not satisfying)"与"违反 φ(violating)"——后者指进入某状态后 φ **再也无法被满足**(对应 FSA 的陷阱状态 trap state)。

## 用什么方法解决的（含直觉：为什么 work）
- **任务规约层(scTLTL→FSA)**:用语法上 cosafe 的截断线性时序逻辑(scTLTL,即去掉"always □"算子的 TLTL 受限版),这样每个公式都能对应一个有限状态自动机 FSA(可用 Lomap 自动生成)。FSA 的状态 q 编码"任务进展到哪一步",转移由谓词 ψ 守卫。
- **鲁棒度作奖励**:scTLTL 的"鲁棒度(robustness degree)"ρ 是一个实值函数,ρ>0 即满足公式、ρ 大小量化满足程度。把它当奖励,天然带语义("大于零=完成任务"),且与手写嵌套 min/max 同构但无需人去调。
- **FSA 增广 MDP(FSA augmented MDP)**:把 FSA 状态 q 并进 MDP 状态(状态变成 (s,q)),奖励定义为 r̃(s̃,s̃')=ρ(s', D_φ^q),其中 D_φ^q 是当前自动机状态 q 所有出边守卫谓词的析取。**直觉**:奖励鼓励系统"离开当前自动机状态、推进到下一个",从而最终走到接受态 q_f(即满足整条时序逻辑规约)。
- **处理违规/陷阱状态**:原始 FSA 不显式处理违规,作者加一组陷阱状态 Q_trap(进入后再无路径通向 q_f)。奖励改为 r̃ = min(ρ(s', D_φ^q), c_r·ρ(s', ¬ψ_{q,q_trap}))(式11),即在"推进任务"与"别进陷阱"两项里取 min(惩罚更违反的那项)。注意:**该奖励本身不阻止 agent 在学习时违反 φ**——agent 反而需要探索陷阱状态才能学会避开(故 FSA 有自环)。
- **FSA→CLF 引导探索(goal selection)**:在当前 (s,q),挑一条"最容易激活、通向非陷阱状态"的出边(其守卫谓词鲁棒度最大),再取使该谓词鲁棒度最大的状态作为目标 s_g(式12);构造简单二次型 CLF Vφ=(s−s_g)ᵀ(s−s_g)(式13)。**直觉**:CLF 像个"指南针",把 agent 朝着推进 FSA 的最近子目标推,加快早期探索。若谓词是状态空间里的区域,max 鲁棒度点就是区域中心(实用启发式)。
- **FSA→CBF 安全约束**:要避免激活通往陷阱的守卫 ψ_{q,q_trap},即要 ¬ψ_{q,q_trap} 恒真。把 ¬ψ 化成合取范式 CNF,每个合取子句作为一个零化 CBF h_φ^i(式14)。**直觉**:谓词本就是状态不等式约束,可直接当"安全集"。CBF 保证安全集前向不变(forward invariant),把 agent 挡在陷阱之外。
- **统一进 QP(TL-CLF-CBF QP,式16)**:把 RL 给的动作 a_rl 嵌进已知动力学,求解 acbf、aclf 两项修正,使在用户额外安全约束 h(s)、TL 相关 CBF 约束 h_φ^i、CLF 约束(带松弛变量 δ)与动作上下界下最小化 âᵀâ+Kδ。最终送给系统的动作 = a_rl+acbf+aclf。**直觉**:CBF 约束是硬不等式(优先保证安全),CLF 约束可被松弛 δ 放松(K≈1e10 大常数,冲突时让 CLF 让步);model-based 的 QP 利用已知动力学做规划,model-free 的 RL 处理未知环境动力学(移动障碍),两者互补。

## 动机 & 背景
- 物理系统部署 RL 的两个障碍:奖励难写(易 reward hacking)+ 探索不安全。
- 现有安全做法多靠"仿真训练→sim-to-real 迁移",但仿真难精确匹配现实、需微调;作者倾向用一个"护盾控制器(shielding controller)"在学习与部署都保安全并引导探索 [6][7]。
- 本文把 [9] 的 FSA 增广 MDP 框架扩展到**处理硬约束与规约违反**,并接上 CBF/CLF [8]。
- 与相关工作的差异定位(作者自述):相比此前用 TL/自动机做 RL([10–15])或用 CBF 护盾([17][18])的工作,本方法"**相对易实现、能处理连续状态/动作空间、非线性约束与动力学、可高效执行**",且把 TL 规约里的硬约束用 CBF **严格强制**。(此为作者主张,论文未与这些方法做定量对比——见局限。)

## 方法细节
- 形式化(Problem 1,式10):在 MDP 上求 π_φ*,最大化 E[Σγ^t(r̃+wr)]——r̃ 是 FSA 增广奖励、r 是普通 MDP 奖励、w 为权重——**约束 min_{t∈[0,T]} h(s_t)>0**(轨迹始终在安全集内,且 φ 全程不被违反)。
- 动力学拆分:p={p_k, p_u},已知系统动力学 p_k 形如 ṡ=f(s)+g(s)a(仿射控制系统),未知环境动力学 p_u。CBF/CLF 用已知动力学做约束。
- CBF 定义(Def 4,式7):对安全集 C={s:h(s)≥0},存在扩展 K 类函数 α 使 sup_s(∂h/∂t+αh(s))≥0,则 h 是零化 CBF。CLF 定义(Def 5,式8):指数稳定 CLF 满足 c₁‖s‖²≤V≤c₂‖s‖² 且 inf(∂V/∂t+c₃V)≤0。
- 基础 CLF-CBF-QP(Prop 1,式9):min aᵀa+Kδ s.t. CBF 不等式≥0、CLF 不等式≤δ。
- 算法 1(TL Guided Safe RL)主循环:构造 FSA 增广 MDP→每步 a_rl=π_θ(s_t)→构造 Vφ、安全集 Cφ→解 QP 得 acbf/aclf→用合成动作步进环境→算奖励 r̃+wr 存 buffer→用所选 RL 算法更新策略。

## 数据集 & 实验设置
- **单一仿真任务**(无真实机器人、无多任务):一个已知动力学的 agent + 由两条直线构成的"安全通道"(宽 2w)硬约束 + 三个圆形目标区(位置每回合随机、可能初始在通道外)+ 两个**动力学未知**的移动障碍。
- agent 用**单轮车(unicycle)模型**(式17),欠驱动不可控;按 [26][27] 取偏离中心的参考点 [ε,0] 把系统改写成全驱动形式(式18)再套用式15。
- 状态 14 维:位置朝向 [x,y,θ] + 所有目标与移动障碍位置(共 13 连续维)+ 1 维离散 FSA 状态;动作=前进速度 a_v 与转向速度 a_θ。
- 任务公式 φ(式19):先到 g1 或 g2、再到 g3,g3 不能在 g1/g2 之前访问,且到 g3 前须始终满足通道约束 c1、c2。额外奖励 r=min_i|p_a−p_oi|(与移动障碍的最小距离,作为目标一部分)。
- RL=PPO [28];策略与价值网络均为 3 隐层(300/200/100 ReLU)前馈网。horizon T=200;每次更新收集 5 条轨迹的 batch。训练时允许出通道/撞障碍(领惩罚),评估时不允许。
- **消融式对照四配置**:仅 RL、RL+CBF、RL+CLF、RL+CBF+CLF。评估时 CBF 始终开,成功率统计 20 次试验。

## 主要结果 & 结论（写方向，不堆精确数字）
- **四配置最终性能(折扣回报)相近**;带 CLF 的配置在学习初期**上升更快**——说明 CLF 帮助 agent 更快找到有用策略(observed,见图4)。
- 但**带 CLF 的学习曲线方差/波动更大**(observed):因为 CLF 不知道移动障碍与安全约束,只管把 agent 推向最近子目标,近碰撞/近违规时 RL 要"对抗"CLF 的动作,增加学习难度;RL+CLF+CBF 配置里 RL 需学会与 CLF/CBF 协同(图4)。
- **CBF 能让安全约束在整个学习过程"始终不被违反"**(observed,图5):带 CBF 的配置安全违反量始终≥0;无 CBF 的配置因有违反惩罚(式11)也会**逐渐**学着减少违反,但不是硬保证。RL+CLF(无CBF)还出现过一次骤降(子目标恰在安全区外、RL 尚未学会抵抗 CLF 时,图5a)。
- 与移动障碍的最小距离随训练增大(agent 学会远离障碍);**无 CBF 的配置反而能离障碍更远**——因为它被允许跑出安全区来绕障碍(observed,图6)。
- **评估成功率:带 CBF 训练的 agent 更高**(observed,20 试验,图8)。机制:无 CBF 训练的 agent 常"靠跑出安全区"来避障到达目标,评估时禁止出区,于是更容易卡在安全区边界。
- 轨迹定性(图7):纯 RL/纯 CBF 都走更近的 g2 再 g3;CLF+CBF(无 RL)会被 CBF 拦在安全区边界"卡住"且因不知障碍动力学而撞障碍;RL+CLF+CBF 学会"在边界放弃 g2 改去 g1"完成任务——体现 RL 对 model-based 控制器盲区的补偿。
- **结论方向**:在该仿真任务上,框架能学到完成时序逻辑任务、且学习全程满足安全约束的策略;CLF 主要贡献是**早期探索加速**,CBF 主要贡献是**安全保证 + 更高评估成功率**。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:任务可写成 scTLTL(去掉"always"算子的 cosafe 片段)、谓词是状态空间上的不等式/区域约束(可化 CNF 当安全集);**系统动力学(至少 agent 自身)已知**且为仿射控制形式(CBF/CLF/QP 都依赖 f、g 与梯度);连续状态/动作空间;有明确"硬约束"要严格不违反。
- **不管用/弱**:安全/避障所需的关键动力学**未知**时——CLF/CBF 对移动障碍无能为力(论文明说"nor the CLF or the CBF know the obstacle dynamics"),避障只能交给 model-free 的 RL 学;需要"always □"型持续约束的任务超出 scTLTL 表达范围;状态空间很大时 CLF 目标选择(式12)的第一个优化问题"may be difficult";性能对一堆超参(c_r、w、K、α、c₃、动作上下界)敏感。
- **基线强度**:对照只是**自身组件消融**(RL/±CBF/±CLF),**没有**与其他 TL-RL 或 CBF-safe-RL 方法做定量比较——所以"优于现有方法"无实验支撑,只有"各组件有用"的内部证据。

## 核心贡献
- 提出**一套用 FSA 同时驱动三件事**的方法:同一个自动机既给 RL 提供(自动从 TL 公式生成的鲁棒度)奖励、又给 CLF 提供引导探索的目标、又给 CBF 提供安全集约束。
- 把 [9] 的 FSA 增广 MDP **扩展到处理硬约束与规约违反**(引入陷阱状态、改写奖励式11、把 ¬ψ_{q,q_trap} 化 CNF 当 CBF)。
- 把整套(用户额外安全 CBF + TL 相关 CBF + CLF)**集成进一个可高效求解的 QP**(式16),并融合 model-based 规划与 model-free 学习。
- 在一个带安全约束、已知 agent 动力学、未知环境动力学的连续控制仿真任务上做了组件级有效性研究(消融)。

## 局限与我的质疑
1. **实验极其单薄,结论泛化无依据**:全文只有**一个仿真导航任务、一种动力学(unicycle)、20 次评估试验、batch=5 轨迹**,无真实机器人、无多任务/多公式、无与外部基线对比。"易实现、能处理非线性/连续/高效"等卖点(Related Work 与摘要)在实验里**没有任何定量验证**;所有结论应按 observed 读,不能当成"方法优于 SOTA"。
2. **"安全保证"的范围被措辞放大**:CBF 只能对**已知动力学**的约束(通道、陷阱谓词)给硬保证;对**未知动力学的移动障碍,碰撞照样发生**(图7c 明确撞障碍)。所以"训练全程安全"仅限于可写成 CBF 的那部分约束,标题里的"Safe"不应被读成"全方位安全"。论文也未给 CBF 在离散时间 RL step 下严格前向不变性的理论证明(CBF 定义是连续时间 ∂h/∂t,而 RL 是离散步进,二者衔接的安全性未在文中证明)。
3. **CLF 引导的价值存疑、且引入新问题**:CLF 只换来"早期上升更快",最终性能与不加它**没差别**,反而带来更高方差、甚至一次性能骤降(RL 要对抗 CLF)。作者自己也建议"随训练 shrink CLF 动作界"来缓解——等于承认 CLF 是把双刃剑,净收益在此任务上并不清晰。
4. **超参负担重、且未解决**:作者自承性能"noticeably influenced"于 c_r/w/K/α/c₃/动作界一堆超参,调参靠经验法则(CBF 界宽、CLF 界窄、随训练收缩),"减轻调参负担"被列为 future work——对真要上物理系统的人,这是落地的现实障碍。
5. **可扩展性瓶颈未量化**:goal selection 第一个优化(在大状态空间求 max 鲁棒度状态)作者承认"can be difficult",只给了"谓词=区域时取中心"的启发式;一旦谓词不是简单区域、或状态空间高维,这步如何做、代价多大,论文未答。FSA 状态数随公式复杂度增长(陷阱状态 + CNF 子句数)如何影响 QP 规模也未讨论。
6. **与本研究主题(安全 RL/探索保障)相比的不足**:本文把 CBF 当"事后修正动作"的护盾,**未触及策略本身的安全性学习**,也未与同期 CBF-safe-RL 工作([17][18])或约束策略优化([7][16])做对比,因此很难判断它在"安全探索"这条线上相对强基线的真实位置;鲁棒度奖励本身仍是嵌套 min/max,梯度稀疏/平台问题(TL 奖励常见痛点)在本文也未讨论。
