# Safe Off-Policy Deep Reinforcement Learning Algorithm for Volt-VAR Control in Power Distribution Systems
> Wang Wei, Nanpeng Yu, Yuanqi Gao, Jie Shi · 2019 · IEEE Transactions on Smart Grid · 引用 307 · DOI 10.1109/tsg.2019.2962625

## 一句话
把配电网电压-无功控制(Volt-VAR Control, VVC)建模成**带约束的马尔可夫决策过程(CMDP)**,提出一个 off-policy、model-free 的**约束软演员-评论家算法(Constrained Soft Actor-Critic, CSAC)**,用拉格朗日乘子把"电压不越限"作为硬约束嵌进最大熵 RL,从而在不依赖精确电网模型的前提下兼顾样本效率、可扩展性与约束满足。

## 解决了什么问题
- 配电网 VVC 的传统做法是**基于物理模型的优化/控制**,需要精确的网络拓扑与参数,而实际电网模型常不完整、不准确,且大规模时不可扩展、难以实时(原文 §I)。
- 已有的 RL 类 VVC 方法多用 Q-learning / 动作-值方法,作者指出其参数量随可控设备数**指数增长**、不可扩展;且把约束违反"罚进 reward"的做法要么过度保守、要么不可行(原文 §III-C、§II)。
- 本文要的是一个**同时满足**四个性质的算法:样本高效(off-policy 复用历史运行数据)、可扩展(参数随设备数近似线性增长)、安全(几乎始终满足电压约束)、model-free(supported,§III 开头明确列出这四条诉求)。

## 用什么方法解决的（含直觉：为什么 work）
核心是 CSAC,把四个零件**协同**起来(原文称 "synergistically combining"):
1. **最大熵 SAC 框架** → 提供鲁棒、样本高效的 off-policy 学习。直觉:最大熵让策略有闭式 softmax 解(式13),使 Q 的更新可在 off-policy 模式下进行,从而能反复复用历史运行数据,这是相对 on-policy 方法(如 CPO)样本效率高的根本原因。
2. **乘子法(method of multipliers / 拉格朗日)** → 把"电压违规次数 ≤ 上限"作为显式约束,用可学习的乘子 λ 动态调节"收益 vs 约束"的权衡,而**不是用固定罚系数**。直觉:固定罚系数要么太大导致过度保守、要么太小导致不可行(Table III 用 SAC+不同固定罚系数证明了这点),λ 自适应上升/下降能把策略推到"可行且最优"的边界。
3. **设备解耦的策略网络结构(device-decoupled, Fig 1)** → 让参数量随设备数**线性**而非指数增长,这是可扩展性的来源。
4. **序数编码(ordinal encoding, 式21)** → 把每个设备的离散档位当作有自然顺序的序数变量编码,引入归纳偏置,加速学习。直觉:挡位 0.95/1.00/1.05 之间有"远近"关系,序数编码让网络知道相邻档位更相似,而非把它们当成无序的 one-hot 类别。

## 动机 & 背景
- VVC 协调电压调节器、有载调压变压器(OLTC)、可投切电容器组等设备,目标是把全网电压维持在允许范围内、同时降低网损与设备损耗成本(原文 §I)。
- 现有文献三类:确定性优化(MIQP/二阶锥/混合整数非线性)、含不确定性的优化(随机/鲁棒/MPC)、分布式/去中心化控制;都不同程度依赖模型或牺牲全局最优(原文 §I 综述)。
- 已有 RL-VVC 多基于 tabular Q-learning 或值函数逼近(动作-值方法),本文转向**策略梯度(policy gradient)**:直接学参数化策略、绕开"逼近动作-值函数"的难度,作者称这是采用策略参数化的主要优势之一(§I 末)。

## 方法细节
**CMDP 建模(§II)**
- 状态 `s = (P, Q, Tap, t)`:节点有功/无功注入向量、当前各设备挡位向量、时刻 t。
- 动作:把可控设备挡位从 `Tap` 改到 `Tap'`;动作空间大小为 ∏ |A_i|(各设备挡位数之积,组合爆炸)。
- reward(式6):`R_t = -[C_e·P_loss(t) + Σ_j C_j^T·|Tap_j(t+1) - Tap_j(t)|]`,即网损电费 + 设备切换成本的负值。
- cost(式7):`R_t^c = Σ_i [1(|V_i^{t+1}|>V̄) + 1(|V_i^{t+1}|<V_)]`,即**电压越上/下限的节点计数**(指示函数求和)。
- 优化问题(式1):`max_π J(π) s.t. J^c(π) ≤ J̄`。

**最大熵 + 约束(§III-B/C)**
- 熵正则值函数式(8)-(11);最优策略闭式解(式13):`π†(·|s) = exp(Q_h^π(s,·)/α) / Σ_a exp(Q_h^π(s,a)/α)`,α 为温度参数。
- CMDP 在最大熵框架下写成式(14):`max_π E[V_h^π(s)] s.t. E[V^{c,π}(s)] ≤ V̄^c`;约束上限由有限时域换算 `V^{c,π}(s) ≤ V̄^c = (1-γ^T)/(1-γ)·R̄^c`(T 为一周 168 小时的 episode 长度)。
- 拉格朗日函数(式15-16);乘子更新(式18):`λ^{k+1} = [λ^k + δ_λ(E[V^{c,π_k}(s)] - V̄^c)]^+`(投影到非负)。作者引用[42][43]给出收敛到局部最优可行解的三条步长假设条件(§III-C)。

**策略网络与梯度(§III-E/F)**
- 离散动作策略梯度(式20):`∇_θ V_h^π(s) ≈ E_{a~π_θ}[∇_θ ln π_θ(a|s)(Q_h^π(s,a) - V_h^π(s) - α ln π_θ(a|s))]`。
- 策略损失(式19),其偏导为式(20)的负。
- 设备解耦结构(Fig 1):输入是状态向量,输出层维度为 Σ|A_i|(各设备挡位概率分开输出,每个设备一个 softmax),故参数随设备数线性增长;联合动作概率 `p(a) = ∏_i p_i(a_i)`。
- 序数编码(式21):`l'_ij = Σ_{m≤j} ln o_im + Σ_{m>j} ln(1-o_im)`,其中 `o_im = sigmoid(l_im)`;等价于把第 j 个动作编码成向量 [1,…,1,0,…,0](前 j 个为 1)。

**实现细节(§III-D + 附录 Algorithm 4)**
- 共 **9 个神经网络**:拉格朗日函数侧的 Q_{ψ1}^l, Q_{ψ2}^l, V_{φ}^l, V_{φtarg}^l,约束侧的 Q_{ψ1}^c, Q_{ψ2}^c, V_{φ}^c, V_{φtarg}^c,以及策略网络。
- 借鉴 SAC 的工程技巧:**clipped double-Q** 缓解过估计、目标 V 网络**延迟更新**(式30,延迟因子 ρ)。
- Q/V 训练目标见式(22)-(28),策略更新式(29),λ 更新式(31);用 Adam 优化器最小化 MSE。

## 数据集 & 实验设置
- 测试系统:**IEEE 4-bus、34-bus、123-bus** 配电测试馈线(§IV-A)。设备配置含电压调节器、OLTC、电容器组;调节器/OLTC 各 11 档(变比 0.95–1.05),电容 2 个状态(投/切)。
- 负荷数据:伦敦一年逐时智能电表能耗(原文引[47]),按 IEEE 标准算例的空间负荷分布缩放分配;10 个随机选周作样本外测试,其余训练。
- 电价 $40/MWh,每档切换成本 $0.1;DRL 的 reward/cost 由潮流仿真计算;电压违规上限 V̄^c 设为 **0**(只显式约束电压,线路潮流在此设定下自动满足)。
- 超参(Table I):隐层 (64,32)、relu、batch 256、λ 初值 0、γ=0.99、温度 α=0.02/0.02/0.05(三系统)、各网络步长 1e-3~5e-4、延迟因子 ρ=5e-4。
- 对比基线:RL 侧 **DQN**(把约束罚进 reward,罚系数 $1/违规)、**CPO**(constrained policy optimization,on-policy SOTA,采样步 5000);优化侧 **MICP**(单时段混合整数锥规划,逐小时滚动)、**MPC**(24 小时时域,假设未来已知),用 GUROBI 求解。

## 主要结果 & 结论（写方向，不堆精确数字）
- **样本效率**:在 4-bus 上,CSAC 与 DQN 约 1 万样本即收敛,而 on-policy 的 CPO 需约 50 万样本(supported,§IV-C 与 Fig 2-4)。off-policy 复用历史数据是关键差异。
- **整体性能(Table II)**:CSAC 在 **34-bus、123-bus 取得最高回报(AVR)**;在 4-bus 上为次优(MPC 更好)(supported)。
- **可扩展性**:随馈线规模增大,CSAC 的优势更明显(observed,§IV-D)。**DQN 无法在合理时间内解 123-bus**(动作-值方法需对 ∏|A_i| 个动作算 Q,组合爆炸);**MICP 在 34/123-bus 上 4 小时内解不出单个滚动步**;MPC 在 34/123-bus 上找不到滚动步解(Table II 脚注标 N/A)。
- **约束满足/安全**:CSAC **几乎始终满足电压约束**,4-bus、34-bus 上偶有轻微越限但**平均越限幅度远小于 0.01 标幺**;DQN、CPO 会出现显著电压违规(supported,Table II 的 AVV 列)。
- **乘子法优于固定罚(Table III)**:相比 SAC 配固定罚系数(C_V=0 / 0.1 / 1),CSAC 同时给出更高回报与更小越限——固定罚要么不安全要么过度保守,印证了用自适应 λ 的必要性(supported)。
- 结论(§V):CSAC 是 model-free、不依赖精确拓扑/参数的安全 off-policy DRL,在三个标准馈线上比 SOTA RL 与传统优化在样本效率、可扩展性、约束满足上更优(作者主张)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:离散档位控制设备(调节器/OLTC/电容)的配电网 VVC;系统规模较大、传统优化或 Q-learning 因组合爆炸/求解时间而失效时,CSAC 的线性参数增长与 off-policy 复用优势最突出。
- **管用前提**:有可供训练的运行/仿真数据(本文靠潮流仿真生成 reward/cost),且能容忍训练期的探索(在仿真而非真实电网上训练)。
- **不一定占优**:小系统(4-bus)上有"未来已知"假设的 MPC 回报更高——CSAC 的优势随规模增大才体现(observed)。
- **方法适配范围**:序数编码与设备解耦结构面向**离散有序档位**;连续动作需走原始 SAC 的重参数化(本文专门指出 SAC 的连续动作梯度不能直接用,故才设计离散版,§III-E)。
- **约束类型**:本文只显式约束电压(线路潮流在其设定下顺带满足);作者称其他约束可类似纳入(式7 注),但未实证。

## 核心贡献
- 把 VVC 建成 **CMDP** 而非"约束罚进 reward 的 MDP",显式建模物理运行约束(supported)。
- 提出 **CSAC**:在最大熵 SAC 上叠加乘子法处理 CMDP,得到 off-policy、安全、样本高效的算法(supported)。
- 设计**设备解耦策略网络** + **离散动作序数编码**,使参数随设备数线性增长、并引入挡位有序的归纳偏置以加速学习(supported)。
- 在 IEEE 4/34/123-bus 上与 5 个基线(DQN、CPO、MICP、MPC、固定罚 SAC)系统对比(supported)。

## 局限与我的质疑
1. **"安全"是软约束、训练期不保证安全**。算法保证的是收敛到可行解 + 测试期几乎不越限,但 reward/cost 在仿真中计算、λ 是事后惩罚机制,**训练过程中仍会产生违规**(Fig 2-4 早期越限很高)。标题的 "Safe" 更接近"收敛后约束满足",而非真实电网在线探索的安全——若直接上真实馈线,探索期的越限不可接受。作者自己也指出真实电网采样代价高(§III 开头),但全部实验都在仿真完成,**未验证真机/在线安全**。
2. **依赖潮流仿真生成奖励与成本**。号称 model-free 指的是策略不显式用拓扑/参数,但训练标签 R_t、R_t^c 来自潮流计算(§IV-A),这本身就需要相对准确的网络模型。所谓"不依赖精确模型"在落地时存在张力:没有可信仿真器就没有训练信号。
3. **收敛只给了局部最优 + 引用式保证**。式(18) 后的三条步长假设来自[42][43],本文未在自己设定下证明全局最优或唯一性;且承认"若局部最优不可行需用更大 λ 重启"(§III-C),实操有调参/重启负担。
4. **对比的公平性可质疑**。MPC 被赋予"未来负荷已知"的理想假设(§IV-B)却仍只在小系统赢,说明对比侧重可扩展性叙事;而 MICP/MPC 在大系统"解不出"用的是 4 小时计算上限,这个阈值的设定与求解器调优未充分讨论,"传统优化不可扩展"的结论有被框定的成分。
5. **泛化与鲁棒性未测**。仅用伦敦一份负荷数据、IEEE 标准算例;对负荷分布漂移、设备故障、拓扑变化、模型误差下的鲁棒性没有实验——对一个主打"不靠精确模型"的方法,这是关键缺口。
6. **与本研究主题(通用约束 RL 算法)相比的不足**:CSAC 本质是"SAC + 拉格朗日 + 离散动作工程化",约束处理思路与同期 RCPO/Lagrangian-SAC 类工作高度同源,算法层面的新颖性主要在**领域适配**(设备解耦 + 序数编码),而非约束 RL 机制本身;想借鉴其约束求解器可直接看式(15)-(18),但需注意它对离散有序动作的强假设,迁到连续/高维动作需重新设计策略头。
7. **数字细节须回 PDF 核**:样本量(~1万 vs ~50万)、AVR/AVV 具体值取自正文 §IV-C 与 Table II/III,精确数值以 PDF 为准,本总结只给量级与方向。
