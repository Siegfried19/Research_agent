# SimGenHOI: Physically Realistic Whole-Body Humanoid-Object Interaction via Generative Modeling and Reinforcement Learning
> Yuhang Lin, Yijia Xie, Jiahong Xie, Yuehao Huang, Ruoyu Wang, Jiajun Lv, Yukai Ma, Xingxing Zuo · 2025 · arXiv.org · 引用 3 · DOI 10.48550/arxiv.2508.14120

## 一句话
SimGenHOI 把"扩散生成模型"和"物理仿真里的强化学习控制策略"拼成一个统一框架,让 humanoid（拟人机器人）在物理引擎里完成全身、长时程、物理真实的人-物交互（搬箱子、举三脚架等），并用一套"生成模型与控制策略互相微调"的机制缓解二者衔接处的分布偏移（OOD）。

## 解决了什么问题
- 纯生成式（扩散）方法做 HOI 时容易产生穿模（penetration）、脚滑（foot sliding）、接触不真实、全身动作不物理这些 artifact，无法在物理环境里真正执行（原文 Abstract / Introduction）。
- 纯物理 RL 方法能保证物理合理，但作者指出现有代表性工作（如 Closed，Tevet et al. 2024）"局限于打击类简单交互，且难以泛化到高动态、长时程任务"（原文 Introduction）。
- 因此目标是：既可控（文本/路标条件）、又物理真实、还能长时程的人-物交互生成。

## 用什么方法解决的（含直觉：为什么 work）
框架由两块 + 一个互相微调环路组成（见原文 Figure 2、Algorithm 1）：

1. **HOI 生成模型（扩散，DiT 架构）**：以文本提示、物体几何、物体稀疏路标（waypoints）、初始 humanoid 姿态为条件,生成人体动作、物体轨迹、以及手脚的接触概率。关键创新是**不生成稠密逐帧动作,而是预测一组"关键动作（key actions）",再线性插值成平滑轨迹**。
   - 直觉:稠密序列冗余且难追踪;只预测少数"临界帧"能抓住交互的本质动态,天然支持长时程（一次预测覆盖更长时间跨度→更少迭代→更接近实时）,且插值出的运动更结构化、更好被控制策略跟踪。这一思路借鉴自 AWE（waypoint-based imitation, Shi et al. 2023）。

2. **接触感知全身控制策略（RL）**：在 Isaac Gym 里用 PPO 训练,跟踪生成的运动并纠正穿模/脚滑。基于预训练 humanoid 运动表征 PULSE（Luo et al. 2023a,在 AMASS 上训）提供运动先验。
   - 直觉:生成模型不预测精细手部姿态（缺 grasp pose),所以作者设计**接触促进型奖励（contact-promoting reward）**,"充分利用 RL 的探索性"让策略自己摸索出有效的抓握策略,而不是去模仿参考手部动作。物理仿真本身则负责消除穿模/脚滑。

3. **互相（交替）微调（mutual / alternating fine-tuning）**：在仿真里跟踪生成运动→收集"被成功跟踪、物理可行"的动作作为高质量样本→反过来微调扩散生成模型,使其生成更物理可行、更易跟踪的运动;改进后的生成模型又反过来微调控制策略。
   - 直觉:生成模型产出的运动对控制策略而言常是 OOD,交替微调让两者分布逐渐对齐,提升一致性（原文 "HOI In Physics Simulation - Fine-Tuning"）。

## 动机 & 背景
- HOI 生成是 CV / 具身 AI / 机器人交叉的核心问题;现有研究多聚焦"静态场景简单动作"（躺床、坐沙发）,忽视与动态物体的日常交互（原文 Introduction）。
- 领域存在"生成多样性 vs 物理真实"的根本权衡:生成模型多样可控但不物理,物理 RL 物理真实但难泛化、难长时程（原文 Introduction）。
- 相关工作三类:数据驱动动作合成（MDM、HumanML3D 等）；面向物体交互的扩散（OMOMO、InterDiff、CHOIS 等,但难消除脚滑/手穿模）；物理 humanoid 控制（DeepMimic、PULSE、OmniGrasp 等,但精细控制尤其手部仍是难点）。

## 方法细节
**运动表征(双表征)**：
- 生成模型输出人体姿态 X ∈ R^{T×D}（每帧含关节位置 + 6DOF 旋转,兼容 SMPL-X）、物体姿态 O ∈ R^{T×12}（全局位置 + 相对输入几何的旋转矩阵）、以及手脚接触概率 H ∈ R^{T×4}。
- 物理仿真里 humanoid 动作 x^sim 含关节旋转 θ_t ∈ R^{J×6}、位置 p_t ∈ R^{J×3}、线速度 v_t、角速度 ω_t（J 个肢节,含手与身体）；用 R2G/G2R 在"相对-全局"表征间转换。

**物体几何(BPS)**：用 Basis Point Set,在半径 1m 球体内采样基点,记录各基点到物体网格最近点的方向向量 G ∈ R^{1024×3},经 MLP 投影为 Ĝ ∈ R^{256×3}（沿用 OMOMO）。

**扩散模型(基于 DDPM,DiT/Transformer 去噪)**：
- 前向加噪 式(1) `q(τ_n|τ_{n-1}) = N(τ_n; √(1-β_n)·τ_{n-1}, β_n I)`；式(2) 为其连乘。
- 反向 式(3) `p_θ(τ_{n-1}|τ_n, C) = N(τ_{n-1}; μ_θ(τ_n,n,C), Σ_n)`,Σ_n 固定方差。
- 重参数化为**直接预测干净样本 τ_0**,训练目标 式(4) `L = E[ ||τ̂_θ(x_n, n, C) - τ_0||_1 ]`（L1 损失）。
- 条件 C 含:物体 BPS 几何嵌入 Ĝ、用于 in-filling/编辑的掩码姿态 S（S ∈ R^{T×(12+D)},保留初始姿态、物体 2D 稀疏路标 (x,y)、目标 3D 位置 (x,y,z)）、CLIP 文本嵌入 e_text;噪声级 n 经 MLP 与语言嵌入融合成统一条件向量。

**关键动作抽取(key actions)**：
- 给定稠密关节序列 J,找稀疏关键帧 K,线性插值重建 Ĵ=f(K)。质量用**加权重建误差** 式(5) `L(Ĵ,J) = max_t ( max_n ( w^n · ℓ(j_t^n, ĵ_t^n) ) )`,ℓ 为欧氏距离,w 为人工设的关节重要性权重（对关键关节给更高权重）。
- 递归算法:首末帧恒为关键帧；找当前最大重建误差的帧加为新关键帧,递归切分子段,直到重建误差低于阈值。
- 训练时对原序列用滑窗,每窗首帧为初始状态、其余填入抽取的关键动作,用 L1 损失对齐预测与真值。

**接触感知控制策略**：
- humanoid 状态 s_t = (s_t^p, s_t^g):本体感知 s_t^p = (q_t, q̇_t, β)（肢节位置、速度、可选体型 β）;参考状态 式(6) `s_t^g = (θ̂_{t+1}⊖θ_t, p̂_{t+1}-p_t, v̂_{t+1}-v_t, ω̂_{t+1}-ω_t, θ̂_{t+1}, p̂_{t+1})`,⊖ 为旋转差,参考速度由运动学规则算出。
- **接触引导(contact guidance)** c_t 编码"何时该抓/放"的潜在动作;物体观测 式(7) 在物体位姿/速度差之外加入 `ĉ_{t+1} ⊙ c_t`（⊙ 为 XNOR）等接触项。

**奖励设计**：策略只跟踪关键关节的预测姿态（无精细手姿参考）。
- 人体跟踪奖励 式(8) `r_t^g = w_jp·e^{-100||p̂_t-p_t||} + w_jr·e^{-10||θ̂_t⊖q_t||} + w_jv·e^{-0.1||v̂_t-v_t||} + w_jω·e^{-0.1||ω̂_t-ω_t||} + w_jc·||ĉ_t⊙c_t||`。
- 物体奖励 式(9) 形式类似(位置/朝向/线速度/角速度指数项)。
- 总奖励 式(10) `r_t = α·r_t^g + (1-α)·r_t^{g-obj}`。

**Interaction Early Termination**：在标准 ET 基础上,新增两个提前终止条件:(i) 物体关键点相对参考的平均偏差 > 0.5m;(ii) 预期的人-物接触连续缺失超过 10 帧。

**自回归长时程**：用重叠窗逐段生成,上一段末几帧作下一段初始条件;因预测稀疏关键动作覆盖更长时间跨度,显著减少所需迭代、改善实时性。

## 数据集 & 实验设置
- **训练/评测主数据**：FullBodyManipulation 数据集(即 OMOMO, Li/Wu/Liu 2023),10 小时高质量配对人-物交互,15 种物体;沿用 OMOMO 划分,15 个 subject 训练、留 2 个测试。
- 控制策略训练用带关节化手部的 SMPL-X body model 机器人。
- **生成指标四类**:条件匹配(物体轨迹起点 T_s / 终点 T_e / 中间 T_xy 的欧氏距离)；人体运动质量(脚滑 FS、脚高 H_feet)；交互质量(接触精度/召回/F1 C_prec/C_rec/C_F1、接触百分比 C_%、基于 SDF 的手穿模分数 P_hand)；与真值差异(MPJPE、root 平移 T_root、物体位置/朝向误差等)。
- **跟踪指标**(沿用 OmniGrasp, Luo et al. 2024):humanoid 位置/旋转误差 E_pos/E_rot、物体位置/旋转误差,接触成功率 Succ_cont、目标成功率 Succ_tgt(物体到达终点 0.5m 内)、跟踪时长。
- **基线**：InterDiff、MDM、OMOMO 改造适配;因本文只预测稀疏关键动作,为公平比较会在已知索引处插值恢复全序列。

## 主要结果 & 结论（写方向，不堆精确数字）
- 在 FullBodyManipulation 上,SimGenHOI 在条件匹配、交互质量、与真值差异等多维度上整体优于 InterDiff / MDM / OMOMO 系列基线(原文 Table 1) — supported。
- 增加扩散去噪步数(OURS_200→OURS_1000)有收益但**边际递减**,作者称性能在某规模后饱和 — supported。
- 去掉关键动作抽取权重 w_i 后多项指标明显下降;但作者指出此时手穿模分数 P_hand 反而更低,原因是模型抓不住精细接触、手离物体更远、网格碰撞更少(即"看着不穿模其实是没接触好") — observed。这条提示 P_hand 单看会误导。
- 纯插值生成的运动在物理相关指标(尤其脚部)较差,但**一旦经物理仿真跟踪,物理指标显著改善**;Table 2 中经物理跟踪的 SimGen-HOI 在脚高、脚滑、手穿模三项物理一致性上最好(手穿模降到约 0,见 Table 2) — supported。
- 跟踪/交互对比(Table 3, OMOMO 7 物体):SimGen-HOI 在接触成功率与目标成功率上达到 7/7,并在加速度/速度误差上最好;OmniGrasp 在物体位置/旋转误差上更低且目标成功率也 7/7,但作者强调 **OmniGrasp 严重依赖预抓取姿态(pre-grasped pose),对大物体易失败**,而本文不需精细 grasp pose、靠 RL 探索抓握 — observed（这是 7 条人工选定参考运动上的对比,样本小）。
- 消融(Table 4, OMOMO smallbox):完整模型成功率最高(约 41.67%);去关键动作→成功率与运动保真度下降;去接触引导→物体跟踪精度与成功交互下降(但**有意思的是 humanoid 位置误差 E_pos 反而更低**,因为没接触约束时策略转而优先跟踪人体参考动作);去微调→跟踪成功率下降 — supported。

## 适用边界（什么时候管用 / 什么时候不管用）
- 管用:文本 + 物体几何 + 稀疏路标 + 初始姿态驱动的全身搬运/操作类交互(搬箱、举三脚架、推物等),需要在物理引擎里可执行、且要长时程的场景。
- 相对强基线的优势:对比 OmniGrasp(物理 RL 抓取 SOTA 之一)在"无需预抓取姿态、能处理大物体"上更鲁棒,这是 observed 级别(7 个物体上的对比)。
- 可能不管用/未验证:依赖精细灵巧手部操作的任务(本文手姿不直接生成,靠 RL 探索 + GRIP 补抓握,精细灵巧度未单独验证);全部定量评测在单一数据集(OMOMO/FullBodyManipulation)上,跨数据集/真实机器人(sim-to-real)迁移**未给证据**;成功率绝对值不高(smallbox 约 41.67%),说明任务本身仍难。

## 核心贡献
1. 提出"预测稀疏关键动作 + 插值"的物理真实全身 HOI 生成范式,天然支持长时程并提升物理可行性。
2. 设计支持复杂人-物交互(超出简单搬运)的接触感知全身控制策略,含接触引导与接触促进奖励。
3. 提出生成模型与控制策略的**交替互相微调**,提升跟踪成功率与生成-执行一致性。
4. 在 FullBodyManipulation/OMOMO 上做了较系统的对比与消融,验证各组件作用。

## 局限与我的质疑
1. **评测域单一,泛化无证据**：所有定量结果都在 OMOMO/FullBodyManipulation 一个数据集族内;论文标题与摘要主张"realistic, diverse, physically plausible",但跨域、未见物体类别、真实机器人 sim-to-real 都未实验。"diverse" 的强度更接近 observed,不宜读成已证明的泛化。
2. **关键对比样本极小**：Table 3 仅 7 个人工选定参考运动、Table 4 消融在 smallbox 子集;"7/7 成功"这类数字样本太小,统计意义有限,不应当作强结论。且对 OmniGrasp 的优势叙述里,OmniGrasp 在 E_pos/E_rot 上其实更好,本文优势主要靠"无需预抓取"的定性论证支撑——这是合理但偏定性的主张。
3. **指标可被"假性改善"误导,作者自己也点到**：P_hand(手穿模)在 w/o w_i 时反而更低却是因为根本没接触好;类似地 w/o contact 时 E_pos 更低却成功率更差。说明单看某些物理/误差指标会得出反向结论,读者应结合成功率综合看;论文整体结论站得住,但若只摘单指标容易被误读。
4. **成功率绝对水平偏低**：smallbox 约 41.67% 的跟踪成功率说明该任务远未"解决",标题的 "Physically Realistic" 更多是相对基线的改善,而非高可靠执行;偏弱场景(小盒)尚且如此,大物体/复杂物体未给逐类成功率,难判断稳健性。
5. **手部灵巧操作仍是短板**：精细手姿不由生成模型产出,训练参考靠 GRIP 补、跟踪靠 RL 探索;论文未单独量化抓握质量(如抓握稳定性/滑脱),对"全身 whole-body"中最难的手部交互真实度,证据相对薄。
