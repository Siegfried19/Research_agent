# Secrets of RLHF in Large Language Models Part I: PPO
> Rui Zheng, Shihan Dou, Songyang Gao, Hua Yuan, Wei Shen, Binghai Wang, Yan Liu, Senjie Jin, Qin Liu, Yuhao Zhou, Limao Xiong, Lu Chen, Zhiheng Xi, Nuo Xu, Wenbin Lai, Minghao Zhu, Cheng‐Chang Chang, Zhangyue Yin, Rongxiang Weng, Wensen Cheng, Haoran Huang, Tianxiang Sun, Hang Yan, Tao Gui, Qi Zhang, Xipeng Qiu, Xuanjing Huang · 2023 · arXiv (Cornell University) · 引用 19 · DOI 10.48550/arxiv.2307.04964

## 一句话
这是一篇 RLHF 工程经验拆解报告：系统解剖 PPO 在语言模型对齐里的各个组件，指出"对策略的约束"是稳定训练的关键，并把一组有效实现技巧打包成 **PPO-max**，让 vanilla PPO 不再崩、能跑更长步数（supported）。

## 解决了什么问题
- RLHF 的 PPO 阶段在语言模型上极不稳定、对超参敏感，常常重复失败，作者要找出"哪些技巧关键、哪些指标能反映训练状态"。
- 一个具体病症叫 **pattern collapse（模式崩塌）**：vanilla PPO 训练中策略模型会"钻奖励模型的空子"（reward hacking），靠某些固定生成模式刷高 reward，但人类/GPT-4 评估并不认为更好（supported，见 §5.2、图4）。
- 作者明确指出：**reward 分数和训练 loss 都不能指示 PPO 是否在朝正确方向优化**（supported）——训练 loss 收敛得很稳，但奖励升高不代表策略行为变好。

## 用什么方法解决的（含直觉：为什么 work）
- 先把 RLHF 三阶段（SFT → 奖励模型 RM → PPO）逐部件拆开，再逐个验证 RL 文献里的实现技巧在语言模型场景是否有效。
- **核心直觉一：用"动作空间"的建模指标监控训练**，而不是只看 reward/loss。作者提出看 **perplexity（困惑度）、response length（回复长度）、policy 与 SFT 模型之间的 KL 散度**——这些比 reward 值和 loss 值更能反映训练稳定性（supported）。机制：崩塌的模型表现一致——回复变长、困惑度变低（生成模式趋于固化），KL 异常抬升说明策略漂出了奖励模型训练时见过的分布（OOD），奖励此时已"过优化"不可信。
- **核心直觉二：约束策略别漂太远**就是稳定训练的钥匙。崩塌源于"过优化把策略困进固定生成模式"，所以在 reward 层和 policy 层都加约束（normalize/clip + KL 惩罚），把更新幅度压住，策略就留在奖励模型可靠的区域里。
- **PPO-max** = 把验证有效的技巧集合起来并调好彼此干扰：基于历史均值/方差的 **reward normalization + clipping**、**token 级 KL 惩罚**、**critic 模型预训练**（取代学习率 warmup）、**小的 experience buffer**、**value function loss clipping**、**global gradient clipping**，并加 **PPO-ptx**（混入预训练语言建模损失）以减小对齐税（supported）。

## 动机 & 背景
- RLHF 被 OpenAI/Anthropic 验证为对齐语言模型与人类意图的有效路径，但成功训练需要：准确的奖励模型、稳定的超参、强健的 PPO 实现，三者缺一就容易把策略训崩。
- PPO 阶段要同时协调四个模型：policy、value(critic)、reward、reference（SFT），且语言环境里奖励稀疏、词空间探索低效，使 PPO 对超参极敏感。
- 作者动机是"实践出真知"（"practice makes perfect"）：代码级实现细节真实影响训练动力学，需要把这些常被论文略去的低层决策讲清楚。作者也开源了中英文奖励模型和 PPO-max 代码（github.com/OpenLMLab/MOSS-RLHF）。

## 方法细节
- **奖励建模（§3.1、§4）**：
  - 基础成对偏好损失 `L(ψ)=log σ(r(x,y_w) − r(x,y_l))`（式1，σ 为 sigmoid，y_w 优选/y_l 劣选）。
  - 加入对优选回复的自回归 LM 模仿损失（式2，权重 `β_rm`，实验取 `β_rm=1`），让模型同时"模仿"优选回复。
  - 总奖励含 KL 惩罚：`r_total = r(x,y) − η·KL(π_RL_φ(y|x), π_SFT(y|x))`（式3）。KL 项有两个作用（作者明述）：① 充当熵奖励、鼓励探索、防止过早收敛到单一模式；② 保证 RL 策略输出不偏离奖励模型训练时见过的样本分布。
- **GAE（§3.2.2）**：TD-k 回报式(7)、k 步优势式(8)，GAE 是 k 步优势的指数加权平均 `Â_t^GAE(γ,λ) = Σ_l (γλ)^l δ_{t+l}`（式9），`δ_t=r_t+γV(s_{t+1})−V(s_t)`。λ=0 高偏差、λ=1 高方差，GAE 平滑插值在两者之间（这是 GAE 的标准动机）。
- **PPO 目标（§3.2.3）**：TRPO 硬约束式(13)；PPO-penalty 式(14)；**PPO-clip** `L=Ê[min(ρ_t·Â_t, clip(ρ_t,1−ε,1+ε)·Â_t)]`（式15，ρ_t 为新旧策略概率比）；critic 的 MSE loss 式(16)；**PPO-ptx** `L_ppo-ptx = L_ppo-clip + λ_ptx·E_{D_pretrain}[log(π_RL(x))]`（式17）。
- **被系统验证的 12 个实现技巧（图5）**：token 级 KL 惩罚、importance sampling、entropy bonus、reward scaling、reward normalization+clipping、advantage normalization+clipping、value function loss clipping、critic 初始化、policy 初始化、GAE、clipped surrogate、global gradient clipping。其中 PPO-max 采用了带★的几项（token 级 KL 惩罚、reward normalization+clipping、value loss clipping、critic 初始化、global gradient clipping）。
- **Score reparameterization（§5.3.1）**：reward normalization+clipping 式(18) `r̃ = clip((r_n−r̄)/σ(r), −δ, δ)`。作者发现 reward scaling 单独并不能引导正确优化（observed）；advantage normalization 在 minibatch 级做。结论倾向"在 reward 层施加更紧的约束"。
- **Policy constraints（§5.3.2）**：token 级 KL 惩罚式(19) `r_total(x,y_i)=r(x,y_i) − η·KL(π_RL_θ(y_i|x), π_SFT(y_i|x))`，λ 设 0.05。

## 数据集 & 实验设置
- **奖励模型数据**：英文用 HH-RLHF 160k 成对样本（118k helpful + 42k harmless），起点 LLaMA-7B；中文用自雇标注员标的 39k 成对样本（31k helpful + 8k harmless），起点 OpenChineseLLaMA。RM 训练 1000 步、`β_rm=1`、学习率 5e-6。
- **PPO 阶段**：SFT/policy/reference 用 7B SFT 模型（OpenChineseLLaMA 上 1M 指令数据微调 2 epoch）；HH 数据集 8k harmless + 20k helpful query；采样 batch 128、训练 batch 32，policy/critic 学习率 5e-7 / 1.65e-6。
- **硬件**：每台 8×80G A100 + 1TB RAM + 128 CPU，用 ZeRO2 + 梯度检查点。
- **评估**：人类标注偏好 + GPT-4 as judge（LLM-as-a-judge），对比 SFT 基线与 ChatGPT(gpt-3.5-turbo-0613)；NLU 用中文 C-Eval（约 13k 多选、52 学科）few-shot 测。

## 主要结果 & 结论（写方向，不堆精确数字）
- **监控指标更有用**：perplexity / response length / KL散度 比 reward值和loss值更能反映训练稳定性（supported）。
- **vanilla PPO 会模式崩塌 / 奖励作弊**：reward 升高但人类与 GPT-4 评估不变好，崩塌模型一致表现为回复更长、困惑度更低（supported，§5.2、图4）。
- **策略约束是稳定训练的关键**：在 §5.3.2 中，只有"对策略熵或 KL 散度的惩罚"能提供**长期稳定**的优化；importance sampling 能进一步稳住训练但**牺牲最终性能**（observed）；entropy bonus 对参数/实现极敏感、相对 KL 惩罚没有明显优势（observed），故作者推荐 KL 惩罚而非直接约束策略空间。
- **初始化**：policy 模型必须经 SFT 初始化——不经 SFT 直接 PPO 会导致语言能力严重退化、训练失败，作者称 SFT 策略是 PPO 的**必要前提**（supported）；critic 初始化方式对收敛影响不大，但 critic 预训练能提供更稳的优势估计，作者建议用 critic 预训练替代学习率 warmup（observed→supported）。
- **PPO-max 能稳定跑 10K 步**（图9，reward 平稳上升、KL 受控），缓解了 vanilla PPO 的不稳定（supported）。
- **RLHF 优于 SFT**：在 helpful/harmless、中英文上，人类与 GPT-4 评估都偏好 RLHF（supported，图10）。harmless 提升尤其明显（如英文 harmless 人评 RLHF 胜率远高于 SFT，具体数值见 §6.2、图10）。
- **对比 ChatGPT**：RLHF 仍落后 ChatGPT，但显著缩小了"被 ChatGPT 打败"的比例（英文 harmless 败率从 45%→24%、中文 37%→29%，见 §6.3、图11）——是"减少失败"而非"超越"（observed）。
- **对齐税**：PPO 后 NLU(C-Eval) 能力下降，PPO-ptx 能缓解这一下降（supported，图12）。

## 适用边界（什么时候管用 / 什么时候不管用）
- 适用：用 PPO 对**已做过 SFT 的** 7B/13B 量级语言模型做 RLHF 对齐，且训练不稳/崩塌时——PPO-max 这套约束技巧能稳住训练并跑长步数。
- 跟谁比：基线主要是 **vanilla PPO（同作者实现）** 和 **SFT 模型**；与强模型 ChatGPT 比仍处下风。所以"PPO-max 有效"是相对 vanilla PPO 的稳定性提升，不是"对齐质量超越 SFOTA"。
- 不太管用/未验证：未经 SFT 的策略直接 PPO 不行；reward scaling 单独不能引导正确优化；entropy bonus 在不当配置下不稳。
- 边界提示：reward 分数本身不可靠，不能作为"训练期性能/早停"的判据——这意味着把这套方法迁到新任务时，需要另找监控信号（作者推荐 KL/困惑度/长度）。

## 核心贡献
- 开源有较好跨模型泛化能力的中英文奖励模型，降低重新标注偏好数据的成本。
- 对 PPO 内部机制做系统拆解，识别出 pattern collapse 问题，并提出"用动作空间建模指标监控训练"+"策略约束是关键"两条经验。
- 提出并开源 **PPO-max**（一组校准过、相互不打架的实现技巧），保证训练稳定、可跑长步数。

## 局限与我的质疑
- **作者自述局限**：① 只在 7B 规模做，未研究模型/数据规模对 RLHF 的影响（scaling law 缺失）；② 奖励模型数据（开源英文 + 少量自建中文）的质量与数量不足以全面评估 RM；③ 评估主要靠人评 + GPT-4，没用大量公开 benchmark；④ 训练期 reward 分数不能可靠预测 RLHF 性能，仍缺好的训练期性能指标。
- **我的质疑（接地于本文设定）**：
  1. **PPO-max 是"技巧合集"而非受控消融**——文中多数结论来自图4/6/7/8 的曲线趋势观察，缺少把每个技巧单独加/减的严格因子化消融与显著性统计；"哪个技巧贡献多少"难以从本文定量归因（这点作者自己也指出 reward 不可靠，更让趋势判读偏主观）。
  2. **评估可能存在偏置**：GPT-4 as judge 与人评虽"趋势一致"，但二者都偏好更长/更详尽的回复，而本文又指出崩塌模型恰恰输出更长——"RLHF 更受偏好"是否部分来自长度偏好而非真实质量，文中未排除。
  3. **奖励模型本身的弱点被轻描淡写**：表1已显示 RM 会给"更长但编造事实"的回复更高分（reward 本就 misspecified），而整套 PPO-max 是在这样一个有缺陷的 RM 上优化稳定性——稳定地优化一个错的目标，未必导向更好的对齐，这层张力本文没有正面回答。
  4. **与本研究主题（RL 训练/稳定性通用方法）的差距**：结论高度绑定 RLHF/语言模型的特定设定（KL-to-SFT、奖励作弊、对齐税），其"策略约束=稳定钥匙"的经验能否迁移到非语言的通用 RL 任务，本文未验证，迁移时需谨慎。
  5. 文中多处引用附录（A/B.1–B.3/C.4）承载更细的消融与超参，正文给的多为方向性结论；若要复现具体 δ/η/λ 取值与逐项消融，需回到对应附录与开源代码核对 `[原文未提具体在正文]`。
