# From Sparse to Dense: Toddler-inspired Reward Transition in Goal-Oriented Reinforcement Learning

## 一句话
本文借鉴幼儿"先在稀疏奖励下自由探索、再转向稠密奖励的目标导向行为"这一发展规律,提出在训练中途把**稀疏奖励切换为基于势函数的稠密奖励(Sparse-to-Dense, S2D)**的课程式奖励过渡,在多个目标导向 RL 任务上观察到比纯稀疏/纯稠密/反向(Dense-to-Sparse)/内在动机更高的成功率与样本效率,并用策略损失地形(更平滑、更宽的极小)解释其机制。

## 解决了什么问题
- 目标导向 RL 中"探索 vs 利用"难平衡:纯稀疏奖励促探索但学得慢,纯稠密奖励反馈频繁但易让智能体只顾短期、陷入次优——尤其在高维、第一人称图像输入的 3D 类真实环境里更严重。(原文 §1)
- 作者主张:不该全程只用一种奖励密度,而应**随训练动态调整奖励密度**(reward transition),且方向应是"稀疏→稠密"(模仿幼儿先自由探索、再目标导向)。

## 用什么方法解决的（含直觉：为什么 work）
- **核心:S2D 奖励过渡课程。** 训练前期只给稀疏奖励(仅在智能体进入目标半径内才有奖励,稀疏阶段附加势函数项 F₁=0);训练进行到某个切换点后,改为在稀疏奖励之上叠加**基于势函数的稠密奖励(PBRS)**,引导智能体高效到达目标。(§4.1, Algorithm 1)
- **保持最优策略不变的理论保证(PBRS):** 稠密项 Fᵢ(s,a)=E_{s′∼P(s,a)}[γΦᵢ(s′)−Φᵢ(s)](式1);代入 Q 值后只把 Q 平移一个常数 −Φ(s₀),不改变 argmax,故"加稠密奖励"不会改变最优策略集(引 Ng et al. 1999)。势函数取 Φ(s):=diam_p(S)−‖s−g‖_p(式4),即"状态集直径减去当前位置到目标 g 的距离"(p=2 欧氏 / p=1 曼哈顿)。
- **S2D-课程的形式定义(Def 2):** 奖励支撑集随阶段单调变稠 supp(R₁)⊆supp(R₂)⊆…⊆supp(R_N),且各阶段最优策略集嵌套 Π₁*⊇Π₂*⊇…⊇Π_N*——保证每个稠密阶段与稀疏阶段共享同一组最优策略。
- **为什么 work(机制/直觉):**
  - 前期稀疏=**自由探索期**:智能体在没有稠密引导时会广泛探索,积累多样经验,形成"鲁棒的初始参数 / 类似认知地图的内部表征"(类比 Tolman 迷宫的潜在学习 latent learning);随后稠密奖励再"利用"这些表征高效收敛。(§7.4, §6.4.4)
  - **损失地形平滑→宽极小:** 作者用自研 Cross-Density Visualizer 可视化奖励过渡后的策略损失地形,观察到 S2D 过渡显著**减小局部极小的深度、平滑地形**,产生更宽的极小;宽极小对参数/数据扰动不敏感,因而泛化更好。(§6.2, §6.3, 图5)
- **过渡时机:** 消融发现最佳切换点大致落在训练的**前 1/3(前四分之一附近)**,作者类比幼儿"早期关键期";具体时机随任务复杂度变(§7.1)。三个候选切换点 C₁/C₂/C₃ 对应 t∈{1N,2N,3N},N≈总训练量的 1/12(§5.1.2, 附录表4)。

## 动机 & 背景
- 生物/发展学启发:幼儿先作为"天生的探索者"无目标地接触环境(稀疏奖励),随成长转向受稠密反馈(视觉线索/反馈)引导的目标导向行为(§1, 图1)。
- 方法谱系:本文把**势函数奖励塑形(PBRS)**与**课程学习(curriculum learning)**结合——课程是一串难度递增的 MDP(Def 1),这里"难度"体现为奖励密度递增。作者自述本文是其早期工作[47](AAAI 2024)的延伸(§1 贡献列表)。
- 相关背景被明确归为他人工作:内在动机(NGU、RND、curiosity/next-state prediction)、wide minima / sharpness 文献、Tolman 认知地图实验,均作为背景或基线引用,**非本文原创结论**。

## 方法细节
- **四种奖励策略基线(图2, §5.1.1):** Only Sparse(全程稀疏)、Only Dense(全程 PBRS 稠密)、**S2D**(稀疏→稠密)、**D2S**(稠密→稀疏,S2D 的反向对照)。另加内在动机基线:离散环境用 **NGU(Never Give Up)**,连续控制用 **RND**。
- **算法载体:** 主实验用 **SAC**(LunarLander/CartPole/UR5);ViZDoom 用 **A3C**;Minecraft 迷宫/RWARE/Gridworld 用 **PPO**;Gridworld 另用 **DQN**。部分可观测的 playroom 用带 **RNN/LSTM** 的循环 actor-critic。(表5, 附录)
- **算法流程(Algorithm 1):** 维护回放缓冲;每步用当前阶段 k 的奖励 r̃ₜ=rₜ+F_k(sₜ,aₜ) 存样并更新策略;当累计步数 T≥T_k 时进入下一阶段 k←k+1,直到终止步 T_d。
- **锐度(sharpness)度量(式5):** max_{‖ε‖_p≤ρ} L_π(θ+ε)−L_π(θ),用 ρ=0.02、p=q=2 估计,锐度越低→极小越宽(借 Foret et al. 的 SAM 形式)。
- **诊断工具:** (1) Cross-Density Visualizer 画奖励过渡后的 3D 策略损失地形;(2) RNN 隐状态跨训练检查点的平均成对 ℓ₂ 距离,衡量内部表征收敛速度(Algorithm 2);(3) 动作频率分析(直行/左转/右转占比)看策略稳定性;(4) 2D 轨迹可视化看探索范围。

## 数据集 & 实验设置
- **环境(表1、表3、图3):** LunarLander-V2;CartPole-Reacher 与 UR5-Reacher(MuJoCo,连续控制、目标随机生成);ViZDoom-Seen / ViZDoom-Unseen(第一人称导航,Unseen 换了三种墙面贴图测泛化);ViZDoom-FourObjects(Level1–3,递增难度,附录);Minecraft Cross Maze(评估期出现训练未见过的目标点 Goal 2)与 Toddler Playroom Maze(高维第一人称、目标随机);RWARE 货架配送(多子目标,Level1–3);Gridworld。
- **稀疏/稠密奖励形式:** 稀疏=到达目标半径内才给奖;稠密=在其上叠加 γΦ(s_{t+1})−Φ(s_t) 的势函数项(各环境阈值见表1)。
- **种子/试验数(注意不一致):** 正文 §11.4 称"每个环境至少用了五个以上随机种子";表2 标注"至少六次试验";但附录部分实验试验数更少且文中表述不统一——例如 ViZDoom-FourObjects 任务设置正文写"均值与标准差基于三次试验"而其图19 caption 又写"五次试验";RWARE 写五次(图20),playroom 写六个种子(图7);动作频率分析基于"三个 rollout episode/五次试验以上"。**因此不能笼统断言所有环境都≥5种子。**
- **过渡时机超参(表4):** 各环境 N 不同(如 LunarLander 总训练1M帧、C₁/C₂/C₃=100k/200k/400k);RWARE 为三阶段、C₁/C₂/C₃=1M/2M/3M。

## 主要结果 & 结论（写方向，不堆精确数字）
- **S2D 在所测目标导向任务上整体优于 Only Sparse / Only Dense / D2S / 内在动机**(成功率、样本效率),作者称这一方向在离散与连续动作空间都成立 —— supported(跨多个环境系统实验)。
- **D2S 在所有环境都低于 S2D**,作者据此强调"顺序很重要、稀疏在前是关键"(§6.1.1)—— supported。
- **内在动机基线(NGU/RND)探索强但偏向找新状态、不重达成目标**,在 LunarLander/UR5 等接近零分,难以与 S2D 比 —— observed(特定任务上)。
- **UR5 连续控制(更需精细控制):** 表现最佳 S2D(C₃)的成功率指标≈94(表2),明显高于 Only Dense(≈64)、而 Only Sparse 与三种 D2S 都≈0 —— observed(单一较难任务)。
- **泛化:** 在 ViZDoom-Unseen(换墙面贴图)与 Cross Maze 评估期新目标点(Goal 2)上,S2D 比基线泛化更好、样本效率更高 —— observed(这些泛化设定下)。
- **宽极小/锐度(方向需谨慎,见原 Table 2):**
  - 在 **LunarLander 与 CartPole**,表现最佳的 S2D 配置同时取得**最低锐度(最宽极小)** —— observed。
  - 在 **UR5 锐度并非 S2D 最低**:锐度绝对最低的是 Only Sparse(≈0.00)与 D2S(≈0.47/0.52),但它们性能≈0;作者将这种"低锐度"判为梯度停滞/几乎不更新导致的**退化人为低锐度**(§7.3),而表现最佳的 S2D(C₃)锐度≈0.61(表2)。即"S2D=最宽极小"只在能正常学到东西的方法之间成立,不可外推为绝对最低。—— observed,带例外。
- **内部表征/策略稳定性:** 过渡后 S2D 的 RNN 特征距离下降更快(收敛更快更稳,图9a);动作频率上 Only Dense 即便看似收敛仍持续不稳(疑似落入次优局部极小),S2D 在五次试验间保持一致稳定(§6.4.5)—— observed。
- **过渡时机消融(ViZDoom-FourObjects, 附录14.1):** 过渡时机确实关键;Level1/Level3 在最早的 1M-onset(C₁)最好,Level2 在 2M(C₂)最好,纯稠密(C₅)最差甚至学不会;熵消融显示过渡前用较大熵(0.1>0.01>0.001)更好,支持"早期自由探索重要" —— observed。
- **多子目标任务(RWARE, 附录14.2):** 方向相反——这里**较晚的三阶段过渡 C₃ 最好**,而过早过渡(C₁/C₂,3M 步之前)反而欠佳;说明复杂多子目标任务需要更长的早期探索期,且作者自承"带子目标任务的最优过渡时机仍是难题"(§14.2.6)—— observed。
- **损失地形平滑普遍性:** 在 SAC 之外,作者称在 PPO、DQN(及 Gridworld)也观察到 S2D 过渡带来类似平滑效果(§6.2, 附录C, 图23–25)—— observed(主要靠可视化呈现)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用:** 目标导向、可定义"到目标距离"作为势函数的任务(导航/到达类),尤其 Only Sparse 学不动(LunarLander、CartPole 默认稀疏表现差)或需要泛化到新视觉/新目标位置的设定。
- **依赖几何结构:** 稠密奖励是基于"到目标的距离"的势函数,需要已知目标位置且距离度量有意义;对没有这种几何/距离结构的任务能否适用,原文未验证(`[原文未提]`此类任务)。
- **时机敏感:** 过渡太早或太晚都会损失收益;不同任务最优时机不同(简单任务≈前 1/3,UR5 需更长探索,多子目标 RWARE 需更晚过渡)——**没有一个跨任务通用的固定时机**,当前靠人工预设。
- **多子目标任务上不确定:** 作者明确把"带子目标任务的最优奖励过渡策略"列为未解难题。
- **对比性质:** 主要与自身奖励调度的消融(Only Sparse/Dense/D2S)和内在动机(NGU/RND)比,**未与其它课程学习/奖励塑形调度的强基线系统对比**,故"优于其它策略"应理解为"优于这些对照",而非战胜该领域所有 SOTA。

## 核心贡献
- 提出并形式化"幼儿启发的 S2D 奖励过渡课程"(Def 2),用 PBRS 保证过渡过程中最优策略不变。
- 在多类环境(连续控制、第一人称 3D 导航、Minecraft 迷宫、RWARE)上系统验证 S2D 优于纯稀疏/纯稠密/D2S/内在动机,并测了泛化(ViZDoom-Unseen、未见目标点)。
- 用自研 Cross-Density Visualizer + 锐度度量,把性能提升与"损失地形平滑、宽极小"联系起来,作为机制性解释。
- 用 Tolman 迷宫(认知地图/潜在学习)与幼儿关键期重新诠释"早期自由探索"的价值,并辅以 RNN 表征收敛、动作频率、轨迹可视化等多维证据。

## 局限与我的质疑
1. **预印本,未经同行评审**(arXiv,2025-01-30;引用计数为0),其结论尤其是机制性主张应保留判断。它是作者 AAAI 2024 工作[47]的扩展版。
2. **"幼儿启发"主要是动机性叙事,非被检验的因果机制。** 方法实质是"PBRS + 稀疏→稠密课程",这两者都是既有技术;论文没有任何实验把"toddler 发展"与算法效果建立因果联系,生物类比更多是包装。
3. **方差大 + 逐环境挑配置,削弱稳健性主张。** 表2 中多处标准差巨大(如 LunarLander 的 S2D(C₂) 性能 63.40±160.55、锐度 1231.93±2424.61),而"最佳"是逐环境从 C₁/C₂/C₃ 里各挑一个加粗——这更像**每个环境单独调过渡时机**,而非一个固定设置就普遍最优;加上前述试验数(3/5/6)不一致,统计可靠性存疑。
4. **锐度→泛化是相关而非因果,且锐度本身可被退化情形污染。** 作者自己的 UR5 例子说明锐度可因"几乎不更新/梯度停滞"而人为变低;用 sharpness 当泛化代理在文献中本就有争议,本文未给因果证据。
5. **损失地形"平滑"多靠定性 3D 可视化(自研工具)呈现**,除锐度外缺少定量、可复现的地形指标,说服力受限于"看上去更平滑"。
6. **稠密奖励依赖已知目标位置 + 距离度量**,对"无法定义有意义距离势函数"的任务能否迁移完全未测,适用范围可能被过度泛化解读。
7. **缺少外部强基线对比。** 对照基本是自身奖励调度的变体与两种内在动机方法,没有与其它 curriculum/reward-shaping 调度方法、或目标条件 RL/HER 类方法的横向比较,因此"S2D 更优"的外部参照偏弱。
