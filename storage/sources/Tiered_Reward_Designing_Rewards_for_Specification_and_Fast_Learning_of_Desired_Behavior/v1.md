# Tiered Reward: Designing Rewards for Specification and Fast Learning of Desired Behavior
> Zhiyuan Zhou, Shreyas Sundara Raman, Henry Sowerby, Michael L. Littman · 2022 · arXiv · 引用 0 · DOI arxiv:2212.03733

## 一句话
提出一族"分层奖励"(Tiered Reward)——把状态按好坏分成若干层、相邻层奖励值按 1/(1−γ) 比例指数放大且全为非正的、与环境无关的奖励结构,在"到达目标/避开障碍"这类任务上**既能可证明地诱导出 Pareto 最优策略,又能让多种 RL 算法学得更快**。

## 解决了什么问题
- 奖励设计(reward-design)有两道难关:第一是**如何指定"什么行为是想要的"**(在随机环境里,"快 5% 到目标但多 8% 概率撞障碍"哪个更好难以说清);第二是**如何把这个偏好写成一个能诱导该行为、且让 agent 学得快的奖励函数**。
- 作者要解决的具体设定是"目标—障碍"(goal–obstacle)类任务:状态分为目标态、障碍态、背景态,目标与障碍都是吸收态;希望"更快到目标、更晚/更少撞障碍"。
- 传统困难:即便"看起来合理"的奖励也可能诱导出次优策略;而为快速学习设计奖励的已有方法(如 Sowerby 2022、Devidze 2021)往往要**已知环境转移动态**去解优化问题,实践中不可得(§2)。

## 用什么方法解决的（含直觉：为什么 work）
- **第一步:用 Pareto 最优性给策略空间定序(解"指定偏好")**。定义 o_t=第 t 步处于障碍层 S₁ 的概率、g_t=处于目标层 S₃ 的概率。策略 π^A **支配(dominates)** π^B 当且仅当对所有 t 同时满足 Σo^A ≤ Σo^B 且 Σg^A ≥ Σg^B(且不全相等)(§4)。直觉:"到目标更快、撞障碍更晚"就更好;无法互相支配的策略视为不可比但都属"想要的"。不被任何策略支配的集合就是 **Pareto 最优集**(有限策略+传递性 ⇒ 非空)。作者用 Pareto 最优替代标准 RL 的"唯一最优",以回避随机环境里说不清的权衡。
- **第二步:用 Tiered Reward 保证诱导出 Pareto 最优策略(解"写成奖励")**。把状态空间划成 k 层 S₁<…<S_k(层内同奖励、层间越高越好)。
  - 3 层定义(Def 5.2):R(s)∈{r_obs, r_background, r_goal},约束 **r_obs < (1/(1−γ))·r_background < r_goal**。**Theorem 5.3**:满足此约束的 Tiered Reward 在 3 层 MDP 中**可证明 Pareto 最优**(附录 A 给反证法证明)。
  - k 层定义(Def 5.4,k>3):奖励值满足 **r₁ < (1/(1−γ))r₂ < (1/(1−γ))²r₃ < … < (1/(1−γ))^{k−1}r_k ≤ 0**,即所有层奖励**非正**、相邻层按因子 1/(1−γ) 指数放大,目标层吸收。
- **为什么 work(机制,作者给的直觉)**:
  - 中间项 (1/(1−γ))·r_background 恰等于"无限期一直待在背景层"的累积折扣回报 ((1+γ+γ²+…)r_background)。所以只要"目标处的奖励比无限期游荡更诱人、障碍比之更不诱人",奖励就会推动 agent **尽早到目标、避开障碍**(§5.1)。
  - **全非正(step penalty)+ 价值函数零初始化 ⇒ 乐观初值**:每一步都受罚,使 agent 对没试过的状态—动作抱有"可能更好"的乐观,从而**主动定向探索**(§5.2,引 Koenig & Simmons 1993、Sowerby 2022)。
  - **层间指数放大 ⇒ 棘轮式(ratchet-like)策略**:高层奖励指数级高于低层,促使 agent "尽快爬到更高层、且绝不回落到低层"(§5.2)。
  - **Theorem 5.5**:在 k 层 Tiered Reward 下,诱导的最优策略**对最差层 S₁ 的累积访问概率最小、对其余各好层的累积访问概率最大**(附录 B 证明)。

## 动机 & 背景
- 作者把奖励视作"一种编程语言"——人类作为行为正确性的裁定者,负责"编写"这段程序(reward-design problem,§1)。
- 论文明确两步走:先"指定想要什么行为",再"设计诱导它的奖励";第一步难在没有普适偏好、要显式写出所有权衡;第二步难在有些策略甚至无法用马尔可夫(基于状态)的奖励表达(引 Abel 2021)。
- 与相关工作的差异(§2):偏好型 RL 需人造偏好数据集;多目标 RL 是"激励所有目标",本文是"用单个奖励在多行为间做权衡"的正交方向;奖励机(reward machine)是非马尔可夫的有限状态机;时序逻辑(LTL)更表达但易状态爆炸——本文提供"不同的表达力—可解性折中"。

## 方法细节
- **问题设定**:MDP,奖励仅定义在状态上 R:S→ℝ(为简化设计);目标/障碍为吸收态;以"指定一组想要的(Pareto 最优)策略 Π、再造出使最优策略落入 Π 的奖励"为目标(§3)。
- **k-Tier MDP(Def 3.1)**:状态分 k 个互斥层,R(s)=r_i (s∈S_i),且 r₁<r₂<…<r_k。框架很通用——任何"奖励定义在状态上"的有限 MDP 都能写成 Tier MDP(把同奖励状态归一层);但它**最适合有明确好/坏状态(目标、障碍、子目标)**的任务。
- **k 层比 3 层更严(§5.2)**:Def 5.4 比 Def 5.2 更强,因为它额外要求所有层奖励非正(为利用 step-penalty 的快学习好处),且能把每个子目标各设一层。论文指出:任意一层 i 视角下,把 1..i−1 当 S₁、i 当 S₂、i+1..k 当 S₃,即退化为一个 3 层 Tiered Reward,故由 Theorem 5.3 仍 Pareto 最优。
- **实验里采用的具体取值**:k-Tiered Reward 取 r_i = 0 (i=k);r_i = (1/(1−γ))·r_{i+1} − δ (i<k),δ 为满足严格不等式的小常数(§6,tabular 实验 δ=0.1)。
- **基线设计**:
  - **Action Penalty**(Koenig & Simmons 1993):每步 −1、到目标 +1,只需知道目标位置。
  - **Tier Based Shaping**(用 Ng et al. 1999 势函数塑形):取势函数 Φ(s)=R_tier(s),R_tbs(s,a,s′)=R_penalty(s)+γΦ(s′)−Φ(s),作为与 Tiered Reward 信息量相当的"公平"对照(避免用最优价值塑形带来的循环论证)。

## 数据集 & 实验设置
- **表格域**:Flag Grid(Ng 1999 的 6 层 MDP,需按序捡 4 面旗再到目标,80% 成功率)、Chain(90 态一维)、Grid(9×9)、Frozen Lake(带洞,滑)、Wall Grid(有墙+熔岩)。算法用 **Q-Learning**(乐观初值,α=0.90,γ∈{0.99,0.95,0.90,0.85})与模型型 **RMAX**(r_max=10⁵)。层数据按到目标的 L1 距离(或 L1 到目标与起点加权 2:1)分配。
- **深度 RL 域**:MiniGrid 的 EmptyGrid、FourRooms、DoorKey,图像观测,算法用 **PPO**(ImpalaCNN,γ=0.5,200k 步,30 seeds;γ 取 0.5 是为缓解奖励缩放数值问题,见附录 H)。DoorKey 按已完成子目标(拿钥匙/开门/到目标)分层。奖励线性缩放到 [−1,0]。**评估用 MiniGrid 原始奖励**(1−0.9·步数/最大步数,失败 0)衡量"多快学会指定行为"。
- 误差棒为 30(表格部分某些为 300)seeds 标准差。

## 主要结果 & 结论（写方向，不堆精确数字）
- 在 Flag Grid 上,Tiered Reward 用 Q-Learning **学得最快**,优于 action penalty 与 tier-based shaping(Fig 2,supported)。
- **Tier-Based Shaping 在零初始化 Q 值下表现极差(比 action penalty 还差数个量级)**:因为带折扣时,当 s、s′ 同层,塑形项 F=γΦ(s′)−Φ(s)>0,使该转移变成正奖励,**鼓励利用而非探索**,导致探索无方向、学习很慢(Fig 2 左,observed/作者机制解释)。把所有方法 Q 值都乐观初始化(Q_init=10⁵)后差距缩小,但 **Tiered Reward 仍持续胜出**(Fig 2 右,supported)。
- 深度 RL(MiniGrid)三环境上,Tiered Reward(PPO)学得最快,优于两基线(Fig 4,supported);FourRooms 上初期慢于 tier-based shaping、但后期反超(observed)。FourRooms 三种奖励方差都大,作者归因于其是"难探索"问题。
- **层数影响**:总体上层数越多、学得越快(更多环境信息辅助设计),Tiered Reward 在表格域上一致胜过 action penalty、至少不差于(常远好于)tier-based shaping(Fig 5,supported)。但在深度 RL 缩放到 [−1,0] 时,**层数过多会因数值问题反伤性能**:FourRooms 上 5 层最佳、超过 5 层单调变差;高层奖励缩放后趋近 0(可低到 10⁻⁶~10⁻¹⁵)而"在数值精度下变得难以区分"(Fig 6 + 附录 H 表 5/6,observed)。
- **理论结论(已证明)**:Tiered Reward 在 3 层 MDP 诱导 Pareto 最优策略(Thm 5.3),并使最差层访问最少、好层访问最多(Thm 5.5)。作者还指出在满足 r_lava<r_background<r_goal 的 1000 个随机采样奖励里,**90.5% 是 Pareto-被支配的**(§5),说明"看似合理"的奖励大多不够好,凸显 Tiered Reward 约束的价值(supported)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:有清晰"好/坏状态"(目标、障碍、可分层子目标)的目标—障碍类任务;吸收型目标;希望"既正确指定偏好又加速学习";想要**与具体环境无关、与 RL 算法无关**(Q-Learning/RMAX/PPO 均验证)的奖励设计。
- **需要的环境知识**:虽奖励值本身与环境无关,但**把状态划分到各层仍需环境特定知识**(如到目标的 L1 距离、子目标定义)(§5.1 作者自述)。
- **不太管用 / 要小心**:层数很多 + 把奖励缩放到 [−1,0] 时,高层奖励数值塌缩、层间难分,性能反降(深度 RL 尤甚);难探索环境(如 FourRooms)结果方差大、不稳定;最优层数往往需先验或经验确定。
- 折扣因子要落在 γ∈(0,1);深度 RL 里作者用较小 γ=0.5 来压数值问题。

## 核心贡献
1. 用 Pareto 最优性给整个策略空间定义严格偏序,在随机环境里"指定想要的行为"(§4)。
2. 提出与环境无关的 Tiered Reward 奖励族,并**证明**其在 3 层 MDP 诱导 Pareto 最优策略(Thm 5.3)、且最小化最差层、最大化好层的累积访问(Thm 5.5)。
3. 在多个表格域(Q-Learning、RMAX)与深度 RL 域(PPO/MiniGrid)上**实证** Tiered Reward 加速学习、且不依赖具体 RL 算法。

## 局限与我的质疑
1. **预印本,未经同行评审**(arXiv,引用 0):理论证明(附录 A/B)看上去自洽,但定理只覆盖"目标—障碍/层结构"这一窄设定,且 Pareto 最优是相当弱的最优性概念(很多不可比策略都算"想要的"),不等于通常意义的"最好策略"——对其"可证明诱导想要行为"的卖点要按字面理解,别外推。
2. **"快速学习"只有实证、没有理论保证**:作者在结论里明确把"Tiered Reward 渐近更快学习的理论保证"列为未来工作。因此"学得更快"是 observed/supported 级,且全部在小型 grid 类环境(表格 + MiniGrid)上,**未在连续控制、大规模或真实任务上验证**——与本研究主题(可与环境交互的复杂 agent / 通用 RL 工具箱)相比,任务规模和复杂度都偏低。
3. **数值问题是真实硬伤且未解决**:层数一多、缩放到 [−1,0] 后高层奖励塌到 10⁻¹⁵ 量级、层间不可分,导致"层越多越好"的卖点在深度 RL 里反转(FourRooms >5 层单调变差)。作者只是"假设更好的缩放/裁剪能解决"并留作未来工作,并未给出方案。
4. **分层仍需环境知识**:号称"环境无关",但层划分(L1 距离/子目标)恰恰要环境特定信息,这弱化了"无需了解环境即可设计奖励"的叙述;对不易定义"到目标距离/子目标"的任务(如开放式交互),如何分层并不显然。
5. **基线偏弱/对照设计可质疑**:主要对手是 action penalty 和自造的 tier-based shaping;后者在零初始化下表现极差,部分是"势函数+折扣使同层转移变正奖励"这一可预期的塑形/初值交互,作者也承认"不是要论证塑形无效"。是否对比了更强的现代探索/奖励设计方法,文中不充分,胜负关系应限定在这些特定基线与初值设置下解读。
6. **关键超参的敏感性未充分剖析**:δ、γ、Q 初值都明显影响结论(如 γ=0.5 是为压数值问题而选),但缺少系统的敏感性分析来说明结论的稳健边界。
