# Extreme Value Policy Optimization for Safe Reinforcement Learning
> Shiqing Gao, Yihan Zhou, Shuai Shao, Haoyu Luo, Yiheng Bing, Jiaxin Ding, Luoyi Fu, Xinbing Wang · 2026 · International Conference on Machine Learning · 引用 1 · DOI 10.48550/arxiv.2601.12008

## 一句话
EVO 把极值理论（EVT）引入约束强化学习：用广义帕累托分布（GPD）显式建模**代价分布的尾部**，并把约束从"期望代价 ≤ 阈值"改成"代价的极值分位数 ≤ 阈值"，从而压住那些虽稀有但高危的违例事件。

## 解决了什么问题
- 现有约束强化学习（CRL）多数把安全约束写成"期望累积代价 ≤ 阈值 d"（如 CPO、PID-Lagrangian），即 J_C(π) ≤ d。
- 作者指出：期望满足约束**只保证平均合规，忽略了代价分布的内在波动**，尾部仍可能频繁违例（论文 Figure 1a：即便期望低于阈值，仍有相当概率落进"违例区"）。
- 这类尾部"极端代价样本"（论文称类比"黑天鹅 / black swan incidents"）在自动驾驶、金融交易等安全攸关场景后果严重，但因**出现概率低、样本稀少、获取代价高**而难以建模，导致尾部估计方差大。
- 此前的概率约束 / 风险约束方法（WCSAC 用高斯近似代价分布算 CVaR；QCPO 用 VaR）作者认为**高斯近似拟合不准尾部衰减**，且都没有充分利用极端样本本身的学习信号。

## 用什么方法解决的（含直觉：为什么 work）
- **核心直觉**：尾部不该用整体分布（高斯）去硬套——EVT 的 Pickands 定理保证"超过某阈值 t 的超额量"渐近服从 GPD（论文 Theorem 3.1 / Eq.2-3）。所以只对超过安全边界的那部分"峰值样本"拟合一个 GPD，就能更准地刻画稀有大代价该有多大、出现多频繁。论文用 KS 检验经验验证 GPD 比高斯拟合尾部更准（Figure 7，GPD 的 KS 统计量普遍低于高斯）。supported
- **极值分位数约束（extreme quantile constraint）**：把约束目标改为 `q_{μ+ν} ≤ d`，其中 q_μ 是"安全边界"分位数、q_{μ+ν} 是把尾部极值纳入后的"风险边界"。安全边界 q_μ 取期望累积代价（q_μ = J_C(π)），风险边界写成 `q_{μ+ν} = q_μ + q^H_{ν/(1-μ)}`（Eq.9），即在期望之上再加一截由 GPD 算出的尾部超额量。直觉：约束不再只盯平均值，而是盯"把尾部算进来后的那个更靠右的分位点"，留出安全裕度。
- **最终优化目标**（Eq.11/12）：`max J_R(π)  s.t.  q_μ + q^H_{ν/(1-μ)} ≤ d`，即在最大化回报的同时，让"期望代价 + GPD 尾部修正项"不超过阈值。
- **用 CPO 求解（EVO-CPO）**：在信赖域内对回报目标与代价约束做一阶展开、对 KL 散度做二阶展开，用原始-对偶 / 共轭梯度法更新（附录 A，Eq.31-36）。GPD 的形状参数 ξ 与尺度参数 σ 用极大似然估计（Eq.14），风险边界由 Eq.15 闭式给出。
- **极值优先回放（Extreme Prioritization Resampling）**：对回报和代价**各自**拟合 GPD，超过各自风险边界的样本被识别为"极端奖励样本 / 极端代价样本"。回放时按其在 GPD 下的分位数水平赋优先级，优先级分数 `p = ω_r + ω_c`（奖励分位数 + 代价分位数，Eq.16），回放概率按 Eq.17 归一化。直觉：稀有但信息量大的极端样本（极端奖励指示任务目标、极端代价指示约束边界）平时被淹没，主动放大它们的学习信号。supported（消融 Figure 5a/5b 显示去掉后性能下降）
- **离策略重要性重采样降方差**：尾部样本太少→GPD 拟合方差大、单个极值影响过大。用历史策略 π_0 产生的存储样本，经重要性比 `A'_R = (π/π_0)·A_R`、`C' = (π/π_0)·C`（Eq.18）校正分布漂移后扩充极端样本集，降低 GPD 拟合方差（理论 Theorem 4.3，经验 Figure 6：去掉离策略样本后代价/分位数标准差明显上升）。supported
- **自适应 ν**：尾部"利用范围"ν 不是固定的——用 `L(ν) = -ν(J_C(π)-d)` 自适应（Eq.75-77）：当 J_C > d 时 ν 增大→抬高 GPD 分位数→更保守；J_C < d 时 ν 减小→鼓励探索。

## 动机 & 背景
- CMDP 框架：状态/动作/奖励 R_f/代价 C_f/转移/折扣 γ；目标是约束优化 `max J_R(π) s.t. J_C(π) ≤ d`（Eq.1）。
- 相关工作分三类并各指其短：期望约束（CPO/FOCOPS/CUP 等，捕捉不到代价分布的波动）、概率约束（WCSAC 高斯近似拟合不准尾部、QCPO 用 VaR 但没充分利用极端样本）、以及 EVT 在 RL 的先例 EVAC（NS et al. 2023，用 EVT 降极端**回报**方差做风险厌恶，但**不处理约束满足**）。EVO 自我定位为"把 EVT 用于约束侧、既建模极端样本又降方差"。

## 方法细节
- 累积代价分布拆成"主体 + 尾部"两段（Eq.7）：超过安全边界 q_μ 的超额变量 Z = C - q_μ 用 GPD 建模其 CDF F_H(z)。
- 关键关系：`P(C ≤ q_μ + z) = μ + (1-μ)P(Z ≤ z)`（Eq.8）；密度关系 `f_C(q_μ+z) = (1-μ)f_H(z)`（Eq.10）。
- 信赖域代理目标（Eq.13）：`max E[A_R^{π_k}] s.t. J_C(π_k) + (1/(1-γ))E[A_C^{π_k}] + q^H_{ν/(1-μ)} ≤ d, D_KL(π‖π_k) ≤ δ`。
- GPD 的 MLE 对数似然：`log L(ξ,σ) = -N_μ log σ - (1 + 1/ξ)Σ log(1 + (ξ/σ)Y_i)`（Eq.14），Y_i 为峰值集样本，N_μ 为峰值数。
- 算法流程（Algorithm 1）：每轮采样轨迹→更新价值网络 V_R、V_C→离策略重采样调整样本→拟合代价 GPD、算风险边界→拟合奖励 GPD→算极值优先级→用新目标更新策略（on-policy）。
- **理论结果**（均在约束**期望**层面，且证明依附录）：
  - Theorem 4.1：EVO 的约束违例期望上界比 CPO 更紧（多减了一项风险边界 q^H ≥ 0）；并给出"零违例利用范围 ν_0"，当 q^H 大于某 TV 散度项时保证更新后策略 π_{k+1} **严格**满足约束（Eq.19-20，证明 B.1）。strong（作者明确强主张，但属理论命题）
  - Theorem 4.2：当安全边界取期望代价时，EVO 违例概率 `P(C>d) < (J(E+1))^{-1/ξ}`，比期望型 CRL 的 `P(C>d) < 1-μ` 低一个 ν_0 的裕度（Eq.21-22，证明 B.2）。strong（理论）
  - Theorem 4.3：EVO 估计分位数的方差 Ω_1 低于分位数回归的方差 Ω_2（Eq.23-25 / 66-67，证明 B.3）；方差随用于估计的样本数 N 增大而减小——故离策略扩充样本能降方差。strong（理论）

## 数据集 & 实验设置
- 两类环境：**Safety Gymnasium**（导航类，模拟简化自动驾驶：Point/Car 机器人 × Goal/Circle 任务，PointGoal1 含 8 个 Hazards）+ **Safety MuJoCo**（速度类，Ant/HalfCheetah/Humanoid/Swimmer，超速给代价信号 1）。基于 Omnisafe（Ji et al. 2024）。
- 训练 10^7 步、最大轨迹长 1000、**6 个随机种子**、报告均值±方差。约束阈值 d = 25（Figure 3/4 虚线）。
- 主基线：CPO（期望约束）、WCSAC（概率约束）、Saute、Simmer（状态增强、强调零违例）；附录另加 PPO-Lagrangian、RCPO。
- 网络都是 2 层 ×64、tanh、actor/critic lr=1e-3、γ=0.99、GAE=0.95、信赖域 0.01（与 CPO 同；Table 3）。硬件单卡 RTX 3090。
- 自设综合指标 `ratio = AverageReturn / (ConstraintViolationRate + ξ)`（Eq.74），同时衡量回报与违例率。

## 主要结果 & 结论（写方向，不堆精确数字）
- 在 Safety Gymnasium 8 个学习曲线上，EVO 快速收敛到可行域并**全程维持接近零的约束违例**，回报与 CPO 相当（Figure 3）。observed
- 在 Safety MuJoCo 上，当初始策略落在可行域内时，EVO 训练全程零约束违例，经验印证 Theorem 4.1 的零违例保证（Figure 4）。observed
- 作者强调：CPO 在 SafetyPointGoal1-v0 上违反了约束阈值，因此它回报比 EVO 高**不代表更好的策略**——这是把"安全前提下的回报"作为正确比较口径。supported
- WCSAC 在 SafetyCarCircle1-v0、SafetyHalfCheetahVelocity-v1 出现明显违例，作者归因于其没充分考虑极端样本影响。observed
- 综合指标 ratio：EVO 在 8 个环境的 7 个取得最高（Table 2，唯 SafetySwimmerVelocity 被 Saute 略胜），即在"回报 vs 违例"权衡上整体占优。supported
- 消融（Figure 5a/5b）：把 EVT 约束换成固定常数分位数约束→约束满足但策略性能下降；去掉极值优先回放→性能退化；去掉离策略重采样→GPD 拟合方差上升（Figure 6）。三个组件各有贡献。supported
- GPD 拟合：KS 检验下 GPD 对尾部的拟合普遍优于高斯（Figure 7）。supported
- 样本量敏感性（Figure 8）：拟合 GPD 用的样本越多通常约束满足越好；但 EVO 在**少至 10 个样本**时（SafetyPointCircle1-v0）仍能维持较好的约束满足与性能。observed
- 训练开销（Table 1）：相比 CPO 仅增加有限训练时间，GPD 拟合只占几秒，开销小。supported

## 适用边界（什么时候管用 / 什么时候不管用）
- 面向**on-policy 信赖域**式 CRL，实现搭在 CPO 上（EVO-CPO）；论文也提供了 PPO-Lag/RCPO 的对比，但方法本体是 CPO 变体。
- 最有效的前提：**初始策略已在可行域内**——此时零违例保证（Theorem 4.1）才在经验上成立；初始不可行时是"快速收敛进可行域后再维持"。observed
- 依赖 GPD 能拟合好尾部；论文自承当"极端值与正常值差距很小（gap subtle）"时 GPD 可能拟合不佳（EVT 要求阈值 t 足够大），建议先做非线性变换放大差异——属未落实的补救建议。
- 验证局限于**低维仿真**安全基准（Safety Gym / MuJoCo，state/action 维度都不高），未在高维像素观测或真实机器人上验证。
- 代价信号是相对密集的（如超速=1、撞 Hazard 计代价），对极端**稀疏**代价场景是否还有足够峰值样本拟合 GPD，论文未直接考察。

## 核心贡献
1. 把 EVT 引入 CRL，用 GPD 显式建模奖励/代价分布尾部，针对"稀有高危事件"难处理这一空白。
2. 提出基于 GPD 的极值分位数约束（Eq.6/11）+ 极值优先回放机制（Eq.16/17），放大稀有高信息样本的学习信号。
3. 给出理论与实验双重证据：更低的期望约束违例上界（Th.4.1）、更低的违例概率（Th.4.2）、比分位数回归更低的方差（Th.4.3）。代码开源（github.com/ShiqingGao/EVO，见正文）。

## 局限与我的质疑
1. **理论保证的口径要看清**：Theorem 4.1/4.2 给的仍是对**期望**约束违例的上界与违例**概率**的界，而非确定性的"每条轨迹都不违例"；且零违例利用范围 ν_0 严格成立需要"q^H 大于某 TV 散度项"等条件、并以"初始可行"为前提。把它当成无条件"训练期零违例"会过度解读——经验上的零违例也只在初始可行的 MuJoCo 子集观察到（observed）。
2. **q_μ 的设定有循环嫌疑**：安全边界 q_μ 取期望累积代价（q_μ = J_C），再在其上叠 GPD 尾部得风险边界。即"分位数"的基准锚在期望上，而非真正从数据估计的某个高分位（如 VaR）。这使方法更像"给期望约束加一个 EVT 校正余量"，与作者批评高斯近似/期望法的力度相比，定位需更谨慎看待。
3. **GPD 适用性的现实风险**：EVT 要求阈值足够大、尾部样本足够，而强约束/安全策略恰恰会让极端代价越来越稀少（论文自己在 Figure 6 讨论里也提到代价极值随训练越来越罕见）。靠离策略重采样补样本，但重要性比在策略漂移大时方差爆炸——这套降方差手段在长训练后期是否仍稳，论文未给后期专门分析。
4. **基线强度与公平性**：对比的是 CPO/WCSAC/Saute/Simmer 等较经典基线，附录补了 PPO-Lag/RCPO；但近年更强的安全 RL 方法（如 CUP、FOCOPS、各类基于编辑/投影的方法）在 related work 提到却未纳入实验对比。"7/8 环境 ratio 最高"中的 ratio 是作者自定义指标（Eq.74），其归一化与 ξ 取值会影响排名，作为主要卖点需保留态度。
5. **结果呈现偏定性**：主结果靠学习曲线 + 自设 ratio 表，正文未给出标准的"最终回报±std / 最终违例率"汇总数值表，难以精确复核各方法终态差距；多数曲线方差带较宽（6 seeds），部分环境 EVO 与 CPO 回报几乎重叠，"competitive"的措辞是恰当的，但也意味着 EVO 的收益主要在**安全侧**而非回报侧。
6. **与本研究主题（RL 通用工具箱/约束优化）的契合与不足**：方法新颖点（EVT 建模尾部）确实是 SAC/PPO 主流之外的一条思路，可作为"约束 RL 中处理重尾代价"的工具收录；但它绑定在 on-policy CPO 框架、且只验证于低维仿真，作为"通用工具"的可迁移性（到 off-policy actor-critic、到高维任务）尚未被本文证明。
