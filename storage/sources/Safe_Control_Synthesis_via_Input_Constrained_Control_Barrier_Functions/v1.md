# Safe Control Synthesis via Input Constrained Control Barrier Functions
> Devansh Agrawal, Dimitra Panagou · 2021 · arXiv · 引用 0 · DOI 10.1109/cdc45484.2021.9682938

## 一句话
本文提出"输入约束控制障碍函数"(ICCBF):当输入饱和导致整个安全集无法被维持时，构造性地在安全集内挖出一个能被输入受限控制器保持前向不变的"内安全集"，并给出实时可解的 QP 控制器；ICCBF 是高阶 CBF(HOCBF) 的推广，可处理非均匀相对阶系统。

## 解决了什么问题
- 经典 CBF/CBF-QP 的安全保证默认控制权限足够大；但当控制输入有界(`u ∈ U`)时，往往**只有安全集的一个子集**才可能被保持前向不变。
- 原文用一个标量例子点明该问题:系统 `ẋ = x + u, u ∈ [−1,1]`，安全集 `S = {x ≤ 2}`、`h(x) = 2 − x`;在边界 `x = 2` 处 `ḣ = −2 − u ≤ −1 < 0`，故**任何容许输入都无法阻止轨迹离开 S**，S 在输入约束下不可前向不变(见 Example 1)。
- 已有求"可保持子集"的方法各有短板:Hamilton-Jacobi 可达性分析需解状态空间上的 PDE、平方和(SOS)半定规划要求动力学/约束可表为多项式，两者"随状态维数扩展性差"(scale poorly with dimension)；还有方法只针对特定类(如 Euler-Lagrange 系统)。
- 正式目标(Problem 1):给定系统 (1)，找一个闭子集 `C* ⊆ S` 和反馈控制器 `u : C* → U`，使任意 `x(0) ∈ C*` 的闭环轨迹满足 `x(t) ∈ C*` 对所有 `t ≥ 0` 成立。

## 用什么方法解决的（含直觉：为什么 work）
- **核心构造(递归挖内集)**:从 `b₀(x) = h(x)` 出发，递归定义
  `b_{i+1}(x) = inf_{u∈U} [ L_f b_i(x) + L_g b_i(x) u + α_i(b_i(x)) ]`，
  每个 `α_i` 是用户指定的 class-K 函数，直到第 N 步得 `b_N`。对应集合 `C_i = {x : b_i(x) ≥ 0}`，内安全集 `C* = C₀ ∩ C₁ ∩ … ∩ C_N`(`C₀ = S`)。
- **为什么对 u 取下确界(infimum)是关键直觉**:对 `u` 取 inf 后，`b_i` 只依赖状态 `x`、不再依赖 `u`。若某点同时落在 `∂S` 与 `C₁` 上(即 `h=0` 且 `b₁≥0`)，则由定义 `inf_u ḣ ≥ 0`，意味着"**对任意容许输入 ḣ 都 ≥ 0**"——闭环向量场必落在 S 的切锥内，没有任何轨迹能从这种点穿出 S(式 (9))。这就是"内集能兜底"的机制:把"存在性"问题转成"对所有 u 成立"的状态条件。
- **逐层兜底的链式逻辑**:任何让 `C₁` 前向不变的控制器，也让 `S ∩ C₁` 前向不变(用反证+连续性:若轨迹要破 S，必先经过 `∂S ∩ C₁`，但那里 `ḣ ≥ 0`，矛盾)。若某个 `α₀` 选得不好、`C₁` 没法被保持，就再挖一层 `b₂/C₂`，递归到 `b_N`。
- **ICCBF 的定义条件(Def. 3)**:若存在 class-K 函数 `α_N` 使
  `sup_{u∈U} [ L_f b_N(x) + L_g b_N(x) u + α_N(b_N(x)) ] ≥ 0, ∀x ∈ C*`，
  则 `b_N` 是 ICCBF。注意它只要求在 `C*`(而非整个 `C_N`)上成立，故**不要求 `b_N` 在 `C_N` 上是 ZCBF**。
- **主结果(Theorem 1)**:若 `b_N` 是 ICCBF，则任何满足 `u(x) ∈ K_ICCBF(x) = {u ∈ U : L_f b_N + L_g b_N u ≥ −α_N(b_N)}` 的 Lipschitz 控制器都能让 `C*` 前向不变。证明用 Nagumo 切锥定理:在 `∂C*` 上对每个"恰好为 0"的 `b_i` 验证 `ḃ_i ≥ 0`——`i<N` 的层由 inf 构造天然 `ḃ_i ≥ 0` 对所有 `u∈U` 成立，`i=N` 层由 ICCBF 条件保证。
- **QP 控制器(Theorem 3)**:设 `U` 是凸多面体 `{u : Au ≤ B}`，控制器取
  `u*(x) = argmin_u  ½ uᵀH(x)u + F(x)ᵀu  s.t.  L_f b_N + L_g b_N u ≥ −α_N(b_N),  u ∈ U`。
  该 QP 实时可解，计算复杂度"与 [2],[10] 的 CBF-QP 几乎相同"，因为最终只用到 `b_N` 及其导数。
- **与 HOCBF 的关系(Remark 1)**:相对阶为 2 时 `L_g h = 0`，于是 `b₁ = L_f h + α₀(h)`，恰好是 HOCBF 的构造;对相对阶 `ρ`，ICCBF 的前 `ρ` 个表达式与 HOCBF 相同。故 **ICCBF 是 HOCBF 的推广**，且通过取 `N ≥ 最大相对阶` 可处理**非均匀相对阶**系统。

## 动机 & 背景
- CBF-QP 已成为安全关键控制的主流低层综合手段:实时求 QP，保证轨迹留在安全集内。
- 缺口:主流 CBF 工作假设控制权限充足；输入约束下整体安全集常不可保持，需要可计算的"内安全集 + 配套控制器"，且要避开 HJ-PDE / SOS 的维数与多项式限制。
- 一个有用特例——简单 ICCBF(simple ICCBF, Def. 4 / Thm. 2 / Remark 3):若 `C*` 是 `C_N` 的**严格**子集(`C* ⊂ C_N`)，则 `C* ∩ ∂C_N = ∅`，于是**任意** Lipschitz `u ∈ U` 都能保持 `C*`。直觉:此时 `C*` 边界处无受控的、自由动力学 `f(x)` 已主导把系统推向安全，"不需要专门的安全控制器"。

## 方法细节
- 全程针对控制仿射系统 `ẋ = f(x) + g(x)u`，`f,g` 已知且足够光滑、状态可测;安全集 `S = {h ≥ 0}` 假定闭、非空、单连通。
- 用 Nagumo 定理(Lemma 1)及其在 `h≥0` 下的简化(Lemma 2):`S` 前向不变 ⟺ `L_f h + L_g h u ≥ 0` 在 `∂S` 上成立。
- 设计自由度:`N`、每层 class-K 函数 `α_i`、QP 的代价 `H、F`。这些**由用户/工程主观选取**(原文 ACC 里直言 `N=2` 和 `α` 是"arbitrarily"选的)。
- ICCBF 验证(原文用于检验给定 `b_N` 是否合格):解
  `γ = min_{x∈C*} sup_{u∈U} [ ḃ_N(x,u) + α_N(b_N(x)) ]`，当且仅当该问题可行且 `γ ≥ 0` 时 `b_N` 为有效 ICCBF。原文指出该问题"一般是非线性非凸"，但可用标准非线性优化软件求解。
- 符号计算:`b_N` 及其导数表达式可能很长，ACC 用 Mathematica 做符号推导，rendezvous 用 Julia `ForwardDiff.jl` 自动微分。

## 数据集 & 实验设置
- 无数据集——是两个仿真控制案例(无学习/无 RL)。
- **案例一 自适应巡航(ACC)**，取自 [10]:状态 `x = [d, v]ᵀ`(车距、车速)，安全约束 `d ≥ 1.8v`(`h = x₁ − 1.8x₂`)，输入 `u`(加速度)受限 `−0.25 ≤ u ≤ 0.25`(约 0.25g 最大减速)。选 `N=2`，`α₀=4h, α₁=7√h, α₂=2h`;期望加速度由 CLF `V=(x₂−v_max)²`(`v_max=24`)给出。对比对象=带输入裁剪的 CLF-CBF-QP 控制器 [10]。
- **案例二 自主交会(Autonomous Rendezvous)**:追踪航天器(点质量)与旋转目标(如 ISS)交会，5 维状态(相对位置/速度 + 目标角 ψ)。用**完整非线性**相对运动方程(非线性化 Clohessy-Wiltshire)；安全约束=视线(LOS)锥 `h = cosθ − cosγ`(`γ=10°`)；推力 1-范数受限 `|u_x|+|u_y| ≤ 0.25 kN`。`N=2`，`α₂ = (0.05+k)h` 中 `k>0` 由 QP 自行最小化(如 [4]);目标从 100 m 抵近到 3 m。

## 主要结果 & 结论（写方向，不堆精确数字）
- ACC:ICCBF-QP 全程保持可行且安全，而 CLF-CBF-QP 因撞上输入上限被迫离开安全集——直观原因是 ICCBF **提前刹车**(约 t≈2.9 s 起，而对比方法约 t≈5 s 才动、t≈5.9 s 撞限)。结论方向:**在该 ACC 任务上，考虑输入约束的 ICCBF-QP 保持安全，不考虑输入约束的 CLF-CBF-QP 失败**(observed,见图 2(e–g))。
- ACC 中数值验证 `b₂` 为合法 ICCBF:解得 `γ = 2.33 ≥ 0`(出处:§IV-A,作为可行性证据，非性能卖点)。
- 交会:ICCBF-QP 完成从 (100,−10) m 的成功转移，**全程满足 LOS 约束**且推力始终在 1-范数界内(observed,见图 3(c–g))。该案例无基线对照，仅作可行性演示。
- 总体结论:方法把输入约束**显式纳入** CBF 构造，理论上(Thm. 1/3)保证内安全集 `C*` 前向不变，从而 `h(x(t)) ≥ 0` 始终成立(strong——这是有完整证明的数学主张，但成立前提见下"适用边界")。

## 适用边界（什么时候管用 / 什么时候不管用）
- 适用:控制仿射、`f,g` 已知且光滑、状态全可测的确定性系统;希望在**已知输入界**下拿到带前向不变性证明的安全控制器;尤其当 HJ/SOS 因维数或多项式假设不适用、或系统存在**高阶/非均匀相对阶**时。
- 计算上轻:最终只需在线解一个 QP，复杂度与普通 CBF-QP 相当——适合实时。
- **不**直接适用/需谨慎:`f,g` 未知或有显著模型失配、有噪声/扰动(原文把鲁棒性明确列为未来工作，**未做**鲁棒性分析);非控制仿射或输入集非凸多面体(QP 形式要求 `U` 为凸多面体);需要离线找到合格 `b_N`——而找 `N`、各 `α_i` 目前靠手调，验证 `b_N` 还要解一个非凸优化。
- 与本研究主题(CBF 安全增强 + RL)的契合度:本文**完全不涉及学习/RL**，是纯模型已知的几何/集不变性方法;可作为"把输入约束塞进 CBF 安全层"的理论基座，但要嫁接到 RL/数据驱动还需补模型不确定性与无模型设定的处理。

## 核心贡献
- 提出 ICCBF 概念:在输入约束下构造性地给出安全集内可被保持的内安全集 `C*` 及配套控制器(原子化解决 Problem 1)。
- 证明 ICCBF 是 HOCBF 的严格推广，并能处理**非均匀相对阶**系统(Remark 1)。
- 给出实时可解的 QP 综合(Thm. 3)与一个"无需安全控制器"的特例——简单 ICCBF(Thm. 2/Remark 3)。
- 两个非平凡案例(ACC、含完整非线性动力学的航天器交会)验证可行性，提供开源代码与动画([17],GitHub: dev10110/Input-Constrained-Control-Barrier-Functions)。

## 局限与我的质疑
1. **构造高度依赖手调、缺乏自动化**:`N`、每个 `α_i`(ACC 里 `α₀=4h, α₁=7√h, α₂=2h` 明说是"arbitrarily"选)都靠人猜;不同选择得到不同(可能为空或过小的)`C*`，论文未给如何系统选取或保证 `C*` 非空的指引(作者把"自动搜索 ICCBF"列为未来工作)。这使方法距离"即插即用"较远。
2. **验证步骤本身是非凸全局优化**:判定 `b_N` 是否为 ICCBF 要解 `min_x sup_u […] ≥ 0`，原文承认"一般非线性非凸"。对高维系统这步可能和它要取代的 HJ/SOS 一样难;论文没给该验证的可扩展性或失败处理，"比可达性方法更省"只是停留在期望(future work),**未做复杂度对比**。
3. **实验对照偏弱、范围窄**:ACC 仅与一个**不考虑输入约束**的 CLF-CBF-QP 比——后者在输入饱和下失败几乎是设计上的必然，这更像"证明问题存在"而非证明 ICCBF 比强基线(如 HJ 可达、MPC)更优;交会案例**根本没有基线**。所谓优势是 observed(两个低维玩具/演示任务)，**不能**外推为"全面优于现有可达性方法"。
4. **零鲁棒性保证**:全部前向不变性证明建立在 `f,g` 精确已知、无噪声、无扰动、状态完美可测之上。现实中模型失配或测量噪声会直接破坏 `ḃ_i ≥ 0` 的边界论证，安全保证可能失效;作者也承认鲁棒性"could be investigated",即当前**未证明**。
5. **`C*` 的保守性未被量化**:挖内集天然丢掉一部分本可安全的状态，`α` 选得越保守 `C*` 越小、可行域越窄。论文没分析 `C*` 相对真实最大可控不变集的保守程度，工程上可能过度牺牲性能/可达区域。
6. **与本研究主题的距离**:无任何学习成分，假设全模型已知,因此不能直接当作"RL 安全盾"使用;若用于 RL，需先解决其未触及的模型不确定性、在线可行性与无模型估计问题——这点本文未涉及。
