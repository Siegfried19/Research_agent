# Locomotion Beyond Feet
> Tae Hoon Yang, Haochen Shi, Jiacheng Hu, Zhicong Zhang, Daniel Jiang, Weizhuo Wang, Yao He, Zhen Wu, Yuming Chen, Yifan Hou, Monroe Kennedy, Shuran Song, C. Karen Liu · 2026 · arXiv · 引用 0 · DOI arxiv:2601.03607

## 一句话
本文提出 Locomotion Beyond Feet——一套让人形机器人**主动用手、膝、肘、躯干等"脚以外的身体部位"建立接触**来穿越极端地形（钻椅子下、翻膝高墙、爬上/下膝高平台、上/下陡楼梯）的整套系统，核心做法是**用"物理可行的关键帧动画"提供运动先验、再用 RL（DeepMimic 式动作追踪）把它变成鲁棒可上机的策略**，并配一个**视觉技能规划器**把九种分立技能串起来。

## 解决了什么问题
- 主流人形/双足运动方法几乎只依赖腿的步态，在低净空（椅下）、膝高墙/平台、陡楼梯这类环境里"只用脚"要么不可行、要么必须做剧烈动作。
- 人类在极端环境里会自然调用手、膝、肘、躯干建立**额外接触点**来稳定和支撑身体；本文要把这种"全身富接触"的策略迁移到人形机器人上。
- 作者点出两大挑战：(1) 富接触环境需要**策略性的接触规划 + 鲁棒控制**；(2) 不同地形需要**根本不同的运动技能**（走/爬/钻），单一策略不合适。

## 用什么方法解决的（含直觉：为什么 work）
- **核心洞见**：传统关键帧动画与 RL 高度互补。关键帧能直观编码"人对运动技能与物理交互的知识"（哪一刻该把哪个接触点放哪、关节大致什么构型），且**直接在机器人状态空间里设计参考动作、绕开了人-机本体差异（embodiment gap）**——不像 mocap 重定向那样受人类示范约束；RL 则把这种开环、可能不精确的参考变成能抗扰动/建模误差的物理策略。直觉：关键帧给"该怎么摆姿势走接触序列"的强先验，RL 补上"实时反应与可上机的鲁棒性"。
- **物理接地的关键帧（physics-grounded keyframe）**：用一个基于 MuJoCo 的 GUI 工具交互式指定机器人姿态 + 到达时间，关键帧间**线性插值**成完整参考轨迹；工具提供关节镜像、足底贴地对齐、质心(CoM)/碰撞/接触可视化，能在仿真里直接校验姿态是否物理可行（站得稳、轨迹平滑）。简单动作（如爬行）整条轨迹设计成仿真里可直接重放；难动作（如翻墙）则至少保证每个关键帧**静态可行**、插值轨迹物理可信。作者称设计一条难技能轨迹"熟练后通常几小时"，比 mocap+重定向+大量 reward shaping 高效。
- **动作追踪策略（RL）**：DeepMimic 式，用 PPO 训练，把插值出的参考动作当追踪目标。
- **技能分三类**：① 运动技能（走、爬，周期信号、可无限执行、终止姿态不固定，便于持续与衔接，走路还接受速度指令）；② 过渡技能（站↔爬、仰卧/俯卧→站等）；③ 地形技能（爬上平台、平台上转身、下平台、翻墙、上楼、下楼，触发后自主执行整条轨迹一次）。
- **四个标准姿态做"状态机"**：所有策略都被训练成从"站/爬/俯卧/仰卧"四种规范姿态之一开始、并结束于其一，从而保证技能之间的**平滑衔接**。作者发现这种简单状态机就足以保证执行期顺畅过渡，无需复杂的 meta-composer。
- **分层执行 + 视觉规划**：50 Hz 低层策略负责快速抗局部扰动；**3.1 Hz** 视觉技能分类器（ResNet，吃深度图）负责低频"选哪个技能"。理由：运动模式切换本来就是低频事件。IMU 检测到摔倒触发恢复（recovery）策略。

## 动机 & 背景
- 生物力学背景：四足与双足支撑模式不同，关键在"支撑多边形"大小——只用脚时落脚切换瞬间常缩成单一接触片，难地形上易被迫做剧烈动作；**全身接触可同时用三块或更多接触片，形成更大更稳的支撑多边形**，动作更安全。这是"为什么要用脚以外部位"的力学动机。
- 与 RL 难地形运动相关工作（如 Rudin et al. 大规模并行 RL、四足 parkour）相比，作者批评以往人形多沿用"四足思路/腿主导、手臂参与极少"，忽视了人类手脚分工；本文主张全身各部位都贡献于稳定。
- 关键帧在动画/机器人里是编码人类专家知识的直观手段；作者强调与 kinematic 重定向相比，关键帧"含动力学信息、可直接在仿真/开环上机验证"，迭代更快。

## 方法细节
- **观测状态**：`s_t = (φ_t, c_t, Δq_t, q̇_t, a_{t-1}, θ_t, ω_t)`（式1）。φ_t 是相位信号（运动技能用周期信号、过渡/地形技能用单调递增信号做时间协调）；c_t 可选速度指令；Δq_t 关节相对中性姿态 q_0 的偏移；q̇_t 关节速度；a_{t-1} 上一动作；θ_t 躯干朝向；ω_t 躯干角速度。动作 a_t 是 PD 控制器的关节位置 setpoint。
- **奖励**：`r_t = r_t^imitation + r_t^regularization + r_t^survival`（式2）。
  - 模仿奖励是加权和：`r_t^imitation = w^m r_t^m + w^p r_t^p + w^v r_t^v + w^e r_t^e + w^c r_t^c`（式3），分别对应电机位置追踪、姿态、局部体速、末端执行器（手脚位置）、质心偏差。
  - 电机位置追踪奖励：`r_t^m = Σ_g w_g · exp(−‖q_g − q_g*‖²)`（式4），g ∈ {腿, 臂, 颈, 腰}，q_g 实际电机位置、q_g* 参考、w_g 各组权重。对"物理已验证"的关键帧动作，用**指令动作**而非参考姿态作为追踪基准，以吸收追踪误差。
  - regularization 抑制关节力矩、能耗、动作变化率；survival 防早停。
- **两个值得注意的例外（机制细节）**：
  - **走路不用全身动作追踪**：改用速度追踪目标 + 简单足高追踪项引导摆动腿，让走路步态"涌现"（emergent），并加姿态稳定/足姿态奖励。直觉：周期步态更适合用目标涌现而非逐帧模仿。
  - **平台上转身（rotating）**：保留全身追踪，但额外加"绕竖直轴朝向追踪"项；虽参考动作对应爬行姿态，但该项让"原地协调全身接触的稳定旋转"涌现出来。
- **域随机化（domain randomization）**：地面摩擦、电机执行参数、初始状态、不同地形上的起始位姿、随机推力、IMU 噪声、动作延迟。IMU 噪声模型组合了有色噪声、白噪声、随机游走偏置、对 θ 与 ω 的随机幅度缩放，以模拟真实 IMU。
- **深度感知**：双鱼眼 RGB @30 Hz → 校正 → **Foundation Stereo** 离线生成深度图（离线是因 RGB 采集帧率远高于深度估计速度，便于快速采数）。推理时把 480×640 降到 192×256、TensorRT float16 编译，在 Jetson Orin NX 16GB 上从 0.5 Hz 提到 **3.1 Hz（约 6×）**且不降分类精度。
- **视觉技能分类器**：ResNet 吃深度图选技能；类别不均衡靠对过渡/地形类按比例加权缓解；部署时用指数移动平均做时间平滑、置信度阈值触发切换。
- **技能规划器（Algorithm 1）**：输入深度图 D、躯干 pitch 及上下界、深度极值界、置信阈 c、当前技能、恢复技能。逻辑：先判摔倒（pitch 过小且 max(D) 过小，或 pitch 过大且 min(D) 过大）→ 返回恢复技能；否则分类得 p，做平滑 `p̄ ← 0.1·p̄ + 0.9·p`，取最高分技能，若其平滑置信 > c 则切换、否则维持当前技能。运动技能持续执行直到平滑置信越阈才切到过渡/地形技能；某些技能链式串联（如"平台上转身→下平台"）；过渡执行期间忽略分类器输出，完成后恢复运动控制。

## 数据集 & 实验设置
- **机器人**：开源微型人形 **ToddlerBot**，30 自由度，类人活动范围，紧凑体型适合在椅子/泡沫块/木板搭的家用障碍里测富接触技能。仿真里泡沫块/木板用简单几何体建模，椅子用图像转网格生成器（手测尺度）建模。
- **测试障碍（Fig 3，按腿长 25 cm 折算）**：椅下净空 < 机器人身高（需爬行）；墙高约为腿长的 48%（≈12 cm 设计值）；平台高约腿长 44%（≈11 cm 设计值）；每级台阶约腿长 16%。
- **技能分类器训练数据**：全部来自真实测试台，27,987 对"深度图-技能"（22,389 训练 / 5,598 验证），另收 3,394 真实样本做留出测试集；标签在采数时按技能切换时刻自动打（过渡时刻定义清晰），约 18 分钟真实录制（主要受 30 Hz 相机限）、深度离线生成约 150 分钟。
- **评测内容**：对深度估计、视觉分类器、各策略鲁棒性做受控实验，再做整机端到端评测；完整含一项"几小时关键帧设计得到的退出小推车 cart-exit"技能见补充视频。

## 主要结果 & 结论（写方向，不堆精确数字）
- 各动作追踪策略实现 **zero-shot 仿真到真实迁移**，在椅下爬行、翻墙、上/下平台、平台转身、上/下楼、从仰卧/俯卧起身、以及摔倒恢复等任务上于真实硬件展示成功（主要为实拍照片 Fig 4/7 + 补充视频的定性展示）〔observed〕。
- 视觉技能分类器在真实留出集上总体准确率约 **93.9%**（混淆矩阵 Fig 6）；错分主要集中在技能"过渡时刻"的几何线索本就模糊处（如爬出椅下转站立），作者认为这种边界模糊由下游规划器的时间平滑 + 置信选择兜住〔supported，有量化测试集〕。
- 深度估计在 192×256（部署分辨率）下黑框区域像素级 MAE 约 62 mm、点云 Chamfer 距离约 19 mm，与 480×640 相近，作者判定足够支撑下游分类〔supported；MAE/Chamfer 见 §IV-C 与 Fig 5〕。
- **超出设计点的尺寸泛化**：为 12 cm 墙设计的翻墙策略可泛化到约 9–14 cm；为 11 cm 平台设计的上平台策略泛化到约 8.5–13 cm（Fig 7a/b）〔observed，仅这两项技能、给定区间〕。作者明确对比："简单重放关键帧动画、或朴素动作追踪策略，在地形配置改变时会立刻失败"——即域随机化带来的鲁棒性是关键〔observed/supported〕。
- **技能链泛化**：在五种不同障碍顺序（如 椅→墙→平台→楼梯 等排列、含"连续两把椅子"）上 zero-shot 成功（Fig 7c + 补充视频）〔observed〕。
- 结论：在一台微型人形上做了分量级受控实验 + 整机评测，证明该框架能稳定完成多种极端地形的全身富接触运动。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：低净空（钻椅下需爬行）、膝高墙/平台、陡升降楼梯等"需要主动用手/膝/肘/躯干建立额外接触"的离散、较大尺度结构化障碍；障碍尺寸在设计点附近一定区间内变化；多障碍按不同顺序串联。
- **依赖前提**：需要人工用 GUI 设计物理可行关键帧（要本体与领域知识）；需要双鱼眼深度 + Foundation Stereo 管线 + 真实采集的分类器训练数据；低层 50 Hz、视觉 3.1 Hz 的分层假设（运动模式切换是低频事件）。
- **不管用 / 边界**：极端富接触动作（如翻墙）"偶尔会在硬件上失败"，作者归因于接触建模近似；线性插值牺牲了动作自然度；障碍若是分类器训练分布外的几何，或切换时刻几何线索高度模糊，选技能可能出错（靠平滑/阈值缓解但非根治）。全部实验在微型 ToddlerBot 上，**对全尺寸人形只是"预期可迁移"，未做实证**。

## 核心贡献
- 提出"超越脚（beyond feet）"的全身富接触人形运动**整套系统**：主动调用手/膝/肘/躯干增加接触以稳定支撑，跨越椅下/墙/平台/楼梯等极端地形。
- 把**物理接地的关键帧动画**作为运动先验、与 **RL 动作追踪**结合，绕开 mocap 重定向的本体差异、并可在仿真/开环快速验证迭代。
- 设计**四标准姿态状态机 + 三类技能（运动/过渡/地形）**，用简单机制保证九种技能的平滑衔接。
- 提出**深度驱动的分层技能规划器**（ResNet 分类 + 时间平滑 + 置信阈 + IMU 摔倒检测），并把 Foundation Stereo 深度管线压到 3.1 Hz 上机。
- 在真实微型人形上做控制变量实验 + 整机 zero-shot 评测，展示尺寸/顺序泛化；全部工作开源。

## 局限与我的质疑
1. **本文为 arXiv 预印本（v1, 2026-01-07），未经同行评审**；下文涉及"成功/泛化"的结论应保留，尤其因核心证据偏定性。
2. **缺乏定量成功率/失败率**：策略本身的结果几乎全是实拍照片 + 补充视频的定性展示，没有给出各技能在 N 次试验中的成功率、跌倒率、完成时间等统计表（只有分类器有混淆矩阵、深度有 MAE）。这让"鲁棒""稳定"难以被量化复核，泛化区间（如墙 9–14 cm）也未说明各端点的成功率与样本量。〔我的判断，基于通读全文未见此类表；如在补充材料另有统计则需回查〕
3. **"翻墙偶尔失败"被一笔带过**：作者自述极端富接触会因接触建模近似在硬件上偶发失败，但没给失败频率或哪些技能更脆弱，读者无法判断真实可靠度。
4. **强基线缺位**：对比对象主要是"朴素重放关键帧/朴素动作追踪"这类弱化版自身消融，而非其他全身运动 SOTA（如 mocap 重定向 + RL 路线、或同类人形 parkour 方法）的同台对比；因此"我们的方法更好"更多是相对自身简化版〔observed〕，不能据此声称优于现有强方法。
5. **可扩展性瓶颈在人工关键帧**：每个技能都要人工设计物理可行关键帧（作者自承需领域专家、且把自动化优化列为未来工作）；技能数量与新地形扩展成本未量化，"几小时一条技能"也只是定性说法。
6. **全尺寸迁移纯属推测**：所有实验在 30 自由度微型 ToddlerBot 上完成，富接触的力矩/接触动力学在全尺寸人形上差异巨大，"expect transfers seamlessly"无任何实证支撑，应视为未证明的主张。
7. **感知链路的真实鲁棒性存疑**：深度离线生成 + 训练数据仅来自单一真实测试台（约 18 分钟录制、障碍用家用物搭建），分类器对光照/杂乱背景/新物体几何的分布外鲁棒性未评测；3.1 Hz 的低频选技能在动态或意外环境变化下是否够快也未验证。
