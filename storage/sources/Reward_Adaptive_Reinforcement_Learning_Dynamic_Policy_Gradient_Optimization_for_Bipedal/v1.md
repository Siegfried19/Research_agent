# Reward-Adaptive Reinforcement Learning: Dynamic Policy Gradient Optimization for Bipedal Locomotion
> Changxin Huang, Guangrun Wang, Zhibo Zhou, Ronghui Zhang, Liang Lin · 2022 · IEEE Transactions on Pattern Analysis and Machine Intelligence · 引用 38 · DOI 10.1109/tpami.2022.3223407

## 一句话
把双足行走的多分量奖励**不再求和成一个标量**，而是用"多头 critic"为每个奖励分量单独学一个价值函数，再按各分量的"易学程度/稳定程度"动态加权合成策略梯度（HDPG），让机器人先学会平衡、再学前进，从而比求和式 DDPG 学得更快、抗扰更稳。

## 解决了什么问题
- 双足行走是多约束任务，奖励通常由多个分量构成（前进、步态、能耗/力矩、姿态、跌倒等），各分量之间存在依赖关系。
- 主流 RL 做法把这些分量**直接加权求和成单一奖励、学单一价值函数**（如 DDPG），作者主张这会"丢失不同奖励之间的依赖信息"，导致价值函数学习效率受限、策略次优（原文："may break the correlation between different rewards and therefore limit learning efficiency"）。
- 一个具体痛点：求和后若 agent 收到负奖励，单一 Q 值"无法分辨这是因为姿态不自然还是因为电机过扭"（原文 §IV 开头举例），即 Q 值不能反映各因素对策略的贡献。

## 用什么方法解决的（含直觉：为什么 work）
- **多头 critic（multi-head critic）**：奖励被分解成向量 `r_t = [r_{t,1},...,r_{t,K}]`，critic 输出对应的 Q 向量 `Q(s_t,a_t|θ^Q) = [Q_{t,1},...,Q_{t,K}]`（Eq.4），每个头只从对应子奖励学习一个独立价值函数。直觉：让每个分量的价值各自清晰可学，而不是被混进一个标量里互相掩盖。
- **动态优先级加权（dynamic policy gradient）**：各头各自产生一份策略梯度 `∇J_k`，总梯度按权重合成 `∇J = Σ_k m_k ∇J_k`（Eq.8），权重 `m_k` 每 T 个 episode 更新一次。直觉：不同分量难易不同，与其所有技能"同一学习率并行学"，不如按优先级有序地学。
- **为什么这样能 work（核心机制）**：作者用当前策略采样 N 个一步奖励，归一化后统计每个分量的均值 `μ_k` 与方差 `σ_k`。`μ_k` 大 = 该分量当前更容易拿到大奖励 = 对当前策略更易学；`σ_k` 大 = 策略在该分量上更不稳定，希望提高其学习率把它学稳。据此定义优先级权重（Eq.9）：
  `m_k = K(μ_k + e^{σ_k²}) / Σ_{k=1}^{K}(μ_k + e^{σ_k²})`
  机制上的故事是："先学简单分量、再学复杂分量"——例如先学会保持身体平衡（平衡是前进的前提），再学前进（原文："keeping balance is the prerequisite of moving forward"）。Fig.4 右图佐证：高度/姿态奖励约在 2k episode 先上升，步态/步幅奖励约在 6k 才上升。
- **底座是 DDPG（连续动作）**，区别于灵感来源 HRA/drQ（基于 Q-learning、只能离散动作）。多头 critic 的更新（Eq.6/7）让所有 Q_k 朝**同一个一致策略**收敛：
  `L(θ^Q) = E Σ_{k=1}^{K} (y_{t,k} - Q_k(s_t,a_t|θ_k^Q))²`，其中 `y_{t,k} = r_{t,k} + γ Q_k(s_{t+1}, π(s_{t+1})|θ_k^Q)`（Eq.7）。整体 Q 值定义为各头之和 `Q = Σ_k Q_k`。

## 动机 & 背景
- 传统双足控制（ZMP 零力矩点、HZD 混合零动力学、DCM）依赖已知的机器人动力学/运动学、且对障碍/斜坡等复杂地形适应性有限（原文 §II）。
- 模仿学习（IL）类方法需要人工设计的专家参考轨迹，费力（原文 §II）。
- RL 不需已知动力学、可在交互中学策略，但现有方法多用"奖励求和学单一价值函数"，作者认为这正是效率瓶颈所在。
- 本文方法**不依赖人工设计的参考轨迹**（原文 §IV-C："HDPG does not rely on manually designed reference trajectories"），只用人类步态的若干通用原则来设计奖励分量。

## 方法细节
- **状态/动作**：状态 `s_t` 含 IMU 数据与各关节角位置；为提取时序特征，拼接 3 帧 `(s_{t-2}, s_{t-1}, s_t)` 作为 actor 输入（每帧 23 维，合计 69 维）。动作是 10 个关节的目标角位置（10 维），经最小 jerk 规划模块生成平滑过渡轨迹，再由底层 PD 控制器跟踪。
- **网络结构**：actor 为 3 层全连接 (69,128)/(128,256)/(256,10)。multi-head critic 中 action 与 state 各先过一层 (10,128)、(69,128) 再拼接，过两层 (256,256)/(256,6) 输出 6 个 Q 值；不同头**共享低层、只有最后一层独立**。
- **6 个奖励分量**（K=6，奖励向量 `r_t = [r^g, r^s, r^t, r^h, r^o, r^d]`，§IV-C）：
  - 步态奖励 `r^g`（Eq.10）：发生单/双支撑交替的"gait"时为 `w1 d_t^g cos θ^g`，否则为 0（鼓励朝前进方向走出步态）。
  - 步幅奖励 `r^s`（Eq.11）：`w2 d_t^s cos θ^s`，鼓励每步向前移动。
  - 力矩奖励 `r^t`（Eq.12）：`-w3 Σ_i |f_t^i|`，惩罚过大关节力矩，降能耗、使轨迹更平滑（作者称该力矩奖励在 OpenAI Gym Robotschool 上已被验证有效）。
  - 高度奖励 `r^h`（Eq.13）：`-w4 |h_t - h0|`，盆骨高度偏离目标则惩罚。
  - 姿态奖励 `r^o`（Eq.14）：`-w5(|α_t^r| + |α_t^p|)`，惩罚盆骨 roll/pitch 角偏离。
  - 跌倒奖励 `r^d`：机器人倒地时固定为 -50。
- **奖励归一化**：对每个分量做简单 max-min 归一化到 (0,1)，以便统计 μ/σ 时量纲一致（以 gait 奖励为例给出 `d_max^g` 的算法，§VI-A）。
- **训练超参**（§VI-A）：γ=0.99；actor/critic 学习率 1e-5 / 1e-4；batch 64；优先级权重每 T=20 个 episode 更新一次；Adam 优化器；探索用 OU 噪声 + replay buffer。力矩/步幅权重参照 Gym Walker2d（w1=1.0, w3=0.001），其余权重设 1.0。

## 数据集 & 实验设置
- **自建仿真器 AIDA**：基于 ROS + Gazebo（ODE 物理引擎），机器人 SolidWorks 建模，10 自由度（每腿 5 DoF），盆骨质心居中（类人）。作者表示将开源 AIDA 仿真器与 HDPG 代码。
- **实体机器人**：Intel NUC + IMU + 10 个 DYNAMIXEL 舵机；策略仅凭当前关节角与 IMU 数据实时预测控制。
- **双足 benchmark 三任务**：①随机推力扰动（前/后/侧向，6–14N，持续 0.2s）；②跨越随机障碍（高 0.6–1.4cm）；③上斜坡（3–15°）。每个设置 100 次试验，成功=能稳定走 10 秒。
- **对比方法（含消融）**：ZMP（经典控制）、DDPG（单头 critic、求和奖励）、**MHDDPG**（多头 critic 但各头**静态等权** m_1=...=m_K=1）、**HDPG**（多头 + 动态权重，完整版）。MHDDPG 用于隔离"多头"本身的贡献，HDPG = MHDDPG + 动态权重。
- **MuJoCo 泛化实验**：Hopper-v3、Walker2d-v3、HalfCheetah-v3，1M 步，跨 10 次运行取均值±方差；用公开实现 tianshou 为 baseline；并把思想嫁接到 PPO 得 HD-PPO。

## 主要结果 & 结论（写方向，不堆精确数字）
- **学习效率**：HDPG 累计奖励约在 2k episode 开始上升，MHDDPG 约 4k、DDPG 约 6k；HDPG 收敛奖励最高、效率最佳（supported，Fig.4 左）。MHDDPG 明显优于原版 DDPG，说明"多头 critic"本身就带来增益（supported）。
- **抗推力扰动**：6N 时各 RL 方法都好；8N 侧向推力下只有 HDPG 成功率 >90%，DDPG/MHDDPG 掉到约 80%（observed，仅侧向这一条件）。扰动增到 12–14N 时 HDPG 更稳，约比其它方法高 ~10%；ZMP 掉得最快、最差（高扰动下三方向仅 38/38/24%）（supported，Fig.5）。
- **跨障碍**：HDPG 在所有高度最好；0.6cm 时 HDPG/MHDDPG 都 100%；1.2cm 时只有 HDPG >60%、其余约 50%；1.4cm 时 HDPG 仍最好但仅约 40%，作者归因于"腿抬升高度的物理限制"（supported，Fig.6 左）。ZMP 几乎无法跨障碍，故未参与此项对比。
- **上斜坡**：DDPG 与 MHDDPG 表现接近，说明"多头 critic 在此任务上增益不强"；HDPG 最好，12° 时约高 ~20%（observed，此任务多头单独贡献有限，Fig.6 右）。
- **动态权重的作用**：MHDDPG 的步幅/步态奖励训练曲线非常不稳（说明分量间存在相互影响），而 HDPG 五个分量都训练平稳；且高度/姿态奖励先升、步态/步幅后升 → 体现"先学平衡、再学前进"的有序学习（supported，Fig.4 中/右）。
- **Sim-to-real**：在仿真中加动力学随机化（仅随机化盆骨质心）训练的策略成功迁移到实体机器人，能从前向推力中恢复稳定步态（约 13.1s 受扰→13.9s 恢复，Fig.7）。这是**单次定性演示**（observed）。
- **MuJoCo 泛化**：1M 步内 MHDDPG 与 HDPG 在三个任务上都优于 DDPG，HDPG 最佳（supported，Table I）。HD-PPO 在 Hopper/Walker 上较 PPO 提升 >25%、HalfCheetah 仅约 6.6%；作者据此推断**奖励分量越多，方法增益越明显**（HalfCheetah 只有 2 个奖励分量，故提升小）（observed→supported 的因果解释，证据为三任务对比）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：奖励由**多个分量**构成、且分量之间存在依赖关系的连续控制任务（双足行走、Hopper、Walker2d）——分量越多，"多头 + 动态权重"收益越大。
- **增益弱**：奖励分量少的任务（如 HalfCheetah 仅 2 分量，HD-PPO 仅 +6.6%）；以及像"上斜坡"这类任务里"多头 critic"单独的贡献不明显（主要靠动态权重拉开差距）。
- **依赖底座**：方法构建在 actor-critic 连续控制（DDPG/PPO）之上；其灵感来源 HRA/drQ 基于 Q-learning 只能离散动作，本文的卖点之一正是把"分解价值函数"推广到连续动作。
- **物理上限不可逾越**：跨 1.4cm 障碍成功率仅约 40%，受限于机器人腿抬升能力——算法改进救不了硬件/形态限制。

## 核心贡献
- 提出多头 critic：为每个奖励分量学独立价值函数，实验显示优于传统"奖励求和"（supported）。
- 提出 hybrid policy gradient 的动态权重机制（Eq.9）：按各分量的均值/方差动态调优先级，提升学习效率（supported）。
- 构建 AIDA 双足机器人仿真+实体平台，并发布含推力恢复/障碍/斜坡的 3 个 benchmark 挑战（声明开源）。
- 在 OpenAI Gym/MuJoCo 上验证泛化性，并把思想嫁接到 PPO（HD-PPO）证明方法不绑定 DDPG。

## 局限与我的质疑
1. **"求和会丢失依赖信息"是动机式断言，缺直接证据**：作者反复用"sum loses dependency / breaks correlation"作为立论根基，但论文没有给出一个隔离实验直接证明"恰恰是求和导致了依赖信息丢失"，更多是 DDPG vs HDPG 的端到端比较——而二者差异其实由"多头 critic + 动态权重"两件事共同造成。
2. **动态权重的理论依据偏启发式**：Eq.9 把"易学(高 μ)优先"与"不稳定(高 σ)优先"用 `μ_k + e^{σ_k²}` 混在一起，但这两条直觉方向并不完全一致（既想先学简单、又想给不稳定的加学习率），论文未做权重形式的消融（例如只用 μ、只用 σ、换别的函数），无法判断是这个特定公式有效还是"任何让平衡先学的偏置"都有效。
3. **基线强度与公平性存疑**：RL 侧主要对比 DDPG 系列（自家底座），未与更现代或更强的双足 RL 方法（如基于 PPO 的参考运动模仿、DeepMimic 类）做正面较量；ZMP 作为经典控制基线在障碍/斜坡上"几乎无法完成"，对比偏弱，容易高估相对优势。
4. **Sim-to-real 仅单次定性演示**：实体迁移只展示了一次前向推力恢复的时间序列（Fig.7），没有像仿真那样给出成功率统计、多方向/多力度的量化结果，"成功迁移"的结论被讲得比证据强。
5. **结果方差很大、可复现性待考**：MuJoCo 上 Walker2d 的标准差极大（HDPG 3217.5±1144.8，见 Table I），HalfCheetah 上 DDPG 甚至均值高于 HDPG，"HDPG 全面最佳"的表述对这种高方差结果有点过度解读；且关键成功率多来自图（Fig.5/6）目测，原文未给完整数值表。
6. **对本研究主题（奖励工程）的不足**：奖励分量及其权重（w1..w5）仍是人工设计，方法只是把"如何组合各分量梯度"自动化，并未解决"奖励分量本身怎么设计/该不该存在"这一更上游的奖励工程难题；归一化用的 μ/σ 由当前策略采样估计，策略早期很差时这些统计量是否可靠、会不会自我强化偏置，论文未讨论。
