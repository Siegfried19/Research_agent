# Hierarchical deep reinforcement learning: integrating temporal abstraction and intrinsic motivation
> Tejas D. Kulkarni, Karthik Narasimhan, Ardavan Saeedi, Joshua B. Tenenbaum · 2016 · DSpace@MIT (Massachusetts Institute of Technology) · 引用 541 · DOI title:ef3200782950c96e

## 一句话
提出 h-DQN：一个两层时序抽象的深度强化学习框架，上层（meta-controller）用外在奖励选"子目标"、下层（controller）用"达成子目标"的内在奖励选原子动作，从而在奖励极稀疏、延迟极长的环境（如 Montezuma's Revenge）里完成有效探索（supported）。

## 解决了什么问题
- 在反馈稀疏、奖励延迟的环境里，agent 探索不足，导致学不到稳健的值函数——这是本文针对的核心难题（原文 Abstract："insufficient exploration, resulting in an agent being unable to learn robust value functions"）。
- 现有探索策略（ε-greedy、Boltzmann 探索、Thompson sampling、bootstrapped DQN）都在"基本动作层"上操作，奖励 horizon 很长时仍失效（原文 §2.4：经典 DQN 在 Montezuma's Revenge 上得分为 0）。
- 论文要解决的是"如何把探索约束到一个高效空间"——办法是引入由实体/关系定义的内在子目标来引导探索。

## 用什么方法解决的（含直觉：为什么 work）
- **两层层级（核心机制）**：meta-controller 接收状态 s_t，从目标集合 G 中选一个目标 g_t；controller 同时看 s_t 和 g_t，连续选原子动作 a_t，直到目标达成或回合终止；之后 meta-controller 再选下一个目标，循环往复（原文 §3 "Temporal Abstractions"，Figure 1）。
- **内在 critic 提供内在奖励**：一个"internal critic"判断目标是否达成，只有达成对应目标时 controller 才得到正的内在奖励 r_t(g)（原文 §3）。
- **两个目标函数（分别在两个时间尺度上优化）**：controller 最大化累积内在奖励 R_t(g)=Σ γ^(t'−t) r_t'(g)；meta-controller 最大化累积外在奖励 F_t=Σ γ^(t'−t) f_t'（原文 §3）。
- **两个 DQN**：controller 估计 Q₁\*(s,a;g)=max E[Σ γ^(t'−t) r_t' | s_t=s, a_t=a, g_t=g, π_ag]（式1）；meta-controller 估计 Q₂\*(s,g)=max E[Σ_{t'=t}^{t+N} f_t' + γ max_{g'} Q₂\*(s_{t+N},g') | …]（式2），其中 N 是 controller 为当前目标运行的步数——meta-controller 的转移跑在更慢的时间尺度上（原文 §3）。
- **损失与梯度**：controller 损失 L₁(θ_{1,i})=E[(y_{1,i}−Q₁(s,a;θ_{1,i},g))²]，其中 y_{1,i}=r+γ max_{a'} Q₁(s',a';θ_{1,i−1},g)，上一轮参数固定（式3，遵循 DQN 做法）；meta-controller 的 L₂ 同理推导。
- **直觉：为什么 work**——把"长 horizon 的稀疏外在奖励"拆成"一串短 horizon 的、能频繁兑现的内在奖励"。controller 因为子目标可达、内在奖励密集而能学到可复用的"达成某子目标"的子策略；meta-controller 只需在更粗的时间尺度上把这些子策略串成达成外在奖励的序列。子目标定义在"实体/关系"空间（如"agent 到达钥匙/门/梯子"），把巨大的探索空间约束成"少量有意义的目标"，这是数据高效的关键（原文 §1、§4.2）。
- **不为每个 option 设独立 Q 函数**，而是把目标 g 作为网络输入的一部分（类似 universal value function [34]），好处是不同目标间共享表示、可扩展到大量目标（原文 §2.1 末）。
- **训练细节**：controller 与 meta-controller 用各自独立的经验回放 D₁、D₂，在不同时间尺度上采样更新；controller 每步收集经验、meta-controller 仅在 controller 终止时收集（Algorithm 1）。controller 的探索率 ε_{1,g} 按"到达目标 g 的经验成功率"自适应退火（每个目标一个）；meta-controller 的 ε₂ 从 1 退火（原文 §3 "Learning Algorithm"）。

## 动机 & 背景
- 复杂环境里"带稀疏反馈的目标导向行为"是 AI 的根本挑战，需要在多层时空抽象上表征知识并高效探索（原文 §1）。
- 受发展心理学启发：婴幼儿/灵长类用"实体、agent 及其动作、数量、空间"等核心认知系统组织知识，并在这些核心知识空间里构造子目标（如"把重物放到轻物之上"以搭高塔）——本文据此把子目标定义在实体/关系空间（原文 §2.5）。
- 理论根基：把值函数泛化为 V(s,g)（针对达成目标 g 的效用），用 options 框架 [Sutton et al. 48] 做时序抽象，可纳入 semi-MDP 框架（原文 §2、§2.1）。
- 作者明确说本文受 universal value function [34]、options [48]、universal option models [49] 启发并在其上构建（原文 §2.1）。

## 方法细节
- 两层模块：meta-controller（看原始状态出目标策略，优化未来外在奖励）+ controller（看状态+目标出动作策略，优化未来内在奖励）+ internal critic（查目标是否达成、给内在奖励）。controller 在回合结束或目标达成时终止（原文 Figure 1 说明）。
- 内在 critic 定义在 ⟨entity₁, relation, entity₂⟩ 空间，relation 是实体配置上的函数；实验中 agent 自由选 entity₂，当 agent 实体"到达（reaches）"另一实体（如门）即判定目标完成并给奖励（原文 §4.2 ATARI 部分）。作者举例这种关系型内在奖励可泛化到其它游戏（Asteroids 的子弹"到达"小行星、Pacman 的"到达"豆子），并把"让模型自己进化出参数化内在奖励函数"留作 future work。
- Montezuma's Revenge 的网络（Figure 5b）：堆叠卷积层 + ReLU；controller Q₁ 的输入是 image(s)+goal(g)，三层 Conv（32/64/64 feature maps）→ ReLU:Linear(h=512)→Linear 输出 Q₁(s,a;g)；meta-controller Q₂ 结构类似但不把 goal 作输入。目标在图像空间用一个二值 mask 编码、与 4 帧原图拼接喂给 controller（原文 §4.2 "Model Architecture and Training"、Figure 5）。
- 超参（Montezuma's，原文 §4.2）：D₁=1E6、D₂=5E4；学习率 2.5E−4；折扣 0.99；输入为 4 帧连续 84×84 图像。
- **两阶段训练**：阶段(1) 把 meta-controller 的 ε₂ 设为 1（等于随机给目标），先 pre-train controller，让它先学会达成一部分子目标（约 230 万步）；阶段(2) 联合训练 controller 与 meta-controller（再约 200 万步）（原文 §4.2、Figure 6 说明）。

## 数据集 & 实验设置
- **实验一：离散随机决策过程**（原文 §4.1，Figure 2）。6 个状态、链式结构，agent 总从 s₂ 出发；向左确定性成功、向右只有 50% 成功（否则左移）。终止态 s₁：先访问过 s₆ 再到 s₁ 得奖励 1，否则到 s₁ 只得 0.01。外在奖励依赖访问历史而非仅当前状态——专为凸显探索难度而设（是 [32] 的 MDP 的修改版）。每个状态都可作为探索目标。对比对象：不带神经网络的 h-DQN vs. 不带内在奖励的 Q-Learning baseline；所有 ε 在 50000 步内从 1 退火到 0.1，学习率 0.00025，10 次运行平均。
- **实验二：Montezuma's Revenge**（ATARI 2600，原文 §4.2，Figure 5–7）。极稀疏延迟奖励：要先爬梯子、走到钥匙拿钥匙（+100），再去开门（+300）。用 Arcade Learning Environment。作者**自建了一个 object detector** 给出候选物体，用实体/物体来参数化目标（无监督物体检测被列为开放问题，未采用）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **离散 MDP**：Q-Learning baseline 收敛到次优策略——直接去 s₁ 拿 0.01（200 epoch 后仍找不到最优）；h-DQN 学会选 s₄/s₅/s₆ 作目标，从而统计上会先访问 s₆ 再回 s₁，平均奖励显著更高（约 0.13，见 §4.1、Figure 3）(supported)。
- **离散 MDP 探索证据**：随训练推进，对 s₃–s₆ 的访问次数上升，说明模型在选目标使其更频繁到达关键态 s₆（原文 Figure 4）(observed)。
- **Montezuma's Revenge**：联合训练后模型逐步学会既拿钥匙又开门，单回合外在奖励达到约 +400（§4.2、Figure 6a）(observed)。
- **对照强度**：原文报告经典 DQN [28] 在该游戏得分为 0，而当时最好的系统 Gorila DQN [30] 平均也只有 4.16——h-DQN 相对这些得 0/接近 0 的强基线有质的突破(observed，仅此单一游戏)。
- **学习的课程式涌现**：agent 先学会简单目标（如到右门、中梯），再慢慢学会更难目标（钥匙、底部梯子）；训练后期"钥匙""左下梯""右下门"被选中的频率明显上升（§4.2、Figure 6c）(observed)——这是"内在动机自发产生由易到难课程"的直觉证据。
- **达成钥匙目标的成功率**随训练上升（Figure 6b）(observed)。
- 结论：时序分解值函数→内在动机行为→在延迟奖励环境里高效探索；把内在动机参数化在实体/关系空间是构建"时序扩展探索"agent 的有前景方向（原文 §5）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：奖励极稀疏、延迟极长、但环境里存在"有意义的中间子目标/可识别实体"的任务（钥匙→门这种有清晰子结构的导航/收集任务）。子目标把探索空间约束小，是数据高效的来源。
- **强探索基线下仍管用**：作者把 ε-greedy、Boltzmann、Thompson、bootstrapped DQN 都归为"在动作层探索"而不足以应对长 horizon（原文 §1、§2.4），h-DQN 在 Montezuma's 上相对 DQN/Gorila DQN 有突破。
- **依赖外部提供的目标空间**：本文的子目标来自手工搭的 object detector + 人定的"reach 实体"关系。**当无法（自动）获得有意义的物体/子目标时，方法不直接适用**——作者自承"automatic discovery of objects"是缺失组件（原文 §4.2 末、§5）。
- **长程非马尔可夫设定不够用**：作者明说要 scale 到更难的非马尔可夫设定，需要"灵活的 episodic memory / 短期记忆"和"能间歇终止 option 的能力"，当前框架缺这些（原文 §4.2 末、§5）。

## 核心贡献
- 提出 h-DQN：把分层值函数（两个时间尺度上的 DQN）与内在动机深度 RL 整合的框架（原文 Abstract）。
- 用 internal critic + 内在奖励把长 horizon 稀疏奖励问题分解为可频繁兑现的子目标问题，实现高效探索。
- 把目标参数化在实体/关系（⟨entity, relation, entity⟩）空间，并论证这能显著约束探索空间。
- 在两个延迟奖励问题（离散随机 MDP + Montezuma's Revenge）上给出实证，后者是当时多数 SOTA 深度 RL 失败的环境。

## 局限与我的质疑
1. **作者自承的关键缺失件**：物体的自动无监督发现、灵活的短期/episodic 记忆、间歇终止 option 的能力——三者都没做，本文靠"自建 object detector"绕过了最难的一环（原文 §4.2 末、§5）。这意味着 Montezuma's 的成功有相当部分被"先验注入的目标空间"承担，方法的自主性被高估的风险存在。
2. **实验广度极窄**：深度版只在**一个** ATARI 游戏上验证，离散实验是 6 状态玩具 MDP。没有跨多游戏/多任务的系统实验，"observed"远谈不上"泛化"——结论不应被读成"h-DQN 普遍优于深度 RL"。
3. **数字与统计不充分**：Montezuma's 结果（Figure 6）来自联合训练阶段的曲线，正文只给"约 +400"这一量级，未见多 seed 的均值±方差汇报（图中有阴影带但正文没给统计口径），与 baseline 的对比也只是引用他人论文的 0 / 4.16，而非同实验同设置下重训的对照——严格性弱于一次受控比较。
4. **预训练阶段成本巨大且被淡化**：阶段(1) 给 controller 约 230 万步预训练、阶段(2) 再约 200 万步，总样本量很大；"数据高效"的主张需要相对这个总预算来审视，而非只看分解带来的探索增益。
5. **目标达成判定是人工设计的硬规则**（"reach 某实体"），internal critic 不是学出来的；一旦子目标设计不当或不可达，controller 的内在奖励会失真。论文把"让模型自己进化内在奖励函数"留作 future work，等于承认当前这层是脆弱的人工先验。
6. **与本研究主题（可与环境交互的数字人 / RL 通用工具箱）的契合度**：本文提供的是"分层+内在动机解稀疏奖励探索"的通用方法论与直觉，而非可直接落地的工程清单或针对交互式 agent 的具体配方；其 object detector、目标 mask 编码等都高度任务定制，复用到别的交互环境需要重做目标空间设计。
