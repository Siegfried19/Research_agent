# Safe Reinforcement Learning for Autonomous Vehicles through Parallel Constrained Policy Optimization
> Lu Wen, Jingliang Duan, Shengbo Eben Li, Shaobing Xu, Huei Peng · 2020 · arXiv (Cornell University) · 引用 87 · DOI 10.1109/itsc45102.2020.9294262

## 一句话
本文提出 PCPO（Parallel Constrained Policy Optimization）安全 RL 算法，在常规 actor-critic 上**增设一个"风险网络"构成 Actor-Critic-Risk 三网络框架**，用约束优化（风险期望被硬上界 δ 约束）+ 信赖域（KL 约束）保证学习过程中的策略安全，再用**多个同步并行学习者探索不同状态子空间**来缓解约束不可行、加速收敛，并在车道保持与无信号交叉口两个自动驾驶仿真任务上验证。

## 解决了什么问题
- 现有 RL 算法很少上真车，作者归因于两大问题：行为不可解释、且在新场景下无法保证安全（§I）。
- 安全 RL 的核心矛盾：只看奖励、不看潜在风险的训练过程对自动驾驶不可接受；本文目标是在**学习过程本身**（而不仅是部署后）就把风险约束住——属于作者所说的"近似安全（approximately safe）"而非"严格安全"。
- 同时要解决：约束优化常出现**无可行解**（危险状态/近似误差导致 CPO 更新失败），以及小学习率保证单调改进但收敛慢的矛盾。

## 用什么方法解决的（含直觉：为什么 work）
- **新增风险函数 + 约束（沿用 CPO 思路）**：除奖励 r 外，智能体每步还观测一个由人工设计的标量风险信号 r̃（进入不安全状态时赋大值）。定义累计风险与风险值函数 Q̃(s,a)，并用约束 J̃(π) ≤ δ 把期望风险压在安全界以下。直觉：把"安全"显式建成一条可计算、可求导的硬约束，而不是混进奖励里靠权重调，避免风险被高回报淹没。
- **信赖域约束保单调改进**：因 Q 与 Q̃ 都是估计值，仅当策略变化不大时才能保证单调改进；加 KL 约束 `E[D_KL(π_θ, π_θold)] ≤ δ` 允许较大更新步而不破坏单调改进条件（思想来自 TRPO/CPO）。直觉：在"可信"邻域内可以大步走，从而比小学习率收敛快。
- **求解方式**：原非线性约束问题（式3）对小步长做局部近似——目标/风险线性化、KL 用二阶（Hessian H）展开——化为凸问题（式4），经对偶（式5）得闭式策略更新 `θ_{k+1} = θ_k + (1/λ*)H^{-1}(g - bν*)`（式6）；不可行时用 Achiam 的恢复规则 `θ_{k+1} = θ_k - sqrt(2δ/(b^T H^{-1} b)) H^{-1} b`（式7）拉回可行域。
- **并行约束策略优化（本文核心增量）**：用多个并行 agent 同步基于共享策略采样、各自求解式(4)。直觉与机制：单 agent 在危险状态下常无可行解、恢复规则又会拖慢收敛；让多个 agent 探索不同状态子空间能**降低样本相关性、扩大覆盖**，从而"提高找到可行状态的概率"。每个 agent 的样本用两个指标 `c_i` 与 `e_i = δ − c_i²/(b^T H^{-1} b)` 判可行（仅当 c_i>0 且 e_i<0 时可行）。
- **关键的样本分工**：所有 agent 的样本都用来更新 value 网络与 risk 网络；**只有"可行"样本才用来更新 policy 网络**；若某步无任何可行样本，才退回恢复规则(7)。直觉：值/风险估计要尽量多数据，但策略更新必须只用安全可行的方向。

## 动机 & 背景
- 自动驾驶控制策略分规则法与学习法；规则法（如有限状态机）难覆盖所有场景且工程负担大，故选学习法（§I）。
- 综述式地把安全 RL 分为两条路线：**改优化准则**（maximin / 风险敏感 / 约束型 / 其它）与**改探索过程**（引入外部知识 / 风险导向探索）；作者指出前者易"过度悲观或计算不可解"，后者"对早期与长期风险都难可靠检测"（§I–II）。本文走"约束型准则"。
- 方法谱系上明确"受 Achiam et al.(2016/2017) CPO 启发"（§II-C），信赖域来自 Schulman TRPO[21]——可理解为 **PCPO ≈ CPO + 同步并行学习者**。

## 方法细节
- **MDP/AC 基础**：无限折扣 MDP，随机高斯策略（policy 网络输出均值 µ 与标准差 σ）。优势函数 `A^π(s,a)=Q^π(s,a)−V^π(s)`；用重要性采样构造代理目标 `J(π)=E_{s,a∼π_old}[ (π(a|s)/π_old(a|s)) Q^{π_old}(s,a) ]`（§II-A）。
- **三网络**：policy π_θ、value Q^ω、risk Q̃^φ，各为 2 个全连接隐层、每层 100 单元、隐层用 ELU（§III-A2）。value/risk 用 TD/n-step return 更新（式1 及 `dφ=(R̃_t−Q̃^φ)∇_φ Q̃^φ`）。
- **约束优化问题（式2/3）**：max J(π_θ) s.t. J̃(π_θ)≤d 且 KL≤δ。局部近似式(4)中 g=目标梯度、b=风险梯度、H=KL 的 Hessian、c:=J̃(π_k)−d；作者称 H 半正定故凸、并"假设其正定"用对偶求解。
- **算法流程（Algorithm 1）**：每次迭代各 agent 采样→更新 value、risk→估计 g,b,H,c→把可行 τ 存入缓冲 D；若 D 非空则解式(5)得 λ*,ν* 并用式(6)更新策略，否则用式(7)恢复。
- 注意原文公式存在排印瑕疵（如 R̃_t 求和上下标写成 `k=∞`），按上下文应为标准 n-step 累计；此处以方法意图为准、精确写法以 PDF 为准。

## 数据集 & 实验设置
- **任务一 车道保持（单车、仅横向控制）**：闭环道路宽 3m；状态 S={d（与车道中心线横向距离）, β（航向与轨迹切线夹角）}；动作=前轮转角 δ∈[−π/4, π/4]；恒速 50 km/h，二自由度自行车模型。奖励 `r = −(100/9)d² − β²`，出车道边界给风险 100。4 个并行车、每迭代各探 16 步、每 epoch 25 episode，γ=0.95，value/risk 学习率 1e-3、policy 1e-4。安全界 d=1、δ=1e-3（图5题注）。
- **任务二 无信号交叉口（3 车、集中式策略）**：轨迹预先固定，状态 S={l₁,v₁,l₂,v₂,l₃,v₃}（l=到轨迹中点距离，v∈[6,14] m/s），动作=三车加速度 a∈[−3,3] m/s²；每通过一车 +10、每步 −1、终止成功 +10，发生碰撞给风险 50；安全界 d=5。
- **基线与协议**：对比 CPO 与 PPO（PPO 用 ε=0.2 的 clip 代理目标）；三者共用相同网络结构与超参；结果取 5 次独立运行，图示均值±标准差（或最大/最小阴影带）。

## 主要结果 & 结论（写方向，不堆精确数字）
- 车道保持中，**所有并行车在整个学习过程都待在车道内**、横向偏差约 70 个 epoch 内快速下降——支持"学习过程中即保持安全"的主张（observed，仅此 2D 任务）。
- 车道保持中 PCPO 收敛速度优于两基线：相对 CPO 约提升 35%、相对 PPO 提升 70%+；且只有 CPO 与 PCPO 把期望风险压在风险界以下，PPO 在学习中多次冲出车道（observed，单任务、5 次运行）。
- 交叉口任务中 PCPO 与 CPO 的风险都单调下降并稳定在安全界附近（作者认为越贴近界越好，因"安全与通行效率本质对抗"）；PCPO 在收敛速度与最终最优性上都更好：约 800 epoch 收敛到理论最高回报 0，CPO 收敛更慢（约 1400 epoch、且只到约 −5，作者称慢约 75%），PPO 则收敛到约 −15 且风险约 30（远超界 5），被判为"次优且不安全"的策略（observed，单任务）。
- 作者据此总结三点贡献方向：学习过程可满足安全约束、学习速度与数据效率更高、更不易陷入次优（或至少陷入"安全的"次优）（§IV）。

## 适用边界（什么时候管用 / 什么时候不管用）
- 适用：可定义出**人工标量风险信号**、且约束/信赖域近似（小步长）成立的连续控制任务；状态空间足够低维、能跑多个并行 agent 同步采样的仿真设定。
- 在两个仿真任务上，相比 CPO（强相关同源基线）与 PPO（无安全约束基线），PCPO 在"学习期安全 + 收敛速度"两轴更好——但这是**单算法族内的小规模验证**。
- 不适用/未验证：高维感知输入、真实车辆（尽管动机谈真车，全部实验均为仿真）、需要"严格安全/硬保证"的场景（本文自述只是"近似安全"，早期 epoch 图中仍有风险/偏差波动）。交叉口为"轨迹预先固定 + 集中式单策略控三车"，不是真正的多智能体/自由轨迹设定。

## 核心贡献
- 提出 Actor-Critic-Risk 三网络架构：在 AC 上显式增设风险网络逼近风险值函数，把安全做成可求导的硬约束（J̃(π)≤δ）。
- 将 CPO 的约束+信赖域+恢复规则与**同步并行学习者**结合（=PCPO）：用多 agent 探索不同状态子空间降低样本相关性、提高约束可行性与收敛速度；并给出每 agent 样本的可行性判据（c_i、e_i）与"全样本更新值/风险、仅可行样本更新策略"的分工。
- 在两个自动驾驶仿真任务上实证：学习期保持安全 + 比 CPO/PPO 收敛更快、更不易陷入不安全的次优。

## 局限与我的质疑
1. **"保证安全"措辞偏强、与方法本质不符**：方法只是把期望风险约束在界内、且依赖局部近似与凸化（还"假设 H 正定"），属作者自承的"近似安全"，并非硬安全保证；学习曲线早期也确有风险/偏差波动。把它读成"可保证安全"是过度解读。
2. **实验规模与多样性都很有限**：仅 2 个低维仿真任务（车道保持 2 维状态、交叉口 6 维），无真车、无高维感知、无更强或更现代的安全 RL 基线（如 Lagrangian-PPO、SAC-Lagrangian、PID-Lagrangian 等同期/后续方法均未比）。结论的泛化性证据不足。
3. **关键收益数字单薄**："35%/70%/75% 更快"均来自单任务、单指标、5 次运行，缺乏统计显著性检验与多任务复现；"theoretical highest return 0"等说法也未给出推导。这些数字宜当方向性参考，不宜当结论卖点。
4. **风险信号需人工设计**：r̃ 由专家手工赋值（出界=100、碰撞=50 等），其取值直接决定安全行为；论文未做风险设计的敏感性分析，迁移到新任务需重新人工调，削弱了"通用安全"主张。
5. **"并行带来的增益"未做干净消融**：并行同时改变了样本相关性、覆盖与吞吐，论文未单独隔离"并行"相对"单 agent CPO + 等量样本"的净贡献——PCPO 对 CPO 的优势有多少来自算法、多少来自更多/更分散的数据，并不清楚。
6. **交叉口任务设定弱化了难度**：轨迹预先固定、用单一集中式策略控制三车，回避了真正的多智能体交互与轨迹规划，难以支撑"一般自动驾驶任务"的强结论。
7. **与本研究主题（SAC/PPO 之外的安全约束算法实现细节）相比**：方法本质是 CPO 的并行化，工程实现细节（如 H^{-1} 的共轭梯度近似、并行同步开销、缓冲与同步实现）几乎未给，复现性偏弱；公式排印也有瑕疵（如 R̃_t 求和上下标）。
