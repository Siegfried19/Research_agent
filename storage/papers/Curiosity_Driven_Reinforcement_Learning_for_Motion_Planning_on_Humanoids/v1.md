# Curiosity Driven Reinforcement Learning for Motion Planning on Humanoids
> Mikhail Frank, Jürgen Leitner, Marijn Stollenga, Alexander Förster, Jürgen Schmidhuber · 2014 · DOAJ (DOAJ: Directory of Open Access Journals) · 引用 75 · DOI 10.3389/fnbot.2013.00025

## 一句话
本文在真实 iCub 人形机器人上，用"好奇心(人工好奇/内在动机)驱动的基于模型 RL"自主探索高自由度位形空间、学出一个可复用的 MDP 运动规划器，作者称这是"首个用于实时运动规划的具身好奇 agent"（"the first ever embodied, curious agent for real-time motion planning on a humanoid"）。

## 解决了什么问题
- 传统运动规划（如 PRM/RRT）走"先规划、后执行"(plan first, act later)路线：先在位形空间采样、用前向运动学+碰撞检测预先校验每条轨迹的可行，计算昂贵、且要求工作空间静态。
- 这种范式在 iCub 这类轻量、线缆驱动、带非线性动力学（摩擦/形变）的机器人上很难成立：轨迹难以在仿真中忠实校验，且环境一旦变动校验就失效。
- 同时，先前的人工好奇/内在动机工作大多只在玩具场景（仿真迷宫、1–2 自由度简单系统）验证；作者要把好奇 agent**真正具身**到复杂硬件、控制多自由度（many DOFs）。

## 用什么方法解决的（含直觉：为什么 work）
- **两层架构**：底层是反应式控制层 MoBeE（实时保安全），顶层是好奇 agent（探索并学世界模型）。
- **关键直觉**：把规划器"具身化"——让底层控制器实时强制所有约束（关节限位、线缆长度、自碰撞），于是规划器**可以放心地"试动作"而无需预先穷举校验可行**；参考轨迹变得多余，规划器只需存储/调用/下发控制命令，也不再要求工作空间静态。约束的避让由底层动力学系统自动完成。
- **为什么好奇能加速**：在真实硬件上"试动作"极其昂贵（受限于实时、不能并行/加速），所以必须**高效探索**。好奇 agent 用"信息增益"奖励，把试动作的精力集中到"学习还在进步、模型还不准"的区域，而不是已经摸透的无聊区域——这就是它比随机探索快的根源。

## 动机 & 背景
- 人工好奇(Artificial Curiosity, AC)：由依赖世界模型的价值函数驱动的**定向探索**，奖励应基于**学习进步**(learning progress)而非单纯的不可预测（否则会盯着本质随机、无法学习的区域发呆）。本文用信息论的**信息增益/KL 散度**度量"有趣程度"，与 Itti & Baldi 的"贝叶斯惊奇"同源。
- 定位在自主心智发展(AMD)/发展机器人学(Developmental Robotics)脉络下：通过试错、内在动机逐步学出可复用技能。
- 作者指出过往发展机器人学的好奇实现要么用预编程高层运动基元、要么离散化、要么用极简机器人；"我们不知道有任何 AC（或其他内在动机）实现能学习并利用复杂机器人的高维位形空间"（原文主张其新颖处）。

## 方法细节
- **底层 MoBeE**（来自作者另一篇工作，本文只用其"动作"定义）：用二阶动力系统持续高频控制机器人：
  - 公式(1)：`M q̈(t) + C q̇(t) + K(q(t) − q*) = Σ f_i(t)`，其中 `q(t)∈ℝⁿ` 是位形，M/C/K 为质量/阻尼/弹簧常数矩阵，`q*` 是吸引子；约束通过虚拟"约束力" `f_i(t)` 推开机器人，自动避让关节限位、线缆长度、碰撞。
  - **一个"动作"= 把吸引子 `q*` 设到某个目标位形**；机器人朝 `q*` 运动，动作在系统稳定或超时时终止——最终落点可能到达 `q*`，也可能被约束力顶偏到别处。
- **状态-动作空间离散化**（图3）：在位形空间选 m 个采样点 `Q={q_j}`，每个采样点的 **Voronoi 区域**就是一个状态 `s_j∈S`（用欧氏范数作距离）。状态是"区域"不是"点"。
  - 每个状态连到它的 **k = 2ⁿ 个最近邻**（直觉：n 维超立方体有 2ⁿ 个顶点），动作 `A(s)` 即"试图移动到这 k 个邻居状态之一"。由此 `|A|=|S|`，但每状态只看 k 个动作，故状态-动作数随状态数**线性**增长。作者指出这个连法让 Markov 模型形似 PRM 的 Roadmap 图。
- **转移概率 T 与三类结果**：动作"意图"到目标态，实际可能落在任意态，故须学习 T 表征位形空间连通。三类（作者实测只见这三类）：
  - 公式(3) 确定性到达目标态 `s_g(a)`；
  - 公式(4) 确定性落到另一个固定态 `s*≠s_g(a)`（如被关节限位/线缆长度可预测地偏折）；
  - 公式(5) 真正非确定（落点是个小集合，通常在初始态邻域、且由"碰到可移动物体"等动态约束引起）。作者强调真正非确定的态在全空间中**占比很小**，大部分位形不受约束、动作都如计划完成。
- **人工好奇 = 信息增益 = KL 散度**：
  - 公式(6)：`D_KL(P‖T) = Σ_j ln(P_j/T_j)·P_j`，T 是当前估计的转移分布、P 是观测到新一次转移后更新的分布；二者差异越大说明模型被这次经验改进越多 → 作为内在奖励 `R(s,a)`。agent 因此被吸引到"学习正在进步"的区域。
  - **两个隐患**：① KL 在 P、T 有为零分量时无定义，而本应用里大多分量本来就是零；② KL 数值对分布的基数(状态空间大小)敏感（公式7–10举例：同样首次尝试不论结果都给相同奖励 0.0589；小状态空间数值上更"有趣"）。
  - **解法——动态/压缩转移分布 + 乐观初始化**（Algorithm 1 `Observe`）：T、P 初始**没有任何 bin**，每观测到一个新落点 s′ 就给 T 追加一个 bin 并初始化为 1（同时更新 P），再算 KL。这样：(a) 绕过零分量问题；(b) 乐观初始化让**每个动作第一次尝试都"有趣"**，可配合贪心、激进的策略；(c) 奖励随经验积累而衰减（表1–4 展示 T/P/R 随观测的演化：确定性到目标态的动作"无聊"得快=表2，确定性到惊讶态稍慢=表3，多落点的非确定动作最"有趣"、衰减最慢=表4）。
- **RL 求解**：模型已学好后用**值迭代**(Algorithm 3，`V_new(s,a)=R(s,a)+γΣ_{s'}T(s,a,s')V(s')`)；探索循环(Algorithm 2 `Curious_Explore`)= 先把每个 state-action 各 observe 一次做乐观初始化，再反复"值迭代→在当前态选 V 最大的贪心动作→在真机上执行→observe"。超参 **γ=0.9，收敛阈 δ=0.001**。
- 注意：内在奖励 `R_intrinsic` 只随 (s,a) 变（不依赖落点 s′）；要"利用"该规划器去做具体任务，需另加一个外部奖励替换/叠加内在奖励（本文实验只跑探索/建模阶段，**未真正加外部目标做规划任务**）。

## 数据集 & 实验设置
- 平台：**真实物理 iCub 人形机器人**（非仿真），通过 MoBeE/YARP 控制。两个在线学习实验。
- **实验一（静态环境，单臂）**：状态空间 4 维=3 个肩关节 + 肘关节，每关节取活动范围 25%/50%/75% 三档 → 81 顶点的 4D 格点，每点连 2⁴=16 邻居 → **81×16=1296 个状态-动作**。任务=学出自碰撞与线缆长度不可行区，从而能有效规划运动。对比三种探索策略：好奇(AC) vs 随机(RAND) vs 总选最少尝试的(LT, least-tried)。跑约 12 小时。
- **实验二（多 agent，全身）**：控制双臂+躯干共 **12 DOF**。12 维超立方体有 4096 顶点，均匀采样不可行，故**拆成三个互不知道彼此状态的好奇 agent**分别控左臂/右臂/躯干。臂的状态空间同实验一；躯干用 3D 格点(27 顶点、连 2³=8 邻居)=216 状态-动作。iCub 放在工作桌前（桌子是大障碍）。跑约 50 小时(约18000+次状态转移做统计)。可视作三个相互影响的 POMDP，或"把一条臂看成另一条臂的动态障碍"。

## 主要结果 & 结论（写方向，不堆精确数字）
- **AC 是最高效的探索者**：在状态-动作空间覆盖上，AC 明显优于 RAND 和 LT（图4，observed）。早期 AC 与 LT 都只试新动作、RAND 会重复试旧动作；但 AC 因为有**全局价值**（看重"有很多未试动作"的状态、会专门跑过去），覆盖优势随学习拉大；AC 大约用 **LT 三分之一的时间**就试遍所有状态-动作（observed，约见 §3.1 与图4）。
- **AC 的访问/尝试分布比 RAND、LT 更均匀**（图5，observed）；少数被反复尝试的尖峰对应"撞到约束、结果有趣"的动作（其奖励按表3/表4衰减得慢，故被更多关注）。内在奖励随时间整体衰减且衰减均匀（图6）——agent 逐渐"变无聊"，说明模型越学越好。
- **重要发现：静态约束并不总导致确定性转移**（observed，§图7讨论）。学出的 MDP（图7）里多数动作如预期确定到达目标态（灰色），但部分动作即使在静态环境、同一段控制代码下也时而到目标、时而偏走——源于 iCub 作为轻量线缆驱动机器人的**非线性动力学**，使其无法可靠复现精确运动。作者由此主张"PRM 这类先规划后执行的方法在 iCub 上永远难以奏效，且机器人越轻越柔，非线性越主导"（作者明确主张，但属定性论证）。
- **多 agent 涌现行为**（图8–10，observed）：三个只靠内在奖励、互不通信的 agent 协同出"探索桌面"的行为——iCub 学会避开桌子约束，随后**对桌子产生兴趣并频繁触碰**，在"空中探索"和"摸桌面"之间周期性切换。最常被选的动作=把臂放低、躯干前倾去够桌子（图10）。左右臂行为分布高度相似（机械对称、离散化相同）。
- **动态环境视角的结论（未实证、属推断）**：若给某目标加外部奖励、去掉内在奖励重算价值函数，得到的策略会**绕开状态转移概率低（即常有障碍）的区域**——即该框架原则上能在动态障碍环境里规划。作者明说这是"key thing to observe"式的论断，本文并**未真正跑带外部目标的动态规划实验**。
- **可扩展性结论**：本实验中状态空间"绰绰有余地可处理"；真正的瓶颈是**在真机上把所有动作各试几次的时间**，而非值迭代计算——"机器人从一个位姿移到另一个的时间，比更新价值函数的时间约大一个数量级"（observed/supported，§4.1）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：高自由度、带难以建模非线性、不能靠精确仿真预校验轨迹的真实机器人（如线缆驱动人形）；需要在线、增量地学一个可复用的连通性/转移模型；探索预算昂贵、必须聪明分配试探精力的场景。
- **前提依赖**：必须有一个能实时强制全部约束的反应式底层控制器（MoBeE）兜底安全，否则"放心试动作"不成立。
- **不太管用/未覆盖**：状态-动作空间目前**靠手工构造**（采样、连通），是主要短板；本文给出的是探索+建模的可复用规划器**雏形**，并未实测"加外部目标→完成具体取放/到达任务"的端到端规划性能；非确定性高、约束频繁变动的极端环境下未验证。
- **比较基线偏弱**：实验只与 RAND、LT 两个朴素探索基线比覆盖效率，**未与主流规划器（PRM/RRT）或其他内在动机方法做定量任务级对比**——对 PRM 的劣势更多是定性论证。

## 核心贡献
- 首次将人工好奇/内在动机**具身到真实多自由度人形机器人(iCub)**，在线学出基于 MDP 的运动规划器（作者强调的首创点）。
- 提出"具身规划器"思路：用实时反应式控制层强制约束，从而免去 PRM 式的预先轨迹校验和静态工作空间假设；MDP 的每条边不再代表一条具体轨迹，而是"尝试去往某区域"的更一般动作。
- 用 **KL 散度信息增益**作内在奖励，并以**动态压缩分布 + 乐观初始化**(Algorithm 1)同时解决"零分量无定义"与"对状态空间基数敏感"两大问题，使乐观初始化能配合贪心策略激进探索。
- 实证 AC 探索效率优于随机/最少尝试基线，并展示多 agent 并行控制全身、涌现出协调探索桌面的行为，论证该方法朝"智能控制整个人形"的可扩展性。
- 揭示真实轻量机器人下"静态约束≠确定性转移"，论证 plan-first 范式在此类机器人上的固有缺陷。

## 局限与我的质疑
1. **缺任务级、定量的评估**：全文核心证据是探索覆盖曲线（图4–6）和定性可视化（图7–10），没有把学到的规划器真正用于完成某个外部目标任务并给出成功率/路径质量/与 PRM/RRT 的对比数字。"能规划"在本文更多是**架构论证而非实证**——"动态环境能绕障"完全是推断（"the resulting policy/plan will try to avoid…"），并未实验。结论应按 observed 读，勿当作"已证明可做实时运动规划"。
2. **基线偏弱**：只与 RAND、LT 比探索效率。LT/RAND 都是无模型朴素策略，AC 胜出几乎是必然；缺与同类内在动机方法、或与成熟规划器的横向比较，难判断方法相对前沿的真实增量。
3. **状态-动作空间手工构造**（作者亦自述为主要短板）：采样点、k=2ⁿ 连通都靠人定，且作者承认"连通比实际需要的更密"。这使方法离"自主发展"还有距离，且离散化粒度/连法如何影响规划质量未做敏感性分析。
4. **可扩展性论证不充分**：12 DOF 已经必须拆成三个互不通信的 agent 来回避状态空间爆炸，本身说明单一 MDP 难扩到全身；多 agent 间通过物理后果"松耦合"，其协调是涌现的、无理论保证，更多自由度/更复杂任务下是否仍稳定未知。"层级 agent"被列为未来工作。
5. **样本效率与真机代价**：作者自己点出瓶颈是真机试动作时间（实验跑了 12h/50h 才得到上述结果）。对更高维问题，"试遍所有状态-动作各几次"的成本可能不可承受，而文中并未量化好奇相对随机到底省了多少真机时间（只给"约 1/3 LT 时间"的覆盖性说法）。
6. **对本研究主题(RL 训练可交互数字人/通用工具箱)的契合度有限**：这是 2014 年、表格驱动的离散 MDP + 值迭代方案，规模小（≤1296/216 状态-动作）、无深度网络、无连续控制策略、无 sim-to-real 现代手段；其价值更多在**思想层面**（具身好奇、信息增益奖励、用反应式底层让规划器敢试错），而非可直接复用的现代算法基线。
