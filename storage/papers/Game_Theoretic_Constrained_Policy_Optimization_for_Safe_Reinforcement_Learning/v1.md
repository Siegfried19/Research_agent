# Game-Theoretic Constrained Policy Optimization for Safe Reinforcement Learning
> Changxin Zhang, Xinglong Zhang, Yixing Lan, Hao Gao, Xin Xu · 2025 · IEEE Transactions on Neural Networks and Learning Systems · 引用 3 · DOI 10.1109/tnnls.2025.3586603

## 一句话
把"带约束的安全RL(CMDP)"重新建模成一个**多玩家一般和马尔可夫博弈**:任务玩家专心最大化回报、每个约束玩家专心把对应代价压到限值以下,各玩家用**各自独立的子策略**,再用一套"主导时间尺度(dominant timescale)"机制决定每步谁主更新,从而**绕开拉格朗日乘子/权衡超参的调参,并缓解多目标共享一套参数时的梯度冲突**。

## 解决了什么问题
- 现有 CMDP 安全RL(拉格朗日、reward shaping、信赖域/CPO 等)有两个痛点:① 对**权衡超参/学习率敏感**,初值和量纲一变就要重调,换任务/换奖励代价尺度就不灵;② 多个目标(任务+多约束)更新**同一套策略参数**时方向不一致,产生**梯度冲突**,损害学习。(见 §I、Fig.1)
- 本文目标:在**不引入对偶变量、不调权衡因子、也不依赖可行初始化**的前提下,既保证学习收敛、又满足约束。

## 用什么方法解决的（含直觉：为什么 work）
- **核心思想:目标分家 → 玩家分家 → 子策略分家。** 把 CMDP 写成 task-constraints Markov game(TCMG):玩家集合 {0,1,…,m},玩家0=任务玩家(max 累积回报 J_r),玩家1..m=约束玩家(把各自累积代价 J_{c^i} 压到限值 d^i 以下,**注意是"满足即可"而非一味最小化**,见式(6)与正文"stay below d^i instead of minimizing")。
- **联合动作 = 各玩家动作相加再裁剪。** Mixer 函数 `a = a^0 + a^1 + … + a^m, s.t. a∈A`(式(4)),超界用 `Clip(a, a_min, a_max)`。直觉(Fig.3):任务玩家给"朝目标"的动作(绿箭头),约束玩家给"避危险"的修正动作(红箭头),二者向量叠加成智能体真实动作(黑箭头)——是一种连续的合作+竞争混合博弈,而不是像 shielding/安全层那样"先算好再事后改",从而避免改得太晚救不回来。
- **为什么能消梯度冲突(关键直觉):** 每个目标交给**独立的子策略参数**去优化,不再让一套参数同时被多个相互矛盾的梯度拉扯;冲突在"分配不同参数"这一步被天然化解(§III-A)。
- **主导时间尺度机制(Def.2,治"何时该听谁"):** 设两个学习率 αd > αn ≥ 0。每个更新步只选一个玩家当"主导玩家"用**快**学习率 αd 更新(式(7) θ_i ← θ_i − αd∇J_i),其余玩家用**慢**学习率 αn 更新(式(8))。选谁主导的规则(Algorithm 1):**所有约束都满足 → 任务玩家主导**(去冲回报);**有约束被违反 → 任选一个被违反的约束玩家主导**(去把它压回限内)。直觉:谁"最该被照顾"谁就跑得快,于是策略被反复推向"先满足约束、再在可行域里抬回报"。
- **收敛靠 Nash Q-learning 的压缩映射。** 值函数按 Nash 算子 `P_t Q(s,a)=E_{s'}[r(s,a)+γV^Nash(s')]`(式(11))迭代,该算子在完备度量空间上是压缩映射,故 Q 收敛到不动点(Nash Q 值),联合策略收敛到 Nash 均衡(Theorem 1)。
- **落地是即插即用:** 把上面机制套进标准 actor-critic 即可——和 SAC 组合叫 GCSAC,和 PPO 组合叫 GCPPO,和 DDPG 组合叫 GCDDPG;**相比无约束RL只多一个超参:主导学习率 αd**(实验里固定取 αd = 1.2·αn)。

## 动机 & 背景
- CMDP(Altman)是安全RL常用框架:在 MDP 上加 m 个约束,要求期望累积代价 `J_{c^i}(π) ≤ d^i`(式(1))。主流解法:拉格朗日松弛、reward shaping、信赖域类(CPO 等)。
- 作者把已有思路画在 Fig.1:(a) reward shaping、(b) 拉格朗日、(c) 信赖域都需要"灰色"的预设/在线调参参数;(d) GCPO 用博弈结构把任务和约束分到不同分支。
- 与两篇"博弈思路安全RL"的区别(§II-A):[45] DESTA 是"安全动作过滤/拦截",[46] 是零和博弈处理**对抗扰动鲁棒性**且在任务策略与安全策略间**切换**、约束仍走拉格朗日;本文声称是**首个用一般和博弈正式求解 CMDP**、用**一套联合策略同时**处理任务与安全、不做策略切换。
- 与 shielding/CBF/安全层/可达安全区等"改不安全动作"的方法区别:那些常需环境先验或可行初始解、且事后改动作会带来行为不连续;GCPO 学一个联合策略,不需先验也不需可行初始化(§II-A)。

## 方法细节
- **TCMG 形式化** `⟨I,S,A,P,γ,r,C⟩`,C={c^i,d^i};各玩家策略 π^i,联合策略 π=⟨π^0,…,π^m⟩(§III-A)。
- **目标(式(6)):** π^0_*=argmax J_r(π);π^i_*=argmin J_{c^i}(π)(但实际只要压到 ≤ d^i)。
- **值更新(式(9)):** 对任务与各约束分别维护 Q,`Q^r_{t+1}=(1−β_t)Q^r_t+β_t[r+γV^r_t(s')]`,约束同理用 c^i;其中 `V^r_t(s')=E_{s'~P,a~π_t}[Q^r_t(s',a)]`(式(10))。约束评估 `J_{c^i}(π_t)=E_{ξ,π_t}[Q^{c^i}_t(s,a)]`,作者指出**该约束评估步不需额外与环境交互采样**(从 ξ,π_t 采即可)。
- **策略优化:** 主导玩家用 αd、其余用 αn;约束玩家朝 min J_{c^i} 更新,任务玩家朝 max J_r 更新;满足的约束玩家可"暂时挂起"(temporarily suspended)。
- **理论假设与结论:**
  - Assumption 1:Q 步长满足 Robbins-Monro 条件(RL 收敛常规假设)。
  - Assumption 2:每个 stage game 的均衡或是全局最优、或是鞍点(来自 Nash Q-learning,[53])。作者**坦承**学习期的 stage game"很少完全满足"该假设,但实验中即便违反也观察到稳定收敛。
  - Theorem 1(收敛):在 Assumption 1、2 + GLIE(贪婪且无限探索)下,Q 收敛到 Nash Q 值(证明靠式(11)压缩映射 + Lemma 1–3,见 Appendix A)。
  - Assumption 3:对主导/非主导更新分别设期望改进下界 ε1、期望下降上界 ε2(式(12)(13))。
  - Theorem 2(约束满足):在 Theorem 1 + Assumption 3 且 **ε1 > (m−1)ε2** 下,收敛联合策略满足 `J_{c^i}(π_*) − d^i ≤ 0`(式(14)–(20))。
  - Proposition 1(局部最优,Appendix B):在 **ε1 > m·ε2** 下,联合策略收敛到 CMDP 的**局部最优且可行**解。作者明确指出 Nash 均衡对应**联合策略空间的局部最优**,**不保证全局最优**(可能不捕捉目标间的全局协作)。

## 数据集 & 实验设置
- **环境与对比(三类基准):**
  1. **四旋翼轨迹跟踪**(Safe-Control-Gym,[59]):状态 `[x,ẋ,z,ż,θ,θ̇]`、动作两推力 `[T1,T2]`,要求高度 z∈[0.5,1.5](约束 c(s)=0 若 0.5≤s^(3)≤1.5 否则 1,式(21))。off-policy 的 **GCSAC** vs SAC-SI、SAC-CBF、SAC-RS、SAC-Lagrangian、RAC(可达约束RL,[12])。
  2. **Safety-Gym**(MuJoCo,带 LiDAR,[60]):PointGoal1/CarGoal1/DoggoGoal1/PointPush2,观测 60D–104D,Doggo 动作 12D,约束限值 d=25。on-policy 的 **GCPPO** vs PPO-Lagrangian、TRPO-Lagrangian、CPO、CPO-lm、CUP、CVaR-CPO(后者数值取自原文献)。
  3. **多尺度鲁棒性**:自建 SquareMapEnv(10×10 方格,导航到小目标区、避开危险区),用 **GCDDPG** vs DDPG-RS、DDPG-Lagrangian,测三种奖励/代价尺度(1:1、10:1、100:0.1,Table II)。
  4. **受约束操作任务** FreightFrankaCloseDrawer(Safety-Gymnasium / Isaac Gym):移动底盘+机械臂关抽屉且避红区,57D 观测、12D 动作,GCPPO vs PPO-Lag/TRPO-Lag/CPO/CUP,测三种尺度。
- **超参:** αd = 1.2·αn;其余学习率与对比算法一致;约束目标设为智能体累积安全代价。两个 GitHub 仓库公开(SquareMap、2Constraints)。

## 主要结果 & 结论（写方向，不堆精确数字）
- 四旋翼任务:GCSAC **零违约**且接近最优跟踪精度,轨迹严格留在安全集内;对比中 SAC-CBF 因策略保守导致跟踪误差大、SAC-SI 倾向把飞行器推出上界、拉格朗日法学习波动大、RAC 收敛更慢(observed,单任务,Fig.6/7)。
- Safety-Gym:在所有三个被报告的基准上,**GCPPO 在"已满足约束"的方法中取得最高回报**(Table I,PointGoal1/CarGoal1/PointPush2 回报最高且满足约束)(supported)。
- DoggoGoal1(高维 Doggo):**只有 GCPPO 满足约束**;CPO 回报更高(约 27.88,见 Table I)但**严重违约**(代价约 76.57,远超限值 25);作者把别家失败归因于"任务与约束冲突时单套参数被两方向同时拉扯"(observed)。
- 对主导学习率 αd 的敏感性:αd∈{3.3,4,5,10,20}×10⁻⁴ 学习曲线(尤其约束满足)基本一致,说明对 αd **在较宽范围内鲁棒**,该唯一新增超参调参成本低(supported,Fig.11)。
- 多尺度鲁棒性:GCDDPG 在 1:1/10:1/100:0.1 三种尺度都能既安全又学好;reward shaping 在三尺度上**一致失败**,拉格朗日法**仅在尺度2成功**——印证传统法对奖励/代价量纲敏感、需精细调参(supported,Fig.12/13)。
- 受约束操作任务:GCPPO 在各尺度下都能维持约束满足同时拿到高回报(supported,Fig.15)。
- 理论结论:在所列假设下**证明了**收敛到 Nash 均衡(Thm.1)与约束满足(Thm.2),并在更强条件下给出**局部最优**(Prop.1);全局最优**未被证明**、被明确留为开放问题。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用:** ① 多目标/多约束、且奖励与约束代价**量纲尺度差异大或未知**、不想反复调权衡超参的连续控制任务;② 没有可行初始解、不便用拉格朗日对偶或 primal-dual(后者对初始化敏感)的场景;③ 需要"约束硬满足优先、再抬性能"的安全关键任务(四旋翼、机械臂操作)。可即插即用嵌 SAC/PPO/DDPG,on/off-policy 均可。
- **不(那么)管用 / 需注意:** ① 追求**全局最优回报**时——本方法只保证 Nash 均衡=局部最优,Doggo 上 CPO 回报更高(代价是违约),说明若可放松安全、GCPO 不一定回报最高;② 约束个数 m 大时,约束满足定理要求 ε1 > (m−1)ε2,m 增大对"主导改进必须显著大于非主导退化"的要求更苛刻(理论隐含,作者称该条件实践中难直接验证);③ 联合动作靠**向量相加+裁剪**合成,若各玩家动作尺度/语义不匹配,Mixer 的合理性存疑(原文未对 Mixer 的设计权衡做消融)。

## 核心贡献
- 提出 **GCPO**:首个(作者自述)从**一般和博弈**视角正式求解 CMDP 的安全RL框架,用 task-constraints Markov game 把任务与各约束分给独立子策略,绕开权衡超参、缓解梯度冲突。
- 设计**主导时间尺度机制**(两学习率、按约束是否满足切换主导玩家),并给出**收敛(Thm.1)+约束满足(Thm.2)+局部最优(Prop.1)**的理论分析。
- 即插即用实现(GCSAC/GCPPO/GCDDPG),在四旋翼、Safety-Gym、自建多尺度环境、Isaac Gym 操作任务上实验,展示对任务奖励/约束代价**尺度变化的鲁棒性**(这点作者称以往工作很少关注)。

## 局限与我的质疑
1. **理论假设强且作者自承难满足/难验证。** Assumption 2(stage game 全局最优或鞍点)作者明说学习期"很少完全满足";Theorem 2 的关键条件 ε1 > (m−1)ε2、Prop.1 的 ε1 > mε2 作者也承认"不易验证(not easy to verify)"。于是"保证约束满足"在实践中更多是**经验现象**而非可核验的保证——理论与实测之间存在缺口。
2. **只保证局部最优,回报上限可能吃亏。** 作者自己点明 Nash 均衡=联合策略空间局部最优、不保证全局最优;DoggoGoal1 上 CPO 回报显著更高(虽违约)。若任务对回报敏感而对安全可适度放松,GCPO 的"安全优先"反而可能不是最优选择——把"满足约束下最优"说成普遍优越需谨慎。
3. **基线虽含 SOTA,但部分对比口径需打问号。** 部分对比数值(CVaR-CPO)直接取自原文献而非作者复现,跨实现可比性有限;DoggoGoal1/PointPush2 上 CVaR-CPO 缺值(Table I "—"),覆盖不完整。"全面超越 SOTA"应降级为"在所报告基准、在满足约束的方法中回报最高"。
4. **新增的"主导玩家选择"含随意性。** 多约束被违反时"任选一个(arbitrary)"当主导,这个选择策略既未优化也未做敏感性分析(只分析了 αd 的敏感性),它对收敛速度/稳定性的影响是盲区。
5. **Mixer 用动作向量直接相加,缺乏论证与消融。** 联合动作 = Σ 各玩家动作再裁剪,这一关键设计为何合理、是否优于其他融合方式(加权、注意力等)没有实验或理论支撑;裁剪本身也可能破坏各子策略的梯度一致性。
6. **与本研究主题(安全约束RL中处理多目标梯度冲突)契合,但"消除梯度冲突"是结构性论断而非直接度量。** 论文用"分配独立参数→天然无冲突"做直觉论证,但**没有直接测量/可视化梯度冲突的减少**(如梯度夹角、冲突频率),性能提升被归因于消冲突,因果链条偏间接。
