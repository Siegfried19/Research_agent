# Broad Critic Deep Actor Reinforcement Learning for Continuous Control
> S. Thalagala, P. Wong, Xiaozheng Wang, Tianang Sun · 2024 · IEEE Transactions on Neural Networks and Learning Systems · 引用 3 · DOI 10.1109/tnnls.2025.3554082

## 一句话
把 actor-critic 连续控制算法（DDPG/TD3/SAC）里的 critic 网络从深度神经网络（DNN）换成"宽度学习系统"（Broad Learning System, BLS），用岭回归闭式解代替梯度下降来估 Q 值，actor 仍保留 DNN 用策略梯度更新，从而在不损精度的前提下显著缩短训练时间。

## 解决了什么问题
- 深度强化学习（DRL）依赖深层 DNN 同时逼近策略和价值函数，导致计算成本高、训练时间长，尤其在高维状态-动作空间的在线连续控制中明显（作者动机，见 §I 摘要与引言）。
- DNN 要提升精度通常要加层、并对所有层用梯度下降重估参数，更新慢（作者论点，§I）。
- 作者主张 critic 的 Q 值估计本质是"回归任务"，适合用结构更浅、训练更快、且支持增量学习（不必重建网络即可加精度）的 BLS 来做（§I、§II-D）。

## 用什么方法解决的（含直觉：为什么 work）
- 核心：提出 **BCDA（Broad Critic Deep Actor）** 混合架构——critic 用 BLS（称 BCN，Broad Critic Network），actor 用 DNN（称 DAN，Deep Actor Network）。supported（架构本身是确定的设计）
- **为什么这样分工（直觉）**：critic 学的是一个回归函数（状态-动作→Q 值），有闭式最小二乘/岭回归解，可一步算出权重，省掉迭代梯度优化，所以训练快；actor 学的是策略（概率分布或确定动作），要靠策略梯度定理做可微的梯度上升，而 BLS 用"固定随机特征映射 + 不可微的伪逆"无法把梯度反传到策略输出，因此 actor 不适合换成 BLS（§II-D "Rationale for Choosing BLS for Critic Networks"）。
- **BCN（BLS critic）怎么算**（§II-A/B、图1）：输入 X = {s_t, a_t}。
  - 先做特征节点：`Z_i = ϑ(X·W_{f_i} + β_{f_i})`，i=1..n（式3），W_f、β_f 随机生成、ϑ 是非线性映射；所有特征节点记作 `Z^n = [Z_1,…,Z_n]`（式4）。
  - 再做增强节点：`H_j = ξ(Z^n·W_{e_j} + β_{e_j})`，j=1..m（式5），W_e、β_e 也随机生成；记作 `H^m = [H_1,…,H_m]`（式6）。
  - 拼接后过输出层：`Y = [Z^n | H^m]·W_n^m`（式7）。令 `A_n^m = [Z^n|H^m]`，输出权重用岭回归伪逆求闭式解：`W_n^m = (A_n^m)^+ = (A_n^m (A_n^m)^T + λI)^{-1} (A_n^m)^T Y`（式8、9）。
  - **增量学习（IL）**：精度不够时可只加增强节点（式10–13）或加特征节点，按 BLS 理论只需对新增矩阵更新伪逆、不必重算整个 `A_n^m`，因此"加精度"很便宜——这是 BLS 相对 DNN"加层重训"的关键优势（§II-B）。
- **目标值 / 训练信号**：BCN 的目标数据是 Q 学习的 target Q 值 `y_t`：终止态 `y_t = r_t`，否则 `y_t = r_t + γ_t·max Q(s_{t+1}, a_{t+1})`（式1、2），其中下一动作由 t-DAN 生成、下一 Q 由 t-BCN 估计。**注意机制差异**：BCN 不是去最小化均方贝尔曼误差（MSBE，式1）的梯度，而是把 `y_t` 当回归标签、用岭回归直接拟合（§II-B "BCN Training"），这点和传统 RL 用梯度下降降 MSBE 不同。
- **三个变体**（§II-C）：
  - BCDA-DDPG：单 BCN critic，actor 按 DDPG 方式（[11]）梯度上升更新。
  - BCDA-TD3：把 TD3 的孪生 DNN critic 换成两个 BCN，仍取二者最小 Q 抗高估：`y_t = r_t + γ_t·min_{i=1,2} Q^{(i)}_{t-BCN}(s_{t+1}, t-DAN(s_{t+1}))`（式16）；actor 仍 DNN。
  - BCDA-SAC：两个 BCN 替换 SAC 的孪生 critic，保留熵正则的 target：`y_t = r_t + γ_t·(Q − α·logπ_{t-DAN}(s_{t+1}))`，`Q = min_{i=1,2} Q^{(i)}_{t-BCN}(s_{t+1}, a_{t+1})`（式17、18），α 动态调到目标熵；高斯随机策略的 actor 仍是 DNN。
- 目标网络 t-BCN/t-DAN 用软更新：`ϕ_{t-BCN} ← ρ·ϕ_{t-BCN} + (1−ρ)·ϕ_{BCN}`（式14、15）。整体流程见 Algorithm 1。

## 动机 & 背景
- 强化学习在机器人、自动驾驶、工业过程控制、航空航天等连续控制中有前景，但在线训练时学习效率与计算成本是关键考量（§I）。
- BLS（Chen & Liu，[9]）是浅层、增量式网络，相比 DNN 结构更简单、训练计算量更小，且能增量加节点提精度而不必重建网络（§I）。
- 相关工作铺垫：已有把 BLS 用进基础 Q 学习（[14] BRL for IoT、[15][16]）的尝试，但局限于低维离散空间或需预采集离线数据集做岭回归；[17] 探索 BLS 做 RL 信号处理但没碰 actor-critic（§II 开头综述）。
- 作者声称的新颖性（§II 列表）：据其所知**首次**把 BLS-based critic 整合进 actor-critic 算法、并首次把 BLS-based RL 用于连续控制；混合用梯度下降（actor）+ 岭回归（critic）；并引入多项鲁棒性技巧（调正则强度、集成 BCN、dropout）。

## 方法细节
（见上"用什么方法解决"——式1–18、Algorithm 1、图1 BCN 架构）。补充：
- actor 更新沿用原算法（DDPG 用 [11] 的策略梯度），critic 不反传梯度而用伪逆闭式解，这是省时来源。

## 数据集 & 实验设置
- 7 个 MuJoCo（[22]）+ OpenAI Gym（[23]）连续控制任务：Inverted pendulum (INP, 4维状态)、Inverted double pendulum (DIN/DINV)、Reacher (REA, 2-DOF)、Pusher (PUS)、Ant (ANT)、Half cheetah (HCH)、Humanoid (HUM, 376维状态/17维动作)，覆盖低到高维（§III-A）。
- BCDA-DDPG 在全部 7 个任务对比 DDPG；BCDA-TD3、BCDA-SAC 只在最难的 HCH、HUM 两个任务对比 TD3、SAC（§III-A）。
- 每实验 5 个随机种子、跑 100,000 步，每 5000 步评估（评估时不加动作噪声），记平均 reward 与平均训练时长；硬件 NVIDIA Tesla T4 GPU，TensorFlow（[24]）实现（§III-A）。
- 超参：base BCN（b-BCN）= 10 特征节点 + 500 增强节点；所有 BCN 变体的 shrinkage=0.8、正则因子=2^{−30}、学习率=0.005；DNN（actor 及 DDPG）均三层、每层 256 隐节点、ReLU（§III-A）。
- 源码作者声明公开：https://github.com/ShironT/bcda （§I 脚注）。

## 主要结果 & 结论（写方向，不堆精确数字）
- **训练时间**：BCDA-DDPG 在全部 7 个任务上都比 DDPG 快，效率提升从约 22%（HUM）到约 68%（INP）不等（Table II）。supported（7 任务系统对比）
- **精度（最终/最高 reward）**：BCDA-DDPG 在多个任务上的"5 次试验最大平均 reward"持平或略高于 DDPG（Table I）。**注意幅度很小**——例如 HCH 3504.00 vs 3451.64、PUS −27.43 vs −31.27（reward 越大越好），多数任务几乎打平（INP/ANT 完全相同，HUM 实际持平）。observed（精度提升幅度小，更多是"不掉精度"而非"显著超越"）
- **收敛速度**：在所有控制任务上 BCDA-DDPG 初期学习曲线更陡、更快趋向最优 reward（图3、图6、图7）。supported
- **但都没真正解最优**：作者明说在 ANT/HCH/HUM 等复杂任务里，BCDA-DDPG 和 DDPG **都没在 10^5 步内收敛到最优 reward**（§III-B）——即 BCDA 是"更快接近"，不是"解了 DDPG 解不了的"。supported（作者自述）
- **TD3/SAC 变体**：在 HCH、HUM 两任务上，BCDA-TD3 比 TD3、BCDA-SAC 比 SAC 学习更快、精度更高、且 reward 方差波动更小（更稳）（图4、图5）。observed（仅 2 个任务）
- **鲁棒性消融（仅 INP 任务，§III-C）**：更强正则 λ=2^{−20} 比 baseline λ=2^{−30} 让收敛后 reward 方差降约 18.12%，但略损学习速度；λ=2^{−40}（弱正则）方差暴增约 89.59%、不稳（Table III）。加集成 BCN + dropout 进一步降低收敛后波动（图7b）。observed（单任务）
- **增量学习消融（仅 REA 任务，图8，§III-D）**：Scheme-3（加 5 特征节点 + 300 增强节点）平均 reward 最高；无 IL（Scheme-1）容量不足欠拟合；增强节点太少（Scheme-2）收敛慢；特征节点过多（Scheme-4）冗余、训练不稳。observed（单任务，说明节点数需权衡）
- 总结论方向：把 BLS 当 critic 嵌进 actor-critic，**能在基本不损精度下显著省训练时间并加速收敛**，适合对计算效率/快速适应敏感的实时控制（§IV）。

## 适用边界（什么时候管用 / 什么时候不管用）
- 管用：在线连续控制、对训练时长/计算成本敏感、需要快速收敛或快速适应的场景；从低维（INP 4维）到高维（HUM 376维）任务均测过，省时在低维任务上最明显（INP 省约68%，高维 HUM 仅约22%——省时收益随维度上升而递减）。observed
- 对比的是**强基线**：DDPG/TD3/SAC 是连续控制主流强基线，且 TD3/SAC 本身已优于 DDPG，作者目标是"在这些强算法上再加 BCDA 提效率而不损精度"（§III-A）。
- 不管用 / 不解决的：BLS 不能做 actor（无法反传梯度到策略、确定性非概率输出），随机策略的 actor 仍须 DNN（§II-D）——所以 BCDA 不是"全 BLS"方案。
- 作者自述待解：BLS-based actor 仍是开放问题（§II-D）；向"工业级 TB 量数据"的大规模可扩展性需进一步优化（§IV，提到稀疏 BLS 剪枝、分布式岭回归、量化训练等方向）。

## 核心贡献
1. 提出 BCDA 混合 actor-critic 架构：BLS 做 critic（岭回归闭式解 Q 值）+ DNN 做 actor（策略梯度），作者称首次把 BLS-critic 用进 actor-critic 连续控制（§II 新颖性、§IV）。
2. 把该框架实例化为 DDPG/TD3/SAC 三个变体（BCDA-DDPG/-TD3/-SAC），且架构对三者一致、仅参数更新环节不同（§II-C）。
3. 引入并消融三类鲁棒性技巧（调 λ、集成 BCN、dropout）缓解 BLS 过拟合（§III-C）。
4. 在 7 个 MuJoCo 任务上系统验证训练时间显著下降（22%–68%）且精度不降（Table I/II）。

## 局限与我的质疑
1. **"精度提升"被措辞放大，实质是"几乎打平"**：Table I 多数任务 BCDA 与基线 reward 差距极小（INP/ANT 完全相同，HUM 928.10 vs 928.105，REA −1.36 vs −1.39），摘要却写"surpass... in accuracy"。真正站得住的卖点是**省时**，"提精度"几乎无证据支撑——读者别被"更准"误导。
2. **统计显著性缺失**：只跑 5 个种子、报"最大平均 reward"（5 次里的最大值，对噪声/离群极敏感），没给标准差表、置信区间或显著性检验。HCH 3504 vs 3451 这种~1.5% 差异在 RL 高方差下很可能落在噪声内，不能当"更好"。
3. **消融只在单个、最简单的任务上做**：鲁棒性（§III-C）只在 INP、IL 分析（§III-D）只在 REA，都是低维易任务。在 HUM/ANT 这种高维任务上这些技巧是否有效、节点数怎么选，原文没验证，泛化性存疑。
4. **省时来源未拆解 / 公平性存疑**：训练时间对比（Table II）没说两边是否在相同总步数、相同 wall-clock 评估开销下比；BLS 伪逆在大 batch / 高维 `A_n^m` 上的矩阵求逆成本随节点数增长，作者也承认对"TB 级数据"扩展性未解（§IV），所以"省时"在更大规模是否保持未知。
5. **TD3/SAC 变体证据单薄**：只在 2 个任务（HCH/HUM）上比，就下"BCDA 普遍改善 SAC/TD3 效率与精度"的结论，覆盖面不足，属 observed 被往 supported 方向写。
6. **方法描述有小瑕疵 / 可复现性**：Algorithm 1 第7–10 行动作采样的条件（`t<T or t=T` 随机、`t>T` 用 DAN）写法可疑、像笔误；BCN 的 target `y_t` 依赖 t-BCN 自身估计的 max Q，BLS critic 是否会和 DNN critic 一样有高估/发散问题、岭回归闭式解在非平稳 RL target 下的稳定性，作者未深入分析。
7. **对本研究主题（SAC/TD3/DDPG 横向算法增强）的相关性**：本文是"换 critic 实现以省算力"的工程增强，不改 RL 的探索/样本效率/最优性本质，也未在更现代的强基线或更大规模 benchmark 上验证；若关注的是"样本效率"或"最终性能上限"而非"训练 wall-clock 时间"，本文增益有限。
