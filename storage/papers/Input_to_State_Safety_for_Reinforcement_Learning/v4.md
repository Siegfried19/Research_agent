# Input-to-State Safety for Reinforcement Learning.
> Jha M.S., Marthi S., Vamvoudakis K.G., Kanso S., Theilliol D. · 2026 · IEEE transactions on neural networks and learning systems · 引用 0 · DOI 10.1109/tnnls.2026.3688045

## 一句话
针对**连续时间非线性仿射系统、且执行器有饱和（输入限幅）**的安全强化学习，提出一套端到端框架：用可调的"input-to-state safe"放大安全集 + 一个随状态自适应收紧/放松的 ε-调节律做在线安全过滤器，保证**初始化、探索（采数据）、学习三个阶段都安全**，并给出饱和下的离策略（off-policy）最小二乘闭式更新。

## 解决了什么问题
- 标准 CBF-based 安全 RL 在**探索阶段**（注入大幅探测噪声采数据）常被忽视安全性，或在安全边界附近过度保守、甚至不可行，反而把"最该采到的近界数据"采不到。(motivation)
- 既有 ISSf-CBF 方法虽能在有界扰动下保证更大不变集的前向不变，但**控制律设计偏保守**；可调 ISSf-CBF（TISSf）虽减保守却没结合执行器饱和与安全学习。
- 多数工作**假设已有一个初始可行的安全策略**、且**不考虑控制输入饱和**（执行器限幅会裁剪实际施加的行为输入，改变轨迹、并使忽略饱和的离策略更新失效）。
- 本文要在**同时考虑饱和 + 大幅探测激励 + 离策略学习**的设定下，端到端地保证安全、稳定、最优。

## 用什么方法解决的（含直觉：为什么 work）
- **系统与饱和**：仿射系统（式 1）`ẋ = f(x) + g(x)u(t)`，输入受饱和约束 `|u_i| ≤ ρ`（或 `‖u‖_∞ ≤ ρ`）。`x=0` 是平衡点，满足 **`f(0)=0`、`g(0)` well defined**（原文明确只设这两条，未设 g(0)=0），系统在 Ω 上可镇定。
- **用 tanh 把饱和"装进"代价函数**：采用广义非二次型性能指标（式 2），其中输入代价 `U(u)=2∫₀ᵘ ρ(Γ⁻¹(v/ρ))ᵀ R dv`，`Γ=tanh`（式 3）。由此推出的最优控制天然带饱和：`u*(x) = -ρ tanh((1/2ρ)R⁻¹ gᵀ(x)∇V*(x))`（式 7），因 tanh∈(-1,1) 保证 `|u*|<ρ`。直觉：把"超限的控制"在目标里惩罚到无穷，最优解就自动落在限幅盒子内。
- **安全集**：用户给的安全函数 `h(x)`（C¹），安全集 `C={x: h(x)≥0}`（式 8），安全=`C` 前向不变（Def 2）。文中区分 RCBF（边界处发散，Def 3）与 ZCBF（边界处趋零，Def 4）和 CLF（Def 5）。
- **探索阶段的"放大安全集"（Tunable ISSf-Exp）**：探索时注入有界探测噪声 `e_u(t)`，作为**匹配扰动**进入系统（式 15）`ẋ=f(x)+g(x)(u+e_u)`。构造一个**比 C 更大的集** `C_{ξ,T}`，由 `h_{ξ,T}(x,ξ)=h(x)+γ_T(h(x),ξ)`（式 16）的 0-超水平集定义（式 17–19），并要求它在 `‖e_u‖≤ξ` 下前向不变。直觉：**留出一圈缓冲**——只要把放大集守住，真正的安全集 C 自然不会被噪声推出去。
- **ISSf-Exp-CBF 条件（Def 7，式 20）**：`sup_u[L_f h + L_g h·u] ≥ -α₄(h(x)) + ‖L_g h‖²/ε(h(x))`。`ε` 越小 → 右端越大 → 约束越严（更保守、更防护）；`ε` 越大 → 约束越松（允许更激进输入）。
- **核心创新：ε 随状态自适应的调节律（式 24–25）**：`ε(h)=ε₀+(ε_max-ε₀)(1-exp(-σ(h)/τ))`，其中 `σ(h)=0 (h≤0)`、`σ(h)=h·exp(-1/(κh)) (h>0)`，`κ≈10⁵`。**直觉（为什么 work）**：当状态接近安全边界（h→0）时 `ε→ε₀`（小）→ 约束（式 20）收紧 → 控制保守、强力把状态拉回；当状态深在安全集内部（h 大）时 `ε→ε_max`（大）→ 约束放松 → 容许大幅探测噪声做"近界但仍安全"的丰富探索。于是**保守度随到边界的距离自动调**，既不像经典 CBF 全程一刀切保守，也不像固定/倒数型 ε 在边界处保护不足。
- **理论保证（探索）**：Theorem 1 证明，若 h 是 ISSf-Exp-CBF 且用此 ε-调节律，则系统在 `‖e_u‖≤ξ` 下经历 ISSf-Exp、放大集 `C_{ξ,T}` 前向不变（用 Nagumo 定理）。Lemma 1 给出 `γ_T` 与 `α₄` 的关系 `γ_T(h,ξ)=-α₄⁻¹(-ε(h)ξ²/4)`（式 21）。
- **在线安全过滤器（QP，式 32）**：解 `min (1/2)‖u_QP‖² + (p/2)δ²`，约束含 CLF 条件（带松弛 δ 保可行）+ ISSf-Exp-CBF 条件 + 饱和硬约束 `-ρ1 ≤ u_noisy+u_QP ≤ ρ1`。它是**最小范数修正**：在满足 CLF/CBF/饱和的前提下，对（含探测噪声的）行为输入做尽量小的纠正。决策维度只有 m+1（输入维+1 个松弛），便于实时。
- **安全学习的代价改造（式 33–35）**：把性能指标里的效用改成**安全感知效用 r_safe**（式 33），在原效用上加一个 RCBF 候选项 `B_λ(h(x))`，取 `B_λ(h)=-log(λh/(λh+1))`（式 34），λ 是阻尼系数。直觉：状态在安全集深处时该项≈0、几乎不影响最优性；逼近边界时该项**急剧增大**，于是最小化 `V_safe`（式 35）会学到"把状态保持在安全集内部"的策略。λ 越小越强调安全（更保守），越大则越快地随远离边界而衰减惩罚（更接近原始 safety-agnostic 效用）。
- **安全策略迭代（S-PI，Algorithm 1）**：策略评估解广义安全感知 HJB（G-SHJB，式 41/42），策略改进 `u^(i+1)=-ρ tanh((1/2ρ)R⁻¹gᵀ∇W^(i))`（式 43）。
- **离策略实现（Algorithm 2）**：行为策略采数据 + 目标策略迭代改进；价值函数（critic）与策略（actor）用神经网络/基函数逼近 `Ŵ=ĈᵀΦ`、`û=ρ tanh(ÛᵀΨ)`（式 50）。推导出**饱和下的离策略最小二乘闭式回归**（式 51–54，Lemma 6），actor 参数化 `u=ρ tanh(UΨ)`（式 64）天然保饱和。Remark 10 指出：**离策略更新本身数据驱动、不需显式模型**，但在线 QP 安全过滤器仍需控制仿射模型（或其辨识近似）来算 Lie 导数。

## 动机 & 背景
- 安全 RL 要在学习全过程（初始化/探索/学习）守住状态在安全集内；CBF/CLF-QP shielding 是主流。
- 已有进展：ISSf（输入到状态安全）→ ISSf-CBF（放大不变集抗有界扰动）→ TISSf-CBF（可调放大集减保守，文献 [2][3][15]）；CLF 表征镇定控制族 [30]，CLF+CBF 在 QP 框架下统一稳定与安全 [4][9]。
- 本文定位：在这些基础上，**专门把"近界安全探索 + 持续大幅激励 + 执行器饱和 + 离策略"四件事一起做**，并给闭式离策略表达。

## 数据集 & 实验设置
- 纯**仿真**，两个低维例子：
  1. **倒立摆**（式 65）：m=1 kg, g=9.81, l=1 m；安全集 `C={-5≤x₂≤3}`；Q=diag([0.1,0.01]), R=0.001, |u|≤5；critic 基 N₁=22、actor 基 N₂=9、m=1、PI 未知参数 p=31。探测噪声为多正弦叠加随机相位（式 68）。
  2. **喷气发动机喘振/失速**（式 69）：安全集 `C={-1.1<x₂<0.45}`；Q=diag([20,10]), R=0.3, |u|≤10，α₄=20。
- 比较设置：探索阶段对比**经典 CBF 过滤器、固定 ε、倒数型 ε=1/h(x)、本文 ε-调节律**；整体对比**无安全过滤器 / 经典 CBF / 本文 ISSf**三种。参数表见 Table I/II（不同 ε_max、τ 组合）。

## 主要结果 & 结论（写方向，不堆精确数字）
- 探索阶段：**经典 CBF 能保安全但全程一致保守**，把轨迹压在安全集内部、限制近界探索；**固定/倒数型 ε** 能减保守但在大幅噪声下出现**边界越界或保护不一致**；**本文 ε-调节律在两个例子上都做到"近界丰富探索 + 不越界"**（Fig 1–3、8–10）。observed（仅在这两个仿真任务上展示）。
- 整体三方对比：**无过滤器→探索期越界（违反安全）**；**经典 CBF→安全但保守、近界激励受限**；**本文 ISSf→保持约束满足且允许更丰富的近界探索，调控性能与经典 CBF 相当**（Fig 5、11）。observed。
- 学习收敛：actor-critic 价值函数**少数迭代即收敛**——倒立摆约 17 步（Fig 6），喷气发动机约 7–8 步；值函数随迭代单调（Fig 7，印证 Lemma 5）。observed。
- 参数作用：**ε_max 主要塑造近边界行为**（越大→近界 QP 修正越弱、越激进）；**τ 主要调瞬态快慢/激进度，而非安全集不变性本身**（Fig 9/10）。supported（作者多组参数实验佐证）。
- 结论方向：在饱和 + 大幅激励 + 离策略设定下，框架可同时给出安全初始化/探索/学习的理论保证，并用闭式 LS 实现离策略更新。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：连续时间、**控制仿射**、执行器对称（或可分量化处理非对称）饱和的非线性系统；安全规范能写成光滑 `h(x)`（盒/多面体/椭球/距离型约束）；存在有效的 ISSf-Exp-CBF 与可行 CLF；扰动是**匹配的、有界的**探测噪声/不确定性。
- **需要模型**：在线 QP 安全过滤器要算 Lie 导数 → 需控制仿射模型或其辨识近似（Remark 10 自承）；只有离策略学习更新是数据驱动免模型。所以"免模型"只对学习更新成立，安全过滤层不免。
- **可能不管用/受限**：**非匹配扰动**未处理（作者列为未来工作）；高维系统未验证（只给 2 状态例子）；需要存在初始可行安全策略（Assumption 2）与合理选定的多组超参（ε₀, ε_max, τ, κ, λ, ξ 及手工基函数）。

## 核心贡献
- 把**近界安全探索形式化为放大集（ISSf-type）上的鲁棒安全问题**，并通过带饱和界的 CLF/CBF-QP（ISSf-Exp-QP）强制执行。
- 提出**指数型 ε-调节律**：边界处收紧、内部放松，减少保守同时允许大幅、近界的持续激励探索。
- 在**在线安全过滤器与安全感知学习目标中一致地纳入输入饱和**，并严格建立端到端的安全、稳定、最优性证明。
- 给出**饱和下的离策略闭式最小二乘表达**（式 51–54），使方法可在数据驱动、免模型的离策略架构中实现。

## 局限与我的质疑
1. **实验偏弱、规模小**：只有两个 2 维仿真（倒立摆、喷气发动机），与摘要/致谢里"Heterogeneous Robots Fleet"的宏图相比，没有高维、没有真实机器人、没有噪声鲁棒性/统计重复实验；近界探索的"更丰富"主要靠轨迹图定性展示，缺定量指标（如采到的数据信息量、违约率统计）。结论强度应停在 observed。
2. **基线偏弱**：安全过滤层只对比"无过滤 / 经典 CBF / 固定或倒数 ε"，**没有**与其它 ISSf-CBF/TISSf-CBF 或其它安全 RL 方法（如 [15][19] 的学习阶段）做正面定量较量；"不牺牲调控性能"只是定性"comparable"。
3. **"免模型"是局部的**：在线 QP 仍需模型/辨识来取 Lie 导数（Remark 10 自承），只有离策略更新免模型——标题与卖点容易让人误读为整套免模型。
4. **收敛缺一般性保证**：作者承认对一般非线性系统**没有 PI 迭代次数的解析上界**（只报实验迭代数与停止准则），所谓"少数步收敛"是经验现象。
5. **参数与基函数工程量大**：ε₀, ε_max, τ, κ(≈10⁵), λ, ξ 及高阶单项式基函数（式 66/70）都靠手工设计/调，论文给的是经验指导（Remark 11），实际可移植性存疑。
6. **关键定理外包**：Theorem 5 的证明直接"follows from [19]"，本文未自给完整论证；其结论是 utility 函数 r_safe 最小值趋零，并不等于"值函数能趋零"或"安全余量被消除"，使用时勿过度解读。
7. **匹配扰动假设较强**：把探测噪声当匹配扰动是支撑整套 ISSf 推导的关键前提；现实中模型/辨识误差多为非匹配，作者明确将其留作未来（"absorbed into the disturbance bound"只是设想，未实现）。
