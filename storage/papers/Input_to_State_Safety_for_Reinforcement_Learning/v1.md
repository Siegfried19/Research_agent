# Input-to-State Safety for Reinforcement Learning.
> Jha MS, Marthi S, Vamvoudakis KG, Kanso S, Theilliol D · 2026 · IEEE transactions on neural networks and learning systems · 引用 0 · DOI 10.1109/tnnls.2026.3688045

## 一句话
本文为**带执行器饱和的连续时间非线性系统**提出一套端到端的安全强化学习框架：用"输入到状态安全(ISSf)"把探测噪声当作匹配扰动、把安全集放大，再配一个**随到边界距离自适应的 ε-调节律**，让系统能在贴近安全边界处做高幅度激励探索而不越界，并用 off-policy 最小二乘的 actor-critic 在饱和约束下学到最优安全控制律。

## 解决了什么问题
- 经典 CBF/QP 安全滤波器在安全边界附近**过度保守**（甚至不可行），导致数据采集恰恰在"最该探索的近临界区"质量很差。
- 持续激励(persistent excitation)在连续时间系统里往往需要高幅度探测信号，标准 CBF 难以兼顾"安全"与"信息丰富的近边界探索"。
- 执行器饱和(actuator saturation)是被以往安全 RL 工作普遍忽略的硬约束；饱和会裁剪施加的行为输入、改变轨迹，并使忽略饱和的 off-policy 更新失效。原文称"现有工作均未同时考虑输入饱和，以及 off-policy 方案下的饱和"。
- 目标是在**探索阶段(数据采集)和利用阶段(学习)统一地**保证安全(safe initialization / exploration / learning，即"端到端安全")。

## 用什么方法解决的（含直觉：为什么 work）
三块拼起来：

1. **ISSf-Exp-CBF + ε-调节律（探索期安全滤波）**：把探测噪声 e_u 视为"匹配扰动"，定义一个比真实安全集 C 更大的不变集 C_{ξ,T}（放大量由噪声界 ξ 和调节量决定）。只要在放大集上保持前向不变，叠加噪声后真实集 C 仍不变 → 数据采集期安全。
   - **直觉**：ε(h) 越小，约束式右端 ‖L_g h‖²/ε(h) 越大 → 约束越严、修正越强（保守、护栏）。设计 ε 随安全裕度 h 变化：贴边界(h→0)时 ε 小 → 强力护栏防越界；深入内部(h 大)时 ε 大 → 放松约束 → 允许高幅度噪声探索。于是"近边界也能探但不出界、内部不瞎保守"，破解经典 CBF 全程一刀切保守的毛病。

2. **饱和下的安全学习（safety-aware cost + 安全 PI）**：把奖励里加一个**互反型 barrier(RCBF)** B_λ(h)，状态深处时≈0、逼近边界时→∞，于是"最小化代价"天然把状态往内部推、不碰边界。饱和靠**非二次代价**用 tanh 自然把控制约束在 ρ 内。再用安全策略迭代(S-PI)交替"策略评估(解 G-SHJB)+策略改进"。

3. **off-policy 安全 RL（数据驱动、免模型更新）**：分行为策略(注入噪声、经 QP 滤波后施加)与目标策略(只更新不施加)；critic/actor 用神经网络基函数逼近，权重由一个**新推导的闭式最小二乘回归**求解 —— off-policy 更新本身不需要显式模型(只在线滤波器需要 control-affine 模型或其辨识近似)。

## 动机 & 背景
- 安全=安全集的**前向不变性**；CBF 有 ZCBF(边界处趋零)与 RCBF(边界处趋无穷)两类。ISSf-CBF(文献[15])通过放大可容许集来对抗有界扰动；Tunable ISSf-CBF([2][3])显式参数化放大量以减保守。
- 本文建立在这些之上，**新增三件事**：把饱和一致地纳入在线滤波器与学习目标；ε 自适应调节让放大量随状态变化；给出 off-policy 闭式解。
- CLF/CBF 在 QP 框架里统一稳定性与安全性([4][8][9])；本文沿用 CLF/CBF-QP 作为护栏。

## 方法细节
- **系统**：ẋ = f(x) + g(x)u(t)，饱和 |u_i| ≤ ρ（式1）；x=0 为平衡点，f(0)=0。
- **非二次性能指标**：U(u) = 2∫₀ᵘ ρ(Γ⁻¹(v/ρ))ᵀ R dv，Γ(·)=tanh（式3）；据此得广义 HJB（式4），最优控制 **u\*(x) = -ρ tanh( (1/2ρ) R⁻¹ gᵀ(x) ∇V\*(x) )**（式7）—— tanh 保证控制天然落在 ±ρ 内。
- **ISSf-Exp-CBF 条件（式20）**：sup_u [L_f h + L_g h·u] ≥ -α₄(h) + ‖L_g h‖²/ε(h)。ε 越小右端越大 → 约束越严。
- **ε-调节律（式24-25）**：ε(h) = ε₀ + (ε_max - ε₀)(1 - exp(-σ(h)/τ))，其中 σ(h)=0（h≤0）、σ(h)=h·exp(-1/(κh))（h>0），κ≈10⁵ 当阻尼系数让 σ(h)→h 迅速。ε∈[ε₀, ε_max]：边界处≈ε₀(保守)，内部→ε_max(放松)。τ 控制过渡深度/适应快慢。
- **Lemma 1** 建立 γ_T 与 α₄ 的关系：γ_T(h,ξ) = -α₄⁻¹(-ε(h)ξ²/4)（式21），证明放大集随 ξ、ε 缩放。
- **Theorem 1（ISSf 探索）**：在 ε-调节律下放大集 C_{ξ,T} 对所有 ‖e_u‖∞≤ξ 前向不变 → 探索期 ISSf 安全（用 Nagumo 定理，证毕）。
- **鲁棒 QP 安全滤波（式32）**：min ½‖u_QP‖² + (p/2)δ²，约束=CLF（带松弛 δ，软约束保可行）+ ISSf-Exp-CBF（硬约束）+ 饱和 -ρ1 ≤ u_noisy+u_QP ≤ ρ1。是最小范数修正的在线滤波器。**Remark 3**：饱和编码为硬约束。
- **安全学习目标**：RCBF 取 **B_λ(h) = -log( λh/(λh+1) )**（式34）；安全感知奖励 r_safe = Q + B_λ(h) + 非二次 U 项（式33），代价 V_safe（式35）。
- **安全 PI（Algorithm 1）**：策略评估解 G-SHJB（式42）；策略改进 u^{(i+1)} = -ρ tanh((1/2ρ)R⁻¹ gᵀ∇W^{(i)})（式43）。
- **off-policy（Algorithm 2）**：把动态改写成行为/目标策略分离形式（式49）；critic Ŵ=ĈᵀΦ、actor û=ρ tanh(ÛᵀΨ)（式50）；权重解最小二乘 Θ̃ᵢᴺ[vec(Ĉ);vec(Ûᵀ)] = Ẽᵢᴺ（式51-54），需 N≥N₁+mN₂ 个样本且回归矩阵满列秩。**actor 必须用 ρΓ(UΨ) 形式（式64）以保证学习期也满足饱和**。

## 主要结果 & 结论（写方向，不堆精确数字）
- **无滤波**在高幅度噪声下探索会把系统推出安全界、产生越界违规（observed，图5/图11）。
- **经典 CBF**保住安全但**全程一致保守**，轨迹被压在安全集内部、限制近边界探索（observed，图1/图5/图11）。
- **本文方法**在同等高幅度噪声下既保持约束满足、又允许更丰富的近边界探索，调节性能与基线相当（"regulation performance remaining comparable"）（observed，倒立摆+喷气发动机两例）。
- **ε_max 主要塑造近边界行为**：增大 ε_max 放松约束→更靠边界探索、修正更弱；过大可能在激进激励下削减鲁棒裕度（observed，图2/图9）。
- **τ 主要调过渡瞬态**：小 τ→增益变化快、近约束处瞬态更陡、切换更多；大 τ→更平滑更保守。原文称 τ"主要调节瞬态激进度而非整体安全集不变性"（observed，图3/图10）。
- **学习收敛**：actor-critic NN 训练倒立摆约 17 步、喷气发动机约 7–8 步收敛；值函数随迭代单调下降（observed，图6/图7，且与 Lemma 5 单调性一致）。
- **理论(已证明)**：安全(Theorem 2)、稳定(Theorem 3，安全区内一致稳定)、最优(Theorem 4，W^{(i)}→W\*、u^{(i)}→u\*)、ISSf 探索不变性(Theorem 1)、以及 Theorem 5（适当选 RCBF 参数 λ 可把安全感知值函数最小值逼到任意接近 0）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：control-affine 连续时间非线性系统；有已知饱和界 ρ；安全规范可写成光滑 h(x)（box/polytope/椭球/距离约束等有解析形式）；x=0 可镇定；噪声为**有界匹配扰动**(‖e_u‖∞≤ξ)。
- **在线 QP 滤波器需要 control-affine 模型(f,g)或其辨识近似**来算 Lie 导数；只有 off-policy 权重更新是免模型的（Remark 10）。这点限制了"完全无模型"的适用性。
- **不直接管**：非匹配扰动(unmatched disturbance)——作者明列为未来工作；建模/辨识误差当前未严格纳入(仅设想吸收进噪声界)。
- ξ 由探测信号界给定、ε₀ 选为近 ∂C 仍能保 QP 可行的最小值；λ 需让 Q 在安全区内"压住"B_λ（Remark 8），否则保守性/性能权衡失衡。
- 对比的是**强基线**（经典 CLF/CBF-QP 安全滤波[12]，是该领域标准护栏），不是弱基线，这点可信度较好。

## 核心贡献
1. 把安全探索表述为**鲁棒安全问题**：引入 ISSf 型放大集，通过 CLF/CBF-QP（含饱和界）强制 ISSf-Exp-CBF 约束。
2. **指数型 ε(h) 调节律**：近边界收紧、内部放松，在高幅度持续激励下做"边界感知"探索而减保守。
3. 在**在线滤波器与学习目标里一致地纳入输入饱和**，并严格给出端到端的安全/稳定/最优性证明（Theorem 1–5、Lemma 1–6）。
4. off-policy 实现，并**新推导饱和下的闭式最小二乘表达式**（式51–63），更新过程数据驱动、免显式模型。

## 局限与我的质疑
1. **实验规模与说服力偏弱**：仅倒立摆+喷气发动机两个低维(n=2, m=1)经典 toy 系统、纯仿真，无统计性报告（多随机种子的均值/方差、违规率统计、消融对照表都没有量化汇总，结论主要靠时域轨迹图"看出来")；"探索更丰富""性能相当"缺乏量化指标(如累计奖励、覆盖度、违规次数)，因此这些结论我只敢标 observed，不能外推到高维/真实机器人。
2. **"免模型"被过度暗示的风险**：摘要/卖点强调 off-policy 数据驱动，但在线 QP 安全滤波器仍需 f,g（或其辨识）来算 L_f h、L_g h、L_f V、L_g V。读者若误以为整套无模型会踩坑——真实系统里 g(x) 误差直接影响安全保证，而文中未分析模型误差对 ISSf 不变性的冲击（仅在结论里"设想"把它吸收进扰动界，未做）。
3. **理论保证依赖若干强假设**：Theorem 1 需 h_{ξ,T} 的 0 为正则值、∂h_{ξ,T}/∂x≠0；稳定性/最优性需初始策略可容许、安全且 RCBF 参数选得当(λ 让 Q 压住 B_λ)。这些在低维例子里可手调，但**如何系统地选/验证仍偏经验**（Remark 11 给的是经验指南而非保证），新系统冷启动可能很难。
4. **收敛性无一般上界**：作者自承"一般非线性系统下 PI 步数无解析上界"，只报经验步数（~7–17）。对工程落地的可预测性有限。
5. **ε-调节律里 κ≈10⁵ 等参数偏 ad-hoc**：σ(h) 的平滑正部代理函数引入 κ、τ、ε₀、ε_max 多个需手调旋钮，超参敏感性未充分扫描（Fig 2/3/9/10 只各扫一个维度、固定其余），实际调参负担可能不小。
6. **与本研究主题(可与环境交互的 RL / safe-RL)对照的不足**：这是**连续时间控制论范式**(HJB/PI/CLF-CBF)，不是主流深度 RL(无回放、无 actor-critic SGD、无离散动作/图像观测)；它处理的是已知结构的低维动力系统，迁移到高维深度策略/复杂环境交互并不直接，"RL"一词在这里更接近自适应最优控制(ADP)而非现代深度 RL。
7. **引用 0 + 接受稿(未定页)**：尚无第三方复现/验证，结论可信度待时间检验。
