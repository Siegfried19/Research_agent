# Value Bonuses using Ensemble Errors for Exploration in Reinforcement Learning
> Abdul Wahab, Raksha Kumaraswamy, Martha White · 2026 · arXiv · 引用 0 · DOI arxiv:2602.12375

## 一句话
VBE 维护一组"随机动作值函数"(RQF)，用预测器追逐随机目标产生的 TD 误差当作 **value bonus**（直接加到价值上、不经 reward bonus 传播），从而获得"首次访问乐观性"与深度探索，并能以仅约两倍计算的代价**插到任意 off-policy 价值算法之上**。

## 解决了什么问题
- 基于价值的 RL 探索常靠"乐观价值估计"，但主流的 reward bonus 方法（RND、ACB）把不确定性放进奖励、再用第二个价值函数传播，**只有回溯性乐观**：只有在某状态已被访问、看到高 reward bonus 之后才回头抬高其价值，**不鼓励"首次去访问一个没去过的状态-动作"**（即缺 first-visit optimism）。
- Bootstrap DQN with priors（BDQN）虽有 first-visit optimism，但**难用**：要把整套算法改成维护并更新一个集成、还要调"跟随集成中某个价值函数多久再切换"等关键设计选择，常需大集成。
- 目标：做一个**易用、可叠加到现有算法上**的定向探索方法，去替换默认的 ε-greedy，而不必大改底座。

## 用什么方法解决的（含直觉：为什么 work）
- 核心对象：行为策略改成"价值 + 价值奖励"的贪心 π_b(s) = argmax_a q_w(s,a) + c·b(s,a)，其中 b(s,a) 是 value bonus，c 是 bonus scale。价值奖励应反映该 (s,a) 的不确定性。
- **最朴素版（类 RND，Eq 2）**：采样 k 个随机网络 f_i 作目标，学一组 f̂_i 去拟合，bonus 取 b(s,a) = max_{i∈[k]} |f̂_i(s,a) − f_i(s,a)|。作者指出这样"误差收缩太快"，不能像深度探索那样兼顾"它会通向哪个状态"的不确定性。
- **VBE 的关键改造**：不让集成成员去做监督学习拟合随机函数，而是把每个 f_i 视为一个**随机动作值函数（RQF）**，并反推出"与该 RQF 自洽的随机奖励"，再用标准 TD 自举去学一个预测器 f_{w_i}。
  - 随机集成奖励（Eq 3）：R_{i,t+1} = f_i(S_t,A_t) − γ_{t+1} f_i(S_{t+1},A_{t+1})，其中 A_{t+1}∼π。
  - **Proposition 1（带望远镜式抵消证明）**：在策略 π 下，由该奖励定义的真实动作值 q_i^π 恰好等于 f_i 本身（q_i^π = f_i）。直觉：奖励是"f_i 的一步 TD 差分"，把它沿时间累加，相邻项逐对抵消（telescoping），只剩 f_i(s,a)。
  - **为什么 work（机制核心）**：因为目标 RQF f_i 与预测器 f_{w_i} 取自同一函数类（realizable），预测器最终能把 f_i 学到、误差 |f_i − f_{w_i}| → 0，于是 **value bonus 会自然衰减到零**；而在它被充分学会之前，没访问过的 (s,a) 上预测器与随机目标必然有较大误差 → 给出**首次访问乐观性**。又因为这些 RQF 用和主价值函数一样的 TD 自举、同样的时间尺度学习，bonus 的"乐观"会像价值一样**沿轨迹向前传播**，鼓励朝"通向不确定状态"的方向深度探索。
- **bonus 还能反映 MDP 的转移动态（Proposition 2）**：b(s,a) = max_i |E[γ_{t+1}(f̂_i(S_{t+1},A_{t+1}) − f_i(S_{t+1},A_{t+1}))|s,a] + ε_i(s,a)|，含下一状态项 → 与只看自身随机网络的 RND 不同，VBE 的 bonus 能体现转移的随机性/不确定性。
- **算法（Algorithm 1，底座用 Double DQN）**：每步 (1) 照常 DDQN 更新 q_w；(2) 随机抽一个 i，按 Eq 5 用 TD 更新该 RQF 预测器 f_{w_i}，其奖励为 r_i = f_i(s,a) − γ f_i(s', argmax_{a'} q_w(s',a'))。注意 RQF 用主价值的贪心策略（target policy = greedy in q_w）采样动作。**每步只更新一个 RQF**（更新整个集成既贵又没必要；少更新让 bonus 衰减更慢）→ 每步计算量约为 DDQN 的两倍。
- **保证乐观初值（Proposition 3）**：在单位长特征、权重 iid 高斯的假设下，给出集成大小 k 与 bonus scale c 的下界，使 q(s,a) + c·max_i|f_i − f_{w_i}| > q_max 以高概率（1−δ）成立 → 说明 ensemble error 能提供足够的 first-visit 乐观。

## 动机 & 背景
- 乐观价值估计在 contextual bandit 有成熟理论，但扩到深度 RL 的理论多限于线性函数逼近（UCLS、UBE）或依赖访问计数（Dora），难扩展到一般函数逼近。
- 现有深度 RL 乐观法两条路线：① BDQN/随机价值函数（Thompson 采样式，从集成里抽一个价值函数跟随一整集）；② reward bonus（Bellemare、RND、ACB 等，把不确定性加进奖励）。VBE 想取 BDQN 的 first-visit 乐观、又要 reward bonus 的易用性。
- 论文明确把 b 称为"价值奖励"而非"置信区间"，并在脚注说明：它们用的启发式不保证是有效的置信上界（"it is not clear we get a valid upper confidence bound"）。

## 方法细节
- 价值更新底座 DDQN（Eq 1），δ = r + γ q_{w̄}(s', argmax_{a'} q_w(s',a')) − q_w(s,a)。
- RQF 预测器更新（Eq 5）：w_i ← w_i + η δ_i ∇f_{w_i}(s,a)，δ_i = r_i + γ f_{w̄_i}(s', argmax_{a'} q_w(s',a')) − f_{w_i}(s,a)；用目标网络 f_{w̄_i} 自举。
- 控制 bonus 衰减速度的两个旋钮：集成大小 k（越大衰减越慢）和"每个 RQF 多久更新一次"（越少更新衰减越慢）。
- 收敛讨论（§3 末 + 附录 A）：在固定策略下，TD 理论（LSTD 以 1/√T 收敛、神经 TD 在单隐层 ReLU 下收敛到全局解、gradient-TD 在 off-policy + 非线性下收敛）支持 f_{w_i}→f_i；但 VBE 中**行为策略与目标策略都随时间变**，作者承认"据我们所知尚无理论能保证这种情形收敛"，只是实验中观察到 bonus 总会收敛到零。
- 与 BDQN 的联系：把 BDQN 的随机先验 q_θ = f_θ + c·p 展开，其 RQF 隐含奖励是 VBE 的 Eq 3 奖励的缩放负值；两者估计的量相似，**关键区别**是 BDQN 用 Thompson 采样诱导乐观、VBE 对乐观价值直接贪心；且 BDQN 的先验 bonus 被 c 缩放会把目标方差放大 c²、使优化更难、对学习率敏感，而 VBE 估 RQF 时不含 c、只在行为策略里用 bonus scale。

## 数据集 & 实验设置
- 四个经典探索环境：Sparse Mountain Car、Puddle World、River Swim、Deepsea（含一个纯探索的 Tabular Deepsea，agent 收不到环境奖励、用 one-hot 线性逼近测纯状态覆盖）。
- 六个 Atari：Private-Eye、Pitfall、Gravitar（硬探索）+ Breakout、Pong、Q*bert。4×84×84 帧、跳 4 帧、reward 裁到 [−1,1]、3 个种子、2500 万步。
- 基线：BDQN、reward bonus 方法 ACB、RND，以及 DQN-P（DQN 加固定 additive prior，可看作集成大小=1 的 BDQN）。ACB/RND 用 DDQN 版以公平；也比了 PPO 版（附录 B，发现更不省样本）。
- 消融 **VBE-SL**：把 RQF 的 TD 更新换成监督学习（直接拟合随机目标），用来检验"误差衰减太快→探索不足"的假设。
- 经典控制：2 隐层各 50 节点；50000 步、30 次运行（Deepsea 10000 episodes、5 次）。Atari：3 CNN 层共享表示 + 价值头；VBE 用 k=10 共享表示只更新 RQF 头、c=10；ACB 用 k=128、RND 用 512 节点 CNN 目标/预测器。各环境最佳 (k,c) 见附录表 1–3。

## 主要结果 & 结论（写方向，不堆精确数字）
- **纯探索 Deepsea 状态覆盖**：VBE 在所有网格尺寸（30–50）都**覆盖全部状态空间**，且只需集成里 **1 个 RQF** 就做到；BDQN 仅在 30、35 覆盖、更大网格失败；ACB、RND 覆盖差（ACB 甚至不如 DQN-P）；VBE-SL 强于 ACB/RND/DQN-P 但弱于 VBE。supported。（图 1、表 1）
- **VBE-SL 验证了机制假设**：监督学习版有 first-visit 乐观（优于 reward bonus 法）但**价值奖励衰减太快**，探索不如完整 TD 版 VBE → 支持"用 TD 让 bonus 与主价值同尺度学习"的设计动机。observed→supported。
- **经典控制四环境**：VBE 学得更快、最终性能在四个环境里都最好。supported。（图 2）
- DQN-P 出人意料地在四个里有三个与 BDQN 相当；在稀疏奖励的 Mountain Car 失败。observed。
- RND 在 River Swim、Puddle World 有竞争力，但在 Deepsea 多数运行学不到最优策略。observed。
- ACB 在 Puddle World 有竞争力但 Deepsea 失败。observed。
- 结论方向：reward bonus 法（ACB/RND）"在经典控制里一般无法提供有效探索"，因缺 first-visit 乐观（论文还分析出：它们在 Deepsea 偶尔能学好，其实是靠线性层 bias 项 + 优化器动量的副作用抬高了未见 (s,a) 的价值，而非真有 first-visit 乐观——见附录 F）。supported。
- **Atari**：VBE 在所有六个游戏上**一致地优于 BDQN**。observed。相对 RND/ACB 则是**互有胜负、整体相当**：RND 在 Breakout/Pong/Q*bert 与 VBE 很接近、Pitfall 略好、Gravitar 先好后掉回与 VBE 持平；Private-Eye 谁都学不好但 VBE 似乎收到更高奖励更频繁。作者自评为"on par with, if not better than"。observed。（图 3）
- 目标策略选择（附录 F）：贪心 target policy 一般比乐观 target policy 表现更好（乐观目标会过度探索），故 VBE 选 off-policy 贪心目标。observed。

## 适用边界（什么时候管用 / 什么时候不管用）
- **最受益场景**：硬探索、稀疏/欺骗性奖励、需要 first-visit 乐观与深度探索的环境（Deepsea、Sparse Mountain Car、River Swim）——这正是 VBE 相对 reward bonus 法拉开差距的地方。
- **bonus scale c 与集成大小 k 要按环境调**：River Swim 这种硬探索环境，增大 c 和 k 提升性能；而 Puddle World、Mountain Car 不需要太多探索，**增大 c/k 反而损害性能**（附录 E）。即"探索越多越好"并不普适。
- **依赖 realizable 假设**：bonus 能衰减到零，前提是预测器 RQF 与目标 RQF 同函数类。若不可表示，则"乐观自动消退、收敛到贪心"的好性质不一定成立。
- **易用性是卖点**：因价值奖励单独估计、只影响行为策略，可叠加到许多 off-policy 价值算法（甚至 actor-critic 用乐观 critic）；每步计算约两倍 DDQN。
- 在密集奖励、探索本就不难的环境，相对 ε-greedy/DQN-P 的增益可能有限（DQN-P 在多数经典环境已有竞争力）。

## 核心贡献
1. 提出 VBE：用**集成 RQF 的 TD 误差**直接做 value bonus，给出"反推自洽随机奖励 + telescoping 证明（Prop 1）"，使 bonus 能首次访问乐观、又随学习衰减到零。
2. 理论上给出乐观初值的高概率保证（Prop 3）、bonus 反映 MDP 转移动态的刻画（Prop 2），并厘清与 RND（随机函数 vs 随机价值函数）、BDQN（Thompson vs 直接贪心、c 是否进目标方差）的异同。
3. 实证：在受控的 Deepsea 状态覆盖上展示 first-visit 乐观（仅 1 个 RQF 即全覆盖），在经典控制四环境上快且好，并演示可无改动地扩到 Atari。

## 局限与我的质疑
1. **预印本、未经同行评审**（封面标 RL Journal 2025 但 arXiv 2026 v1，引用 0）：所有结论应保留，尤其下面几条。
2. **作者自承的核心理论缺口**：行为策略与目标策略都在变时，**没有任何收敛保证**保证 bonus 一定衰减到零（"we know of no theory that would allow us to guarantee this"）；附录的收敛 Corollary 全部建立在**固定策略**假设上，与 VBE 实际运行情形不符。"bonus 总会收敛到零"目前只是经验观察、非证明。
3. **Atari 的优势被措辞略微拔高**：正文/摘要给人"VBE 更好"的印象，但逐图看 VBE 相对 RND 基本是**打平**（RND 在 Breakout/Pong/Q*bert 接近、Pitfall 略胜），真正一致超越的只有 BDQN；且只有 3 个种子、6 个游戏，作者也承认"复杂环境里性能差异的确切原因难以判别"。把 Atari 结果读成"VBE 在硬探索上更强"会是过度解读——它在经典控制的优势更扎实，Atari 只是"能 scale、不更差"。
4. **DQN-P（仅加固定先验）竟在 4 个经典环境里 3 个与 BDQN 相当**，这反过来削弱了"必须用集成 RQF"的卖点：在不少环境一个简单 prior 就够，VBE 的额外机制收益边界不清；论文未充分讨论"何时 VBE 相对 DQN-P 才真正必要"。
5. **first-visit 乐观的对照实验里，作者自己揭示 RND/ACB 在 Deepsea 偶尔学好是 bias+动量的"伪乐观"**——这说明此类对比对实现细节高度敏感；VBE 自身是否也存在类似实现侧的隐性增益（如共享表示、特定初始化），文中未做对称排查。
6. **超参高度依赖环境**（c、k 每个环境最佳值都不同，附录表 1–3），而"调 c/k 在低探索环境反而变差"意味着实战中需要 per-task 调参，削弱了"即插即用替代 ε-greedy"的易用性主张——对一个把"易用"当核心卖点的方法，这是要紧的张力。
7. **与本研究主题（可与环境交互训练的 RL）相关性的不足**：全部实验都是低维经典控制 + Atari 像素，**没有连续动作、机器人/具身或人机交互任务**；bonus 的 max-over-ensemble 形式在大动作空间/连续控制下如何取 argmax、计算如何 scale，均未涉及，迁移到交互式数字人等场景还需额外验证。
