# Safe exploration in model-based reinforcement learning using control barrier functions
> M. Cohen, Călin Belta · 2022 · Automatica · 引用 83 · DOI 10.1016/j.automatica.2022.110684

## 一句话
本文提出一种基于模型的强化学习（MBRL）框架，用一类新的"类 Lyapunov 控制屏障函数（LCBF）"构造**最小侵入的安全护盾控制器**，把安全性与学习收敛**解耦**，从而在线学习不确定非线性系统的最优值函数/策略时，**始终**满足以控制屏障函数（CBF）表达的安全约束。

## 解决了什么问题
- 学习型控制（尤其 RL）缺乏可证明的安全保证，限制其在安全攸关系统中的应用。
- 现有"把安全嵌进 RL 学习目标"的方法（如把 CBF 项加进代价函数）有一个根本缺陷：安全依赖于 RL 算法收敛、依赖于激励/持续激励（PE）条件，而这些条件实践中无法验证——**于是安全和学习被紧耦合，学习没收敛之前可能违反安全**（原文："safety and learning become tightly coupled"，§2 末）。
- 许多前序 BLF（barrier Lyapunov function）方法只能处理矩形（hyper-rectangle）状态约束，无法表达碰撞避免等更复杂安全规格（原文指出 [11,26,39] "limited to rectangular state constraints"）。
- 本文目标：**把学习从安全中解耦**，让安全在任意时刻、独立于任何学习相关条件而成立。

## 用什么方法解决的（含直觉：为什么 work）
- **核心系统**：控制仿射非线性系统 `ẋ = f(x) + g(x)u`（式1），`f(0)=0`，安全集 `C = {x | h(x) ≥ 0}`（式3）。
- **新工具 LCBF（式5）**：取一个候选 CBF `b`（在 Int(C) 上、原点在内部），构造"重新中心化屏障函数" `B(x) := (b(x) − b(0))²`。它满足 `inf B ≥ 0`、`B(0)=0`、`lim_{x→∂C} B(x)=∞`。
  - **直觉**：与标准 CBF 的关键区别是 **B 在原点处归零且半正定**。这一点使它能与"镇定到原点"的标称策略叠加而不破坏原点平衡——既当安全证书又像 Lyapunov 函数（原文："retain the beneficial properties of CBFs … while also possessing desirable Lyapunov-like qualities"）。
- **护盾控制器（式6）**：`k_b(x) := −c_b · g(x)ᵀ ∇B(x)ᵀ`，`c_b>0` 为增益。
  - **直觉/为什么 work**：沿闭环求导得 `Ḃ = ∇B·f − c_b‖∇B·g‖²`；在安全集边界邻域可上界（式7），并证明 `lim_{x→∂C} Ḃ = −∞ < 0`（式8）。即一旦轨迹逼近边界 `∂C`，`B` 的增长被强烈"往回压"，**轨迹无法到达边界**，因此 Int(C) 前向不变（Theorem 1）。
  - **最小侵入**：护盾项只在轨迹"快撞墙"时才发力，平时几乎不动手——文中实验显示加/不加护盾的轨迹在逼近 `∂C` 之前几乎重合。
- **与标称策略叠加（Corollary 1）**：`u = k(x,t) + k_b(x)`，既保安全又保原点为平衡点。
- **最优控制层（§4，ADP）**：无限时域代价 `J = ∫(xᵀQx + uᵀRu)dτ`（式10），值函数 `V*`（式11）满足 HJB（式12），最优策略 `k*(x) = −½R⁻¹g(x)ᵀ∇V*(x)ᵀ`（式13）。因 HJB 一般无闭式解、且需精确模型，转而用 MBRL 在线近似。
- **值函数近似**：用 StaF（State-following）核做**局部、跟随轨迹**的近似 `V*(y) = W(x)ᵀφ(y,c(x)) + ε`（式14），critic/actor 各用权重估计 `Ŵc, Ŵa`。
- **系统辨识（§4.3）**：漂移项假设对未知参数线性，`f(x) = Y(x)θ + ε_θ`（式16，Y 为已知基），用自适应控制/并发学习辨识器在线估 θ，权重误差指数收敛到一个小球（式17）。
- **"经验仿真"式安全探索（§5，本文关键创新）**：定义实际部署策略（式19）`u = k̂(x,x,Ŵa) − (c_b/2)R⁻¹g(x)ᵀ∇B(x)ᵀ`（学习策略 + 护盾项）。
  - **直觉**：在真实系统上只跑"安全策略"；而把 Bellman 误差（BE，式18）在状态空间中**未探索的虚拟点**上用近似模型外推评估（式21），用一个**不带护盾的探索策略** `u_i` 沿这些虚拟轨迹"模拟经验"。**这样既能充分探索状态空间、又不在真实系统上冒险违反安全**——探索的"危险"发生在仿真里，部署的"安全"发生在真实系统上。
  - **权重更新**：critic 用递归最小二乘（式22–23），actor 用带投影算子的更新律（式24），投影保证 `Ŵa` 有界。

## 动机 & 背景
- 属于"安全学习型控制（safe learning-based control）"领域；安全常被形式化为指定安全集的前向不变性（forward invariance）。
- 把 CBF 与 MBRL 联合，目标是**联合在线学习**不确定控制仿射系统的动力学与无限时域最优镇定问题的值函数/策略。
- 本文方法谱系：LCBF 受 [28] 启发；MBRL 框架建立在 Kamalapurkar 等 [16–18] 的"经验仿真（simulation of experience）"之上；在线 RL 求解连续时间最优控制根植于 [35] 的自适应控制思想。
- 与 [16,17] 的关键差异：本文在**探索时用学习策略、部署时用安全策略**（两套不同策略），使分析更复杂但换来安全与学习解耦（§1 contributions 第二点）。

## 方法细节
- 三大技术贡献（作者自述）：
  1. 提出 LCBF（半正定、原点归零），并用其梯度构造护盾控制器，以最小侵入方式给"性能驱动"的 RL 策略加安全护盾。
  2. 把 [16] 的 MBRL 架构发展成安全探索框架，为不确定非线性系统**在线安全地学习** `V*` 与最优控制，并给出收敛性证明。
  3. 数值例证明能处理比对照方法更一般的安全约束，并展示动态时变反馈下"镇定 + 避障"可同时实现。
- 关键定理/命题：
  - **Theorem 1**：Assumption 1 下，护盾控制器 `k_b` 令 Int(C) 前向不变。
  - **Corollary 1**：标称策略 + 护盾 令 Int(C) 前向不变且保原点为平衡点。
  - **Proposition 1**：式19 的策略令 Int(C) 前向不变——**不依赖任何 Lyapunov 论证**，只需 `Ŵa` 有界（由投影算子保证）。原文强调："the above proposition does not make use of any Lyapunov-based arguments … only that Ŵa remains bounded"——**这正是"安全独立于学习"的技术体现**。
  - **Theorem 2**（稳定性）：在 Assumption 1–3（含 PE 持续激励）及式25 充分条件下，复合状态 + 权重估计误差向量 `Z(t)` 一致最终有界（UUB，式27）。

## 数据集 & 实验设置
- 无真实数据集；两个数值仿真：
  1. **非线性系统**（取自 [15]）：`x∈R²`, `u∈R`, `f(x)=[−0.6x₁−x₂, x₁³]ᵀ`, `g(x)=[0, x₂]ᵀ`；漂移未知但对参数线性 `θ=[−0.6,−1,1]ᵀ`。安全集 `h(x)=p·x₁²−x₁+1`，`p=−1`（凸）与 `p=1`（非凸）两种——**均非矩形约束，故 [11,26,39] 无法处理**。用 L=3 个多项式 StaF 核近似值函数（核心放在以当前状态为重心的等边三角形顶点上），整体积分并发学习（ICL）在线辨识漂移参数。
  2. **碰撞避免**：2D 单积分器 `ẋ=u`，绕开圆形障碍（中心 `x_o`、半径 `r_o`），`h(x)=‖x−x_o‖²−r_o²`；动力学平凡故不做辨识。
- 对照设置：(a) RL + 护盾（CBF）、(b) 只有 RL（No CBF）、(c) 把 CBF 加进代价函数 `r(x,u)=‖x‖²+u²+20B(x)`（CBF Penalty，即 [6,27] 那类"学一个安全策略"）；碰撞避免里另比 ARE/LQR + 护盾。

## 主要结果 & 结论（写方向，不堆精确数字）
- **加护盾的 RL 能在不离开安全集的前提下把状态镇定到原点**（凸与非凸安全集均如此，Fig 1/2）—— observed（仅 2D 仿真）。
- **去掉护盾的 RL 能镇定系统但多次违反安全约束**（Fig 1 蓝 vs 橙）—— observed。
- **把 CBF 加进代价函数那一档（CBF Penalty）初期仍会违反安全、要等策略收敛后才变安全**（在该例中轨迹一度冲进非安全区，Fig 2 左下）—— observed。这条直接支撑全文论点：**靠"学一个安全策略"让安全依赖学习收敛，收敛前不安全**；本文护盾则任意时刻安全。
- **护盾是最小侵入的**：加/不加护盾的轨迹在逼近 `∂C` 前几乎重合，护盾"仅在绝对必要时介入"—— observed。
- **碰撞避免中，式19 的 RL 策略能绕过障碍并收敛到原点，而 LQR + 护盾会卡在障碍后面**（Fig 3）—— observed。
  - **机制（直觉）**：LQR + 护盾是**时不变**连续反馈，受某些初始条件下的拓扑限制，无法同时实现"镇定 + 避障"（原文引 [24, Ch.4.1]）；而 RL 策略因显式依赖在线演化的 `Ŵa`，是**时变/动态反馈**，能挣脱卡死、形成绕障的新策略。这是"动态反馈优于静态反馈"的一个具体体现。
- **证明了什么 vs 没证明**：理论上证明了安全（前向不变，Prop 1，不依赖学习）与 UUB 稳定性（Theorem 2，依赖 PE 等充分条件）；性能"最优性"只是近似（值函数/策略是 StaF 近似 + 权重估计误差有界，非精确最优）。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**：控制仿射系统 `ẋ=f+gu`；控制矩阵 `g(x)` **已知**、漂移 `f` 不确定但对未知参数线性（`f=Yθ`，基 Y 已知）；安全集可写成相对阶为 1 的（候选）CBF；低维状态空间。
- **能处理对照方法处理不了的**：非矩形、甚至非凸的安全集（凸/非凸算例 + 圆形障碍），优于 BLF 类 [11,26,39]。
- **不管用 / 未覆盖**：高相对阶 CBF（作者把引入 zeroing CBF 列为未来工作）；`g(x)` 未知的系统；漂移对参数非线性时辨识律不直接适用；高维系统（外推点数 N 随状态维数"scales poorly"，维数灾难）。
- 对照基线偏理论/经典（自家前序 MBRL、BLF、LQR/ARE），**不是现代深度 RL 强基线**。

## 核心贡献
- 提出 LCBF（半正定、原点归零的一类 CBF）及其梯度构造的最小侵入护盾控制器（Theorem 1 / Corollary 1）。
- 把"经验仿真"式 MBRL 扩展为安全探索框架：探索用学习策略、部署用安全策略，**安全（Prop 1）独立于学习收敛/PE 条件**，并给出 UUB 收敛性证明（Theorem 2）。
- 数值上展示可处理更一般（非矩形/非凸）安全约束，以及时变动态反馈下"镇定 + 避障"同时达成。

## 局限与我的质疑
1. **稳定性充分条件难以验证（作者自述，Remark 3）**：式25 的条件依赖未知量（重构误差 ε、常数 ι）或完全由轨迹决定的项，"无法事先形式化保证其满足"。作者辩称安全（Prop 1）已独立成立——但这意味着**论文真正"无条件"成立的只是安全，性能/稳定性保证是条件性的、实践中不可验证**，读者不应把"稳定 + 最优"当作板上钉钉。
2. **依赖 PE（持续激励）条件（Assumption 3）**：作者也承认 PE 一般无法验证，只能靠加探测信号"启发式"满足。这是这类自适应/ADP 方法的老问题，本文并未真正消除，只是把它从"安全"挪到了"稳定/收敛"上。
3. **结构性假设强**：要求系统控制仿射、`g(x)` 已知、漂移对参数线性且基函数 Y 已知、CBF 相对阶为 1（Assumption 1 第 3 条要求 `∇b·g≠0`）。这些在真实复杂系统（尤其高维、含未知执行通道）上往往不成立。
4. **实验非常单薄**：仅两个 2D 玩具仿真，单条轨迹、无统计重复、无误差棒、无基准化指标；"更一般约束""动态反馈更优"等结论建立在精心设计的低维算例上，**泛化性未被证明**（observed 级别，不能读成普适结论）。
5. **与本研究主题（可交互数字人 / 通用 RL 工具箱）的差距**：这是控制论意义的 ADP + StaF 核近似，不是高维深度 RL；核数/外推点随维数爆炸，难直接用于高维数字人/机器人控制。安全集必须能显式写成已知结构的 CBF，**学习型/复杂约束（如从数据学到的约束）未涉及**——这是把它迁移到现代深度 RL 安全探索时最大的鸿沟。
6. **"最小侵入"的代价 `c_b` 需人工调**（Remark 后讨论）：`c_b` 太小理论上让护盾仅在 `∂C` 附近主导，但实践中会导致控制输入幅值过大、超执行器限幅且变化剧烈——即安全护盾的"温和程度"是个需谨慎手调的设计参数，并非自动。
