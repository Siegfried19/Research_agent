# No More Hand-Tuning Rewards: Masked Constrained Policy Optimization for Safe Reinforcement Learning
> Stef Van Havermaet, Yara Khaluf, Pieter Simoens · 2021 · Adaptive Agents and Multi-Agent Systems · 引用 4 · DOI 10.65109/kqto7314

## 一句话
在"安全=避免提前进入危险终止态"的约束式安全 RL（CMDP）里，作者提出 MCPO：通过对优势估计器做"掩码"（把危险转移带来的贡献清零），让策略优化目标**彻底不看危险态的奖励信号 r△**，从而免去人工调这个奖励的痛苦，安全完全交给约束来保证。

## 解决了什么问题
- 在安全 RL 中，"安全"被作者定义为"不提前掉进危险终止态 s△ 的存活概率"，并用 CMDP（约束马尔可夫决策过程）框架建模：最大化任务回报，同时约束 J_C(π) ≤ 1−δ（Eq.5）。
- 作者指出一个"冗余"问题：即便安全已经由约束负责，为了把风险嵌进 MDP，还得给"进入 s△ 这条转移"配一个奖励 r△（即扩展奖励函数 R△）。**这个 r△ 仍会进到最大化目标里，反过来改变最优策略的安全程度**——它的作用等价于加权式目标（Eq.4）里那个权衡参数 ω。
- 选 r△ 的值是个高度依赖领域专家、费时费力的 reward engineering 任务；而 r△ 和安全阈值 δ 之间的关系"远非直观"（"the relation between ω and δ is far from straightforward"）。
- 核心动机一句话：**既然安全由约束保证，那任务目标里就不该再被危险奖励污染**。

## 用什么方法解决的（含直觉：为什么 work）
- MCPO = 在 CPO（Constrained Policy Optimization，一个为 CMDP 提供"全程满足约束"保证的信赖域策略搜索法）之上加"掩码"。
- **直觉**：策略梯度只通过"优势估计"从环境拿反馈。如果把所有源自危险转移的优势贡献清零，梯度就**根本看不到 r△**，于是 r△ 的大小/正负都无法把策略往"冒险"或"过度保守"方向拽。安全则仍由独立的约束 J_C ≤ 1−δ 把控（约束不含 r△）。这样就把"安全"与"任务表现"解耦：安全靠约束，表现靠（被掩码后的）真实任务奖励。结果是策略恰好用满允许的安全预算（风险逼近阈值 δ），同时最大化真正的任务回报。
- 为什么"直接把 r△ 设成 0"不行：r△=0 本身就是一种特定取值，会让 agent 朝"把安全约束顶到上限"方向走（见问题示例），是次优的。掩码不是把奖励替换成 0，而是把它对梯度的贡献整段移除。

## 动机 & 背景
- 论文把安全 RL 方法分两类：改探索策略 / 改优化准则。改优化准则又分三路：(1) 最坏情况回报（过度保守、无法权衡）；(2) 奖励与风险的加权目标（Eq.4，透明但要调权重 ω、还可能因两目标互相干扰陷入鞍点/局部最优"plateaus"）；(3) 用约束（CMDP）把安全外置——本文走这条。
- 本文沿用 [12] 的定义：危险态 s△ = 不属于任务目标的终止态（如导航中无人车被卡死）。risk-embedded MDP 定义为 ∃s,a: p(s,a,s△)>0。
- 安全等级（Eq.3）：策略 π 是 δ-safe ⟺ E_{τ∼π}[Pr(s△∈τ)] ≤ 1−δ。
- 基线 CPO [Achiam 2017]：信赖域 + 约束，靠限制每步策略改动幅度来控制近似误差，从而**在学习全程**保持约束满足——这是本文要扩展的对象。

## 方法细节
- **成本函数**：C(s,a,s′)=1(s′=s△)（指示函数），对应的 V_C/Q_C/A_C 与奖励侧对称；约束写成 J_C(π) ≤ 1−δ。
- **CPO 内核（被复用）**：对目标和约束在 π_θk 处线性化、KL 用二阶展开（Eq.9），用对偶（Eq.10）求拉氏乘子 λ*、ν*，得到策略更新（Eq.11）`θ = θk + (1/λ*)H⁻¹(g − g_c ν*)`；若不可行则退化为只降约束的恢复更新（Eq.12）；最后用 backtracking line search 兜近似误差。
- **掩码两步（MCPO 的核心，4.4.2）**：
  1. **掩码 GAE 的 TD 残差**（Eq.14）：把 GAE `Â=Σ(γΛ)^k Δ_{t+k}` 改成 `Â=Σ(γΛ)^k · 1(s_{t+k+1}≠s△) · Δ_{t+k}`，即危险转移对应的 TD 残差 Δ_t = r_{t+1}+γV̂(s_{t+1})−V̂(s_t) 被清零。
  2. **掩码价值函数 V̂ 的奖励估计损失**（Eq.15–16）：仅做第 1 步不够，因为 TD 残差里用到的 V̂ 本身是学来预测未来奖励的、会把 r△ "烤"进去。于是把 V̂ 拆成各步奖励估计之和 `V̂(s)=Σ γ^k R̂_k(s)`，并对每个奖励估计器的预测误差做掩码（Eq.16）：`E_k(s)=1(∀l≤k: s_{t+l+1}≠s△)·(R̂_k(s)−r_{t+k+1})`——只要这段轨迹中途因危险终止，就丢弃该误差，不更新对应估计器。
- **实用实现（4.4.3）**：只估计前 n 步单步奖励、第 n+1 步起用 bootstrap（Eq.17）；用一个共享隐藏层、n 个输出节点的神经网络一次性出 n 个奖励估计；并指出可直接用 CMDP 的成本判据 `1(s_{t+1}=s△) ≡ 1(c_{t+1}=1)` 来触发掩码，免去单独识别危险态。
- **其它优势估计器（4.4.4）**：Q̂、Q̂−V̂ 都能按同法掩码奖励估计误差；若直接用采样回报 G_t，则需丢弃所有危险终止的样本——作者预期其采样效率较低。
- **性能度量 J▽（4.4.6）**：定义为"只计入未因危险终止的轨迹"的期望回报——这是 MCPO 真正想优化、也是后面比较的关键指标。

## 数据集 & 实验设置
- 基于开源工具包 garage [7]；策略=多元高斯，均值由两隐层 (64,32)+tanh 的网络输出，协方差作为可训练参数。
- 超参：γ=0.995，GAE Λ=0.95，KL 步长 κ=0.01；每次学习 100 次迭代、每迭代 5·10⁴ 步；10 个随机种子；MCPO 用 n=32 个奖励估计器（带 bootstrap）。
- 三个连续控制玩具任务：
  - **导航 LakeWorld**：状态=(x,y)∈[−5,5]²，动作=速度∈[−1,1]²，奖励=到目标的负距离；δ=0.2，ρ=0.25，r△=−500（另测 r△=−5000）。
  - **导航 CoastWorld**：δ=0.1，ρ=0.33，r△=0。
  - **觅食 Foraging**：11 个 patch 里采集 6 个最高奖励；5 个无风险(奖励10)、5 个带奖励 r_i=100−20i 且风险 ρ_i=0.5−0.1i、外加 1 个奖励10/风险0.92 的 patch；δ=0.1，r△=−500，跑 150 迭代。
- 对照只有一个：**CPO**（同样用 GAE 估优势）。没有与 primal-dual、RCPO、TRPO-Lagrangian 等其它安全 RL 方法的横向比较。

## 主要结果 & 结论（写方向，不堆精确数字）
- **核心结论**：当 r△ 没被精心手调时，按"已完成轨迹的回报 J▽"衡量，MCPO 优于 CPO（结论句：MCPO "outperforms CPO in the average of accumulated rewards, for the episodes that were not terminated due to risk, when unsafe reward signals are not properly hand-tuned"）。supported（在 3 个玩具任务、10 种子上系统观察到）。
- **方向上的关键细节，别看反**：在 LakeWorld、r△=−500 时，按"含 r△ 的原始回报/风险"看，CPO 反而回报更高、风险更低（Fig.3a/3b）——但这是因为很负的 r△ 让 CPO 学得保守；两者其实都满足 δ-safe。**只有换用 J▽（仅完成轨迹，Fig.3c）才显出 MCPO 更优**，且其学到的是真正更短的路径。observed。
- **MCPO 对 r△ 不敏感**：r△ 从 −500 调到 −5000，CPO 变得"完全风险规避"、任务表现下降；MCPO 表现与 −500 时几乎不变（Fig.4）——直接证明 MCPO 成功"忽略"了危险奖励。supported。
- **r△=0 的反面案例（CoastWorld）**：因为 0 比任何安全奖励都高，CPO 反而学会"最大化风险"、既次优又更危险；MCPO 找到更短路径（Fig.5）。作者借此提醒"把 r△ 设 0 的朴素做法 [6] 要谨慎"。observed。
- **觅食任务**：CPO 最大化"含 r△ 的奖励总和"，MCPO 只优化完成任务的回报，结果 MCPO 导向更高奖励（Fig.7c），两者用同一安全约束。observed。
- **共性**：MCPO 学到的策略风险会逼近阈值 δ（把安全预算用满去换任务表现），而 CPO 的风险随 r△ 变化漂移。

## 适用边界（什么时候管用 / 什么时候不管用）
- 适用：安全被建模为"避免提前进入危险终止态"的 CMDP；危险态可由成本指示 1(c=1) 识别；优势用 GAE/Q̂ 等基于奖励估计的估计器（便于掩码）。
- 最能体现优势的设定：δ 较小（更需省着用安全预算）、且 r△ 难以正确手调时——此时 CPO 对 r△ 取值敏感而 MCPO 不敏感。
- 作者自陈的失效边角（4.4.5）：当某状态在策略 π 下几乎必然 h 步内触险时，部分奖励估计器 R̂_h 会因掩码很少被更新；但作者论证这只在策略 δ′-safe 且 δ′≈0 时发生，而那意味着发生了"坏的策略更新"（近似误差所致），此时新策略更新不依赖这些优势估计、故无影响；若目标本就 δ≤δ′，则任意策略都满足约束，"已不算安全策略学习问题"。
- 不适用/未验证：奖励/风险并非"提前终止"型的安全语义、危险态无法用成本指示判定、用纯采样回报 G_t 做优势（采样效率会低）的情形未实测。

## 核心贡献
1. **揭示问题**：清楚论证了即使 CMDP 已用约束管安全，危险态奖励 r△ 仍"冗余地"改写最大化目标、左右最优策略的安全程度（toy 例 + Table 1：r△=0→最冒险 π_r、r△=−100→过度保守 π_b、r△=−10→最优 π_g，说明要选对 r△ 等于要事先知道最优策略）。
2. **提出 MCPO 算法**：用布尔掩码（对 GAE 的 TD 残差 + 对奖励估计器损失，两处）把危险奖励从最大化目标中剔除，免去手调 r△；给出 GAE 推导、实用实现、对其它优势估计器的推广、局限分析与对 CPO 的性能差异分析。

## 局限与我的质疑
1. **实验只有玩具任务、只比一个基线**：三个 2D 连续任务都很小、易解释，唯一对照是 CPO。没有与 RCPO/TRPO-Lagrangian/primal-dual 等安全 RL 方法比，也没有 MuJoCo/Safety-Gym 这类标准高维 benchmark。"outperforms"的强度只支撑在这几个玩具任务上，不能外推为"普遍优于安全 RL 现状"。
2. **比较指标对 MCPO 有利、需警惕"自定义裁判"**：J▽ 是作者为本方法量身定义的度量（只算完成轨迹回报）。在原始回报指标下 CPO 反而更好（Fig.3a），论文用 J▽ 来翻盘。J▽ 确有合理性（衡量"成功时多好"），但这等于换了评价标准；对"既要常完成又要高回报"的应用，单看 J▽ 可能掩盖 MCPO 完成率/风险更高（风险贴着 δ 跑）的代价。
3. **MCPO 把风险顶到阈值 δ 是双刃剑**：它靠"用满安全预算"换性能。若 δ 估计偏松、或真实风险被低估，这种"贴边"策略的实际危险可能超预期；论文未讨论约束估计误差下的安全鲁棒性（CPO 的 line search 兜底在 MCPO 里是否同样可靠也没单独验证）。
4. **掩码导致奖励估计器更新稀疏的问题**被作者用"只在 δ′≈0 才发生"论证掉了，但该论证偏理论、且依赖"坏更新才会触发"的假设；高风险任务早期探索阶段大量轨迹触险、奖励估计器长期欠训练对学习稳定性的实际影响，缺少专门的实证（如学习曲线方差、对 n 的敏感性消融）。
5. **缺关键消融**：n=32 步奖励估计、bootstrap、共享网络这些实现选择对结果影响多大，没有消融；两步掩码各自的必要性也只有文字论证、无"只掩第一步 vs 都掩"的实验对照。
6. **与本研究主题（治"手调 reward 耗时"）的契合但偏窄**：它确实正面打"免调 reward"，但只针对"危险终止态那一个奖励 r△"这一类很特定的 reward engineering，不解决一般任务奖励塑形（reward shaping）的手调问题；适用前提（安全=提前终止、可用成本指示）也较强，迁移到更一般的安全/奖励设计场景仍是开放问题。
