# Deep dive into model-free reinforcement learning for underwater locomotion: theory and practice.
> Jiao Y, Ling F, Heydari S, Heess N, Merel J, Kanso E · 2026 · Bioinspiration & biomimetics · 引用 0 · DOI 10.1088/1748-3190/ae4930

## 一句话
这是一篇**教程（tutorial）**，面向流体力学/生物力学/机器人领域的 RL 新手，自洽地讲清无模型 RL（聚焦 actor-critic）的数学推导与工程实现，并给出把它用到水下 locomotion（embodied agent）问题上的建模指南——不提出新算法、不报告新实验（"No new data were created or analysed"，见 Data availability）。

## 解决了什么问题
- 它要解决的是**认知/上手门槛问题**，不是某个控制任务：让物理/生物科学与工程背景、对 RL 数学基础和实现细节陌生的研究者能真正理解并应用无模型 RL。
- 作者强调他们关心的设定（为有身体的物体——生物或机器人——在水下环境中学一套"感觉-运动控制律 / 反馈控制律"）与传统 RL 教材关注点不同，所以需要一份专门讲清"具身（embodiment）建模选择落在哪里"的材料。
- 论文明确表态：RL 在此不是要复刻动物神经反馈环，而是提供一个系统提问的框架——"完成某行为需要哪些信息、哪些感觉线索能提升对环境扰动的鲁棒性、哪种 reward 最能复现观察到的 locomotion 模式"（见 §2 引言段）。

## 用什么方法解决的（含直觉：为什么 work）
- 全文是"从数学地基逐级搭到工程实践"的推导式讲解：MDP/POMDP → 策略梯度 → actor-critic → critic 近似 → 训练（TRPO/PPO）→ 水下系统的建模选择。
- 核心直觉链：①直接对无限时域目标 J(θ) 求梯度不可解；②用"似然比技巧（likelihood ratio trick）"把梯度改写成只需**采样轨迹**就能估计的形式，于是无需对物理转移 P(s_{t+1}|s_t,a_t) 求导——这正是"model-free"的含义（§2.3、图2）；③朴素策略梯度（REINFORCE）方差极大，于是引入 critic（值函数）做基线和期望回报替代，降方差（§3）；④用 K 步 bootstrap 在偏差/方差间折衷（§4）；⑤为提高数据利用率与稳定性，引入 PPO 的"裁剪 + 信任域"限制每步策略变化幅度（§5、附录C）。

## 动机 & 背景
- 水生动物与水下机器人都在**复杂、常常是动态（dynamic）的流场**中运动，必须把感觉信息持续转成协调动作以完成觅食、避敌、逆流导航等目标；在神经元电路层面研究这些决策过程仍是难题（§1）。
- 作者把世界划成三块：**agent（控制器/决策）**、**body（被控且用来感知的身体）**、**external environment（agent 无法直接控制的一切）**；动作与感知都必须经过物理身体，这种"通过身体行动与感知"即 embodiment，是本文反复强调的关键约束（§2、图1B、附录表D.1）。
- 作者指出 agent/body/environment 的划分本身是一种**建模选择**，需按问题逐案判断，而非物理事实（§2 引言"philosophical subtleties"段）。
- 几乎所有真实控制问题都属于 POMDP（部分可观测），因为 agent 只拿到 state 的部分观测 o_t，不同 state 可能产生相同观测、不可区分——所以观测设计至关重要（§2.1）。

## 方法细节
- **MDP/轨迹/回报（§2.1–2.2）**：离散时间，策略 π_θ(a|o) 概率式；回报 R_t = Σ_{t'≥t} γ^{t'-t} r_{t'}（式2.2），γ∈[0,1) 为折扣因子；目标为期望回报 J(θ)=E_{π_θ}[R_0]=∫R_0 p_θ(τ)dτ（式2.3）。
- **策略梯度（§2.3）**：用似然比技巧得 ∇_θ J(θ)=E_{π_θ}[Σ_t Σ_{t'≥t} γ^{t'}r_{t'}∇_θ log π_θ]（式2.6），并证明"t'<t 的项期望为0"（附录A），化简为 ∇_θ J=E[Σ_t γ^t R_t ∇_θ log π_θ]（式2.7）；可用 Monte Carlo 采样 M 条轨迹估计（式2.8），再做参数更新 θ_new=θ_old+α∇_θ J（式2.9）。作者明说此即 REINFORCE，方差高、对轨迹随机性与学习率敏感（§3 开头）。
- **actor-critic（§3）**：定义 advantage A_t:=Q(s_t,a_t)−V(s_t)=E[R_t|s_t,a_t]−E[R_t|s_t]（式3.1）；V、Q 定义见式3.2/3.3，满足 Bellman 关系 V(s_t)=E[r_t+V(s_{t+1})]（式3.4）。梯度改写为 ∇_θ J=E[Σ_t γ^t A_t ∇_θ log π_θ]（式3.5）。直觉：V(s_t) 当 baseline，衡量动作"比平均好多少"，比用单轨迹绝对回报 R_t 评分**方差显著更低**（§3 "advantage"段、式3.6）。附录B 给出从式2.7 到 advantage 形式的推导，并指出 baseline 可取任何"不依赖 a_t"的函数，V 只是直觉上方便的选择、非最优。
- **近似 critic（§4）**：Q 的 K 步截断近似（式4.1）与 K 步 bootstrap 近似（式4.2，用 γ^K V_φ(s_{t+K}) 替代残差）；critic 用最小二乘训练 L(φ)=E[Σ(V_φ(s_t)−V̂(s_t))²]（式4.3），梯度式4.4。作者明确**偏差-方差权衡规则**：bootstrap（式4.2）+小K+大γ → 方差低但偏差高；截断（式4.1）+大K+小γ → 偏差低但方差高；K=1 即退化为 TD（temporal difference）学习。
- **训练与参数化（§5）**：训练按 episode 组织（初始化→rollout→终止→reset，图3、算法1）。连续动作策略常设为高斯 N(a_t|μ_θ(s_t),σ_θ(s_t))，神经网络出均值与方差，可对策略反传梯度（与 reparameterization trick 相关）。
- **TRPO/PPO（§5.2、附录C）**：用 surrogate 目标 + 重要性采样比 ρ_t=π_θ/π_{θ_old} 实现有限数据复用（式5.2/5.3，仅"部分修正"因 advantage 也依赖 π）。TRPO 用 KL[π_{θ_old}||π_θ]<δ 约束（信任域）；PPO 直接**裁剪**似然比到 [1−ε,1+ε]（式C.1，建议 ε=0.2），取裁剪/未裁剪目标的较小值，使策略只在"改善目标"时才允许变化；再加熵奖励项鼓励探索（式C.2，建议 α=0.01）。直觉：限制每步策略漂移以避免梯度估计带来的失控大更新、稳定训练。作者区分 PPO 的"批内复用"与 off-policy（DDPG/TD3/SAC，replay buffer）的"跨老策略复用"，并权衡了 on-policy（稳定但交互成本高）vs off-policy（样本效率高但调参敏感）。
- 提供配套实现：GitHub `mjysh/RL3linkFish`（附录C 末），含 PPO 简洁实现。

## 主要结果 & 结论（写方向，不堆精确数字）
- 作为教程，本文"结果"是**方法论结论与建模指南**，不是性能数字；下列条目均为作者论述/建议，而非实验证据（故不标 observed/supported/strong 这类实证强度）。
- 无模型 RL 的本质：梯度估计 ∇_θ J 可仅凭采样轨迹得到、独立于物理转移模型，这是它能用于复杂/非定常流场控制的根本原因。
- actor-critic（用 advantage + critic）相比朴素 REINFORCE 主要价值在**降方差、提稳定性与数据效率**（作者论证，非本文实验对比）。
- 水下具身 RL 的**建模指南（§6，作者推荐性结论）**：
  - 观测应"够用就好"，过高维会引入噪声、降低学习效率；优先用 **egocentric（自我中心）观测** —— 它天然带来对身体空间变换不变的动作、简化对复杂场景的编码、利于泛化（§6.2）。可在训练时给 critic 喂"特权信息"加速训练，但 policy 输入须保持生态可得，以保证测试时策略仍有意义。
  - 观测表示影响函数逼近难度：例如理想控制器是关节角 β 的线性函数时，喂 [sin β, cos β] 比喂裸角 β 学得更容易（§6.2）。
  - 动作空间须与身体的形态与驱动方式兼容（关节力矩/角速度、连续体曲率基函数权重、偶极子航向指令等）；力矩控制更"基础"，但学习语境下有时更关心驱动方案能否带来更快更鲁棒的学习（§6.3）。
  - reward 工程：dense shaping reward（如 exp[−γ‖x_ref−x_current‖²]）便于学习；sparse reward 难学需强探索；推荐"先朴素 reward 拿到高回报策略，再迭代反推 reward 直到产生想要的行为"（§6.4）。
  - 终止条件要精心设计（区分时限终止 vs 成功终止——前者用 bootstrap、后者用 truncation），防止 agent 钻空子（如刻意触发终止以避负奖励）（§6.5）。
  - 决策时间步应比物理仿真步**更粗**，对应动物神经系统/机器人的反应时间，否则学到的策略不真实（§6.6）。
  - 科学诠释（§6.7）：深 RL 对随机种子/环境随机性/reward shaping/超参敏感，单个训练好的策略只是"该建模下的一个可行解、非唯一解"；建议**多随机种子训练、报告分布式指标而非单个 best**，并验证定性结论跨种子稳定才更可能有物理意义。可通过分析步态/轨迹/协调模式、或拟合可解释的代理模型来从黑箱策略中提炼机制。

## 适用边界（什么时候管用 / 什么时候不管用）
- 这是一份"上手与建模"教程，**对已熟练 RL 的人增量有限**；它本身不给新算法/新基准结果。
- RL 的定位：作者明说 RL **不是用来复刻动物神经反馈环**的，而是当作"系统性提问 + 把建模假设与可对比数据的行为预测连起来"的理论工具；想要"生物机制级真相"的人不应把训练出的策略当唯一答案。
- 强调的设定是"有身体的 agent 在水下环境中学反馈控制律"，与传统 RL 教材聚焦点不同；想看通用 RL 全景的读者作者反而推荐去看 Sutton & Barto、Silver、Murphy（§1）。
- 几乎所有真实问题是 POMDP，full observability 只是为推导 actor-critic 而临时假设（§3 末、§5.2）；直接把 s_t 换成 o_t 在数学上不严格（可能让两个不同 state 有相同 advantage），需谨慎设计观测、必要时加记忆——作者称在多个水下 locomotion 问题上"已被证明可成功"（§5.2，引文献，非本文实验）。

## 核心贡献
- 提供一份**自洽、面向非 RL 专家的教程**：从策略梯度到 actor-critic 再到 PPO 的完整数学推导（含附录A/B 的两处证明），把"物理建模选择落在公式何处"讲清。
- 系统梳理水下具身 RL 的**建模决策清单**（观测/动作/reward/终止/时间步/可复现性），并以表1 五个文献例子做范例对照。
- 给出可跑的**伪代码 + 开源 PPO 实现**（`mjysh/RL3linkFish`），并把 RL 立场为"探索动物与机器人反馈控制假设的工具"，呼应 bioinspiration 主题。

## 局限与我的质疑
1. **无任何自有实证**：全文不报告新实验，所有"方法好在哪/建议怎么做"都是论述或转引他人工作（表1、§6 引文献）。读者不能从本文获得"PPO vs off-policy 在水下任务上谁更好"之类的实证对比——这类方向性结论必须回到被引原文核实，不能算到本文头上。
2. **建议偏定性、缺量化依据**：如"决策步要比物理步粗""egocentric 观测利于泛化""多种子报分布"等都合理但未在本文给出量化证据或失败案例分析，工程上"粗到什么程度/几个种子才够"无可操作阈值。
3. **POMDP 处理一笔带过**：把 s_t 换成 o_t 破坏数学严格性这点作者诚实点出，但对"如何设计观测/加多少记忆才补得回来"只给原则、未深入，而这恰是水下部分可观测控制最难、最该"deep dive"的地方。
4. **公式呈现以势流/简化体例子为主，对真实高雷诺数非定常 CFD 的训练成本、sim-to-real gap 几乎未触及**——而这正是水下机器人落地的真正瓶颈；教程停在"仿真里怎么建问题"，未谈仿真到实体的迁移。
5. **与本研究主题（locomotion 实战/算法实践）相比**：本文是入门教程而非算法创新或大规模实战 benchmark，可作为搭建水下 RL 实验的"建模 checklist"和教学材料，但若要找"哪种算法/奖励/观测在某任务上实测更优"的可复用结论，需转向其引用的 Jiao 2021/2025、Verma 2018、Gazzola 等原文。
6. **引用 0、2026 年新发表**：尚无第三方检验或后续验证其教学路径与建议的有效性（中性事实，提示读者自行判断）。
