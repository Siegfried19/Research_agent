# AFU: Actor-Free critic Updates in off-policy RL for continuous control
> [, ", N, i, c, o, l, a, s,  , P, e, r, r, i, n, -, G, i, l, b, e, r, t, ", ] · 2024 · arXiv.org · 引用 0 · DOI 10.48550/arxiv.2404.16159

## 一句话
AFU 提出一种**不依赖 actor 来解连续动作 max-Q 问题**的新办法——用"回归 + 条件梯度缩放"直接把值函数学成 Q 的最小上界,从而让 critic 更新完全独立于 actor;在 7 个 MuJoCo 任务上样本效率与 SAC/TD3 相当(supported)。

## 解决了什么问题
- 连续动作 Q-learning 的核心障碍是 **max-Q 问题**:Bellman 最优更新需要 `max_a Q(s,a)`,但动作连续多维时这个 max 难算(原文"max-Q problem")。
- 主流做法(DDPG/TD3/SAC 等 actor-critic)是**用 actor 间接近似 argmax**,副作用是 critic 更新被 actor 牵着走、不是"真正的 off-policy",且 actor 可能陷入局部最优(原文引 [22])。
- 另一端从 Q-learning 直接改造的方法(如 IQL、CAQL、SQL/EQL)在在线 RL 表现不好或难扩展到高维动作:IQL 类的 expectile 回归在逼近真实 max 时损失会"失衡"(unbalanced),至今基本只用于离线 RL。
- AFU 想要一个**真正 off-policy 且适合在线 RL**的算法:critic 更新不碰 actor、也不用 OOD(分布外)动作做 Bellman backup。

## 用什么方法解决的（含直觉：为什么 work）
核心是**不用 actor、用回归把 max-Q 解出来**,机制分三步:

1. **把 max 拆成 V + A 的回归**。引入值函数逼近器 `V_φ` 和优势函数逼近器 `A_ξ`(优势满足 `A*(s,a)=Q*(s,a)−V*(s) ≤ 0`,即非正)。最朴素的回归损失是 `l = Mean[(V_φ(s)+A_ξ(s,a)−Q_ψ(s,a))²]`(式2)。
   - **直觉**:因为 `A ≤ 0`,回归让 `V = Q − A ≥ Q`,所以 `V_φ(s)` 会变成 batch 内各动作 `Q(s,·)` 的**上界**——但是"不紧"的上界(原文"upper bounds ... but not tight ones")。我们真正想要的 `max_a Q` 是**最小的那个上界**。

2. **条件梯度缩放(本文招牌)——给 V 施加"向下压力",把松上界压到紧上界**。定义
   `Υ_i^a(s) = (1 − ϱ·I_i^{s,a})·V_φ_i(s) + ϱ·I_i^{s,a}·V_{φ_i^{no_grad}}(s)`,
   其中 `φ^{no_grad}` 是 `φ` 的**不回传梯度的拷贝**,`I_i^{s,a}=1` 当且仅当 `V_φ_i(s)+A_ξ_i(s,a) < Q_ψ(s,a)`(否则为 0);`0<ϱ<1`。用 `Υ` 替换式2里的 `V` 得损失式3。
   - **关键方向(务必读对)**:`I=1` 表示当前估计**低于**目标,梯度下降本会把 `V` **往上抬**;此时 `Υ` 里只有 `(1−ϱ)V_φ_i` 这一项带梯度,于是**上抬方向的梯度被缩放成原来的 (1−ϱ) 倍**(被削弱)。当 `V` 本会**下降**时(`I=0`),梯度**全额通过**。
   - **直觉**:上抬被打折、下降不打折 → 净效果是持续的"向下压力",把 `V_φ` 从松上界逐步压到**紧上界 = `max_a Q`**;同时 `A=Q−V` 被顶上去逼近最优优势。附录 B 把这等价解读为一种**自适应正则**:相当于给损失加了 `2ϱ·|e|·V_φ` 这样一项,正则权重正比于误差绝对值 `|e|`,误差越大压得越狠。
   - ϱ 控制压力强度:ϱ 太小(如 0.05)压力不够 → `V` 仍偏高、**高估** max;ϱ 偏大压力更强。toy 实验里 ϱ∈[0.2,0.7] 都给出精确逼近,MuJoCo 上 ϱ∈{0.2,0.3} 最好。

3. **软约束 A 的符号**。直接硬性约束 `A_ξ ≤ 0` 会让梯度抖动,所以改用一个非对称函数 `Z(x,y)=(x+y)² if x≥0 else x²+y²`(附录 C),得损失式4:`Λ' = Mean[Z(Υ_i^a(s)−Q_ψ(s,a), A_ξ_i(s,a))]`。

4. **去掉对 Q 的依赖 → 真·actor-free critic**。把式4里的 `Q_ψ(s,a)` 换成训练 Q 时用的 TD 目标 `r + γ·min_{i∈{1,2}} V_{φ_i^target}(s')`(式5)。配合 clipped double-Q 的 critic 损失 `L_Q`(式1,双 `V_φ1/V_φ2` 取 min 抑制高估),`Q_ψ、V_φ、A_ξ` 全部不需要 actor 即可训练。
   - **为什么"直接解 max 比用 actor 解 argmax"更稳(原文给的理论直觉)**:`Q` 连续变化时,它的逐状态**最大值**也连续变化,但逐状态 **argmax 可能跳变(不连续)**;在很 off-policy 的设定下,探索策略一旦在很不同的动作上发现更好结果,跟踪 max 平滑、跟踪 argmax 难 → actor 易被"欺骗性价值景观"困住(原文引 [22])。

5. **actor 怎么来**。仍需 actor 采样动作产环境数据。**AFU-alpha**:直接照搬 SAC 的随机 actor,损失 `L_π=Mean[α·log π_θ(a_s|s) − Q_ψ(s,a_s)]`(式6)+ 自动温度调节 `L_temp`(式7)。critic 既已 actor-free,actor 不必确定性、也不必精确等于 argmax。

6. **AFU-beta——修 SAC 式 actor 的局部最优病**。先训一个确定性 `μ_ζ(s)` 当"mode 该在哪"的回归估计:用 batch 里(及 actor 重采样的)那些 `Q(s,a) > min V_φ(s)`(即靠近 argmax)的动作当回归目标,损失 `L_μ=Mean[(μ_ζ(s)−a_•)²]`(式8)。再在算 actor 梯度时,把 `∇_a Q(s,a_s)` 过一个算子 `G`:当该梯度**背离 μ_ζ 方向**(点积 `v·(μ_ζ−a_s)<0`)**且** `a_s` 不在 argmax 附近(`Q(s,a_s)<min V_φ`)时,把它**投影到 `(μ_ζ−a_s)` 的正交超平面**上(抹掉"指向远离 μ_ζ"的分量);否则不动(图5)。
   - **直觉**:`μ_ζ` 靠回归学(训练用 replay buffer 里真实采过的动作,不只是 actor 重采样),所以即便新的 Q 峰出现在当前策略很少采到的远处,`μ_ζ` 也能先发现它,再引导 actor 越过那些"欺骗性梯度"挪过去——前提是 critic 自己学得好。

## 动机 & 背景
- 真·off-policy 的价值:机器人等高样本效率场景需要能复用历史/异策略数据。但当下最成功的连续控制 off-policy 算法都是 actor-critic,在"大量训练数据与当前策略不相关"时会失效,所以"不算真正 off-policy"(原文引 [8])。
- 相关工作里直接解 max-Q 的尝试都有短板:NAF/ICNN 强行让 Q 对动作凸、QT-Opt/SDQN 等靠动作离散化、CAQL 混合整数规划、IQL/X-QL/SQL/EQL 靠 expectile/value-regularization——要么表达力受限、要么算力高、要么只在离线好用。AFU 把自己定位成"第一个真正脱离 actor-critic 视角、又能与 SOTA 在线算法比肩的 model-free off-policy 算法"。
- 一个被作者强调的设计选择:**AFU 的 Bellman backup 不用 OOD 动作**。作者承认在线设定下 OOD 动作带来的乐观偏差本可被纠正,但更愿意"一开始就不引入高估",用别的方式鼓励探索(related work 末尾讨论)。

## 方法细节
- 双值函数 `V_φ1,V_φ2` + 各自优势 `A_ξ1,A_ξ2` + critic `Q_ψ`;`V` 带 target 网络,软更新系数 τ。
- critic 损失式1:`L_Q(ψ)=Mean[(Q_ψ(s,a) − r − γ·min_{i} V_{φ_i^target}(s'))²]`(终止转移 γ 视作 0)。
- 关键 max-Q 损失:朴素式2 → 条件梯度缩放式3 → 软符号约束式4 → actor-free 版式5(见上"方法"第2–4步,公式已转写)。
- 算法 1(AFU-alpha 与 AFU-beta 共用框架):每次迭代 = 1 个环境步 + 1 个梯度步;梯度步里依次更新 `ψ`(用 `L_Q`)、`φ_i`/`ξ_i`(用 `L_{V,A}`)、target 软更新、actor `θ` 与温度 `α`。AFU-beta 多两行:训 `μ_ζ`(用 `L_μ`)、并用**修改后的 actor 梯度** `∇_θ^{MODIF} L_π`(把 `∇_a Q` 换成 `G(∇_a Q)`)。
- AFU-beta 实现上让 `π_θ` 的网络多输出一个 `μ_ζ(s)`,与 actor 共享主干(原文说"不改变方法本身");算 `L_μ` 梯度时要小心忽略 `ζ` 对重采样动作 `a_s` 的影响。

## 数据集 & 实验设置
- **toy max-Q 问题**:`Q_toy(s,a)=sin(4s)+0.7cos(4a)`,`s,a∈[−1,1]`;3000 梯度步、batch 256;比 AFU 的回归法 vs IQL/SQL/EQL 在拟合 `s↦max_a Q_toy(s,a)` 上的精度(图1、附录 D 图6)。
- **SFM(SAC Failure Mode)合成环境**(§7):单状态、一维动作 `a∈[−1,1]`,奖励 `R_SFM(s0,a)=5−100(a−0.1)²`(当 `a≥−0.6`)否则 `0`,所有转移终止;最优 `a=0.1`、回报 5。用于暴露 SAC 的局部最优陷阱。
- **7 个 MuJoCo 任务**(Gymnasium):Ant-v4、HalfCheetah-v4、Hopper-v4、Humanoid-v4、InvertedDoublePendulum-v4、Reacher-v4、Walker2d-v4;动作维 1(IDP)~17(Humanoid),观测维 11~376(Humanoid)。
- 每算法/超参跑 **10 个随机种子**;每 10000 步评估(10 条 rollout);前 10000 步纯随机动作无梯度;用 **rliable** 库画 performance profile。训练步数:IDP/Reacher 1M、Ant/Hopper/Humanoid/Walker2d 3M、HalfCheetah 5M。
- 基线:**完整算法层面比 SAC、TD3**(强基线);**max-Q 子问题层面比 IQL、SQL、EQL**(把 AFU 的 `L_{V,A}` 换成这些方法对应损失)。SAC 与 AFU 用相同 τ、学习率、目标熵 `H̄=−d`。
- 超参(附录 A):Adam,actor/critic/温度 lr 均 3e-4,γ=0.99,replay 1e6,2 隐层×256 ReLU,τ=0.01,无 reward scaling 等。

## 主要结果 & 结论（写方向，不堆精确数字）
- **max-Q 子问题**:在 toy 上,AFU 的回归+条件梯度缩放,在"实际 RL 里可用的超参范围"内,比 IQL/SQL/EQL 明显更精确地逼近 `max_a Q`;这些基线只有用"在真实(离线)RL 里不会用的极端超参"时才精确(图1、图6,supported)。MuJoCo 上把 `L_{V,A}` 换成 IQL/SQL/EQL 会带来明显性能下降(图2a,supported)。
- **整体算法**:AFU-alpha 在 7 个 MuJoCo 任务上样本效率与 SAC、TD3 **相当**(图2b,supported)。作者称在 Humanoid 这类最复杂任务上 AFU 表现相对较好、且不像有些直接改造 Q-learning 的方法那样在复杂任务上崩(observed)。
- **SAC 失效模式**:在 SFM 上,SAC 的 `Q` 能精确收敛到 `Q*`,但其 **actor 收敛到次优解**(被卡在 `a≈−1` 附近);原因是 `R_SFM` 在 `a=−0.6` 的不连续让 `Q` 出现陡坡,策略一旦集中到陡坡左侧,KL 损失产生**欺骗性梯度**充当"屏障",阻止 mode 挪回 `0.1`(图3、图4,observed)。
- **AFU-beta**:在 SFM 上**快速收敛到最优解**,SAC 不能(图4a,observed,单一玩具环境)。
- **AFU-beta vs AFU-alpha**:在 MuJoCo 上两者差异**不显著**,作者推测是这些环境里很少真撞上局部最优(图7、附录 G,supported)。
- 作者总结:AFU 是"据其所知第一个真正脱离 actor-critic 视角、又能与 SOTA 比肩的 model-free off-policy 算法",并认为这条路对连续控制 off-policy RL 有新前景(conclusion,作者强主张/strong 措辞,但证据仅限上述基准)。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:在线连续控制、需要真 off-policy(可大量复用与当前策略不相关的历史数据)、想避免 actor 牵着 critic 走/避免 OOD 动作高估的场景;7 个标准 MuJoCo 任务规模(动作维 ≤17)。
- **AFU-beta 才管用的场景**:容易出现 actor 局部最优、欺骗性梯度(如 SFM 那类奖励有陡坡/不连续、最优 mode 远离当前策略采样区)的环境;普通 MuJoCo 上 beta 相对 alpha 没明显增益。
- **超参敏感**:max-Q 精度依赖 ϱ——ϱ 太小(≈0.05)会高估,需落在大致 0.2~0.7(MuJoCo 推荐 0.2/0.3);作者强调 AFU 对 ϱ 的"可用区间"比 IQL/SQL/EQL 对其超参宽得多。
- **理论上不保证**:附录 B 明说条件梯度缩放**不保证** `V_φ` 收敛到真 max——若回归很快到精确解、梯度消失,`V_φ` 可能停在严格大于真 max 处;只有当残差不可忽略时自适应正则才生效(实践中作者称观察到会逐步降到近似 max)。

## 核心贡献
1. 提出用**回归 + 条件梯度缩放**直接解连续动作 max-Q 问题的新机制(把 `V_φ` 从松上界压成紧上界=max),不需 actor、不需 OOD 动作。
2. 据此构造 **critic 更新完全独立于 actor** 的 off-policy 算法 AFU-alpha(actor 仍照 SAC 训,只管采数据)。
3. 给出并剖析一个 **SAC 的简单失效模式**(SFM 环境 + 欺骗性 KL 梯度的两阶段机理分析)。
4. 提出 **AFU-beta**:用回归学的 `μ_ζ` + 梯度投影算子 `G` 修掉 actor 的欺骗性梯度,使其在 SFM 上不再卡局部最优。
5. 在 7 MuJoCo + toy + SFM 上给出实验,并开源 JAX 实现。

## 局限与我的质疑
1. **基准偏窄、被过度上探的结论要打折**:整体竞争力只在 7 个标准 MuJoCo(最大动作维 17)上验证,且 AFU-alpha 是"与 SAC/TD3 相当"而非超越——把"competitive"读成"更好"会夸大。"在 Humanoid 上相对较好"也只是 observed,缺更高维/更难任务(如真实机器人、像素输入)的检验。
2. **AFU-beta 的核心卖点只在一个人造环境(SFM)上证明**:SFM 是单状态一维玩具,专为暴露 SAC 弱点而设计。beta 在真实 MuJoCo 上相对 alpha **无显著增益**,所以"修好了局部最优"目前更像存在性演示,实际收益的普适性未被证明(作者自己也把"找能凸显 beta 优势的复杂环境"留作 future work)。
3. **计算开销更高**:AFU 需维护比 SAC 更多的函数逼近器(`Q_ψ` + `V_φ1/V_φ2` + `A_ξ1/A_ξ2` + actor,beta 再加 `μ_ζ`),单步训练更重;作者在引言也承认这点。论文没给(我没读到)墙钟时间/FLOPs 的量化对比,"样本效率相当"掩盖了每步算力代价。
4. **关键方法无收敛保证、靠经验调参兜底**:条件梯度缩放不保证收敛到真 max(附录 B 自承),max-Q 精度强依赖 ϱ 的取值;虽说可用区间较宽,但本质仍是"用一个超参在'高估'与'慢/偏'之间手调平衡",换环境是否还稳未充分检验。
5. **理论直觉强、形式证明弱**:"跟踪 max 比跟踪 argmax 更平滑/更难被困"是有说服力的直觉(并引 [22]),但文中是论证性叙述,没有给出严格的收敛性或最优性定理来支撑"truly departs from actor-critic 更优"这一总主张。
6. **与本研究主题(RL 通用工具箱/可与环境交互)相比的不足**:这是纯连续控制 off-policy 的算法贡献,未触及多任务/分层/与复杂环境交互的工程层面;`μ_ξ`/`A_ξ` 等额外网络与梯度投影增加了实现复杂度与调参面,迁移到非 MuJoCo 任务的稳健性需要使用者自行验证。
