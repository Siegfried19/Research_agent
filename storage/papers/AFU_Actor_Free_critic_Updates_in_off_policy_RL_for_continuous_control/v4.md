# AFU: Actor-Free critic Updates in off-policy RL for continuous control
> [, ", N, i, c, o, l, a, s,  , P, e, r, r, i, n, -, G, i, l, b, e, r, t, ", ] · 2024 · arXiv.org · 引用 0 · DOI 10.48550/arxiv.2404.16159

## 一句话
AFU 是一种 off-policy 连续控制 RL 算法,用"回归 + 条件梯度缩放"直接求解 Q 函数在连续动作上的最大值(max-Q 问题),使 **critic 的更新完全独立于 actor**——从而真正脱离 actor-critic 范式,同时在样本效率上与 SAC/TD3 相当。

## 解决了什么问题
- Q-learning 的核心障碍是 max-Q 问题:Bellman 最优更新要算 `max_a Q(s,a)`,在连续/多维动作空间里难以直接求解。
- 主流做法(DDPG/TD3/SAC 等 actor-critic)是**间接**解 max-Q:训练一个 actor 去最大化 Q,把 actor 当成近似 argmax,再用它评估 critic。
- 这种耦合的副作用是 actor 可能陷入局部最优(原文点名 DDPG 及其衍生 TD3 "the actor may become trapped in local optima",§1)。
- 另一类直接面对 max-Q 的方法(CAQL、IQL 等)各有短板:CAQL 在高维动作空间扩展性差;IQL 类的 expectile 回归在试图逼近真最大值时损失会"失衡(unbalanced)",至今主要限于离线 RL(§1)。
- AFU 想要的是:一个**真正 off-policy** 且适合**在线** RL 的、直接解 max-Q 的算法。

## 用什么方法解决的（含直觉：为什么 work）
- **核心拆分**:利用 `V*(s) = max_a Q*(s,a)`,引入优势函数逼近器 `A*(s,a) = Q*(s,a) − V*(s) ≤ 0`。学一个值函数 `V_φ` 去逼近 Q 在该状态下的最大值,学 `A_ξ`(非正)补足差额。
- **直接解 max-Q 比"先学 actor 再 argmax"好的直觉(关键机制)**:原文论证"Q_ψ 的连续变化会带来其状态条件**最大值**的连续变化,却可能带来状态条件 **argmax** 的不连续变化"(§5)。所以在 off-policy 设定下,跟踪"最大值"可以平滑进行,而跟踪"argmax"困难得多、易出现欺骗性的值地形让 actor 卡住。AFU 跟踪的是前者。
- **为什么不会被 actor 污染(结构性区别)**:critic 的更新不依赖 actor。AFU 从不用分布外(OOD)动作训练 critic,作者据此主张 Bellman 回溯里用 OOD 动作的好处"其实并不明显"(§2)。
- **怎么让 V_φ 收敛到"紧"的最大值——条件梯度缩放(本文真正的新点)**:
  - 基础回归损失(式2)`l_{V,A}=Mean[(V_φ(s)+A_ξ(s,a)−Q_ψ(s,a))²]` 只能让 V_φ 成为 Q 的**上界**,而非紧上界——无正则时所有上界都"同样好"。
  - 作者不用普通正则(要么收敛慢、要么有偏),而是**非对称地调制梯度**:当 `V_φ(s)+A_ξ(s,a) < Q_ψ(s,a)`(即会让 V_φ 上升时)只施加一个比例 `ρ∈(0,1)` 的梯度;反之(会让 V_φ 下降时)施加完整梯度。于是 V_φ 受到持续的"向下压力",逐步逼近真正的最大值。形式化为 `Υ_i^a(s)=(1−ρ I_i^{s,a})V_{φi}(s)+ρ I_i^{s,a} V_{φi}^{no_grad}(s)`,`I=1` 当且仅当上式取上升方向(式3)。
  - 附录 B 说明这等价于一种**自适应正则**:正则权重正比于误差绝对值;误差大时压力大、误差趋零时压力消失(故理论上不保证收敛到精确最大值,但实践中观察到 V_φ 逐步逼近,supported)。
- **对 A 的符号约束做"软处理"**:A 本应 ≤0,但硬约束会产生抖动梯度,故用函数 `Z(x,y)=(x+y)² if x≥0 else x²+y²` 软性约束(式4,附录C)。
- **去掉对 Q_ψ 的依赖(真正 actor-free)**:式5 把回归目标里的 `Q_ψ(s,a)` 换成训练 Q_ψ 时用的 TD 目标本身,于是 `Q_ψ, V_φ, A_ξ` 都能在**没有 actor**的情况下训练。
- **critic 损失沿用 TD3 的 clipped double Q-learning**(式1):用两个值逼近器 `V_φ1,V_φ2` 取 min 以抑制过估计偏差。
- **仍需 actor 选动作/产数据**:AFU-alpha 直接复用 SAC 的随机 actor(高斯+tanh、自动调温度 α,式6/7)。注意此处 actor **只用于采样**,不参与 critic 更新。
- **AFU-beta——治 actor 自身的局部最优(§8)**:
  - 额外训一个确定性 `μ_ζ(s)`,用回归(式8 `L_μ=Mean[(μ_ζ(s)−a_•)²]`)估计"actor 的 mode 应该在哪":把 mini-batch 中(含**直接来自回放缓冲、不只是 actor 重采样**的)Q 值大于 `min_i V_φi(s)` 的动作当作目标(这些动作位于 argmax 附近)。
  - 然后**修改 actor 梯度以抹掉欺骗性梯度**:在采样动作 a_s 处的梯度 `∇_a Q_ψ(s,a_s)`,若它指向远离 `μ_ζ(s)` 的方向(与 `μ_ζ(s)−a_s` 点积为负)且 a_s 不在 argmax 附近(`Q_ψ(s,a_s) < min_i V_φi(s)`),就把它投影到与 `μ_ζ(s)−a_s` 正交的超平面上(算子 `G^{s,a_s}`,图5),得到修正梯度 `∇_θ^MODIF L_π`。
  - **直觉**:`μ_ζ` 因为用回归且能看到回放缓冲里的真实动作,在"非常 off-policy"时,即使 Q 的新峰出现在远离已采样动作处,μ_ζ 也能先找到它,再通过删除沿途的欺骗性梯度来引导 actor 翻过去——只要 critic 学得好,就能防 actor 被局部最优困住。

## 动机 & 背景
- 现代最成功的 off-policy 深度 RL(连续控制)其实是 actor-critic,而它们在大量训练数据偏离当前策略分布时会失效,因此**并非真正 off-policy**(§2,引 [8])。
- 反过来,真正 off-policy、源自 Q-learning 的方法(如 IQL)适配的是**离线** RL,在**在线** RL 上表现不好(§2)。
- AFU 定位于填补这个空档:既真正 off-policy、又适合在线 RL。
- 相关方法谱系(§2):NAF/ICNN(强制 Q 对动作凸)、QT-Opt/SMC/SDQN(动作空间离散化/随机优化)、X-QL、AWR(回归训值函数+策略,但样本效率落后 SOTA)等;TQC/REDQ/AQE/DroQ/BAC 等改进点(分布式 critic、集成、dropout 等)与 AFU 正交,作者留作未来融合。

## 方法细节
- 见上节的式1–8;两版算法共用同一个 Algorithm 1 框架(每个迭代=1 个环境步 + 1 个梯度步),AFU-beta 仅多训 `μ_ζ` 并把 `∇_θ L_π` 换成 `∇_θ^MODIF L_π`(算法清单中红色行)。
- AFU-alpha 的总损失 = `L_Q`(式1)+ `L_{V,A}`(式5)+ `L_π`(式6)+ `L_temp`(式7)。
- 超参(附录A,与 SAC/TD3 共享):Adam,actor/critic/温度学习率均 `3·10⁻⁴`,γ=0.99,回放缓冲 `10⁶`,2 层 256 单元 ReLU,目标平滑 τ=0.01,batch 256,目标熵 `−d`(d=动作维度),**不做 reward scaling**。AFU 关键超参是梯度缩放比例 `ρ`。

## 数据集 & 实验设置
- **玩具 max-Q 问题**(§4.2、附录D、图1/图6):函数 `Q_toy(s,a)=sin(4s)+0.7cos(4a)`,单网络拟合 V 与 A,与 IQL、SQL、EQL 比"谁更准地逼近 `max_a Q_toy`"。
- **7 个 MuJoCo 任务**(Gymnasium,§6 Experiments、图2):Ant、HalfCheetah、Hopper、Humanoid、InvertedDoublePendulum、Reacher、Walker2d;动作维 1(InvDoublePendulum)到 17(Humanoid),观测维 11–376。每配置 10 个随机种子;按 rliable 库画 performance profile;HalfCheetah 跑 5M 步,Ant/Hopper/Humanoid/Walker2d 3M,InvDoublePendulum/Reacher 1M。AFU、SAC、TD3 共用 τ、学习率、目标熵启发式。
- **SAC 失效模式环境 SFM**(§7,图3/4):单状态、1 维动作 `a∈[−1,1]`,`R_SFM(s0,a)=5−100(a−0.1)²` 若 `a≥−0.6` 否则 0;所有转移即终止,最优 `a=0.1`、回报 5。
- 对照里还把 AFU 的 `L_{V,A}` 替换成 IQL/SQL/EQL 对应损失,做"同一框架下只换 max-Q 解法"的消融。

## 主要结果 & 结论（写方向，不堆精确数字）
- 在玩具 max-Q 问题上,AFU 的解法在很宽的 `ρ` 区间(约 0.2–0.7)都能给出对 `max_a Q` 的精确逼近;而 IQL/SQL/EQL 用"适合实际 RL 的超参"时精度明显更差(supported,图1/图6)。仅 `ρ=0.05` 偏小时会过估计(observed)。
- 在 7 个 MuJoCo 任务上,把 max-Q 解法换成 IQL/SQL/EQL 会带来"明显的性能下降",AFU 自己的 max-Q 解法显著更好(supported,图2a);最佳 `ρ∈{0.2,0.3}`。
- AFU-alpha 在 7 个 MuJoCo 任务上与 SAC、TD3 **样本效率相当(competitive)**(supported,图2b)。
- 作者明确主张 AFU 与 TD3/SAC 样本效率相当**且并不更耗算力**("competitive in sample-efficiency with TD3 and SAC without being more computationally expensive",§1;摘要亦称其为"首个在与 SOTA actor-critic 相当的同时脱离 actor-critic 范式的 model-free off-policy 算法")。这是作者的对比结论性主张,论文未单列算力基准表来量化(strength:作者主张,observed/未给独立计时实验)。
- 复杂任务上 AFU 不会像其它"直接适配 Q-learning 到连续控制"的方法那样失败;在 MuJoCo 最难的 Humanoid 上,AFU 相对 SAC/TD3 表现尤其好(observed,§2/§6)。
- **SAC 失效模式**:在 SFM 上,SAC 的 critic `Q_SAC` 能精确收敛到 `Q*`,但其 actor 仍收敛到次优解(图3/4)。机制:单峰高斯策略 + KL 损失下,奖励在 `a=−0.6` 处的陡峭不连续被 critic 拟合成一道陡坡,形成"势垒"把 actor 困在左侧次优区;后期即便策略 mode 应回到 0.1,陡坡产生的欺骗性 KL 梯度阻止其翻越(observed,构造性环境)。AFU-alpha 因复用 SAC actor 也同样失败。
- **AFU-beta** 在 SFM 上能收敛到最优解(SAC 卡住)(observed,图4a);在 7 个 MuJoCo 任务上与 SAC/TD3 也 competitive(supported,图7)。
- AFU-beta 与 AFU-alpha 在 MuJoCo 上差异"不很显著",作者推测是因为这些环境里很少真正遇到局部最优问题(observed,§8);并把"找到 AFU-beta 明显占优的复杂环境"留作未来工作。

## 适用边界（什么时候管用 / 什么时候不管用）
- **管用**:连续控制的在线 off-policy RL,尤其是希望"critic 学习不被 actor 牵连"的场景;在 MuJoCo 这类标准连续控制基准上达到 SAC/TD3 水平。
- **AFU-beta 才更管用的场景**:当 actor(单峰高斯+KL)会被欺骗性梯度/陡峭不连续奖励困入局部最优时(如 SFM 这类)。但论文承认在常规 MuJoCo 上这种情形罕见,beta 相对 alpha 优势不明显。
- **可能不管用 / 未验证**:论文只在 MuJoCo + 一个构造的 SFM 上验证,未涉及图像观测、稀疏奖励真实任务、离散动作、真实机器人等;`ρ` 取值需调(过小如 0.05 会过估计)。
- 对照是**强基线**:SAC、TD3 都是连续控制 SOTA,且共享同套超参做公平对比;max-Q 消融对照 IQL/SQL/EQL 也是认真基线。这一点比只对弱基线的工作可信度高。

## 核心贡献
- 提出用**回归 + 条件梯度缩放**直接、可扩展地求解连续动作 max-Q 问题的新方法(作者认为该思路在 RL 之外也可能有用)。
- 给出 critic 更新**完全独立于 actor** 的 off-policy 算法 AFU——作者称其为首个在样本效率上与 SOTA 相当、却真正脱离 actor-critic 范式的 model-free off-policy 算法。
- 构造 SFM 环境清晰刻画 SAC 的一类局部最优失效模式,并据此设计 AFU-beta(用回归得到的 `μ_ζ` 引导、投影掉欺骗性 actor 梯度)使其不再同样失败。
- 提供基于 JAX 的开源实现(§1 脚注给出 GitHub 链接)。

## 局限与我的质疑
1. **"不更耗算力"缺独立量化**:这是对比结论而非实测基准——AFU 比 SAC 多了 `A_ξ1,A_ξ2`(乃至 beta 的 `μ_ζ`)等额外网络与损失项,直觉上每步计算与显存应略增。论文未给出 wall-clock/FLOPs/更新耗时对照表来支撑"without being more computationally expensive",读者若关心算力应自行测。(本条仅指出证据形态,不改写作者立场。)
2. **失效模式实验偏"玩具"**:SAC 的局部最优只在专门构造的单状态 SFM 上演示,且这正是为暴露问题而设计的奖励;在真实多状态任务里该失效有多普遍、AFU-beta 的修复能带来多少实际收益,论文自己也承认 MuJoCo 上 beta≈alpha、优势场景"留待未来工作"——即 beta 的核心卖点几乎没有在真实基准上兑现。
3. **理论保证弱**:附录B 明确承认条件梯度缩放**不保证** V_φ 收敛到精确最大值(误差趋零时压力消失),"紧上界"只是经验观察;`ρ` 是需要调的敏感超参(0.05 过估计、0.2–0.3 最好),论文未给选 ρ 的原则性方法。
4. **引用量为 0、单作者预印本**:2024 年 arXiv 预印本,尚无社区独立复现/同行评审背书;结论强度应以"作者自报实验"看待。
5. **适用范围窄**:仅 MuJoCo 状态向量任务 + 一个构造环境;未触及视觉输入、稀疏/长程奖励、离散动作、真实机器人——对"数字人/可交互环境"这类更复杂、可能多模态最优的设定,AFU 的单峰高斯 actor 仍是 alpha 的同款短板,beta 的投影修复在高维多峰下是否仍有效未验证。
6. **与正交改进的叠加未做**:作者把 TQC/REDQ/AQE/DroQ/BAC 等过估计/集成类改进明确留作未来工作,因此 AFU 当前是"与 SAC/TD3 持平",而非超越当下最强组合;"competitive"应理解为持平、非领先(Humanoid 的相对更好属个别任务 observed,不可外推成全面超越)。
