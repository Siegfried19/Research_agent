# Lazy Agents: A New Perspective on Solving Sparse Reward Problem in Multi-agent Reinforcement Learning
> Bo Liu, Z. Pu, Yi Pan, Jianqiang Yi, Yanyan Liang, Du Zhang · 2023 · International Conference on Machine Learning · 引用 36 · DOI title:4767e85b9c83c66b

## 一句话
针对协作式多智能体强化学习(MARL)的稀疏奖励问题,本文提出从"懒惰智能体(lazy agent)"视角切入:用因果图把全局状态拆成"内部/外部状态",用 do-演算定义"对外部状态毫无因果影响=懒惰",并设计两个内在奖励(IDI/CDI)逼智能体去影响外部状态,从而在 SMAC、GRF 的稀疏奖励任务上取得优于多个 SOTA 稀疏奖励基线的表现(supported)。

## 解决了什么问题
- 稀疏奖励下,MARL 智能体常退化成"懒惰智能体":不积极参与协作、不做有风险的主动行为,而是学会"消极保命/躲避"这类容易够到的次优策略(原文 §1、§3)。
- 作者以 SMAC 的 3m 任务 + QMIX 为例,展示稀疏奖励下 QMIX 陷入局部最优:至少一个 Marine 躲到地图边缘避免被发现,导致探索不足、协作失效、整局打不死敌人(§3、图1)。
- 核心洞察:稀疏奖励的奖励结构"不足以激励主动贡献",因此 50% 胜率策略比"纯躲避"策略更难被探索到(二者平均奖励相近时,躲避只需选移动动作),奖励结构反而在"鼓励懒惰"(原文 §3,见图1(f))。

## 用什么方法解决的(含直觉:为什么 work)
- 框架名 **LAIES**(Lazy Agents Avoidance through Influencing External States),基于 QMIX 实现。
- **状态二分(Def 4.1)**:全局状态 s_t = (s_t^i, s_t^e),内部状态 s_t^i 是与智能体直接绑定的(如自身位置),外部状态 s_t^e 是智能体能影响但非直接绑定的(如敌人位置/血量、GRF 里球的位置)。直觉:**最终目标的达成总是更强地关联于外部状态**(三个蓝 Marine 死亡、球进门),所以"是否在影响外部状态"是衡量智能体是否真在干活的好代理量。
- **用因果定义懒惰(§4.1)**:对智能体 j 的动作 a_t^j 在外部状态后继 s_{t+1}^e 上做 do-演算,算其因果效应,记为个体勤奋度 IDD τ_{a_t^j}。Def 4.3:**当且仅当 Σ_{t=0}^T τ_{a_t^j} = 0,智能体 j 完全懒惰**;Def 4.4:Σ τ_{a_t} = 0 则整队完全懒惰。直觉:一个智能体一整局对外部状态的因果影响为零 = 它干了等于没干。
- **两个内在奖励逼智能体勤奋**:
  - **IDI**(个体勤奋内在动机):奖励每个智能体对外部状态施加因果影响(让每个体"动起来")。
  - **CDI**(协作勤奋内在动机):单纯让每个个体影响外部状态 ≠ 让整队的联合影响最大化,所以再加一个对"联合动作"因果效应的奖励,鼓励智能体**协同地选出对外部状态有更大因果效应的联合动作**。
  - 直觉互补:IDI 治"个体偷懒",CDI 治"个体各自乱动但不形成有效合力"。
- **ESTM(外部状态转移模型)**做反事实推理:反事实量(如"换个动作外部状态会怎样")没法直接采样,且环境模型不可得;于是用 GRU 神经网络以 (状态, 联合动作) 预测下一外部状态,在 CTDE 训练期可用全局状态训练 ESTM,再用它对动作做 do-operator 算反事实结果(§4.2、图3)。

## 动机 & 背景
- 设定为完全协作的 Dec-POMDP,联合策略诱导联合动作值函数 Q_tot;主流范式是 CTDE(中心化训练、去中心化执行)(§2.1)。
- 因果工具:用因果图表示变量因果关系,用 do-演算识别可识别的因果估计量 P(O|do(M=m), C=c)(§2.2)。
- 相关工作(§2.3,均为被引背景、非本文结果):
  - 增强探索类(MAVEN、好奇心驱动 Pathak、CMAE 共享探索目标)——作者批评其"只强调探索、不研究哪些状态值得探索"。
  - 影响型行为类(最大化智能体间互信息 Jaques、塑造他人策略 Foerster/Letcher、PMIC 高低层互信息 Li 2022)——作者批评其可能催生"为各自目标而非整体目标"的不良联盟。
  - 子目标类(HDMARL 用领域知识、MASER 从经验回放自动生成子目标)——作者批评领域知识法难迁移、自动生成法性能不稳。

## 方法细节
- **个体因果效应推导(Eq 2–3)**:令节点集 w_t = {s_t, h_t, a_t^{~j}}(h_t 为历史轨迹,a_t^{~j} 为除 j 外的联合动作)。
  - Y_{s_{t+1}^e}(A_t^j=a_t^j) = P(s_{t+1}^e | do(A_t^j=a_t^j)) = Σ_{w_t} P(s_{t+1}^e | a_t^j, w_t) P(w_t),因只算 t 时刻效应故 P(w_t)=1,得 = P(s_{t+1}^e | a_t^j, w_t)。
  - **个体勤奋度 IDD(Eq 3)**:τ_{a_t^j} = D_KL[ Y(A_t^j=a_t^j) ‖ Y(A_t^j≠a_t^j) ] = D_KL[ P(s_{t+1}^e|a_t^j, w_t) ‖ P(s_{t+1}^e|w_t) ]。直觉:**"做这个动作"与"不做这个动作"对外部状态分布的差异**——差异越大,该动作越"有用"。
- **联合因果效应 CDD(Eq 4)**:τ_{a_t} = D_KL[ P(s_{t+1}^e|ā_t, s_t, h_t) ‖ P(s_{t+1}^e|s_t, h_t) ],衡量整队联合动作 ā_t 的因果效应。
- **IDI 内在奖励(Eq 5)**:r_t^IDI = Σ_{j=1}^{|N|} τ_{a_t^j}(把全体个体勤奋度加总)。
- **实践中用 MSE 替 KL(Eq 6–7)**:作者论证给定 s_t、h_t、ā_t 时状态转移固定,P(s_{t+1}^e|do(ā_t),s_t,h_t) 与 P(s_{t+1}^e|s_t,h_t) 服从**单点分布**(one-point distribution),故把 KL 散度换成 MSE。Eq 7 中反事实项用 ESTM 枚举其他动作的潜在结果取均值:τ_{a_t^j} = MSE( Y(A_t^j=a_t^j), (1/(|A|−1)) Σ_{k≠a_t^j} Y(A_t^j=a_k) )。
- **CDI 内在奖励(Eq 8)**:r_t^CDI = MSE( Y(Ā_t=ā_t), (1/(|A|^n−1)) Σ_{k≠ā_t} Y(Ā_t=ā_k) );因联合动作的反事实组合数随智能体数**指数增长**,实践中**随机采样若干联合动作**近似(原文 §4.3 明说)。
- **总内在奖励(Eq 9)**:r^I = β1·r^IDI + β2·r^CDI,β1、β2 为非负缩放系数。
- **训练(Eq 10–11)**:LAIES 用 QMIX 估 Q_tot,端到端最小化 TD 损失 L(θ) = Σ_i (y_i^tot − Q_tot(τ,a,s;θ))^2,其中 y_i^tot = r^E + r^I + γ·max_{a'} Q_tot(τ',a',s';θ^−)(r^E 为外在奖励,θ^− 为目标网络)。附录 A.1 补充:内在奖励在平均奖励 >0 后会被退火(annealed)。

## 数据集 & 实验设置
- 两个基准:**SMAC**(StarCraft 多智能体挑战,SC2.4.10,9 张地图:3m / 2m_vs_1z / MMM / 1c3s5z / 3s_vs_3z / 5m_vs_6m / 8m_vs_9m / MMM2 / 6h_vs_8z,难度 easy→super hard,见表1)与 **GRF**(Google Research Football,4 个 academy 任务,3 官方 + 1 手工)。两者均用稀疏奖励设定(SMAC:胜+1/平0/负−1;GRF:进球+10/失败−5)。
- SMAC 外部状态 = 对手位置与血量;GRF 外部状态 = 对手与球的位置和方向。
- 基线:SMAC 上对比 CMAE、MAVEN、MASER、QMIX、RODE,并额外加 **QMIX-DR**(QMIX + 稠密奖励,作为"开了密集 reward 的强参照",其 shaped reward 见附录 Eq 12);GRF 上对比 QMIX、QPLEX、CDS、MAVEN。CMAE 因未公开 SMAC 代码,用其论文最高分代表。
- 5 个(SMAC 曲线,§图1注)/6 个(主实验)随机种子;NVIDIA GTX3090;β1/β2 各地图单独调(如 3m {100,0.2}、2m_vs_1z {200,0.3}、5m_vs_6m {20,0.02}、MMM {600,0.3}、GRF 全任务 {1,8},见附录 A.1)。
- 附录 B.1 还把 LAIES 接到策略梯度法 **IPPO** 上(对比 IPPO-DR 等),验证不局限于值分解法。

## 主要结果 & 结论(写方向,不堆精确数字)
- 在 SMAC 全部 9 张地图(含 easy/hard/super hard)上,LAIES 相对稀疏奖励 SOTA 基线整体收敛更快、最终胜率更高(supported,图4)。MMM 任务能达到接近 100% 成功率(observed,§5.2)。
- 关键对照:相对**开了稠密奖励的 QMIX-DR**,LAIES 在 4 个场景(MMM、3s_vs_3z、5m_vs_6m、8m_vs_9m)仍**逊于** QMIX-DR(observed,§5.2)。作者解释这 4 个场景共性是**敌我实力差距小/对称**,而"懒惰更容易在一方有明显优势时出现"——即 LAIES 的优势主要体现在**实力非对称、稀疏奖励**的情形。
- GRF 4 个 academy 任务上,LAIES 在收敛速度与最终胜率上超过对比方法(supported,图5);academy 3vs2 胜率最终在 40% 以上(observed)。
- 消融(图6):去掉 IDI 在 MMM2、8m_vs_9m(SMAC)上显著掉点 → IDI 对"学会有效策略"关键;去掉 IDI 或 CDI 在 GRF 任务上都显著掉点,且 **CDI 在 GRF 中作用更主导**(QMIX-CDI 曲线优于 QMIX-IDI)。作者解释:GRF 外部状态变化更"整体性"(需把所有己方球员一起考虑),故"联合影响"更重要。
- 勤奋度与外部状态关系验证(§5.5、图7,5m_vs_6m):QMIX(稀疏)的 IDD 曲线随训练**持续下降趋近 0**(越来越懒),而 QMIX-DR 的 IDD 持续上升、与奖励上升一致;且 QMIX-DR 的 IDD/CDD 曲线始终高于 QMIX。结论方向:**越勤奋(能完成任务)的智能体对外部状态影响越大,IDD/CDD 能反映勤奋程度**(supported)。
- IPPO 变体(附录 B.1、图9):在 3m、2m_vs_1z 上 LAIES(IPPO) 优于所有对比;1c3s5z 上约 80% 概率全歼敌人,远高于 IPPO-DR 约 20%(observed)。证明 LAIES 思路也能用于策略梯度法。

## 适用边界(什么时候管用 / 什么时候不管用)
- **管用**:协作 MARL + **稀疏奖励** + 任务存在明确"外部状态"(有对手、有球这类智能体能影响的外部对象);尤其**敌我实力非对称、一方有显著优势**时(此时懒惰最易发生),LAIES 收益最大。
- **相对弱**:当任务**实力对称/差距小**(如 MMM、对称对战)时,LAIES 相对稠密奖励 QMIX-DR 优势缩小甚至被反超——它的价值在于"在稀疏奖励下逼近甚至接近稠密奖励效果",而非无条件最强。
- **可能不适用**:作者自述,没有对手的任务里"外部状态"的选取需领域知识(原文称 external states 的选择"may require domain knowledge");矩阵博弈这类简单任务没有外部状态(Remark 4.2,本文明确聚焦"含外部状态的复杂任务")。
- 对比的是**强基线**(QMIX、QPLEX、RODE、MAVEN、CDS、MASER、CMAE,以及开了稠密奖励的 QMIX-DR/IPPO-DR),不是弱基线——这一点结论较扎实。

## 核心贡献
- 提出"懒惰智能体"这一看待 MARL 稀疏奖励的新视角,并**用因果图 + do-演算给出"完全懒惰智能体/懒惰队伍"的数学定义**(Σ τ = 0)。
- 设计两个基于反事实推理的内在奖励 **IDI(个体)与 CDI(协作)**,分别治个体偷懒和缺乏有效合力。
- 提出 **ESTM**(GRU 外部状态转移模型)在 CTDE 下做 do-operator 反事实推理,使内在奖励可在无环境模型时计算。
- 在 SMAC + GRF 的稀疏奖励设定下系统验证,并开源(github.com/liuboyin/LAIES)。

## 局限与我的质疑
1. **"外部/内部状态"的划分依赖人工领域知识**(作者自述局限一)。这是方法的命门:在没有天然对手/无明确可影响外部对象的任务里,如何选 s^e 没有原则性方法,直接影响 IDD/CDD 的定义,泛化性存疑。
2. **懒惰的定义可能过窄**(作者自述局限二)。作者举例 MMM 里 Medivac 的"懒"体现在不影响**友军**状态而非外部(敌方)状态——说明"懒=不影响外部状态"并不能覆盖所有懒惰形态,定义本身需要进一步打磨。
3. **CDI 的组合爆炸 + 采样近似**。联合动作反事实数随智能体数指数增长,实践靠随机采样若干联合动作近似(Eq 8 上方原文),这会带来方差和偏差;论文未给采样数量/采样误差对结果影响的分析(我未读到相关消融,但作者也未声称做了),大规模智能体下是否还稳不清楚。
4. **"单点分布→用 MSE 替 KL"的假设在随机环境下可疑**。作者论证给定 (s_t,h_t,ā_t) 转移固定故为单点分布;但 GRF 本身"inner stochasticity"(附录 A.3 自述),环境转移并非完全确定,此时把 KL 简化为 MSE 的理论依据被削弱;且 ESTM 是学出来的近似器,其预测误差会直接污染反事实量与内在奖励,论文未深入评估 ESTM 自身精度。
5. **超参 β1、β2 跨任务波动极大且需逐图搜索**(100/0.2、600/0.3、20/0.02、GRF 全用 1/8,见附录 A.1),还要"平均奖励>0 后退火"。这意味着实际部署需要不小的调参成本,削弱了"开箱即用"的说服力,也让"通用解法"的主张打折扣。
6. **并非无条件超越**:相对稠密奖励 QMIX-DR 在 4 个对称/小差距场景仍落后——读者勿把"SOTA"读成全面碾压,其优势是**特定条件(稀疏+非对称)下**的(observed)。
7. **与本研究主题(单策略训练目标)的契合度有限**:本文是多智能体协作设定,核心机制(状态二分、个体/联合因果效应、CTDE 下训练 ESTM)高度绑定多智能体结构,迁移到单智能体/单策略训练目标时,IDI/CDI 的"个体 vs 联合"区分会失去意义,可借鉴的主要是"用反事实因果效应构造内在奖励对抗稀疏奖励"这一思路,而非整套框架。
