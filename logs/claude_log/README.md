# logs/claude_log/ — agent 的自由备忘位置

> 2026-06-21 用户定。**不是强制日志,不是每轮都写。**

## 这是什么
当 agent **自己觉得**有什么值得记下来、**又不属于现有记忆体系**的东西时,可以写到这里。
完全自由裁量——没必要就别写,这个目录空着也正常。

现有记忆体系(优先往这些里归;放得进就别用本目录):
- 根 `claude_log.md` —— 面向用户的改动时间线总账(铁律:实质改动就记)。
- `claude-memory/` —— 模块设计 README + STATE 层积日志(结构化沉淀)。
- 私有记忆(`~/.claude/.../memory/`) —— 用户偏好/项目约定等跨会话事实。

本目录 = 上面三者都不太合适、但我判断"以后自己可能想翻"的零散东西的兜底处。
随 git 走(`.gitignore` 给本目录开了例外),所以换机器也看得到。

## 写法(真要写时)
