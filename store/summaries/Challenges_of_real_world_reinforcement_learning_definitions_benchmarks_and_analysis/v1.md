# Challenges of real-world reinforcement learning: definitions, benchmarks and analysis
> Gabriel Dulac-Arnold, Nir Levine, Daniel J. Mankowitz, Jerry Li, Cosmin Păduraru, Sven Gowal, Todd Hester · 2021 · Machine Learning · 引用 563 · DOI 10.1007/s10994-021-05961-4

## 一句话
这是一篇"立坐标系"的论文:它把阻碍 RL 从仿真走向真实系统的困难提炼成**九大挑战**,逐一形式化定义、在一套开源连续控制套件 `realworldrl-suite` 里单独复现并量化其难度,并用两个 SOTA 算法做基准——结论是现有 SOTA 在很多挑战上(尤其组合起来时)很快就崩。

## 解决了什么问题
RL 在仿真里成绩斐然,但落地慢。作者认为根因是"实验设定与真实系统之间的鸿沟":真实系统有延迟、噪声、非平稳、安全约束、海量状态/动作空间、只能从有限样本或离线日志学、要低延迟出动作、还要可解释。论文要做的不是提一个新算法,而是**识别并形式化一组独立挑战**——"In this work, we identify and formalize a series of independent challenges that embody the difficulties that must be addressed for RL to be commonly deployed in real-world systems"(p.2419 Abstract)。九大挑战是(p.2420 §1):①有限样本在线学习;②系统延迟;③高维连续状态/动作;④满足环境约束;⑤部分可观测与非平稳;⑥多目标/不良定义奖励;⑦实时推理;⑧从固定离线日志训练;⑨可解释策略。"We posit that these difficulties can be well summarized by a set of nine challenges that are holding back RL from real-world use"(p.2420 §1)。

## 用什么方法解决的
**做法是"基准化每个挑战"**:把每个挑战在一套可参数化、可调难度的连续控制环境里单独实现,然后观察它对学习算法的孤立影响。

- **套件**:`realworldrl-suite` 扩展自 DeepMind Control Suite——"Seven real-world challenge wrappers (mentioned above) across 8 DeepMind Control Suite tasks"(p.2453 §4);评测用其中 4 个任务:cartpole:swingup、walker:walk、quadruped:walk、humanoid:walk(维度依次升高,见 Table 1)。
- **两个基准算法**:"Distributional Maximum a Posteriori Policy Optimization (DMPO) ... and Distributed Distributional Deterministic Policy Gradient (D4PG)"(p.2424 §2)。选它们的理由是双重的:"We chose these two algorithms for benchmarking performance as they (1) yield SOTA performance on the dm-control suite"(p.2424 §2),且二者算法本质不同(DMPO 是 EM 式随机策略,D4PG 是确定性策略梯度)——用两种范式来佐证"是挑战本身难,不是单个算法的毛病"。D4PG 的核心改进:"D4PG makes four changes to improve the critic estimation ...: evaluating n-step rather than 1-step returns, performing a distributional critic update ..."(p.2424 §2)。
- **协议**:"Each algorithm is run for 30 K episodes on 5 different seeds"(p.2424 §2);"the mean performance reported in each graph is the mean performance of the last 100 episodes of training with the corresponding standard deviation"(p.2424 §2)。

## 数据集 & 实验设置
本文不是"喂数据集"型工作,而是"造受控扰动"型:每个挑战都有一个可从"无→不可解"连续调节的参数。

- **挑战1(有限样本)**:定义两个度量——pre-convergence 的**global normalized regret**(收敛前损失了多少回报,公式见 p.2426)与 post-convergence 的**instability**(收敛后多大比例 episode 仍低于下界,公式见 p.2427)。
- **挑战2(延迟)**:"An action delay is defined here as delaying the agent's action execution for [n timesteps], whereas an observation/reward delay is defined as withholding an agent's observation/reward"(p.2428 §2.2);动作/观测延迟扫 0→20 步,奖励延迟扫 0→100 步(Fig.2)。
- **挑战3(高维)**:用哑变量注入额外状态维度(0/10/20/50/100);并叠加高斯动作/观测噪声(Fig.4–5)。
- **挑战4(约束)**:用 CMDP 形式化——"Constrained MDPs define a constrained optimization problem and can be expressed as:"(p.2431 §2.4),即在 \(C^k(\pi)\le V_k\) 约束下最大化回报;每个域配一组布尔安全约束(cartpole 三条:`slider_pos`/`slider_accel`/`balance_velocity`,全表见 Table 2),用 `safety_coeff∈[0,1]` 调难度。
- **挑战5(部分可观测/非平稳)**:用 Robust MDP(最坏情形价值,公式 (2),p.2435)框架;实验加卡住/丢失传感器(Fig.7–8)、按 Table 3 扫物理参数扰动、跑 uniform/cyclic 两种非平稳调度(Fig.10–11)。
- **挑战6(多目标)**:朴素混合奖励 \(r_m=(1-\alpha)r_b+\alpha r_c\)——"where r_b is the task's base reward, r_c is the number of satisfied constraints during that timestep and [α balances the objectives]"(p.2442 §2.6),扫 `multiobj_coeff`(Fig.12)。
- **挑战7(实时)**:用动作重复(throughput)和动作延迟(latency)模拟算力瓶颈,动作重复扫至 20 步(Fig.13)。
- **挑战8(离线)**:用三档数据集(small/medium/large,规模见 Table 5,如 walker 1000/2000/5000 episodes),行为策略取 DMPO 训到约 75% 收敛性能的快照;离线算法用 CRR 与离线版 D4PG。
- **组合挑战(2.10)**:把多个挑战按 easy/medium/hard 三档(Table 6)拼成一个环境,结果见 Table 7(D4PG)/Table 8(DMPO)。

## 主要结果 & 结论
**单挑战层面(均为受控实验下的观察,非普适断言):**
- 样本效率:"We can observe that DMPO has higher normalized regret than D4PG on all tasks"(p.2426 §2.1);但收敛后,"DMPO also has higher instability than D4PG, except for cartpole:swingup"(p.2427 §2.1)。综述节进一步概括为 DMPO "almost an order of magnitude worse in terms of regret, but significantly more stable once converged"(p.2454 §5)——即"学得慢/损失大,但稳"。同域内还观察到 D4PG 在 humanoid 上收敛更慢却比 walker 上更稳(p.2427 §2.1)。
- 延迟:"Both algorithms appear to be less sensitive to reward delay compared to delays in observations or actions"(p.2428 §2.2),奖励延迟"has to be increased to 100 timesteps to see a significant drop"(p.2428 §2.2);但综述指出这条有例外——"reward delays seem to be globally less impactful except on the humanoid:walk task"(p.2454 §5)。
- 高维:"the algorithm learns to deal with the noise and converges to the optimal performance for the cases of cartpole:swingup, quadruped:walk and walker:walk"(p.2430 §2.3);综述概括"additional observation dimensions don't affect either DMPO or D4PG significantly, and ... environments with more action dimensions are not necessarily harder to learn"(p.2454 §5)。一个有意思的机制性观察:"[quadruped] yet converges faster since it is a fundamentally more stable system"(p.2430 §2.3)——**系统内在稳定性比维度更主导学习难度**,这条直觉在动作重复实验里再次复现:"we observe that albeit quadruped has larger state and action spaces, it still more robust to action repetition"(p.2444 §2.7)。
- 约束:"constraint violations are non-uniform throughout time"(p.2432 §2.4),`safety_coeff` 越趋 0 越难。
- 传感器:"both dropped and stuck sensors have a significant effect on degrading the final performance"(p.2435 §2.5)。
- 多目标:"over-emphasis on [r_c quickly degrades r_b and therefore base task performance]"(p.2442 §2.6)——约束权重一高,基础任务就塌,体现真实任务里目标天然冲突。
- 离线:CRR "fails to learn properly in the [humanoid:walk and cartpole:swingup domain]",但在 walker/quadruped 上尚可(p.2446 §2.8);而"D4PG was also trained on each of the tasks, but failed to learn in each case and therefore the results have been omitted"(p.2446 §2.8)——**在线 SOTA 直接搬到离线会全面失败**。

**组合挑战层面(本文最有冲击力的结论):**
- "[Even taking the relatively easy versions of each challenge] and combining them together creates a surprisingly difficult task"(p.2449 §2.10);"We can see that both learners' performance drops drastically, even when applying the smallest perturbations of each challenge"(p.2449 §2.10)。Table 7/8 的数字很惊人:humanoid:walk 上 D4PG 从无挑战的约 934 掉到 medium 档约 1.3,DMPO 从约 788 掉到约 1.3——**几乎归零**。

**结论**:现有 SOTA 在单个挑战上往往还撑得住、组合起来就崩;作者把组合挑战作为推动社区进步的参考基准。

## 核心贡献
作者自述四项贡献(p.2422 §1.2):①识别与定义这组真实世界挑战;②为每个挑战设计实验与分析(除可解释性外);③定义并基准化 RWRL 组合挑战任务;④开源 `realworldrl-suite` 代码库。论文明确**只处理了九个里的八个**——"we have addressed 8 of the 9 challenges originally presented in Dulac-Arnold et al. (2019). The remaining challenge is explainability"(p.2451 §2.11),可解释性留作未来工作。对实战的价值:这是一份**带可调旋钮的"训练坑清单"**,谁要做真实 RL,可以拿它逐项压测自己的算法到底卡在哪一类困难上。

## 局限与我的质疑
1. **只测了两个算法,且都是同一家族的 distributional actor-critic。** 作者自己说本可以加 SAC、PPO,但出于算力成本没加(p.2424 §2)。这意味着"SOTA 在这些挑战上很挣扎"的结论,严格说只对 D4PG/DMPO 成立,不能外推到所有现代算法——尤其针对延迟、部分可观测,本就有专门方法(RNN 策略、RUDDER 等,作者在 related work 里都引了)却没纳入基准对比。所以基准给的是"朴素学习器"的下界,而非"已知最优应对"的水平,这点作者也坦承(p.2451:baseline "is with a naive learner that is not designed to answer these challenges")。
2. **大量结论是"observed"级,不是"proven"级。** 很多结论建立在 4 个任务、各 5 个种子的曲线观察上(如"奖励延迟影响小"在 humanoid 上就被自己推翻)。"系统内在稳定性主导学习难度"是个很有启发的直觉,但论文只给了 quadruped vs walker 这类零散对照,没有系统隔离"稳定性"这一变量,机制解释偏叙事。
3. **挑战度量本身的可比性存疑。** 归一化 regret 是相对"已知最优策略"算的,作者也承认一旦出现更好算法,这些指标会随之改变(p.2427)——即基准是"移动靶",跨论文比较时要小心。约束、部分可观测等都用了相当简化的代理(布尔约束、哑变量噪声、卡住/丢失传感器),与真实系统的复杂故障模式差距有多大,没有验证。
4. **可观测性混用 state/observation。** 论文为方便把 observation 当成 state(MuJoCo 内部状态对 agent 可见,p.2423/p.2453),这恰恰**弱化了部分可观测挑战的真实难度**——真正难的恰是观测不等于状态,而基准里大部分实验 agent 拿得到近乎完整的状态。
5. **与本研究主题(实战训练坑清单)对照的不足。** 它给的是"挑战分类学 + 受控基准",非常适合作为"训练时会踩哪些坑"的清单;但它**不提供 do/don't 级的可操作处方**——告诉你延迟会害你,却没系统对比"该上哪种缓解手段"。要落到实战,还需结合各挑战 related work 里被引但未被基准化的具体方法。
