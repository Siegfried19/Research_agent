# Whole-body simulation of realistic fruit fly locomotion with deep reinforcement learning
> Roman Vaxenburg, Igor Siwanowicz, Josh Merel, Alice A. Robie, Carmen Morrow, Guido Novati, Zinovia Stefanidi, Gert‐Jan Both, Gwyneth M Card, Michael B. Reiser, Matthew Botvinick, Kristin Branson, Yuval Tassa, Srinivas C. Turaga · 2024 · bioRxiv (Cold Spring Harbor Laboratory) · 引用 27 · DOI 10.1101/2024.03.11.584515

## 一句话
在 MuJoCo 里造了一个解剖学精细的果蝇全身生物力学模型（67 个刚体、102 自由度），并用深度强化学习 + 模仿学习训练神经网络控制器，让它能在闭环感知-运动回路中真实地飞行、行走，并用自带视觉完成避障飞行。

## 解决了什么问题
要理解神经系统如何产生行为，就必须有一个足够真实的"身体"——身体决定了运动指令如何转化为动作、动作的后果又如何通过感觉反馈回传。过去的果蝇仿真要么身体简化、要么控制器靠手工设计、要么只能做飞行或只能做行走。本文要给出一个**通用、解剖精细、开源**的整身体模型，并用它在同一套身体上同时复现真实的飞行与行走，作为未来"脑-体-环境"具身神经控制研究的平台。

## 用什么方法解决的
1. **建模**：共聚焦显微镜成像 → Fiji 手工分割 67 个身体部件、Blender 装配出 66 个关节/102 自由度的运动学树 → 导入 MuJoCo 加碰撞几何、质量、执行器和传感器（视觉/前庭/本体感觉/机械感受）。
2. **扩展物理引擎**：给 MuJoCo 新增两个通用特性——(a) 一个无状态、准稳态的**唯象流体力模型**（把 Andersen 2005 推广到三维，含附加质量、黏性阻力、黏性阻尼、Magnus 升力、Kutta 升力五项系数），用于扇翅产生升力；(b) **黏附执行器**模拟足端抓附（让果蝇能倒挂在天花板上）。
3. **控制**：用 **DMPO**（off-policy actor-critic，带分布式 critic 的 MPO 扩展，acme + Ray 分布式训练）做端到端 RL。飞行控制器 = 固定**扇翅模式发生器(WPG)** + 可训练 MLP（策略只学对基线翅拍的微小偏移）；行走控制器 = 单个 MLP（步态变化大、无法用模式发生器）。两者都用**模仿学习**：奖励让模型的质心轨迹、身体朝向以及各身体部件/腿翅运动去匹配真实果蝇视频数据。再额外做**视觉引导飞行**任务（CNN 处理 32×32 复眼图像 + 策略网络端到端训练）。

## 动机 & 背景
动物行为是脑、身体、环境三者构成的感知-运动反馈回路的产物。身体精确决定了运动命令→动作的映射，以及动作后果→感觉反馈的回传，所以要理解运动的神经控制，必须先有一个详细的身体生物力学模型。
此前工作：Grand Unified Fly（Dickson 2008，简化身体 + 手工控制器，做过视觉闭环飞行）；NeuroMechFly（Lobato-Rios 2022 / Wang-Chen 2023，解剖真实身体 + 含学习成分的混合手工控制器，做过视觉闭环行走）。本文的定位是：**单一通用解剖真实身体上同时做飞行与行走，且控制器靠端到端 RL 从数据中学，能模仿任意复杂的自然轨迹**。最终目标是结合连接组(connectome)约束的神经网络，构建果蝇"全脑+全身"的具身模型（NeuroAI）。

## 方法细节
- **身体几何**：共聚焦荧光显微镜成像（拆解身体、酶解软组织、漂白色素），Fiji 分割 67 部件，Blender 把网格从 22.6M 顶点简化到约 20K，在 66 个关节处装配，得 102 自由度。每个生物关节建模为 1/2/3 个铰链关节组合。
- **物理化**：生成碰撞用 geom 原语；测得各部件质量（头 0.15mg / 胸 0.34mg / 腹 0.38mg / 每腿 0.0162mg / 每翅 0.008mg，整虫 0.983mg，体长 0.297cm，翼展 0.604cm），按均匀密度估转动惯量；翅关节用力矩执行器、其余用位置执行器；多节跗节/腹部由 tendon 耦合、单执行器驱动多自由度；跗节尖与口器加黏附执行器。
- **流体模型**：唯象、准稳态，对椭球体近似五种流体力（附加质量/黏性阻力/黏性阻尼/Magnus/Kutta），**忽略湍流、涡街等有状态流体现象**（这些已知对昆虫飞行有贡献）。翅近似为细长椭球。系数 fluidcoef=[1.0,0.5,1.5,1.7,1.0]，通过让净升力在悬停时平衡体重来标定。
- **计算成本**：102 自由度、飞行约 200Hz 拍翅，仿真步长约 0.1ms。单核 Xeon 上仿真 10ms 飞行/行走环境分别需 421.5ms / 68.65ms（其中 MuJoCo 本身 55.5 / 23.2ms），靠 Ray 多 CPU + GPU 分布式把训练压到数天/数小时。
- **RL 算法**：DMPO（分布式 critic），actor-critic、前馈 MLP 策略与 critic，Adam，动作范围 [-1,1] 再缩放，观测全部在自体中心坐标系；物理步比控制步小 4–10 倍保稳定；训练随机策略、测试用均值确定性策略；提前终止（撞地/偏离参考）会截断未来奖励。
- **飞行**：WPG 产生镜像对称的固定基线翅拍（基于悬停果蝇数据），策略只控制拍翅频率（218Hz±10%）和对基线的小偏移；用 DMPO 动作惩罚把翅运动约束在基线附近。观测 62 维（本体+前庭+转向指令），动作 12 维（头、翅、腹、WPG 频率）；飞行时腿收起冻结。奖励 = 质心位移项 × 朝向项（式13）。**翅角不进训练奖励，只用于评估。**
- **行走**：单 MLP，无模式发生器；观测 741 维（含腿力/触觉传感器、执行器内部状态、未来 64 步转向指令），动作 59 维（头、腹、6×8 腿关节、6 个腿黏附）。奖励 = 质心+关节四元数+关节速度+末端足尖位置四项高斯乘积（式18-19）。**黏附不进奖励**，但 agent 自发学会在支撑相激活黏附增大摩擦。
- **视觉引导飞行**：两眼用 MuJoCo 相机各渲染 32×32、150° 视场（≈复眼 4.6° 个眼间视角）；视觉经类 ResNet 单块 CNN 压成 8 维特征喂给策略；任务额外输入目标速度/高度；CNN+策略端到端训练。"bumps"（正弦起伏地形上维持恒定离地高度）和"trench"（穿越正弦弯曲沟道不撞壁），地形/目标每幕随机生成，撞地形即提前失败。

## 数据集 & 实验设置
- **飞行参考数据**：Drosophila **hydei**（比 melanogaster 大）的高速摄影（7500fps），自发 saccade 44 条 + 视觉 looming 逃逸 92 条，镜像增广后共 272 条轨迹（约 53 秒），80% 训练。注意建模身体用的是 melanogaster，飞行数据用的是 hydei（平均拍翅 192Hz vs 218Hz）。
- **行走参考数据**：单相机俯视 150fps、50mm 圆形竞技场内多只果蝇自由行走，APT 追踪 17 个关键点（用其中 13 个）；按距离/速度/时长筛出片段，2D→3D 用侧视视频估高度/俯仰角 + 腿尖摆动正弦弧近似 + 正则化逆运动学拟合全身位姿。共约 16,000 片段、约 80 分钟，约 13k 训练。
- **腿自由度验证**：392 帧梳理(grooming)姿态做逆运动学拟合，各关键点中位误差普遍 < 体长 1%。
- **评测**：飞行 56 条测试轨迹，质心位置中位误差 0.25mm、朝向中位误差 <5°；行走 3.2k 条测试，位置中位误差 0.4cm、朝向 4°；视觉任务各 1000 条轨迹，bumps 高度误差 0.045cm/速度 2.2cm/s，trench 高度 0.032cm/速度 -0.16cm/s（均为加速期后中位值）。

## 主要结果 & 结论
- **飞行**：单个可转向控制器能稳定飞行并泛化到新轨迹；用与真蝇相似的翅运动达成质心匹配，复现了"只靠对基线翅拍的微小左右差异即可产生大转向加速度"的真实现象；转向时滚转/俯仰角速度的相对重要性与真蝇一致。
- **行走**：质心跟踪良好；自发涌现真实步态——高速(4cm/s)平均 3.1 条腿支撑、低速(1cm/s)3.9 条，与真蝇一致；各腿相对 L1 的摆动相位分布与真蝇吻合；转向时通过调节左右步幅实现，与真蝇中后腿规律一致——**但前腿学出了一个真蝇没有的非对称模式（只在左转时调前腿步幅、右转不调）**。
- **视觉飞行**：CNN+策略端到端学会用复眼图像维持离地高度、穿越沟道避障。
- **结论**：单一通用解剖真实身体上首次同时实现真实飞行与行走的闭环感知-运动控制，全部开源（含预训练控制器、数据、模型），作为未来连接组约束的具身神经控制研究平台。

## 核心贡献
1. 解剖学精细的果蝇全身 MuJoCo 模型（67 部件 / 102 自由度），开源、可编程修改/扩展。
2. 给 MuJoCo 新增两个通用物理特性：三维唯象流体力模型 + 黏附执行器。
3. 用 DMPO + 模仿学习训练出可转向的低级飞行/行走闭环控制器，能模仿任意复杂自然轨迹、并涌现真实步态与翅拍策略。
4. 演示用模型自带视觉做端到端视觉引导飞行（高度控制 + 沟道避障）。
5. 完整开源平台（代码/数据/预训练网络），为 NeuroAI 具身建模奠基。

## 局限与我的质疑
1. **作者自述的物理/解剖近似很重**：流体模型完全忽略湍流、涡街等有状态流体现象（这些恰是昆虫飞行升力的关键来源之一，如前缘涡）；关节是单/双/三铰链的简化，作者明确承认颈关节、翅铰、胸-基节关节尤其粗糙；翅是细长椭球近似。换言之"真实"主要是运动学层面的真实，气动力机理上是凑出来的——升力靠手工标系数让悬停时平衡体重，这意味着定量气动结论不可过度采信。
2. **跨物种数据混用**：身体模型基于 melanogaster，但飞行训练/评估数据来自更大的 hydei（拍翅频率 192 vs 218Hz），作者因此**主动放弃了翅拍轨迹的定量比较**，只做定性比较。所谓"复现真实翅拍"因此缺乏严格的定量校验；而前腿转向出现真蝇没有的非对称模式，说明 RL 找到的是"能完成质心模仿任务的某个解"，未必是生物真实的运动方案——模仿质心+部件位置不足以唯一约束出真实的肌肉协调。
3. **行走 3D 真值本身是推断出来的，存在循环论证风险**：行走参考姿态来自 2D 13 关键点 + 固定高度/俯仰假设 + 正弦腿尖弧 + 正则化逆运动学"脑补"出的全身位姿。模型再去"模仿"这套被先验假设塑形过的轨迹，那么"步态与真蝇吻合"在一定程度上是被注入的先验，而非独立验证；黏附自发涌现也缺乏真实足端力的直接测量来佐证。
4. **作为预印本未经同行评审**，且评测只报中位误差、未给误差分布尾部/失败率（尤其视觉任务的撞地终止率没量化），泛化性证据偏弱。
5. **与"RL 训练数字人与环境交互"主题的差距**：这是果蝇而非人形/数字人，自由度数量级与人体差距大，且环境交互停留在地形避障/离地高度这类被动地形，**没有与可操纵物体、其他智能体或人类的主动交互**（无抓取、推拉、接触力交换、社交交互）。控制是低级运动模仿 + 简单视觉导航，没有高层任务规划或多目标交互。方法论（MuJoCo + 模仿学习 + 可转向低级控制器 + 端到端视觉）对具身全身控制高度可借鉴，但"与环境/人交互"这一核心命题在本文几乎未触及，迁移到数字人交互场景还有很大缺口。
