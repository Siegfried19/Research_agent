# Generative Agents: Interactive Simulacra of Human Behavior
> Joon Sung Park, Joseph O’Brien, Carrie J. Cai, Meredith Ringel Morris, Percy Liang, Michael S. Bernstein · 2023 ·  · 引用 1412 · DOI 10.1145/3586183.3606763

## 一句话
给大语言模型(ChatGPT/gpt-3.5-turbo)接上一套"记忆流 + 反思 + 规划"的认知架构,让 25 个智能体在类《模拟人生》的沙盒小镇里自主过日子、互相交谈、扩散信息、结成关系并协同办派对,产生**可信(believable)**的个体与群体涌现行为。

## 解决了什么问题
长期以来人们想要"可信的人类行为代理"(游戏 NPC、社会仿真、原型工具、认知模型),但旧方法各有死穴:规则/行为树/有限状态机靠人工硬编码,覆盖不了开放世界的全部交互;强化学习只在有明确奖励的对抗博弈(StarCraft、Dota)里成功,搞不定开放世界的可信行为;认知架构(SOAR/ICARUS)受限于手工编写的程序性知识。LLM 能在**单一时间点**模拟人类行为,但受限于上下文窗口,无法在**长期**保持连贯——记忆会不断增长、需要检索相关经验、需要从经验中归纳出更高层结论,再据此规划当下与长远都说得通的行为。本文要解决的就是"如何用 LLM 撑起长期连贯、可涌现社会动态的可信智能体"。

## 用什么方法解决的
提出一套三组件的智能体架构,全部用自然语言记录与推理,因而可直接喂给 LLM:
1. **记忆流(Memory Stream)+ 检索**:把智能体所有经历(observation)按自然语言条目存下来(含创建/最近访问时间戳)。检索时用三项加权打分(α 全设为 1):**近因 recency**(对游戏小时数做指数衰减,衰减因子 0.995)、**重要性 importance**(直接让 LLM 给 1–10 分,区分刷牙这类琐事与分手这类大事)、**相关性 relevance**(对记忆文本求 embedding,与当前查询做余弦相似度)。三项 min-max 归一化后加权,取塞得进上下文窗口的 top 条目。
2. **反思(Reflection)**:周期性触发(最近事件重要性分累计超 150,实测约每天 2–3 次)。先用最近 100 条记忆让 LLM 提出 3 个最显著的高层问题,再以这些问题做检索、让 LLM 抽取洞见并引用支撑记忆条目,生成更抽象的"反思"存回记忆流。反思可基于反思,形成**反思树**(叶子是观察,越往上越抽象,如"Klaus 专注于他的研究")。
3. **规划(Planning)与反应**:自顶向下递归生成计划——先用智能体摘要描述+前一天概要生成当天 5–8 段粗略议程,再递归拆成小时级、5–15 分钟级动作,避免"在 12 点、12:30、1 点连吃三顿午饭"这类瞬时可信但时间上崩坏的行为。每个时间步感知环境后,让 LLM 判断是否打断现有计划去**反应**(如看到炉子烧起来去关火),需要时重生成计划并生成对话。
环境用树结构(区域/物体的包含关系)表示,转成自然语言("厨房里有个炉子")喂给模型;智能体维护自己见过部分的子图(非全知)。底层模型为 ChatGPT(gpt-3.5-turbo,GPT-4 当时仅邀请制)。

## 动机 & 背景
"可信的人类行为代理"是交互、游戏、AI 社区四十多年的"北极星",可用于:填充虚拟社区产生真实社会现象、训练人应对罕见棘手的人际情境、检验社会科学理论、做认知模型与可用性测试、驱动泛在计算与社交机器人、撑起开放世界 NPC。作者梳理三条脉络(人机交互、可信代理、LLM 与人类行为),论点是:**LLM 单独不够,但配上合适架构,就能重新打开"可信代理"这个老问题**。关键观察是 LLM 从训练数据里编码了大量人类行为,给定窄上下文即可生成可信行为;但已有工作多是"一阶提示"(few-shot / CoT),只依赖当前环境,无法依赖海量过往经验——本文把检索做成"每步动态更新、与当前上下文和计划混合"的形式,推进了这一点。

## 方法细节
见上"用什么方法"。补充几个工程要点:
- **种子记忆**:每个智能体由一段分号分隔的自然语言描述初始化(姓名/职业/关系等),拆成多条初始记忆;随经历增多,摘要与行为会演化。
- **用户控制**:用户以某"persona"(如记者)与智能体对话;若以智能体的"内心声音(inner voice)"下令,智能体更倾向当作指令执行。
- **对话生成**:双方各自检索关于对方的摘要记忆+对当前话语的相关记忆,轮流生成,直到一方决定结束。
- **环境落地**:递归遍历智能体的环境树,让 LLM 选最合适的区域→子区域→叶子节点,再用传统寻路动画移动;动作执行后让 LLM 判定物体状态如何变化(如咖啡机 off→brewing)。
- 沙盒 Smallville 用 Phaser 框架,服务器维护 JSON 同步智能体位置/动作/物体状态,把视野范围内的对象推给对应智能体记忆。

## 数据集 & 实验设置
两层评测:
- **受控评测(Controlled)**:把智能体当人"访谈",五类各 5 题——自我认知、记忆、规划、反应、反思。对比 5 个条件:完整架构 / 去反思 / 去反思+去规划 / 去观察+去反思+去规划(≈此前 LLM 智能体 SOTA)/ 人类众包作者基线。被试内设计,100 名 Prolific 评测者(美国、英语流利、>18 岁,$15/小时,约 30 分钟)对每题五条件按可信度排序。用 **TrueSkill**(Elo 的多人推广)把排序转成区间评分(μ, σ);用 **Kruskal-Wallis** 检验整体显著性 + **Dunn 事后检验**(Holm-Bonferroni 校正)看两两差异;另做归纳式开放编码做质性分析。智能体取自完整架构跑满 2 个游戏日后的状态。
- **端到端评测(End-to-end)**:25 个智能体在 Smallville 连续互动 2 个游戏日,测三类涌现:信息扩散、关系形成、协同。

## 主要结果 & 结论
- **消融全胜**:完整架构最可信(μ=29.89),依次为去反思(26.88)、去反思+去规划(25.64)、人类众包(22.95)、全去除(21.21)。每去掉一个组件性能都下降;完整架构 vs 此前 SOTA 的 Cohen's d=8.16(八个标准差)。Kruskal-Wallis H(4)=150.29, p<0.001;除"人类众包 vs 全去除"这两个最差条件外,所有两两差异显著(p<0.001)。值得注意:**完整架构甚至胜过人类众包基线**(但作者声明该基线不代表人类最高水平)。
- **涌现行为**:2 天内,知道 Sam 竞选市长的智能体从 1(4%)增到 8(32%),知道 Isabella 情人节派对的从 1(4%)增到 13(52%),全程无用户干预;关系网络密度从 0.167 升到 0.74;派对当天 12 个被邀请者中 5 人到场(未到的有人称"忙于自己的画展"等合理冲突)。声称知情者经核查均非幻觉(453 条关系回答中仅 1.3%/6 条为幻觉)。
- **失败模式**:记忆检索失败(Rajiv 明明听过竞选却说没关注);检索到不完整碎片(Tom 确信要在派对上谈选举,却不确定派对是否存在);**幻觉式添油加醋**(Isabella 编造 Sam"明天要宣布",Yuriko 说邻居 Adam Smith 写了《国富论》);指令微调导致**过于正式、过度配合**(Isabella 对不符自己人设的建议很少拒绝,久而久之兴趣被他人塑造);随地点增多选址变怪(去酒吧吃午饭)、norm 误判(多人进单人浴室、5 点后进已关门的店)。
- 结论:这套"记忆+反思+规划"架构能产出可信的个体与群体行为,可用于设计工具、社会计算、沉浸式环境等。

## 核心贡献
1. 提出"生成式智能体"——随经历与环境动态变化的可信人类行为仿真体。
2. 一套让智能体记忆、检索、反思、与他者互动、在动态环境中规划的新架构,把 LLM 的提示能力扩展到长期连贯与动态记忆管理、递归高层反思。
3. 两个评测(受控+端到端),用消融建立各组件对可信度的**因果**效应,并刻画失败边界(如检索不当)。
4. 系统讨论了机会与伦理/社会风险:防止用户产生**寄生社会关系**(智能体应公开自己是计算实体、价值对齐、不回应"示爱")、用**审计日志**对抗 deepfake/定向劝服、强调智能体应**补充而非替代**设计流程中的真人。

## 局限与我的质疑
**作者自述局限**:
- 成本与速度极高——模拟 25 个智能体 2 天花了"数千美元 token 费、跑了好几天",远非实时;需并行化或专门模型来改进。
- 评测时间尺度短(仅 2 游戏日),人类基线只是"基本胜任"而非黄金标准;未变换底层模型/超参做敏感性分析。
- 鲁棒性未知:可能受 prompt 注入、记忆篡改(用精心设计的对话让它"记得"从未发生的事)、幻觉等攻击;LLM 的偏见与对边缘人群的覆盖不足会被智能体继承。

**我的批判**:
1. **"可信(believable)"≠ 正确,评测指标本身偏软**。因变量只是人类排序出的"可信度",而非行为是否符合事实、是否完成目标。完整架构甚至超过人类众包基线,这恰恰提示评测可能在奖励 LLM 流畅、连贯、礼貌的"文风优势",而非更深的人类性——作者自己也承认指令微调让对话"过于正式/过度配合"。也就是说,部分"可信度"得分可能来自和真实人类行为相反的特征。
2. **消融对比设计偷了懒,夸大了组件因果**。所有消融条件都被喂同一条完整架构走出来的记忆轨迹(作者承认这是"保守估计",因为重新模拟会发散)。但这意味着去规划/去反思条件回答问题时,依赖的是**有规划有反思才产生**的历史事件——组件的真实独立贡献无法干净分离,d=8.16 这种夸张效应量要打折看。
3. **样本与统计的稳健性存疑**。核心数字(信息扩散 4%→32%/52%、网络密度 0.167→0.74、5/12 到场)都来自**单次** 25 智能体、2 天的运行,无重复、无置信区间、无随机种子方差报告。涌现行为可能高度依赖这一次的初始化与随机性,可复现性未验证。受控评测 100 人但性别严重失衡(73 男/25 女)、种族以白人为主,排序任务也易受文风等表面线索带偏。
4. **"涌现"被过度解读**。所谓自发办成派对,起点是用户**人工注入**了"Isabella 想办派对""Maria 暗恋 Klaus"两个种子意图;信息扩散、协同更多是架构按提示链把种子展开,而非真正无中生有的社会动力学。把它说成"社会现象的仿真"在外推到真实社会科学结论时风险很大(作者在伦理节也提醒不可替代真人,但正文叙事仍偏乐观)。
5. **与本研究主题(RL 训练能与环境交互的数字人)相比的根本不足**:本文智能体**不学习、不优化、无身体**。行为全靠冻结 LLM 的提示工程产生,没有奖励信号、没有策略更新、没有从交互中改进(记忆增长≠参数学习);"动作"只是自然语言→emoji→寻路动画的符号落地,完全绕开了物理/运动控制与连续控制问题(作者脚注明确声明这不是真正的 agency,类比迪士尼动画角色)。因此它对"可信社会/认知行为的生成"有启发(给行为合理性、长期记忆建模提供了新视角),但对"用 RL 训练数字人在物理环境中交互"几乎不提供可迁移的训练方法——二者在"是否优化、是否具身、是否处理连续控制"上正交。把它纳入本主题更多是借鉴其**行为合理性/记忆-反思架构**这一侧面,而非控制方法。
