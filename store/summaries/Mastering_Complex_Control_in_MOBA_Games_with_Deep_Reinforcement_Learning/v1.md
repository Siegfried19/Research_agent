# Mastering Complex Control in MOBA Games with Deep Reinforcement Learning
> Deheng Ye, Zhao Liu, Mingfei Sun, Bei Shi, Peilin Zhao, Hao Wu, Hongsheng Yu, Shaojie Yang, Xipeng Wu, Qingwei Guo, Qiaobo Chen, Yinyuting Yin, Hao Zhang, Tengfei Shi, Liang Wang, Qiang Fu, Wei Yang, Lanxiao Huang · 2020 · Proceedings of the AAAI Conference on Artificial Intelligence · 引用 271 · DOI 10.1609/aaai.v34i04.6144

## 一句话
腾讯用一套高扩展、低耦合的分布式深度强化学习系统加上若干算法改进（控制依赖解耦、动作掩码、目标注意力、dual-clip PPO），训练出能在《王者荣耀》1v1 模式中击败顶级职业选手的 AI。

## 解决了什么问题
MOBA 1v1 游戏（如《王者荣耀》）的状态/动作空间比围棋、Atari 大几个数量级（状态约 10^600、动作约 10^18000，而围棋是 10^170 和 10^360），且环境部分可观测、需实时复杂微操、英雄间打法差异巨大、又缺乏高质量人类对局数据（无法用监督学习）。如何在这种复杂控制问题上训出人类水平的策略，是本文要攻克的核心难题。

## 用什么方法解决的
从系统和算法两个层面入手：系统上设计了 RL Learner / AI Server / Dispatch Module / Memory Pool 四模块解耦的可扩展、off-policy 架构，把经验生成与参数学习分离，支持百万 CPU 核、上千 GPU 的大规模并行自对弈；算法上提出 actor-critic 多标签网络，配合控制依赖解耦（把动作各分量独立化形成 multi-label PPO 目标）、动作掩码（用游戏知识剪枝非法探索）、目标注意力（做攻击目标选择）、LSTM（学技能连招）以及 dual-clip PPO（保证大偏差 off-policy 批次下的收敛）。

## 动机 & 背景
深度强化学习已在 Atari、围棋、象棋/将棋等 1v1 对抗环境取得人类乃至超人水平，但这些环境相对简单。MOBA 1v1 属于实时策略（RTS）游戏，被视为 AI 研究的重大挑战，其复杂性来自三方面：(1) 巨大的状态/动作空间；(2) 玩法机制——部分可观测下需要规划、进攻、防守、连招、诱导、欺骗，且场上还有小兵、防御塔等大量单位，目标选择困难；(3) 不同英雄打法完全不同（"换个英雄等于换个游戏"），需要鲁棒统一的建模，且缺乏高质量 1v1 人类数据。作者聚焦 1v1 而非 5v5，因为 5v5 更强调团队协作策略，而 1v1 更纯粹地考验单个 agent 的复杂动作控制（微操）。

## 方法细节
**系统设计（四模块，低耦合高扩展）**
- **AI Server**：负责 AI 模型与游戏环境交互，用镜像策略自对弈生成对局，基于 Boltzmann 探索（softmax 采样）预测动作。每个 AI Server 绑定一个 CPU 核，推理也放在 CPU 上以省 IO，并自研 CPU 版快速推理库 FeatherCNN（可自动转换 TensorFlow/Caffe 模型）。
- **Dispatch Module**：收集 AI Server 产生的样本（reward、feature、动作概率等），压缩打包后发往 Memory Pool。
- **Memory Pool**：内存高效的环形队列，支持变长样本、按生成时间采样。
- **RL Learner**：分布式训练环境，多个 Learner 并行从对应 Memory Pool 取数据，用 ring allreduce 平均梯度；用共享内存而非 socket 与 Memory Pool 通信（提速 2-3 倍），训练后的模型 P2P 同步到 AI Server。与 IMPALA 的不同在于：IMPALA 把参数分布在 learner 上、actor 并行从所有 learner 取参；本文从 master Learner P2P 同步。

**算法设计（actor-critic 网络 + 多项改进）**
- **多模态编码**：图像特征 fi（卷积）、向量特征 fu（FC）、游戏状态 fg（FC）分别编码；fu 编码拆成单位表示和目标注意力的 key；同类单位用 max-pooling 映射到定长向量以应对数量可变；拼接后经 LSTM 得 hLSTM，再接 FC 预测动作。
- **目标注意力**：把 hLSTM 的 FC 输出当 query、所有单位编码堆叠当 keys，softmax 算出对各单位的注意力分布 p(t|a) 来选攻击目标。
- **控制依赖解耦**：一个动作含多个标签（按钮、Move X/Y、Offset X/Y、目标单位），它们之间相关性难显式建模，于是把每个标签独立处理，形成 multi-label PPO 目标（公式3）。好处：简化策略结构、增加动作多样性（各分量独立 value 输出）从而促进探索。还在开局随机化双方位置以强制探索多样性。
- **动作掩码（action mask）**：用资深玩家先验知识剪枝非法/不合理探索——地图障碍方向、冷却中的技能/不可用攻击、被敌方控制/装备效果限制、英雄/道具特定限制。
- **dual-clip PPO**：标准 PPO 的比率 rt(θ) 在大规模 off-policy 下（轨迹来自多种旧策略）可能极大，当 Ât<0 时 rt(θ)Ât 会引入巨大无界方差导致难收敛。dual-clip 在 Ât<0 时额外用常数 c（c>1，取3）给 rt(θ)Ât 设下界（公式5）。

**奖励设计**：零和（自己减对手），含 hp/塔血/金钱/蓝量/死亡/击杀/经验/补刀等稠密+稀疏奖励混合，灵感来自 OpenAI Five 的 Dota 奖励。

## 数据集 & 实验设置
- 测试平台：《王者荣耀》1v1 模式（镜像对局，双方同英雄）。打全场（直到摧毁基地），zero-start（从第0帧开始）。
- 算力：总计 60 万 CPU 核（Docker 封装）+ 1064 张 Nvidia GPU（P40 与 V100 混合）。单英雄训练用 48 张 P40 + 18000 CPU 核；每 GPU minibatch=4096；LSTM 时间步16、单元1024；每 GPU 每秒约 80000 样本；每英雄每天采集约相当于 500 年人类 1v1 数据。
- 超参：Adam，初始学习率 0.0001；dual-clip 的 ε=0.2、c=3；折扣因子 0.997（半衰期约46秒）；GAE λ=0.95；FP16 传输、FP32 训练。
- 评测：部署进游戏每 133ms 预测一次动作（约顶级业余玩家反应速度）；对手包括行为树（游戏内置AI）、MCTS 及其变体；用 Elo 评级比较不同版本。

## 主要结果 & 结论
- **对顶级职业选手**：邀请5名各自专精英雄的 KPL 职业选手打 BO5，AI 在 Mage/Marksman/Warrior/Assassin/Warrior+Mage 各类型英雄上均获胜（如貂蝉 3:0 击败联盟最佳法师 eStarPro.Cat，场均5杀仅被杀1.33次）；金钱、经验也全面领先。
- **鲁棒性（公开赛）**：2019 ChinaJoy 上海公开赛，限 top 1% 排名玩家参赛、赢 AI 奖手机。8个英雄共 2100 场，AI 胜率 99.81%，仅输4场，5个英雄百场全胜。
- **对比基线**：在与 Jiang et al. 2018 的 MCTS 系列（FBTS/NR/DPI/AVI）和内置AI相同设置下（比谁更快击败同一基线对手），本文方法显著更快。
- **训练进程**：以"狄仁杰"为例，约6小时即100%胜内置行为树AI，约30小时达王者（top 1%）水平，约70小时可比肩职业，约80小时 Elo 趋稳。
- **消融**：action mask 大幅缩短训练时间（同等能力下，胜率50.5%）；target attention（75%）和 LSTM（73%）均提升能力；full rollout 相比 partial rollout 把胜率提到70%~80%；random initial frame 比 zero-start 收敛快15%但能力略降（胜率40%）。
- 结论：从系统+算法两面解决 MOBA 1v1 复杂控制，AI 能击败顶级职业选手；并承诺开源框架、算法及游戏核心、提供部分算力供公开使用。

## 核心贡献
1. 首次对 MOBA 1v1 复杂动作控制（电竞微操）做系统化、彻底的研究，系统层面给出可扩展、off-policy 的 DRL 框架。
2. 算法层面提出 actor-critic 多标签网络，集成控制依赖解耦、目标注意力、动作掩码、LSTM 连招，以及保证收敛的 dual-clip PPO。
3. 大量实验证明在《王者荣耀》多类型英雄上均能击败顶级职业玩家，并展示了训练曲线、消融与基线对比。

## 局限与我的质疑
1. **作者自述局限有限**：文中几乎没有专门的"局限"小节，对失败案例（如公开赛输掉的4场、对职业选手输掉的1局）只字未深究是什么策略/英雄克制导致，缺乏对 AI 弱点的剖析，给人"全面碾压"的过度乐观印象。
2. **算力门槛极端、可复现性差**：60万 CPU 核 + 1064 GPU、单英雄每天 500 年人类数据，这种规模几乎只有腾讯能复现。论文也未做"算力—能力"的边际分析（少10倍资源还能不能赢？），dual-clip/action mask 等"算法贡献"的实际增益与暴力算力的贡献无法清晰区分。消融虽测了组件，但都在同等（巨量）资源下，没回答"资源受限时哪些技巧才是关键"。
3. **评测设计偏向 AI**：133ms 反应、零失误、不知疲劳是机器固有优势；1v1 镜像赛本就放大微操（机器强项）而弱化人类的宏观策略、心理博弈。把"击败职业选手"解读为"掌握复杂控制"有过度解读之嫌——更像证明了反应速度+精确执行而非高层策略智能。样本上职业对局仅 BO5、且选手打自己专精英雄但未必练过对抗 AI，存在适应性偏差。
4. **与"RL 训练数字人与环境交互"主题的差距**：本文的 agent 是游戏内抽象单位，动作空间是离散化的游戏按钮（move/skill/target），并非物理意义上的具身数字人（无连续关节控制、无真实物理/感知）。其价值对本主题主要在**工具箱层面**——dual-clip PPO（off-policy 大批次稳定性）、action mask（用先验剪枝非法动作空间）、目标注意力（多目标选择）、控制依赖解耦（多标签动作），这些训练稳定性与动作建模技巧可迁移；但其"与环境交互"是规则化游戏环境，不涉及人机交互、社会性或拟人行为，对数字人"像人一样交互"这一核心诉求贡献甚微。
5. **dual-clip PPO 的理论论证较弱**：仅从"Ât<0 时比率过大引入大方差"的直觉出发加一个下界裁剪 c=3，没有给出收敛性证明或对 c 取值的敏感性分析，更像工程经验性 trick 而非有理论保证的算法改进。
