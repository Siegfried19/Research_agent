# InterReal: A Unified Physics-Based Imitation Framework for Learning Human-Object Interaction Skills
> D. Liang, Yuhang Lin, Xinzhe Liu, Jiyuan Shi, Yunlong Liu, Chenjia Bai · 2026 ·  · 引用 2 · DOI arxiv:2603.07516

## 一句话
一个统一的、物理约束下的模仿学习框架,让真实人形机器人(Unitree G1)通过跟踪人-物交互(HOI)参考动作,学会搬箱、推箱等精细全身交互技能,并能真机部署。

## 解决了什么问题
现有人形机器人全身控制大多是**非交互式**的(走、跳、跳舞),无法精准完成人-物交互任务;而动画领域的 HOI 方法(InterMimic、CooHOI)用的是理想化的"动画级物理",忽略真实接触力学,难以直接迁移真机;遥操作方案(CLONE/TWIST/OpenWBT)虽能即时产生交互行为,但稳定性、控制精度差,且不考虑手-物接触。作者要在真机上做出**精确、闭环、带反馈**的 HOI 策略,主要攻克两个难点:① 真机部署时人/物轨迹的传感扰动(尤其二者**相对位置**扰动)会把策略推出分布甚至崩溃;② HOI 任务奖励项规模大、目的异质,手工调权重既繁琐又次优。

## 用什么方法解决的
两个核心组件:
- **带手-物接触约束的 HOI 动作数据增强**:沿原始动作物体的 XY 轴注入位置偏移 ∆pxy,在骨盆坐标系下用逆运动学(IK,Ipopt 非线性优化器)反解手臂关节角,**保持手-物接触细节与锚定动作一致**,生成对应同一任务但物体位置不同的多条动作。用这些增强动作做"单任务多动作"训练,提升对物体扰动的鲁棒性。
- **自动奖励学习器(双层 meta-DRL)**:洞察是"模仿类 DRL 的终极目标其实就是最小化几个关键位置跟踪误差"。内层用 PPO 学具体 HOI 策略;外层用 SAC 训一个 meta-policy,根据关节/物体/连杆位置跟踪误差在一个时间窗内的**变化量**(Gt = ∆(ejp+eop+elp)/∆t)作为奖励信号,动态分配内层大规模奖励项的权重 Θ,使奖励随任务相位自适应(如搬箱早期偏重平衡)。外层每 N 个 PPO epoch 才训一次,开销很小。
- 另含:沿用 InterMimic 的**交互图(interaction graph)跟踪奖励**鼓励精确接触;**非对称 actor-critic**——critic 看完整特权状态(含交互图、物体速度/旋转),actor 只看不含交互图、仅含 FoundationPose 检测出的物体位置的"不完美状态",以缩小 sim-to-real gap。
- 流程:SMPL mocap → 重定向到 G1 → InterMimic 在 IsaacGym 做物理校验 → 数据增强 → 多动作训练 → MuJoCo sim-to-sim → 真机 G1(用 FoundationPose 做 6D 物体位姿估计提供观测)。

## 动机 & 背景
DRL + 动作模仿已让人形机器人做出走、跳、跳舞等高动态全身技能,但缺乏交互能力,无法完成工业等真实场景的复杂 HOI 任务。动画界(InterMimic、CooHOI、TokenHSI、RMD)能让虚拟角色完成丰富 HOI,但物理是理想化的(只引入小质量、摩擦等动画级设定),难迁真机。机器人界则要么靠上半身遥操作(限制自主性),要么靠通用全身遥操作控制器(稳定性/精度不足、不管手-物接触)。作者主张提供一个**统一 HOI 训练框架**,同时跟踪人-物运动轨迹并把两者观测都纳入 DRL 训练,实现精确平滑的闭环交互。

## 方法细节
- **问题建模**:HOI 任务建为 MDP (S, A, P, ft, γ),动作空间 A∈R²³(机器人 DoF),PPO 优化。状态 st = [本体感知 sht, 物体特征 sot, 交互特征 sint_t, 任务相位 p]。本体含关节位/速、root 角速度、重力投影、上一动作;物体含全局位/速/朝向;交互含接触布尔量 + 交互图。
- **动作增强(IV-B)**:在世界系给物体和左右腕末端加偏移 ∆pjxy,经躯干、骨盆坐标变换后,在骨盆系用 Ipopt 解新手臂关节角;偏移取 ∆x,∆y∈linspace(−ϵ,ϵ,∛c3),生成 c3 条增强动作。
- **内层 PPO(IV-C)**:加权奖励 ft(Θ)=Σθk·rk(t),子奖励为机器人-物体状态与参考的差及力矩/质心投影惩罚。引入交互图跟踪奖励 rtig=exp(−θig·eig);非对称 actor-critic(critic 看 perfect state,actor 看 imperfect state)。
- **外层自动奖励学习(IV-D)**:每 N 个内层 PPO epoch 定义为一个潜在子任务 Ti,共享奖励函数 ft(Θ)。SAC 优化 meta-policy Uψ,以内层 PPO 训练作为环境,观测内层 MDP 抽象特征(连杆/物体位置、学习进度、PPO 奖励与动作),输出权重动作 Θt。权重更新 Θ′=Θ0·σ(t)·µmeta(Θt|ut),σ(t)=clip(1−c4/t, δ, 1);奖励 Gt 为跟踪误差变化量;熵温度 α=0.1。
- **部署**:MuJoCo sim-to-sim 验证稳定性与对不同物体偏置的泛化,再以相同配置上真机 G1,FoundationPose 提供物体位姿。

## 数据集 & 实验设置
- **任务**:Box-picking(取自作者自有 mocap 数据集)、Box-pushing(取自 Omomo 数据集)。
- **基线**:ASAP*(在 ASAP 基础上加物体跟踪)、InterMimic*(保留原框架但对齐 DR/噪声/超参)。二者均与 InterReal 对齐 domain randomization、噪声、关键超参以求公平。
- **指标**:Empjpe(关节位置误差,rad)、Emllpe/Emulpe(下/上连杆位置误差,m)、Em3lpe(三关键连杆)、Emope(物体位置)、Emorae(物体旋转角)、Emige(交互图误差)、Emlrae(连杆旋转角);及任务成功率(每任务 100 次重复,成功=完成整个 HOI 任务不摔倒)。跟踪误差为最佳模型 20 次评估均值。训练 5e4 PPO epoch,统一 DR。
- **消融**:自动奖励组件(可视作从 InterReal 依次剥离自动奖励→InterMimic*、再剥离交互图→ASAP*);meta-learning 内部系数 δ∈{0.0,0.1,0.25,0.50}。

## 主要结果 & 结论
- **跟踪精度(Table I)**:InterReal 在两任务大多数指标上误差最低。Box-picking 上 Empjpe 0.1076(vs ASAP* 0.1634、InterMimic* 0.1984)、Emlrae 0.2893(vs ~0.49)。Box-pushing 上多项指标(Emope 0.0010、Emorae 0.0007、Emige 6.04)均最优。
- **成功率(Table II)**:Box-picking 96.41%(ASAP* 77.38%、InterMimic* 84.72%);Box-pushing 87.45%(ASAP* 70.63%、InterMimic* 79.10%)。推箱比取箱更难。
- **消融**:δ=0.1 跟踪性能最佳,两端退化,δ=0.0(无自动奖励)最差;固定/手工奖励权重难达最优。ASAP* 因缺交互图特征与奖励,物体误差最差。
- **真机(Fig.1)**:G1 完成感知箱姿同时取-走-放高密度箱、以及略弯腰持续推箱;训练阶段模拟了物体位置丢失、延迟、扰动,配合多动作增强,可根据不同初始物体位置和 FoundationPose 检测结果实时调整手臂行为。
- **结论**:动作增强 + 自动奖励有效提升交互泛化与策略学习效率;相比有交互潜力的遥操作控制器,InterReal 能感知物体状态,实现更精确平滑的交互,有望推动人形机器人在复杂交互场景落地。

## 核心贡献
1. **统一的物理约束 HOI 模仿框架 InterReal**,把动画领域的 HOI DRL 学习器扩展到真实人形机器人,支持真机部署与交互反馈,而非仅非交互全身控制或遥操作。
2. **带手-物接触约束的动作增强**:用 IK 在改变物体位置的同时保持接触细节一致,显著提升交互策略对物体扰动的泛化。
3. **自动奖励学习器(双层 meta-DRL)**:以关键跟踪误差变化量为 meta-policy 奖励,自动、随相位地分配大规模奖励权重,免去繁琐手工调参且效果更优。
4. 在 box-picking/box-pushing 上跟踪误差与成功率均超 ASAP*/InterMimic*,并在 Unitree G1 真机验证。

## 局限与我的质疑
1. **作者自述**:仍难克服**物体位置扰动**问题,根源是"被动物体跟踪"训练模式 + 真机物体检测的高方差与延迟;留待未来工作。这其实击中了交互任务最关键的闭环反馈环节——目前更像"开环跟参考 + 被动观测",而非真正力/接触反馈驱动的交互。
2. **任务与数据极其单一**:只在"箱子"取/推两类任务、各一条锚定动作上验证。所谓"多动作训练"只是对**同一条**动作做 XY 平移增强,并非不同动作/不同物体/不同抓握方式的多样性。框架自称"unified/universal",但泛化证据严重不足——换形状、换重量分布、换交互模式(倒、塞、旋拧)是否成立完全未知。
3. **基线偏弱、对比不充分**:对比对象是作者自己改造的 ASAP*、InterMimic*,且承认"很少有支持真机的开源 HOI 基线"。没有与真正的全身遥操作控制器(CLONE/TWIST/OpenWBT,它们正是引言里被批评的对象)做定量交互对比;"我们更精确平滑"主要靠 sim 内跟踪误差和成功率说话,缺乏对遥操作方案的真机正面较量。
4. **成功率定义偏宽松**:成功仅定义为"完成整个 HOI 任务且不摔倒",且在 **MuJoCo** 里统计(非真机大样本)。真机只展示了 Fig.1 的若干 live photo,没有真机成功率/重复次数/失败模式统计,sim-to-real 的"鲁棒性"论断证据薄弱。
5. **方法可复现性存疑**:关键的"HOI 动作重定向"明确写着"This particular work will be published later";物理校验、增强、奖励项细节大量推给 Appendix。自动奖励的 meta-policy 是否真"学到"了语义,Fig.5 的权重曲线只是定性展示,缺乏与"随机/退火权重"等更强基线的对照,δ=0.1 最优也可能只是单任务上的超参过拟合。
6. **与"RL 训练数字人与环境交互"主题的差距**:它是把动画 HOI 落到真机,方向高度契合;但"交互"目前局限于**刚体箱子的搬运/推动**,既无可变形物体、也无多物体/工具使用、更无与人或动态环境的交互;且物体仅作被动跟踪对象,机器人并未学习物体动力学(不像 CooHOI 显式建模被操控物体动力学)。作为"可与环境交互的数字人"的样本,其交互维度仍偏窄、偏被动。
