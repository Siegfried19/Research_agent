# Safe reinforcement learning: A control barrier function optimization approach
> Zahra Marvi, Bahare Kiumarsi · 2020 · International Journal of Robust and Nonlinear Control · 引用 229 · DOI 10.1002/rnc.5132

## 一句话
把控制屏障函数(CBF)作为一项加进 RL 的代价函数里,用 off-policy 强化学习在不需要完整动力学模型的情况下,学出一个"既不撞安全边界又最优"的控制策略,并给出安全/稳定/最优三重理论保证。

## 解决了什么问题
安全关键系统(如自动驾驶)既要满足硬性安全约束、又要最小化性能代价,而二者常有冲突;传统 CBF 方法需要系统动力学知识、只把安全当约束而非目标,且只在约束被违反时才介入(短视、被动)。作者要解决的是:**在模型不完整的数据驱动条件下,同时规划安全与最优,且让对最优控制器的介入最小化**——"This article presents a learning-based barrier certified method to learn safe optimal controllers that guarantee operation of safety-critical systems within their safe regions while providing an optimal performance."(p.1 Summary)

## 用什么方法解决的
- 把 CBF 项 B_γ(x) 加进代价被积函数(增广代价,公式9),"The cost function that encodes the designer's objectives is augmented with a control barrier function (CBF) to ensure safety and optimality."(p.1)
- 在 CBF 里引入阻尼系数 γ 调节安全与最优的相对权重:"A damping coefficient is incorporated into the CBF which specifies the trade-off between safety and optimality."(p.1)
- 用 off-policy RL + actor-critic 神经网络,无需完整动力学即可求解:"An off-policy reinforcement learning (RL) algorithm is then employed to find a safe optimal policy without requiring the complete knowledge about the system dynamics, while satisfies the safety constraints."(p.1)

## 动机 & 背景
论文针对非线性控制仿射系统 ẋ = f(x) + g(x)u(p.1925 公式1,f 为漂移动力学、g 为输入动力学,f(0)=0)。安全集定义为状态满足不等式约束的区域:"where h(x) is a continuously differentiable function of x. Note that h(x) > 0 represents the admissible state space that respects safety constraints."(p.1926 公式4),即 C = {x | h(x) ≥ 0}。原始最优控制目标用二次型效用 r(x,u)=Q(x)+uᵀRu("where Q(x) is a positive-definite function and R is a symmetric positive-definite matrix",p.1926 公式3)。

作者指出传统 CBF 方法(把 CBF 作为不等式约束、需检查其导数条件、需要动力学信息)虽优雅但不顾及最优性、且难与 RJ 框架结合;MPC 类方法又是短视的、依赖模型。本文据此给出三点区别于已有工作的贡献:
1. "It addresses possible conflict between safety and performance and the safe set does not necessarily contain the origin."(p.1925 §1)——处理安全与性能的冲突,且安全集不必含原点。
2. "Off-policy RL is employed which allows to learn about an optimal safe policy that minimizes the augmented cost while applying a safe and possibly conservative policy to collect data during learning."(p.1925)——用 off-policy 把"学习的目标策略"与"采集数据的行为策略"分开:"This is because off-policy RL separates the target policy (policy we learn about) from the behavior policy (policy we apply to the system to collect data)."(p.1925)
3. "To provide an optimal performance, instead of using a zeroing factor, a function is considered as a CBF that rapidly damps to zero within a specific distance to the safety boundary; this facilitates taking safety as a control objective not only as a constraint."(p.1925)——用一个在距边界一定距离内迅速衰减到零的函数当 CBF,把安全变成"控制目标"而非单纯约束,实现前瞻式、主动的安全规划。

## 方法细节
**增广代价(核心)**:"the cost-to-go function is augmented with a CBF term"(p.1927 公式9),即
J(x,u) = ∫(Q(x) + uᵀR(x)u + B_γ(x)) dτ。
其中 B_γ(x) 须满足三条性质——在安全集内为正、在边界上趋于无穷、在安全集内单调递减("B in (9) is a function with the following properties,",p.1927 Assumption 1)。

**具体 CBF 候选**:B_γ(x) = −log( γh(x) / (γh(x)+1) )(p.1927 公式10),"The parameter γ determines how rapidly B"(γ 决定其远离安全边界时衰减多快)。增广效用相应定义为 r_a(x,u)=Q(x)+uᵀRu+B_γ(x)("the augmented utility function and the augmented value function are defined,",p.1927 公式11)。

**与传统 CBF 的关键差异**:"the new formulation does not impose any conditions on the derivative of"(p.1928 Remark 3)——因为 B_γ 进了代价函数,在边界附近会成为主导项,最优控制器自动沿其下降方向作用,使 Ḃ_γ 隐式地在边界附近变负,从而无需像传统 CBF 那样显式施加导数不等式约束(也就免去了对动力学信息的需求)。

**最优控制律**:最小化哈密顿量得到 u_j* = −0.5 R⁻¹ gᵀ(x) ∇W_j("is obtained by the control input",p.1929 公式16)。

**off-policy 改写**:把动力学拆成行为策略 + 目标策略两部分,"is the target policy which is updated in the algorithm but not applied to the system; while"(p.1933 公式32)——目标策略只更新不施加,行为策略(安全、可能保守)施加到系统产生数据。目标策略更新律 u^{i+1} = −0.5 R⁻¹ gᵀ J_x^i("The control input u is updated by optimizing over the Hamiltonian function",p.1933 公式34)。

**NN 近似**:"the solution to the off-policy RL algorithm is learned using an actor-critic structure which does not require knowledge of the system dynamics."(p.1934 公式36/37)——critic 估值函数 J^i、actor 表示控制 u^{i+1};权重用最小二乘解,"Equation (43) has a solution if"(p.1935 公式43/44)给出有解条件 N > l₁ + m·l₂(采样点数须超过基函数个数)。Remark 12 强调训练采样要兼顾安全区与边界区:"for having a reliable training, one needs to collect samples from both the safe region and the region in vicinity of the safety boundary in which the CBF comes to play."(p.1935)

## 数据集 & 实验设置
非仿生数据集,纯数值仿真。用例为自动驾驶**车道保持(lane keeping)**问题:"The efficiency of the proposed method is examined in lane keeping problem for an autonomous vehicle."(p.1936 §5),目标是车在弯道上保持居中,同时满足"最大允许横向位移"的安全目标,采用线性轮胎力模型与恒定纵向速度。状态为 [横向位移 y、其速度 v、误差偏航角 φ、偏航角速度 ψ̇]。

仿真参数(表1,p.1936):车质量 M=1650 Kg、转动惯量 I_z=2315.3 m²·Kg、纵向速度 v0=27.7 m/s、前轮刚度 C_f=133000 N/rad、后轮刚度 C_r=98800 N/rad、最大/最小允许横向位移 0.45 / −0.45 m、阻尼系数 γ1,γ2 = 0.95, 2("Simulation parameters",p.1936 TABLE 1)。

## 主要结果 & 结论
**理论结果(论文真正证明的部分)**:
- 定理1(安全):序贯改进控制输入(16)后,"stay within the safe set and safety of the system is ensured for all t > 0."(p.1931)——状态保持在安全集内,对所有 t>0 安全。
- 定理2(稳定):由优化哈密顿量得到的控制序列"uniformly stabilize the system within the safe region D."(p.1932)——在安全域 D 内一致镇定。
- 定理3(最优):在安全域内适当选 γ,"the minimum can get arbitrarily close to zero"(p.1932),即 lim_{γh(x)→∞} r_a(u*)=0,说明在安全与性能不冲突时不牺牲最优性。安全域由 B_γ(x)/(B_γ(x)+Q(x)) ≤ 0.5 界定,使"within the safe region, Q(x) is the dominant term in the optimization problem."(p.1931)。
- 定理4(收敛):"Algorithm 1 converges to a safe optimal solution."(p.1935)。
- γ 的直觉:"for example, for h(x) = 1 and γ = 5, B"(=0.08,p.1932 Remark 8)——γ 越大 CBF 衰减越快、越保留原始性能,γ 越小越保守。

**仿真结果(观测级,单一用例)**:经过六次迭代学习完成("After six iterations, the learning process is completed.",p.1937);学习后"the states of the system have stayed within the safe region and have not exceeded the limits."(p.1937 图1,与无 CBF 情形对比,无 CBF 的横向位移会冲出 y_min);系统以 γ1=0.95、γ2=2"the states of the system have reached the origin with"(p.1933 Remark 10);其余状态见图2,"Trajectories of other states of the system are given in Figure 2, which are converged to the origin."(p.1937)。

## 核心贡献
1. **CBF×RL 的统一**:把 CBF 嵌进代价函数而非作为不等式约束,使安全成为可优化的控制目标,既前瞻规划安全又最小化对最优控制器的介入。
2. **数据驱动安全最优**:off-policy RL + actor-critic,行为策略保守采数据、目标策略学最优,**学习过程不需要完整系统动力学**;并证明 off-policy Bellman 方程(35)与原 Bellman 方程(30)等价、共享同一更新律(Lemma 4)。
3. **理论完备**:给出安全(定理1)、一致稳定(定理2)、安全域内最优性(定理3)、算法收敛(定理4)的成套证明,且安全集不必包含原点。

## 局限与我的质疑
1. **实验极其单薄(我的质疑,最关键)**:全文只有一个车道保持仿真用例,且系统状态模型是**线性**的(表1 与状态方程都是线性时不变 + 恒定纵向速度),而方法论上号称针对一般非线性系统 ẋ=f(x)+g(x)u。结论"stayed within the safe region and have not exceeded the limits"(p.1937)只能算 observed 级——在单一线性化场景、单组 γ 下成立,**不能外推为"对一般非线性安全关键系统普遍有效"**。没有与强基线(如 CBF-QP、reachability、安全 MPC、其他 safe RL)的定量对比,只对比了"有/无 CBF"自身两种情形。
2. **"不需要动力学"有保留(作者自述+我的补充)**:虽然学习目标策略不需要 f、g,但行为策略仍需"any available prior knowledge about the system dynamics can be used to find a safe but possibly conservative behavior policy"——即**必须先有一个安全(保守)的初始策略**才能保证学习期间安全(Assumption 3、Remark 13 也假设了可行控制输入存在)。这对很多真实系统并非平凡前提,论文未讨论行为策略本身从何而来、若初始策略不安全会怎样。
3. **理论保证的前提偏强**:定理依赖初始状态严格在安全集内部(Assumption 2)、可行安全输入集非空(Assumption 3)、值函数存在且 Lipschitz 等标准但理想化假设;最优性(定理3)只在"安全与性能无冲突的安全域 D"内成立——而论文的卖点恰恰是处理二者冲突的边界区,**在冲突区只保证安全、不保证最优**,这点容易被读者过度解读。此外定理2/4 是连续时间 + 精确 NN 近似下的论证,NN 近似误差、最小二乘样本充分性(N>l₁+m·l₂)在有限样本/逼近误差下的鲁棒性未做实验或理论刻画。
4. **与本研究主题的契合度与不足**:正面看,它正是"把 CBF 嵌入代价函数 + off-policy RL 求安全最优策略"的代表作,机制清晰、理论扎实;但对实际部署关心的样本效率、采样如何覆盖边界区(Remark 12 只定性提到)、γ 如何系统化选取(论文靠手调 0.95/2)、对扰动/模型失配的鲁棒性,均未给出可复用的工程指引。想复用者需注意:CBF 形式 B_γ=−log(γh/(γh+1))、阻尼条件 B_γ/(B_γ+Q)≤0.5、有解条件 N>l₁+ml₂、actor/critic 基函数(论文用了 x_i² 及交叉项等多项式基)是关键可操作细节,但仅在该线性车道保持例中验证过。
