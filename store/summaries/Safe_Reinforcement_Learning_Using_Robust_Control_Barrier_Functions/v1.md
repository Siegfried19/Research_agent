# Safe Reinforcement Learning Using Robust Control Barrier Functions
> Yousef Emam, Gennaro Notomista, Paul Glotfelter, Zsolt Kira, Magnus Egerstedt · 2022 · IEEE Robotics and Automation Letters · 引用 52 · DOI 10.1109/lra.2022.3216996

## 一句话
把"鲁棒控制屏障函数(RCBF)"做成一个**可微的二次规划安全层**塞进基于模型的 RL(SAC)里,让智能体在训练全程不越界的同时还能被安全层有效引导探索,并支持把奖励任务和安全约束**解耦**以便零样本迁移。

## 解决了什么问题
RL 在安全攸关系统上不好用——训练需要大量探索,而探索会撞进不安全状态。现有"加安全层把动作投影到安全集"的做法有个核心难题:**安全层对动作的修改没有被 RL 算法显式感知**(相当于把安全层当成了未知的转移动态),在智能体为躲避违规而剧烈动作时会拖累学习;同时既有 CBF 方法要么不可扩展(Lyapunov 离散化、每步约束数=状态数),要么受限(离散时间 CBF 只能实时求解仿射形式、只能编码多面体障碍),要么要靠一个监督网络(compensator)去近似 CBF 行为而引入近似误差。

## 用什么方法解决的
1. **可微 RCBF 安全层**:用 RCBF(对含扰动的微分包含系统给出前向不变性保证)构造一个最小侵入的 QP,把 RL 动作 uRL 改成安全动作 u* = uS + uRL;借助可微优化(OptNet / 可微凸优化层,通过 KKT 条件反传梯度),让 SAC 的 Q-loss 和策略 loss **直接对安全动作求导并端到端反传过 QP**,从而显式把安全层的影响纳入训练。
2. **扰动估计**:用高斯过程(每维一个 GP)在线学习未知扰动 d,把均值±k_c·标准差作为扰动集 D 喂给 RCBF(k_c=2 给 95.5% 置信)。
3. **基于模型提升样本效率**:已知奖励/安全约束时,用学到的动态做短时域 rollout 生成合成数据塞进 replay buffer(短时域是因模型误差随步数累积)。
4. **模块化任务学习(Modular SAC-RCBF)**:在 Bellman 更新里只把**cost-to-go 项**的安全补偿 uS_{t+1} 置零(当前步 uS_t 保留),让价值函数学成"仿佛没有障碍"的奖励任务本身,从而独立于训练时的具体安全约束,利于零样本迁移到不同约束的环境;且不改变实际执行动作,因此训练安全性不受影响。

## 动机 & 背景
安全 RL 分两类:只保证训练**结束时**策略安全,和保证**训练过程中**安全探索——本文属后者。安全训练天然含两部分:保证安全的约束分量,和要优化的性能(奖励)分量。作者重点对标 Cheng et al. (AAAI 2019, 文献[9]) 的离散 CBF + GP + compensator 方案,指出其三大缺陷:(a) 离散时间 CBF 只对仿射函数能实时 QP 求解,表达受限;(b) 用监督网络近似 CBF 本质是近似,不准会反噬;(c) 安全层/补偿的修改未进 RL 的 loss。作者用连续时间 RCBF + 可微 QP 一举绕开这三点。另一动机是:**训练与测试时的安全约束常常不同**(无人机要离操作员一定距离、持久任务的充电约束、多智能体训练时的互撞约束),所以需要让最终价值函数独立于一部分训练约束。

## 方法细节
- **RCBF(定理1,来自[18])**:对微分包含 ẋ ∈ f+gu+D(x),若 D 是一组点 Ψ 的凸包,则条件 Lf h + Lg h·u ≥ −γ(h) − min ∇h^T Ψ 成立即为有效 RCBF,保证扰动系统**所有轨迹**的前向不变性;可扩展到凸包的有限并以处理非凸扰动。优点:非仿射也能实时合成、能编码一大类扰动。
- **安全层 QP(式8)**:min ‖u‖² + l·s²(s 为松弛变量保证可行,l 大以最小化违规),约束为各 RCBF 的屏障证书;可模块化加入执行器限制约束。最终动作 u* = uS + uRL(式9)。
- **可微化**:训练时算 loss 要解一批 QP(增加训练计算量),但推理时每步仍只解一个 QP,**推理时间不变**。
- **连续/离散衔接**:RCBF 是连续时间的;若 Δt 足够小,按所需频率查询策略+解 QP 即全程安全;Δt 大则对 RL 动作做零阶保持、再以必要频率解 QP(细节留待未来)。
- **相对度处理**:Car Following 中 h 相对度为 2、PVTOL 中障碍 h 相对度为 3,用级联 RCBF(cascaded,h* = ḣ + γ₁h)处理(声明理论细节将来再给,此处无证明直接用结果)。
- 也讨论了为何用 RL 而非 MPC:MPC 一般只在凸优化时能实时求解;RL 测试期高效、且训练末得到的价值函数可当 CLF/CBF 复用。

## 数据集 & 实验设置
全为自建仿真环境(因 Safety Gym 不显式暴露 f、g,无法构造 RCBF 约束)。两组实验:
- **样本效率**:对比 MB / MF 版 SAC-RCBF 与两个基线(基线1=model-free SAC+不可微 RCBF-QP;基线2=再加 [9] 的 compensator 神经网络)。指标=每回合累计奖励 vs 训练回合数,各曲线为 10 个随机种子均值、阴影为 ±2 标准差。
  - **Unicycle 环境**:独轮车避障到点,扰动 ud 模拟斜坡,GP 学扰动,障碍用 RCBF h=‖p−p_o‖²−δ²。
  - **Car Following 环境**(基于[9]):5 车成链、各为含扰动双积分器,智能体只控第 4 车加速度,奖励 r=−‖u‖²(最小化控制力)+ 避撞;两个相对度2的 RCBF 用级联式。
- **模块化/零样本迁移**:在 Unicycle 和 PVTOL(2D 四旋翼,改造模型直接控角速度 ω 和推力导数 uf;还要在训练时离安全飞行员一定距离 hh=δ²−(x1−xh)²)上各迁移到 **200 个**不同障碍配置(形状/大小/位置/操作员约束不同)的环境,比较平均回合奖励、标准差、完成率。上界=用无障碍无安全层的纯 SAC 训练。

## 主要结果 & 结论
- **零安全违规**:全部实验训练过程中**没有发生任何安全违规**,验证 RCBF-QP 有效保证安全。
- **样本效率**:Unicycle 中所有方法都收敛,MB SAC-RCBF 最优(合成数据有用);但 MF SAC-RCBF 仅略胜基线——因圆形障碍使安全层行为平滑,不显式建模也学得动。Car Following 中 MB/MF SAC-RCBF **都显著优于基线**,因为安全层会让第4车急加/急减、强烈影响动态与奖励,不显式建模就像动态里有突变难学;基线(无 compensator)在多次试验中根本学不出有意义策略。
- **模块化迁移**:可视化价值函数显示 SAC-RCBF 在障碍周围被赋予不该有的低值,而 Modular SAC-RCBF 学到的价值函数几乎与"无障碍 SAC"一致。
  - Unicycle 200 环境完成率:SAC 无障碍上界 81% / Modular SAC-RCBF **63%** / 基线 21% / SAC-RCBF 17%(平均奖励:7.009 / 6.189 / 3.533 / 3.223)。
  - PVTOL 200 环境完成率:上界 87% / Modular **69%** / SAC-RCBF 52% / 基线 34%,Modular 比 SAC-RCBF 相对提升约 33%(平均奖励 11.969 / 10.656 / 9.450 / 7.228)。
- **结论**:SAC-RCBF 在训练中既保证安全又提升样本效率与稳态性能;模块化方案让策略可迁移到不同安全约束的环境。未来方向:用该框架去 RL 学习**非安全攸关**的 CBF。

## 核心贡献
1. 提出 **可微 RCBF 安全层**,首次把连续时间鲁棒 CBF 的 QP 做成可反传的 RL 层,显式把安全修改纳入策略梯度的 loss,绕开离散 CBF 的仿射限制和 compensator 的近似误差。
2. 用 GP 在线估计扰动并以凸包形式接入 RCBF,使框架适用于含未知扰动的一大类系统。
3. 提出 **Modular SAC-RCBF**:仅在 cost-to-go 中丢弃安全补偿,把奖励任务从安全约束中解耦,显著提升对不同约束的零样本迁移,且不损害训练安全。
4. 在三个自建环境给出系统的样本效率与迁移实验验证。

## 局限与我的质疑
1. **作者自述局限**:(a) RCBF 要求**显式已知输出动态 f、g**才能构造约束(所以才放弃 Safety Gym、全用自建环境),这在真实机器人/感知驱动场景里往往不成立;(b) Δt 较大时的零阶保持修正、级联 RCBF 的理论保证都"留待未来",当前级联结果**无证明直接给出**;(c) 需要松弛变量 s——意味着存在"无任何控制能满足屏障证书、违规不可避免"的情形,安全保证并非绝对,只是在 GP 估计的扰动集内成立。
2. **安全保证依赖 GP 扰动估计的正确性,存在循环风险**:RCBF 的"保证"是相对于 GP 学到的 D(x) 而言;若训练早期数据稀少导致 GP 低估扰动(置信区间没盖住真值),屏障证书就是基于错误模型的,"零违规"可能只是这些温和仿真扰动(斜坡 −0.1cos θ、d=0.1)恰好被覆盖,**未对 GP 失准/分布外扰动做压力测试**。把"实验里零违规"读成"方法保证安全"是被过度解读。
3. **实验规模与难度都偏小**:状态维度低(独轮车、双积分器链、2D 四旋翼),障碍多为圆形,扰动是人为设定的简单解析式;MF 版在 Unicycle 几乎不比基线强,说明可微层的收益高度依赖环境是否"安全层行为剧烈"。缺与非 CBF 类安全 RL(如 CPO、Lagrangian/CMDP、Recovery RL)的横向对比,基线只取了 [9] 一条线,**证据不足以支撑普适优越性**。所有结果都是仿真,无任何实体机器人验证。
4. **与"RL 训练数字人与环境交互"主题的差距**:本文对象是低维移动机器人(独轮车/车队/四旋翼),不是高维拟人/全身控制;它解决的是"避撞/保持距离"这类几何安全约束,而数字人交互的"安全/合规"往往是语义的、接触丰富的、难以写成解析 h(x) 的——RCBF 需要手工设计屏障函数并已知动态,这恰恰是高自由度拟人体最难满足的前提。其价值对本主题更多是**方法论借鉴**(可微安全层、约束与奖励解耦的迁移思路),而非可直接套用的方案。
5. **"模块化"的代价未充分讨论**:把 cost-to-go 的安全项置零让价值函数"假装没有障碍",迁移分数确实涨了,但这等于训练出一个**对训练时见过的障碍视而不见**的价值函数——在测试环境约束更严或安全层无法救场时,这种"乐观"策略是否反而更易把系统逼到松弛违规的边界?论文只报完成率/奖励,没有报告迁移时各方法的**实际违规率/松弛触发频率**,安全侧的迁移代价是个盲区。
