# Safe Reinforcement Learning Using Robust Control Barrier Functions
> Yousef Emam, Gennaro Notomista, Paul Glotfelter, Zsolt Kira, Magnus Egerstedt · 2022 · IEEE Robotics and Automation Letters · 引用 52 · DOI 10.1109/lra.2022.3216996

## 一句话
把鲁棒控制屏障函数(RCBF)做成一个**可微的安全层**嵌进基于模型的 SAC 强化学习里,让安全约束的影响能反向传播进 RL 损失("In this paper, we frame safety as a differentiable robust-control-barrier-function layer in a modelbased RL framework"),既保证训练全程不越界、又能引导探索,并提出**模块化学习奖励任务**以支持对不同安全约束的零样本迁移。

## 解决了什么问题
安全 RL 的常见做法是加一个"安全层"把 RL 动作投影到安全集合,难点是**怎样把 RL 与安全层有效耦合以提升学习表现**。本文针对前作 [9](Cheng et al., AAAI 2019)的三个缺陷:① 它用的离散时间 CBF 只对**仿射** CBF 才能用 QP 实时求解(避障时只能编码多面体障碍);② 它用监督学习去近似 CBF 行为,近似不准会反过来损害 RL;③ 安全层对动作的修改**没有显式写进 RL 的损失函数**,相当于把安全层当成未知转移函数的一部分,在 agent 为避障而剧烈动作时会阻碍学习。

## 用什么方法解决的
框架称为 **SAC-RCBF**(底层 RL 用 SAC,"The motivation behind using SAC is that it is sample-efficient; however, we note that the methods proposed in this paper are compatible with any off-the-shelf policy-gradient algorithm"),由三块组成:
1. **扰动估计**:对带未知扰动 d 的控制仿射系统("x˙(t) = f(x(t)) + g(x(t))u(x(t)) + d(x(t))",式 1),用高斯过程(GP)学习扰动集 D(x),**每个维度训一个 GP、共 n 个**("we train one GP per dimension for a total of n GP models"),并带用户选的置信参数("kc = 2 achieves a confidence of 95.5%")。
2. **RCBF-QP 安全层**:用最小侵入的二次规划修正 RL 动作,目标最小化补偿项范数加松弛项 `min ||u||² + l·s²`,其中松弛变量 s 保证 QP 可行("s ∈ R is a slack-variable that serves to ensure feasibility of the QP, l > 0 is a large weighting term to minimize safety violations",式 8);最终执行动作是补偿项与 RL 动作之和 **u\*=uˢ+u^RL**(式 9)。RCBF 相比仿射 CBF 更通用("RCBFs are amenable to real-time control synthesis, even if the functions are non-affine … Additionally, the differentiable safety layer eliminates the need to learn the behavior of the CBF and thus a supervised-learning component"),直接消除了 [9] 的监督学习近似组件。
3. **两个样本效率增强**:(i)**可微安全层**——借 OptNet/可微凸优化 [16][17],"propagation of gradients through the QP as in (8) using a linear system formulated from the KKT conditions",从而把 RL 的 Q-loss/policy-loss(式 10、11)显式写成对安全动作 `uᴿᴸ+uˢ` 的函数;(ii)**基于模型的合成数据**——已知奖励与安全约束时用学到的动力学生成**短时域 rollout** 入回放缓冲,短时域是因为"model errors compound over long horizons … in the worst case, can significantly impede the agent from learning an optimal policy"。

**模块化任务学习(Modular SAC-RCBF)**:针对训练/测试安全约束不同的迁移场景。关键操作是**只把 cost-to-go 里下一步的安全层输出置零**("the modification we propose is to solely discard the safety's layer output when computing the cost-to-go (i.e., only setting uˢ_{t+1} = 0 in (12))",式 13),而非全部置零(全置零因 x_{t+1} 仍依赖 uˢₜ 而得不到想要的 Q 函数)。这样学到的值函数"as if there were no obstacles",独立于训练期障碍配置;且**不牺牲训练期安全**:"this method does not affect the safety of the agent during training since the final action taken in the environment given by (9) remains unchanged"。

## 数据集 & 实验设置
两组自建仿真实验(代码 github.com/yemam3/Mod-RL-RCBF,见原文第 5 页脚注 1),曲线均为"average of ten experiments using different seeds … confidence interval of two standard deviations"。
- **样本效率组**:对比 SAC-RCBF 的 MB/MF 版与两个基线(原文第 5 页实验设置:基线1=model-free SAC + 非可微 RCBF-QP;基线2=再加 [9] 的 compensator 神经网),指标是每回合累计奖励 vs 回合数。
  - *Unicycle*:独轮车去目标点避障,扰动 ud=−0.1cos(θ)[1 0]ᵀ 模拟斜面;避障 RCBF `hₒ=‖p(x)−pₒ‖²−δ²`(原文第 6 页)。
  - *Car Following*:5 车链,受扰双积分器,扰动 di=0.1 且对除第 4 车外的所有车非零("di = 0.1 is a disturbance unknown to the agent that is non-zero for all cars except car 4 (i.e., ∀i ∈ {1, 2, 3, 5})",原文第 6 页),智能体**只控第 4 车加速度**,"reward function r(u) = −||u||²",最小间距 δ=3.5;h₃、h₅ 相对度为 2,用 [21] 的级联 RCBF。
- **模块化/迁移组**:对每个环境做**200 个不同障碍配置**的零样本迁移,报告平均/标准差回报与完成率。*PVTOL*(2D 四旋翼)避障 RCBF 相对度为 3,并加"与安全操作员保持距离"的约束 `hₕ=δ²−(x₁−xₕ)²`(原文第 7 页)。

## 主要结果 & 结论
- **安全**:在部分实验设置下观察到全程零越界——"no safety violations occurred throughout the experiments"。
- **样本效率(观察性,逐环境)**:Unicycle 里所有方法都收敛到最优,**MB SAC-RCBF 样本效率最好**,而"MF SAC-RCBF approach performs only slightly better than the two baselines"(因圆形障碍下安全层行为平滑);Car Following 里 **MB 与 MF 都"significantly better sample efficiency compared to the baselines"**,且无 compensator 的基线"inability … at learning a meaningful policy in several trials"——说明显式建模安全层对找到最优策略也关键。
- **零样本迁移**:
  - *Unicycle(表 I,200 配置)*:无障碍上界 SAC 平均回报 7.009 / 完成 0.81;**Mod. SAC-RCBF 6.189 / 0.63**;基线 3.533 / 0.21;SAC-RCBF 3.223 / 0.17。即"Modular SAC-RCBF which had a completion average of 63% … the baseline and SAC-RCBF performed quite poorly solving only 21% and 17%"。值函数可视化(图 5)显示 SAC-RCBF 在障碍周围赋低值,而 Mod. 版"learns a value function that is almost identical to the target"。
  - *PVTOL(表 II,200 配置)*:上界 11.969 / 0.87;**Mod. SAC-RCBF 10.656 / 0.69**;SAC-RCBF 9.450 / 0.52;基线 7.228 / 0.34。即"Modular SAC-RCBF yields a 33% improvement over SAC-RCBF by completing 69% of the environments as compared to 52%"。
- **结论**:"SAC-RCBF approach is empirically validated in simulated environments and is shown to improve both the sample efficiency and steadystate performance during RL training";模块化方法产出可迁移到不同安全约束环境的策略。

## 核心贡献
1. **可微 RCBF 安全层**,兼容标准策略梯度 RL,把 QP 经 KKT 求导端到端接进 RL 损失,**无需**像 [9] 那样用监督学习近似 CBF,且支持非仿射 CBF。
2. **基于模型的样本效率增强**:用部分学到的动力学 + GP 扰动估计生成短时域合成 rollout。
3. **模块化任务学习**:仅在 cost-to-go 中丢弃下一步安全层输出,使值函数独立于训练期约束,从而显著改善零样本迁移、又不损训练安全。

## 局限与我的质疑
1. **实验只在低维自建仿真上,优势是"逐环境观察"而非普遍证明**。MF 版在 Unicycle 里几乎不如基线(作者自己承认),说明可微安全层的收益强依赖"安全层行为是否剧烈影响动力学/奖励";论文没给出何时该用 MB/MF 的判据。任何"全面/大幅超越"的解读都超出证据——增益是任务相关的。
2. **关键理论留白**:Car Following 和 PVTOL 都依赖级联 RCBF(相对度≥2),但作者明说"The theoretical particulars of cascaded RCBFs will be discussed in future work, and we present the results without proof here"——即论文用于主要迁移实验的安全构造**本文未给安全性证明**,这与"保证安全"的主张之间存在缺口。"零越界"是经验观察,不是这些级联构造下的理论保证。
3. **安全保证以模型/扰动估计为前提**:RCBF 只对 GP 估计出的扰动集保证安全(置信 kc 人选),GP 估计若偏差或真实扰动超出置信区间,安全不再有理论保证;且需已知输出动力学 f、g,这限制了向"动力学完全未知"场景的适用。连续时间安全靠"足够高频求解 QP"成立(原文第 3–4 页:"solving the RCBF-based optimization program at a sufficiently high frequency ensures safety");ΔT 较大时作者提出对 RL 动作做零阶保持再按需求解 QP,但"in the interest of brevity, we leave these modifications to future work"(原文第 4 页),即明确推给未来工作。
4. **基线偏弱 / SAC-RCBF 自身迁移很差**:迁移实验里 SAC-RCBF 完成率仅 17%/52%,提升主要来自"模块化"这个相对独立的技巧,而非可微安全层本身;与更广泛的安全 RL SOTA(如 Lyapunov-based、CPO 等)没有直接对比,迁移上界也只是"无约束 SAC",对比面偏窄。
5. **可微层有训练期算力代价**:作者承认损失(式 10、11)计算中要批量解 QP("increased computation time because batches of QPs are being solved during the computation of the losses",原文第 4 页),但推理时间不变("the inference time remains the same since only a single QP is solved at each time step");大规模/高维问题上的可扩展性未验证。
6. **对复用者**:核心超参/结构细节(GP 的 kc、松弛权重 l、级联增益 γ₁、δ、rollout 步长 k 与数量 M、SAC 网络规模、ΔT)文中只零散给出部分数值(如 δ=3.5、kc=2、di=0.1、vdes=30),完整复现需依赖其开源代码;且方法要求**显式知道 f、g 并能构造 RCBF**,这是落地的主要门槛。
