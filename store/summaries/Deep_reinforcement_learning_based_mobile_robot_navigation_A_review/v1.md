# Deep reinforcement learning based mobile robot navigation: A review
> Kai Zhu, Tao Zhang · 2021 · Tsinghua Science & Technology · 引用 459 · DOI 10.26599/tst.2021.9010012

## 一句话
一篇系统梳理 2016–2020 年间深度强化学习（DRL）用于移动机器人导航的综述，把零散的研究按"局部避障 / 室内导航 / 多机器人导航 / 社会导航"四类应用场景归纳，并提炼出部分可观测、稀疏奖励、泛化差三大共性挑战及其对策。

## 解决了什么问题
传统导航框架（SLAM 建图 → 定位 → 全局/局部路径规划）是多模块串联，误差沿管线累积、依赖高精度全局地图、对传感器噪声敏感，难以应对未知或动态环境。DRL 提供了一条"从原始传感输入直接学导航策略"的无地图（mapless）替代路径。但此前的导航综述对 DRL 覆盖不足，已有 DRL 综述又只聚焦多智能体或视觉导航单一切面；本文要给出一份覆盖各类导航任务、强调 DRL 共性增益的全景式梳理，帮助研究者改进结果并落地到真实系统。

## 用什么方法解决的
这是综述（非实验论文），方法是"读文献 + 归类 + 抽取共性"：
1. **背景层**：把导航建模为 MDP（状态 S / 动作 A / 奖励 R / 转移 P），复盘价值型（DQN、DDQN）与策略型（DDPG、A3C、PPO）两类 DRL 算法的原理与优缺点。
2. **框架层**：定义 DRL 导航系统三要素——状态空间（起点/目标/障碍，agent-level vs sensor-level）、动作空间（离散动作/连续速度/电机转速）、奖励函数（稀疏 vs reward shaping）；并说明 DRL agent 替代传统框架的定位+局部规划模块，复杂结构时仍需传统全局规划给中间航点。
3. **场景层**：按四类应用场景分别梳理代表工作、sim-to-real 与传感器鲁棒性等子问题（配两张对比表）。
4. **挑战层**：归纳三大挑战及对策——部分可观测（POMDP / 堆叠帧 / RNN-LSTM-GRU 记忆）、稀疏奖励（reward shaping / 辅助任务 / 课程学习）、泛化差（扩样本空间加随机化 / 缩状态空间用稀疏激光）。

## 动机 & 背景
导航是移动机器人（无人车、无人机、无人船）的基础能力，目标是在 2D/3D 环境中从起点到目标点找最优路径并避障。传统框架靠 SLAM（视觉/激光）+ 定位 + 全局规划（A*、蚁群、RRT）+ 局部规划（人工势场 APF、动态窗口法 DWA）。作者指出传统框架的根本痛点：模块串联导致误差累积、依赖高精度全局地图、对传感噪声敏感、动态环境下重规划计算量大。2013/2015 年 DQN 在 Atari 上的突破催生了 DRL，2016 年起把 DRL 用于导航成为趋势。DRL 导航的卖点：无地图、学习能力强、对传感器精度依赖低。因为 RL 是试错学习、实机训练会撞坏机器人，所以普遍先在仿真训练再迁移到真机。

## 方法细节
- **价值型 DRL**：DQN（目标网络 + 经验回放解决 TD 误差与样本相关性）；DDQN（双网络分离动作选择与价值评估，缓解过估计，57 个 Atari 上归一化性能约为 DQN 两倍）。局限是只能处理离散低维动作空间。
- **策略型 DRL**：DDPG（确定性策略 + AC，解决连续高维动作，适用机械臂等 20+ 连续控制任务）；A3C（并行 actor + N 步回报，CPU 多核、成本低于 DQN，但调参难、采样效率低）；PPO（裁剪替代目标，允许小批量多轮更新，样本利用率与稳定性优于 A3C）。
- **三要素设计**：状态可用 agent-level（障碍速度/位置/尺寸）或 sensor-level（激光/超声/单目/深度）；动作分离散移动、连续速度、电机转速（后者可端到端但训练最难）；奖励多用 dense reward shaping（目标奖励 + 碰撞惩罚 + 每步时间惩罚）。

## 数据集 & 实验设置
本文不含原创实验。涉及的仿真/测试平台：DeepMind Lab（3D 迷宫）、AI2-THOR（交互式 3D 房间，Zhu 等 2017 提出）、House3D（基于 SUNCG 数据集）。作者用两张表横向对比代表工作：Table 1 按四场景比较静态/动态/结构连续障碍、规模、速度、协作、随机性；Table 2 列出约 30 篇代表文献的算法、感知类型（激光/超声/单目/深度/agent-level）、动作空间（连续/离散及维度）、奖励设置（dense/sparse）、是否仿真/真机验证及年份。

## 主要结果 & 结论
- **四场景归纳**：局部避障（最基础，反应式，DQN/DDQN/DDPG/Fast-RDPG 等，含无人机/无人船）；室内导航（复杂结构 + 视觉导航，target-driven、Nav A3C + 辅助任务、IMPALA 提升泛化）；多机器人导航（CADRL、并行 PPO、hybrid-RL、PRIMAL 千机器人、编队/围捕）；社会导航（行人密集，SA-CADRL、GA3C-CADRL + LSTM、图卷积 + 注意力、freezing robot 问题）。
- **三挑战对策**已系统列出（见上）。
- **结论**：DRL 策略仍无法始终产生完美行为、性能有波动，但作者认为 DRL 最有希望在导航能力上取得突破，期望本文助力研究者改进并落地真实系统、实现"人类水平的导航智能"。

## 核心贡献
1. 提出"四应用场景"分类框架，统一了此前混乱的 DRL 导航分类（如 mapless/map-based/visual navigation 概念混用）。
2. 系统对比五类主流 DRL 算法在导航中的适配性，并抽象出状态/动作/奖励三要素设计空间。
3. 把分散的难题收敛为部分可观测、稀疏奖励、泛化差三大共性挑战，并为每个挑战配套了对策清单——这是综述最有参考价值的部分。
4. 两张文献对比表给出感知类型/动作空间/奖励/真机验证维度的横向速查。

## 局限与我的质疑
1. **作者自述局限**：DRL 导航策略性能波动、无法稳定产生完美行为；策略空间设太大难收敛，因此当前只能"特定场景训练再泛化到相似场景"；sim-to-real 的 reality gap 仍是核心障碍；reward shaping 过拟合场景、设计不当会误导学习。这些坦白说明该领域 2021 年仍未真正落地。
2. **综述深度偏浅、缺批判性**：本质是"分类 + 罗列代表工作 + 抽取挑战"，几乎没有定量横向 benchmark（没有统一指标对比各方法的成功率/路径长度/碰撞率），Table 2 只有定性标签。读者无法据此判断哪个方法在同一任务上真的更好——综述停在"谁做了什么"，没到"谁做得更对"。
3. **结论被轻度过度拔高**："实现人类水平导航智能"是愿景式表述，与正文承认的"性能波动、无法泛化、reality gap 未解"之间存在张力；把 DRL 说成"最有希望突破"缺乏与传统/混合方法的公平对照证据（事实上正文多处显示纯 DRL 不行、要靠 PID/全局规划/模仿学习兜底，混合方案才实用）。
4. **覆盖窗口与时效**：只覆盖 2016–2020，截稿于 2021 年初，缺 Transformer 策略、大规模 sim2real（如 domain randomization 的成熟工作）、以及后来主流的端到端学习导航进展；对"社会导航如何量化社会规范"这一最难点只点到为止。
5. **与本研究主题（RL 训练数字人与环境交互）相关性弱**：本文的"agent"是轮式/飞行/水面移动机器人，研究的是 2D 平面点到点导航 + 避障，状态多为激光测距/坐标，动作是线速度/角速度。它**完全不涉及人形/数字人的全身控制、多自由度运动、与物体的接触交互、人体动作模仿**。对数字人课题，可借鉴的只是方法论层面的通用件——POMDP+LSTM 记忆、reward shaping、课程学习、sim-to-real 随机化、PPO/DDPG 选型；但其"低维动作 + 稀疏激光降状态空间"的核心思路恰恰与数字人"高维全身动作 + 富接触"的需求相反，参考价值有限，相关性评分 40 偏合理甚至略高。
