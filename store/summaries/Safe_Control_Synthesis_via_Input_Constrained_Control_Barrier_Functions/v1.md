# Safe Control Synthesis via Input Constrained Control Barrier Functions
> Devansh Agrawal, Dimitra Panagou · 2021 · arXiv · 引用 0 · DOI 10.1109/cdc45484.2021.9682938

## 一句话
提出"输入约束控制屏障函数(ICCBF)",在控制输入受限(执行器有上下界)时,从原始安全集里切出一个**确实能守住**的内安全子集,并给出一个可实时求解的二次规划(QP)控制器把系统永远困在这个子集里。

## 解决了什么问题
传统控制屏障函数(CBF)假设控制权限足够大,总能把整个安全集 S 守成前向不变。但真实系统的执行器有饱和(刹车最多 0.25g、推力有上限),此时**整个安全集根本守不住**——在安全集边界上,任何允许的输入都会让系统跑出去。论文要解决的就是:在输入受限下,如何**找到安全集中真正能守住的那部分**,并构造一个尊重输入约束的控制器。

## 用什么方法解决的
对安全函数 h 反复做"取输入下确界 + 加 class-K 函数"的递归构造,得到一串函数 b₀=h, b₁, …, b_N(每个 bᵢ 只依赖状态、不依赖输入,因为对 u 取了 inf),各自的 0-超水平集 C₀,…,C_N 取交集得到内安全集 C\* 。只要 b_N 满足 ICCBF 条件(在 C\* 上存在可行输入使 sup[ḃ_N+α_N(b_N)]≥0),就证明任何满足该约束的 Lipschitz 控制器都能让 C\* 前向不变(主定理,用 Nagumo 切锥定理证)。最终控制器写成一个带输入约束的 QP,只需 b_N 及其导数,计算量和普通 CBF-QP 几乎一样。

## 动机 & 背景
- 安全关键的赛博物理系统需要"安全约束永不被违反"的保证,通常把安全建模为状态空间的一个安全子集 S,要求轨迹始终留在其中。
- CBF + QP 已成为合成底层安全控制器的主流:在当前状态实时解 QP,适用于大量非线性系统。
- **既有工作的盲点**:大多假设控制权限足够大,能保证整个安全集前向不变。一旦有输入约束,只有 S 的一个子集守得住。
- 已有计算这种子集的方法都有硬伤:Hamilton-Jacobi 可达性分析、Sum-of-Squares(SOS)半定规划,**都随状态维数急剧变差(维数灾)**,且 SOS 还要求动力学和约束能写成多项式;另有一些方法只针对特定系统类(如 Euler-Lagrange)。
- 论文用 Example 1(不稳定标量系统 ẋ=x+u, u∈[−1,1], 安全集 x≤2)直观说明:在边界 x=2 处 ḣ=−2−u≤−1,任何输入都会越界,故 S 不可守。

## 方法细节
- **问题设定**:控制仿射系统 ẋ=f(x)+g(x)u,输入受限 u∈U,安全集 S 为 h(x)≥0 的 0-超水平集;f、g、h 已知且足够光滑,状态可测。
- **Nagumo 定理 + 引理 2**:S 前向不变 ⟺ 在边界上 L_f h + L_g h·u ≥ 0。若 h 是 ZCBF 则保证存在守住 S 的控制器;本文专攻 h **不是** ZCBF 的情形。
- **核心构造(递归)**:bᵢ₊₁(x)=inf_{u∈U}[L_f bᵢ + L_g bᵢ·u + αᵢ(bᵢ)],αᵢ 为用户自选 class-K 函数,N 为正整数。因对 u 取下确界,bᵢ 只依赖状态。关键性质:若某点同时在 ∂S 和 C₁ 上,则 inf_u ḣ≥0,意味任何输入都不会让轨迹从此处逃逸,从而 S∩C₁ 在任何守住 C₁ 的控制器下也前向不变;递归叠加得 C\*=∩Cᵢ。
- **与 HOCBF 的关系(Remark 1)**:对相对度为 2 的系统 L_g h=0,递归首项退化为 L_f h+α₀(h),正是 Higher Order CBF 的定义。故 ICCBF 是 HOCBF 的推广,且能处理**非均匀相对度**系统(取 N≥系统在 S 内的最大相对度)。
- **主定理(Thm 1)**:若 b_N 是 ICCBF,则任何取值在 K_ICCBF(x)={u∈U: L_f b_N+L_g b_N·u≥−α_N(b_N)} 内的 Lipschitz 控制器都使 C\* 前向不变。证明对边界上 bᵢ=0 的各 i 分情形:i<N 时由构造 inf_u ḃᵢ≥0 自动满足;i=N 时由 ICCBF 条件满足,凑齐 Nagumo 条件。
- **简单 ICCBF(Def 4 / Thm 2)**:若 C\* 是 C_N 的严格子集,则 C\* 内任意 Lipschitz 控制器(无需安全干预)都守得住——直观上即无控动力学 f(x) 本身就把系统推向安全(Remark 3)。
- **QP 控制器(Thm 3)**:U 写成凸多面体 Au≤B 时,解 min ½uᵀHu+Fᵀu s.t. ICCBF 约束 + u∈U,得到的反馈控制器使 C\* 前向不变。计算复杂度与普通 CBF-QP 几乎相同(只需 b_N 及其导数;长表达式用 Mathematica 或 Julia 的 ForwardDiff 自动微分得到)。

## 数据集 & 实验设置
两个仿真案例(无真实硬件、无数据集,纯数值仿真):
1. **自适应巡航控制(ACC,源自文献[10])**:点质量车辆跟车,状态 x=[d, v](车距、车速),安全约束 d≥1.8v;输入即加速度,约束 |u|≤0.25(最大 0.25g 减速);速度限 v_max=24。取 N=2,class-K 函数 α₀=4h、α₁=7√h、α₂=2h。期望加速度 u_d 由控制 Lyapunov 函数 V=(v−24)² 给出。与文献[10]的 CLF-CBF-QP(再对解做 clip 到可行域)对比。
2. **航天器自主交会**:追逐航天器(点质量,质量 1000 kg)向旋转目标(如 ISS,角速度 0.6°/s)从 100 m 接近到 3 m,安全约束为保持在对接轴 10° 视线锥(LOS)内;5 维状态(相对位置/速度 + 目标姿态角),用**全非线性**相对运动方程(非线性化的 Clohessy-Wiltshire),推力 1-范数受限 |uₓ|+|u_y|≤0.25 kN。取 N=2,α 函数线性,QP 中让参数 k>0 与松弛 δ 一起被优化。
- ICCBF 有效性的验证:解非凸优化 γ=min_x sup_u[ḃ_N+α_N(b_N)] s.t. x∈C\*,γ≥0 即合法;ACC 中算得 γ=2.33。

## 主要结果 & 结论
- **ACC**:CLF-CBF-QP 在 t=5.9 s 撞到输入上限,被迫离开安全集(违反安全);ICCBF-QP 因为在 t=2.9 s 就**提前刹车**(而非 5.0 s),全程保持可行且安全。说明不考虑输入约束的 CBF 会失败,而 ICCBF 因内置约束意识而成功。
- **交会**:追逐器从 (100, −10) m 出发,成功转移到目标,推力 1-范数始终满足约束,LOS 视线角全程在 10° 锥内。
- **结论**:ICCBF 把输入约束显式纳入屏障函数构造,识别出内安全集并给出守住它的反馈控制器,是 HOCBF 的推广,可处理非均匀相对度;QP 实现可实时运行。
- **未来工作**:数值高效地自动搜索 ICCBF;与可达性方法在高维下的复杂度比较;研究对噪声和模型失配的鲁棒性。

## 核心贡献
1. 提出 ICCBF 概念,首次把输入约束**显式**编入 CBF 构造,保证受限控制器能守住一个内安全子集 C\*(主定理给出充分条件与可行控制集 K_ICCBF)。
2. 证明 ICCBF 是 HOCBF 的严格推广,并扩展到**非均匀相对度**系统。
3. 给出可实时求解、复杂度与标准 CBF-QP 相当的 QP 综合方法,并定义"简单 ICCBF"这一无需安全干预的特例。
4. 在 ACC 和航天器交会两个非线性案例上验证,且开源代码与动画。

## 局限与我的质疑
- **作者自述局限**:① ICCBF 的"寻找"目前不是自动的——递归里的 N 和每个 class-K 函数 αᵢ 全靠**用户手工/任意选取**(论文里 N=2、α 系数都写"arbitrarily"),没有系统化搜索方法;② 验证 b_N 是否为合法 ICCBF 要解一个**全局非凸**优化(min sup),本身可能困难、不保证全局最优;③ 未分析对噪声和模型失配的鲁棒性(全程假设 f、g、h 精确已知且状态完全可测)。
- **可扩展性存疑**:论文批评 HJ/SOS 方法维数灾,但自己也没给出任何高维证据——最大案例才 5 维,且递归 bᵢ 要反复符号微分(用 Mathematica/自动微分),随相对度和维数增长,b_N 的表达式会爆炸式膨胀,所谓"复杂度与 CBF-QP 相当"只在"b_N 已离线算好"的前提下成立,离线那步的代价被回避了。此外 C\* 取多个集合的交,其几何形状和非空性只是被**假设**(假设 C\* 闭、非空、无孤立点),并未给出何时保证非空、内安全集会不会被切到过小甚至为空的分析。
- **实验过于单薄、对比不公平**:只有 2 个仿真、各 1 条轨迹,没有蒙特卡洛、没有统计、没有对扰动的测试;ACC 的对比基线只是"普通 CBF-QP 再硬 clip 输入",这本来就是注定失败的稻草人——更强的基线(如显式 MPC、HJ 可达集控制器)完全没比。引用数为 0 也佐证其影响尚未被验证。
- **结论的适用边界**:保证只在"系统初始就落在 C\* 内、模型精确、无噪声、连续时间"这组理想假设下成立;离散化采样、测量噪声、未建模动力学都可能击穿前向不变性的数学保证,而这些恰恰是真实系统的常态。
- **与本研究主题(RL 训练可与环境交互的数字人)的差距**:这是一篇纯**模型驱动**的控制论文,要求动力学 f、g 解析已知且光滑,与 RL 的"无模型/数据驱动、从交互中学策略"范式正交;它处理的是低维刚体/质点(车、航天器)的安全综合,完全没有触及高维、接触丰富、人机交互式的数字人控制。其真正可借鉴之处是**作为安全过滤层(safety filter)**——若数字人的局部动力学可近似建模,ICCBF 的"输入受限下的可行安全子集"思想或可在 RL 策略外套一层执行器约束安全壳;但论文本身既无 RL、无学习、无高维接触动力学,也无人类交互或数字人语境,直接迁移的工程缺口很大。
