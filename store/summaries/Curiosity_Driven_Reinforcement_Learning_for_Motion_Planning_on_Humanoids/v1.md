# Curiosity Driven Reinforcement Learning for Motion Planning on Humanoids
> Mikhail Frank, Jürgen Leitner, Marijn Stollenga, Alexander Förster, Jürgen Schmidhuber · 2014 · DOAJ (DOAJ: Directory of Open Access Journals) · 引用 75 · DOI 10.3389/fnbot.2013.00025

## 一句话
把"人工好奇心"(信息增益最大化)装进真实的 iCub 人形机器人,让它自主探索高维构型空间、边玩边学出一个可复用的 MDP 运动规划器,并自发对自身约束和环境中的桌子产生"兴趣"。

## 解决了什么问题
此前的人工好奇心(AC)/内在动机研究大多停留在理论和玩具场景(模拟迷宫、一两个自由度的简单系统),即便上了真实机器人,也都靠预编程的高层动作基元、离散化的电机指令或极简机器人来"作弊"地简化动作空间。本文要解决的是:**如何让一个好奇心驱动的智能体在真实复杂人形机器人的高维构型空间里在线学习、实时控制硬件,并把"规划"和"反应式控制"两条历来分裂的路线融合起来**,得到一个既完备又鲁棒、还能应对动态环境的运动规划器。

## 用什么方法解决的
分层架构:**底层用反应式控制器 MoBeE**(一个二阶动力学系统 Mq̈+Cq̇+K(q−q\*)=Σfᵢ,用虚拟力场实时强制关节限位、缆长、碰撞等约束,保证机器人安全),**高层是好奇的 RL 智能体**。把连续构型空间用采样点的 Voronoi 区域离散成状态集 S,"动作"= 把 MoBeE 的吸引子 q\* 设到某个邻近目标状态(每个状态连到 2ⁿ 个最近邻),系统作为一个 MDP。状态转移概率 T 从真实硬件试错中学得。**内在奖励 = 该状态-动作再试一次后,转移分布更新前后的 KL 散度(信息增益/学习进展)**,用动态可变长度的分布表示 + 乐观初始化,解决了 KL 在零概率和状态空间基数上的两个数值问题。最后用 value iteration(γ=0.9, δ=0.001)在内在奖励下做贪婪探索;若要"利用"规划器,再叠加/替换外部奖励即可。

## 动机 & 背景
- **两条历史分裂的路线**:① 路径规划(PRM/RRT 等)——先在构型空间里搜索、预先验证每条边的可行性、生成参考轨迹再交给控制器执行,结果是"先思考后行动",慢、且要求工作空间静态、要求机器人动力学可精确建模(对 iCub 这种缆驱、有摩擦和形变的轻型机器人很难);② 反应式控制(势场/动力系统/直接用传感信号)——快、紧耦合、能应变,但短视、易陷局部极值,不是好的规划器。
- 作者主张:**把规划器"具身化"并赋予反应能力**,就能各取所长——底层反应控制实时兜住所有约束,高层规划器便可"直接试",无需预先穷举验证每个动作,也不再要求静态工作空间;PRM 的图于是从"轨迹网络"升级为"连续构型空间的拓扑",每条边变成"试图去那个区域"的一般动作 → 自然变成需要学转移概率的 MDP。
- 但硬件实验极其昂贵(受真实时间约束,不能像仿真那样加速/并行),所以**高效探索是刚需**,这正是引入好奇心驱动 RL 的理由。
- 谱系:Schmidhuber 系的 AC 思想(1991 起,奖励应基于"学习进展"而非单纯不可预测性,否则会盯着本质随机的区域;Storck 1995 用 KL 散度;Itti & Baldi 称之"贝叶斯惊奇")。

## 方法细节
- **MoBeE(动作的实现)**:二阶动力学吸引子系统,把约束实现为力 fᵢ(t)。一个"动作"就是设吸引子 q\*=qg 到某目标状态的采样点,机器人按瞬态响应移动,直到系统稳定或超时;由于途中遇到的约束力,最终 q∞ 可能落在目标状态也可能不落在。
- **状态-动作空间**:真实构型 q∈Rⁿ 连续,但为可解把它离散成 m 个采样点的 Voronoi 区域为状态;每个状态连 k=2ⁿ 个最近邻,动作数随状态数线性增长。
- **转移概率的三类形态**:实际只出现三种——确定到目标状态(式3)、确定到另一个状态(式4,如撞上关节限位被可预测地偏转)、真正非确定(式5,通常是遇到非静态物体,但可能的结果状态也只是少数邻近状态)。因此用"动态可变长度分布"(不显式存零 bin)来紧凑表示。
- **好奇心奖励(KL 散度)**:R(s,a)=D_KL(P‖T),P 是再试一次、观察到 s′ 后更新的更优估计,T 是更新前的估计。**乐观初始化**:首次失败(停在原状态)给 0 奖励,首次成功(到达目标)给一个与状态空间大小无关的非零奖励;这样可不调参地乐观初始化奖励矩阵,直接用贪婪策略激进探索。奖励随经验衰减:确定到目标的动作(表2)衰减最快最无聊,确定到意外状态的(表3)次之,多结果的不可预测动作(表4)最有趣、衰减最慢。
- **RL**:value iteration(Algorithm 3),γ=0.9。规划器"训练"时只用内在奖励;"利用"时加外部奖励。

## 数据集 & 实验设置
- 平台:真实物理 iCub 人形机器人(非仿真),在线学习。
- **实验一(静态环境,单臂)**:状态由肩 3 关节 + 肘共 4 维定义,每维取活动范围 25%/50%/75% → 81 个顶点的 4D 超晶格,各连 16 个最近邻 → 1296 个状态-动作。任务是找出不可行区域(自碰撞、缆长限制)并学转移概率。对比 AC vs 随机探索(RAND)vs 总选最少尝试(LT)。运行约 12 小时,统计到 4000 次状态转移。
- **实验二(桌子 + 多智能体)**:iCub 坐在工作台前,控制双臂 + 躯干共 12 DOF。12 维直接采样不可行(rank-3 超晶格有 531,441 顶点),故**并行三个互不知晓彼此状态的好奇智能体**分别控制两臂和躯干(躯干 3D:27 顶点 × 8 邻居 = 216 状态-动作)。运行约 50 小时,统计到 18,000 次状态转移(两天多)。从手臂视角看不到躯干状态,等价于"桌子是动态障碍"的设定。

## 主要结果 & 结论
- **实验一**:AC 是最高效的探索者,用约 LT 一半的时间就试遍所有状态-动作;访问/尝试分布比 RAND、LT 更均匀,但在撞缆长约束的状态-动作上出现明显尖峰(这些动作结果"意外",更有趣,被反复尝试)。学到的 MDP 中大多数动作确定到目标(无聊/灰色),少数有趣;**值得注意的发现:即便环境静态,有些状态-动作仍非确定性**——说明 iCub 这种轻型缆驱机器人因机械/嵌入式控制的非线性,无法可靠重复精确动作,因此"先规划后执行"(PRM)在这类机器人上不可行,越轻越柔的机器人越如此,这正是用 MDP+学习的动机。
- **实验二**:三个仅靠内在奖励、互不通信的智能体**涌现出协调行为**——躯干前倾 + 手臂下放,使 iCub 反复触碰桌面,即"对桌子产生兴趣";两臂行为分布高度相似(符合机械对称)。机器人在"探索/查自身约束/摸桌子"间周期性循环,内在奖励整体衰减。证明 AC+MDP 规划能让多 DOF 人形机器人有结构地探索环境、建可复用模型。
- **动态环境推论**:若以外部奖励"利用"该规划器,策略会自动绕开转移概率低(常有障碍)的不可预测区域,即在动态障碍环境训练会产出"绕开易出障碍区"的规划。
- 可扩展性:更新值函数比机器人移动一步快约一个数量级,瓶颈是"把所有状态-动作各试几次"的真实时间;状态连通度其实比需要的更密。

## 核心贡献
1. **首个**在真实人形机器人上、实时运行的具身好奇心智能体用于运动规划(作者自称)。
2. 让 AC/内在动机真正学习并利用复杂机器人的**高维构型空间多自由度**,而非靠预编程基元/极简机器人回避难点。
3. **直接学控制指令而非参考轨迹**,却仍得到分辨率完备的规划器,简化了轨迹跟踪的工程问题,动作/观察回路更轻更快。
4. 反应式控制只用来"实现单个动作"(而非生成整条运动),既保完备性又增鲁棒性,可应对未预见/变化的约束与动态环境。
5. 提出动态可变长度分布 + 乐观初始化的 KL 奖励工程方案,解决 KL 在稀疏分布上的数值与基数敏感问题,且使多智能体奖励数值可比。

## 局限与我的质疑
- **作者自述:状态-动作空间是手工构造的**(均匀采样 25/50/75%)。这是全文最大短板——它不是真正"开放式发育",而是在人定的离散网格里跑;作者希望未来能自动搜索"有趣的位姿"增量扩展状态空间,但承认"如何评估新采样点质量"尚不清楚。我补充质疑:既然状态/邻接都人定,且连通度自承"比需要的更密",那么"好奇心带来的效率优势"有多少是被这套人工先验所兜住的,论文没有消融。
- **可扩展性存疑且证据弱**:12 DOF 已经要靠"三个互不通信的智能体硬拆"才跑得动,且耗时 50 小时;真正全身协调要靠尚未实现的"智能体层级"(作者只给了构想,未做)。所谓"多智能体协调"其实是三个独立学习器经由物理身体的副作用松耦合涌现,并非显式协作,把它说成"能扩展到控制整个 iCub"有过度解读之嫌。
- **实验充分性不足**:只有两个实验、各一次长跑,缺统计意义上的重复(多 seed/多次试验)与方差报告;AC vs RAND/LT 的优势主要靠覆盖曲线和分布图定性展示,没有对最终规划质量(成功率、路径长度、规划耗时)的定量基准对比。"对桌子产生兴趣"也基本是定性观察(合成照片 + 频次表),桌子是"大而简单"的物体。
- **奖励=学习进展的老问题未在硬件上正面检验**:KL 散度衡量的是模型更新幅度,理论上规避"盯着纯随机区域"的陷阱,但本文真实硬件里"静态约束也产生非确定转移"恰恰意味着存在不可消除的随机性,智能体是否会被这些不可学的噪声状态-动作长期吸引(尖峰区反复尝试),论文未做长期收敛性分析。
- **与"RL 训练数字人/虚拟人与环境交互"主题相比的差距**:这是 2013–2014 年的工作,落在物理机器人 + 表格型 MDP + value iteration 的范式,**没有任何深度网络、没有连续控制策略、没有视觉/感知输入**(状态只来自电机编码器,环境"桌子"也只是通过约束力间接被感知,而非从像素或接触感知);"交互"仅限于碰撞约束层面的避让/触碰,谈不上对物体的操作或语义理解。对今天关注"用 RL 训练能与丰富环境/物体做接触式交互的数字人/人形"的研究,它的价值主要在**思想层面**(内在动机驱动具身探索、规划与反应式控制融合、把规划器具身化为 MDP),方法本身已被现代深度 RL + 学习世界模型 + 连续控制远远超越,直接迁移价值有限。
