# Temporal Logic Guided Safe Reinforcement Learning Using Control Barrier Functions
> Xiao Li, Călin Belta · 2019 · arXiv (Cornell University) · 引用 31 · DOI 10.48550/arxiv.1903.09885

## 一句话
把时序逻辑(scTLTL)、控制屏障函数(CBF)、控制李雅普诺夫函数(CLF)与强化学习整合进一个二次规划:用逻辑公式同时定义任务奖励、引导探索的目标和必须满足的安全集——对**写进 CBF 的那类状态不等式安全约束(如本文的"通道"约束)**在学习全程硬性保证不被违反(注意:移动障碍动力学未知,不在此硬保证范围内,训练中仍允许碰撞并受罚)。

## 解决了什么问题
作者在引言开篇即把目标定为"解决当前 RL 的两个挑战——复杂任务规范与安全探索"(原文:"Our aim in this work is to address two challenges in current reinforcement learning (RL) methods - complex task specification and safe exploration")。(1)复杂任务的规范/奖励难以手工设计——智能体常钻奖励漏洞("reward hacking"),且"任务复杂度越高,奖励函数越难准确定义"(原文:"For tasks with higher complexity, an accurate definition of a reward function is challenging");(2)在物理系统上学习时的**安全探索**。他们的做法是"用时序逻辑公式的鲁棒度(robustness degree)作为奖励函数,用户只需把任务写成逻辑公式,到奖励的转换自动完成"(原文:"we use the robustness degree of temporal logic formulas as the reward function … the user only needs to specify the task as a logic formula and the transformation to the reward function is performed automatically"),且鲁棒度有严格语义——"大于零即表示任务完成"("a value greater than zero indicates completion of the task")。安全方面则用 CBF 把**写进 CBF 的安全约束(用户额外约束 h 与 TL 谓词导出的状态不等式约束)**作为硬约束在学习与部署中强制执行;对未建模、动力学未知的危险(如移动障碍)并不在此硬约束之列。

## 用什么方法解决的
核心是把一个 scTLTL 公式转成等价的有限状态自动机(FSA),并让 FSA 在系统里**身兼三职**(论文第一条贡献):"给 RL 提供奖励、为 CLF 做目标选择以引导探索、为 CBF 定义安全集"(原文:"provide reward for the RL agent, perform goal selection for the control Lyapunov function for guided exploration and define safe sets for the control barrier functions")。RL 动作、CLF 动作、CBF 动作三者相加后注入已知系统动力学,最终通过求解一个 QP 得到安全动作下发给系统。

## 动机 & 背景
本文延续 FSA 增广 MDP(FSA augmented MDP)这一思路:奖励"鼓励系统离开当前自动机状态、进入下一个,从而最终到达满足规范的终止状态"(原文:"the reward function … encourages the system to exit the current automaton state and move on to the next … eventually reach the final state")。区别于以往工作(如需手工设计 reward machine 的方法),这里任务规范一次给定、奖励自动生成,且把硬安全约束直接嵌进 CBF。论文将自己定位为:相对前人方法实现简单、能处理连续状态/动作空间与非线性约束、可高效执行(原文 §II 末:"Compared to previous work, our method is relatively easy to implement, able to handle continuous state and action spaces, nonlinear constraints and dynamics, and can be executed efficiently")。

## 方法细节
**① FSA 作为 RL 奖励(含陷阱状态)。** 原始 FSA 定义不显式处理"违反规范",作者引入陷阱状态集(trap states):"这一问题可通过额外加一组陷阱状态来解决"(原文:"This problem can be solved by adding an additional set of trap states")——一旦进入陷阱状态就再也无法满足规范。修改后的奖励(式 11)取"促进离开当前状态进入下一非陷阱状态"项与"惩罚进入陷阱状态"项的 min,权重系数 cr>0。关键的诚实之处:"式(11)的奖励并不阻止 RL 智能体在学习中违反 φ"(原文:"r˜ in Equation (11) does not prevent the RL agent from violating φ")——智能体反而需要探索陷阱状态来学习(故 FSA 上有自环),测试时用户可选择一进陷阱状态就终止。

**② FSA 用于 CLF 目标选择。** 直觉是"找当前状态下最容易激活的、通向非陷阱状态的出边"(原文:"find the outgoing edge (leading to a non-trap state) that is easiest for the agent to activate at its current state"),再取使该边守卫谓词鲁棒度最大的 MDP 状态作为目标 sg(式 12)。找到 sg 后用一个简单的二次型 CLF Vφ(s,q)=(s−sg)ᵀ(s−sg)(式 13),作者说明"其它满足式(8)判据的 CLF 也可用,为简单起见案例研究采用上式"。

**③ FSA 用于 CBF 约束。** 利用"FSA 的守卫谓词 ψ 本就是状态不等式约束的命题逻辑公式,可自然解释为安全集并并入 CBF"(原文:"the guarding predicates ψ in an FSA are propositional logic formulas of inequality constraints over states. They can be naturally interpreted as safe sets and incorporated into the CBF")。具体把"不进入陷阱状态"的条件 ¬ψ 转成合取范式(CNF),每个合取项给出一个屏障函数 hᶠ_φ(式 14)。

**④ TL-CLF-CBF QP。** 把 RL 动作 arl 与待求的 acbf、aclf 相加注入已知动力学(式 15,arl 即"RL 智能体提供的动作"),再解一个 QP(式 16):目标 âᵀâ+Kδ,约束包括用户额外安全约束 h(s) 的 CBF 条件、各 TL 相关屏障 hᶠ_φ 的 CBF 条件、CLF 条件(带松弛 δ),以及 acbf/aclf 的动作上下界。松弛变量 δ"在 CBF 与 CLF 约束冲突时增大",K"取很大的正常数(约 1e10)"。整体"结合了基于模型的规划与无模型学习,既能利用已知动力学也能处理未知动力学"(原文:"combines model-based planning and model-free learning so that knowledge about the system dynamics can be taken advantage of while unknown dynamics can also be handled")。完整流程见算法 1。

## 数据集 & 实验设置
单一仿真连续控制任务(§VI、图 3):一个已知动力学的智能体走独轮车(unicycle)模型,控制量为"前进速度 av 与转向速度 aθ"(原文:"The agent's controls are the forward velocity av and steering speed aθ");由于该欠驱动系统不可控,用一个偏移参考点把它改写成全驱动形式(式 17、18)。环境含两条直线构成的"通道"安全约束(智能体须留在内)、三个圆形目标区(episode 内固定、episode 间随机)、以及"两个在通道附近移动、动力学未知的障碍"(原文:"two obstacles that move in the vicinity of the channel and whose dynamics are unknown")。任务公式 φ(式 19)在原文中明确表述为:"最终访问 g1 或 g2、最终访问 g3、g3 不得在 g1/g2 之前被访问、且 g3 被访问前始终满足通道约束 c1/c2"(原文:"the agent is to eventually visit g1 or g2 and eventually g3 and g3 is not to be visited before g1 or g2 and constraints c1 and c2 are to be satisfied at all times before g3 is visited")。状态:位置朝向 [x,y,θ] 加所有目标与障碍位置共 13 连续维,"加 1 维离散 FSA 状态,总状态空间 14 维"(原文:"the total state space is 14 dimensional")。

实现细节:RL 用 PPO("we use proximal policy optimization (PPO) [28] as the learning algorithm");策略为"3 个隐层、分别 300/200/100 个 ReLU 单元的前馈网络,值函数同结构";"每个 episode 时间 horizon T=200 步,目标区位置 episode 间随机";"每次更新收集 5 条轨迹的批"。原文 §VI-D 明确:"训练时允许智能体走出安全通道并与移动障碍碰撞(以受罚),但评估时不允许"(原文:"The agent is allowed to travel outside the safety channel and collide with the moving obstacles during learning (to receive a penalty). However, this is not allowed during evaluation")。

## 主要结果 & 结论
实验对比四种配置:纯 RL、RL+CBF、RL+CLF、RL+CBF+CLF,主要看每个组件对学习的影响(均为定性曲线/图,无汇总数值表)。

- **最终性能相近、CLF 起步更快但更抖**:图 4 显示"所有配置都能达到相近的最终性能"(原文:"all configurations are able to achieve similar end performance");"带 CLF 的配置在学习初期上升更快"("exhibit faster rising time at the beginning"),但"带 CLF 的学习曲线方差和波动更大"("show higher variances and volatility")。作者给出机制解释:CLF 不知道移动障碍和安全约束,只负责把智能体引向最近的、能推进 FSA 的目标,故在临近碰撞/违规时 RL 要"对抗"CLF 的动作,增加了学习难度——在 RL+CLF+CBF 配置中尤为明显。
- **CBF 对通道安全约束的硬保证**:图 5 统计的是通道安全约束 ψc1、ψc2 的最大违反量,显示"CBF 能在整个学习过程中始终阻止智能体违反(这些)安全约束"(原文:"the CBF is able to prevent the agent from violating the safety constraints at all times during learning");无 CBF 的配置因有违反惩罚也会"逐渐学到减少违反",但不是始终为零。需注意此硬保证针对的是写进 CBF 的状态不等式约束(通道),不含动力学未知的移动障碍。
- **代价**:图 6 显示"无 CBF 的配置能与障碍保持更远距离,因为它允许智能体走出安全区"——即 CBF 把智能体限制在安全区内,反而少了一条绕障的退路。
- **评估成功率**:图 8 在"20 次评估试验"上统计成功率,"带 CBF 训练的智能体成功率更高"(原文:"the agents trained with CBF exhibits higher success rates"),因为评估时 CBF 始终开启、不允许走出安全区,而无 CBF 训练出来的智能体更容易卡在安全区边界。注意原文只给柱状图、未列具体百分比数字。
- **组件耦合的代价(图 7)**:在 CLF+CBF(无 RL)配置里,"CLF 仍命令智能体去 g2,但 CBF 把它停在安全区边界、卡住"(此情形下还真撞上了移动障碍,因 CLF/CBF 都不知障碍动力学);加入 RL 后,智能体学会"快到边界时改去 g1 并最终完成任务"——说明 RL 是协调 CLF/CBF 冲突所必需的。

结论(§VII):在已知智能体动力学、未知环境动力学的仿真任务上,系统"能学到一个完成逻辑公式所述任务、同时在学习全程保证安全的策略"(原文:"our system is able to learn a policy that accomplishes the given task expressed as a logic formula while ensuring safety during learning")。

## 核心贡献
1. 提出 FSA 三种用法(奖励/CLF 目标选择/CBF 安全集),把任务规范与安全约束统一到一个逻辑来源。
2. "扩展 FSA 增广 MDP 框架以处理硬约束和规范违反"(陷阱状态机制)。
3. "把系统整合进一个可高效求解的二次规划"。
4. 在带安全约束、已知系统动力学+未知环境动力学的仿真连续控制任务上演示,并逐组件分析其作用。

## 局限与我的质疑
1. **作者自述:超参负担重。** 论文坦承系统含大量超参(cr、w、K、α、c3 及各控制界),"学习过程与最终性能明显受其影响"(原文:"the learning process and the final performance of the policy is noticeably influenced by these parameters"),并把"减轻用户调参负担"列为重要未来工作。这意味着复用此方法者要花相当精力调参(尤其要让 CBF 动作界足够宽以在边界占主导、CLF 界比 RL 窄以便 RL 能压过它),论文只给了定性经验、没有自动化方案。
2. **实验单一、缺强基线与数值。** 全文只有一个 2D 独轮车导航仿真任务,基线全是自身组件的消融(RL / +CBF / +CLF / 全开),**没有与其它安全 RL 方法(如 CPO、shielding、Cheng 等基于 CBF 的工作)做对比**,也没有给出成功率/回报的具体数字表——结论只能支撑"在这个任务上、各组件按预期起作用",远谈不上对方法整体竞争力或泛化性的证明。(总结者注)措辞上我刻意只说"相近/更快/更高",因为原文证据是单任务的定性曲线(observed 级)。
3. **安全保证依赖强假设,可能被过度解读。** "CBF 始终阻止违反"成立的前提是已知系统动力学(独轮车)且安全约束是状态的解析不等式;论文也明确点出 CLF/CBF 都不知道移动障碍的动力学,因此对动力学未知的障碍**并不能保证避碰**(图 7c 就真撞上了),只能靠 RL 去学。换言之"safe RL"这里只对**已写进 CBF 的那类安全约束(通道)**是硬保证,对未建模危险并无保证——标题的"Safe"需要这样限定理解。
4. **CLF 引入的不稳定未必划算。** 实验自己显示 CLF 带来更高方差、甚至 RL+CLF 出现性能骤降(最近目标恰在安全区外、RL 尚未学会对抗 CLF)。CLF 的收益("起步更快")与代价("更抖、需 RL 对抗")在这个任务上看是接近抵消的(最终性能各配置相近),其净价值在更复杂任务上是否成立,论文未证明。
5. **可扩展性存疑。** 目标选择(式 12)需在状态空间上解最大鲁棒度优化,作者承认"状态空间大时第一个优化问题会困难"(原文:"The first problem can be difficult if the state space is large"),目前靠"谓词是区域时取区域中心"这一启发式绕过;FSA 也需对每个公式离线生成。这些都限制了向高维、谓词非区域型任务的推广,论文未做相关验证。
