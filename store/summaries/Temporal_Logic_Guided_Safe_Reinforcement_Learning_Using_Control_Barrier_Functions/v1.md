# Temporal Logic Guided Safe Reinforcement Learning Using Control Barrier Functions
> Xiao Li, Călin Belta · 2019 · arXiv (Cornell University) · 引用 31 · DOI 10.48550/arxiv.1903.09885

## 一句话
把时序逻辑(scTLTL→有限状态自动机)、控制李雅普诺夫函数(CLF)和控制屏障函数(CBF)拼进强化学习里,让用户用逻辑公式而非手写奖励来描述复杂任务,并在训练和部署全程用一个二次规划(QP)护栏保证硬约束安全。

## 解决了什么问题
当前 RL 用在物理系统上有两大痛点:(1)**复杂任务难以指定**——手写奖励函数费力且容易被 agent 钻空子(reward hacking);(2)**探索不安全**——训练过程中可能撞障碍/越界,在有人在场的物理系统上不可接受。作者想同时解决"怎么准确说清任务"和"怎么在学习全程不出事"。

## 用什么方法解决的
用 scTLTL(语法上 co-safe 的截断线性时序逻辑)写任务,自动转成等价有限状态自动机(FSA),再把 FSA 一物三用:
- **当奖励**:用逻辑公式的鲁棒度(robustness degree,>0 即满足)作为 RL 奖励,免去手写奖励;并扩展 FSA-augmented MDP 加入"陷阱态(trap state)"来显式处理规范违反。
- **给 CLF 选目标**:在 FSA 当前态选一条最容易激活的出边,把其守卫谓词鲁棒度最大的状态当成探索目标,构造二次型 CLF 引导探索、加速早期学习。
- **给 CBF 定安全集**:把通往陷阱态的守卫谓词取反、化成合取范式,变成一组 CBF 约束,保证 agent 不进陷阱态、不违反硬约束。
最后把 RL 给出的动作 + CBF/CLF 修正动作整合进一个 **CLF-CBF-QP**(每步求解)输出最终安全动作。框架融合 model-based(已知系统动力学进 QP)与 model-free(PPO 学未知环境动力学)。

## 动机 & 背景
RL 在物理系统落地受制于"任务规范"和"安全探索"。reward hacking(如 Amodei 2016)说明手写奖励易被钻空,复杂任务(如带嵌套 min/max 的插孔)调参困难。安全方面常靠 sim-to-real,但仿真与现实动力学难以完全一致,因此在学习与部署阶段都加一个"护盾控制器(shielding controller)"既保安全又引导探索是有效做法。本文延续作者团队此前的 TLTL 奖励(Li 2016)与 automata-guided RL(Li 2018)工作,引入 Ames 等的 CBF/CLF-QP 框架(2014)。

## 方法细节
- **scTLTL & FSA**:限制不用 □(always)算子,使公式与 FSA 一一对应;FSA 可用 Lomap 等工具自动生成。鲁棒度 ρ 把"状态轨迹+公式"映射成实数,>0 即满足。
- **FSA-augmented MDP**:状态扩展为 (MDP 状态 s, 自动机状态 q);奖励 r̃ = ρ(s', D_φ^q),鼓励 agent 离开当前自动机态、推进到下一态直至终态。
- **陷阱态处理**:加 trap state Q_trap(进入即永远无法满足规范);奖励改为 r̃ = min(ρ(s', D_φ^q), c_r·ρ(s', ¬ψ_{q,q_trap})),既奖励推进又惩罚进陷阱;注意训练时仍允许探索陷阱态(自环),测试时可选择进陷阱即终止。
- **CLF 目标选择**:sg = argmax 鲁棒度的状态,通常是某区域中心;CLF 取 V_φ = (s−sg)ᵀ(s−sg)。
- **CBF 约束**:把 ¬ψ_{q,q_trap} 化 CNF,每个析取子句取鲁棒度最小者作为 h_φ,构成安全集 C_φ。
- **TL-CLF-CBF QP**:把系统动力学改写成 fixed 形式,求 a_cbf、a_clf 的 QP(最小化 âᵀâ + Kδ,δ 是 CBF/CLF 冲突时的松弛变量,K≈1e10);受 CBF 不等式、CLF 不等式与动作上下界约束。
- **训练流程(算法1)**:每步 RL 给 a_rl → 构造 V_φ、C_φ → QP 求 a_cbf/a_clf → 用 a_rl+a_cbf+a_clf 推进环境 → 算奖励 → 用所选 RL 算法(PPO)更新策略。

## 数据集 & 实验设置
纯仿真,单个连续控制导航任务:
- **环境**:一个已知动力学的 agent;两条直线构成的"通道(channel)"作为安全约束;三个圆形目标区(episode 内固定、episode 间随机);两个动力学未知、在通道附近移动的障碍物。
- **agent**:独轮车模型(unicycle),状态为 [x,y,θ]+所有目标与障碍位置共 13 维连续,加 1 维 FSA 离散态共 14 维;控制为前进速度与转向速度;用偏离中心的参考点把欠驱动系统化为全驱动。
- **任务公式**:φ=(♦ψg1∨♦ψg2)∧♦ψg3∧(¬ψg3 U (ψg1∨ψg2))∧((ψc1∧ψc2) U ψg3),即先到 g1/g2 再到 g3,到 g3 前不能进 g3、且全程留在通道内;额外奖励 r=与最近障碍的最小距离。
- **RL**:PPO,前馈网络 3 隐层(300/200/100 ReLU),值函数同构;episode 长 200 步,每次更新收 5 条轨迹;训练时允许越界/碰撞(吃惩罚),评估时不允许且 CBF 恒开。
- **对比配置**:仅 RL / RL+CBF / RL+CLF / RL+CBF+CLF 四组。

## 主要结果 & 结论
- **最终性能**四组相近;带 CLF 的早期上升更快(探索更高效),但学习曲线方差、波动更大——因为 CLF 不知道移动障碍和安全约束,只管把 agent 引向下一个目标,临近碰撞/越界时 RL 要"对抗"CLF,增加学习难度(RL+CLF+CBF 最明显)。
- **安全约束**:带 CBF 的配置在训练全程零违反;无 CBF 的靠惩罚逐渐学会少违反但非零。
- **与障碍距离**:随训练增大;无 CBF 反而能离障碍更远(因为它可以越界绕路)。
- **评估成功率(20 次)**:带 CBF 的成功率更高——无 CBF 的策略训练时依赖越界绕障,评估禁止越界后容易卡在安全区边界。
- **轨迹案例**:CLF+CBF(无 RL)会被 CBF 卡在边界且会撞障碍(CLF/CBF 都不知障碍动力学);RL+CLF+CBF 学会在边界放弃 g2 转去 g1 完成任务。
- **实践问题**:大量超参(c_r, w, K, α, c3, 动作界)显著影响结果;建议 CBF 动作界宽、CLF 动作界比 RL 窄并随训练收缩(类似有演示的 guidance scheduling),未来要减轻调参负担。

## 核心贡献
1. 提出把 FSA 一物三用(给 RL 奖励、给 CLF 选目标、给 CBF 定安全集)的统一方式。
2. 扩展 FSA-augmented MDP,用 trap state 处理"规范违反"与硬约束。
3. 把整套整合进可高效求解的二次规划(CLF-CBF-QP)。
4. 在带安全约束、已知 agent 动力学+未知环境动力学的连续控制任务上验证,并逐组件消融分析。

## 局限与我的质疑
1. **作者自述:超参敏感、调参负担重**。c_r、w、K、α、c3 和各动作界对学习过程和最终性能影响明显,作者把"减轻调参"列为重要未来工作。这等于承认当前框架要让它工作很大程度靠人工调,泛化性存疑。
2. **CLF/CBF 不知道未知动力学,导致护盾不完整**。论文自己展示:CLF+CBF 配置仍会撞移动障碍,因为避障需要障碍动力学而 CBF/CLF 都没有。也就是说"安全保证"只对**已写进谓词的、静态/已知的**约束(通道边界)成立,对真正动态、未知的危险(移动障碍)CBF 并不能硬保证——而后者恰恰是物理系统最危险的部分。标题里"safe"的承诺被悄悄缩小了范围。
3. **实验极其单薄,结论被过度外推**。只有**一个**2D 独轮车导航的仿真任务、动力学已知、20 次评估,没有真机、没有 sim-to-real(尽管动机大谈 sim-to-real 困难)、没有与其他安全 RL 基线(如 CPO、Cheng 2019 的 barrier RL)定量对比,只做了自家四配置消融。"我们的方法相对易实现、能处理连续/非线性"等论断缺乏跨任务、跨基线的证据支撑。
4. **CBF 要求显式仿射控制系统 + 可微 h(s) + 谓词写成 f(s)>0**,意味着安全集必须能解析地写成不等式;对高维感知(图像)输入、接触丰富、或无法解析建模的系统不适用。CLF 目标选择还用了"区域中心=最大鲁棒度状态"这种启发式,只在谓词是简单几何区域时成立。
5. **与"RL 训练数字人与环境交互"主题相比的不足**:本文是低维点状 agent 的导航/安全控制,既没有高维身体(humanoid/角色动力学)、没有丰富物理交互或操作、也没有人在环或拟人行为;14 维状态、独轮车模型离"数字人与环境交互"还很远。它的价值是**方法论借鉴**——用时序逻辑表达复杂多阶段任务、用 CBF 给探索上硬安全护栏——而非可直接迁移到数字人场景的实证。把逻辑规范当奖励来规避 reward hacking、把安全约束做成 QP 护栏,这两点对数字人交互的安全训练有参考意义,但其"已知解析动力学 + 低维 + 单任务"的设定使其结论不能直接外推到高维交互式数字人。
