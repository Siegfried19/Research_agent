# Deep dive into model-free reinforcement learning for underwater locomotion: theory and practice.
> Jiao Y, Ling F, Heydari S, Heess N, Merel J, Kanso E · 2026 · Bioinspiration & biomimetics · 引用 0 · DOI 10.1088/1748-3190/ae4930

## 一句话
一篇面向流体力学/生物力学/机器人背景新手的**教程**(tutorial),自成体系地讲清楚如何把"水下游动"建模成一个无模型强化学习(model-free RL)问题,并落到 actor-critic / PPO 的数学推导与工程实现细节。

## 解决了什么问题
RL 的算法和代码越来越易得,但把一个"具身(embodied)反馈控制问题"——一条鱼或水下机器人通过身体与流体环境交互——formulate 成 RL 问题时,背后那些**建模假设和选择**(状态/观测/动作/奖励怎么定、物理在哪进来、部分可观如何处理)往往不透明。本文为物理与生物科学、工程领域的 RL 新手补上这层"从物理到 RL 公式"的桥梁。

## 用什么方法解决的
不是提新算法,而是**系统性梳理 + 推导 + 实践指南**:①从 MDP/POMDP、轨迹、回报、策略梯度(REINFORCE)一路推到 actor-critic 的 advantage 公式;②讲 critic 近似(K 步截断 vs bootstrap、bias-variance 权衡、TD)、TRPO/PPO 的信赖域/裁剪机制、on-policy vs off-policy(DDPG/TD3/SAC)的取舍;③用文献里 5 个水下游动实例(连续变形体/刚性连杆/自驱动粒子 × CFD/势流)归纳如何选观测、动作、奖励;④给出针对水下系统的逐项建模 checklist(初始分布、egocentric 观测、动作空间、奖励 shaping、终止条件、决策步长、可复现性)。附录给出 PPO 完整伪代码与公开 GitHub 实现。

## 动机 & 背景
水生动物在复杂多变的流场中要把丰富的感觉流转化为协调动作以完成觅食、避敌、导航等目标,其底层(神经回路级)决策机制在神经科学/生物力学中仍是难题。作者用"感觉运动反馈环"(图1A)概念化这一过程:神经系统发运动指令→肌骨系统使身体变形→变形经流体作用产生运动→感觉模态再反馈。仿真身体和仿生机器人成为研究这类"具身智能"的可行抓手,而 RL 作为一种**优化框架**,特别适合非定常、动态变化的流环境——区别于经典优化,RL 寻找能随经验适应、变化的控制律。文章明确目标:不是综述所有 RL 方法,而是帮新手理解 RL 的数学概念并把它应用到与水下环境交互的具身 agent。已有 Sutton&Barto、Silver、Murphy 等优秀入门材料,但"为物理身体求感觉运动策略"这一设定与传统 RL 关注点不同,本文据此展开。

作者把世界划分为:agent(负责感觉运动决策的抽象单元)、body(agent 控制并借以感知的身体)、environment(身体之外不可直接控制的一切)。强调这种划分是**建模选择**,需逐案评估;并指出 RL 不是要复刻动物神经反馈环,而是提供一种系统提问的方式(某行为需要什么信息、哪些感觉线索提升鲁棒性、什么目标函数最能复现观测到的运动模式),可通过消融感觉输入、改形态、变环境来分析训练好的策略,从而把建模假设与可对照数据的行为预测连起来。

## 方法细节
**数学框架(第2节)**:学习策略 π(a|o),状态 s 含身体形状/流场位置/周围流场,观测 o 是 agent 真正能感的(局部流速、压力、视觉、本体感觉),动作 a 对应身体驱动。状态按物理(动量守恒等)演化,构成 MDP;只有部分观测时为 POMDP——作者强调"几乎所有现实控制问题都是 POMDP",观测设计与引入记忆至关重要。定义轨迹分布 p_θ(τ)、折扣回报 R_t、目标 J(θ)=E[R_0]。

**策略梯度(第2.3节)**:用"似然比技巧"∇p=p∇log p,推出 ∇J 可只靠采样轨迹估计、不需对物理转移 P(s'|s,a) 求导——这就是 "model-free" 的含义,也是 REINFORCE 思想。指出朴素 PG 方差高、对学习率敏感。

**Actor-Critic(第3节)**:用期望回报 Q、V 替代单轨迹回报,引入 advantage A=Q−V(V 作 baseline 降方差),改写策略梯度;证明见附录 A、B。**Critic 近似(第4节)**:K 步截断估计 vs K 步 bootstrap 估计;给出 bias-variance 权衡(bootstrap+小K大γ→低方差;截断+大K小γ→低偏差,但需长轨迹),K=1 即 TD 学习。部分可观下把 st 换成 ot,承认这破坏了 advantage 替换的数学严谨性(可能两个回报不同的状态有相同 advantage),但配合观测设计与记忆,实践上对水下问题有效。

**训练(第5节)**:episode 结构、神经网络参数化 actor/critic(连续动作用高斯策略输出均值方差,重参数化技巧)、TRPO(用 KL 散度约束信赖域)与 PPO(裁剪概率比,ε=0.2)。区分 on-policy 的"批内多 epoch 复用"与 off-policy 的"replay buffer 复用";比较 PPO(稳定易实现但样本效率低)与 DDPG/TD3/SAC(样本效率高但对奖励缩放/超参/逼近误差更敏感)。强调熵奖励促进探索。附录 C 给出 (soft) clipped PPO 完整目标函数与两段伪代码(环境仿真 + 网络更新),并指向 GitHub 仓库 RL3linkFish。

## 数据集 & 实验设置
本文是 tutorial,**未产生或分析任何新数据**(原文 Data availability 明确声明)。"实验设置"以表1的 5 个文献实例呈现,覆盖建模谱系:
- Gazzola 2014:连续变形体 + 2D CFD,动作=3 条曲率 profile,奖励=与目标轨迹距离 → 轨迹跟踪(Q-learning,无神经网络);
- Gazzola 2016:自驱动粒子 + 势流,离散动作(3 种速度、左右转)→ schooling;
- Verma 2018:连续变形体 + 2D/3D CFD,动作=5 种行波幅值,观测含相对位置/近期动作/尾拍相位,奖励=侧向偏差或游动效率 → schooling;
- Jiao 2021:三连杆刚性体 + 势流,动作=连杆间角速度,观测=目标方向,奖励=到目标距离变化 → 游向目标;
- Jiao 2025:自驱动粒子 + 预计算 2D CFD,动作=游动者角速度,观测=目标位置/流速/流梯度,奖励=距离变化+到达奖励 → 点到点导航。

## 主要结果 & 结论
作为教程,"结果"是**提炼出的建模指南(第6节)**:
- **初始化**:精心设计 P(s0) 形成"课程学习",随训练动态调整难度;
- **egocentric 观测**:观测应以身体为中心、对空间变换不变;讨论部分可观程度(全图规划 vs 盲 agent vs 中间),警告全状态高维反而引入噪声;强调生物合理性,并提出"可给 critic 喂特权信息而保持 policy 输入生态合理"的非对称技巧;
- **动作空间**:位置/力矩/类肌肉控制的选择应匹配形态与驱动极限,学习友好性常比底层可实现性更重要;
- **奖励**:稠密 shaping(如 exp[−γ‖x_ref−x‖²])vs 稀疏奖励,需反复反向工程以防意外行为;
- **终止条件**:正常/成功终止用 value bootstrap,失败终止用截断;警惕 agent"自杀"或徘徊刷低奖励等边缘案例;
- **决策步长**:应粗于物理步长、反映反应时,否则学出不真实策略;
- **可复现性**:深度 RL 对随机种子/超参敏感,单个策略应被视为"一个可行解而非唯一解",建议多种子、报告分布而非最优;神经网络是黑箱,可通过分析行为/步态/低维序参量或拟合可解释代理模型来支持科学理解。

结论部分指向更高级方向:RNN、Transformer、KAN、LLM 增强 RL,以及用 RL(尤其模仿学习/逆 RL)以数据驱动方式复现/扩展生物行为策略(如斑马鱼逃逸)。

## 核心贡献
1. 一篇自成体系、面向物理/生物/机器人新手的 model-free RL(聚焦 actor-critic)**水下locomotion 教程**,明确指出"物理建模选择在数学公式何处进入";
2. 从 REINFORCE 到 advantage、再到 PPO 的**完整可读推导链**(含附录 A/B 证明与 PPO 伪代码、公开代码);
3. 用 5 个文献实例归纳的**观测/动作/奖励建模谱系**(表1)与一套**逐项的水下系统建模 checklist**(第6节);
4. 强调把 RL 当作**提问/做科学的工具**(可复现性、消融、行为级可解释性),而非单纯求解器。

## 局限与我的质疑
- **作者自述局限**:①POMDP 下用 ot 替 st 破坏了 advantage 推导的严谨性,可能出现"不同回报、相同 advantage"的退化,作者承认这点仅靠"观测设计+记忆"在实践中绕过,缺乏理论保证;②深度 RL 对种子/奖励 shaping/超参高度敏感,单个策略不能当唯一解;③神经网络策略是黑箱,参数级机制不可直接解读,只能退而做行为级分析。这些都是诚实但**未被本文解决**的开放问题。
- **教程性质 = 零实证增量**:本文不产生新数据、不提新方法、不做任何对照实验(连引用都还是 0)。所有"结论"都是对他人工作的二手归纳和经验性建议(如"决策步长应粗于物理步长""egocentric 更好"),**缺少本文自己的消融或基准来支撑这些 guideline 的普适性**——读者只能当作经验法则而非被验证的结论。
- **方法覆盖偏窄且略陈旧**:正文主线几乎只讲 on-policy 的 PPO/TRPO,off-policy(SAC/TD3)仅一段文字带过、无推导;对样本效率这一真实机器人最痛的点着墨不足;Transformer/RNN/LLM/逆 RL 全部塞进结论一句话,没有展开。对"水下"这一卖点,真正水下特有的难题(流场部分可观、传感器物理约束、sim-to-real 间隙)只有定性讨论,**没有量化的失败案例或对比**。
- **与本研究主题("RL 训练能与环境交互的数字人")的差距**:本文的"具身"是鱼/水下游动者,身体多被简化为连续变形体、三连杆或自驱动粒子,**不涉及高自由度人形/数字人、全身控制、肌骨驱动或人机交互**;奖励与任务都是单一预定目标(到点、跟轨迹、schooling),没有多任务、层级控制、模仿动捕、与人协作等数字人场景。它对我们有用的是**底层算法直觉(actor-critic/PPO 推导、观测/奖励设计哲学、可复现性纪律)**,但在"训练数字人与复杂环境/人交互"这一目标上,本文的任务复杂度、身体保真度和交互维度都明显不足,只能当作打基础的入门读物,而非可直接迁移的方法参考。
