# Leveraging exploration in off-policy algorithms via normalizing flows
> Bogdan Mazoure, Thang Doan, Audrey Durand, R Devon Hjelm, Joelle Pineau · 2019 · arXiv · 引用 0 · DOI arxiv:1905.06893

## 一句话
用 normalizing flows(归一化流)把 SAC 的单峰高斯策略换成可表达多峰分布的策略,在连续控制任务上提升探索能力、加快收敛,且策略参数量大幅缩小(低至 SAC 的 5.5%)。

## 解决了什么问题
SAC 作为最大熵 off-policy 算法虽探索能力强,但其策略被限制在有闭式熵的分布(单峰对角高斯)上,在欺骗性奖励/稀疏奖励/多局部最优的高维控制(如 humanoid)中,对称的高斯策略要么过早收敛到次优解、要么乱探索掉进负奖励区,无法同时"走安全路径"且"到达高奖励区"。

## 用什么方法解决的
在 SAC 的策略输出端串接一段长度为 N 的可逆变换(normalizing flows,主用 radial flow,也试了 planar、IAF):先从状态相关的基础高斯采噪声,再经流变换得到动作。这样策略可表达多峰、非高斯分布;训练时沿用 SAC 的 KL(策略‖Boltzmann-Q)目标,只是策略对数似然多了各层流的对数雅可比项,算法上只比 SAC 多一步对流层参数 φ 的梯度更新(Algorithm 1)。重正则化下流退化为恒等映射,故 SAC 是 SAC-NF 的特例。

---

## 动机 & 背景
- 强化学习解连续控制时常探索不足,高维机器人任务(腿、臂、姿态等多控制因子组合)有大量局部最优;humanoid 中存在很多次优"前进"策略,环境一变就崩。要避免过早收敛,需要好的探索策略。
- SAC 通过给可微策略目标加最大熵奖励项来鼓励探索,且作为 off-policy 算法样本效率高(机器人实验昂贵,这点很关键)。但其策略局限于有闭式熵的分布(单峰高斯),作者认为这损害了探索。
- normalizing flows 是强力密度近似器:把简单初始噪声分布经一串可逆光滑变换映射到复杂后验。radial flow 表达力强、参数极少、有闭式行列式。此前 NF 已用于 on-policy(IAF 扩展 TRPO);本文针对 off-policy,聚焦 planar/radial flow。
- 与 HSAC(用 real NVP + 分层策略、每层优化不同奖励)相比,本文方法更简单:所有 NF 层在单一奖励上联合训练、无额外条件,贴近原始 SAC 却显著超越 SAC 与 HSAC。

## 方法细节
- 策略采样:ε∼N(0,I) → 状态-噪声嵌入 h(ε,sₜ)(给出状态相关均值 μ(sₜ),尺度矩阵有两种:state-dependent 条件式 j=1 / state-independent 平均式 j=2)→ 经 N 层流 fφ 复合得到动作 aₜ。
- radial flow 形式:f(z)=z+β/(α+‖z−z₀‖)·(z−z₀),取 β≥−α 保证可逆,围绕可学习中心 z₀ 做同心扩张。
- 训练目标与 SAC 一致(最小化策略与 Boltzmann-Q 的 KL),策略对数密度 = log q₀(a₀) − log|det L| − Σ log det(∂fᵢ/∂aᵢ₋₁);损失梯度用 Monte-Carlo 近似。
- 算法:在 SAC 的 V、Q、基础策略 θ 更新之外,增加对流层 φ 的梯度步(αφ=3e-4);流层训练开销相对很小,运行时间与 SAC 基本相同。
- 与变分推断关系:利用最大熵 RL 与 ELBO(证据下界)的联系来优化。

## 数据集 & 实验设置
- 三类实验:① 欺骗性奖励的 2D 导航玩具任务(高奖励区藏在负奖励"坑"后面);② MuJoCo / Rllab / PyBullet Roboschool 连续控制基准 + 一个稀疏奖励 MuJoCo 任务(SparseHumanoid);③ radial 策略多峰性/形状分析。
- 模型:SAC-NF 策略 = 1 个 256 单元前馈隐层做状态嵌入 + 长度 N∈{3,4,5} 的流;SAC 基线 = 2 个 256 单元隐层。Adam,学习率 3e-4,batch 256,replay buffer 1e6。
- 评估:每 10,000 环境步评估 10 次取平均(噪声置 0);所有曲线 5 个随机种子平均,Savitzky-Golay(窗口 7)平滑;表中报最大平均回报 ± 1 标准差。1M/2M/3M 步视任务而定。全部用单 CPU、8GB 内存。
- 多峰性测度:gap statistic(k-means 选簇数)判断模数、skewness/kurtosis 判断非高斯;另算 NF 策略与单位高斯的 KL 随训练增大。

## 主要结果 & 结论
- 欺骗性导航:vanilla SAC 要么保守留在黄区、要么乱探索掉坑;加 3 层 radial flow 后 SAC-NF 能沿安全路径绕行到达绿色高奖励区。4-goal 任务中 SAC-NF 能访问全部 4 个模态。
- MuJoCo(表1,最大平均回报):SAC-NF 在多数任务更优,尤其 Humanoid-rllab(2079→5531)、Walker2d(3813→5196)、Ant(4372→4912)、Hopper(3095→3538);HalfCheetah 反而更低(11410→8429);Humanoid-v2 基本持平。稀疏 SparseHumanoid:88→547,明显更好。
- 参数效率:SAC-NF 用远少参数达到甚至超过 SAC——Hopper 仅约 5.5%–6%(70,406→3,861),Walker/HalfCheetah ≈0.09,Humanoid-v2 ≈0.6。缩小 SAC 自身参数(64/128 单元)一般会变差。
- PyBullet Roboschool(表2):radial flow 在三个 humanoid 环境上一致排名最好(Humanoid 1263→1755),planar/IAF 时好时坏(Flagrun Hard 出现负值)。
- 与 TD3 对比(表5):TD3 在 Humanoid-v2(71)、Humanoid-rllab(286)、SparseHumanoid(0)上几乎学不动,SAC-NF 大幅领先。
- 形状分析:训练中 NF 策略与高斯的 KL 持续增大;gap statistic 差值远大于 SAC(SAC 全部 <1);负的 excess kurtosis 与 skew → 策略确实非高斯、多峰、不对称。
- 结论:SAC-NF 能更快发现更丰富策略、把笨重高斯策略压缩成轻量网络、更好避开局部最优。未来工作:研究泛化性与理论性质、从富仿真器迁移到真机。

## 核心贡献
1. 提出 SAC-NF:用 normalizing flows 把 SAC 扩展到多峰策略类,实现简单(只多一步流层梯度更新),且 SAC 是其特例。
2. 实证证明在欺骗性奖励、稀疏奖励、多个连续控制基准(MuJoCo/Rllab/PyBullet)上收敛更快、性能更好。
3. 显著的参数效率:用低至 5.5% 的策略参数达到或超过 SAC,并系统比较了 radial/planar/IAF 三类流(radial 最稳)。
4. 提供多峰性/非高斯性的量化证据(gap statistic、KL、skew/kurtosis)。

## 局限与我的质疑
1. **未经同行评审确认 / 来源信息不全**:本条目标为预印本(arXiv:1905.06893,引用计入为 0,且元信息标注为预印本)。虽然文末注明投稿 CoRL 2019,但应对其数字与结论保留态度——下述质疑大多源于正文自报数据,未经第三方复现。
2. **结果不一致且方差巨大,"普遍提升"被过度概括**:HalfCheetah 上 SAC-NF 明显更差(8429 vs 11410),论文用"better convergence/sample efficiency"淡化了这点。更严重的是 Humanoid-rllab 的 5531 ± **4435**——标准差几乎与均值同量级,说明结果由极少数幸运种子撑起;PyBullet Flagrun 也出现负回报。仅 5 个种子、报"最大平均回报"(best observed)而非最终稳定回报,容易夸大优势(cherry-picking 风险)。
3. **机制解释偏叙事、缺对照**:作者把改进归因于"多峰探索",但参数量同时大幅下降,二者混杂——到底是多峰带来探索增益,还是流层起了正则化/归纳偏置作用?缺乏关键消融(如固定参数量下纯加宽 vs 加流、或在相同参数预算下公平对比)。多峰性证据(gap statistic、kurtosis)是事后描述性统计,并未直接因果联系到回报提升。
4. **无理论保证、无方差/稳定性分析**:off-policy + 表达力更强的策略本身可能加剧不稳定;论文未讨论 NF 是否带来训练不稳或对超参(流长度 N、α)的敏感性,N 在不同任务间从 2 到 5 手调,泛化性存疑。作者自己也把"理论性质"列为未来工作。
5. **与本主题(RL 训练数字人与环境交互)契合度有限**:实验全在 MuJoCo/PyBullet 仿真 humanoid 的纯运动控制(locomotion),奖励是前进/距离,**不涉及与人或环境的交互、社交/沟通、感知-反馈闭环**。它能为"数字人底层运动策略的探索"提供一个轻量、强探索的策略改进件,但对"可与环境/用户交互的数字人"这一层(高层意图、多模态、人机协同)几乎没有直接证据;sim-to-real 也只是愿景而非验证。
6. **计算与可复现细节单薄**:全程单 CPU、最多 3M 步,humanoid 这类任务通常需要更长训练;论文承认未在简单环境(如 Reacher)上比较(称"提升不值一提"),这种选择性报告进一步削弱了"普适提升"的说服力。
