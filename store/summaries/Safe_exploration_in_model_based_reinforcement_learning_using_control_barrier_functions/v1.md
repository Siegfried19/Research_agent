# Safe exploration in model-based reinforcement learning using control barrier functions
> M. Cohen, Călin Belta · 2022 · Automatica · 引用 83 · DOI 10.1016/j.automatica.2022.110684

## 一句话
本文提出一个 model-based RL（MBRL）框架，在线学习无限时域最优控制问题的值函数与不确定系统的漂移动态，并用一类新构造的"类 Lyapunov 控制屏障函数（LCBF）"把安全保证从学习过程里解耦出来——让系统去**安全地学习一个性能驱动策略**，而不是像以往那样只能"学一个安全策略"（"This paper develops a model-based reinforcement learning (MBRL) framework for learning online the value function of an infinite-horizon optimal control problem while obeying safety constraints expressed as control barrier functions (CBFs)."，p.1 摘要）。

## 解决了什么问题
安全学习控制的核心张力是：要探索就得去访问没去过的状态，但探索可能撞上安全约束。以往把 CBF/值函数耦进 RL 的方法（如把 CBF 项塞进代价函数）存在一个被作者点名的隐患——安全证书（safety certificate）依赖于值函数收敛，而收敛又取决于实践中无法验证的激励条件，于是"安全"与"学习"被绑死。作者的目标是**把学习与安全解耦**：让安全在任何时刻都成立，且不依赖任何与学习相关的条件。

## 用什么方法解决的
两块拼起来：① 一个能保证安全的"保护控制器"，以最小侵入方式罩在任意学习策略外面；② 一个用"模拟经验"在线逼近最优值函数/策略的 MBRL 框架。安全靠 ① 在每个时刻独立保证，性能靠 ② 学习，二者用**两套不同策略**（探索用学习策略、部署用安全策略）实现解耦。

## 动机 & 背景
作者把方法定位为对"统一 CLF 与 CBF"传统路线的推进：传统 CBF 方法需要同时构造一个有效的 CLF（镇定）和 CBF（安全）；本文指出，由于这里考虑的最优控制问题的值函数本就是一个 CLF，"只需构造一个有效的 CBF 就能同时拿到稳定与安全，还额外能处理部分未知动态"。相比把 CBF 写进代价函数的做法（[6,27] 等），那类方法是在"**学一个安全策略**"，安全要等策略收敛才兑现；本文要做的是"**安全地学一个性能策略**"——"the aforementioned methods aim to learn a safe policy, whereas our safe exploration framework allows for safely learning a performance-driven policy"（p.2）。与最接近的前作 [16,17] 的区别在于"探索（学习策略）与在原系统上部署（安全策略）用了不同的策略，这使收敛性分析更复杂"（"different policies are used for exploration (learned policy) and deployment on the original system (safe policy), which complicates the resulting convergence analysis."，p.2）。

## 方法细节
**① 类 Lyapunov CBF（LCBF）。** 受 [28] 的类 Lyapunov 屏障函数启发，作者用"重新中心化的屏障函数"（"we consider the following recentered barrier function"，p.3 式5）构造 LCBF：`B(x) := (b(x) − b(0))^2`，其中 `b` 是候选 CBF。`B` 被证明满足三条关键性质（"B can be shown to satisfy the important properties"，p.3）：在 Int(C) 内下确界 ≥ 0、在原点为 0、趋向安全集边界 ∂C 时趋于无穷。与标准 CBF 的首要区别是 **B 在原点处消失**——"The primary distinction between standard CBFs and LCBFs is that B vanishes at the origin, which will become important when combining the subsequently designed safeguarding controller with a nominal stabilizing policy."（p.3）。这一点正是它能和镇定策略叠加而不破坏原点平衡的关键（正半定性使保护项在原点不产生多余控制）。

**② 保护控制器（safeguarding controller）。** 作者提出 `k_b(x) := −c_b·g(x)^T·∇B(x)^T`（"we propose the following safeguarding controller"，p.3 式6），`c_b` 是增益。Theorem 1 证明：在 Assumption 1 下，单用 `u = k_b(x)` 就能让 Int(C) 对闭环系统前向不变（"Provided Assumption 1 holds, the controller u = k_b(x) … renders Int(C) forward invariant for the closed-loop system (1)."，p.4）。Corollary 1 进一步把它做成可叠加的安全滤波器：`u = k(x,t) + k_b(x)` 在保证前向不变的同时"ensures the origin is an equilibrium point for the closed-loop system"（p.4）。证明思路是对 B 沿闭环求导后做上界估计，证明在逼近 ∂C 时 Ḃ → −∞ < 0，从而轨迹无法穿越边界。`c_b` 是需要人调的设计参数：取小则保护项只在 ∂C 附近占主导（更接近"最小侵入"），但实践中过小会导致控制量幅值过大或变化过快。

**③ MBRL / 逼近动态规划。** 镇定策略来自一个无限时域最优控制问题：最小化代价泛函，被积项为 `x^T Q x + u^T R u`（"A general way to search for a CLF is to find a control policy that minimizes the infinite-horizon cost functional"，p.5 式10），`Q` 正定、`R` 对称正定。对 HJB 方程右端取极小给出最优反馈策略 `k*(x) = −(1/2)R^{-1}g(x)^T∇V*(x)^T`（"yields the optimal feedback control policy as"，p.5 式13）。值函数未知，用 **StaF 核**沿轨迹做局部逼近 `V*(y) = W(x)^Tφ(y,c(x)) + ε(x,y)`，"只在跟随系统轨迹的小邻域 B_i(x) 上表示值函数"（"the value function (11) can be represented at points"，p.5 式14）。漂移动态也未知，假设可线性参数化 `f(x) = Y(x)θ + ε_θ(x)`（"can be expressed as a linear combination of weights"，p.6 式16），权重 θ 在线由自适应控制（积分并发学习）辨识。

**④ 经"模拟经验"安全探索。** 实际加到原系统上的控制策略（式19）= 学习策略 + 保护项 `−(c_b/2)R^{-1}g(x)^T∇B(x)^T`（"develop a safe exploration framework for learning V*…"，p.6 式19）。探索的精髓在于不必真的把系统开到危险状态去采数据：Bellman 误差"可在状态空间任意点用一个**不同的**策略来评估，以生成更有代表性的数据"（"the BE can be evaluated at any point in the state-space [17] using a different policy to generate data more representative of (18)."，p.6）。这些外推（extrapolated）轨迹上用的探索策略**不带保护项**——"the exploratory policy u_i is not augmented with the safeguarding controller, thereby allowing for maximum exploration of the state-space … without risking safety violation of the original system."（p.6）。也就是说：在"想象"里放开手脚探索整个状态空间，在真实系统上始终戴着安全护栏。

**收敛性（证明了什么）。** Proposition 1 证明式19 的策略 + 权重更新律仍使 Int(C) 前向不变。Theorem 2 在 Assumption 1–3 下证明复合误差状态 `Z(t)`（含状态、值函数权重误差、策略权重误差、参数辨识误差）**一致最终有界（UUB）**——"Z(t) is uniformly ultimately bounded such that (27) holds."（p.8）。需注意这是 UUB（收敛到原点附近一个有界球），不是渐近收敛到精确最优；且作者在 Remark 3 自陈，UUB 的充分条件依赖 ε、ι 等"未知或由轨迹决定"的量，因而无法事先形式化保证（见下"局限"）。

## 数据集 & 实验设置
纯数值仿真，无真实数据集；两个例子。

**例1·非线性系统（取自 [15]）。** 二维系统，漂移项未知但线性于未知参数（取 `ε_θ ≡ 0`，"The drift is assumed to be unknown but linear in the unknown parameters"，p.8），真值 `θ = [−0.6, −1, 1]^T` 在线辨识。安全集 `h(x) = p·x2^2 − x1 + 1`，`p ∈ {−1,1}` 决定 C 凸（p=−1）或非凸（p=1，"defined by h(x) = px…"，p.8）；保护控制器取 `b(x) = 1/h(x)` 据式5 构造 LCBF。值函数用 **L=3 个 StaF 多项式核** `φ_i = x^T c_i(x)` 逼近，核中心放在绕当前状态的等边三角形顶点（"approximated using a basis of L = 3 StaF kernels"，p.8）。学习按 §5 把 Bellman 误差外推到绕 x 的均匀分布方格内一个点上、漂移参数用积分并发学习辨识（"The learning procedure outlined in Sec. 5 is carried out by extrapolating the BE to one point from a uniform distribution"，p.8）；增益 `k_c1=0.1, k_c2=1, k_a1=1, k_a2=0.1, γ_c=1, β_c=0.001`，权重初值 `[0.5,0.5,0.5]^T`，`Γ(t0)=100I3`（凸例 c_b=1；非凸例改 c_b=0.001、Γ(t0)=10I3）。

**例2·避障。** 二维单积分器 `ẋ = u`，导航到原点同时避开圆形障碍，安全集 `h(x) = ||x − x_o||^2 − r_o^2`（"Consider a mobile robot modeled as a two-dimensional single integrator"，p.9）。把式19 的 RL 策略与解代数 Riccati 方程（ARE）得到的 LQR 策略对比，两者都罩同一保护控制器（c_b=0.1，权重全初始化为 1，Γ(t0)=10I3）。

## 主要结果 & 结论
- **安全护栏有效且最小侵入（例1，观测于该仿真）。** 式19 + 保护控制器把 x(t) 镇定到原点且全程不离开安全集；去掉保护项则系统仍被镇定但**多次违反安全约束**——"the RL policy in (19) augmented with the safeguarding controller stabilizes x(t) to the origin without leaving the safe set. Without the safeguarding component, the RL policy stabilizes the system, but violates the safety constraints multiple times."（p.9，图1/图2）。带/不带护栏的轨迹在逼近 ∂C 之前几乎重合，体现"只在必要时介入"的最小侵入性。
- **对比"把 CBF 塞进代价函数"的方法。** 该对比法初期会违反安全约束、要等策略收敛后才"converges to a safe policy"（p.9）——直观印证了作者的核心论点：把安全绑在学习收敛上，收敛前就有违约窗口；本文方法把安全前置到每一时刻。
- **能处理更一般的约束（作者声称，有该例支撑）。** 作者称上述非凸安全集"无法被 [11,26,39] 处理，因为约束不是 a_i < x_i < ā_i 的超矩形形式"（"such a set cannot be rendered safe using the approaches from [11, 26, 39] as the constraints are not of the form"，p.8）。
- **避障：动态反馈胜过静态 LQR（观测于该仿真）。** RL 策略绕过障碍并收敛到原点，而 LQR "gets stuck behind the obstacle"（p.9–10）。作者给出机制解释：LQR 是**时不变**反馈，无法同时实现避障与镇定两个目标；而 RL 策略因权重 Ŵ_a 在线演化是**时变**的，等价于一种非线性动态反馈，故能脱困（"LQR policy … is a continuous time-invariant feedback controller and can therefore not achieve dual objectives of obstacle avoidance and stability from certain initial conditions"，p.10）。

结论（"we developed a safe MBRL framework that allows to learn online the value function … and the drift dynamics of an uncertain control affine system while satisfying safety constraints given as CBFs."，p.10）：框架在线学值函数与不确定漂移、同时满足 CBF 安全约束；未来工作含把 zeroing CBF 纳入框架。

## 核心贡献
1. **新工具——LCBF**：重新中心化得到的、正半定且在原点消失的一类 CBF，使"安全护栏"能与镇定策略无缝叠加（Theorem 1 + 式5/6）。
2. **安全与学习解耦**：安全在每一时刻独立成立、不依赖任何学习收敛条件；这是相对 [6,9,11,26,27,39] 把值函数当安全证书那一路的本质区别。
3. **双策略安全探索**：探索用不带护栏的策略在"模拟经验"里放开探索整个状态空间，部署用带护栏的安全策略在真实系统上跑；并给出 UUB 收敛性分析（Proposition 1 + Theorem 2）。
4. **更一般的约束 + 动态反馈优势**：非凸安全集、避障两个数值例展示了超出超矩形约束的能力，以及时变 RL 策略相对静态 LQR 的脱困优势。

## 局限与我的质疑
1. **作者自述：UUB 充分条件不可事先验证。** Remark 3 明确承认，保证 UUB 的充分条件（式25）依赖 ε、ι 等"未知或完全由系统轨迹决定"的量，"因此无法事先形式化保证其满足"。换言之，**性能/收敛侧没有先验保证**——能形式化兜底的只有安全（前向不变性）。这把方法的"卖点"清晰地一分为二：安全是硬保证，学习好坏是经验性的。
2. **激励/持续激励（PE）条件仍在，只是搬了地方。** Assumption 3 要求 PE 类条件，作者说可通过在外推映射里加探针信号"启发式满足"，且 N 个外推点的条件"随状态维数扩展性差（scales poorly with the state dimension）"（p.7 脚注8）。所以"解耦"解的是**安全对学习的依赖**，并没有消掉学习本身对激励/维数的老问题——高维系统可扩展性存疑。
3. **实验规模极小、全是低维仿真。** 两个例子都是 2 维、单输入/双输入、解析已知的玩具系统，且漂移被设成线性参数化（例1 甚至 ε_θ≡0，即无重构误差）。没有更高维、强非线性建模误差、或任何物理/真实数据的验证。"能处理更一般约束"主要靠一个非凸例**展示**，而非系统性基准对比，证据强度有限（observed/supported，不能读成普适结论）。
4. **基线偏弱、对比不够硬。** 避障里的对比是静态 LQR——一个先天无法做时变避障的基线，"胜出"几乎是设定决定的；与"CBF 塞进代价函数"的对比也只在单个例子上定性展示。缺与近年更强的安全 RL / 约束 MPC / 可达性方法的定量横评。
5. **保护增益 c_b 是个需手调的痛点。** 作者自陈 c_b 取小理论上更"最小侵入"，但实践会导致控制量幅值过大或剧烈变化，"必须由用户针对具体问题谨慎选择"（p.5）。这意味着安全护栏的实际表现对一个无自动整定办法的超参敏感，复用时要留意。
6. **对本研究主题（RL 通用工具箱）的定位**：这是一篇**控制论味很重**的工作（自适应控制 + ADP + CBF），其"RL"是连续时间 actor–critic/值函数逼近，而非主流深度 RL；安全保证强、但被牢牢绑在"控制仿射 + 漂移线性参数化 + 已知 g(x)"的结构假设上。作为"安全探索"工具，它的价值在于**可证明的安全护栏这一思想**，而非可直接搬到高维深度 RL 任务上的现成算法——迁移到无模型/高维场景需要大量额外工作。
