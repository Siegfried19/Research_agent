# Beyond Words: Infusing Conversational Agents with Human-like Typing Behaviors
> Jijie Zhou, Yuhan Hu · 2025 · arXiv · 引用 0 · DOI 10.1145/3640794.3665560

## 一句话
给基于 ChatGPT 的文字聊天机器人加上"犹豫停顿"和"自我修改打字"两种类人打字行为,并做小规模用户实验,发现同时具备这两种行为的 agent 被用户感觉更自然、更像人、更可信。

## 解决了什么问题
当前 LLM 对话 AI 回复又快又精准、没有思考停顿和打字错误,这恰恰成了它与真人的可辨别标志,显得"不真实/不像人"。已有研究多停留在**文本/词汇层面**模拟拟人化,或只研究"整句延迟",缺少对**打字过程视觉动态**(逐字停顿 + 当众自我纠错)这一多模态线索的探索。本文想填补这个空白:把"打字行为本身"作为非语言线索,看它能否提升对话的投入度与可信度。

## 用什么方法解决的
1. **设计框架(design space)**:把类人打字拆成两大类——
   - **犹豫(hesitation)**:调节平均打字速度与方差、停顿频率(pause rate)、每次停顿时长;参数包括 characterTypingPace、spaceLagPace、characterDeletionPace、cursor moving speed,并用正态分布加入随机波动。
   - **自我编辑(self-editing)**:删除、插入、修改已打文字,各有发生概率;可作用于段/句/词/字符四个层级。修改用 WordsAPI 找同义词替换,删除从自建常用词库里随机挑"冗余词",每个元素只编辑一次。
2. **平台实现**:用 Flutter 做跨平台(Web/iOS/Android)开源 app,调 OpenAI API(GPT-3.5 text-davinci-003)生成内容并限制回复长度,再按打字参数渲染出带闪烁光标的实时打字过程。参数可实时调。
3. **用户实验**:被试内(within-subject)设计,三个 agent——Blue(基线,无行为)、Green(仅犹豫)、Red(犹豫+自我编辑)。任务是把对方当作"刚认识的网友"聊爱好,每个 agent 最多 5 条消息,不告知对方是人还是 AI。用 5 点 Likert 量表(改编自 UEQ/HRIES)测响应时间、能力、满意度、友好、易用、清晰、自然度、类人度,加开放式问题与客观指标(字数、句数、时长)。

## 动机 & 背景
研究表明人会像对待人一样对待智能机器;拟人化线索(头像、语气、情感提示)能提升无实体聊天机器人的可信度、智能感与有用性。打字行为本身能透露情绪、认知负荷、压力、话题熟悉度等心理状态(Vizer、Ong、Cohen 等)。但既有工作:(a) 自我纠错——多数研究只看"机器人犯错被用户如何看"(多为负面),很少有机器人**主动自纠并透明展示**的实验;(b) 时间延迟——已证明动态延迟比即时回复更像人、社会临场感更高,但只研究整句延迟、且多在被试**已知**对方是机器人的前提下,缺少身份模糊场景。本文把时间维度与文本维度(犯错/纠错)首次结合。

## 数据集 & 实验设置
- 雪球采样招募 20 人,因数据不全/未通过注意力检验,最终仅 **11 人**有效,共 33 个数据点(每人 3 个 agent)。年龄 18–34,6 男 5 女,5 名英语母语、6 名流利。
- 平衡 agent 呈现顺序以减学习效应;进聊天室前设 5–15 秒随机"连接等待"以掩饰对方是 24/7 在线的机器人。
- 在用户消息后追加一行隐藏 prompt 限制回复句数/词数并强制英文,使回复更口语简短;每次生成修改 prompt 前会重置模型。

## 主要结果 & 结论
- **量化(Likert)**:
  - 响应时间:Blue 最高(M=4.55)> Red(3.82)> Green(3.46)。
  - Green(仅犹豫)整体最差,自然度 M=2.27、类人度 M=1.73,**H1、H2 不成立**(单独加犹豫并未提升类人度与好感)。
  - Red(犹豫+自editing)在自然度(3.0 vs 2.91)、类人度(2.91 vs 2.46)、能力(3.82 vs 3.45)、友好(4.27 vs 4.0)上略高于 Blue,**方向上支持 H3、H4,但推断统计均不显著**。
- **客观投入**:用户与 Red 互动最久(M=238.7s)、输入字数(62.3)句数(10.3)最多;Green 最低。用户字数与 agent 字数正相关:Y=0.67X+6.81,R²=0.79。
- **质性**:Blue 被评"太快""不真实""太正式";Green 被评"机器人""重复""听不懂上下文",最不受欢迎;Red 被 6/11 人选为最喜欢,认为它"自然""真诚""更聪明",自纠被视作智能/纠错能力体现——但也有人觉得当众纠错"瘆人(creepy)"、希望隐藏自回归中间输出。
- **结论**:单加犹豫无益甚至有害;**犹豫+自我编辑组合**最被偏好,self-editing 是有前景的拟人特质;需在"像人"与"高效响应"间权衡。

## 核心贡献
1. 提出一套可参数化的类人打字行为设计框架(犹豫 + 四层级自我编辑),并开源跨平台实现。
2. 首次把"打字过程的视觉动态"(逐字停顿 + 当众自纠)作为多模态拟人线索来研究,区别于以往只做整句延迟或纯文本拟人。
3. 通过被试内试点实验给出设计启示:推荐引入 self-editing 行为以正向改变用户感知,而单纯放慢/加停顿反而招致"迟钝/机械"的负评。

## 局限与我的质疑
1. **样本极小、统计不显著(作者自述+我的强调)**:有效仅 11 人、33 数据点,作者自己承认是 pilot;关键的 H3/H4 优势"未达统计显著",H1/H2 直接被否。也就是说论文最被宣传的"Red 更好"结论在统计上站不住脚,标题"Beyond Words"和摘要里"reveals a preference / suggesting an improvement"措辞相对证据强度有过度解读之嫌,只能算趋势性观察。
2. **混杂变量未被控制,自变量不纯**:内容由 GPT-3.5 生成且每次重置模型、限长,导致 agent 频繁"听不懂上下文/答非所问/重复",作者也承认用户评价被**内容质量**主导而非被研究的打字行为。三个 agent 内容生成机制本应相同,但响应时间天然不同(Red/Green 慢),用户一旦察觉是机器人就转向"可用性/速度"标准——这等于自变量(打字行为)与一堆噪声/期望变化纠缠在一起,因果归因很弱。此外"自纠"用随机同义词替换或随机塞冗余词来制造"错误",作者承认常显得不自然,这意味着实验里的 self-editing 与真人打字错误并不等价。
3. **测量与外部效度问题**:大量依赖质性编码(仅两位作者本人编码,无报告信效度/一致性),量化指标自定义改编;任务局限于"聊爱好"的社交闲聊,作者承认不能推广到客服等任务型场景;被试英语水平、雪球采样也带选择偏差。"creepy""希望隐藏中间输出"等反馈说明该设计的可接受度其实存在分歧,不是一边倒的正面。
4. **与"RL 训练数字人与环境交互"主题的根本差距(相关性仅 20)**:本文是纯文本 UI 层的**表层行为模拟**——打字停顿/纠错由**手工规则 + 随机参数 + 正态分布**脚本化生成,完全没有学习、没有策略、没有奖励或与环境的闭环交互;数字人的"行为"既不是从数据中学到的,也不会因交互反馈而自适应。它对本主题唯一可借鉴的是"行为真实性/自然度能提升交互体验、过度拟人反而 creepy"这一**评价视角**,以及"用户输入字数随 agent 字数线性增长(R²=0.79)"这种交互投入度度量思路;但在方法论上(无 RL、无具身、无环境)与目标主题几乎不重叠,不能作为技术参考,只能作为"拟人行为的人因评估"参照。
