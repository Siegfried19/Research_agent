# Input-to-State Safety for Reinforcement Learning.
> Jha MS, Marthi S, Vamvoudakis KG, Kanso S, Theilliol D · 2026 · IEEE transactions on neural networks and learning systems · 引用 0 · DOI 10.1109/tnnls.2026.3688045

## 一句话
针对带执行器饱和的非线性连续系统,提出一套"端到端安全"的离策略强化学习框架,核心是一条自适应的 ε 调参律,让探索在安全边界附近"敢冒险"(采到信息量大的数据)的同时,在数学上严格保证全程不越界。

## 解决了什么问题
现有 safe-RL(尤其基于控制屏障函数 CBF 的)有三个被忽略的缺口:① **探索阶段的安全被无视**——为了持续激励(persistent excitation)注入大幅度探测噪声时,系统容易冲出安全集;② 经典 CBF 滤波器为了保安全而**一刀切地保守**,把轨迹死死压在安全集内部,恰恰采不到"贴近边界"这类最有价值的数据;③ 几乎没有工作在**执行器饱和**约束下、且以**离策略**(off-policy)方式同时给出安全、稳定、最优三重保证。本文要在这三点上同时给出可证明的保证。

## 用什么方法解决的
1. **把"安全探索"建模成鲁棒安全问题**:把探测噪声 e_u(t) 当作"匹配扰动",引入一个比真实安全集 C 更大的扩张集 C_{ξ,T}(由噪声界 ξ 和调参 ε 参数化),定义 ISSf-Exp-CBF(输入到状态安全探索屏障函数)约束,保证扩张集在噪声下前向不变(用 Nagumo 定理证明,Theorem 1)。
2. **核心创新——ε 调参律(式24-25)**:ε(h) 随安全裕度 h(x) 指数变化。靠近边界(h→0)时 ε 取最小值 ε₀,约束收紧、控制保守;深入内部(h 大)时 ε→ε_max,约束放松,允许大幅度激励。由此实现"边界附近也能安全地大胆探索"。
3. **CLF/CBF-QP 安全滤波器**:把稳定性(CLF,软约束+松弛变量 δ)、ISSf-Exp-CBF 安全(硬约束)、以及饱和上下界(硬约束)统一进一个二次规划(式32),在线对名义噪声输入做最小范数修正。该 QP 同时给出 PI 所需的初始可行安全策略(令 e_u≡0 过同一滤波器)。
4. **饱和下的安全学习**:用非二次型代价函数处理 tanh 饱和(式3),在效用里增广倒数屏障函数 B_λ(式34),得到 G-SHJB(式41),用安全策略迭代(S-PI,Algorithm 1)迭代求解,并证明了收敛(Lemma 5)、安全(Theorem 2,轨迹永不触边界)、稳定(Theorem 3)、最优(Theorem 4)。
5. **离策略实现**:把动态拆成行为策略+目标策略(式49),用神经网络(critic Φ + actor ρ·tanh(·))逼近值函数与策略,并推导出饱和下的**闭式最小二乘公式**(Lemma 6,式51-54)从数据直接解权重,策略更新无需模型。
6. 在**倒立摆**和**喷气发动机喘振/失速**两个仿真上验证。

## 动机 & 背景
安全可形式化为状态空间中某集合的前向不变,常用 CBF(分 ZCBF 与 RCBF)实现。为应对扰动/不确定,提出了 ISSf(输入到状态安全)及 ISSf-CBF,通过扩大不变集保证鲁棒安全,但偏保守;TISSf-CBF 通过可调集合大小缓解保守性。RL 分探索与利用两阶段,探索噪声会把系统带入不安全区。已有 safe-RL(如 Marvi & Kiumarsi 用 RCBF 增广代价、Kanso 等的端到端安全)要么忽略探索阶段安全,要么不考虑执行器饱和、不给离策略表达式。作者指出:**最有信息量的数据恰恰产生在贴近边界的轨迹上**,但持续激励要大幅探测信号,标准 CBF 在边界附近过保守甚至不可行,数据质量在最需要处反而下降——这正是本文要解决的核心张力。

## 方法细节
- **ISSf-Exp-CBF(Definition 7,式20)**:在 sup_u [L_f h + L_g h·u] ≥ -α₄(h) + ‖L_g h‖²/ε(h) 中,ε 越小右端越大、约束越严。
- **γ_T 与 ε 的关系(Lemma 1,式21)**:γ_T = -α₄⁻¹(-ε(h)ξ²/4),量化扩张集与真实集的间隙,随噪声 ξ 与 ε 缩放。
- **ε(h)(式24)**:ε₀ + (ε_max-ε₀)(1-exp(-σ(h)/τ)),其中 σ(h) 是 C^∞ 的"正部"光滑替代(h≤0 时为0,h>0 时≈h,用阻尼系数 κ=10⁵ 让其快速逼近 h);τ 控制过渡深度。
- **学习目标用真实集 C 而非扩张集**(Remark 5):扩张集只用于数据采集的鲁棒不变,学到的策略要对真实安全约束最优。
- **复杂度**:QP 仅 m+1 个决策变量、2m+2 个线性约束,与输入维 m 而非状态维 n 挂钩,利于实时;离策略 LS 每次 PI 复杂度 O(Np²+p³),实验中 p=N₁+mN₂=22+9·1=31。

## 数据集 & 实验设置
纯**仿真**,两个二阶系统:
1. **倒立摆**:m=1kg, g=9.81, l=1;安全集 C={-5≤x₂≤3};Q=diag(0.1,0.01), R=0.001, |u|≤5;critic 22 项、actor 9 项多项式基;探测噪声为多频正弦叠加随机高斯幅值(式68,a=8.5,13 个频率)。学习约 17 步收敛。
2. **喷气发动机喘振/失速**(二阶):安全集 C={-1.1<x₂<0.45};Q=diag(20,10), R=0.3, |u|≤10, α₄=20;同样的基函数;学习约 7-8 步收敛。
对比对象:无安全滤波器、经典 CBF(无 ISSf)、以及本文 ISSf 滤波器的不同 ε(h) 方案(常数、倒数 1/h、本文调参律)。文中给出迭代收敛步数等数值,但无 RMSE/成功率等量化指标表;呈现的对比主要为状态/输入轨迹曲线与值函数曲面的定性比较。

## 主要结果 & 结论
- **安全探索**(Fig.1/5/8/11):同样的高幅探测噪声下,无滤波器会越界;经典 CBF 保安全但过保守、轨迹远离边界、采不到边界数据;常数/倒数 ε 方案在**倒立摆**中表现不一致(内部过怯/边界附近保护不足,Fig.1),在**喷气发动机**中则在激进噪声下出现边界越界(Fig.8,鲁棒性不足);**本文调参律既不越界又能贴边界探索**,数据更丰富。
- **参数影响**:在喷气发动机中(Fig.9)ε_max 主要塑造边界附近行为(远离激活处轨迹基本重叠);而倒立摆中(Fig.2)ε_max 也影响远离边界处的保守性——ε_max 越大整体越不保守,但激进激励下鲁棒裕度下降;τ 主要调过渡瞬态的"激进度",小 τ 切换更快、瞬态更尖锐。
- **安全学习**:值函数随迭代单调下降(Fig.6),值函数曲面印证 Lemma 5 的单调性;输入曲线显示滤波器只做满足约束所需的最小修正。
- **理论**:在数学上严格建立了探索安全(Thm1)、学习期安全(Thm2,永不触边界)、稳定(Thm3)、最优收敛 W^(i)→W*(Thm4),以及饱和下的离策略闭式 LS 表达(Lemma6)。
结论:框架实现"安全初始化+安全探索+安全学习"三位一体,在不牺牲探索丰富度的前提下保证激进探索时的安全;未来工作含非匹配扰动、与数据驱动系统辨识结合以减弱模型依赖。

## 核心贡献
1. 把安全探索建模为鲁棒安全问题,提出 ISSf-Exp 扩张集与 ISSf-Exp-CBF 约束,纳入 CLF/CBF-QP 并带饱和界。
2. 提出指数型 ε(h) 调参律,边界收紧、内部放松,在高幅持续激励下实现"边界感知"的低保守探索。
3. 在在线安全滤波器与安全学习目标中一致地纳入输入饱和,并严格证明端到端安全+稳定+最优。
4. 给出饱和下离策略 PI 的新颖闭式解析 LS 表达式,实现免模型权重更新。

## 局限与我的质疑
1. **作者自述局限 / 未来工作**:只处理"匹配扰动"(探测噪声经由输入通道进入),**非匹配扰动留作未来工作**;模型不确定的减弱也被列为**未来工作方向**——结论中作者提出有界建模/辨识误差可作为额外扰动项吸收进噪声界 ξ,但本文并未实际这样实现;在线 QP 仍需 control-affine 模型(或辨识近似)算 Lie 导数,并非完全免模型(离策略权重更新则可免模型)。
2. **实验严重单薄,结论有过度解读之嫌**:全部是两个**二阶、单输入(m=1)**的经典玩具系统,且主要靠**定性曲线**论证"数据更丰富/探索更优",除迭代收敛步数外**几乎没有量化指标**(如越界次数、采到的状态覆盖度/激励持续性度量、学到策略的最终代价、对比基线的回报),也没有统计重复或误差棒。"richer data collection 带来更好学习"这一全文卖点其实**未被任何端到端的学习性能数字证实**——只展示了值函数单调下降(那是 PI 的理论必然,不能当作"探索更优"的证据)。
3. **保证的前提很强、可能掩盖实用难点**:安全证明依赖 RCBF 当 h→0 时 B_λ→∞(屏障趋无穷)→轨迹有限时间不可达边界,这是连续时间理想化结论;实际**离散采样、零阶保持、QP 求解延迟、模型误差**下这种"永不触边界"极易被打破,文中未做任何离散化/鲁棒性退化分析。ε(h) 里 κ=10⁵ 的硬选取、QP 可行性(尤其饱和+CBF 同时为硬约束、CLF 才软化)在边界附近是否总可行,仅靠 Lemma 2 的"标准正则性假设"带过,缺实证。
4. **"安全探索 vs 安全学习"用了两套不同的屏障逻辑**(探索用扩张集+ZCBF 式条件,学习用真实集+RCBF 增广代价),衔接处的整体性保证(尤其离策略数据来自扩张集、却要对真实集最优)论证偏形式化,Lemma 3/4 的证明多为"直接由前述引理得出",可读性与严谨性之间存在落差。
5. **与本研究主题("RL 训练能与环境交互的数字人")相距较远**:这是控制论谱系的安全-RL(连续时间 HJB/CBF/策略迭代+多项式基函数 critic-actor),面向低维已知动力学的调节/镇定问题;它**不涉及高维感知、人体/虚拟人运动、人机交互、模仿学习或深度策略网络**,可迁移性主要停留在"安全护盾/CBF 滤波"这一抽象理念层。把它用于数字人,需克服:状态维度爆炸(多项式基不可扩展)、安全函数 h(x) 在高维交互场景中难以解析设计、以及人类在环交互带来的非匹配/非平稳扰动——而这些恰是本文明确回避的部分。引用数为 0、2026 年新刊文章,实证沉淀也尚不足。
