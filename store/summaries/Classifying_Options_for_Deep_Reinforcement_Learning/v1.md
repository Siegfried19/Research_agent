# Classifying Options for Deep Reinforcement Learning
> Kai Arulkumaran, Nat Dilokthanakul, Murray Shanahan, Anil Anthony Bharath · 2016 · arXiv · 引用 0 · DOI arxiv:1604.08153

## 一句话
把分层强化学习的"选项(options)"框架塞进 DQN——给策略网络加多个"选项头(option heads)"再配一个监督网络来挑头,从而在子任务之间存在负迁移时降低样本复杂度。

## 解决了什么问题
端到端的 DQN 虽然通用,但样本复杂度高;当一个任务能被人类专家拆成共享状态空间、却彼此干扰(负迁移)的若干子任务时,单一 Q 函数的标准 DQN 会因子任务相互干扰而学得慢。作者想用"显式构造 options"这一结构先验来注入领域知识、降低样本复杂度,同时尽量不损失 DQN 的通用性。

## 用什么方法解决的
在标准 DQN 的共享卷积层之上分叉出多个全连接"选项头",每个头对应一个子任务、单独输出该子任务可用动作的 Q 值,并各自维护独立的经验回放缓冲;训练时由 oracle(先验知识)决定当前时刻该评估哪个头。另加一个"监督网络"(softmax 分类器,交叉熵训练,oracle 给标签)学习"状态→该用哪个选项",评估时用它替代 oracle。完整确定性策略为 π(s)=argmaxₐ Q_{O(s)}(s,a)。在自制的 Catch 游戏(白/灰两种球,构造正迁移与负迁移两种设置)上,与标准 DQN、参数减半的 half DQN 对比,并扫了 16/32/64 神经元三档容量。

## 动机 & 背景
深度强化学习(DQN 表示 Q 函数、深度网络表示策略)成功源于深网的表征能力,但通用方法需要海量样本。降低样本复杂度的一条路是用领域知识把算法偏向有希望的解。经典 RL 里有大量关于时间抽象的分层强化学习研究:options 框架(Sutton 1999)用"策略 π + 终止条件 β + 初始集 I"三件套把可执行动作集扩展到时间延展动作;MAXQ(Dietterich 2000)把任务递归分解成子任务层级。两者都便于自然地注入先验。作者关注的问题类别是:任务可被人类专家拆成"奖励独立、共享状态空间、但可显式划分(给不同选项)"的子任务,若动作空间也能划分则进一步约束各选项可用动作。虽有证据表明 DQN 能隐式学到 options(Zahavy 2016),作者要验证显式构造是否有额外收益。

## 方法细节
- **选项头**:架构等同 bootstrapped DQN(Osband 2016)/ MCDQN(Parisotto 2015)——共享卷积层 + 各头独立全连接分支。头数由领域知识先验决定,每个头按各自子任务单独训练。训练时 oracle 选头,在该头上用共享的 ε-greedy 选动作;每个头有独立的经验回放 buffer(存 (sₜ,aₜ,sₜ₊₁,rₜ))。与 Osband 不同,作者**不**对各头梯度做归一化,因为每次只反传过一个头。
- **监督网络**:任意分类器,输入整个状态,softmax 输出选项分布,交叉熵损失,训练标签来自 oracle;评估时取代 oracle 决定用哪个头。
- **options 框架的简化**:在全可观测 MDP 下 sₜ 是充分统计量,故 oₜ 在给定 sₜ 时与 oₜ₋₁ 条件独立,把终止条件和初始集都吸收进"监督策略"π(oₜ|sₜ),完整策略写成 π(aₜ|sₜ)=Σ_o π(oₜ|sₜ)π(aₜ|oₜ,sₜ)。
- 底层用 Double DQN 更新降低 Q 值高估;假设卷积层学通用状态表征、顶部全连接层编码实际策略。

## 数据集 & 实验设置
- **环境**:重写的 Catch(Mnih 2014),24×24 灰度图,3 个离散动作(左/右/no-op),输入为当前+前3帧堆叠;2 像素宽挡板接 1 像素球。原版只有白球(+1);作者加灰球引入子任务,每个 episode 切换球的种类。
  - 正迁移:接白球或灰球都 +1(两子任务相同)。
  - 负迁移:灰球 +1,白球 **−1**;最优体要学会接灰球、躲外观相似的白球。
- **对比模型**:标准 DQN(baseline)、half DQN(全连接隐层参数减半、无选项头)、2 选项头 DQN。为公平:(1) 每个选项头隐层神经元数 = 标准 DQN 除以头数,保持总参数一致;(2) 交替更新各头,保持训练样本数一致。half DQN 用来区分"收益来自每个头参数变少"还是"来自结构约束"。
- **容量扫描**:标准 DQN 用 16/32/64 神经元,对应 half DQN 8/16/32、每个选项头 8/16/32。
- 统计:15 个随机种子,每次得分为 250 episodes 平均,1 epoch=10000 训练步;优化器 Adam,回放 10000,目标网络每 4 步更新,ε 在 10000 步内线性退火至 0.01/0.05,学习率搜索 {0.000125,0.00025,0.0005}。

## 主要结果 & 结论
- **容量是最主要因素**:容量低时性能最受影响,容量增大三种网络差距缩小。
- **正迁移**:架构无显著影响,主要看容量。
- **负迁移**:选项头 DQN 比标准 DQN 进步明显更快(样本复杂度更低);给足容量时 half DQN 也能收敛到同等性能,但样本复杂度更高——说明收益来自**结构约束**(注入领域知识),而非单纯参数变少。
- 各 DQN 学到的卷积滤波器高度相似,印证"共享卷积学通用底层特征(落球/移挡板),各头学专门策略(接/躲)"的直觉。
- 监督网络在此域分类任务简单,能快速学会划分状态空间,故评估时未用 oracle 替代它。
- 一个超参发现:负迁移下标准/half DQN 需更低学习率(0.000125),而选项头 DQN 仍可用 0.00025。
- 结果与 Parisotto 2015 中 MCDQN 在 8 个 Atari 游戏上反被标准 DQN 超过相反;作者认为多任务下各游戏状态差异大、梯度在共享卷积层互相干扰,而分层 RL 设定下状态空间更连贯,故此问题较轻。

## 核心贡献
1. 提出"选项头 + 监督网络"的 DQN 增强架构,把 options 框架显式嵌入 DQN,并用 oracle/监督网络处理选项选择。
2. 在保持模型容量和训练样本数不变的受控对比下,实证显示该结构约束能在负迁移子任务上降低样本复杂度,且不损害正迁移子任务的性能。
3. 用 half DQN 作对照,把收益归因于"结构约束注入领域知识"而非参数量变化;并指出后续可朝"去掉 oracle、做选项发现(option discovery)"方向走。

## 局限与我的质疑
- **作者自述局限**:相比基于目标的方法(UVFA、h-DQN)泛化性差——选项头 DQN 处理的是固定子任务而非可泛化的目标;且当前严重依赖 oracle(训练时选头、给监督网络标签),作者也承认未来需要做无监督的选项发现来去掉 oracle。多任务设定下即便这种增强也可能因底层策略干扰而失败(引 Rusu 2015)。
- **实验极其单薄,结论被放大**:全部证据只来自一个自制的 24×24 玩具游戏 Catch,且只有 2 个子任务、2 个选项头。从这样一个简化环境就声称"结构先验能降低深度 RL 样本复杂度"是过度外推;论文连 Atari 等标准 benchmark 都没碰(尽管反复引用 Atari 多任务工作做对照),无法证明方法可扩展到更多/更复杂的子任务或真实视觉域。
- **"领域知识"被偷偷外包给 oracle**:方法的核心收益建立在一个能完美告诉你"当前是哪个子任务、该用哪个头"的 oracle 上——这等于把任务分解、子任务标注这件最难的事预先解决了。在真实问题里恰恰没有这种 oracle;论文用"监督网络在此域很好学"来回避,但 Catch 里白/灰球用颜色一眼可分,根本不能代表难划分的情形。负迁移收益很可能正源于这种近乎完美的监督切分,而非架构本身的普适优势。
- **公平性对照仍有疑点**:虽然控制了总参数和样本数,但选项头各自独立的经验回放 buffer + 交替更新,实际改变了数据分布与梯度信号;把"更快收敛"全部归因于结构约束、排除优化动力学差异的论证不够严密(超参里负迁移需不同学习率本身就暗示优化景观被改变了)。15 种子虽好,但单环境单设置的统计意义有限。
- **与本主题(RL 训练数字人与环境交互)的差距很大**:这是一个离散动作、低维像素、玩具级的通用分层 RL 方法验证,完全不涉及连续控制、全身动作、物理仿真或人机交互。对数字人而言唯一可借鉴的是"技能/子策略分层组合 + 共享底层表征 + 上层调度器选技能"的思想骨架(类似后来的 hierarchical motor skills / options-over-motions),但本文既没有连续动作空间的处理,也没有自动技能发现(全靠 oracle),离"可组合全身动作技能库"还差得远,启发性远大于可直接复用性。
