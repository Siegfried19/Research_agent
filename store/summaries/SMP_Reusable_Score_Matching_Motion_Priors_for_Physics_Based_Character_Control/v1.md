# SMP: Reusable Score-Matching Motion Priors for Physics-Based Character Control
> Yuxuan Mu, Ziyu Zhang, Yi Shi 等（Simon Fraser University / Sony Interactive Entertainment / Stanford / Snap / NRC Canada / NVIDIA）· 2025 · arXiv · 引用数 8 · DOI 10.48550/arxiv.2512.03028

## 一句话
本文提出 SMP（Score-Matching Motion Priors），把预训练的运动扩散模型借助 Score Distillation Sampling（SDS）改造成一个"冻结、可复用、模块化"的奖励函数，让物理仿真人形角色在强化学习中无需保留原始动作数据集就能学到自然、风格化的全身运动。

## 解决了什么问题
数据驱动的"运动先验"是让虚拟角色动作自然的关键。当前主流的对抗式模仿学习（AMP/GAIL）有两个结构性痛点：
1. **不可复用**：判别器（discriminator）必须与每个新策略联合训练，换一个任务/策略就要重训先验。
2. **必须长期保留原始数据集**：因为判别器训练时既要喂策略数据也要喂参考数据，原始动作数据集要被无限期保留，既不模块化也不便于分发与版权管理。
作者主张理想的运动先验应当**模块化**（独立于原始数据集即可指导策略训练）且**可复用**（一次构建后可跨多任务、多策略直接使用，无需再训练）。

## 用什么方法解决的
给定一个无结构的动作数据集，先独立训练一个运动扩散模型（与任何任务/策略无关），捕捉动作分布；训练完成后**永久冻结**该扩散模型，通过 SDS 把它当作衡量"仿真动作与参考分布相似度"的奖励函数。RL 训练时，把策略产生的动作片段加噪到某扩散时间步，让冻结扩散模型预测噪声，用预测噪声与真实加噪噪声的残差 ‖ε̂−ε‖² 经指数变换归一化到 [0,1] 作为风格奖励，与任务奖励组合进行目标条件强化学习。先验可用 classifier-free guidance（CFG）按风格标签条件化，把一个在大数据集上训的通用先验"提示"成多种风格专属先验，甚至组合不同风格合成数据集中不存在的新风格。

## 动机 & 背景
让物理仿真角色在动态任务与环境中表现出自然、有生命感的动作，是动画、游戏、VR、机器人的共同需求。传统无数据控制器（如 SIMBICON）动作机械不自然；跟踪式方法（DeepMimic 等）逐帧刚性模仿参考片段，灵活性差、难以偏离参考完成新任务；分布匹配类的对抗模仿（AMP）更灵活，但其判别器作为先验存在前述"不可复用 + 必须保留数据集"的问题。同时扩散模型在生成上表现优异，已有工作把扩散模型当规划器或控制器组件，或用 SDS 把图像/视频扩散模型当 RL 目标，但后者往往产生不自然、模糊的动作，难以匹敌对抗方法。与本文最接近的是 SMILING（用类似 VSD 的 score-matching 目标），但 SMILING 需为每个任务训练专属扩散模型；本文则训练一个**任务无关**的先验并复用。

## 方法细节
- **SMP 奖励（核心）**：r_smp = exp(−w_s ‖ε̂−ε‖²)，ε̂ 为冻结扩散模型在加噪样本上预测的噪声。借鉴标准 RL 奖励设计做指数归一化到 [0,1]（虽偏离原始 SDS 形式，但经验上提升了训练效果）。
- **Ensemble Score-Matching（ESM）**：SDS 对扩散时间步 i 极敏感——高噪声步预测可靠但信息少（趋于产生平均化/泛化动作），低噪声步对抖动伪影过敏；随机采单一时间步会给奖励引入巨大方差，损害值函数/优势估计。作者改为在固定一组代表性时间步 K={22,15,8} 上聚合多次 SDS 评估求平均，显著降方差（论文报告方差从 1.140 降到约 9.964×10⁻⁶）。
- **自适应归一化**：用各时间步 SDS 误差的滑动均值 μ_i 归一化，缓解不同噪声尺度、不同预训练模型与风格间的尺度差异，减少手工调参。
- **Generative State Initialization（GSI）**：传统 Reference State Initialization（RSI）需访问数据集采初始状态；GSI 改用扩散模型直接生成初始状态，使先验同时承担"奖励函数 + 初始状态分布"双重角色，从而彻底摆脱对原始数据集的依赖。
- **风格化与组合**：通过 CFG 按风格标签条件化把通用先验变成风格专属先验；多风格可组合（例如把多种风格组合出类似交谊舞、优雅手臂+连续旋转的新行为）。
- **人-物交互（HOI）**：训练联合建模角色动作与物体动作的扩散模型 f(x^char, x^obj)，物体姿态在角色局部坐标系下表示，用同样流程评估交互自然度。
- **真实机器人部署**：用 SMP 在仿真中训行走控制器并直接部署到 Unitree G1 人形机器人；采用非对称 actor-critic（critic/扩散模型获得 root 高度、线速度、末端位置等特权信息，策略仅观测 67 维本体感知），并做域随机化以提升真实环境鲁棒性。

## 数据集 & 实验设置
- **仿真环境**：Isaac Gym，1024 个并行环境，单卡，约 12 小时内完成训练。
- **数据集**：100STYLE（100 种风格，用于通用先验与风格化）、LaFAN1 子集（无结构跑步动作）、HOI 数据集（Object Carry）、以及极小数据（Target Speed 任务仅 3 个不同速度的片段）。规模从 ~3 秒片段到约 20 小时大规模数据集。
- **任务**：Steering（朝向+速度跟踪）、Target Location、Dodgeball（躲避球）、Object Carry（走向箱子、抬起、搬运到目标点）、以及 Backflip/Cartwheel/Crawl 等高动态接触丰富技能；机器人侧含 Stair Traversal。
- **对比基线**：AMP（每任务联合训练判别器）、AMP-Frozen（冻结判别器复用）、纯任务奖励（w/o Prior）。
- **评测指标**：归一化任务回报（Task Return，归一化到 [0,1]）、风格分类器度量的 Style Accuracy、GSI 生成初始状态质量用 FID 与 Coverage@1 评估。

## 主要结果 & 结论
- **风格化（100STYLE）**：SMP 一次预训练即可适配各风格，Style Accuracy 平均约 0.875、任务回报普遍高（多任务接近 0.97–0.99）；AMP-Frozen 在多种风格下崩溃（如 CrossOver 0.470、Skip 0.512、FlickLegs 0.580），证明对抗先验无法被冻结复用。
- **一先验多任务**：单个 LaFAN1 跑步先验可复用到 Steering / Target Location / Dodgeball；策略涌现出后退慢跑、侧步、远跑近走等未被显式规划的自然步态；Dodgeball 中自发学出跳跃躲避（数据集中并无此技能）。AMP 在 Dodgeball 上无法学到有效策略。
- **样本效率**：SMP 因奖励模型固定（stationary）而比 AMP 的非平稳对抗奖励更稳定、收敛更快。
- **小数据泛化**：Target Speed 仅用 3 个离散速度片段，策略能在连续速度区间内自然过渡（走→慢跑→跑）。
- **GSI 质量**：生成初始状态 FID 在 0.0922–0.1997、Coverage@1 ≥ 89.3%，与参考分布接近，能在不保留数据集下替代 RSI。
- **结论**：用 SDS 做 RL 目标可达到与对抗模仿相当的动作质量，同时实现模块化、可复用、丢弃原始数据集，并扩展到 HOI 与真实机器人。

## 核心贡献
- 提出把**冻结的预训练扩散模型经 SDS 改造为可复用、模块化的 RL 奖励先验**，使运动先验摆脱"必须随策略重训 + 必须保留数据集"的对抗范式局限。
- 提出 **Ensemble Score-Matching（ESM）** 与自适应归一化，解决 SDS 奖励对扩散时间步敏感、方差过大的问题，使 SDS 目标首次稳定匹敌对抗方法的动作质量。
- 提出 **Generative State Initialization（GSI）**，用扩散先验生成初始状态，彻底去除对原始数据集的依赖。
- 展示通用先验经 CFG 提示可派生风格专属先验、并可组合出数据集中不存在的新风格；并验证可扩展到 HOI 任务与真实 G1 人形机器人部署。

## 局限与我的质疑
作者自述局限：
- **模式坍缩（mode collapse）**：作为 mode-seeking 目标，策略易收敛到任务可行行为的一个小子集而非完整分布，且在大规模数据集上更明显。
- **GSI 可能生成无效状态**（如自穿插），引入仿真不稳定。

我的批判：
1. **"自然度"评估偏薄弱且偏向自家方法**。主表几乎只报告任务回报和风格分类准确率，缺少对动作自然度的独立、感知层面的定量评估（如动力学/足部滑动/物理合理性指标或大规模用户研究）；任务回报高并不等于动作自然，而"自然"恰是本文卖点。FID/Coverage 仅用在 GSI 的初始状态生成上，没有用于评估最终策略动作的分布匹配质量，存在论证缺口。
2. **基线设置对 AMP 略不公平、削弱了"comparable"的说服力**。AMP-Frozen 本就是一个明显劣化的设定（冻结判别器导致 OOD），用它来反衬 SMP 复用性几乎是"打靶子"；而真正强的对比应是为每任务正常重训的 AMP，但这恰恰不在 SMP 主打的"复用"语境内，二者比较维度并不完全对齐。"质量可比"的结论更多建立在少数任务上，泛化性证据有限。
3. **关键设计高度依赖手工经验值**。固定时间步 K={22,15,8}、ESM 聚合策略、指数归一化等都靠经验选取且"偏离原始 SDS 形式"，作者承认这些归一化是经验性改进。这意味着方法对新数据集/新角色的可迁移性可能需要重新调参，所谓"减少手工调参"的说法需打折扣。
4. **与"用 RL 训练数字人与环境交互"这一主题相比的不足**：本文的"交互"主要是角色与刚性物体（搬箱子）或被动障碍（躲避球）的物理交互，**缺乏与动态/智能体环境或真人用户的实时双向交互**，也没有社交/对话/多智能体协同的成分。它解决的是"动作自然度先验"这一子问题，离"数字人在真实交互场景中感知并响应外部主体"还有距离；模式坍缩问题也意味着在需要行为多样性的交互场景中表现可能受限。
5. **真实机器人证据偏弱**。机器人部分仅展示行走、爬行、上下楼等定性快照，没有给出真实部署的成功率、鲁棒性或与基线的定量对比，sim-to-real 的可靠性证据不足以支撑"可直接部署"的强结论。
