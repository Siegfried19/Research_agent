# Imitating Interactive Intelligence
> DeepMind Interactive Agents Group（Abramson、Ahuja、Hill、Wayne 等约 29 人） · 2020 · arXiv (Cornell University) · 引用 74 · DOI 10.48550/arxiv.2012.05672

## 一句话
DeepMind 在一个名为"Playroom"的 3D 虚拟房间里，用大规模人-人交互数据，通过"行为克隆 + 辅助损失 + GAIL 式逆强化学习"训练出能同时扮演"出题者(setter)"与"解题者(solver)"的具身智能体，让它们能感知房间、理解并产生自然语言指令、并用一个会移动和抓取的虚拟机器人完成任务，并配套构建了一整套从自动脚本到人工评测的评估体系。

## 解决了什么问题
论文要解决的核心问题是：**如何训练能与人类自然交互的具身智能体**，这种交互同时整合了 AI 的几个中心难题——复杂视觉感知、目标导向的物理控制、基于情境的语言理解与生成、以及多智能体社交互动。
两个关键痛点：
1. **不能直接用人类反馈的强化学习来训练**。作者用"性能差异引理(performance difference lemma)"论证：从零开始的智能体几乎永远不会偶然产生成功行为（成功率可能低到 10^-3），人类评价者绝大多数时候只能看到失败，反馈毫无区分度，导致 RL 早期陷入"高原期"，人在回路(human-in-the-loop)的训练在数据效率上不可行。因此必须先用模仿学习造一个"行为先验(behavioural prior)"。
2. **交互行为难以评估**。什么叫"有用/好"的交互本身是主观、含糊的，无法事先用规则写死奖励函数；可靠地评估这种智能体几乎和评估智能本身一样难。

## 用什么方法解决的
- **用学到的智能体近似人类**：理想情况下应在与真人交互中训练，但不现实，于是用另一个学到的智能体（setter）来近似人类出题者的角色，再用逆强化学习的思想缩小"人-人交互"与"agent-agent 交互"之间的行为差距。
- **三类学习目标叠加**：①行为克隆(BC)，把模仿问题当作监督式序列预测，最小化人类专家策略与智能体策略的 KL 散度；②辅助/正则化损失，包括 Language Matching(LM，类似对比预测编码 CPC/NCE，让视觉表征与语言概念对齐)和 Object-in-View(OV，让视觉表征编码画面中的有色物体)；③GAIL 式逆强化学习，训练一个判别器作为奖励模型，让智能体在与环境交互中"回到专家常访问的状态分布"，弥补 BC 会"脱轨且无法恢复"的缺陷。
- **交互式训练 + setter replay**：训练单一智能体同时扮演 setter 和 solver；setter 出题、solver 执行，solver 由 GAIL 判别器给奖励。早期 setter 语言策略未训练会产生无法满足的指令，于是用"setter replay"——一半训练回合直接回放数据集中真人 setter 的动作来热启动。

## 动机 & 背景
作者从"人类是交互性物种"的视角出发：人类智能在很大程度上是大规模群体交互（社交与语言）塑造的产物。要造类人 AI，就必须同时处理人作为物理智能体和作为群体中沟通智能体的行为。论文明确把自己定位为一个"研究纲领"的开篇，目标是造出能感知与操纵世界、理解与产生语言、并能对人类的一般请求做出胜任反应的具身智能体。相比此前"跟随自然语言指令"的工作，本文强调智能体不仅跟随指令、回答问题，还要**生成**指令、**提出**问题。选择虚拟环境而非真实机器人，是为了在规避硬件难题的同时整合感知、控制与语言研究。

## 方法细节
- **环境(Playroom)**：基于 Unity 的 3D 随机化房间，含儿童玩具与家居物品、容器、家具、门窗；房间为 L 形造成视线遮挡，尺寸与物体布局每回合随机。具身为"移动机械手(mobile manipulator)"，可移动并搬运物体。环境支持空间/物体关系推理、指代歧义、容纳、遮挡、部分可观测等。
- **动作空间**：多维，含连续 2D 鼠标视角(look)、WASD 键盘移动、grab 抓/放，以及 no-op。15 动作/秒，离散时间。策略是**自回归**的：先采一个动作分量、再条件于它采下一个；连续 look 通过递归地把 (-1,1)×(-1,1) 窗口九等分来逼近任意分辨率。语言以约 550 词的词表按整词产生/处理，超出用 UNK。
- **网络架构**：视觉用 ResNet（输入 96×72 RGB，可抓物体带 bounding box）→ 与语言 token 嵌入拼接 → 多模态 Transformer(MMT) → 输出 mean-pooling + 类 BERT 的 CLS 向量 → LSTM 记忆 → 分别参数化运动策略与语言策略。
- **判别器架构**：与策略用同类编码器(ResNet+文本嵌入+MMT)，再接一个能访问历史时间步的 Temporal Transformer，mean-pool 后过 MLP 输出"该序列来自真人示范的概率"。判别器与策略**不共享参数**。GAIL 只要求匹配状态分布 π(s)=π*(s)（而非 (s,a)），因为状态分布交给 GAIL、动作条件分布 π(a|s) 交给 BC 即可。
- **高维输入的关键工程**：作者强调据其所知尚无人把 GAIL 用到如此高维(带语言的视觉短视频)的输入；为避免判别器靠死记像素颜色等虚假特征过拟合，对送入判别器的图像用 RandAugment（随机裁剪、旋转、平移、错切）做扰动，并对判别器同样施加 LM 辅助损失，使其奖励聚焦于人类可理解的语义事件。

## 数据集 & 实验设置
- **数据**：通过"语言游戏(language games)"协议在 Playroom 采集真人 setter-solver 配对交互，共约**两年**的真人交互（视频+文本）。把交互分为问答(Q&A)、指令跟随、play、对话四类，本文只用前两类；用 24 个基础 prompt + 最多 10 个 modifier。共采集 **610,608** 回合（549,468 训练 / 61,140 验证），单回合最长 2 分钟(3,600 步)，平均 55±25 秒。共 320,144 条独特 setter 话语、26,023 条独特 solver 话语，即约 32 万个独特任务。
- **评测体系**（多层级、互相印证）：①自动学习诊断与启发式指标（如"是否抬起了与真人相同的物体"、"提到的物体是否真在房间里"）；②6 个 scripted probe task（指令跟随：Go/Lift/Position；问答：Colour/Exist/Count），由环境引擎回调无歧义打分，奖励仅用于评测不用于训练；③observational human evaluation（人看视频回放打"成功/失败"，每个智能体约 1 万标注回合）；④Turing 式 interactive human evaluation（人直接与智能体实时交互）；⑤训练"评估模型"用历史人类评测数据预测对新回合/新智能体的人类判断。
- **消融命名**：B=行为克隆，G=GAIL，A=辅助损失，R=setter replay，外加去视觉/去语言版本；BGR·A 为默认最佳智能体。每个变体仅跑 2 个随机种子，超参因算力受限未做穷举搜索。

## 主要结果 & 结论
- 在简化的"把 X 放到床上"任务上：纯 GAIL(G·A)无法学习；纯 BC(B)只会随机抓物；BC+GAIL(BG)、BC+辅助(B·A)都明显改善；三者全用(BG·A)最好。说明 **GAIL 更擅长重塑已有行为先验，而不擅长从零构建**。
- 在 scripted probe task 上，**交互训练的智能体（BG·A、BGR·A）整体 ≥ 所有对照**；有趣的是真人在同样无反馈条件下也并非完美，凸显"成功"本身的主观性。
- **BC 验证集 log 概率具有欺骗性**：交互训练的智能体在 BC 验证损失上反而比纯 BC 差，但在 probe task 和人类评测上更好——说明动作预测准确度不是衡量任务能力的可靠指标。
- 辅助损失对 setter 能力提升最关键：物体提及准确率从纯 B 的 0.241 提升到 B·A 的 0.660、BGR·A 的 0.686（人类 0.870）；智能体的用词频率与人类高度贴合（聚集在 unity line 附近）。
- GAIL 奖励模型具备一定语义一致性：把指令里"white robot"反事实改成"red robot"（房间里不存在）后，奖励大幅下降。
- 总结论：**大规模人类行为模仿是构建智能交互智能体的有希望工具**，且可靠评估这类智能体是可以克服的；交互训练与辅助损失带来的提升超过单纯监督式动作学习，能力可泛化到数据集字面经验之外，并能训练出与人类判断高度一致的自动评估模型。

## 核心贡献
- 提出一个把感知、目标导向控制、情境语言理解与生成、多智能体社交统一在一个虚拟环境中训练的研究纲领与具体实现。
- 首次（据作者称）将 GAIL 扩展到带语言的高维视觉时序输入，并给出使其可行的关键正则化方案（RandAugment + Language Matching）。
- 用 setter agent + 判别器奖励来"近似人类在回路"，规避了人类反馈 RL 的数据效率困境。
- 构建并交叉验证了一套从廉价自动脚本到昂贵交互式人评的多层级评估体系，并训练出可替代人评的机器评估模型。
- 贡献了约两年规模的人-人具身交互数据集与语言游戏采集方法论。

## 局限与我的质疑
1. **作者自述局限**：setter replay 不适用于持续来回的对话/主动协作，且在真实机器人上不可行；observational 评测因回放 setter 动作而排除了"hand me""连续做两件事"等需要双向协作的任务；对话(dialogue)与 play 两大类交互本文完全没碰；评估"成功"本身主观，连真人都达不到满分；算力限制使每个变体只跑 2 个种子、无法穷举超参。
2. **与"RL 训练数字人与环境交互"主题相比偏离明显**：本文的"physical control"是抽象的鼠标/键盘/抓取离散动作（15Hz、九宫格逼近视角），**没有任何全身动力学、关节力矩、物理仿真角色或运动自然性**。它解决的是"理解指令并搬对物体"的语义-决策层面，而非数字人全身运动控制；与本主题中 AMP/物理仿真角色一类工作几乎不在同一层。把它归到"RL 数字人与环境交互"更多是因为"具身+RL+交互"标签重合，实质上是**语言-具身智能体**而非物理数字人。
3. **GAIL 在此究竟贡献了多少存疑**：消融显示纯 GAIL 学不动、GAIL 主要"重塑"BC 先验，而 BC+辅助(B·A)在简单任务上已与 BG·A "基本相同甚至更好"；setter 指标的主要驱动力被作者归功于辅助损失而非 GAIL。换言之，论文标题强调的"逆强化学习"在很多指标上可能是边际增益，真正起作用的是大规模 BC + 辅助正则化——这一点结论容易被读者过度解读为"IRL 是关键"。
4. **评估的循环论证风险**：probe task 与人评一致被当作彼此印证的证据，但 probe task 的"成功"由作者自己写的环境回调定义，而作者又承认真人都不认同这套定义（真人得分不满分）；同时训练出的"机器评估模型"是用人评数据拟合的，用它评估新智能体存在与判别器类似的分布偏移与自我印证风险，"既要又要"的廉价评估替代未必稳健。
5. **泛化与规模的证据偏弱**：声称"能力泛化超出字面经验"，但环境是 ~550 词词表、玩具家居的封闭世界，物体类别与语言模板高度受限；从 Playroom 到真实人机交互（更别说真实机器人）的迁移鸿沟巨大，论文对此基本未提供证据，更多是纲领性宣称。
6. **判别器奖励的语义"理解"被轻度夸大**：用一个反事实颜色改写就让奖励下降，只能说明奖励模型对"指令-视觉一致性"敏感，不足以支撑"reward model 理解指令一致性"这种偏强的措辞；判别器仍可能依赖浅层视觉-语言相关而非真正语义推理。
