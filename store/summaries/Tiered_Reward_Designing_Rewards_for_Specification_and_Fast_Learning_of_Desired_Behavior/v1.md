# Tiered Reward: Designing Rewards for Specification and Fast Learning of Desired Behavior
> Zhiyuan Zhou, Shreyas Sundara Raman, Henry Sowerby, Michael L. Littman · 2022 · arXiv · 引用 0 · DOI arxiv:2212.03733

## 一句话
提出一种"分层奖励"(Tiered Reward)的奖励设计范式——把状态空间按"好坏程度"切成若干层、层间奖励呈指数级递增,从而**不依赖环境转移概率**就能保证学到的策略是帕累托最优的,且实证上比基线奖励学得更快。

## 解决了什么问题
奖励设计的两个核心难题:(1)**如何表达想要的行为**——在随机环境里,"到达目标的概率"和"撞上障碍的概率/时间"之间存在难以言明的权衡,人很难写出完整的偏好;(2)**如何让学习快**——即使行为偏好定清楚了,设计出真能诱导该行为、还学得快的奖励函数本身极难,且常需要预先知道环境动力学(转移概率、最优值函数),这在实践中拿不到。论文聚焦"到达目标状态、躲避障碍状态"这类 goal–obstacle 任务。

## 用什么方法解决的
分三步:① 用**帕累托最优**在策略空间上定义一个严格偏序——若策略 A 在所有时间步上都"更快/更高概率到达目标、更慢/更低概率撞障碍",则 A 支配 B;不可比时则保持无差异,把帕累托前沿上的所有策略都视为"想要的行为"。② 提出 **k-Tier MDP** 与 **Tiered Reward**:把状态分到 k 个层(障碍/背景/目标,或含子目标的多层),同层同奖励,相邻层满足 `r_i < (1/(1-γ)) · r_{i+1} < 0` 的指数递增约束;并**证明**(Thm 5.3 / 5.5)只要满足该不等式,最大化期望折扣回报得到的策略就是帕累托最优,且对最差层访问次数最少、对各好层访问次数最多。直觉是:只要"到达目标"比"无限在背景层徘徊"更划算、"撞障碍"更不划算,就会诱导出"尽快爬向高层、不掉回低层"的棘轮式策略。③ 在多个表格域(Flag Grid、Chain、Grid、Frozen Lake、Wall Grid)和深度 RL(MiniGrid 的 EmptyGrid/FourRooms/DoorKey,图像输入)上,用 Q-Learning、RMAX、PPO 验证,与 action penalty、tier-based shaping 两个基线比学习速度。

## 动机 & 背景
作者把奖励视为一种"编程语言"——它是对 agent 目标行为的规约(specification),设计奖励的责任在人。已有路线各有短板:基于偏好的 RL 需要人工标注的轨迹偏好数据集,而轨迹概率上的偏好本身难以指定;多目标 RL 用一组奖励刻画多个任务,本文则反方向——用**单个**奖励在多种行为间做权衡;reward machine 和时序逻辑(LTL/GLTL)更具表达力但易引发状态爆炸、规划求解困难。在"为快速学习设计奖励"方向上,Mataric(1994)、Sowerby et al.(2022)、Devidze et al.(2021)等方法都需要解优化问题或已知真值转移/参考奖励,不实用。本文要给出一个**环境无关**(reward 结构与各层取值跨 MDP 通用,只需把状态分层这一步用到环境知识)、设计简单、又有理论保证的方案。

## 方法细节
- **k-Tier MDP**(Def 3.1):状态空间划分为 k 个不相交的层 S₁∪…∪S_k,`R(s)=r_i (∀s∈S_i)`,且 `r₁<r₂<…<r_k`;目标层和障碍层为吸收态。任何有限 MDP 都能形式化成 Tier MDP,但在有明确好/坏状态(目标、障碍、子目标)时最有用。
- **3 层情形**(Def 5.2):`r_obs < (1/(1-γ)) r_background < r_goal`。中间项 `(1/(1-γ))r_background` 等于"无限领取背景奖励"的折扣累积回报,直觉即"到达目标要比永远徘徊更香、撞障碍要更不香"。
- **k 层推广**(Def 5.4):`r₁ < (1/(1-γ))r₂ < (1/(1-γ))²r₃ < … < (1/(1-γ))^{k-1} r_k ≤ 0`。比 3 层约束更严:**所有奖励非正**(step penalty 已被证明能促进快速学习——零初始化值函数下,步罚激励 agent 去尝试没访问过的状态动作对,实现快速探索),且高层奖励指数级大于低层。可证明当 agent 处于任意层 i 时,把上下层归并即退化成一个 3 层 MDP,故诱导出"尽快上爬、不下掉"的棘轮策略。
- **两条定理**:Thm 5.3 用值函数构造法(把到目标/障碍的 t 步轨迹回报 f_t^g、f_t^o 分别证成关于 t 严格递减/递增),反证若存在支配 π* 的策略则与 π* 是最优解矛盾,从而 Tiered Reward 必诱导帕累托最优策略。Thm 5.5 进一步证明它在"累积层访问"意义下最优(最差层访问最少、其余各好层访问最多)。完整证明在附录 A/B。
- **实验中具体取值**:`r_i = 0 (i=k); r_i = (1/(1-γ))r_{i+1} − δ (i<k)`,δ 为满足严格不等式的小常数。深度 RL 中把奖励线性缩放到 [−1,0] 以数值稳定。
- **基线**:action penalty(每步 −1,到目标 +1);tier-based shaping(把 Tiered Reward 当势函数 Φ 去 shape action penalty:`R_tbs = R_penalty + γΦ(s')−Φ(s)`)。

## 数据集 & 实验设置
- **表格域**:Flag Grid(6 层,按持有旗子数分层,动作 80% 成功)、Chain(90 状态一维)、9×9 Grid、Frozen Lake、Wall Grid;算法用 Q-Learning(α=0.9,乐观/零初始化)和 RMAX(基于模型)。表格实验基于 MSDM 库,跑 30–300 个随机种子。
- **深度 RL**:MiniGrid 的 EmptyGrid、FourRooms(长视野)、DoorKey(复杂转移与动作空间,稀疏奖励难解),图像观测,PPO + ImpalaCNN,γ=0.5、200k 步、每环境 30 个种子。EmptyGrid/FourRooms 按到目标的 L1 距离分层,DoorKey 按完成的子目标(拿钥匙/开门/到目标)分层。
- **评测口径**:表格域以"首次到达目标所需步数"衡量学习速度;MiniGrid 用其原始(专家设计)奖励作为评测指标(成功 = 1−0.9×步数/最大步数,失败 = 0),即看 agent 多快学会被规约的行为。还做了 tier 数(2/3/5/7/9)的消融。

## 主要结果 & 结论
- **设计正确性**:在 Russell/Norvig 网格里,满足 `r_lava<r_back<r_goal` 这种"看似合理"的奖励中,随机采样 1000 个有 **90.5% 是帕累托被支配的**(表 1 的 B 即反例),说明直觉奖励常常不对;而 Tiered Reward 有保证。
- **学习速度**:Flag Grid 上 Tiered Reward 学得最快;tier-based shaping 因折扣下同层 shaping 项 `γΦ(s')−Φ(s)>0` 破坏了零初始化的乐观性,探索无方向,反而比 action penalty 还慢几个数量级(即便统一乐观初始化 Q 值后 Tiered Reward 仍稳定领先)。MiniGrid 三个环境上 Tiered Reward 学习最快,FourRooms 因探索难、方差大,初期慢于 shaping 但后来反超。
- **层数影响**:表格域里层数越多学得越快(更多环境信息助力奖励设计),RMAX 结果类似。深度 RL 里因缩放到 [−1,0] 导致高层奖励被归一化到极小(10⁻⁶~10⁻¹⁵)、数值上难以区分,层数过多反而变慢(FourRooms 在 5 层最优),作者用更小的 γ=0.5 缓解,并把数值缩放问题留作未来工作。
- **结论**:Tiered Reward 是一类环境无关、跨表格/高维、跨 RL 算法通用、可证明帕累托最优、且实证快速学习的奖励结构。

## 核心贡献
1. 用帕累托最优在**整个策略空间**上定义严格偏序,绕开了随机环境中难以显式写出的行为权衡。
2. 提出 **Tiered Reward** 这一**环境无关**的奖励函数族,并给出可证明诱导帕累托最优策略的简单不等式条件(无需知道转移概率)。
3. 在多个表格与深度 RL 环境、多种算法(Q-Learning/RMAX/PPO)上实证其学习速度优于 action penalty 与 tier-based shaping 两个基线,且与算法选择无关。

## 局限与我的质疑
1. **来源未经同行评审**:本文为 arXiv 预印本(v3, 2024-08),引用计数 0,未确认正式发表与同行评审。其核心是数学定理(附录 A/B 的证明逻辑自洽、可独立检验),但实验结论应保持保留——我未核验其代码与图表数据。
2. **作者自述局限**:(a)缩放到 [−1,0] 引发**严重数值问题**,使高层奖励几乎无法区分,导致"层越多越好"在深度 RL 里不成立,只能靠调小 γ 临时缓解,根因未解决;(b)只证明了诱导帕累托最优(渐近最优性),**没有"渐近学习更快"的理论保证**,"快"全靠实证,作者自己把它列为未来工作。
3. **适用范围被框得很窄**:整套理论只对"goal–obstacle、好坏状态明确、目标/障碍为吸收态、奖励只定义在状态上"的任务成立。一旦奖励本质上依赖动作或历史(论文自己引用 Abel et al. 2021,有些行为根本无法用马尔可夫状态奖励表达),框架就不适用。"环境无关"也有水分——**分层这一步仍需环境知识**(L1 距离、子目标定义),只是把"设计奖励数值"的难度转移到了"如何分层、分几层",而后者论文承认要靠 MDP 先验或试错。
4. **实验偏弱、基线偏少**:全部是小网格世界(最大 90 状态/9×9),没有连续控制、机器人、真实高维任务;只比了 action penalty 和(被自己证明有缺陷的)tier-based shaping 两个基线,**没有和势函数 shaping 用真最优值函数、curiosity/内在奖励、reward machine 等主流方法做强对比**(作者以"信息量不对等/循环逻辑"为由回避)。所谓"快"很大程度被乐观 Q 初始化与步罚式探索这两个混杂因素裹挟,论文也承认"目的不是论证 shaping 无效、也不是讨论如何初始化 Q 值"——但这恰恰让"Tiered Reward 本身带来加速"的因果归因变得不干净。
5. **与本研究主题(RL 训练可与环境交互的数字人)关联薄弱**:本文是抽象的离散网格世界奖励设计原理,**没有任何数字人、人机交互、连续/高维动作空间或具身控制的实验**。它对主题的价值在于"奖励规约/reward shaping 的理论框架"这条方法论主线(分层奖励 + 帕累托视角 + 子目标分层的思路可迁移到数字人的多阶段交互任务的奖励设计),但能否在高维连续、长视野、含人类反馈的数字人场景里仍保持"环境无关 + 快速学习",论文完全没有触及,数值缩放问题在连续控制里只会更严重。直接照搬需谨慎。
