# Third-Person Visual Imitation Learning via Decoupled Hierarchical Controller
> Pratyusha Sharma, Deepak Pathak, Abhinav Gupta · 2019 · arXiv · 引用 0 · DOI arxiv:1911.09676

## 一句话
让机器人只看一段第三人称的人类示范视频,就能用自己的第一人称视角对新物体完成操作任务——办法是把"该做什么(意图/子目标)"与"怎么做(底层控制)"显式解耦成两层分别学习。

## 解决了什么问题
第三人称模仿学习的根本难点:人类示范(第三人称视角、人手外观)与机器人执行(第一人称视角、机械臂外观)之间存在巨大的视角差和形态差,而端到端从"人类视频→机器人关节轨迹"直接学一个函数需要海量示范数据、且每个任务要单独训练、难以泛化到新任务/新物体。作者要在只看**一段**示范视频、且**不访问环境状态信息(仅靠原始像素)**的前提下完成操作。

## 用什么方法解决的
两层分层结构,两个模块独立监督训练、推理时交替执行:
1. **高层 目标生成器(Goal Generator)**:条件 GAN(pix2pix 风格的 U-Net 生成器 + 判别器),输入是人类示范的两帧 h_t、h_{t+k} 加机器人当前观测 s_t,输出机器人在 t+k 时刻的**视觉子目标图像** ŝ_{t+k}。关键技巧是把"凭空生成目标图像"降级为"按人类示范图像的变化方式去搬动机器人当前图像的像素"(re-rendering 而非 generation),用 L1 损失保证生成正确帧 + 对抗损失保证逼真。
2. **底层 逆控制器(Inverse Controller)**:ResNet-18(ImageNet 预训练)+ 3 层全连接,输入当前状态 s_t 与目标状态 ŝ_{t+1},回归输出 14 维关节角动作(Baxter 双臂各 7 维)。该模块**任务无关、不用时序信息**,可跨任务共享,因而样本高效、不易过拟合。

## 动机 & 背景
人类能"看别人做就学会做",这要求:推断他人意图、把目标翻译到自己的语境、把第三人称动作映射到第一人称动作、再做底层控制。经典 LfD(从示范学)靠动觉示教/遥操作收集数据,通常局限于单任务、单视角。近期工作要么用机器人自身视角、要么仅有微小视角差;用元学习(DAML)的方法每个任务单独训练、难迁移。本文要解决更一般的第三人称设定。作者的核心洞见:与其端到端硬学,不如**显式注入分层结构**,让数据饥渴的底层控制器跨任务共享,把任务相关的部分隔离在高层。

## 数据集 & 实验设置
- **数据**:MIME 数据集(作者自己 2018 年的工作),Baxter 采集,8260 对"人类示范+动觉机器人示范",覆盖 20 个任务。每条样本含三元组:人类示范图序列、机器人示范图序列、机器人关节角序列(配对但**时间未严格对齐**,靠子采样到 200 步粗略对齐)。
- pouring 任务:训练 230 / 验证 29 / 测试 30 条;多任务模型:训练 6632 / 验证 829 / 测试 829。
- **超参**:目标生成器 k=10(在"子目标够细"与"子目标与当前帧差异够大让控制器能预测出变化"间折中);图像 128×128;Adam。
- **基线**:CycleGAN、纯 L1/L2 预测、光流、SIFT/轨迹特征最近邻;End-to-End [27];DAML [30]。
- **评测**:分别单独评估两模块(假设对方完美);再联合部署到真实 Baxter,做 pouring 与 placing-in-box;成功判据为到达/倾倒/放置在目标 5cm 半径内(与 Yu 等人一致)。

## 主要结果 & 结论
- **目标生成器**(pouring 测试集):本方法 L2=39.98、L1=52.37、PSNR=3.95、SSIM=0.18,四项指标均优于 L1-only/L2-only/CycleGAN;光流基线极差(L1 127.28)。
- **逆控制器 RMSE**:Ours(single)8.1、Ours(all)14.4,优于 End-to-End(single 8.9 / all 14.7)与 DAML(11.84);最近邻轨迹特征 22.20、SIFT 45.32 远差。新任务泛化(15 训练任务→5 新任务):Ours 16.90 vs End-to-End 24.83 vs DAML 36.45。
- **联合系统(真实机器人)**:pouring 到达 75% / 倾倒 60%;placing 到达 70% / 放下 50%。基线 End-to-End 与 DAML 仅 8%~25%。作者自承"仍远未达到完美完成"。
- 仿真补充:Sawyer 机械臂逆控制器对新物体新位置 RMSE 6.09。
- **结论**:解耦的分层控制相比端到端在新物体/新配置/新任务上泛化更好。

## 核心贡献
1. 提出"what(任务相关目标生成)/how(任务无关底层控制)"的显式解耦分层框架,用于第三人称、单视频、纯像素的模仿学习。
2. 把跨域目标生成从"图像生成"重构为"按人类示范变化去搬运机器人当前图像像素"的 re-rendering 问题,显著降低条件 GAN 的学习难度。
3. 任务无关、可跨任务共享的逆控制器,带来样本效率与泛化;并在真实 Baxter 上端到端验证 pouring/placing。

## 局限与我的质疑
1. **作者自述局限——无时序、轨迹抖动**:两个模块都按单时间步运作、不用时序信息,导致预测轨迹"shaky"。作者也指出用 LSTM 引入时序会"作弊"记住平均轨迹反而更难泛化——这等于承认当前方法在时序一致性上没有好解法,只能寄望"多任务一起训"缓解,是个未解决的硬伤。
2. **绝对成功率仍很低**:最好的 pouring 也只有 60%、placing 倒下率仅 50%,作者自己说"远未完美"。对于真实部署而言这个可靠性远不够用;且评测判据宽松(5cm 半径算成功),倾倒/放置是否真正完成任务(液体倒进去没有、物体姿态对不对)缺乏更严格度量。
3. **高层目标生成器并非任务无关,泛化主张被夸大**:论文反复强调"解耦带来泛化",但真正任务无关、可共享的只有底层逆控制器;高层仍是任务相关的,"跨新任务"的强结果(Table 3)全部来自逆控制器单独评估、且假设对方完美。联合系统里 placing 是在"只训 pouring"上测的,但 placing 与 pouring 高层意图差异巨大,这种"跨任务"更像是底层控制的复用,而非真正理解了新任务意图——结论有被过度解读之嫌。
4. **数据与可复现性依赖自家 MIME 数据集**:示范"配对但不对齐",靠子采样到 200 步"粗略对齐",这种弱对齐对 GAN 的 L1 监督质量影响很大,但论文没量化对齐误差的敏感性;且全部依赖动觉示范(人手actuate机器人)来获得配对的机器人轨迹,这本身就需要大量人工,削弱了"只看一段视频就会"的卖点。
5. **引用为 0、仅 arXiv、规模小**:发表于 NeurIPS 2019 但 DOI 仍是 arXiv 预印本、被引 0;只在两个任务(pouring/placing)、单一 Baxter 平台上验证,自监督扩展、task-agnostic 高层均被推给 future work,实证覆盖偏窄。
6. **与"RL 训练数字人与环境交互"主题的差距(最关键)**:本文是**监督式模仿学习**,完全没有强化学习、没有奖励、没有与环境的闭环交互试错——逆控制器是 one-step 逆模型回归动作,不是策略优化。对"用 RL 训练能与环境交互的数字人"而言,本文的借鉴点仅在于"从第三人称人类视频蒸馏子目标/跨视角与跨形态对齐"的思路;而数字人需要的物理交互、接触动力学、长时序闭环控制、奖励设计等核心问题,本文都不涉及。其"目标生成→底层控制"的分层思想可作为分层 RL 的高层子目标来源参考,但方法本身不能直接迁移到 RL 数字人交互场景。相关性评 52(弱相关)是合理的。
