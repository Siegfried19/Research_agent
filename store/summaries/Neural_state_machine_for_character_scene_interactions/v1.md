# Neural State Machine for Character-Scene Interactions
> Sebastian Starke, He Zhang, Taku Komura, Jun Saito · 2019 · ACM Transactions on Graphics · 引用 279 · DOI 10.1145/3355089.3356505

## 一句话
提出"神经状态机"(Neural State Machine, NSM)——一个纯数据驱动的自回归深度网络框架,让虚拟角色仅凭高层指令(目标位置 + 动作类型)就能实时生成走向椅子并坐下、开门穿门、搬运箱子、绕障等带精确场景交互的高质量动作。

## 解决了什么问题
监督学习的动作合成此前主要局限在周期性的行走/奔跑(如 PFNN),难以扩展到日常的场景交互任务。原因是"坐到椅子上"这类看似简单的任务实际涉及:对场景几何的高层理解、绕障路径规划、把角色**精确定位与定向**到目标、以及在周期(走)与非周期(坐/开门)动作之间自动衔接转换。本文要在一个模型里同时解决"多模态动作混合不糊、到达目标足够精确、能适配各种家具几何形状"这三件事。

## 用什么方法解决的
- **双网络自回归架构**:Motion Prediction Network(运动预测网,主体)逐帧根据上一帧姿态 + 周围几何 + 高层指令预测当前帧;Gating Network(门控网)根据目标和运动**相位**输出 8~10 个专家权重的混合系数,动态生成预测网的权重(mixture-of-experts)。借此把差异巨大的动作分别编码进不同专家,避免模糊。
- **学习式相位代替固定相位函数**:不同于 PFNN 用单一预定义周期相位函数,本文把相位(2D 正余弦向量)与动作标签、目标距离/角度通过 **Kronecker 积**喂进门控网,让网络自己学出各动作专属的周期/非周期相位函数,从而单模型容纳走、坐、开门、搬运等。
- **双向控制(bi-directional)**:同时从"以角色为中心(egocentric)"和"以目标为中心(goal-centric)"两个坐标系预测未来轨迹与关节位置,按距离加权融合后反馈回网络,抵消纯 egocentric 推断的误差累积,显著提升到达目标的精度。
- **体素化几何传感器**:用两个体积传感器——环绕角色的圆柱形 Environment Sensor(感知障碍/环境)和环绕目标物体的 8×8×8 立方 Interaction Sensor(感知物体细节如扶手)。体积表示能编码**凹形**几何(墙洞、被桌子挡住需侧身坐),克服了高度图表示的局限。
- **数据增强**:从 ShapeNet 取物体池,每帧随机替换/变换几何,用关系描述子(relationship descriptors)+ 全身 IK(CCD)重算姿态以保持运动语境一致,从而在**不增加数据量**的前提下覆盖广泛形状(训练仅用 20 把椅子、2 桌、3 箱、2 窗)。

## 动机 & 背景
角色与环境的关系很大程度上决定了动作的逼真度。深度监督学习在行走类周期动作上已成功(Holden 等的 PFNN),但扩展到带场景交互的日常任务一直是未解难题:需要一连串复杂动作与转换、高层场景理解、并适应各种 3D 几何。相关工作中,基于运动捕捉的模板/核方法可扩展性差、内存与近邻搜索成本高;基于探索/优化(RRT、A*、RL、接触不变优化)的方法大多回放已有数据或难以实时;强化学习在物理仿真里对"低能耗日常动作"难以设计奖励函数。本文走纯监督、实时、可控的路线。

## 方法细节
- **输入** Xi 含四部分:Frame Input(上一帧 23 关节的位置/旋转/速度 + 过去/未来 2 秒内 13 个采样点的根轨迹与 7 类连续动作标签)、Goal Input(目标位置/朝向 + 6 类 one-hot 目标动作,climb 因难定时机被排除在目标动作外)、Interaction Geometry(R^512)、Environment Geometry(R^1408)。
- **输出** Yi 含:egocentric 坐标下的当前关节姿态/速度、未来 egocentric 与 goal-centric 两套轨迹、更新后的目标参数、5 个关键关节(双脚双手 + 髋)接触标签、1 维相位增量 pÛ。输出反馈回输入构成自回归。
- 各编码器为三层全连接(隐藏/输出维 512/128/256/512);预测网隐藏层 512,激活函数为 ELU。门控网三层,隐藏 128,softmax 输出专家系数。
- 训练:TensorFlow,MSE 损失,AdamWR + warm restart,学习率 1e-4、权重衰减 2.5e-3。
- 运行时控制分两模式:高层目标驱动(鼠标选物体 + 键盘选动作,角色自动走过去并在正确时机触发交互)和低层操控(键盘/手柄直接控行走),二者可无缝切换。

## 数据集 & 实验设置
- XSens 惯性动捕,共 **94 分钟**数据(镜像后翻倍)。动作分布:行走 43.3%、空闲 26.7%、坐 22.2%、搬运 7.7%、跑 5.9%、开门 2.1%、攀爬 1.9%。
- 每帧人工标注:当前动作标签、未来的目标动作标签、相位标量(行走按左右脚落地定 0/π/2π 插值,非周期动作按转换起止定 0/2π 插值)。
- 训练数据 16GB,70 epoch(在 epoch 11、31 重置学习率),batch 32,单张 GTX 1080Ti 约 20 小时,网络约 250MB。运行时在 Unity 实现,实时。
- **对比基线**:MLP、PFNN、MANN、LSTM、Auto-LSTM(概率 teacher forcing),复杂度设为相近、同输入输出。评测维度:响应时间、到达精度(位置误差 PE / 旋转误差 RE)、脚滑(脚离地 <2.5cm 时的水平漂移)。坐的测试用未在训练集中的椅子。

## 主要结果 & 结论
- **精度** NSM 全面领先:坐 PE 2.93cm / RE 0.92°,搬运 PE 3.05cm / RE 1.02°,优于 MANN(坐 5.54/1.87)、PFNN(坐 7.66/3.31)、LSTM(6.14/2.05)、MLP(14.05/4.11)等。
- **响应性**:从 idle 到 run 0.81s、idle 到 walk 1.49s,优于或持平最佳基线;LSTM/Auto-LSTM 响应慢且无法完成训练中未见的转换(如"跑→坐"直接失败)。
- **PFNN 对比**:PFNN 单一周期相位函数在高度多模态数据上产生不必要的姿态混合,导致穿模和抖动伪影;NSM 学习式相位避免了这一点。
- **MANN 对比**:MANN 响应性好、精度优于 PFNN 但不及 NSM,且脚滑更严重(仅靠脚速分割运动类型不够)。
- **消融**:去掉双向控制(坐 PE 升到 4.27)、Interaction Sensor(3.72)、Environment Sensor(角色会无视障碍穿过椅子)、或用拼接代替 Kronecker 积,精度/质量都下降。
- **泛化**:数据增强使角色能坐上训练中未见的新椅子,并在有扶手时把手放上去。
- 结论:单一模型即可实时合成多种带场景交互的周期/非周期动作,用户只需给抽象目标即可引导,适用于游戏、VR/AR。

## 核心贡献
1. 控制信号 + 自回归架构,实现差异巨大的高层动作状态之间的自动转换,同时保持实时与动作质量;
2. 融合 egocentric 与 goal-centric 推断的双向控制框架,提升目标驱动任务精度;
3. 体积(体素)表示,支持凹形物体/环境的交互;
4. 高效数据增强,在不增数据量下覆盖广泛几何;
5. 与多个 SOTA 的系统性对比与消融分析。

## 局限与我的质疑
- **作者自述局限**:① 几何泛化弱——只用极小的几何集合训练,对与训练集差异较大的形状(如造型怪异的椅子)会失败(手放不上扶手、髋部悬空);需更高分辨率体素或预训练的 PointNet++ 等更强几何编码器。② 切换目标动作时输入突变导致动作突兀,需 0.25–0.5s 时间窗平滑,但窗口越长响应越慢。③ 交互类型仅限于坐/拿/避障,种类有限。④ 相位标注严重依赖人工与启发式规则,周期清晰的动作能自动标,但一般非周期动作及"边走边挥剑"这类多周期叠加的动作难以泛化检测。
- **我的质疑(数据与评估)**:数据仅 94 分钟、单一受试者采集,动作分布高度偏向行走(43%)与坐(22%),开门仅 2.1%、攀爬 1.9%——少样本动作的"成功"主要靠定性视频展示,定量表(Table 2/3)只覆盖 sit/carry 两类任务,响应/精度对开门、攀爬、避障几乎没有数字支撑,结论的普适性被视频效果放大了。精度评测也只取 10 个起始位姿、单一测试椅,样本量偏小。
- **我的质疑(方法是否站得住)**:整个框架依赖**逐帧人工相位标注**和大量半自动接触点指定(换物体投影失败时要手动指点),这与"纯数据驱动、可扩展"的宣称之间存在张力——本质仍是高度工程化、依赖人工先验的流水线,难以低成本扩到新动作库。双向控制虽降误差,但融合权重 λ 是手工设计的启发式(随距离衰减),并非学到的,鲁棒性边界不清。
- **与"RL 训练数字人与环境交互"主题的差距**:本文是**纯监督运动学(kinematic)**方法,角色不受物理约束、无动力学/接触力建模,靠 IK 后处理消穿模,因此无法处理外力扰动、推拉、被绊倒后恢复等物理交互;也不具备 RL 那种通过试错探索"训练数据中未出现"的新策略的能力(LSTM 对比里恰恰暴露了监督法无法外推未见转换)。它擅长在**已采集的交互语境内**做高质量插值与定位,但与"让数字人在仿真中通过奖励自主学会与环境物理交互"是正交甚至互补的路线——常被后续物理 RL 工作(如 DeepMimic 系谱)当作参考动作/运动先验来源,而非交互能力本身的来源。
