# From Sparse to Dense: Toddler-inspired Reward Transition in Goal-Oriented Reinforcement Learning
> Junseok Park, Hyeonseo Yang, Min Whoo Lee, Won-Seok Choi, Minsu Lee, Byoung-Tak Zhang · 2025 · arXiv · 引用 0 · DOI arxiv:2501.17842

## 一句话
模仿幼儿"先自由探索(稀疏奖励)、再目标导向(稠密奖励)"的发育过程,提出在目标导向强化学习中用势函数把奖励从稀疏平滑过渡到稠密(S2D),从而在不改变最优策略的前提下提升样本效率、泛化和训练稳定性。

## 解决了什么问题
RL 中奖励密度难以拿捏:纯稀疏奖励鼓励探索但学得慢、反馈稀少;纯稠密奖励反馈频繁、收敛快但容易让智能体只顾短期收益、过早锁死到次优局部解,在高维(如第一人称 3D 图像)环境里尤其严重。固定一种奖励密度无法同时兼顾探索与利用。作者要找的是一种**在训练过程中动态调整奖励密度**、又能保证最优策略不被改变的课程式方案。

## 用什么方法解决的
把奖励密度变化建模成一个多阶段课程(一串只在奖励函数 R_i 上不同的 MDP),用**势函数奖励塑形(PBRS)** 实现"稀疏→稠密"过渡:势函数 Φ(s)=diam_p(S)−‖s−g‖_p(基于到目标的欧氏/曼哈顿距离),附加奖励 F_i=γΦ(s')−Φ(s)。PBRS 的策略不变性定理保证加上 F 后最优策略集不变(论文形式化为 S2D-curriculum:supp(R_1)⊆…⊆supp(R_N) 且 Π*_1⊇…⊇Π*_N)。第一阶段 F_1=0(纯稀疏自由探索),到预设步数 T 后切入带势函数的稠密阶段(Algorithm 1)。对照四种奖励策略(Only Sparse / Only Dense / S2D / D2S)外加内在动机基线(NGU、RND)。并用自研 **Cross-Density Visualizer** 画策略损失地形、用 sharpness 指标量化"宽极小值",以及借 Tolman 迷宫(RNN 特征收敛距离、动作频率、轨迹可视化)分析早期自由探索的作用。

## 动机 & 背景
- 探索 vs 利用是深度 RL 的核心矛盾;奖励密度直接塑造这个平衡。稀疏奖励(只在到达目标才给)促进探索但学习慢;稠密奖励(频繁反馈)加速学习但易短视、陷次优。
- 生物启发:人类幼儿天然地"先无目的自由探索(类比稀疏)→ 随成长转向目标导向、由越来越密的反馈/视觉线索引导(类比稠密)"。作者把这一发育顺序搬进 RL,称 **Toddler-inspired Sparse-to-Dense (S2D) Reward Transition**。
- 课程学习文献里多为"由易到难";本文走"general-to-specific"(先广泛积累经验再利用)路线。PBRS(Ng et al. 1999)提供了"加塑形奖励不改最优策略"的理论保证,但传统 PBRS 全程恒定使用,本文创新点是**让密度随时间动态变化**。
- 还重新诠释了认知心理学家 Tolman 的老鼠迷宫实验(无奖励组/恒定奖励组/延迟奖励组),其中"延迟奖励组"(先无奖励自由探索、后引入奖励)表现最好,被类比为 S2D,佐证早期自由探索能形成"认知地图"。本文是作者 AAAI 2024 工作 [47] 的扩展。

## 方法细节
- **S2D 课程定义**:一串 MDP {M_i},reward 支撑集单调变密(式2)、最优策略集单调收缩且后阶段最优在前阶段也最优(式3)。用 PBRS 满足这两个条件。
- **势函数**:Φ(s)=diam_p(S)−‖s−g‖_p,p=2(欧氏)或 p=1(曼哈顿);稠密奖励按"离目标越近越高"给,各环境有具体距离阈值(Table 1)。
- **训练流程(Algorithm 1)**:第一阶段 F_1=0(纯稀疏),到 T_k 后切阶段;每步 r̃_t = r_t + F_k,存 replay buffer,用 SAC/PPO/DQN/A3C 更新。
- **损失地形可视化(Cross-Density Visualizer)**:沿 θ̃=θ+αx+βy 扰动参数画策略损失三维地形(法 Li et al. 2018),α,β∈[−10,10],对比 S2D / Only Sparse / D2S / Only Dense 过渡后的地形平滑度。
- **宽极小值(sharpness 指标)**:用 SAM 式 sharpness(式5,ρ=0.02,p=q=2)量化极小值宽窄,sharpness 越低 = 极小值越宽 = 泛化越好。
- **Tolman 迷宫分析三件套**:① RNN 隐状态在固定轨迹上的平均成对 ℓ2 距离(衡量内部表征收敛快慢);② 离散动作(前进/左转/右转)频率随训练的分布;③ 2D 俯视轨迹可视化(看探索是否多样)。
- **过渡时机消融**:比较 t∈{1N,2N,3N}(N≈整个训练的 1/12),记为 C1/C2/C3。

## 数据集 & 实验设置
- **环境(主文)**:LunarLander-V2、CartPole-Reacher、UR5-Reacher(MuJoCo 机械臂,6 自由度,目标每回合随机)、ViZDoom-Seen/Unseen(第一人称 3D 导航,墙面纹理换新测泛化)、Minecraft Cross Maze 与 Playroom Maze(第一人称 3D,出生点/目标随机,视觉杂乱)。
- **附录扩展环境**:ViZDoom-FourObjects(三难度级、三阶段奖励)、RWARE 货架配送(单智能体改版、含子目标、三阶段引导)、Gridworld(10×10/4×4,验证 DQN/PPO 上的地形平滑)。
- **算法**:状态型任务用 SAC;ViZDoom 用 A3C;Minecraft/RWARE/Gridworld 用 PPO;另测 DQN。每配置≥5(部分≥6)随机种子。内在动机基线:离散环境 NGU、连续环境 RND。
- **硬件**:4×RTX 3090 + 2×RTX 2080Ti + AMD Threadripper 3960X,188GB RAM。
- 评估指标:成功率、样本效率、回合长度、完成回合数、sharpness。

## 主要结果 & 结论
- **性能(Table 2)**:S2D 在几乎所有环境上领先。UR5-Reacher 上 S2D(C3) 达 94.15,而 Only Sparse、D2S 全是 0.00(几乎学不会);CartPole-Reacher S2D(C2)=14.61 远高于 Only Sparse 0.14;Cross Maze、Playroom Maze 各目标点 S2D 均居首。D2S 在所有环境都低于 S2D。内在动机方法擅长发现新状态但难聚焦目标。
- **过渡时机**:最佳切换点大约落在训练前 1/4~1/3(类比幼儿"关键期");UR5 需要更长的早期自由探索。ViZDoom-FourObjects 上不同难度最佳时机不同(Level1/3 在 1M,Level2 在 2M),时机错了(如 C3/C5)在 Level2 直接 0% 学不会。
- **损失地形**:S2D 过渡后策略损失地形显著平滑、局部极小值变浅,有助跳出局部最优(Figure 5、附录 B/C);SAC/PPO/DQN 上都观察到该平滑效应。
- **宽极小值**:Table 2 中表现最好的 S2D 同时 sharpness 最低(极小值最宽)。注意 UR5 上 Only Sparse 出现"sharpness 异常低但性能近零"的反例,作者解释为梯度停滞/无更新导致的假象。
- **Tolman 迷宫**:S2D 智能体回合更短、样本效率更高;早期稀疏阶段轨迹更发散多样(Only Dense 则"角度化"直冲目标);RNN 特征在过渡后收敛更快(图9a),动作分布更稳定(图9b)。佐证"早期自由探索 → 稳健初始参数(类似认知地图)→ 后续稠密阶段更稳更泛化"。
- **结论**:动态奖励密度过渡(S2D)优于静态奖励;早期自由探索是关键;未来方向包括自动决定过渡时机(元学习/自适应调度)、结合 model-based RL、扩展到多智能体与真实机器人。

## 核心贡献
1. **性能提升**:S2D 在离散/连续动作空间上均提升成功率、样本效率与泛化,优于 Only Sparse/Dense/D2S 及内在动机基线。
2. **多环境验证**:在机械臂操控与视觉导航任务上验证,并自建 ViZDoom、Minecraft 迷宫等定制 3D 环境。
3. **损失地形分析**:用 Cross-Density Visualizer + sharpness 指标证明 S2D 平滑策略损失地形、形成更宽极小值。
4. **Tolman 迷宫的 RL 再诠释**:量化早期自由探索如何建立稳健初始策略,提升过渡后稳定性与泛化。

## 局限与我的质疑
1. **来源未经同行评审**:本文是 arXiv 预印本(2025-01),引用 0,是作者 AAAI 2024 工作的扩展版。主文结论尚未经独立同行评审确认,以下数字与论断我按"待验证"对待。
2. **作者自述局限**:① 过渡时机目前靠人工预设(固定步数),不同环境最优时机差别很大(1M vs 2M)、错了就完全学不会,鲁棒性堪忧,作者把"自动化时机"列为未来工作;② 在含子目标的 RWARE 任务上,"最优奖励塑形策略仍是开放难题"(附录 14.2.6 明确承认);③ 仅用了 model-free RL,未验证 model-based。
3. **"势函数=到目标距离"本身泄露了大量任务信息**:稠密奖励直接用智能体到目标的欧氏/曼哈顿距离,等于把"目标在哪、怎么靠近"喂给了智能体。S2D 相对 Only Sparse 的优势,很可能主要来自这个**强先验的距离塑形**,而非"幼儿式过渡"这个时间安排本身。论文没有充分隔离"过渡调度"与"距离势函数"两者各自的贡献(Only Dense 也用同一个势函数,但缺一个"恒定稀疏+同样信息量塑形"的干净对照来归因)。需要目标位置未知/不可计算距离的任务才能检验该方法的真正普适性。
4. **"幼儿启发"主要是叙事包装**:全文的生物学/Tolman 类比是动机修辞,真正的算法内核就是"分阶段 PBRS 课程"。把成功归因于"模仿幼儿发育"有过度解读之嫌——同样的曲线完全可以用"先广探索建立好初始化、再用稠密信号精修"的纯优化语言解释,不需要幼儿叙事。Tolman 迷宫的"认知地图"类比也只是定性比附,RNN 特征距离下降并不能直接证明形成了"认知地图"。
5. **统计严谨性存疑**:种子数偏少(多为 5~6),而 Table 2 里方差极大(如 LunarLander S2D(C2) Perf=63.40±160.55、Sharp=1231.93±2424.61),在这种波动下宣称"S2D 同时性能最好且 sharpness 最低"说服力有限;UR5 上 Only Sparse 的 sharpness 反例也说明 sharpness 指标本身在性能塌缩时会失真,"宽极小值→泛化"的因果链更多是相关性叙述而非严格证明。
6. **与本研究主题(RL 训练可与环境交互的数字人)的差距**:本文的"数字人"成分很弱——所谓 playroom/toddler 只是 Minecraft 里的导航智能体,没有人体/类人形态、没有人机交互、没有具身多模态感知,纯粹是点目标导航。它对本主题的价值仅在**奖励塑形与稀疏奖励课程的方法层面**(reward shaping、稀疏→稠密课程),而非"数字人与环境/人交互"的建模本身;若要迁移到真正的具身数字人,距离势函数这种低维强先验大概率失效,需要重新设计势函数,本文未涉及。
