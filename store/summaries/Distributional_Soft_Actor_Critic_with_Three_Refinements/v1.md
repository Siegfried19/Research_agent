# Distributional Soft Actor-Critic with Three Refinements
> Jingliang Duan, Wenxuan Wang, Liming Xiao, Jiaxin Gao, Shengbo Eben Li, Liu, Chang, Zhang, Ya-Qin, Cheng, Bo, Li, Keqiang · 2023 · arXiv (Cornell University) · 引用 55 · DOI 10.48550/arxiv.2310.05858

## 一句话
在作者自己此前提出的分布式 Soft Actor-Critic（DSAC，即 DSACv1）上加三项工程化改进——期望值替换、双值分布学习、基于方差的 critic 梯度调整——得到 DSAC-T（又名 DSACv2），主打**训练更稳、对 reward scaling 不敏感、且无需逐任务调超参**。

## 解决了什么问题
DSACv1 用连续高斯值分布学习来提升价值估计精度、缓解过估计,但实践中暴露三个毛病:"DSACv1 faces challenges such as training instability and sensitivity to reward scaling, as well as high variance in critic gradients due to return randomness"(Abstract)。即:把 return 的随机性引入 critic 梯度导致更新不稳;固定的 return 裁剪边界 b 使更新幅度随 reward 尺度变化,需要为每个任务手工调 reward scale。

## 用什么方法解决的
针对上述三点对症下三味药:期望值替换稳住均值更新、双值分布学习压过估计、基于方差的梯度调整去掉对 reward 尺度的手调依赖。三者都只在算法层动手,不改 DSPI 收敛框架。

## 动机 & 背景
model-free RL 常因 Q 值过估计(Bellman 的 max 算子作用在带噪估计上)导致策略变差。作者前作用**分布式价值函数**(学 return 的高斯分布而非只学期望)来缓解过估计,但 DSACv1 因把 return 随机性塞进 critic 梯度而易不稳、且对 reward 尺度敏感(固定裁剪边界 b 与 reward 幅度强相关)。本文目标是在保留分布式价值优势的同时修掉这两个实用性短板,并进一步提精度。

## 方法细节
基础框架是 Distributional Soft Policy Iteration(DSPI):定义 soft state-action return 的分布 𝒵^π,用 KL 散度拟合分布式自洽算子 𝒯_𝒟^π 的目标(式 6–7)。标准 DSAC 的 critic 梯度(式 11)被拆成两部分——**mean-related gradient**(含 return 一阶项)和 **variance-related gradient**(含二阶项);后者在 |TD|→∞ 时会爆炸,DSACv1 靠对 target return y_z 做裁剪 C(·)(式 12,固定边界 b)来压。三项改进:

1. **期望值替换(Expected value substituting)**。DSACv1 只裁剪了 variance-related 梯度里的随机性,mean-related 梯度仍随机。作者证明随机 target return y_z 与用 target Q 值算的 y_q(式 16–17)在期望意义下等价,于是把 mean 项里的 y_z 换成更确定的 y_q(式 18):"DSAC-T uses expected value substituting to stabilize mean-value updates, where the random target return is replaced by a more stable target Q-value, essentially the expected value of the target return"(p.2)。换完后第一项就退化成类似 SAC 的非分布式 Q 更新,稳定性向常规 RL 看齐。

2. **双值分布学习(Twin value distribution learning)**。"we introduce a distributional version of clipped double Q-learning, called twin value distribution learning"(p.2)。训练两套独立参数 θ₁、θ₂ 的值分布,取均值较小者的下标 ī := arg min_{i=1,2} Q_{θ̄_i}(式 19)来构造目标:"The value distribution with the smaller mean value is chosen to construct critic and actor gradients"(p.5)。作者称这倾向于轻微**低估**,而低估比过估计更可取(低估动作不会被策略反复选中传播)。

3. **基于方差的 critic 梯度调整**。把固定裁剪边界改成自适应:b = ξ·E_{(s,a)}[σ_θ(s,a)](式 23),"Typically, we can set ξ = 3 following the three-sigma rule"(p.6)。同时引入梯度缩放权重 ω = E[σ_θ(s,a)²](式 24–25)抵消"更新幅度被方差调制"带来的 reward 敏感性,并加 ε、ε_ω 防梯度爆炸/消失(式 26)。b 和 ω 都用滑动平均估计(式 27)。

完整流程见 Algorithm 1(初始化 target 网络→采样存 buffer→更新 critic/actor/温度 α/target 网络)。作者强调:"Since DSAC-T introduces refinements only at the algorithmic level, its theoretical convergence properties remain the same as those of DSACv1"(p.6),即沿用 DSPI 已证明的一致收敛性,本文未给新收敛证明。

## 数据集 & 实验设置
基于 OpenAI Gym,"including 11 vector-input-based control tasks (Humanoid, Ant, HalfCheetah, Walker2d, InvertedDoublePendulum, Hopper, Pusher, Reacher, Swimmer, Bipedalwalker, and Bipedalwalker-hardcore) and one image-input-based control task (CarRacing)"(p.6),每个任务跑 5 个随机种子。基线为 DDPG、TRPO、PPO、TD3、SAC,以及前作 DSACv1。所有算法用同一模块化结构(3 层、每层 256 单元、GELU;CarRacing 加 6 层卷积编码器)。关键超参(表1):Adam、actor/critic 学习率 1e-4、γ=0.99(Hopper 用 0.999)、τ=0.005、reward scale=1、DSAC-T 的 ξ=3、ε=ε_ω=0.1。**公平性说明**:对比时 DSAC-T 用自适应边界 ξ=3,而 DSACv1 用固定 b=20。

## 主要结果 & 结论
- **总体表现**:"Our results reveal that DSAC-T surpasses (at least matches) the performance of all baseline algorithms across all benchmark tasks"(p.7)。以 Humanoid-v3 为例,"compared with SAC, TD3, PPO, DDPG, and TRPO, our algorithm shows relative improvements of 16.0%, 92.3%, 57.7%, 104.7%, and 1022.2%, respectively"(p.7)。表2 中 Humanoid-v3 DSAC-T 取得 10829±243,高于 DSACv1 的 9074±286 和 SAC 的 9335±695。需注意"at least matches"——在部分简单任务(如 Reacher-v2、Pusher-v2、Swimmer-v3)上它与最强基线基本持平甚至非最优(Swimmer 上 DDPG 的 146±4 略高)。
- **价值估计偏差(表3)**:DSAC-T 多数任务偏差为负(轻微低估),与"低估优于过估计"的设计取向一致。与专门抑制过估计的 RAC-SAC 对比,"The results show that DSAC-T achieves superior estimation accuracy in both Humanoid (estimation bias: -42.29 vs. 97.78) and Ant (estimation bias: -10.55 vs. -18.82)"(p.9)。
- **消融**:去掉期望值替换(改回式 13)或去掉双值分布,在 Humanoid-v3 上稳定性和最终表现都更差——"This confirms the significant contributions of the expected value substitution technique, defined by (18), and the twin value distribution learning technique to learning stability and efficacy"(p.9,图4)。reward scaling 消融中,去掉方差梯度调整的版本"struggles to learn an effective policy under lower reward scales, specifically at 0.01 and 0.1"(p.9-10,图5),而完整 DSAC-T 跨 0.01×–5.0× 尺度表现稳定。
- **代价**:精度提升伴随计算变慢——每 1000 次迭代 "DSAC-T (35.51s), DSACv1 (29.00s), SAC (35.02s), TD3 (31.41s), and DDPG (25.20s)"(p.8-9),DSAC-T 是其中最慢的。
- **真实部署**:"We utilized the Geekplus M200 mobile robot as the experimental platform, tasked with precisely following a reference path ... with a desired speed of 0.28 m/s"(p.9-10),策略网络以 50Hz 运行于 Intel N4200 CPU,完成跟踪+动态避障(仿真训练→实机部署,图7/图8)。

## 核心贡献
1. **期望值替换**:用确定的 target Q 值替换 mean-related 梯度里的随机 target return,把分布式 critic 的均值更新稳定到接近常规 RL。
2. **双值分布学习**:clipped double Q-learning 的分布式版本,取双分布中较小均值者,进一步压过估计并倾向轻微低估。
3. **基于方差的 critic 梯度调整**:用 b=ξ·E[σ] 的自适应裁剪边界 + 方差缩放权重,消除对 reward scale 的逐任务手调,声称无需 task-specific 调参即"matches or outperforms"主流算法(Abstract)。

## 局限与我的质疑
1. **作者自述——单峰高斯表征受限**:"we utilize a unimodal Gaussian distribution to approximate both the value distribution and the stochastic policy. However, in tasks with multiple goals and complex dynamics, the true distributions may exhibit multimodal characteristics"(p.11),多峰任务下表征力不足,作者把 diffusion 等多峰近似留作 future work。
2. **对比设置可能偏向自家**:DSAC-T 用自适应 ξ=3,而 DSACv1 用固定 b=20——这正是被改进的痛点。固定 b=20 在某些任务/reward 尺度下未必是 DSACv1 的最优配置,因此"对 DSACv1 的提升"里有多少来自自适应边界、多少来自其它两项,边界划分不完全干净(消融只在 Humanoid 单任务上做了期望替换/双分布两项,**未见**对自适应边界 vs 调优固定 b 的同任务并列消融)。
3. **"无需调超参"是相对而非绝对**:仍需设 ξ、ε、ε_ω、γ(Hopper 单独用 0.999),只是声称不必逐任务调 reward scale;reward scaling 鲁棒性也只在 HalfCheetah 单任务上展示(图5),跨任务的尺度鲁棒性证据有限。
4. **"全面超越"需打折**:原文用词是"surpasses (at least matches)",且 Swimmer 等任务上并非第一;相对提升的巨大数字(如对 TRPO +1022.2%)更多反映弱基线在该任务上的失败,而非 DSAC-T 的绝对优势,解读时应区分强/弱基线。
5. **理论无新增**:收敛性直接沿用 DSACv1 的 DSPI 证明,本文三项改进均为工程化技巧,期望值替换的"等价"基于期望意义,实际有限样本下 y_q 与 y_z 的偏差对收敛的影响未作分析。
6. **与本主题(RL 训练稳定性/超参敏感性)契合度高但成本需权衡**:它确实针对"训练不稳+reward scaling 敏感"给出可落地方案,但代价是最慢的单步计算(35.51s/1000it),复用时要在稳定性收益与算力开销间权衡。
