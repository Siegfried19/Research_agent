# WoCoCo: Learning Whole-Body Humanoid Control with Sequential Contacts
> Chong Zhang, Wenli Xiao, Tairan He, Guanya Shi · 2024 · Conference on Robot Learning · 引用 107 · DOI 10.48550/arxiv.2406.06005

## 一句话
把"涉及序列接触的人形全身控制"任务统一拆解成一串"接触阶段(contact stage)",再用一套**任务无关**的奖励与 sim-to-real 设计,让纯端到端 RL(每个任务只需加 1–2 个直观奖励项)在**无任何动作先验**下学会跑酷跳跃、搬箱子、跳舞、攀岩四类真实人形任务。

## 解决了什么问题
人形机器人完成现实任务往往要求按特定顺序"踩点/接触"(脚踩石头、手扶箱子、四肢贴墙)。传统做法靠基于模型的运动规划/轨迹优化:慢、依赖简化降阶动力学、运动质量与真机表现受限;model-free RL 虽鲁棒,但现有工作要么为每个任务/状态机转移单独调一套奖励与状态机,要么受制于长时序探索难题(接触稀疏、复合失败风险让策略不敢探索、域随机化反而妨碍探索)。缺一个**系统、通用、能在真机上按期望接触序列控制人形**的 RL 方法。

## 用什么方法解决的
将任务重构为"顺序完成 I 个接触阶段",每阶段由**接触目标 g^con**(哪些末端执行器该处于何种接触态)+**任务目标 g^task**(姿态等附加要求)定义,阶段完成由传感器/人判定后推进。核心是三项**任务无关的 WoCoCo 奖励**:① **稠密接触奖励**(数对每一次正确/错误接触,优于 0-1 奖励;首阶段屏蔽错误惩罚以鼓励探索);② **阶段计数奖励**(完成阶段越多奖励越高,逼策略往后探索,防止"赖在当前阶段吃稳定奖励");③ **好奇心奖励**(用随机冻结 NN 做 hash 的 count-based 计数好奇心,任务无关,避免 RND 过度探索危险行为)。配合**三阶段 sim-to-real 课程**(先无域随机化收敛→再加域随机化→再每 2000 步把正则奖励权重提 20% 直到翻倍),用 PPO + 对称增强在 Isaac Gym 训练,纯 MLP 端到端策略输出关节目标位置经 PD 跟踪。每个任务只需追加 1–2 个直观任务奖励。

## 动机 & 背景
- 人形要像人一样在环境中操作,常需按序完成接触。给定接触计划,经典解法是基于模型的运动规划/轨迹优化生成全身参考再跟踪——强但慢、靠简化动力学、影响运动质量与真机表现。
- model-free RL 对模型失配/不确定鲁棒,已实现腿足实时敏捷运动;但多数聚焦无序列接触约束的标准行走。少数带落脚点约束的 RL 工作高度针对特定场景调参;真机人形的踢球、loco-manipulation 等也是每个任务/状态机转移单独调一套公式与奖励,难扩展到长时序。
- 对比:单个基于模型的求解器(如 Crocoddyl)只需微调几个直观代价项就能覆盖多任务。作者问:RL 能否也做到这种简洁与适应性?并归纳三大挑战:接触稀疏、机器人因复合风险不敢探索全程、sim-to-real(域随机化+任务无关正则奖励会妨碍探索)。

## 方法细节
- **问题形式化**:扩展 MDP ⟨S,A,T,R,γ,G^con,G^task⟩;目标是找最优策略 π*(s_t | g^con_{i:I}, g^task_{i:I})。奖励 r = r_WoCoCo + r_reg + r_task,前两项任务无关,r_task 仅含少量直观项。
- **稠密接触奖励 r_con**(式3):`r_con = (n_corr − n_con·n_wrong)·1(n_stage>0) + 2·n_con²·F_con·F_task`。n_con=接触序列涉及的最大末端数,n_corr/n_wrong=当前步正确/错误接触数,F_con/F_task=接触/任务目标是否满足的布尔值。系数为避免局部最优而设;首阶段(n_stage=0)屏蔽 n_wrong 惩罚,避免一 reset 就吃惩罚而不敢探索。
- **阶段计数奖励 r_stage = n_stage·F_task**(式4):完成阶段越多奖励越高,驱使前进;乘 F_task 防止"故意不达任务目标来囤积阶段计数"。
- **好奇心奖励 r_curi**(式5/6):弃用 RND(易过度探索无意义/危险状态),改用 count-based:随机初始化并冻结的 NN f_curi 把任务无关的好奇心观测 o_curi 映射后按符号位拼成二进制再转十进制作为 bucket id,`r_curi = 1/√(该 bucket 访问次数)`。访问越多奖励衰减,天然抑制随机网络过拟合。
- **sim-to-real**(3.2 + 附录):域随机化(摩擦、质心偏移、连杆质量、PD 增益、力矩 RFI、0–20ms 控制延迟、推力、地形等)+ 正则奖励;所有人形任务共享同一套设置。三阶段课程见上。叠 3 个控制步的历史关节状态/动作增强时序记忆。非跳跃任务额外加 "feet air time""no fly" 两个风格塑形项。
- **策略**:Actor/Critic 均为 [512,256,128] MLP;观测含本体感知(关节位置/速度/上次动作各叠3步、基座线/角速度、投影重力)+ 目标表示(动捕提供作原型);跳跃任务喂未来两阶段目标以提前调整落脚点,其余只喂当前阶段。PPO + 左右对称增强提数据效率。
- **部署**:策略 50Hz,PD 200Hz,PD 目标过 4Hz Butterworth 低通滤波去抖。发现官方 URDF 躯干质量偏差大、足部几何错误,自行称重/测量修正。

## 数据集 & 实验设置
- 仿真在 Isaac Gym,大规模并行 RL(基于 Rudin 等框架)。无外部数据集、**无动作参考/先验**。
- **四个真机人形任务**:① 多样跑酷跳跃(单/双脚切换、3D 受控落地、上身姿态"hug/relax"跟踪;真机受场地限制只测了双脚接触的一两连跳);② Anywhere-to-Anywhere 箱子 loco-manipulation(两阶段:扶箱→搬到目的地,无姿态先验);③ 动态 clap-and-tap 跳舞(脚精确踏点+可选拍手,Left/Middle/Right 三动作组合);④ 双向崖壁攀爬(四肢精确贴目标区,真机用人手持木板代替崖壁)。
- **跨形态泛化**:22-DoF 恐龙机器人用六个末端(头/尾/四足)推球到指定点,并让球轨迹画出"WoCoCo"字样。
- **消融**(基于最难的跑酷跳跃,5 个随机种子验证稳定性):去稠密接触奖励 / 去阶段计数 / 去好奇心 / 换成 RND 好奇心。各任务的 WoCoCo 奖励权重见附录表1。

## 主要结果 & 结论
- 四个真机人形任务均成功部署,作者称这是**每个任务首次由单一端到端 RL 策略解决**;且能抗扰动(未见碎石、被绊带、推力、变化的接触力)。
- 消融:**0-1 接触奖励**→无法探索跳跃,只原地跟踪上身姿态;**去阶段计数**→故意不完成接触目标以免进入下一阶段(印证设计必要性);**去好奇心**→探索不足;**RND 好奇心**→学到危险的后仰(与 RND 原文 §3.7 观察一致);WoCoCo 好奇心则高效探索且不过拟合特定行为。
- 学到的运动不受简化模型/动作先验约束,敏捷、动作效率高;多配置训练后策略能满足多样接触目标。5 个种子学习曲线稳定。
- sim-to-real 课程消融(附录K):把域随机化提前到 phase1→跑酷平均进度收敛到 <0.6(标准 >0.75);取消 phase3(渐增正则)→真机动作抖、攀岩时踩出崖边致失败。
- 结论:WoCoCo 是按序列接触做全身人形控制的通用 RL 框架,任务无关设计 + 每任务仅 1–2 个直观奖励即可覆盖多样接触序列,并能推广到非人形形态。

## 核心贡献
1. 提出 WoCoCo:基于"接触阶段"自然拆解任务的通用 RL 全身人形控制框架,把长时序探索负担分摊到各阶段。
2. 用任务无关的稠密接触奖励 + 阶段计数奖励 + count-based 好奇心奖励 + 三阶段 sim-to-real 课程,使端到端 RL 在无动作先验下学会四类高难人形任务及 22-DoF 恐龙任务。
3. 四个人形任务全部真机验证,声称各为单一端到端 RL 策略首次解决。

## 局限与我的质疑
1. **作者自述局限**:① 无法预知控制器何时失败(基于模型法可显式判断是否有可行解),需引入失败预测/安全评估;② 接触序列长度未知时可能要靠启发式 reward clamping 防止刷阶段计数;③ 目前用**动捕**提供目标表示作原型,尚未上机载感知;高层接触序列靠启发式预定义,未接采样/LLM 规划器;④ **阶段切换依赖显式接触反馈(接触传感器或人工观察)**,尚不能由策略隐式管理。
2. **"无任务/无人工"被夸大**:框架号称任务无关,但每个任务仍要人工**预定义接触阶段序列、bounding box、目标区域**,并手调 1–2 个任务奖励 + 每任务单独的 WoCoCo 权重(附录表1 四任务权重差异巨大,如 w_curi 从 5000 到 40000)。这说明"通用性"很大程度上转移成了"接触阶段与权重的人工设计",并非真正零调参;与其对标的 Crocoddyl"只调几个直观代价项"相比,优势不明显。
3. **真机实验偏定性、覆盖窄**:几乎没有定量成功率/精度/对比基线的真机数据,结果主要靠图与视频展示。跑酷"真机只测了双脚一两连跳";攀岩"崖壁是人手持木板";跳舞/搬箱也无量化指标。"首次由单一端到端 RL 解决"是较强主张,却缺与基于模型法或既有 RL 方法的真机正面对比,难以判断是否过度解读。消融全部只在跑酷一个任务上做(因成本),对其余任务结论的支撑较弱。
4. **依赖动捕 + 显式阶段切换,削弱自主交互价值**:就本研究主题("RL 训练能与环境交互的数字人")而言,WoCoCo 的接触/任务目标和阶段推进都来自外部动捕与传感/人工判定,机器人本身并不感知或规划"何时该进入下一接触"。这更像"按外部给定接触脚本执行的鲁棒跟踪器",而非自主决定如何与环境交互的智能体;缺机载感知意味着离真实开放环境交互仍有距离。
5. **好奇心/探索机制的稳健性证据有限**:count-based hash 好奇心的有效性主要靠跑酷任务的曲线与"5 个种子稳定"佐证,但 hash 网络结构(单隐层32、16维输出)和 bucket 化对高维冗余观测的敏感性未充分分析;附录I 列了三种预处理但称"无显著差异"亦无数据。是否在更长接触序列、更复杂形态下仍稳定,缺乏证据。
