# Learning Humanoid Standing-up Control across Diverse Postures
> Tao Huang, Junli Ren, Huayi Wang, Zirui Wang, Qingwei Ben, Muning Wen, Xiao Chen, Jianan Li, Jiangmiao Pang · 2025 · arXiv (cs.RO, v2) · 引用 0 · 无 DOI

## 一句话
本文提出 HoST（Humanoid Standing-up Control）框架，用强化学习从零（不依赖任何预定义动作轨迹）训练人形机器人在多种起始姿态下的"起身/站立"控制策略，并直接 sim-to-real 迁移到真实 Unitree G1 机器人，在室内外多种地形下实现平滑、稳定、鲁棒的起身动作。

## 解决了什么问题
人形机器人现有的运动与操作系统大多假设机器人**已经站立**，缺失"起身/站立"这一基础能力（例如从座椅起身、跌倒后恢复）。已有起身控制方法存在两类缺陷：
1. **经典方法**（基于模型的运动规划/轨迹优化）需手工设计与大量调参，对外部扰动和执行器建模误差敏感，且实时优化计算量大；
2. **已有 RL 方法**要么只在仿真中验证、忽视硬件约束，要么依赖"针对特定地面姿态"的预定义参考轨迹，无法泛化到地面之外的多样起始姿态；从零训练又容易学出剧烈、抖动、无法部署到真机的动作。
因此"学习可泛化到多种姿态、且可真机部署的起身控制"仍是未解问题。本文要在**不用预定义轨迹**的前提下，解决探索困难、动作剧烈、sim-to-real gap 三大难题。

## 用什么方法解决的
把起身建模为有限时域 MDP，用 PPO 在 Isaac Gym（4096 并行环境、23-DoF Unitree G1）中从零训练，核心由四个设计支撑：
1. **多评论家（Multi-Critic）RL + 分阶段奖励**：把起身分为"扶正身体 / 起身 / 站立"三阶段（按 base 高度切换），奖励分为 task/style/regularization/post-task 四组，每组配独立 critic 估计回报，标准化后加权聚合优势，缓解多奖励难平衡与调参难题；
2. **力课程（Force Curriculum）作为探索策略**：训练初期对机器人 base 施加竖直向上的辅助拉力（初始 200N），仅当躯干接近竖直（成功坐姿）时生效，随机器人能维持目标高度而逐步衰减（每次 -20N，下限 0N），灵感来自婴儿借助外部支撑学习运动；
3. **运动约束**：引入 action rescaler β（从 1 逐步降到 0.25）隐式收紧动作/力矩上界限制运动速度，避免剧烈砸地与弹跳；并用 L2C2 平滑正则（同时作用于 actor 与 critics）抑制振荡；
4. **sim-to-real**：设计 ground/platform/wall/slope 四种地形覆盖真实起始姿态，配合域随机化（质量、CoM 偏移、PD 增益、力矩偏置、控制延迟等），策略直接零样本部署到真机。

## 动机 & 背景
作者认为"从沙发起身、走到桌前、拿起咖啡"这类人类自然行为要求机器人具备起身能力，而该能力被现有系统普遍忽视。相比双足行走和双手操作可部分解耦上下半身动力学，起身是**高度动态、上下半身强协同**的机动，具有时变接触点、多阶段运动技能和精确角动量控制等难点，使 RL 探索极具挑战。论文用一张对比表（Table I）说明 HoST 是唯一同时满足"真机 / 无预定义轨迹 / 超越地面姿态 / 高自由度 / 单阶段训练"的方法。

## 方法细节
- **观测空间**：仅用本体感知（IMU + 关节编码器），状态含基座角速度、roll/pitch、关节位置与速度、上一步动作、动作缩放标量 β；并堆叠前 5 帧历史隐式增强接触检测。
- **动作空间**：PD 控制器，动作为关节目标位置增量，pd_target = p_t + β·a_t，每维裁剪到 [-1,1]，力矩 τ = Kp·(pd−p) − Kd·ṗ。
- **多评论家 PPO**：各 critic 用 GAE 各自算优势，再做 batch 均值/方差标准化后加权求和；actor 用标准 PPO clip 目标更新。
- **网络与频率**：actor 为 3 层 MLP、critic 为 2 层 MLP；rollout 长度 500 步；仿真 PD 200Hz、真机 500Hz、策略 50Hz。
- **课程一致性**：竖直力与 action bound 共用同一课程触发条件（episode 末头部高度达到 Hhead 才下调）。
- **阶段划分**：Hstage1=0.45m（扶正），Hstage2=0.65m（起身），站立目标高度评测时 slope 为 0.6m、其余 0.7m。

## 数据集 & 实验设置
- **仿真**：Isaac Gym + Unitree G1（35kg、1.32m、23-DoF）；四地形（ground/platform/wall/slope）。每策略每地形 5 次重复 ×250 episode（共 1250 episode）报告均值与标准差。
- **评测指标**：成功率 Esucc（base 高度达 htarg 并维持）、脚部移动 Efeet（站立后稳定性）、动作平滑度 Esmth（相邻控制步关节角二阶差）、能耗 Eengy（达标前消耗）。
- **基线/消融**：单 critic vs 多 critic；探索策略（无力课程、RND 好奇心、力课程）；运动约束（无 bound、Bound0.25、无 L2C2、无 style 奖励）；历史帧数（0/2/5/10）。
- **真机**：实验室 4 场景 + 室外（草地、木台、石路、石台、靠树姿态等），以 HoST-w/o-L2C2 为基线对比；并测负载（最高 12kg，约 2 倍躯干质量）、力矩 dropout、15° 滑坡、3kg 球冲击等扰动。

## 主要结果 & 结论
- **多评论家是关键**：相同奖励下单 critic 版在所有地形成功率均为 0；多 critic 在 ground/platform/wall/slope 分别约 99.5/99.8/94.2/98.5% 成功率。
- **力课程显著提升探索效率**：无力课程时除 platform 外其余地形全部失败；RND 仅部分缓解（ground 仅约 19.8%）。
- **action bound 防剧烈动作、L2C2 防振荡**：去掉它们成功率虽可保持但能耗/不平滑度大幅升高（如 w/o-Bound 在 slope 能耗 16.44、smth 32.22）；Bound0.25 虽成功率高但动作不自然、扰动下能耗偏高。
- **中等历史长度（5 帧）最优**，过短在接触密集的 Wall 表现差，过长略损平滑度并增能耗。
- **真机**：HoST 在四类场景达成 20/20 成功（100%），平滑度全面优于无 L2C2 基线（总体 4.01 vs 6.54）；可泛化到训练未见的室外地形；展现负载 12kg、抗 3kg 球冲击、15° 滑坡动态平衡、未完全跌倒即恢复等涌现鲁棒性。
- **结论**：在不依赖预定义轨迹与额外 sim-to-real 自适应技术的前提下，HoST 实现了跨姿态、可真机部署的平滑稳定起身控制，并可少量调参扩展到更大的 H1/H1-2。

## 核心贡献
- 提出 HoST：首个无需预定义轨迹、可跨多样起始姿态、可直接真机部署的 RL 起身控制框架。
- 方法层面组合了多评论家 RL（分组奖励平衡）、力课程探索、action rescaler + L2C2 运动约束、多地形 + 域随机化四项设计，系统性解决探索难、动作剧烈、sim-to-real 三大问题。
- 设计了一套起身控制评测协议与指标（成功率/脚移/平滑度/能耗），意在为该任务后续研究提供可比较基准。
- 在真实 Unitree G1 上验证室内外平滑、稳定、鲁棒的起身，并初步扩展到 H1/H1-2 大型机器人。

## 局限与我的质疑
作者自述局限：仅用本体感知、缺乏环境感知，室外坐姿起身/与周围碰撞时会失败；同时训练仰卧(supine)与俯卧(prone)姿态会因 rollout 干扰互相损害性能，联合训练可行性不明；尚未真正集成进现有人形系统。我的进一步质疑：

1. **"成功"定义过于宽松，鲁棒性结论可能被高估**：成功仅以 base 达到目标高度并维持来判定，并未严格量化起身后的步态可用性、能否平稳过渡到行走/操作；真机样本量很小（每场景仅 5 次，总体 20 次），12kg 负载和力矩 dropout 测试也只有 3 次重复，统计意义有限，"100% 成功"在如此小样本下说服力不足。

2. **方法依赖大量人工先验与手调，"从零"名不副实**：虽不用参考轨迹，但分阶段高度阈值（0.45/0.65m）、四组奖励权重、力课程的初值/衰减步长/下限、action bound 课程、历史帧数等都是针对 G1 精心设计与调参的结果。扩展到 H1/H1-2 即需"minor tuning"并出现上身姿态偏差和高刚度需求，说明泛化性与可迁移性被论文叙述弱化了。

3. **sim-to-real gap 并未真正闭合**：作者自己在相图分析中承认仿真与真机关节速度存在显著差异、提示力矩建模有 gap，主要靠域随机化"掩盖"而非建模解决；对更大机器人甚至要靠高刚度关节补偿。这意味着方法对执行器特性较敏感，换硬件平台的稳健性存疑。

4. **与"RL 训练数字人与环境交互"主题的契合度有限**：这是一篇偏机器人硬件 sim-to-real 的工作，交互对象基本是地面/墙/坡等被动支撑物，缺乏与可操纵物体、动态环境或人的真正交互；观测只有本体感知、没有视觉/接触语义，因此对"数字人与环境主动交互"的借鉴主要停留在多评论家奖励平衡、课程化探索、运动平滑约束等通用 RL 技巧层面，而非交互建模本身。
