# Reinforcement Learning on autonomous humanoid robots
> E. Schuitema · 2012 · Research Repository (Delft University of Technology) · 引用 17 · DOI 10.4233/uuid:986ea1c5-9e30-4aac-ab66-4f3b6b6ca002

## 一句话
一篇博士论文，系统研究了如何把"无需任务先验知识"的经典 RL（TD 控制 + 线性函数逼近）真正搬到一台真实双足机器人 Leo 上、在嵌入式硬件上实时从零学走路，并逐一识别和缓解由此暴露的工程与算法难题（控制延迟、大扰动、维度爆炸、探索损伤硬件）。

## 解决了什么问题
现有 RL 在真实机器人上的成功案例极少，且几乎都靠预设参数化策略 / 预编程控制器来压缩解空间、规避损伤——这要求大量任务先验知识，与"服务机器人在多样、不断变化的环境中自主学习新任务"的设想相悖。论文要回答：能否用"原味"（vanilla）model-free RL、不依赖任务先验、在机器人自带嵌入式计算机上实时学会低层运动控制（走路）？为此需要解决四个子问题：(1) 选哪种 RL 技术；(2) 硬件/软件要满足什么要求才适配 RL；(3) 真实落地会冒出哪些实际难题；(4) 如何缓解这些难题。

## 用什么方法解决的
选用**时序差分（TD）控制**（SARSA(λ)/Q(λ)，model-free、不需初始策略、计算简单）+ **线性函数逼近中的 tile coding/CMAC**（配合利用系统对称性、哈希降低内存），来应对高维状态-动作空间。围绕 RL 的需求从零设计并造出专用双足机器人 **Leo**（约 50cm/1.7kg，7 个 Dynamixel 伺服电机，2D 受 boom 约束，可摔倒后自行站起，状态空间维度 16、动作维度 7）。在仿真与真机上验证：实时学会"上台阶"和"走路"两个任务。针对暴露的难题分别提出方案：①**控制延迟**——提出 memoryless 的 dSARSA(λ)/dQ(λ)，把更新对齐到实际生效的"有效动作"，并扩展到延迟非整数倍采样周期的情形；②**大扰动**——分析推力/传感器尖峰/采样抖动对学习的影响；③**可扩展性**——让各执行器作为独立学习者（Independent Learners）协作学走路，降内存和算法延迟；④**减少硬件损伤**——用模块化 RL（MRL-SARSA）让机器人先粗略学会预测动作风险、快速学会规避摔倒。

## 动机 & 背景
服务机器人市场快速增长，但其目标环境（家庭、医疗、工地）高度多样且持续变化，无法在生产时穷举测试，手工编程难以鲁棒。让机器人**从与环境的交互中自主学习**运动控制因而比专家手工编程更有吸引力。在 LfD（示范学习）、IL（模仿学习）、LfE（从经验学习）三类中，RL 属于 LfE，largely unsupervised、可 model-free，最契合"无先验、多变环境"的设想。但当时全球能在执行任务的同时**实时**做学习更新的机器人只有约 10 台，且多在粗时间尺度（每步/每宏动作 1–10s）学习、依赖预编程结构、更新多在场外电脑算。在**嵌入式硬件上实时学低层运动控制**几乎无人做到——这正是本文的切入点。

## 方法细节
- **理论选型（Ch.2）**：MDP 框架，聚焦 model-free 的 TD 控制。理由：actor-critic/policy-gradient 收敛到局部最优但通常需要先验初始策略；TD 控制不需初始解、直接从 Q 值导出策略、计算简单。
- **函数逼近**：连续高维空间必须用 FA。选 **tile coding（CMAC）**——线性、计算复杂度低、每个 (s,a) 只激活 K 个二值基函数；用多层位移 tiling 在大 hypercube 下仍获细量化，省内存。配合**对称性映射**（左右腿镜像映到同一特征，用 stance/swing 腿定义状态）和**哈希**（只为真正访问到的状态分配内存）对抗维度灾难。用二值基函数（连续基函数没带来稳定提升）。
- **控制延迟（Ch.2.4，核心算法贡献）**：定义相对延迟 τd=Td/h。延迟使状态转移依赖过去动作 → 破坏 Markov 性 → 实为 POMDP。提出 **dSARSA(λ)/dQ(λ)**：更新时把 Q(sk,ak) 换成对"实际生效动作 âk=a_{k−τd}"的更新（memoryless、model-free，复杂度与 SARSA(λ) 相当）。对**非整数 τd**：在系统可于单步内线性化的前提下，用 âk=a_{k−1}·τd + a_k·(1−τd) 这个"虚拟有效动作"近似，无需系统模型。理论上只有 dQ(0) 保证收敛；经验上 dSARSA(λ) 表现最好，且 α 越小 memoryless 策略越好。
- **硬件/软件设计（Ch.3）**：从 RL 的 7 条需求反推机器人设计（鲁棒抗摔、可观测 Markov 状态、动作效果可复现、采样周期恒定、T 数十小时内平稳、测量到动作零延迟、自由度受限）。Leo 用 boom 约束成 2D 消除侧向稳定问题；电机用电压控制（非位置控制，避免双支撑相过约束导致的突兀动作）；做**温度补偿**（电机发热改变扭矩常数与绕组电阻，按物理模型校正电压）；位置传感器逐一标定建查找表；速度信号用三阶 Butterworth 滤波。
- **Independent Learners（Ch.5）**：每个执行器独立学习但协作（MMDP 框架，MA-Q(λ)/MA-SARSA(λ)），降内存与算法延迟、提升对执行器数量的可扩展性。
- **模块化 RL 减损伤（Ch.6）**：MRL-SARSA(λ)，快速粗略学习预测动作风险，更安全地学解。

## 数据集 & 实验设置
非数据集驱动，是真机 + 仿真实验：
- **Leo 真机**：上台阶任务、学走路任务的实时 TD 学习；鲁棒性测试中用预编程极限环步态控制器连续走约 8 小时、>43000 步、>6000 米、摔 30 次自行站起（仿真估计从零学走路需约 20 小时、数百次摔倒）。
- **控制延迟实验**：大 W-maze 网格世界（整数 τd，延迟 2 步，对比 Q(λ)/SARSA(λ)/dQ(0.8)/dSARSA(0.8)/dQ(0)，各 20 次平均）；二连杆机械臂仿真（非整数 τd，h=0.05s、16 层 tile coding、25 个离散扭矩组合，对比 dSARSA(λ) 与增广状态空间 SARSA(λ)，60 次平均）。
- **大扰动实验（Ch.4）**：用"最简步行者"简化模型，测推力、传感器尖峰、采样抖动三种异常对学习的影响。
- 多数超参数（α、γ、λ、tile 宽等）按经验选取以获稳定学习，**未做系统化优化**。

## 主要结果 & 结论
- **成功在真机上实时、从零、无任务先验地用经典 TD 学会"上台阶"和"走路"**——论文称这是其主章贡献：在大状态-动作空间的非平凡任务上、真机、实时地跑通了 well-known RL 技术。
- **控制延迟**：dSARSA(λ) 在 W-maze 上学习速度与最终策略性能都显著优于 Q(λ)/SARSA(λ)；二连杆上，小于一个采样周期的延迟就能让普通 SARSA(λ) 发散/学不动，而 dSARSA(λ) 仍能收敛，且比"增广状态空间 SARSA(λ)"学得快、最终性能不输（暗示 model-based 预测带来的额外收益在此场景下很有限）。memoryless 算法 α 越小越好；dQ(0) 唯一保证收敛、但因可用大 α 也能学得快。
- **大扰动**：大而稀疏的外部推力对学习过程的破坏，远大于同样大而稀疏的采样周期偏差或传感器读数异常。
- Independent Learners 提升了对执行器数量的可扩展性；MRL 能更安全地学习、减少硬件损伤。
- 总结论：经典 vanilla RL 确实能搬上真机实时学习，但需专门设计的硬件 + 一系列工程缓解措施；自由度仍是核心瓶颈。

## 核心贡献
1. 在真实双足机器人上、嵌入式实时、无任务先验地用经典 TD + tile coding 学会走路/上台阶——填补当时该领域的空白。
2. 从 RL 需求系统反推机器人设计，造出专为 RL 设计的研究平台 Leo（含温度补偿、对称性/哈希降维等工程要点的完整记录）。
3. 控制延迟的 RL 处理：memoryless 的 dSARSA(λ)/dQ(λ)，并首次处理延迟为采样周期非整数倍的情形。
4. 系统刻画并缓解了真机 RL 的若干实际难题（大扰动敏感性、多执行器可扩展性、探索导致硬件损伤）。

## 局限与我的质疑
1. **作者自述：远未实现"从零自主学走路"的最终目标。** 真机学走路实际靠仿真估计要约 20 小时、数百次摔倒，硬件鲁棒性测试 8 小时后髋关节齿轮箱已严重损坏、电位器/足部传感器失效——即"days of autonomous operation"的目标**没真正达到**。多数真机 RL 结论其实建立在仿真上，真机端到端从零学走路的完整闭环证据偏弱。
2. **作者自述 + 我的质疑：方法论高度依赖手工调参与先验，与其"无需先验"的卖点存在张力。** 特征空间（tile 数量/形状/位置）、|A|、h、reward、γ 全靠手工经验调，作者明确承认没有系统化方法、也没做系统化优化。所谓"vanilla、无任务先验"更多是"无初始策略"，但状态表示、动作离散化、奖励塑形里塞进了大量工程先验——可复现性与可推广性都打折扣。
3. **dSARSA(λ)/dQ(λ) 的理论根基薄弱。** 作者自己指出：四个延迟算法里只有 dQ(0) 有收敛保证，dSARSA(λ)/dQ(λ) 的收敛"仍是重要未来工作"，dQ(λ) 还会快速发散。非整数延迟的"虚拟有效动作"近似只在"系统可单步线性化 + 动作可线性叠加（如扭矩/电压）"的强假设下成立，对接触/碰撞主导的真实步行动力学是否站得住，未在真机上充分检验。优势主要在玩具问题（W-maze、二连杆仿真）上展示。
4. **维度瓶颈未被真正突破。** 全文核心难题——大状态-动作空间——仅靠 tile coding+对称+哈希+独立学习者缓解，对象始终是 7 DoF 量级的 2D 受 boom 约束机器人；boom 把 3D 平衡问题人为消掉了，这本身就是一个很强的简化。论文也坦言找不到能保证性能的自动特征构造方法。线性 FA 在更高维真实人形上能否扩展，证据不足。
5. **与"用 RL 训练可与环境交互的数字人"主题的差距（我的批判）：** 本文是 2012 年的真实硬件 + 经典 tabular/线性 RL 工作，**没有**深度神经网络策略、没有 sim-to-real、没有从视频/动捕的模仿、也不涉及与物体/人交互的"数字人"或虚拟角色动画。它的价值在于"真机 RL 工程难题的诚实清单"（延迟、扰动、硬件损伤、采样恒定性），这些对今天 sim-to-real 仍有启发；但其具体算法（SARSA(λ)+tile coding）已被现代 deep RL（PPO/SAC + 大规模并行仿真）全面取代，对虚拟数字人全身控制的直接方法论借鉴有限。把它当作"全身运动控制"强相关篇并不准确——它是**真实双足行走**的早期 RL 落地研究，与数字人/虚拟交互只在"用 RL 学运动"这一抽象层面相关。
