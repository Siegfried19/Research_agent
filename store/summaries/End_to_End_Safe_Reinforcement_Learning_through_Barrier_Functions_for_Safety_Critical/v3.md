# End-to-End Safe Reinforcement Learning through Barrier Functions for Safety-Critical Continuous Control Tasks
> Richard Cheng, Gábor Orosz, Richard M. Murray, Joel W. Burdick · 2019 · Proceedings of the AAAI Conference on Artificial Intelligence · 引用 528 · DOI 10.1609/aaai.v33i01.33013387

## 一句话
把 model-free RL 控制器、基于控制屏障函数(CBF)的 model-based 安全控制器、以及用高斯过程在线学习未知动力学三者拼成一个统一架构(RL-CBF),让 RL 在整个学习过程中以高概率不离开安全集,同时用屏障函数引导策略探索、加快学习。

## 解决了什么问题
RL 之所以难走出仿真、在真实物理系统上落地,**主要原因之一是学习期没有安全保证**(摘要原文:*"one main reason is the absence of safety guarantees during the learning process"*, p.1)——为了最大化长期回报,RL 很可能在学习中探索危险行为,把硬件或人弄坏,所以多数成功只停留在仿真。作者把这一动机讲得很直白:现有 model-free 安全 RL(reward-shaping、带约束的策略优化、teacher advice)"不能保证学习期的安全——安全只在足够长的学习之后被近似保证";根因是"没有模型,安全就只能靠与环境交互来学,这意味着它在初期交互中可能被违反"。而已有 model-based / 备份控制器方法要么不管探索与性能优化,要么(切换备份控制器)"过度约束了策略探索"。本文要同时拿下两件事:**学习全程的安全保证** + **更高的探索/学习效率**。

## 用什么方法解决的
核心是一个三件套架构:"我们提出一个控制器架构,结合 (1) 一个 model-free 的 RL 控制器、(2) 利用控制屏障函数(CBF)的 model-based 控制器、(3) 对未知系统动力学的在线学习,以在学习过程中确保安全"(*"we propose a controller architecture that combines (1) a model-free RL-based controller with (2) model-based controllers utilizing control barrier functions (CBFs) and (3) online learning of the unknown system dynamics, in order to ensure safety during learning."*, p.1)。CBF 把 RL 提出的(可能危险的)动作"投影"到安全策略集里,只做维持安全所需的最小干预。

## 动机 & 背景
- 系统建模为控制仿射、确定性的离散 MDP:`st+1 = f(st) + g(st)at + d(st)`(p.2 式1),其中 `f, g` 是**已知名义模型**,`d` 是**未知部分**。作者强调名义模型可以很差:"实践中名义模型可能相当糟(例如一个忽略摩擦与柔顺性的机器人模型),我们必须靠数据学到更好得多的动力学模型"(*"the nominal model may be quite bad ... we must learn a much better dynamic model through data."*, p.2)。这正是 CBF 要能在"差模型 + 不确定性"下仍给出安全保证的原因。
- 安全被形式化为"安全集 C 前向不变":"在学习过程中维持安全,系统状态必须始终留在安全集 C 内(即 C 前向不变)"(*"the system state must always remain within the safe set C (i.e. the set C is forward invariant)."*, p.3)。
- 基线选了两个主流策略梯度法 TRPO 与 DDPG 作为对照,框架本身"与所用的 RL 算法无关"。

## 方法细节
**1) 用高斯过程(GP)学未知动力学并给不确定性界。** GP 给出 `d(s)` 的均值 `µd` 与方差,从而对真实动力学有高概率置信区间:`µd(s) − kδσd(s) ≤ d(s) ≤ µd(s) + kδσd(s)`,以概率 (1−δ) 成立,"kδ 是决定 δ 的设计参数(例如 kδ=2 对应 95% 置信)"(*"e.g. 95% confidence is achieved at kδ = 2"*, p.3)。GP 求逆随数据量 N³ 增长,作者的工程取舍是"只用最近一批约 1000 个数据点批训练 GP 来绕开这个问题"(*"batch training the GP model with only the latest batch of ≈ 1000 data points."*, p.3)。

**2) 把 CBF 安全条件写成每步可解的二次规划(QP)。** 安全集是连续可微函数 `h` 的超水平集 `{s: h(s)≥0}`;本文"把注意力限制在仿射屏障函数 `h = pᵀs + q`"(p.3),于是 C 是多面体。把离散 CBF 条件(式8)结合 GP 的不确定性界,重写成"每个时间步可高效求解的二次规划(QP)"(*"a quadratic program (QP) that can be efficiently solved at each time step"*, p.3,式9)。QP 目标是 `‖at‖² + Kϵ`,含松弛变量 `ϵ` 与惩罚常数 `K`;原文称"只要 K 足够大,优化对 K 不敏感(例如 10¹²),以重罚安全约束违反"(*"The optimization is not sensitive to the Kϵ parameter as long as it is very large (e.g. 10¹²)"*, p.3,式9 下方)。约束里用 `−kδ|p|ᵀσd(st)` 把不确定性"扣"进安全裕度,并含执行器上下限约束。直观上:在不确定动力学下用**最小控制量**尽量满足安全;满足不了(如力矩受限)时给出"优雅退化"(*"graceful degradation (a small deviation from the safe set)"*, p.4,略微偏离安全集)。

**3) 两种把 CBF 接进 RL 的方式(关键差异)。**
- **补偿式(suboptimal,图1a):** `uk(s) = u_RL_θk(s) + u_CBF_k(s, u_RL_θk)`(p.4 式13)。"这个概念类似 shielded RL,因为 CBF 控制器为 RL 控制器做补偿以确保安全,但不引导 RL 算法的探索"(*"since the CBF controller compensates for the RL controller to ensure safety, but does not guide exploration"*, p.4)。其缺陷:策略是"围绕被更新的 RL 控制器 u_RL"更新,而那并不是真正部署在安全区的控制器 uk,因此探索得不到引导(p.5)。
- **引导式 RL-CBF(图1b,本文主算法):** 总控制器把**所有先前的 CBF 控制器之和**纳入进来(p.5 式15),使"策略围绕之前实际部署的控制器更新,这通过鼓励策略在状态空间的理想区域运行,提升了学习效率"(*"policy updates around the previously deployed controller, which adds to the efficiency of the learning process ..."*, p.5)。这是它比"纯 shield"更快学的机制所在。

**4) 计算上的近似(让它可实现)。** 朴素实现要存 k−1 个网络、依次解 k−1 个 QP,不可行;作者"用一个前馈神经网络(MLP)`u_bar_φ` 去近似所有先前 CBF 控制器之和"(p.6),于是"只需存两个网络、解一个 QP"。重要的是**安全性不受近似影响**:近似只动"引导 RL 项",CBF 控制器仍在解 QP(16)、仍满足 CBF 条件;代价是"Theorem 2 的性能保证在这个近似下不一定再成立"(*"the performance guarantee in Theorem 2 does not necessarily hold with this approximation."*, p.6)。

**5) 理论保证(Theorem 2 + Lemma 1)。** 用式(15)控制律,"若问题(16)存在 ϵ_max=0 的解,则安全集 C 以概率 (1−δ) 前向不变"(p.6);若 ϵ_max>0,但对所有 s∈C 解都满足 ϵ≤ϵ_max,则**扩张后的集合 Cϵ**(原文 p.4 定义 `Cϵ : {s: h(s) ≥ −ϵ/η}`)以概率 (1−δ) 前向不变(p.4 Lemma 1 / p.6 Theorem 2)。"若动力学没有不确定性,则安全以概率 1 得到保证"(*"If we have no uncertainty in the dynamics, then safety is guaranteed with probability 1."*, p.6)。此外若 RL 用 TRPO,控制律 `uk − u_CBF` 还能继承 TRPO 的性能下界 `J(π_prop_k) ≥ J(π_{k−1}) − 2λγ/(1−γ)²·δπ`。注意该性能界是针对 `uk − u_CBF`(非实际部署的 uk),但作者论证这不构成大问题,因为随迭代"u_CBF 迅速衰减到 0……引导后的 RL 控制器很快学会在安全区运行,于是 CBF 控制器变得不激活"(*"rapidly decays to 0 as we iterate ... the guided RL controller quickly learns to operate in the safe region, so the CBF controller ... [becomes inactive]"*, p.6)。

> 时间尺度上要分清两个索引:"CBF 控制器在整个任务中每个时间步 t 更新,而 RL 策略与 GP 模型在以 k 为索引的 episode 策略迭代间隔上更新"(*"The CBF controller updates ... at each time step, t, whereas the RL policy and GP model update at episodic policy iteration intervals indexed by k."*, p.4)。

## 数据集 & 实验设置
两个非线性控制任务,均为**仿真**;实现了 **TRPO-CBF** 与 **DDPG-CBF** 两个版本(分别由 TRPO/DDPG 派生),代码开源(p.6)。
- **倒立摆(OpenAI gym pendulum-v0):** 安全区 `θ∈[−1,1]` 弧度,奖励 `r = θ² + 0.1θ̇² + 0.001u²`(p.6);真实参数 m=1、l=1、力矩 `u∈[−15,15]`。**为引入模型不确定性,名义模型故意取 m=1.4、l=1.4,即模型参数 40% 误差**(*"our nominal model assumes m = 1.4, l = 1.4 (40% error in model parameters)."*, p.6)。
- **仿真跟车:** 一条直路五辆车排队,控制**第 4 辆车**的加减速,目标"在交通拥堵中最大化燃油效率并避免碰撞"(p.7)。奖励项鼓励 3 米车距(软约束),而"RL-CBF 的 CBF 强制 2 米安全车距(硬约束)"(*"the CBF enforces a 2 meter safe distance between cars (hard constraint)."*, p.8)。第 4 辆车只有自身粗糙模型(kd=0)和对前后车的不准确模型,且各车加速度加了高斯噪声——意在展示"用粗糙模型也能高概率保证安全,并通过缓慢构建并利用对其他驾驶者行为的隐式模型来提升油耗"(*"improve fuel efficiency by slowly building and leveraging an implicit model of the other drivers' behaviors."*, p.8)。

## 主要结果 & 结论
> 注:结果均来自上述两个仿真任务,且论文以学习曲线/最大角度/最小车距等图(图3–5)呈现,未给出汇总的数值表格。以下结论按原文措辞,属"在这两个任务上观察到"的层级。

- **倒立摆——更快收敛 + 更安全。** "两个 RL-CBF 算法很快收敛到接近最优解,并显著优于对应的无 CBF 基线"(*"converge near the optimal solution very rapidly, and significantly outperform the corresponding baseline algorithms without the CBFs."*, p.6)。同时 RL-CBF "在整个学习过程中维持安全(从不离开安全区),相反 TRPO 与 DDPG 在学习最优策略时严重违反安全"(p.7,图3)。图4 佐证机制:首个策略下 CBF 把摆角顶在安全区边缘做最小干预,"到最后一次迭代,CBF 控制器完全不激活(u_CBF=0)",因为引导后的 RL 控制器自身已安全——直观印证了"u_CBF 随学习衰减到 0"的论断。
- **倒立摆——基线并非全输。** 作者诚实地说:"TRPO 与 DDPG 有时也会收敛到(与 RL-CBF 相当的)高性能控制器,只是更不可靠、更慢"(*"sometimes converge on a high-performance controller (comparable to ...), though this occurs less reliably and more slowly"*, p.6)。
- **跟车——安全是硬保证,性能优势分算法。** "用任一 RL-CBF 控制器时车辆间没有任何安全违规;而单用 TRPO 或 DDPG(无 CBF)时几乎所有试验都碰撞,即便在学习后期"(p.8,图5)。性能上"TRPO-CBF 学得更快且优于 TRPO;DDPG-CBF 也优于 DDPG,但两者都没收敛到高性能控制器"(*"neither algorithm converged on a high-performance controller in our experiments"*, p.8)。即便 DDPG/DDPG-CBF 没学好,"DDPG-CBF(和 TRPO-CBF)始终维持安全控制器——这是 RL-CBF 的关键优势:它独立于系统的学习性能保证安全"(p.8)。同样诚实地标注:"某些实验里 TRPO 也能找到与 TRPO-CBF 相当的控制器,但由于种子随机性常常并非如此"。
- **结论:** 即使只加入粗糙模型信息 + CBF,也能在保证端到端安全的同时改进 model-free 学习的探索;框架还能即插即换新的 RL 算法,并随测量在线改进 CBF 控制器(p.8)。

## 核心贡献
1. 作者明确主张这是"**第一个把 CBF 控制器与 model-free RL 结合、对非线性控制系统实现端到端安全 RL 的算法**"(*"the first algorithm that integrates CBF-based controllers with model-free RL to achieve end-to-end safe RL for nonlinear control systems"*, p.2)。
2. 用屏障函数引导策略探索,**展示了学习效率的提升**(第二贡献,p.2)。
3. 提供了**与具体 RL 算法无关、学习全程高概率安全**的理论保证(Lemma 1 / Theorem 2),并给出一个只需两网络+一个 QP 的**可计算实现**。
4. 框架的工程优势:易于替换新 RL 算法、能从数据在线改进 CBF(p.8)。

## 局限与我的质疑
- **作者自述的最大局限——安全集是"白送"的。** "本工作的一个重大假设是给定一个可被渲染成前向不变的有效安全集 h(s)"(*"A significant assumption in this work is that we are given a valid safe set, h(s) ..."*, p.8),而计算这种安全集本身非平凡、计算量大;若没有有效安全集就可能进入无法保持安全的状态,作者把"在学控制器的同时学习安全集"留作未来工作。这意味着方法的安全保证是**条件性的**:把最难的一环(可行安全集设计)挡在门外了。
- **安全保证只是"高概率"且依赖 GP 校准。** 全部安全声明都带 (1−δ) 概率,根植于 GP 置信区间 `µd ± kδσd` 成立这一前提。一旦真实动力学落在 GP 假设(平稳、核选择、噪声模型、仅用最近 1000 点)之外——这在真实硬件上很常见——置信界可能失真,"高概率安全"随之打折。论文未对 GP 误设(misspecification)下的安全鲁棒性做实验。(总结者注)
- **仿射屏障函数 + 控制仿射动力学是强结构假设。** 限制 `h=pᵀs+q`(多面体安全集)让 QP 可解,但很多真实安全约束(非凸障碍、姿态/接触约束)并非半空间;作者说"方法可支持更一般的屏障函数",但论文没给非仿射的实验证据,这一泛化是宣称而非验证。(总结者注)
- **实验规模与说服力偏弱。** 仅两个低维仿真任务(单摆、五车跟车),无真实硬件、无高维/接触丰富任务;且基线只有 TRPO/DDPG(2015 年的方法),没有与同期 model-based 安全 RL(如 Berkenkamp 2017 的 Lyapunov 方法、CPO 等带约束策略优化)做**正面对比**。考虑到该方向当时已有多条线,只比"裸 TRPO/DDPG"会让"更安全/更快"显得理所当然——CBF 本就是硬约束投影,不碰安全边界几乎是设计使然,而非令人意外的发现。(总结者注)
- **性能保证与部署控制器之间有缝。** Theorem 2 的性能下界是对 `uk − u_CBF` 而非实际部署的 `uk`,且在用了 MLP 近似后"不一定成立";作者用"u_CBF 会衰减到 0"来弥合,但这是经验观察(图4),不是定理。换言之**安全有证明,性能在实现层面其实没有严格保证**——这一点值得复用者注意。
- **DDPG-CBF 没学好这件事被轻描淡写。** 跟车任务里 DDPG/DDPG-CBF 都没收敛到好控制器,论文把它转化为"安全独立于性能"的卖点。这逻辑成立,但也暴露:CBF 能保证不撞,却**不能挽救一个本身学不动的 RL**,引导式架构对底层 RL 质量仍有依赖。(总结者注)
- **对本研究主题(CBF 安全增强)的价值与不足。(总结者注)** 它确实是"CBF 直接接进学习期 RL、且把不确定性纳入 QP"的奠基性范式,机制清晰、可复用性强(开源、QP 每步可解)。但若要用于复杂数字人/通用工具箱场景,需自备好高维非线性安全集、可靠的不确定性量化,以及对 1000 点批 GP 在大数据下扩展性的替换方案(作者也提到可换 dropout 神经网络等任何带不确定性界的模型,但未实测)。

**复用要点(给想落地的人):** 关键超参/结构——QP 惩罚常数 K 取极大(原文 e.g. 10¹²,且"只要足够大优化对 K 不敏感",p.3 式9 下方)、不确定性放大系数 kδ(95% 取 2)、屏障"内推"强度 η∈[0,1](原文 Definition 1:η=0 时屏障条件退化为 Lyapunov 条件,p.3);GP 只用最近≈1000 点批训练;近似需训练一个 MLP `u_bar` 拟合历史 CBF 之和(全程只存两网络、解一个 QP);倒立摆用 40% 参数误差的名义模型即可工作,跟车用 kd=0 的粗糙自身模型 + 2 米硬约束/3 米软约束。完整性能界证明在作者附录(链接 https://rcheng805.github.io/files/aaai2019.pdf),代码见 https://github.com/rcheng805/RL-CBF。
