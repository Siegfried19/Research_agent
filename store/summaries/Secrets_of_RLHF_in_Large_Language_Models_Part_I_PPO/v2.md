# Secrets of RLHF in Large Language Models Part I: PPO
> Rui Zheng, Shihan Dou, Songyang Gao, Hua Yuan, Wei Shen, Binghai Wang, Yan Liu, Senjie Jin, Qin Liu, Yuhao Zhou, Limao Xiong, Lu Chen, Zhiheng Xi, Nuo Xu, Wenbin Lai, Minghao Zhu, Cheng‐Chang Chang, Zhangyue Yin, Rongxiang Weng, Wensen Cheng, Haoran Huang, Tianxiang Sun, Hang Yan, Tao Gui, Qi Zhang, Xipeng Qiu, Xuanjing Huang · 2023 · arXiv (Cornell University) · 引用 19 · DOI 10.48550/arxiv.2307.04964

## 一句话
这篇报告把 RLHF 中的 PPO 算法逐个零件拆开做对照实验，找出"策略约束"是稳定训练的关键，并据此提出工程化加固版 **PPO-max**，让模型能长时间稳定对齐而不崩塌（论文用 10K 步训练曲线展示了这种长期稳定性）。

## 解决了什么问题
RLHF（尤其是 PPO 阶段）训练极不稳定、对超参数高度敏感、且缺乏开源实现，研究者因巨大的试错成本不敢轻易进入这一阶段。原始 PPO 在语言模型场景下会出现"模式崩塌"（policy 学会用固定套路骗高奖励，奖励分数升高但人类/GPT-4 评价反而变差），而 reward 分数和 loss 曲线都无法提前预警这种崩塌。

## 用什么方法解决的
作者系统解剖 PPO 的内部机制：① 提出用**动作空间建模指标**（困惑度 perplexity、回复长度、policy 与 SFT 的 KL 散度）而非 reward/loss 来监控训练稳定性；② 把 PPO 的各类 trick 分三组（分数重参数化、策略约束、初始化）逐一做消融对照；③ 发现 token 级 KL 惩罚等**策略约束**是长期稳定的决定性因素；④ 把验证有效的组件组装成 **PPO-max**，并与 SFT、ChatGPT 做人类+GPT-4 偏好评测。

## 动机 & 背景
LLM 训练自预训练语料（含低质数据），容易编造事实、生成有偏见/有毒/有害内容，因此需要与人类价值观（helpful、honest、harmless，3H）对齐。仅在 SFT 阶段掺入 3H 数据效果有限，模型在安全性与事实性上仍低于人类水平。OpenAI、Anthropic 已验证 RLHF 是有效路径，但 RLHF 训练常常反复失败：需要准确的奖励模型作为人类判断的代理、需要精细的超参数搜索、需要稳健的 PPO 算法。PPO 阶段要同时协调 **policy / value / reward / reference 四个模型**，在词空间中又面临稀疏奖励与低效探索，对超参极敏感。此前工作（Engstrom、Andrychowicz 等）指出 PPO 的代码级实现细节至关重要，但很少有人专门解决 RLHF 的不稳定性问题，也缺乏开源实现——本报告正是要填补这个空白。

## 方法细节
**奖励建模（RM）**：用去掉 unembedding 层、加一个线性头的 transformer，对最后一个 token 输出标量奖励。损失用成对比较的 sigmoid 排序损失（公式1），并按 [27] 加入对 preferred 回复的自回归 LM 损失（系数 βrm=1）做模仿学习（公式2）。总奖励里加入 policy 与 SFT 之间的 **KL 惩罚**（公式3，系数 η），既当熵奖励促进探索、防止过早收敛到单一模式，又防止 policy 输出偏离 RM 训练时见过的分布。

**强化学习基础**：把对话生成建模为 RL——人类交互是"环境"，对话历史是状态 st，生成下一个 token 是动作 at。介绍策略梯度、用优势函数 A(st,at)=Q−V 替代原始 return 降方差，再引入 **GAE**（公式9）通过 (γλ) 指数加权在 TD（λ=0，低方差高偏差）与蒙特卡洛（λ=1，高方差低偏差）之间平滑插值。PPO 用**裁剪代理目标**（PPO-Clip，公式15）限制新旧策略比值在 (1−ε,1+ε)；critic 用 MSE 拟合 return（公式16）；还可混入预训练梯度（**PPO-ptx**，公式17）缓解语言能力退化。

**PPO 内部机制探索（核心）**，分三类逐项消融：
- **分数重参数化（§5.3.1）**：Reward Scaling（除以滚动折扣和的标准差）——作者发现**无效**，加不加训练轨迹几乎一致；Reward Normalization & Clipping（公式18）和 Advantage Normalization & Clipping——严格裁剪能在固定 epoch 内维持稳定，但不同阈值在早期表现相似、后期才分化，且高奖励≠人工评价更好。建议在 **reward 层面**施加约束，并采用相对宽松的裁剪。
- **策略约束（§5.3.2，关键发现）**：**Token 级 KL 惩罚**（公式19，λ=0.05）对稳定性至关重要、能支撑更长训练步数——与 Anthropic 报告"KL 惩罚（0.001）影响不大"相反；有趣的是 RLHF 能在几乎不改变语言建模（KL 接近零）的情况下显著提升回复质量。Importance Sampling（论文将其等价于"固定策略分布为参考模型、相当于无限大经验缓冲区"做验证）能进一步稳定但牺牲最终性能。Entropy Bonus 对参数极敏感、容易训崩，**不推荐**，建议用 KL 惩罚替代。
- **初始化（§5.3.3）**：**Policy 必须先 SFT**——不经 SFT 直接 PPO 会严重损害语言建模能力，失败。**Critic 初始化不关键**——用 RM 或 SFT 初始化最终收敛相近，但在 PPO 前**预训练 critic**（先把价值预测损失训到接近零）能提供更好的优势估计、提升早期稳定性，建议用 critic 预训练替代学习率 warmup。

**PPO-max 配置（§5.4）**：基于历史均值方差对当前 reward 归一化+裁剪 → 加 KL 惩罚约束策略 → 用 RM 初始化 critic 并预训练 → 全局梯度裁剪 + 较小经验缓冲区（原文仅说 set a small size of the experience buffer，未给具体大小）→ 加预训练 LM 损失（PPO-ptx）降低 alignment tax + 裁剪 value loss。PPO-max 能稳定跑 **10K 步**（图9 给出 10K 步训练曲线）。

## 数据集 & 实验设置
- **RM 数据**：英文用 LLaMA-7B + HH-RLHF（16万对：11.8万 helpful、4.2万 harmless）做训练集，从剩余 8.5k 数据中随机取约 0.7k helpful + 0.3k harmless 共 **1k 作测试集**（其余作验证）；中文用 OpenChineseLLaMA，雇专业标注 **3.9万对**（3.1万 helpful、0.8万 harmless），其中训练集取 24k helpful + 6k harmless、测试集取 2.4k helpful + 0.6k harmless（其余作验证）。RM 学习率 5e-6、固定 1000 步（约 1.06 epoch）、动态 batch（4–128）。
- **PPO 数据**：手工构造 HH 数据（8k harmless + 20k helpful query）。reference 与 policy 均由 **7B SFT 初始化**（SFT 基于 OpenChineseLLaMA 在 100万指令数据上训 2 epoch），critic 与 reward model 由 **reward model 初始化**；sampling batch=128、训练 batch=32，policy lr=5e-7、critic lr=1.65e-6。硬件为 8×80G A100。
- **评测**：人类标注 + GPT-4 作裁判（LLM-as-a-judge）做偏好对比；NLU 用中文 C-Eval（约1.3万道选择题、52学科）。论文称在 7B 和 13B SFT 模型上评测 PPO-max，但正文给出的训练设置与多数分析以 7B 为主。

## 主要结果 & 结论
- **RM 观察**：中文 RM 精度高于英文（因中文数据对内优劣差异更大）；约 200 步后精度提升就显著放缓，但用 200 步 RM 初始化 PPO 效果不佳——**精度不足以单独作为 RM 好坏的标准**。RM 仍会被"更长但编造事实"的回复骗到高分（表1）。
- **崩塌可监控**：原始 PPO 中 reward 稳定上升、loss 平稳收敛，但人类/GPT-4 评价变差；崩塌时回复变长、困惑度降低、KL 异常增大——这些动作空间指标比 reward/loss 更能预警。
- **PPO-max 偏好评测（人类评测，图10a）**：英文 Harmless 上 RLHF 显著优于 SFT，胜率 62% vs 5%；英文 Helpful 上 44% vs 30%。中文 Harmless 上 RLHF 也明显占优；但**中文 Helpful 上优势不明显**（RLHF 胜 46%、负 23%、平 31%）。原文未给显著性检验。
- **对比 ChatGPT**：仍落后，但把"被 ChatGPT 击败"的比例大幅降低——英文从 45%→24%，中文从 37%→29%（"harmless"维度，GPT-4 评测）。
- **NLU**：PPO 会让 C-Eval 成绩下降，**PPO-ptx**（混入预训练数据）能缓解这种语言理解能力的退化。
- 结论：奖励模型质量决定 policy 上限；**策略约束是 PPO 稳定的关键**；PPO-max 让长时训练成为可能。作者声明将开源（we are eager to release / we release）中英奖励模型与 PPO-max 代码（MOSS-RLHF 仓库）。

## 核心贡献
1. 发布有较好跨模型泛化能力的**中英文奖励模型**，降低重新标注偏好数据的成本。
2. 深入解剖 PPO 内部机制，提出用动作空间指标监控训练稳定性，并提炼出稳定训练的 **PPO-max** 算法（含 KL 约束、reward 归一化裁剪、critic 预训练、PPO-ptx 等组合）。
3. **开源完整 PPO-max 代码**（MOSS-RLHF），填补 RLHF 对齐缺乏开源实现的空白（作者表述为"渴望发布/发布"，附仓库链接）。

## 局限与我的质疑
- **作者自述局限**：① 只在 7B（论文称评测含 13B，但主分析与训练设置在 7B）上做，未研究模型/数据规模对 RLHF 的 scaling law；② 奖励模型依赖公开英文偏好数据 + 少量自建中文数据，质量与数量都不足以全面评估 RM；③ 评测主要靠人工 + GPT-4，没用大量标准 benchmark；④ PPO 阶段**只追求稳定、没追求最终性能上限**，且 reward 分数无法可靠预测 RLHF 性能，仍需寻找更合适的训练期性能指标。
- **结论被自身证据削弱（总结者注）**：作者反复强调"reward 升高 ≠ 性能更好""reward/loss 不能预警崩塌""RM 精度不能判好坏"——这等于承认整套优化的代理信号都不可靠。在缺乏可信训练期指标的情况下，"PPO-max 更稳定"这一判断很大程度依赖人工/GPT-4 的定性观察，缺少量化收敛准则，可复现性与客观性存疑。
- **结论可能被过度解读且与已有工作冲突（总结者注）**：若干发现（KL 惩罚的重要性、reward scaling/clipping 是否有效、entropy bonus）与 Anthropic、Engstrom、Andrychowicz 等的对应结论不同，作者归因为"模型规模小/配置不同/场景不同"。但这些对照实验"为省算力未训练到最优、主要在中文子集上跑"，多数曲线只到 1000 步（也有 800 步、PPO-max 到 10K 步），且作者也承认部分"暂时稳定"的设置训练更久仍会崩——这意味着不少"有效/无效"的判定可能只是被截断在崩塌之前，证据强度不足以支撑普适性的 trick 取舍建议。
- **GPT-4 自评的循环性（总结者注）**：用 GPT-4 当裁判评 helpful/harmless，而模型本身是朝"讨人类（及类人评分器）喜欢"优化的，存在评测与优化目标同源的偏置；而且 harmless 提升很可能部分来自模板化的拒答（见附录有害样例多为套话拒绝），未必是真正的"判断力"提升。
- **与"RL 训练数字人与环境交互"主题的差距（总结者注，最关键）**：本文的"环境"是静态的对话历史、"动作"是生成下一个 token、"奖励"来自一个离线训好的偏好打分器——**没有真正的闭环物理/感知环境，没有具身、没有多模态、没有跨时间步的真实状态转移与因果反馈**。它解决的是"如何把语言模型对齐人类偏好"的稳定性工程问题，对数字人**与环境实时交互、感知-动作闭环、长时序控制**几乎没有直接方法可迁移。可借鉴的仅是通用的 PPO 稳定化技巧（KL/优势约束、critic 预训练、监控指标），但词空间稀疏奖励的设定与连续控制/具身交互差异极大，迁移时需高度警惕。
- **"打动人心"等表述偏宣传（总结者注）**：摘要里"能直击人们灵魂""理解 query 深意"以及结尾 Easter Egg 用《流浪地球2》MOSS 类比，属于主观修辞，缺少实验支撑，削弱了报告的客观性。
