# Deep Reinforcement Learning That Matters
> Peter Henderson, Riashat Islam, Philip Bachman, Joëlle Pineau, Doina Precup, David Meger · 2018 · Proceedings of the AAAI Conference on Artificial Intelligence · 引用 1499 · DOI 10.1609/aaai.v32i1.11694

## 一句话
这是一篇**实证方法学论文**:作者系统地展示了深度强化学习(连续控制中的策略梯度方法)的结果对超参数、网络结构、奖励缩放、随机种子、代码实现、评估环境等因素极其敏感,从而难以复现,并呼吁用显著性检验和更严格的报告规范来判断"提升是否真实"。

## 解决了什么问题
深度 RL 进展迅猛,但**复现已有工作、公正判断新方法的提升非常困难**——同一基线算法在文献里报告出差异巨大的结果。作者把不可复现性的来源分为**外在因素**(超参、代码库)和**内在因素**(随机种子、环境特性)——原文:"Reproducibility can be affected by extrinsic factors (e.g. hyperparameters or codebases) and intrinsic factors (e.g. effects of random seeds or environment properties)",并指出"度量指标五花八门 + 缺乏显著性检验"使得结果容易被误导性地报告。作者声称这是"据我们所知,首个在深度 RL 语境下处理这一重要问题的工作"(原文:"to the best of our knowledge this is the first work to address this important question in the context of deep RL")。

## 用什么方法解决的
不是提出新算法,而是设计一组**对照实验**,逐项扰动一个因素、其余固定,观察对最终表现的影响,并引入机器学习/统计学里的显著性工具(bootstrap、2 样本 t 检验、Kolmogorov-Smirnov 检验,以及功效分析 power analysis——论文专设 "Power Analysis" 一节,用 bootstrap 功效分析判断样本量是否够:给样本一个 uniform lift(如统一 ×1.25),跑多次 bootstrap 模拟看多大比例仍显著,显著比例小则说明需要更多试验)来量化结果可信度。

## 动机 & 背景
RL 因在机器人、围棋、Atari、竞技游戏等领域的成果而备受关注(原文引言:"controlling continuous systems in robotics …, playing Go …, Atari …, and competitive video games"),要维持快速进展就必须让已有工作易于复现和比较。但实践中复现深度 RL 极难,文献对同一基线报告出很宽的结果范围。作者明确把研究范围**收窄到连续控制中的策略梯度(PG)方法**,因为带神经网络逼近器的 PG 方法在连续控制上尤其成功(原文:"Policy gradient methods with neural network function approximators have been particularly successful in continuous control")。

技术背景上,论文针对的是几种公开实现、常被当作基线的 model-free 策略梯度算法:"We experiment with Trust Region Policy Optimization (TRPO) …, Deep Deterministic Policy Gradients (DDPG) …, Proximal Policy Optimization (PPO) …, and Actor Critic using Kronecker-Factored Trust Region (ACKTR)"。它们都优化带折扣的期望回报 ρ(θ,s₀)=E_{π_θ}[Σ_{t=0}^∞ γᵗ r(s_t)|s₀],并用策略梯度定理更新(原文技术背景:"Generally, they optimize ρ(θ, s0) = E_{π_θ}[Σ γᵗ r(s_t)|s0], using the policy gradient theorem");TRPO/PPO 把更新重写为最大化重要性比 × 广义优势 At 的目标 max_θ E_t[ (π_θ(a_t|s_t)/π_{θ_old}(a_t|s_t)) · A_t(s_t,a_t) ]:TRPO 用共轭梯度并施加 KL 约束 E_t[KL[π_{θ_old}(·|s_t), π_θ(·|s_t)]] ≤ δ,PPO 把该约束改写成惩罚项(或裁剪目标);DDPG/ACKTR 是 actor-critic,估计 Q(s,a) 并优化最大化 Q 的策略(原文:DDPG 用确定性策略,ACKTR 用 Kronecker 因子化信赖域保证随机策略下的稳定性)。

## 数据集 & 实验设置
- **算法实现**:大多数实验用 OpenAI Baselines 的 ACKTR / PPO / DDPG / TRPO 实现(比较代码库的实验除外)。
- **环境**:主实验用 OpenAI Gym 的 Hopper-v1 与 HalfCheetah-v1 两个 MuJoCo 环境,"These two environments provide contrasting dynamics (the former being more unstable)";环境对比实验另加 Swimmer-v1 和 Walker2d-v1。
- **试验数**:"To ensure fairness we run five experiment trials for each evaluation, each with a different preset random seed (all experiments use the same set of random seeds)";随机种子专项实验则跑 10 次。
- **网络**:全用 MLP。默认设置——"For DDPG we use a network structure of (64, 64, ReLU) for both actor and critic. For TRPO and PPO, we use (64, 64, tanh) for the policy. For ACKTR, we use (64, 64, tanh) for the actor and (64, 64, ELU) for the critic."
- **结构扫描**:比较三种常见架构 "(64, 64), (100, 50, 25), and (400, 300)",并在 tanh / ReLU / Leaky ReLU 间变换激活;每次只动一个超参,**训练 2M 个时间步**后报告"最后 100 条轨迹回报的 5 次试验均值 ± 标准误"(表 1 策略网、表 2 值函数网)。

## 主要结果 & 结论
**超参与网络结构敏感**:表 1/表 2 表明结构和激活的简单改动会显著改变最终表现。作者发现"usually ReLU or Leaky ReLU activations perform the best across environments and algorithms",但紧接着强调"The effects are not consistent across algorithms or environments"——即**没有一个放之四海皆准的最佳设置**(observed,仅在所测环境/算法上观察到)。作者以 PPO 为例说明超参之间的纠缠:原文"using a large network with PPO **may require** tweaking other hyperparameters such as the trust region clipping or learning rate to compensate for the architectural change"——即换用大网络**可能需要**相应调整剪裁/学习率等超参(论文用的是"可能需要"而非"必须",且这是 PPO 这一例的说明)。作为机制旁证,脚注给出量化:大网络 (400,300) 更新的 KL 散度"is on average 33.52 times higher than"(64,64) 网络。这种**超参之间的纠缠**正是复现难的根源之一。

**奖励缩放**:"Figure 3 shows one such example where reward rescaling affects results, causing a failure to learn in small settings below" σ̂=0.01;且"layer normalization changes how the rescaling factor affects results, suggesting that these impacts are due to the use of deep networks and gradient-based methods"。效应在环境/缩放值之间不一致(observed)。

**随机种子**:把同一超参配置的 10 次试验拆成两组各 5 次平均,两条平均曲线竟落在统计上不同的分布上——整段训练分布的 2 样本 t 检验得 t=-9.0916, p=0.0016(原文:"The average 2-sample t-test across entire training distribution resulted in" t=−9.0916,p=0.0016)。这是全文最有冲击力的证据:**仅换随机种子就能造出"看似显著"的差异**。作者据此批评"it is not uncommon for the top-N trials to be selected from among several trials"或在 N<5 的少量试验上平均的做法可能误导。

**环境选择**:"in environments with stable dynamics (e.g. HalfCheetah-v1), DDPG outperforms all other algorithsm. However, as dynamics become more unstable (e.g. in Hopper-v1) performance gains rapidly diminish"——即**哪个算法最好取决于选哪个环境**,不存在通吃的赢家(observed)。Swimmer-v1 上 TRPO 显著领先,但作者揭示一个陷阱:"Due to the dynamics of the water-like environment, a local optimum for the system is to curl up and flail without proper swimming"(该局部最优对应回报约 130)——回报曲线上升不等于学到了期望行为,故主张除回报外还要展示策略的实际演示。

**代码库**:仅"implementation differences which are often not reflected in publications can have dramatic impacts on performance"——同一算法不同实现(如 TRPO 的 Schulman 2015/2017、rllab;DDPG 的 Duan/Gu/Plappert)结果差异巨大(图 6、表 1/2)。

**显著性工具**:用 bootstrap(1 万次迭代、pivotal 法)给出各环境的均值与 95% 置信区间(表 3),发现"TRPO and PPO are the most stable with small confidence bounds"。作者还给出一个具体案例:Walker2d-v1 上 ACKTR 虽略优于 DDPG,但"this performance is not significant due to the overlapping confidence intervals of the two"(t=1.03, p=0.334; KS=0.40, p=0.697; bootstrap 百分比差 44.47%,区间 (-80.62%,111.72%))——这单一案例说明,两者置信区间重叠时该差异不显著(这是针对该对比的具体结论,不是把"区间重叠"当作一般性的统计判定规则)。

**结论/建议**:新基线实现应匹配原始码库结果(原文:"new baseline algorithm implementations used for comparison should match the original codebase results if available");"due to the high variance across trials and random seeds …, many trials must be run with different random seeds when comparing performance";并做适当显著性检验。最重要的一条是"the most important step to reproducibility is to report all hyperparameters, implementation details, experimental setup, and evaluation methods for both baseline comparison methods and novel work"。未来方向之一是构建**对超参不敏感(hyperparameter agnostic)的算法**,以消除奖励尺度、批大小、网络结构等外部因素带来的不公平。

## 核心贡献
1. **首个**系统刻画深度 RL(连续控制 PG 方法)可复现性问题的实证研究。
2. 用对照实验**量化**了超参、网络结构、激活、奖励缩放、随机种子、代码库、环境七类因素对最终表现的影响,并指出它们彼此纠缠。
3. 给出"仅改随机种子即可制造统计显著差异"的直接证据(t=-9.0916, p=0.0016),警示 top-N 选取和小样本平均的报告陷阱。
4. 把 bootstrap 置信区间、t/KS 检验、功效分析(论文 "Power Analysis" 一节)引入 RL 结果评估,并用 Walker2d-v1 上 ACKTR vs DDPG 的实例演示"置信区间重叠时差异不显著"。
5. 提出可复现性实践建议(完整报告超参/实现/设置、匹配原始码库、多种子多试验、显著性检验)与未来方向(超参不敏感算法、更适配 RL 的显著性度量)。

## 局限与我的质疑
1. **作者自述的范围局限**:全文只覆盖连续控制中的少数策略梯度算法(TRPO/DDPG/PPO/ACKTR)和少数 MuJoCo 环境,主实验更只用 Hopper-v1/HalfCheetah-v1 两个环境。结论关于"敏感性"很有说服力,但能否外推到离散控制、value-based 方法、Atari/真实机器人,论文**没有证明**,只能算在所测范围内成立(多数结果 strength=observed)。
2. **诊断强、处方弱**:论文把问题揭示得淋漓尽致,但给不出可操作的硬阈值——作者自己也承认"While there can be no specific number of trials specified as a recommendation"(原文见随机种子一节,紧接着提到 power analysis 可给出大致参考)。对想复现者而言,"多跑几个种子、做显著性检验"是正确但偏原则性的建议;到底几个种子够、用哪种检验最适合 RL(作者也指出监督学习的校正检验假设未必适用于 RL)都留作未来工作。
3. **统计方法本身的细节未充分披露在正文**:t 检验把"整段训练分布"的回报当样本做 2 样本检验,这些回报在时间上高度自相关,普通 t 检验的独立性假设存疑;p 值的绝对数值应谨慎解读(其定性结论"种子能造出显著差异"仍成立,但量级可能被夸大)。许多关键曲线和"采样文献综述""功效分析"明细都放在补充材料,正文只给代表性图表,复核完整证据链需另取补充材料。(总结者注:此条为我的方法学质疑,非论文自身的论断。)
4. **Swimmer "局部最优"论断依赖视频证据**:作者用策略回放说明 TRPO 在 Swimmer 上的高回报其实是"蜷缩扑腾"的局部最优,这一判断基于视频观察而非可量化指标,属于定性论据,读者无法仅从论文数字独立验证。
5. **对本研究主题(训练稳定性工具箱)的意义与不足(总结者注)**:这篇是**问题定义与诊断的经典**,把"训练方差/种子敏感/报告不规范"摆上台面,非常适合作为评估规范的锚点;但它**不提供稳定化方法或监控工具**——它告诉你"水有多深",却不给"船"。要落到稳定性工具,需结合后续提出具体方差削减、自适应超参或标准化评估协议的工作。
