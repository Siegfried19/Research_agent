# VCSAP: Online reinforcement learning exploration method based on visitation count of state-action pairs
> Ruikai Zhou, Wenbo Zhu, Shuai Han, Meng Kang, Shuai Lü · 2025 · Neural Networks · 引用 8 · DOI 10.1016/j.neunet.2024.107052

## 一句话
把传统"只数状态访问次数"的计数式探索升级为"同时数状态访问次数 + 状态-动作对访问次数"，用两套 RND 风格的预测/目标网络产生内在奖励，既鼓励 agent 访问新状态、也鼓励它做出新决策，挂在 PPO/TRPO 上在 MuJoCo（含稀疏奖励版）上比 RND/ICM/RIDE 平均更好。

## 解决了什么问题
计数式（count-based）探索给"很少访问的状态"高内在奖励、给"常访问的状态"低内在奖励，以驱动 agent 探索新状态。但它**只看状态的新颖度、忽略动作（策略决策）的新颖度**：同一个被访问过很多次的状态，即使 agent 这次选了一个全新的动作（可能引出全新策略路径），传统方法仍一视同仁地给低奖励，于是某个状态-动作对被反复采样、agent 陷入局部最优、探索不充分。尤其在连续高维动作空间（如多关节机器人）和稀疏/欺骗性奖励环境下问题更突出。

## 用什么方法解决的
提出 **VCSAP（Visitation Count of State-Action Pairs）**：在 RND 的"随机固定目标网络 vs 可训练预测网络、用预测误差衡量新颖度"框架上，**同时对状态 s_{t+1} 和状态-动作对 (s_t,a_t) 计数**。预测误差大→访问少→新颖度高→内在奖励高。
- 两种实现：① **一对网络**——把 (s_t,a_t,s_{t+1}) 一起喂进单对 predictor/target，误差直接当内在奖励；② **两对网络**——一对数状态 s_{t+1}（误差 r_{s'}）、一对数状态-动作对 (s_t,a_t)（误差 r_{sa}），分别训练。
- 内在奖励组合方式：两对网络版用**乘法** r_i = r_{sa}·r_{s'}（消融实验中乘法普遍最优，作者推测乘法显著放大内在奖励、鼓励 agent 找"两个新颖度都高"的动作）。总奖励 r = r_e + β·r_i，β=0.5。
- 通过四种情形（状态/动作对各自新颖或不新颖的组合）调节奖励：尤其"状态旧但动作对新"（Condition III）这一档，传统方法会给低奖励，VCSAP 反而给较高内在奖励以鼓励新决策。
- 理由还借助 online RL 的"强纠错能力"论证：offline RL 里 OOD 动作有害需用 state-action 计数去避免，但 online RL 实时交互能即时修正坏的 OOD 动作、保留有益动作，所以反过来可以用 state-action 计数去**鼓励** OOD/新动作。
- 挂在 PPO 和 TRPO 上（PPO-VCSAP / TRPO-VCSAP）。

## 动机 & 背景
DRL 正从离散低维动作空间转向连续高维（多腿机器人、自动驾驶、机器人搬运），这些场景奖励常稀疏或带欺骗性，探索是跳出局部最优、保证策略梯度算法全局收敛（前提是状态空间被广覆盖）的关键。作者把探索方法谱系梳理为：动作空间随机性（ε-greedy、各种噪声）→ 参数空间/隐空间噪声、熵项 → 进化/类脑/多样性/乐观/分布式探索 → 内在动机（好奇心、信息增益、计数）。计数式探索是内在奖励的一个重要分支，但短板是"只数状态、不数策略"。VCSAP 即针对此短板。相比好奇心驱动（依赖对环境动态的准确预测，模型不准时效率下降）和信息增益/相邻状态差异（易放大环境噪声）/记忆式（存储与计算开销大），作者主张 VCSAP 更稳定、不需精确环境建模。

## 方法细节
- **网络框架**：复用 RND——目标网络随机初始化且永不更新（作恒定参照），预测网络通过最小化与目标网络输出的 MSE 来训练；常访问的输入预测误差小→内在奖励低，反之高。作者称任何合理的计数式方法都能嵌进 VCSAP。
- **两个内在奖励分量**：r_{s'}（状态新颖度）来自把 s_{t+1} 输入数状态的那对网络；r_{sa}（策略新颖度）来自把 (s_t,a_t) 输入数状态-动作对的那对网络。
- **四种情形**：I 状态与动作对都罕见→r_i 最高；II 状态新但动作对常见→略低；III 状态常见但动作对新→状态分量低、但总内在奖励仍抬高以追更好策略（这是与纯状态计数的关键差别）；IV 都常见→r_i 最低。
- **算法**：给出 PPO-VCSAP / TRPO-VCSAP 各两版伪代码（一对网络 / 两对网络）。两对网络版精度更高但算法复杂度更高。预测网络在训练策略阶段用各自的 r_{sa}、r_{s'} 做梯度下降更新；目标网络不动。
- **超参**（Table 2）：PPO buffer 4000、TRPO 5000；γ=0.995、λ=0.97（GAE）；PPO batch 256、lr 3e-4、clip 0.2；TRPO L2reg、max_kl=0.01；β=0.5。

## 数据集 & 实验设置
- 环境：MuJoCo 四个连续控制任务 Hopper-v2、Walker2d-v2、Ant-v2、HalfCheetah-v2；外加 sparse MuJoCo（如沿 x 轴超过阈值才 +1，否则 0）。HalfCheetah 被视为"稠密且欺骗性"环境，其余为稠密非欺骗。
- 训练 3M 步；结果取 5 个随机种子的均值与标准差。
- baseline：原始 PPO/TRPO、RND、ICM、RIDE。
- 三个研究问题：能否探到更多新动作；是否优于纯状态计数及原因；在稠密/稀疏/欺骗奖励下能否更好。
- 专项实验：初始状态 s_0 采样动作多样性饼图对比（VCSAP vs RND，3000 步、5 个 agent）、参数 β/学习率/max_kl/策略网络复杂度敏感性、r_{sa} 与 r_s 不同组合方式（加减乘除幂）的消融。

## 主要结果 & 结论
- 摘要总述：相比 RND，PPO-VCSAP 与 TRPO-VCSAP 在 8 个环境分别提升 18% 和 8%。
- **稠密环境**：相对原始算法，加 VCSAP 后 PPO 提升 4%–37%、TRPO 提升 18%–24%（Hopper-v2 上 TRPO-VCSAP 与 TRPO 持平、且 −2%，略逊 TRPO-ICM）；相对 RND，PPO-VCSAP 提升 2%–72%，TRPO-VCSAP 在 Walker2d/HalfCheetah 高 14%/18%。HalfCheetah（欺骗性）上 ICM/RIDE/RND 都让 PPO 掉点，唯 VCSAP 稳定提升。Ant-v2 上 ICM 因错误探索掉点。
- **稀疏环境**：VCSAP 与 RND 都优于裸 PPO/TRPO；加 VCSAP 后 PPO 提升 1%–159%、TRPO 提升 9%–238%；相对 RND，PPO-VCSAP 在 SparseHalfCheetah/SparseWalker2d 提升 4%/7%，TRPO-VCSAP 提升 22%/38%。
- **动作多样性**：饼图显示 VCSAP 的初始状态采样动作分布比 RND 更分散，说明确实探到更多新动作、对初始状态敏感度更低。
- **消融**：r_{sa}·r_s 乘法在多数环境最优（Hopper-v2 上 TRPO 乘法为次优）。β=0.5 在稠密环境近最优；稀疏环境对 β 更敏感需仔细调；TRPO-VCSAP 对 max_kl 敏感；策略网络太复杂+数据不足时 PPO-VCSAP 训练波动大、TRPO-VCSAP 因数据更多更稳。
- 代价：因多算 state-action 对，时间复杂度比 RND 高 10%（PPO）/21%（TRPO）。
- 结论：同时计数状态与状态-动作对能提升 online RL 算法性能，在稠密/稀疏/欺骗奖励下都更好；未来计划用更简网络/近似/SVD 降维降时间复杂度，并推广到多智能体 RL。

## 核心贡献
1. 提出一种在线 RL 内在奖励度量法，同时计数状态与动作（状态-动作对）的访问次数。
2. 提出"同时关注状态新颖度与策略新颖度"的新计数式探索思路，鼓励 agent 既访问新状态、又采用新策略。
3. 把 VCSAP 落地到 PPO、TRPO 两类 on-policy 算法（各两种网络实现）。
4. 在 MuJoCo 与 sparse MuJoCo 多任务上做对比实验，验证在稠密/稀疏/欺骗奖励下都能高效探索。

## 局限与我的质疑
1. **作者自述局限**：时间复杂度比 RND 高 10%–21%；β 在稀疏环境敏感、TRPO 对 max_kl 敏感、策略网过复杂时训练波动大——即方法对超参较敏感，工程稳健性打折扣。多智能体推广仅是未来设想，尚未验证。
2. **"计数 state-action 对"的可扩展性存疑（核心质疑）**：在连续高维动作空间里，状态-动作对的空间几乎无限，作者自己也承认"连续控制每个状态可选动作不可计数"。用 RND 预测误差去"近似计数"这个组合空间，当维度升高时预测网络能否真正区分新旧动作对、误差是否会被高维噪声淹没，论文没有任何理论或诊断分析，只给了一个 s_0 处的饼图当佐证——证据相当单薄。
3. **内在奖励用乘法 r_{sa}·r_s 缺乏原理支撑**：作者只"推测"乘法放大了奖励所以好，但乘法会让"任一分量接近 0 时总奖励塌缩"（状态或动作对其一不新颖就几乎无奖励），这与正文 Condition III"状态旧但动作新也要给较高奖励"的设计自相矛盾。消融只在 2 个环境测，结论的普适性可疑。
4. **提升幅度的呈现有夸大嫌疑**：摘要用"提升 18%/8%"，但表格里大量大百分比（159%、238%）来自稀疏环境**基线绝对值极低**（如 PPO Ant-v1 从 198 到 201，标注 1% 却伴随 ±269/±283 的巨大方差）。很多对比的提升完全淹没在 5 个种子的标准差里，没有做显著性检验，"VCSAP 更好"的结论被过度解读。Hopper 上甚至 −2%。
5. **baseline 偏弱、未对比 SOTA 计数法**：选 RND/ICM/RIDE，但 RIDE 本是为程序生成离散环境（MiniGrid）设计的，搬到 MuJoCo 连续控制本就不公平；未对比同样面向连续控制的更强探索法（如 SAC 的最大熵、Disagreement/Plan2Explore、伪计数 hash 法 #Exploration 等），"超越"成色有限。
6. **与本研究主题（RL 训练数字人与环境交互）的差距**：本文完全是 MuJoCo 低维 proprioceptive 仿真控制，没有人形/数字人、没有人机交互、没有视觉或高维感知输入、也无真实物理或人类反馈，纯粹是"探索算法工具箱"层面的贡献。它能进我们工具箱的理由是"计数探索 + PPO/TRPO 横比"，但要迁移到数字人那种超高维动作（全身多关节 + 表情/语音）和需与人交互的奖励结构上，本文方法的可扩展性正是其最大未解问题（见第 2、3 条），实用价值需打折看待。
