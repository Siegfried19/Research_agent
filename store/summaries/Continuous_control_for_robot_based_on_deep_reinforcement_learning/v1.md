# Continuous control for robot based on deep reinforcement learning
> Shansi Zhang · 2019 ·  · 引用 937 · DOI 10.32657/10356/90191

## 一句话
这是一篇南洋理工大学（NTU）的工程硕士学位论文，系统性地把 DDPG、A3C/A2C、PPO、TD3 等主流深度强化学习算法套用到冗余机械臂多目标到达、SCARA/移动机器人轨迹跟踪、自动驾驶超车等连续控制任务上，并叠加 HER、优先回放、分布式框架、两阶段训练、LSTM 等改进做对比实验。

## 解决了什么问题
传统机器人控制依赖精确动力学模型 + 复杂的控制器设计（要满足 Lyapunov 稳定性），而很多系统的精确模型难以获得。本文想用**无模型（model-free）深度强化学习**做高层决策，让机器人只从与环境交互中、直接由观测映射到动作来学会任务，绕开建模与控制器设计；同时针对 RL 在连续控制中的几个老大难——稀疏奖励、探索困难、样本效率低、训练速度慢——逐一套用/微调现有技术。

## 用什么方法解决的
全部在仿真里（机械臂用 V-REP 解逆运动学，自动驾驶用 TORCS），分四大块：
1. **DDPG 系**：用 DDPG+HER（二元稀疏奖励）训冗余机械臂多目标到达，约 80% 成功率；又提出把 HER 思路（final/future/random 选额外目标）与 shaped reward 结合人工造 transition，发现 random 策略成功率最高（87/100）。再用 DDPG+优先回放训 SCARA 与移动机器人轨迹跟踪，引入"随机参考状态初始化"和"提前终止"两个训练技巧解决探索难题。
2. **分布式 DRL**：用 A3C/A2C 训机械臂（提出优化末端路径的新奖励函数，发现 A2C 优于 A3C）；自己提出一个 DDPG 的分布式框架（同步 worker 算梯度 + 采集 worker 用不同策略/噪声填共享回放池），跟踪误差比单 worker DDPG 更小、学得更快。
3. **PPO 系**：PPO+GAE 的分布式框架训机械臂和移动机器人；提出"两阶段训练"（监督预训练 + 分布式 PPO 微调）提升样本效率与跟踪精度；再引入 LSTM 表示 actor/critic（用 buffer 存 cell/hidden state 解决初始状态不准问题），跟踪性能优于全连接网络。
4. **自动驾驶**：在 TORCS 里用 DDPG 和 TD3 端到端学驾驶/超车，采用"模仿学习预训练 + DRL 微调"两阶段策略，设计鼓励平滑行驶与超车的奖励函数，发现 TD3 主要通过提速改善了驾驶表现，且在未见过的复杂赛道上有泛化能力。

## 动机 & 背景
作者从 AlphaGo 谈起，认为深度学习提供丰富表征、强化学习提供基于奖励的"演绎式"试错能力，二者结合更贴近通用人工智能的需求。核心论点：传统控制要精确动力学模型 + 大量数学分析、控制器设计复杂，而 model-free DRL 不需要系统模型，策略由神经网络表示、只吃环境观测，靠最大化长期回报来逼近最优策略，可作为高层控制方法（但实际系统仍需底层控制器输出最终力矩）。第 2 章用大篇幅做文献综述（DQN/Double/Dueling/Rainbow、DPG/DDPG、A3C、TRPO/PPO、GAE、TD3、SAC、HER、好奇心驱动、分布式架构 IMPALA、多任务 PopArt 等），并补齐了 MDP、策略迭代、值迭代、SARSA、Q-learning、DQN、策略梯度的基础推导。

## 方法细节
- **DDPG**：actor-critic，确定性策略 + 目标网络软更新（θ′←εθ+(1−ε)θ′）+ 回放池，OU 噪声做探索，Adam 优化。
- **优先回放**：按 TD 误差给采样概率（P(i)∝P_i^α），用重要性采样权重 w_i 纠偏（β 从<1 逐渐→1 以保收敛），用 sum-tree 高效采样。
- **HER**：把"实际到达的状态"当作事后目标重标记 transition、重算奖励，让稀疏/二元奖励也能学；用 universal value function 思路把 goal 拼进 actor/critic 输入。
- **机械臂**：7 自由度冗余臂，actor 输出末端位置增量 Δp，再过逆运动学（伪逆/DLS）；3 隐层各 100 神经元 FC。
- **跟踪任务**：给出 SCARA（臂矩阵）与差速移动机器人（运动学+动力学）模型；actor 两隐层 300/100，输出 sigmoid×缩放向量；归一化指数奖励函数 + 随机参考状态初始化 + 提前终止。
- **分布式 DDPG / PPO**：多 worker 并行采集与算梯度，避免梯度延迟、提高吞吐与多样性。
- **两阶段训练**：监督预训练 actor → 分布式 PPO 微调；自动驾驶则是模仿学习 → DDPG/TD3。
- **LSTM**：用 buffer 存每个 episode 初始化用的 cell/hidden state 并随训练更新。
- **TD3**：双 Q 取小、actor 延迟更新、目标动作加噪平滑，缓解 DDPG 的 Q 值高估。

## 数据集 & 实验设置
全部为仿真，无真实机器人。机械臂/SCARA/移动机器人在 V-REP；自动驾驶在 TORCS（输入含车位姿、速度、与赛道边缘及其他车距离）。机械臂多目标训练典型设置：200 epoch（HER）或 100 epoch，每 epoch 50 cycle、每 cycle 16 episode，回放池 10^6、batch 128，每 cycle 更新 40 次。给出了若干超参表（学习率 0.001、γ=0.9、ε=0.05 等）和测试统计（100 episode 成功次数、三维跟踪误差表）。评价指标主要是成功率、回合奖励、actor loss、参考路径 vs 实际路径、各维跟踪误差、超车成功次数/速度。

## 主要结果 & 结论
- 机械臂多目标：HER（final/future）均约 80% 成功率；shaped reward 无额外目标仅<10%；shaped+random 策略最高（测试 87/100）。
- A2C > A3C（归因于避免梯度延迟）；分布式 PPO + 路径优化奖励在机械臂上成功率最高。
- 自研分布式 DDPG 比单 worker DDPG 学得更快、跟踪误差更小。
- 两阶段训练（预训练+PPO）显著降低交互步数、提升跟踪精度；分布式 PPO+LSTM 跟踪优于 FC。
- 自动驾驶：两阶段（模仿+DRL）训练后能在未见复杂赛道平稳行驶，TD3 主要靠提速优于 DDPG。
- 总结论：model-free DRL 能在不依赖精确模型下完成多种连续控制高层决策任务，且各类改进（HER、优先回放、分布式、两阶段、LSTM、TD3）分别在样本效率/速度/精度上带来增益。

## 核心贡献
1. 提出 shaped reward + future/random 额外目标策略，把 HER 的事后重标记思路迁移到非稀疏奖励，提升样本效率（random 优于 future，因目标更多样）。
2. 提出一个 DDPG 的分布式框架（同步算梯度 worker + 多策略/噪声采集 worker 共享优先回放池），实验上快于且准于单 worker DDPG。
3. 提出 PPO 的分布式框架，并配两阶段（监督预训练+PPO 微调）训练策略与 LSTM+状态 buffer 方案改善轨迹跟踪。
4. 为机械臂提出优化末端到达路径的新奖励函数；为自动驾驶设计鼓励平滑行驶/超车的奖励函数，并验证 TD3 相对 DDPG 的提升。

## 局限与我的质疑
1. **作者自述局限有限、且基本只在仿真**：全部实验在 V-REP/TORCS 仿真完成，没有任何真机验证，也基本未讨论 sim-to-real gap。文献综述里大量引用了 domain randomization、真机门把手开启等迁移工作，但本文自己一篇都没做迁移实验，"model-free 绕开建模"在真实系统（噪声、延迟、动力学失配）下能否成立完全没有证据。
2. **方法新意弱、更像工程组合与调参**：论文主体是把已有算法（DDPG/HER/优先回放/A3C/A2C/PPO/GAE/TD3/LSTM）逐个套到几个标准任务上做对比。所谓"贡献"（future/random 策略、分布式框架）相对单薄：分布式 DDPG/PPO 框架与文献中 Ape-X、D4PG、IMPALA 高度重叠却未与这些直接对比；新奖励函数属于 reward shaping 试错。作为硕士论文尚可，但**承载 937 次引用显得与其学术分量不匹配**（很可能是被当作 DRL 连续控制的综述式入门文献而非方法被引）。
3. **实验严谨性不足、结论被过度解读**：成功率/奖励曲线大多是单次运行、没有多随机种子的均值±方差，"A2C 优于 A3C""random 优于 future""TD3 优于 DDPG"这类结论缺乏统计显著性支撑，对差异的解释（如"避免梯度延迟""目标更多样")多为事后归因、未做消融隔离变量。测试样本（100 episode）规模小，自动驾驶的"强泛化能力"仅凭 3 条新赛道就下结论，证据偏弱。
4. **与本研究主题（RL 训练可与环境交互的数字人）相关性低**：本文对象是机械臂/移动机器人/车辆的高层运动控制与轨迹跟踪，**完全不涉及数字人、人体动作生成、人机交互、社交/情感行为或与人交互的环境**。最接近的只是文献综述里顺带提到的 Peng 等人 DeepMimic（模仿参考动作生成自然动作），但那是被引用的他人工作，不是本文内容。本文既无"数字人"的具身/外观/交互维度，也无"与人交互"的环境设定，对该主题只能作为 DRL 连续控制的背景性/方法基础参考，实质价值有限。
