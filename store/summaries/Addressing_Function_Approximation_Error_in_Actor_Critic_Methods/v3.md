# Addressing Function Approximation Error in Actor-Critic Methods
> Scott Fujimoto, Herke van Hoof, David Meger · 2018 · UvA-DARE (University of Amsterdam) · 引用 414 · DOI title:7f327668611a45e6

## 一句话
本文指出 actor-critic 连续控制方法同样存在值高估偏差与误差累积，提出用"双 critic 取最小值 + 延迟策略更新 + 目标策略平滑"三件套改造 DDPG，得到 TD3 算法。

## 解决了什么问题
离散动作 Q-learning 中"对带噪值估计取最大"会导致一致性高估，这一问题在连续控制的 actor-critic 中被很大程度忽视。作者明确：「We show that this problem persists in an actor-critic setting and propose novel mechanisms to minimize its effects on both the actor and the critic.」（p.1 Abstract）。更关键的是，他们发现离散设定下通用的解法 Double DQN 在 actor-critic 里失效——「we find the ubiquitous solution in the discrete action setting, Double DQN (Van Hasselt et al., 2016), to be ineffective in an actor-critic setting.」（p.1 §1），原因是慢变化的策略使当前网络与目标网络太相似，无法构成独立估计。除高估外，本文还要处理时序差分误差随更新累积导致的高方差。

## 用什么方法解决的
三个针对函数逼近误差的组件，叠加到 DDPG 上：
1. **Clipped Double Q-learning（critic 端）**——「Our algorithm builds on Double Q-learning, by taking the minimum value between a pair of critics to limit overestimation.」（p.1 Abstract）。
2. **延迟策略更新（actor 端）**——「we propose delaying policy updates until the value estimate has converged.」（p.1 §1），构成双时间尺度算法。
3. **目标策略平滑正则化**——「we introduce a novel regularization strategy, where a SARSA-style update bootstraps similar action estimates to further reduce variance.」（p.1 §1）。

## 动机 & 背景
本文沿用确定性策略梯度（DPG / DDPG）框架：actor 按确定性策略梯度更新，critic 学值函数。作者先在 §4.1 论证确定性策略梯度下值估计在一定假设下必然偏向高估，再用经验佐证：在 Hopper-v1 和 Walker2d-v1 上画出 DDPG 的值估计随时间的曲线（图1），「A very clear overestimation bias occurs from the learning procedure, which contrasts with the novel method that we describe in the following section, Clipped Double Q-learning, which greatly reduces overestimation by the critic.」（p.4 §4）。

对方差，作者强调误差会沿 Bellman 方程累积（§5.1）：高方差的值估计给策略更新提供噪声梯度，会拖慢学习并损害性能。图3 在 Hopper-v1 上对随机选取的单个状态画出值估计，对比**无目标网络**（图注标 τ=1）与**慢更新目标网络**（τ=0.1、0.01）——「However, when the policy is trained with the current value estimate, the use of fast-updating target networks results in highly divergent behavior.」（p.6 §5.1）。即在学习中的策略下，无目标网络/快更新目标网络（τ=1，每步令目标完全追上当前网络）导致发散，而慢更新（小 τ）更稳定（图3 caption: "without target networks, (τ = 1), and with slow-updating target networks, (τ = 0.1, 0.01)"）。这把"目标网络"从工程技巧上升为方差控制的关键。

## 方法细节
**Clipped Double Q-learning**：维持一对 critic，目标取两者最小——「This results in taking the minimum between the two estimates, to give the target update of our Clipped Double Q-learning algorithm:」（p.5 §4.2，式10）。其性质是「While this update rule may induce an underestimation bias, this is far preferable to overestimation bias, as unlike overestimated actions, the value of underestimated actions will not be explicitly propagated through the policy update.」（p.5 §4.2）——即不会在标准 Q-learning 目标上引入额外高估，宁可低估，因为低估的动作不会被策略更新放大传播。实现上「In implementation, computational costs can be reduced by using a single actor optimized with respect to Qθ₁.」（p.5 §4.2），即用单个 actor 配一对 critic（Algorithm 1）。

**延迟策略更新**：「We propose delaying policy updates until the value error is as small as possible.」（p.6 §5.2），即每隔 d 次 critic 更新才更新一次 actor 与目标网络，使 critic 先在稳定目标下收敛，再做策略更新，降低每次更新的误差。

**目标策略平滑**：「We introduce a regularization strategy for deep value learning, target policy smoothing, which mimics the learning update from SARSA (Sutton & Barto, 1998).」（p.7 §5.3）。做法是给目标动作加噪声并裁剪（式14），「where the added noise is clipped to keep the target in a small range.」（p.7 §5.3），在 mini-batch 上平均，使相邻动作的值平滑，避免确定性策略对值估计窄峰的过拟合。

**目标更新公式（式3）**：目标网络以 θ′ ← τθ + (1−τ)θ′ 软更新——原文式3 下方明确「by some proportion τ at each time step θ′ ← τθ + (1 − τ)θ′」（p.4 §3，式3）。三件套合并即 TD3 的目标（式15）：y = r + γ·min_{i=1,2} Q_{θ′ᵢ}(s′, π_{φ′}(s′)+ε)，ε∼clip(𝒩(0,σ), −c, c)，每 d 次迭代按确定性策略梯度更新 actor（p.7 §6 式15 + Algorithm 1）。

## 数据集 & 实验设置
- 任务：「We evaluate our algorithm on seven continuous control domains from OpenAI gym (Brockman et al., 2016), where we outperform the state of the art by a wide margin.」（p.3 §1）。具体七个 MuJoCo 任务可在 Table 1（p.9）与 Figure 5（p.9）逐项核到：HalfCheetah / Hopper / Walker2d / Ant / Reacher / InvertedPendulum / InvertedDoublePendulum（其中前四个亦见 Figure 4 示例图，标题为 "Example MuJoCo environments (a) HalfCheetah-v1, (b) Hopper-v1, (c) Walker2d-v1, (d) Ant-v1"）。
- 网络：「we use a two layer feedforward neural network of 400 and 300 hidden nodes respectively, with rectified linear units (ReLU) between each layer for both the actor and critic, and a final tanh unit following the output of the actor.」（p.8 §6.1）。
- 优化：「Both network parameters are updated using Adam (Kingma & Ba, 2014) with a learning rate of」10⁻³（p.8 §6.1），mini-batch 100 条转移、均匀采样自含全部历史的 replay buffer。
- 超参：延迟更新「delayed policy updates consists of only updating the actor and target critic network every d iterations, with d = 2.」（p.8 §6.1）；「Both target networks are updated with τ = 0.005.」（p.8 §6.1）；目标策略平滑「The target policy smoothing is implemented by adding ϵ ∼」𝒩(0,0.2) 噪声并裁剪到 (−0.5, 0.5)（p.8 §6.1，式15）。
- 评测协议：「Each task is run for 1 million time steps with evaluations every 5000 time steps, where each evaluation reports the」10 个 episode 的无探索噪声平均奖励（p.8-9 §6.1），结果在 10 个随机种子上报告。
- 基线：「We compare our algorithm against DDPG (Lillicrap et al., 2015) as well as the state of art policy gradient algorithms: PPO (Schulman et al., 2017), ACKTR (Wu et al., 2017) and TRPO (Schulman et al., 2015), as implemented by OpenAI's baselines repository (Dhariwal et al., 2017), and SAC (Haarnoja et al., 2018)」（p.9 §6.1），外加作者重新调参的 DDPG（"our DDPG"）。

## 主要结果 & 结论
- 表1（「Max Average Return over 10 trials of 1 million time steps.」p.9）报告各任务最大平均回报。TD3 的数值如 HalfCheetah 9636.95 ± 859.065、Hopper 3564.07 ± 114.74、Walker2d 4682.82 ± 539.64、Ant 4372.44 ± 1000.33（均见 p.9 表1 TD3 列），相对 DDPG（同表：HalfCheetah 3305.60、Walker2d 1843.85）有较大差距。
- 总体结论：「TD3 matches or outperforms all other algorithms in both final performance and learning speed across all tasks.」（p.9 §6.1）。注意这是在所测七个 MuJoCo 任务、上述协议下的结果，宜按"在这套任务上匹配或超过对比算法"理解，而非泛化到任意域。
- 消融（表2）：「We perform ablation studies to understand the contribution of each individual component: Clipped Double Q-learning (Section 4.2), delayed policy updates (Section 5.2) and target policy smoothing (Section 5.3).」（p.10 §6.2）。结果是「While the addition of only a single component causes insignificant improvement in most cases, the addition of combinations performs at a much higher level.」（p.10 §6.2）——单个组件多数情况下提升不显著，组合才显著，说明三者协同。
- actor-critic 版的 Double Q-learning / Double DQN（DQ-AC、DDQN-AC）对比：「Both methods result in insignificant improvements over TD3 - CDQ, with an exception in the Ant-v1 environment, which appears to benefit greatly from any overestimation reduction.」（p.10 §6.2），佐证 Clipped Double Q-learning 比这两种现成方案更能压制高估。

## 核心贡献
1. 证明并实证高估偏差在 actor-critic 连续控制中确实存在（图1、§4.1）；
2. 提出 Clipped Double Q-learning，可替换任意 actor-critic 的 critic（§4.2）；
3. 揭示目标网络与误差累积的关系，提出延迟策略更新（§5.1-5.2）；
4. 提出 SARSA 风格的目标策略平滑正则化（§5.3）；
5. 合成 TD3 并开源代码——「we run our experiments across a fair number of seeds ... and open source both our code and learning curves (https://github.com/sfujim/TD3).」（p.3 §1），并强调「As our modifications are simple to implement, they can be easily added to any other actor-critic algorithm.」（p.10 §7）。

## 局限与我的质疑
1. **结论强度需克制**：摘要的「outperforming the state of the art in every environment tested」（p.1）只覆盖七个 MuJoCo 连续控制任务、特定网络/超参与评测协议。表1 用的是"最大平均回报"（峰值）而非最终或平均水平，峰值指标对方差/随机种子敏感，且 Ant 的标准差高达 ±1000.33（p.9 表1），跨种子稳定性其实存疑。原文未声称在离散动作、稀疏奖励或真实机器人上同样成立，不应替它泛化。
2. **三件套的解释偏经验**：§4.1 给了确定性策略梯度下高估的论证（完整证明作者放在 supplementary material，本 PDF 正文未含），但延迟更新的 d=2、目标平滑噪声 𝒩(0,0.2)、τ=0.005 等关键超参更像调出来的工程选择，文中没有给出对这些取值的敏感性分析（正文层面），复用者需自行重调。
3. **低估偏差被一笔带过**：作者承认取最小值会引入低估（p.5 §4.2），并辩称低估优于高估。但低估同样可能让好动作被压制、探索不足，文中没有量化低估的代价，只论证了"不会传播"，这点的论证略显单薄。
4. **对比公平性的内生张力**："our DDPG"已吸收了 TD3 的全部网络/超参/探索改造，于是 TD3 与"our DDPG"之差才更接近三件套本身的净贡献；与原始 DDPG 的巨大差距里，有多少来自调参、多少来自三件套，需结合消融（表2）才能区分，单看表1 容易高估算法创新的功劳。
5. **与本研究主题（稳定性 trick / off-policy 改进）的契合与不足（总结者注）**：本文对"为什么 work"的机制讨论（高估传播、目标网络与方差累积）正是想复用稳定性技巧者最需要的部分，价值高；但它只在 MuJoCo proprioceptive 状态下验证，未涉及高维观测、模型化或与数字人/交互式环境相关的设定，迁移到这些场景时三件套是否仍是主导因素，本文无法回答。
