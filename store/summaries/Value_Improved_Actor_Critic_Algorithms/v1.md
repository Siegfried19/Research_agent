# Value Improved Actor Critic Algorithms
> Yaniv Oren, Moritz A. Zanger, Pascal R. van der Vaart, Mustafa Mert Celikok, Matthijs T. J. Spaan, Wendelin Bohmer · 2024 · arXiv.org · 引用 3 · DOI 10.48550/arxiv.2406.01423

## 一句话
把 actor-critic 里「实际执行的行动策略」与「被 critic 评估、用于算价值目标的策略」解耦，只对后者施加更贪婪的改进（称为 value improvement），既享受贪婪化带来的更优价值目标、又保留行动策略缓慢更新的稳定性——在 TD3/SAC 上几乎零成本地实现，并在 DeepMind 控制套件上全面更好或持平。

## 解决了什么问题
现代 AC 算法用神经网络参数化行动策略、靠梯度（如策略梯度）缓慢改进。梯度改进每步贪婪程度远低于 Q-learning 的 argmax；但太贪婪又会经高估偏差引发不稳定，于是「贪婪化 vs. 学习稳定性」成为一对矛盾：作者指出"slow changes to the policy can also be beneficial for the stability of the learning process, resulting in a tradeoff between greedification and stability"（p.1 摘要）。以往工作把改进拆成「先用算子产生更贪婪的目标策略、再用监督损失把行动策略回归到它」，但行动策略仍受梯度优化的速率限制，没有真正化解矛盾。本文要在不牺牲行动策略稳定性的前提下，让用于 bootstrap 的评估策略更贪婪。

## 用什么方法解决的
核心是解耦：保留 actor-critic 的行动策略 πθ（照旧缓慢梯度改进），但额外用一个（可以更贪婪的）算子把被 critic 评估的策略再改进一步，用这个更贪婪的策略来生成价值目标——"we propose to decouple the acting policy from the policy evaluated by the critic. This allows the agent to separately improve the critic's policy (e.g. value improvement) with greedier updates while maintaining the slow gradient-based improvement to the parameterized acting policy"（p.1 摘要）。这一步被命名为 value improvement step，整个框架称为 VIAC："We refer to an update step which evaluates an independently-improved policy as a value improvement step and to this approach as Value-Improved Actor Critic (VIAC)"（p.2 §1）。

落地有两条路（p.7 §4）："(i) Incorporating an additional explicit greedification operator to produce a greedier evaluation policy ... (ii) Incorporating an implicit greedification operator, for example by replacing the value loss with an asymmetric loss"：

- **显式（Algorithm 3，VI-TD3）**：在 TD3 流程中插入一行"Further improve the policy"（p.35 Algorithm 3 第9行），即用算子 I₂ 把策略在下一状态上再改进得到 π′，再从 π′ 采样动作来算 bootstrap 目标。其价值目标"is computed in the same manner to the original target of TD3 but with the fresh greedified target network"（p.36 §D.1），随后这个临时贪婪策略即被丢弃。文中显式算子用过重复梯度步（pg=n）和 Best-of-N。
- **隐式（Algorithm 4）**：把 critic 的 L2 损失换成 expectile 损失（asymmetric loss），用单一参数 τ 控制贪婪程度。直觉是"when τ > 0.5 the agent favors errors where the prediction should increase, over predictions where it should reduce"（p.36 §D.2），从而让价值网络隐式逼近一个更优策略的价值；当"If τ = 0.5, this loss is equivalent to the baseline L2 loss"（p.36 §D.2），即退化为原算法。

**机制对比（为什么选隐式）**：作者明确指出"Repeating gradient steps are very computationally expensive however. Implicit policy improvement on the other hand provides value improvement for negligible compute and implementation cost"（p.8 §4）——隐式做法既省算力，又能用 τ 直接旋钮式调贪婪度。

**理论侧**：论文先在 GPI 框架里给出一个反直觉结果——对随机策略，"Policy improvement is not a sufficient condition for the convergence of Policy Iteration algorithms"（p.5 Theorem 2，因为允许无穷小改进，可收敛到非 argmax 的次优策略）。为此作者定义了 lower-bounded greedification（Def 4，有限步收敛）与 limit-sufficient greedification（Def 5，极限收敛）两类充分算子，并证明 Theorem 3："Generalized Policy Iteration algorithms and their Value Improved extension (Algorithms 1 and 2 respectively) converge to the optimal policy for all sufficient greedification operators, in finite iterations (for operators defined in Definition 4) or in the limit (for operators defined in Definition 5), in finite-horizon MDPs"（p.7）。两个推论扩展了适用面：Gumbel MuZero 的 GPI 过程收敛（Corollary 1，p.7："The Generalized Policy Iteration process underlying the Gumbel MuZero algorithm family converges to the optimal policy for finite horizon MDPs"）；以及 value-improved 算法对评估侧算子要求很松——"Algorithm 2 converges to the optimal policy for any non-detriment operator I2 (e.g., operators that satisfy the non-strict inequality of Equation 4), as long as I1 is itself sufficient"（Corollary 2，p.7）。也就是说，只要行动策略侧的算子 I₁ 充分，value-improvement 用的 I₂ 哪怕不是贪婪化算子也不破坏收敛。

## 数据集 & 实验设置
- **环境**：DeepMind 连续控制套件（dm_control），主实验覆盖 12 个环境（hopper-stand/hop、humanoid-stand/walk/run、quadruped-walk/run、fish-swim、walker-walk/run、cheetah-run、acrobot-swingup）。
- **被改算法**：TD3、SAC（主实验隐式 expectile，τ=0.75）；另测显式 BoN（N=64）、显式重复梯度步（pg=n），以及更新的 TD7（VI-TD7）。
- **实现**：基于 CleanRL；公平性上"The VI-variations of all algorithms use the same hyperparameters as the baseline algorithms without any additional tuning, with the exception of grid search for the greedification parameters τ presented in Figure 2"（p.37 §D.5）——即唯一额外调的就是 τ。关键超参（p.37 §D.7）：γ=0.99、buffer 10⁶、batch 256、learning start 10⁴、policy update frequency=2、TD3 actor/critic lr=3e-4、target smoothing 0.005、exploration noise 0.1、target policy noise 0.2、noise clip 0.5；评估每 5000 步用 3 个 episode、确定性取均值动作（§D.3）。
- **统计口径**：主实验"Mean and two standard errors (≈ 95% Gaussian CI) ... across 10 seeds for BoN and 20 for the other agents"（p.9 Figure 3 caption）；其余消融图为 1 倍标准误、10 seeds。算力：单 seed 单 GPU，约 0.5–2 小时 / 10⁶ 环境步，全部实验合计约 12000 wall-clock 小时（§D.4）。

## 主要结果 & 结论
- **主结果（Figure 3，强基线对比）**：相对自身基线 TD3/SAC，"Across all environments, the VI (blue) variations significantly outperform or matches their respective baseline (red) while introducing negligible additional compute and implementation cost"（p.9）。注意措辞——是「全面更好或持平」，并非每个环境都大幅超越。
- **增益幅度（Table 1，p.33）**：以「Max performance gain」列（跨 τ 取最优时的回报增益）看，hopper-stand 为「353.80 ± 60.77」、hopper-hop「217.25 ± 26.38」、humanoid-stand「503.93 ± 14.72」、humanoid-walk「415.28 ± 29.29」，量级可观；但增益高度依赖环境，walker-walk 等环境本就接近天花板、增益很小。
- **贪婪度是可调超参（Figure 2）**：在 hopper-stand/hopper-hop 上，随 τ 增大"Performance increases up to τ = 0.8 and then decays"（p.8），呈先升后降——正面印证了「贪婪化 vs. 稳定性」权衡，且该权衡可被 τ 部分调和。
- **增益不是 expectile 独有（Figure 3 / §4）**：显式 BoN 版同样有效——"BoN-based VI-TD3 (N = 64) provides similar performance gains to expectile-based VI-TD3 in most environments, demonstrating that significant performance gains in these domains are not unique to the expectile operator"（p.9）。
- **机制澄清——不只是高估偏差**：作者把高估偏差单独测量并指出"We find that in the majority of the environments significant performance gains are observed without any over estimation increase"（p.9 §4），即增益不能简单归因于「expectile 抬高了价值目标导致的乐观探索」。
- **对照实验厘清因果**：单纯对行动策略多做梯度步无用——"Increasing the number of acting-policy updates on the same batch does not contribute to performance"（p.33 Figure 6）；说明起作用的是「评估策略更贪婪」，而非「在同一批上多优化几次行动策略」。
- **可迁移到更新算法（Figure 5）**：VI-TD7 相对 TD7"Similar performance gains are observed for VI-TD7 in this domain"（p.33）。

## 核心贡献
1. 提出并形式化 value improvement / VIAC 框架：解耦行动策略与被评估策略，仅对后者贪婪化（p.1 摘要、p.2 §1）。
2. 一个反直觉的理论否定：随机策略下策略改进不足以保证策略迭代收敛（Theorem 2，p.5），并据此提出 lower-bounded / limit-sufficient 两类充分条件、证明 GPI 及其 value-improved 扩展对所有充分算子收敛（Theorem 3，p.7）。
3. 两个收敛推论：覆盖 Gumbel MuZero 家族（Corollary 1），以及 value-improvement 侧算子只需 non-detriment（Corollary 2），后者把 IQL 式 expectile 隐式改进也纳入收敛保证。
4. 在 TD3/SAC/TD7 上以近零成本（隐式 expectile，仅多调 τ）实现，并在 dm_control 12 环境上系统验证、附高估偏差与对照消融。

## 局限与我的质疑
1. **理论与实践之间有明显缺口（作者自述 + 我的强调）**：收敛证明只覆盖"finite horizon MDPs with finite action spaces and discrete state spaces"（p.14），而实验全在连续状态/连续动作、用神经网络近似——Theorem 2/3 严格说并不直接保证实验里的 VI-TD3/SAC 收敛，理论更像「动机/合理性论证」而非对所用算法的保证。读者别把「证明了收敛」误读到深度 RL 实现上。
2. **「全面更好或持平」是经过 τ 调优后的结论**：主结果用 τ=0.75，而 Figure 2/Table 1 显示最优 τ 因环境而异（0.53–0.9 不等），且过大 τ 会衰减性能。论文虽强调 VI 变体「不额外调参，只调 τ」，但 τ 恰是新引入且敏感的旋钮，公平性上仍是给 VI 多了一个调过的自由度；「negligible implementation cost」对算力成立，但「无调参成本」并不完全成立。
3. **增益的环境异质性被均值叙事弱化**：Table 1 里 walker-walk、cheetah-run 等环境增益很小甚至接近噪声（如 cheetah-run 仅 10.37±11.18，误差几乎盖过均值），「significantly outperform or matches」里「matches」承担了不少分量。把它读成「普遍大幅提升」会过度解读。
4. **机制解释仍偏经验**：作者排除了「纯高估偏差」这一解释（p.9），也用 Figure 6 排除了「多做行动策略梯度步」，但对「为何更贪婪的评估策略恰能加速学习而不失稳」缺乏更深的机理刻画（如对 critic 误差传播、bootstrap 偏差的定量分析），目前停在「观察到 + 排除若干替代解释」的层面。
5. **统计口径偏宽松**：消融图用 1 倍标准误、主图用 2 倍标准误，seed 数 10–20，连续控制基准方差大，部分「持平」结论在更严格的多任务聚合统计（如 rliable）下是否稳健存疑——这是该类工作的通病，本文未做此类稳健性聚合。
6. **与本研究主题（RL 通用工具箱/训练稳定性）的契合与不足**：方法确实是对 TD3/SAC/TD7 的即插即用改进、直击贪婪化-稳定性权衡，复用门槛低（一个 expectile 损失 + 一个 τ）；但它默认环境是确定性的——§D.2 指出在随机环境中 expectile 会使价值网络 risk-seeking，需照 IQL 额外引入 vψ 网络，而论文实验「directly replaced the L2 loss」未走这条路，因此在随机环境下的稳定性/正确性尚未在本文实验中验证，迁移到带噪声任务时需补这一步。
