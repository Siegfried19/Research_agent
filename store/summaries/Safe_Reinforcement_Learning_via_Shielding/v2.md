# Safe Reinforcement Learning via Shielding
> Mohammed Alshiekh, Roderick Bloem, Rüdiger Ehlers, Bettina Könighofer, Scott Niekum, Ufuk Topcu · 2018 ·  · 引用 617 · DOI 10.1609/aaai.v32i1.11797

## 一句话
把"正确性"从学习算法里剥离出来,用形式化方法预先综合一个叫 **shield** 的反应式系统,在学习与执行的每一步过滤/纠正会违反时序逻辑安全规约的动作,从而**在环境符合所给抽象的前提下**让每一步都不违反安全规约;并且对那些本来就在标准 MDP 上收敛、且满足本文构造假设的学习算法,其收敛性可被继承(并非对任意 RL 算法的无条件保证)。

## 解决了什么问题
RL 算法能学到最大化回报的策略,但**不保证在学习或执行期间的安全性**——而把学习型控制器用到有人在场的物理系统(自动驾驶、机器人)里,"系统会不会安全运行"是核心顾虑。作者从形式化方法的视角切入,用时序逻辑的"安全片段"作规约语言(`"we focus on the so-called safety fragment of (linear) temporal logic"`, p.1),要回答的问题是:**"只要一切正常就让学习 agent 自由发挥,只在绝对必要时才监视并干预以保证安全"**该怎么做。

## 用什么方法解决的
核心是把一个 **correct-by-construction 的反应式系统(shield)** 插进传统 RL 回路。shield 由"安全规约 + 环境抽象"通过**反应式综合**预先算出,目标是同时保证**安全(safety)与最小干预(minimum interference)**(`"The shield is computed upfront from the safety part of the given system specification and an abstraction of the agent's environment dynamics. It ensures safety and minimum interference."`, p.2)。所谓最小干预,即"尽量少限制 agent,只在动作可能危及系统安全时才禁止"(`"the shield restricts the agent as little as possible and forbids actions only if they could endanger safe system behavior"`, p.2)。两种接入位置:
- **抢占式(preemptive)**:每次 agent 决策前,shield 先给一份安全动作清单(`"the shield acts each time the learning agent is about to make a decision and provides a list of safe actions"`, p.1)。
- **后置式(post-posed)**:shield 监视 agent 已选的动作,**仅当**它会违反规约时才纠正(`"the shield monitors the actions from the learner and corrects them only if the chosen action causes a violation of the specification"`, p.1)。

## 动机 & 背景
作者把 RL 视角(关心收敛/最优/数据效率)与形式化方法视角(关心正确性,尤其反应式综合)看成"互补但基本割裂"的两条线(`"two complementing yet mostly isolated views on safety in reinforcement learning and in formal methods"`, p.3),本文要合二为一:既要形式方法给的正确性保证,又要 RL 给的、对先验未知性能指标的最优化(`"combine the best of two worlds"`, p.6)。与"教师引导 RL(teacher-guided RL)"密切相关——shield 可看作一个"必要时才给安全动作的教师",但**关键区别在于 reward 信号不必被 shield 篡改**(`"Our work is closely related to teacher-guided RL, since a shield can be considered as a teacher ... In contrast to previous work, the reward signal does not have to be manipulated by the shield ..."`, p.3)。安全 RL 被形式化为定义 1:`"Safe reinforcement learning is the process of learning an optimal policy while satisfying a temporal logic safety specification φs during the learning and execution phases."`(p.6)。

## 方法细节
**shield 合成算法(§6)**,抢占式与后置式前两步相同:
1. 把安全规约自动机 φs 与 MDP 抽象 φM 翻成一个**两玩家安全博弈 G**:`"We translate φs and φM to a safety game G = (G, g0, ΣI, ΣO, δ, Fg) between two players. In the game, the environment player chooses the next observations from the MDP state (i.e., elements from L), and the system chooses the next action."`(p.12)。博弈状态空间是"规约自动机状态 × 抽象状态"的乘积。
2. 用标准安全博弈求解算出**获胜区域 W**(p.13)。
3. 据 W 构造 shield 反应式系统:**允许那些"无论下一步观测如何都保证留在 W 内"的所有动作**(`"The shield allows all actions that are guaranteed to lead to a state in W, no matter what the next observation is."`, p.14)。抢占式输出动作集合 ΣO = 2^A;后置式输出单个动作(若 agent 选的动作不在 W 则替换成某个安全动作)。

**机制要点——"向前规划(planning ahead)"**:这是 shield 之所以能保证安全而非事后救火的根源。它绝不允许进入"环境能强迫将来到达不安全态"的状态(`"it can never allow the play to visit a state from which the environment can force the play to visit an unsafe state in the future"`, p.7)——例如汽车要远在悬崖前就减速,而非等到检测出异常才反应。这也意味着 shield 必须有一个**保守的、可能仅近似已知的有限状态环境抽象**来"提前推演"。

**后置式的 reward 处理(§5.2)**:被纠正的不安全动作如何记分有两种选择。若给该不安全动作记惩罚,则"不保证最终策略已排除不安全动作,故 shield 在学习阶段之后仍须保持激活"(`"there is no guarantee that unsafe actions are not part of the final policy. Therefore, the shield has to remain active even after the learning phase."`, p.11)。后置式还可扩展为**排序版**:agent 给动作排名,shield 取排名中第一个安全动作,仅当全部不安全时才偏离排名另选(`"The shield selects the first action ... Only if all actions in rank_t are unsafe, the shield is allowed to deviate and to select a safe action al ∉ rank_t."`, p.15)。

**水箱运行例**:规约自动机与 MDP 抽象的乘积博弈"有 602 个状态"(`"... leads to a game with 602 states"`, p.13,已把错误态/paradise 态各并成一个)。求解后得到的 shield 会强制——水位过低时开进水阀到至少 4,**且水位高于 93 时禁止开阀**(`"it will also prevent the inflow from being opened when the level is above 93"`, p.8),因为阀一旦开就至少要开三步、其间进水可达 2L/s 而出水可能为 0,提前规划才能避免溢出。

## 数据集 & 实验设置
在四个领域演示(`"We applied shielded reinforcement learning in four domains: (1) a robot in 9x9 and 15x9 grid worlds, (2) a self-driving car scenario, (3) an Atari® game called SeaquestTM, and (4) the water tank example from Section 4."`, p.17):
- **网格世界**:表格 Q-learning + ε-greedy,支持一次多步策略更新(`"The agent uses tabular Q-learning with an ε-greedy explorer that is capable of multiple policy updates at once."`, p.17);安全性质 φs1(不撞墙/移动对手,两实验都用)、φs2(不在炸弹上停留超两步,仅 9x9 用)(`"φs1: the robot must not crash into walls or the moving opponent agent ... φs2: the robot must not stay on a bomb for more than two consecutive steps."`, p.17)。
- **自动驾驶**:480×480 环境,每步前进 3 像素、最大转向 7.5 度;离墙小于 60 像素作为 shield 输入;agent 用 **DQN + Boltzmann 探索**。
- **Atari Seaquest**:agent 当**黑盒**(只收 RGB 图像、shield 只改违规动作);φs1=氧气耗尽前必须上浮,φs2=氧气足且尚未救到潜水员时不许上浮(`"First, the submarine has to surface before oxygen runs out (φs1). Secondly, the submarine is not allowed to surface if it has enough oxygen but has not collected any divers yet (φs2)."`, p.20)。
- **水箱**:后置式 shield,对比 Q-learning 与 SARSA。
合成开销很小:9x9 的 shield 2 秒、15x9 的 0.6 秒(`"In the 9x9 grid-world, we synthesized a shield from φs1 ∧ φs2 ... in 2 seconds. In the 15x9 experiment ... in 0.6 seconds."`, p.18);自动驾驶抢占式与后置式均 2 秒(`"Both of the preemptive and the post-posed shields were synthesized in 2 seconds."`, p.19);水箱不到一秒(p.21)。

## 主要结果 & 结论
- **网格世界**(图11):"只有无屏蔽版本出现负奖励;屏蔽版本不仅安全,而且往往学得更快"(`"Fig. 11 shows that only the unshielded versions experience negative rewards. Furthermore, the shielded versions are not only safe, but also tend to learn more rapidly."`, p.19)。
- **自动驾驶**(图12):无屏蔽版奖励虽上升但仿真末段仍会撞墙;"无惩罚的屏蔽版学得更快且从不撞车"(`"The shielded version without punishment ... learns more rapidly than the unshielded learning scenario and never crashes."`, p.19)。
- **Atari Seaquest**(图13):"屏蔽未改变学习者性能,但屏蔽后 φs1∧φs2 不再被违反"(`"shielding the learner did not change its performance, however, the safety properties φs1 ∧ φs2 were not violated when shielding the learner"`, p.20)——即"零性能代价换来零违规"。
- **水箱**(图14):屏蔽与非屏蔽的 Q-learning、SARSA **都**达到最优策略,但"屏蔽实现到达最优所用时间明显更短"(`"... both shielded ... and unshielded ... do reach an optimal policy. However, the shielded implementations reach the optimal policy in a significantly shorter time ..."`, p.21)。

**理论结果(真正被证明的)**:① 所算 shield 满足正确性与最小干预两条性质(`"We now prove that the shields computed according to the definitions indeed have the claimed properties, namely correctness, and minimal interference."`, p.15);② 收敛性可继承——能构造 shield×MDP 的乘积 MDP M',故"凡在标准 MDP 上收敛的学习算法,在 shield 存在下也能被证明收敛"(`"Since M′ is a standard MDP, all learning algorithms that converge on standard MDPs can be shown to converge in the presence of a shield under this construction."`, p.16)。注意这条继承有前提:仅针对**本来就在标准 MDP 上收敛**的算法,且后置式情形还要求"当 agent 选的动作排名里没有安全动作时,对所执行安全动作存在一个不随时间变化的固定概率分布"(p.16),否则无法把 shield×环境建模成乘积 MDP。

**总体结论**:"在所有场景中屏蔽 agent 至少与非屏蔽一样好,多数情况下还改善了学习性能"(`"In all of them, the shielded agents perform at least as well as the unshielded ones. In most cases, our approach even improved the learning performance."`, p.21)。

## 核心贡献
1. **shielded learning 框架**:给定时序逻辑规约综合一个 shield,使系统执行在学习与控制阶段对规约的正确性都得到保证,且与学习收敛快慢无关(`"we propose to synthesize a reactive system called a shield"`, p.1)。
2. **抢占式 / 后置式两种接入方式**及对应的 reward 处理与排序扩展。
3. **shield 合成算法 + 正确性/最小干预证明 + 收敛性继承**(§6–7)。
4. **学习算法无关性**:shield"只依赖被监控的输入-输出行为、环境抽象与正确性规约,与底层学习算法的内部细节无关"(`"A shield depends only on the monitored input-output behavior, the environment abstraction, and the correctness specifications – it is independent of the intricate details of the underlying learning algorithm."`, p.21),因而兼容函数逼近,可用于黑盒 agent(如 Atari DQN)。

## 局限与我的质疑
1. **作者自述的核心软肋——需要环境抽象**:"为阻止不安全动作,必须事先有一个'何种动作在何时不安全'的近似模型"(`"... some approximate model of when which action is unsafe needs to be available."`, p.22)。作者辩称当依赖环境状态时这"不可避免",但这恰恰把难题从"学策略"转移到了"手工建一个**保守而又足够精确**的有限状态抽象"。论文里所有实验抽象要么是"精确"网格、要么是水箱/Atari 这类规则清晰可枚举的离散动力学;对真实世界中动力学复杂、连续、部分可观测的环境,如何得到既安全(不漏掉危险)又不过度保守(不把 agent 困死)的抽象,论文**未给出方法,也未做实验**,这是最大的落地缺口。
2. **安全保证是"相对于抽象"的,不是绝对的**:correctness 证明依赖"环境符合抽象"这一前提;论文自己也承认,当观测到的 MDP 行为偏离抽象时,这种情形在博弈里被记为系统玩家获胜(p.13)——也就是说**抽象一旦不忠实于真实环境,安全保证就失效**。"never crashes""not violated"这些结论应理解为"在抽象成立的前提下",而非无条件成立。
3. **实验规模与强度偏弱,提升幅度多为定性**:四个例子都属小规模/低维或离散设定;多数结论是"学得更快/从不撞车/不再违规"这类**图示定性观察**,缺乏统计显著性、随机种子方差、与更强安全 RL 基线(如约束 RL、CMDP、Lagrangian 方法)的定量对比——对比对象基本只是"无屏蔽"或"加大惩罚的无屏蔽"。因此"improved learning performance"宜按 observed 解读,不应外推成"普遍/大幅优于现有安全 RL 方法"。(总结者注:此为我对论文实验强度的评价,非论文自身论断。)
4. **可扩展性隐忧**:shield 状态空间是"规约自动机 × 环境抽象"的乘积,作者在 p.17 也提到 shield"对复杂抽象与规约可能很大"(`"Shields can be relatively large—especially for complex abstractions and specifications"`)。水箱这种规模乘积博弈已 602 状态;面对高维/长时序规约,博弈求解与 shield 表示的组合爆炸如何应对,论文未深入(仅指出某些单状态规约下可化简)。
5. **对本研究主题(RL 通用工具箱 / 安全增强)的契合与不足**(总结者注):shielding 提供了一个非常干净的"硬安全约束在学习期即生效且不破坏收敛"的范式,很适合作为交互 agent 的安全护栏思路。但它要求安全约束能被写成时序逻辑、且环境能被离散抽象——对涉及人机交互、语义层面"得体/安全"的软约束,本文方法并不直接适用,需要先解决"如何把这类约束形式化并抽象"的问题。
