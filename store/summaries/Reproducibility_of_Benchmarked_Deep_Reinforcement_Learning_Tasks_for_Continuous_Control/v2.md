# Reproducibility of Benchmarked Deep Reinforcement Learning Tasks for Continuous Control
> Riashat Islam, Peter Henderson, Maziar Gomrokchi, Doina Precup · 2017 · arXiv (Cornell University) · 引用 187 · DOI 10.48550/arxiv.1708.04133

## 一句话
本文对连续控制中两个常用策略梯度基线 DDPG(off-policy)与 TRPO(on-policy)做了一次复现性实证研究,系统展示它们对超参数、随机种子与环境随机性的高度敏感,并据此给出"如何公平报告基线结果"的四条准则。

## 解决了什么问题
新方法常以 DDPG、TRPO 为基线作比较,但这两个算法本身方差大、对超参敏感,各家论文用的超参/度量又不一致,导致基线复现困难、比较不公平。作者要回答:这些算法到底有多敏感、敏感在哪些超参上、仅由随机种子能造成多大的结果差异,以及社区该怎么报告才能让比较可信。原文动机:"there are many sources of possible instability and variance that can lead to difficulties with reproducing deep policy gradient methods"(p.1)。

## 用什么方法解决的
在 OpenAI Gym + MuJoCo 的两个连续控制环境上,逐个超参做受控扫描("We evaluate the off-policy DDPG [1] and on-policy TRPO [2] algorithms…using the MuJoCo physics simulator [7]",p.2),用统计检验和学习曲线量化每个超参的影响,最后用随机种子实验暴露纯方差。

---

## 动机 & 背景
策略梯度法在连续控制上取得 SOTA,常分两类:off-policy 的 DDPG 与 on-policy 的 TRPO。但很少有工作真去复现这些基线,多数只是拿来当对照("there are few works which reproduce existing policy gradients methods…yet many use as these algorithms as baselines",p.1)。作者指出每篇引用工作都用了不同的实验超参做所谓的基线比较,用次优超参跑会导致比较失真,因此强调"报告结果时应保持谨慎一致"。

度量选择上,作者明确:Maximum Average Return 与 Maximum Return 两种"被认为高度有偏",而 Std 与 Average Return"被认为是最稳定的度量",所以"除非另有说明,本文余下只用 Average Return 作比较"(原文:"the first two measures are considered to be highly biased, while the last two are considered to be the most stable…we only use the Average Return as our comparison measure unless stated otherwise",p.2)。

## 方法细节
- **算法与实现**:TRPO 基于 rllab 的 Tensorflow 实现 [9],DDPG 基于 Q-Prop 的 Tensorflow 实现 [10](原文:"building upon the rllab Tensorflow implementation of TRPO [9] and the Q-Prop Tensorflow implementation of DDPG",p.2)——之所以选这两个实现,是因为它们被多篇工作直接拿来当对照。
- **环境**:Hopper(状态空间 R²⁰、动作 R³)与 Half-Cheetah(状态 R²⁰、动作 R⁶)(原文:"Hopper ( S ⊆ R 20 , A ⊆ R 3 ) and Half-Cheetah (S ⊆ R 20 , A ⊆ R 6 )",p.2)。
- **实验协议**:每个变体跑 5000 次迭代、结果在 5 次运行上取平均("We run all variations for 5000 iterations and average all results across 5 runs",p.2);每次只变一个待研究超参,其余固定为默认值。
- **扫描的超参**:batch size、策略网络结构、step size(TRPO)、正则系数(TRPO)、GAE λ(TRPO)、reward scale(DDPG)、actor-critic 学习率(DDPG)。
- **默认超参**:TRPO 用网络 (100,50,25) + ReLU 的高斯 MLP 策略、step size 0.01、正则系数 1·10⁻⁵、GAE λ=1.0;DDPG 用 (100,50,25) 网络、actor/critic 学习率 1·10⁻³ 与 1·10⁻⁴、batch size 64、reward scale 0.1(原文逐项列于 p.2)。
- **随机种子实验**:最后用整体最优超参组合跑 10 次随机种子试验,"考察结果差异是否仅由随机种子方差造成"(原文:"a final set of experiments using the overall best cross-section of hyper-parameters for 10 trials using random seeds",p.2)。

## 数据集 & 实验设置
两个 MuJoCo 任务(Hopper-v1、Half-Cheetah-v1),5 次平均、5000 迭代为基本单元;随机种子实验把 10 次试验随机分成两组各 5 次取平均再对比。显著性用双样本 t 检验报告(注:仅对部分超参报告了 t 检验,如网络结构、正则系数、GAE、step size、随机种子;DDPG 的 reward scale 与 actor-critic 学习率只给学习曲线、未见对应 t 检验)。代码开源(p.2 脚注5给出 GitHub 链接:github.com/Breakend/ReproducibilityInContinuousPolicyGradientMethods)。Table 1、Table 2 还在不同迭代数(500/1000/2500/5000)下列出 Average Return / Max Average Return / Std,以便与他人报告值对齐。

## 主要结果 & 结论
> 说明:下列结果多为"在某一/某些任务上观察到"的现象(observed),作者并未声称跨任务/跨算法的普遍规律。

**网络结构**:(400,300) 在 Half-Cheetah 上显著优于两个更小结构,在 Hopper 上优势较弱,且 TRPO、DDPG 都如此(原文:"the (400,300) architecture significantly outperforms both other smaller architectures for Half-Cheetah and to a less significant extent Hopper as well. This is true for both TRPO and DDPG",p.3)。t 检验佐证:TRPO Half-Cheetah 上 (400,300) 对 (64,64) t=-13.4165、p=0.0000,对 (100,50,25) t=-11.3368、p=0.0016;但 TRPO Hopper 上差异不显著(对 (100,50,25) t=-0.5904、p=0.2952)(p.3 脚注7)。值得注意:作者找到的最优结构 (400,300) 并不是 [10,12] 报告基线时用的结构——这正是"基线不可比"的一个具体例证。

**batch size**:DDPG 扫了 (32,64,128),原文的总体结论是"32 与 64 性能相近,128 能带来显著提升"("similar performance can be obtained with mini-batch sizes of 32 and 64, whereas significant improvements can be obtained with a batch size of 128",p.4);但作者随即用 Figure 4 把这一结论按环境拆开:**在 Hopper 上不同 batch size 结果相近,较大 batch 主要是在 Half-Cheetah 上改善性能**("the DDPG algorithm with different batch sizes produces similar results for the Hopper environment…while a larger batch size improves performance in Half-Cheetah",p.4)——故"128 显著提升"应理解为主要体现在 Half-Cheetah,不宜泛化为两任务皆然。TRPO 需要更大 batch,(1000,5000,25000) 中 25000 最好(p.4)。作者给出机制直觉:TRPO 用带 KL 约束的共轭梯度优化,小 batch 在高方差环境下步间梯度差异大、训练更不稳定。

**TRPO 三个专属超参**:① 正则系数(1e-5 到 .1)"未见显著差异"("We don't see a significant difference",p.4),仅在 Hopper 上影响略明显(RC=0.1 时 t=2.8965、p=0.1443);② 较低 GAE λ(.97)在更长序列上改善 Half-Cheetah、对 Hopper 改善轻微(p.5);③ step size 默认 0.01 对两环境总体最好(p.5)。

**DDPG 的 reward scale —— 与文献相反的发现**:尽管 [10][9] 报告最优 reward scale 为 0.1、且 DDPG 被认为对它高度敏感,本文却发现 DDPG 并不因 rescale 而改善;在 Half-Cheetah 上"不缩放(RS=1)反而得到高得多的回报"(原文:"DDPG does not improve by rescaling the rewards. In fact, for the Half-Cheetah environment…no reward scaling (RS=1) yields much higher returns, even though [10] and [9] have reported an optimal reward scale value to be 0.1",p.6)。这是全文最具反直觉、最能说明"复现性危机"的结果之一。

**actor-critic 学习率**:对 Hopper 的影响小于对 Half-Cheetah,提示 DDPG 除学习率外还有别的变化/随机性来源(p.6)。

**仅随机种子就能造成显著差异**:把相同超参、不同种子的 10 次运行随机分两组各 5 次平均,Half-Cheetah 上两条曲线"完全落不进同一分布"(t=-9.0916、p=0.0016),而 Hopper 上不显著(t=2.2243、p=0.1825)(p.7 + 脚注12)。这意味着光靠选种子就可能把基线报成"明显更差"或把自家方法报成"明显更好"。即便精调超参,DDPG 在两环境都拿不到稳定结果("stable results with DDPG, on either of the environments cannot be achieved",p.7)。

**跨环境不一致**:Half-Cheetah 比 Hopper 更易受超参调节影响;作者推测因环境随机性不同——Half-Cheetah 动力学更稳定、失败模式少,Hopper 易快速失败、引入更大外部方差(p.8)。

**汇总表的落差**:Table 1(TRPO)中本文 Half-Cheetah 5000 iters 的 Average Return 达 5010.83(Std 443.87)、Hopper 2421.067(Std 796.58),而 rllab[9] 报告 Half-Cheetah 仅 1914.0、Hopper 1183.3;Table 2(DDPG)中本文 Half-Cheetah 3725.3(Std 512.8)、Hopper 仅 857.6,而 QProp[10] 报告的 Max Average Return 高达 7490 —— 各家报告值差异极大,直观印证基线不可比(p.8–9)。

**结论与准则(作者明确强主张,strong)**:未来工作应:(1) 报告所有度量,尤其 Average Return 与回报标准差;(2) 报告所有用于优化的超参;(3) 尽量用接近最优的超参;(4) 在多于 5 次试验上平均,并报告平均了多少次(原文四条列于 p.8)。并建议社区提供带超参预设、覆盖广泛任务的精调实现,以消除基线的不公平比较(p.9)。

## 核心贡献
1. 对 DDPG、TRPO 在两个连续控制任务上做了系统的超参敏感性与方差实证,逐个超参给出学习曲线,并对其中部分超参补充了双样本 t 检验。
2. 揭示两类"复现陷阱":一是不同工作用不同超参/度量导致基线数值差异巨大(Table 1/2);二是仅改随机种子就能在 Half-Cheetah 上造出统计显著的曲线差异。
3. 给出一份可操作的报告准则(四条)与社区改进建议,意在作为新手判断"自己跑出的值是否合理"的参照起点。
4. 报告了与既有文献相反的发现(DDPG reward scale 在 Half-Cheetah 上不缩放反而更好),直接质疑了被广泛沿用的超参设定。

## 局限与我的质疑
1. **实验规模极小,外推性存疑(我的批判)**:只测了 2 个环境(Hopper、Half-Cheetah)、2 个算法、每配置 5 次平均、5000 迭代。作者自己也承认"需要进一步确定多少次试验 N 才能保证公平比较"(p.8 脚注13)。绝大多数结论被作者审慎地限定为"在某任务上观察到",但读者很容易把"Half-Cheetah 上 (400,300) 更好""128 batch 更好"误读成普适规律——实际上 Hopper 上这些差异多不显著,跨环境结论明显不一致。
2. **统计显著性的标准偏松(我的批判)**:多处被称为"more significant effect""mildly improves"的差异其实 p 值远大于 0.05(如 RC Hopper p=0.1443、GAE Half-Cheetah 末段 p=0.0652、随机种子 Hopper p=0.1825),严格说并不显著。把这些当作"影响"来叙述,与本文倡导的"严谨报告"精神略有张力。
3. **DDPG 调不好可能是实现/调参问题,而非算法固有(我的质疑)**:作者多次说 DDPG"无论怎么调都不稳定、复现不出他人结果",但全程用的是单一实现(Q-Prop 版)、有限的超参网格,且未做更系统的搜索。"算法本身高方差"与"这份实现没调好"两种解释,本文证据尚不足以区分——这恰恰也是它批评他人的那类问题。
4. **方法学浅、无新算法(作者自述性质)**:这是复现性/经验研究,贡献在"诊断"而非"解法";它指出了问题(基线乱、方差大),但没给出量化的、可落地的标准(例如到底该平均多少次 N、怎样的种子协议),(4) 准则更多是定性号召。
5. **与本研究主题(训练可交互数字人/通用 RL 工具箱)的关联是间接的(总结者注)**:它不提供新的 RL 训练方法或工具,但其"必须多种子多次平均、完整报告超参与方差、警惕 reward scale 等外部超参"的准则,对任何要在 MuJoCo 类连续控制上做可信实验/搭基线的人都有直接的工程指导价值。
6. **时效性(总结者注)**:2017 年的工作,只覆盖 DDPG/TRPO 与早期实现;更现代的 SAC/PPO/TD3 及其稳定化技巧未在范围内,结论(尤其 DDPG 极不稳定)在今天的实现上未必同样成立。
