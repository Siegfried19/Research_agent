# Reproducibility of Benchmarked Deep Reinforcement Learning Tasks for Continuous Control
> Riashat Islam, Peter Henderson, Maziar Gomrokchi, Doina Precup · 2017 · arXiv (Cornell University) · 引用 187 · DOI 10.48550/arxiv.1708.04133

## 一句话
一篇实证研究：把连续控制里被当作"基线"的两个主流策略梯度算法（TRPO 与 DDPG）拿来系统复现，证明它们对超参数、随机种子和环境本身高度敏感，复现极难，并给出一套"该报告什么"的实操准则。

## 解决了什么问题
深度强化学习论文普遍拿 DDPG / TRPO 当基线来比较自己的新方法，但各篇报告的基线数字差异巨大、超参常常不写全，导致基线比较不公平、结果难以复现。作者要回答：这些差异到底来自哪里（超参？随机种子？环境随机性？），以及社区应该如何规范化报告才能让比较可信。

## 用什么方法解决的
在 OpenAI Gym + MuJoCo 的两个连续控制任务（Hopper-v1、Half-Cheetah-v1）上，用既有公开实现（rllab 的 TRPO、Q-Prop 的 DDPG，都是被多篇论文直接当基线引用的代码）跑受控实验：每次只动一个超参、其余固定在默认值，扫常用取值范围；考察的超参包括两算法共有的（网络结构、batch size）、TRPO 专有的（step size、正则系数、GAE λ）、DDPG 专有的（reward scale、actor/critic 学习率）。每组配置跑 5000 次迭代、5 次平均；最后用"最佳超参横截面"跑 10 次不同随机种子，随机分成两组各 5 次取平均做两样本 t 检验，看仅靠换种子能否制造统计显著的不同学习曲线。性能度量主张以 Average Return + 标准差为准，弃用易被异常值抬高的 Maximum Return / Max Average Return。

## 动机 & 背景
- 无模型策略梯度（on-policy 的 TRPO、off-policy 的 DDPG）已成连续控制/机器人控制的 SOTA，被大量后续工作当基线。
- 但同一基线在不同论文里报出的数字差很多（见论文 Table 1、2），原因常是超参没报全、各家用不同超参、调参不充分。
- 此前几乎没有专门复现这些策略梯度方法的工作，作者要填这个空白并给社区立规矩。

## 方法细节
- **共有超参**：网络结构对比 (64,64)/(400,300)/(100,50,25)；batch size——DDPG 试 32/64/128，TRPO 试 1000/5000/25000。
- **TRPO 专有**：正则系数（共轭梯度阻尼）1e-5~0.1；GAE λ 取 1.0 与 0.97；step size（即 KL 约束界，等价学习率）默认 0.01。
- **DDPG 专有**：reward scale（默认 0.1）；actor/critic 学习率（1e-3 / 1e-4）。
- **默认配置**：网络 (100,50,25) ReLU 高斯 MLP 策略；TRPO step size 0.01、正则 1e-5、GAE λ=1.0；DDPG actor/critic 1e-3/1e-4、batch 64、reward scale 0.1。
- 统计上用两样本 t 检验报告各超参与默认值的差异显著性。

## 数据集 & 实验设置
- 环境：Hopper-v1（S⊆R²⁰, A⊆R³）、Half-Cheetah-v1（S⊆R²⁰, A⊆R⁶），MuJoCo 物理引擎，OpenAI Gym 基准。
- 算法/代码：TRPO 用 rllab 实现，DDPG 用 Q-Prop 实现（均为他人被广泛引用的基线代码）。
- 训练规模：5000 迭代、每配置 5 次平均；最终对比实验扩展到 10 次种子。
- 代码已开源（github.com/Breakend/ReproducibilityInContinuousPolicyGradientMethods）。

## 主要结果 & 结论
- **网络结构**：Half-Cheetah 上 (400,300) 显著优于更小的网络（TRPO/DDPG 都是，t 检验显著）；但这个最优结构并非被引用论文用来报基线的那个。Hopper 上结构影响不显著。
- **batch size**：DDPG 32/64 接近，128 明显更好（Half-Cheetah）；TRPO 越大越好，25000 最优，小 batch 早早收敛到更低平台。Hopper 上 DDPG 各 batch 差不多。
- **TRPO 正则系数**：整体无显著差异，对 Hopper 影响略大。
- **GAE λ**：较低的 λ=0.97 在长序列上（尤其 Half-Cheetah）改善结果。
- **TRPO step size**：默认 0.01 最稳。
- **DDPG reward scale**：与文献声称"0.1 最优、DDPG 对其极敏感"相反，作者发现 Half-Cheetah 上不缩放（RS=1）回报反而高得多——复现不出来。
- **DDPG 学习率**：对 Half-Cheetah 影响大于 Hopper，且即便固定其它参数 DDPG 仍有其它来源的方差。
- **随机种子方差（核心发现）**：仅靠不同随机种子、把 10 次跑随机分两组各取 5 次平均，就能得到统计显著不同、甚至不在同一分布的学习曲线（Half-Cheetah t=-9.09, p=0.0016）。DDPG 即便调好超参也无法稳定复现。
- **环境差异**：Half-Cheetah 对超参更敏感但动力学更稳；Hopper 易快速失败、外部方差大、难调。
- **给社区的报告准则**：(1) 报告全部度量，尤其 Average Return 与标准差；(2) 报告所有优化超参；(3) 尽量用接近最优的超参；(4) 平均 >5 次试验并写明平均了几次、每次用不同种子。还呼吁社区提供带预设超参的精调基线实现。

## 核心贡献
- 实证量化了 TRPO/DDPG 在连续控制上对超参、随机种子、环境随机性的脆弱性，揭穿"基线数字可直接横向比较"的假象。
- 指出 Maximum/Max Average Return 作为度量有偏，主张以 Average Return + 标准差报告。
- 给出可操作的复现/报告准则（4 条），并提供开源代码与一张"Hopper/Half-Cheetah 合理基线区间"参照表，供新手判断自己跑出的数字是否正常。
- 是后续 Henderson 等《Deep RL that Matters》那条"RL 可复现性危机"研究线的早期工作之一。

## 局限与我的质疑
1. **作者自述局限**：只测了 2 个环境（Hopper、Half-Cheetah）、2 个算法（TRPO、DDPG），每配置仅 5 次平均、单超参逐一扫描（one-at-a-time，没做超参交互/联合搜索）。作者也承认"到底需要平均多少次 N 才能保证公平比较"尚未解决，只是抛出问题。
2. **统计严谨性存疑**：核心结论建立在两样本 t 检验上，但 Hopper 上很多对比 p 值并不显著（如种子方差 Hopper p=0.18），真正显著的几乎只有 Half-Cheetah，结论的普适性其实被单一环境撑着；而且对回报曲线这种高度自相关、非独立同分布的样本做 t 检验本身就不太站得住，"统计显著"的解读要打折扣。文中还有明显笔误（如"Maximum Return unavenged"），打磨程度偏低（这是 7 页 workshop 风格短文，未见正式会议发表）。
3. **"最优超参"的循环论证**：最终对比和种子方差实验用的是"我们找到的最佳横截面"，但既然单超参扫描没覆盖交互、又自承调参困难，这个"最佳"本身可能不是真最优，拿它去声称"种子也能造出显著差异"时，无法排除是次优配置放大了方差。
4. **结论易被过度解读**："换种子就能造出更好/更差的结果"常被引申为"策略梯度都不可信"，但作者实际只证明了在特定代码、特定环境下存在这种可能性，并未给出方差的根因分析（reward scale 反例也只是观察、没解释机制）。
5. **与"RL 训练数字人与环境交互"主题的差距**：本文环境是低维 MuJoCo 刚体运动控制（Hopper/HalfCheetah，状态≤20维），与数字人/人机交互所需的高维多模态观测、拟人化动作、人在环路的奖励设计相去甚远；它对本主题的价值是**方法论警示**（你训练交互数字人时同样必须多种子、报方差、写全超参，否则别人复现不了你的交互策略），而非提供任何数字人建模或交互技术。结论的算法（2015–2016 年的 TRPO/DDPG）也已被 PPO/SAC 等取代，具体数值参照表对今天意义有限。
