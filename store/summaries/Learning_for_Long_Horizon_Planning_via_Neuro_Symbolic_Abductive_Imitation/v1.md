# Learning for Long-Horizon Planning via Neuro-Symbolic Abductive Imitation
> Jie-Jing Shao, Hao-Ran Hao, Xiao-Wen Yang · 2024 · arXiv · 引用 0 · DOI arxiv:2411.18201

## 一句话
把"溯因学习(abductive learning)"引入模仿学习,用专家给的符号知识库(有限状态机)反推每帧观测对应的符号谓词标签,从而无需逐帧谓词标注就能把高维观测落地(grounding)到符号空间,再用符号推理调度一组行为策略,显著提升长程规划任务的数据效率与泛化能力。

## 解决了什么问题
纯模仿学习(BC、Decision Transformer)在**长程(long-horizon)任务**里会因协变量偏移(covariate shift)误差累积而崩;传统符号规划泛化好但依赖人工把观测映射到符号状态(需要昂贵的谓词级标注),且现有神经符号方法要么需大量符号标注、要么依赖预先存在的"完美底层控制器",要么(如 PDSketch 的 model-based 规划)在长序列里搜索误差累积。本文要在**既不需要逐帧谓词标注、也不需要预置完美控制器**的前提下,实现稳健的长程模仿规划。

## 用什么方法解决的
提出 **ABductive Imitation Learning (ABIL)**,分两阶段:
1. **溯因推理学感知**:专家提供把任务拆成子任务的符号知识库(有向图状态机,节点=子任务条件的 ground atoms,边=带增删效果的符号操作 op)。在没有符号监督的情况下,用知识库约束反推(abduce)出每帧观测应满足的符号标签作为伪标签,据此优化对象级谓词感知网络 f。核心是"**序列一致性(sequential consistency)**"原则——按状态机结构(单节点/先后/或/与)把整条专家轨迹切成满足知识库的符号序列,以此解决感知与推理的冲突。
2. **符号落地的模仿(policy ensemble)**:为每个逻辑操作符(如 h_clean、h_put)建一个行为策略,用感知输出的符号状态匹配符号规划解 {(v_k, op_k)},决定当前该执行哪个操作及其对象参数,再用模仿学习训练这些行为网络。这样模仿直接从演示学具体行为(不依赖预置控制器),而调度由符号推理负责,从而获得符号规划的泛化性 + 学习方法的推理效率。

## 动机 & 背景
- 目标:造能在开放、新环境里完成多样长程任务(做饭、组装家具、家务整理)的通用智能体,本质是序列决策/规划问题。
- 两条路线各有短板:模仿学习数据驱动、推理快但理论上随决策步数增长泛化退化(协变量偏移);符号规划泛化强但默认已有 ground-truth 符号,无法直接处理高维视觉等观测。
- 已有神经符号工作(Regression Planning Network、Konidaris 的 skills→symbols、Silver 的 operator learning、PDSketch)大多依赖充足符号标注或完美底层控制器;最相关的 PDSketch 用神经网络做谓词/动作效果模块并学转移模型,但 model-based 规划在原始观测-动作空间累积误差,不适合长序列,且其逻辑推理用得有限、需大量数据。
- 本文借鉴溯因学习(Zhou 等),把中间神经符号 grounding 同时当作"学习的伪标签"和"推理的变量",并首次把溯因学习从传统分类扩展到长程序列决策。

## 方法细节
- **问题形式化**:goal-based planning,环境为 ⟨S, A, T, O, P, OP, S0, g⟩,确定性转移、完全可观。对象级谓词 p(o1,o2) 由二分类器 f_p([o1,o2]) 推断(对象特征来自外部检测模块)。
- **知识库 = 有限状态机有向图** G=⟨V,E⟩:节点含子任务条件的 ground atoms,边 = ⟨op, EFF+, EFF−⟩,v=(u−EFF−)∪EFF+。四种基本结构:仅 v1 / v1 先于 v2 / v1 或 v2 / v1 与 v2(任意序)。可用 A* 或动态规划求符号规划解。
- **溯因目标(Eq.1)**:在"伪标签序列满足知识库 {z_t}⊨G"的约束下,最小化感知输出与伪标签的差异。序列溯因规则把整条轨迹按四种结构切分(终态满足 g;a 先于 b 则前段满足 a 后段满足 b;等)。
- **训练流程(Algorithm 1)**:先 N_R 轮溯因学感知 f(感知→溯因伪标签→更新 f),再 N_I 轮符号落地模仿(f 出符号态→匹配 op→训练行为网络 h_op)。
- **行为集成**:类比"人先意识到目标再行动",把高层逻辑推理嵌入模仿;行为网络从经验学,不依赖预置完美控制器。
- 骨干统一用 Neural Logic Machine(NLM)两层编码,保证与基线公平比较;ABIL-BC/ABIL-DT 分别用 BC/DT 实现行为模块。

## 数据集 & 实验设置
- 三个环境:**BabyAI**(网格指令跟随,5 任务 goto/pickup/open/put/unlock,4→8 物体/门做泛化)、**Mini-BEHAVIOR**(3D 家务,任务长达 ~100+ 步,加未见干扰物做泛化)、**CLIPort**(3D 机器人操作,连续动作,未见颜色/形状)。
- 基线:Behavior Cloning、Decision Transformer、PDSketch(选 full 模式给足符号转移先验);全部用同一 NLM 架构。
- 指标:成功率@100(100 次评测、3 个随机种子平均)。BabyAI 每任务 1000 条演示;Mini-BEHAVIOR 1000 或 3000 条;CLIPort 每任务 1000 条(均为脚本/oracle 生成的成功轨迹)。

## 主要结果 & 结论
- **BabyAI**:ABIL 在长程 Put(9 步)/Unlock(10 步)的泛化设置上大幅超过基线;PDSketch 在长程任务崩(Unlock 仅 ~0.25–0.29),DT 在短程任务弱于 BC。ABIL 推理时间(0.32–0.35s)远低于 PDSketch 的 8.17s。
- **神经符号 grounding 精度**:ABIL 在所有任务近乎完美谓词精度,且 <PDSketch 20% 的数据量即超越;PDSketch 在 open/unlock 上 grounding 差。
- **Mini-BEHAVIOR**:PDSketch 在大多数长程任务超时(>5 分钟)无法完成;ABIL-BC/DT 在 basic 和泛化两栏普遍最佳,尤其泛化栏对基线优势随 horizon 增长被放大。
- **CLIPort**:packing-20shapes 上纯学习 BC/DT 仅 ~20%,ABIL-BC 达 94%;Assembling-kits 从 ~0.18 提到 ~0.82。
- **零样本组合泛化**:训练 pickup+open 后零样本做 unlock,ABIL 接近满分而基线垮;Throwing/Opening 从 1 个推广到 2/3 个也大幅领先。
- **鲁棒性**:即便 grounding 精度降到 75%,ABIL 仍优于纯数据驱动方法(对符号误差有容忍度)。
- 结论:ABIL 用溯因推理自动从知识库生成谓词候选实现 grounding,无需大量人工标注,显著提升长程任务的数据效率与泛化,是有前景的神经符号模仿方案。

## 核心贡献
1. 首次把溯因学习扩展到长程序列决策/规划(以往溯因学习多做分类),提出 ABIL 框架统一数据驱动学习与符号推理。
2. 设计"序列一致性"溯因规则,在**无逐帧谓词标注**下从专家轨迹反推符号伪标签,实现数据高效的神经符号 grounding。
3. 用符号推理调度的"行为策略集成"取代对预置完美底层控制器的依赖,行为直接从演示模仿学习。
4. 在 BabyAI / Mini-BEHAVIOR / CLIPort 三类基准上验证了数据效率、泛化、零样本组合泛化与推理效率优势,并开源代码。

## 局限与我的质疑
1. **作者自述:确定性+完全可观假设**。框架假设环境确定、状态完全可观,真实世界随机且部分可观;作者把 POMDP 留作未来工作。这对"与环境实时交互"的具身场景是硬伤——观测噪声/遮挡下溯因约束可能矛盾无解。
2. **作者自述:重度依赖人工知识库**。ABIL 需要专家事先给出准确、充分的符号状态机(论文附录里每个任务都手工画了完整有向图)。这等于把"长程规划"的难点搬到了"人工设计知识库"上——可扩展性存疑,任务一多/一变就要重画图,所谓"免标注"只是免了**谓词帧标注**,没免**结构化领域知识**。
3. **不是 RL,是模仿学习,且演示来自脚本/oracle**。所有专家演示由 A* 搜索脚本或 oracle 策略生成、且只含成功轨迹。这意味着方法没真正"探索"、没处理失败恢复,本质是在干净监督信号上做监督式行为克隆 + 符号调度。与本研究主题"**用 RL 训练能与环境交互的数字人**"相比,差距很大:没有奖励、没有 online 交互、没有真实物理/人机交互,只是离散网格/抽象操作基准里的规划。
4. **谓词感知依赖外部检测模块**。对象级特征"可由目标检测模型获得"被当作给定,grounding 只学谓词分类器,绕开了真实感知里最脏的检测/分割误差;Table 6 虽测了 grounding 降到 50–75% 的鲁棒性,但那是人为注入,不等于真实检测器的错误分布。
5. **基准偏简单、与数字人/全身交互无关**。最长 task ~106 步但动作空间高度抽象(pick/place/clean/put 等离散符号操作),没有连续全身控制、接触动力学、人体动作模仿这些"数字人交互"真正难的部分。CLIPort 虽连续但只是双姿态 pick-place。结论"promising solution for long-horizon planning"在这些封闭基准成立,外推到开放真实交互被过度乐观解读。
6. **与最相关基线 PDSketch 的比较可能不完全对等**。PDSketch 是 model-based 规划、在原始动作空间搜索,长程超时几乎是其设计必然;把它当主要对手,容易凸显 ABIL 优势,但缺少与更强的分层 RL / 分层模仿 / 近期 LLM-as-planner 方法的对比,横向充分性不足。
