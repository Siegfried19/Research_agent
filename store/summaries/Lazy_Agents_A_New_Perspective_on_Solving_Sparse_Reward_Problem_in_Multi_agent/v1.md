# Lazy Agents: A New Perspective on Solving Sparse Reward Problem in Multi-agent Reinforcement Learning
> Bo Liu, Z. Pu, Yi Pan, Jianqiang Yi, Yanyan Liang, Du Zhang · 2023 · International Conference on Machine Learning · 引用 36 · DOI title:4767e85b9c83c66b

## 一句话
把多智能体强化学习(MARL)稀疏奖励下学不出协作的根因归结为"懒惰智能体"(躲在地图边缘不参与团队、只求活到结束),并用因果推断给"懒惰"下严格定义、再用两种内在奖励(IDI/CDI)逼每个智能体和整队对"外部状态"产生因果影响,从而在 SMAC、GRF 的稀疏奖励版本上取得 SOTA。

## 解决了什么问题
稀疏奖励(只在赢/输/进球时给信号)下,MARL 容易陷入局部最优:部分智能体学会"摸鱼"——不主动攻击/不参与配合,只靠躲避求生存。作者指出这会同时损害**探索**(只探索了自己那部分状态空间,敌方状态空间没被充分探索)和**协作**(协调进攻打不出来),最终导致整队任务失败。本文要从"避免懒惰智能体"这一新角度系统性地解决该问题。

## 用什么方法解决的
提出 LAIES(Lazy Agents Avoidance through Influencing External States)框架:
1. 把全局状态拆成**内部状态**(与智能体自身直接相关,如位置)和**外部状态**(智能体能影响但非自身的,如敌人位置/血量、球的位置)。
2. 画出智能体—环境交互的**因果图**,辨别出 3 类懒惰智能体(代表性的第三类:外部状态影响了它的动作,但它的动作不影响外部状态)与勤奋智能体。
3. 用 **do-calculus(反事实推断)** 计算"动作对下一步外部状态的因果效应",据此定义个体勤奋度 IDD(单个动作 τ)与协作勤奋度 CDD(联合动作 τ),并据此严格定义"完全懒惰智能体/完全懒惰团队"(整个 episode 内对外部状态零影响)。
4. 训练一个**外部状态转移模型 ESTM**(GRU 捕历史 + 线性网络,输入状态和联合动作预测下一外部状态),用它做反事实:把实际动作换成其它候选动作算反事实结果,以 MSE 度量因果效应。
5. 把 IDD/CDD 转成两种内在奖励——**IDI**(逼每个体影响外部状态)和 **CDI**(逼整队联合动作影响外部状态),按 r_I = β1·r_IDI + β2·r_CDI 注入,叠在 QMIX 上端到端训练。

## 动机 & 背景
CTDE(集中训练、分散执行)是合作 MARL 主流范式,QMIX 等价值分解法在稠密、精心设计的辅助奖励下表现优异。但现实任务里稀疏奖励才是常态,且设计好的奖励函数本身极难(尤其对非专家)。作者用 SMAC 的 3m 任务(3 红 Marine 打 3 蓝 Marine,赢+1/平 0/输 -1)做诊断:QMIX 在稀疏奖励下收敛到"消极生存"局部最优,至少一个智能体躲到地图边缘当"逃避者"。原因在于奖励结构本身——胜率低于 50% 时,主动进攻拿到的回报反而比消极逃避更低,于是结构性地鼓励了懒惰。已有解法(增强探索如 MAVEN/CMAE、鼓励影响力行为、子目标如 HDMARL/MASER)各有局限:只强调探索而不问"哪些状态值得探索";影响力法可能催生不利于整体目标的小团体;子目标法靠领域知识难迁移或自动生成质量不足。

## 方法细节
- **因果效应推导**:s^e_{t+1} 有四个父节点(a^j_t、历史 h_t、其他智能体联合动作 a^{~j}_t、s_t),都直接导致外部状态,既有因果也有非因果关联。通过 do-operator 抽出 a^j_t 对 s^e_{t+1} 的纯因果效应,τ 用 KL 散度表示"采取该动作 vs 不采取"两个分布的差异。
- **实践简化**:给定 s_t、h_t、联合动作后状态转移是确定的(单点分布),故把 KL 散度替换为外部状态的 **MSE 损失**。反事实项 Y(A^j_t ≠ a^j_t) 用枚举该智能体所有其它可用动作、取反事实结果均值近似。
- **CDI 的组合爆炸**:联合动作的反事实组合随智能体数指数增长,实践中**随机采样若干联合动作**估均值。
- **ESTM**:训练阶段(CTDE)整条 episode 全局状态可得,用来训练并查询转移模型。
- **整体目标**:QMIX 的 TD 损失,目标值 y = r^E(外部奖励) + r^I(内在奖励) + γ·max Q。内在奖励在平均奖励超过 0 后退火。

## 数据集 & 实验设置
- 基准:**SMAC**(9 张图:3m、2m_vs_1z、MMM、1c3s5z、3s_vs_3z、5m_vs_6m、8m_vs_9m、MMM2、6h_vs_8z,含 easy/hard/super hard)和 **GRF**(4 个 academy 任务:2vs2、3vs2、3vs3、counterattack)。除 QMIX-DR 外一律用**稀疏奖励**设置。
- 基线:SMAC 上对比 CMAE、MAVEN、MASER、QMIX、RODE,并加 QMIX-DR(稠密奖励版)做参照;GRF 上对比 QMIX、QPLEX、CDS、MAVEN。
- 评估:SMAC 五/六个随机种子(正文 6 个种子),指标为测试胜率。
- 实现:基于 pymarl2 框架,LAIES 与 QMIX 除新增超参外其余参数一致;β1/β2 逐任务调(如多数 SMAC 图 {100,0.2}、GRF 全用 {1,8});单卡 RTX 3090。CMAE 因未公开 SMAC 代码,用其论文最高分代表。

## 主要结果 & 结论
- **SMAC**:LAIES 在所有图(易/难/超难)上超越各 SOTA;QMIX/RODE/MAVEN 在稠密奖励下强但稀疏下普遍崩;MASER 在中等稀疏尚可、极稀疏失效。值得注意的是 LAIES(稀疏)在 MMM、3s_vs_3z、5m_vs_6m、8m_vs_9m 四个图上甚至**优于享受稠密奖励的 QMIX-DR**;这四图共性是敌我实力差距小——作者论点是实力悬殊时更易出现懒惰,而 SMAC 的塑形奖励是基于特征、不归因到具体智能体,留下了摸鱼空间。
- **GRF**:更强调团队配合,LAIES 在 4 个任务收敛速度和最终胜率均领先,方差更低;3vs2 最终胜率 40%+。
- **消融**:去掉 IDI 或 CDI 都显著掉点。SMAC 上 IDI 更关键(需每个体都去打敌人),GRF 上 CDI 更主导(外部状态变化是整体性的,需联合影响)。
- **度量有效性验证**(5m_vs_6m):QMIX 学不出时 IDD 持续下降趋近 0、奖励维持 0;QMIX-DR 能完成任务时 IDD 随胜率上升而升高。CDD 趋势类似。说明 IDD/CDD 确实能反映智能体/团队的勤奋程度。
- **结论**:从"懒惰智能体"视角切入稀疏奖励有效;因果图 + 两种内在奖励能避免懒惰、提升整体表现。附录 B.1 还把 LAIES 接到策略梯度法 IPPO 上(3m、2m_vs_1z、MMM、1c3s5z),同样优于 IPPO/IPPO-DR,证明不限于价值法。

## 核心贡献
1. 提出"懒惰智能体"这一看待 MARL 稀疏奖励问题的新视角,并实证它如何从探索和利用两方面损害学习。
2. 用因果图 + do-calculus 给懒惰智能体/团队下了**可计算的数学定义**(IDD/CDD,完全懒惰=对外部状态零影响)。
3. 设计 IDI 与 CDI 两种基于反事实推断的内在奖励,以及配套的外部状态转移模型 ESTM。
4. 在 SMAC、GRF 稀疏奖励版上取得 SOTA,并验证可与价值法(QMIX)和策略梯度法(IPPO)结合;代码开源。

## 局限与我的质疑
- **作者自述局限①——内/外部状态划分依赖任务结构**:在有对手的竞技场景里外部状态可直接取为对手状态,但无对手的任务里外部状态的选取需要领域知识,削弱了"通用框架"的卖点。
- **作者自述局限②——"懒惰"定义太窄**:本文只用"是否影响外部状态"定义懒惰,但懒惰未必体现于此。作者自己举例 MMM 里 Medivac(医疗兵)的懒惰体现在不影响**友方**状态,而非外部状态——说明定义没覆盖支援/辅助型角色。
- **我的质疑①——反事实近似的可靠性存疑**:整套因果效应都建立在 ESTM 这个学出来的转移模型上,且把 KL 散度直接替换成 MSE、用枚举/随机采样动作算反事实均值。ESTM 自身的预测误差会直接污染内在奖励信号,论文几乎没分析 ESTM 的预测精度、误差如何传播,也没做"用真模型 vs 学出模型"的对照,内在奖励的正确性缺乏直接验证。
- **我的质疑②——超参极度敏感、调参成本被低估**:β1/β2 跨任务差异巨大(从 {20,0.02} 到 {600,0.3},GRF 又是 {1,8}),且明说"逐任务搜索最佳超参"。这意味着所谓 SOTA 很可能吃了大量针对性调参红利,而基线是否同等精调存疑;"超越稠密奖励 QMIX-DR"的结论在这种调参不对称下要打折扣。
- **我的质疑③——CDI 的可扩展性只是口头解决**:联合动作反事实随智能体数指数爆炸,作者用"随机采样几个联合动作"绕过,但没给采样数对性能/方差的影响分析;在大规模团队(远超 SMAC 十来个单位)下这个近似是否还成立没有证据。
- **我的质疑④——与本研究主题("RL 训练数字人与环境交互")契合度有限**:本文是合作博弈式多智能体设定(SMAC/GRF 的对抗团队),核心是"让每个 agent 对外部状态有因果影响"。其"外部状态影响"思想与"数字人主动与环境/物体交互、避免被动站桩"在动机上确有共鸣(都反对消极不作为),ESTM+反事实的内在奖励也可迁移到单体交互任务。但它面向的是离散动作、价值分解、团队信用分配,与单策略训练一个连续控制、富交互的数字人目标偏离:没有连续动作空间实验、没有具身/物理交互、没有人类交互维度,迁移到数字人场景需要大量改造,直接借鉴价值主要在"用因果效应度量交互充分性"这一指标思想上。
