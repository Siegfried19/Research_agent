# HAFO: A Force-Adaptive Control Framework for Humanoid Robots in Intense Interaction Environments
> Chenhui Dong, Haozhe Xu, Wenhao Feng, Zhipeng Wang, Yanmin Zhou, Yifei Zhao, Bin He · 2025 · Control Engineering Practice · 引用 1 · DOI 10.48550/arxiv.2511.20275

## 一句话
HAFO 用一套"上半身/下半身解耦的双 agent 强化学习"策略，配合把外部拉力显式建模成虚拟弹簧-阻尼系统的训练机制，让人形机器人在重载、推力扰动、绳索悬吊等强力交互场景下用单一策略保持全身稳定与精确运动跟踪。

## 解决了什么问题
现有 RL 全身控制器在强外力交互（重载操作、高空绳索作业、剧烈碰撞）下往往不稳定：它们大多依赖速度/高度/预定义轨迹这类高层指令，对接触动力学缺乏显式建模，遇到人为干预或显著环境接触时容易失衡。同时两类主流范式各有短板——"下半身RL+上半身IK"对上半身是开环控制，无法实时感知外力；"整体全身RL"用单一控制器管全身关节，但上下身任务目标耦合弱、易过拟合。HAFO 想在一个策略里同时拿到鲁棒移动 + 精确上肢操作 + 力自适应。

## 用什么方法解决的
- **双 agent RL 框架**：把全身自由度拆成上半身策略 π_upper 和下半身策略 π_lower，二者共享同一全身状态空间、都用 PPO 训练，建模成双目标优化问题，实现上下身协同进化。下半身以根部线/角速度为指令、专注鲁棒移动；上半身以参考关节轨迹为指令、专注精确操作。
- **受约束的残差动作空间**：上半身策略不直接学绝对关节目标，而是在采样的参考轨迹关节位置上输出一个有界修正量 aᵘ（|aᵘ|≤Δ），防止双 agent 对抗式交互导致训练崩溃，提升稳定性与样本效率。上半身参考动作来自 AMASS 人体动作数据集（经 PHC 重定向 + 抖动/不连续过滤）。
- **虚拟弹簧-阻尼系统建模外力**：用 mẍ = Kp(x_des−x) + Kd(ẋ_des−ẋ) + f_ext 把外部拉力显式建模成等效弹簧-阻尼力纳入训练回路，通过调节虚拟弹簧的 x_des 实现细粒度张力控制；对比实验显示纯刚度控制会明显振荡，阻尼项对稳定/精度关键。
- **课程学习 + 域随机化**：渐进增大弹簧-阻尼力、随机化施力点/周期/释放时机；下半身训练中引入对抗性上半身扰动 + 高频随机推力。策略由此自主演化出地面移动/空中悬吊两种力自适应模式，并能根据环境反馈自发切换，不依赖显式状态机或预定义切换逻辑。
- **非对称 Actor-Critic**：Critic 可访问特权信息（基座线速度、外力值），给 Actor 更准的价值估计。在 Isaac Gym 训练、MuJoCo 里 zero-shot 跨平台验证，并部署到实体 Unitree G1，另扩展到全尺寸 H1-2。

## 动机 & 背景
学习型全身控制近年靠大规模并行仿真 + 域随机化实现了 sim2real 零样本迁移，但普遍忽略或简化了交互力。面向重载操作、高空作业等真实需求，强外力扰动下的精确鲁棒控制仍是难题。绳索支撑会干扰稳定，大载荷会损害平衡。已有力自适应研究稀少：操作领域常用混合位置/力控制，但人形机器人交互点不确定、力传感器难测；Portela 等给四足做的力控需在位置/力模式间显式切换并假设准静态；多数模型法依赖预规划力轨迹、泛化差；估计法只适用准静态。人形机器人重心高、支撑面小，使力自适应尤其复杂。HAFO 主打"单一双 agent 策略覆盖重载/推力/张力多场景"。

## 方法细节
状态空间上下身相同（全身状态集），动作空间维度对应各自 DOF（G1 下半身 15、上半身 14、整体 29）。奖励函数在 OmniH2O/FALCON/Expressive 等基础上做了针对力自适应的增删（如 Torso Orientation、Feet Parallel、按弹簧力是否为零切换的 Base Height / Stand Still / 速度跟踪项等，见附录 B）。PPO 关键超参：γ=0.99、clip 0.2、Actor/Critic lr 0.001、MLP [512,256,128]。域随机化含地面摩擦 U(0.25,1.25)、基座质量 U(−1,3)kg、控制延迟 U(0,20)ms 等。上半身用渐进模仿课程 q_curr = q0 + αi(q_tar − q0)，αi∈[0,1] 由粗到细调节动作幅度。

## 数据集 & 实验设置
- **上半身参考动作**：AMASS 人体动作数据集，经可行性过滤后重定向到人形姿态。
- **仿真**：Isaac Gym 训练 → MuJoCo zero-shot 验证（跨平台以缓解单仿真器过拟合）。
- **三类力交互实验**：①手部外力（10N→50N 递增，同时随机速度指令 + AMASS 上肢动作）；②绳索悬吊（升降/作业/落地全过程）；③推力扰动（水平面 8 方向的持续恒力与 1 秒瞬态力，逐步加大至失稳）。
- **指标**：上半身运动跟踪误差 E_upper（rad）、速度跟踪误差 E_vel（m/s）、动作平滑度 Δa。
- **基线/消融**：upper-OL-lower-RL（上半身开环+下半身RL，如 Homie）、upper-FIX-lower-RL（上半身固定）、HAFO w.o. DA（去双 agent 只留下半身）、HAFO w.o. Force（去力自适应模块）。
- **实机**：Unitree G1 上做单手/双手负载（各 1kg）实验；另在仿真把策略扩展到 H1-2（1.78m / 70kg）。

## 主要结果 & 结论
- **手部扰动跟踪（表1）**：HAFO 全面最优，且力越大优势越明显。50N（L-Force）时 E_upper 仅 0.46 vs 基线 1.23、E_root 0.53 vs 1.52；upper-FIX 在 30N/50N 直接任务失败。
- **绳索悬吊（表2）**：HAFO 动作平滑度 Δa=0.38、E_upper=0.20，显著优于所有对比（基线 Δa 2.49~5.66）。论文称 HAFO 是**首个**能在绳索悬吊状态稳定运行并安全启动（悬吊启动）的移动控制策略。基线会把绳索正常摆动误判为机器人失稳、触发剧烈振荡。
- **推力扰动（图4）**：多数方向上 HAFO 对持续/瞬态推力的容忍度高于 w.o. Force 和基线。仿真展示可抵 250N 横/纵向 0.2s 推力后快速恢复平衡。
- **实机负载（表3）**：单手/双手负载下 HAFO 速度与上肢误差均最低（双手负载 E_upper 0.39、E_root 0.41）。还演示了扛沙袋、单手搬箱、被抬上高台后恢复行走、双手端花盆、悬吊擦窗、跳舞等。
- **扩展性**：H1-2 只需微调参数即在仿真稳定控制，验证泛化与可扩展性。
- 结论：单一双 agent 策略即可在重载/推力/张力多场景做力自适应全身控制。

## 核心贡献
1. 提出双 agent RL 框架驱动上下身协同进化（下半身保鲁棒移动、上半身保精确操作），并引入受约束残差动作空间提升双 agent 训练稳定性；在 G1 上实现并扩展到 H1-2。
2. 用弹簧-阻尼动力学模型把外部张力显式建模为等效弹簧-阻尼力纳入训练回路，配渐进课程学习，让策略自主演化出地面/空中两种力自适应模式并自发切换，无需显式状态机。
3. 实验证明单一策略覆盖重载、推力、绳索悬吊多场景；并声称是首个实现绳索悬吊稳定运行与安全启动的移动控制策略，为人形机器人高空作业做了探索性铺垫。

## 局限与我的质疑
1. **量化结果几乎全在仿真，实机证据偏弱**：最亮的卖点——绳索悬吊"悬吊启动/高空作业"——表2/表4的数字大多来自仿真，实机部分（图5g 擦窗、表4）缺少与基线的对照量化与统计，"only HAFO completed the final experiment"这类表述更像定性演示而非严格对比。负载实机实验也只到 1kg/手，远谈不上论文反复强调的"heavy load / intense interaction"。
2. **基线选择与公平性存疑**：把上半身完全开环（upper-OL）或固定（upper-FIX）当主要对手，本就是为凸显"上半身闭环"优势而设的弱基线；而真正同期的力自适应工作（如 FALCON [6]、THOR [37]、FACET [8]）只在相关工作里提到，没有任何直接的同台对比实验。所谓"首个绳索悬吊稳定"的 novelty 也缺乏对这些近邻方法的实证排除。
3. **"自主涌现模式切换"被过度解读**：论文称策略"自发"生成地面/悬吊模式切换、不依赖状态机，但奖励函数里大量用 I(‖F_spring‖)>0 / =0 这种"弹簧力是否为零"的指示函数显式切换奖励项（Base Height、Stand Still、速度跟踪等都按此开关）。这等于把模式信息硬编码进了奖励结构，"无需预定义切换逻辑"的说法名不副实——切换逻辑只是从动作空间挪到了奖励设计里。
4. **力建模与真实张力的差距未验证**：弹簧-阻尼是训练时施加的虚拟力，论文没有给出真实绳索/外力与该模型参数（Kp、Kd）的标定关系，也没量化"虚拟弹簧"假设与真实绳索动力学（非线性、松弛、冲击）的失配程度；图2 的优越性只是 spring-damper vs 纯 stiffness 的内部对比，并非对真实力的拟合精度。
5. **与"RL 训练数字人/机器人与环境交互"主题相比的不足**：HAFO 的"交互"主要是被动承受外力（负载、推力、绳拉）下保持稳定，本质是抗扰/平衡，而非主动的物体操作或场景交互（抓取、推拉、协作）。上半身仍是模仿 AMASS 参考轨迹 + 残差修正，没有任务级的操作目标或闭环操作反馈；力是"加在末端的随机 3D 力"而非具体物体接触。因此它更接近"力自适应 locomotion"，离真正意义上"与环境双向交互的数字人"还有距离。
6. **可复现性与统计严谨性**：未提供代码/模型，训练种子数、试验重复次数、显著性检验均缺失；表中 ± 是标准差但样本规模不明，"力越大优势越大"的趋势缺少误差带或显著性支撑。引用量仅 1，且发表渠道与同行评审状态（arXiv 预印本，标注 Control Engineering Practice）需谨慎看待结论强度。
