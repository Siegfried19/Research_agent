# Goal-conditioned Batch Reinforcement Learning for Rotation Invariant Locomotion
> Aditi Mavalankar · 2020 · arXiv · 引用 0 · DOI arxiv:2004.08356

## 一句话
把"只会朝一个方向走"的运动策略采集的数据,通过**旋转数据增强 + Siamese 等价编码器**,离线学成一个"能朝任意方向走"的目标条件(goal-conditioned)策略,在 Ant / Humanoid / Minitaur 上超过标准 RL 与目标条件 RL。

## 解决了什么问题
目标导向运动(goal-directed locomotion,即朝指定目标方向走)比单向直走难得多——加入"目标"会扩大输入空间维度,在高维连续控制里尤其棘手。作者的核心观察是:**直走本身已经很难学,但一旦学会直走,朝任意方向走不应该再需要大量新的环境交互**。于是问题被重述为:能否**只用训练单向直走时顺手存下的那批数据**(batch RL,不再额外探索),离线学出一个全向的目标条件策略?

## 用什么方法解决的
提出"目标条件批量 RL(goal-conditioned batch RL)"设定,利用运动任务的**旋转不变性**(无论智能体朝哪个方向,直走该采取的动作是一样的),分两步:
1. **数据增强**:对原 batch 里每条轨迹 τ,随机取角度 θ∈[0,2π),把智能体初始朝向旋转 θ 后**重放同一串动作**,在环境里真实 step 出一条等价轨迹 τ̃(状态/目标被旋转 θ,动作不变)。得到增强集 Daug = D ∪ D̃。
2. **强制等价的表示学习**:用 Siamese 框架(共享权重)学一个编码器 E: S×G→ℝᵏ,要求等价的 (s,g) 与旋转后的 (s̃,g̃) 映射到**同一个嵌入** h;再学一个吃嵌入均值 h̄=(h+h̃)/2 的策略 πE(h)=a。总损失 L = λLenc + (1−λ)LπE(编码器损失拉近 h 与 h̃ 的 L2 距离,策略损失是对动作的回归/行为克隆),λ=0.25,k=10(Ant/Minitaur)或 50(Humanoid)。
数据采集用 PPO(Ant/Minitaur)/ SAC(Humanoid),策略本身**不**条件于目标。所有模型都是 2 隐层 MLP。

## 动机 & 背景
- 目标条件 RL(Kaelbling 1993;Schaul 2015;HER)让一个策略达成多种目标,但目标维度扩大了输入空间,在高维连续控制(运动)里很难学。
- 作者借用 batch RL(Lange 2012;Fujimoto 2019 的 final buffer 设定)的思路:不再边学边探索,而是吃一批"训练直走时存下的数据"。
- 两条核心直觉:(1) 学单向走 ≪ 学全向走的难度;(2) 会单向走的 agent 应该能"近乎免费"地推广到任意方向。这两条**专属于运动任务**,其根源是状态/目标空间相对运动策略的旋转不变性——而方法框架可推广到任何在状态/目标空间存在不变性的任务。

## 方法细节
- **等价定义**:τ₁、τ₂ 等价 ⟺ 存在 θ,使 ãᵢ=aᵢ(动作完全相同)、s̃ᵢ=rot(sᵢ,θ)、所有目标 g̃=rot(g,θ)。
- **数据增强(Alg.2)**:对每条 τ 采样一个 θ,旋转初始状态,然后在环境里**真实重放原动作序列**记录新状态与"单步目标 g"。注意是真在环境里跑出来的,不是纯几何推算。
- **等价编码(Alg.1)**:Siamese 双塔共享权重同时算 h、h̃;Lenc=‖h−h̃‖²(M 个样本平均),LπE=‖πE(h̄)−a‖²;同一份梯度同时更新 E 与 πE。
- **朴素基线(A.2)**:直接学 πg: S×G→A 的行为克隆,可喂随机/on-policy/增强样本。
- **测试设定(A.7)**:测试时把 agent 随机旋转,目标设在距离 ~2–5 单位(Minitaur ~1.5–2.5)、相对朝向 ±45° 内;输入的是指向目标的**单位向量**(方向)而非绝对坐标。一回合最多 1000 步,够近/摔倒/到达即终止。评测指标=每回合**离目标最近距离**。

## 数据集 & 实验设置
- **环境**:Ant(四足,状态 111-D、动作 8-D)、Humanoid(双足,43-D/17-D)、Minitaur(四足,17-D/8-D);Ant 用 OpenAI Gym/MuJoCo,Humanoid/Minitaur 用 PyBullet。
- **交互预算**:Ant 2M、Minitaur 4M timesteps;增强类方法用 1M on-policy + 1M 等价样本凑齐。Humanoid 较特殊:前 5M 步多是摔倒坏样本,故冻结在 5M 的策略再采 10M 样本,标准/目标条件 RL 则训 15M 步以"公平对比"。
- **基线**:① 标准 RL(SAC for Humanoid,PPO for Ant/Minitaur);② 目标条件 RL = HER + SAC/DDPG,分稀疏/稠密奖励;③ 目标条件批量 RL 的 4 个变体:随机样本、on-policy 样本、增强样本、(本文)增强+强制等价。
- 超参:Adam,lr=0.001,batch 512;标准/目标条件 RL 超参沿用 OpenAI baselines/stable-baselines。GTX 1080 训练。指标在 10 个随机种子 × 每种子 1000(正文写 100 runs)回合上取均值/标准差,且固定初始构型与目标保证可比。

## 主要结果 & 结论
- **本文方法(强制等价)在三个环境上"最近距离"均值最低(最好)**:Humanoid 1.779、Minitaur 0.904、Ant 1.105(数字越小越接近目标)。
- **第二名几乎都是"增强样本上的朴素策略"**(Humanoid 1.936 / Minitaur 1.212 / Ant 1.721),说明两条贡献各有功劳:数据增强本身就已击败所有标准/目标条件 RL 基线,Siamese 强制等价再进一步提升(尤其对**训练分布外的目标**的泛化)。
- 随机样本最差(高维连续控制学不出东西);on-policy 样本优于随机但只在训练分布内的目标上平滑、分布外失败(小提琴图上偏离均值的小峰即分布内目标)。
- **反直觉发现**:标准 RL ≥ 目标条件 RL(HER)。作者解释 HER 在稀疏奖励下需要海量样本才偶遇正奖励;稠密奖励(含 control/contact cost)普遍优于稀疏。
- **定性**:本文策略走**直线、更快**到达连续 4 个目标,且**始终面朝运动方向**;而标准 RL 常"倒着走"(面朝运动反方向),轨迹更绕更慢。
- 结论:在状态/目标空间存在不变性(此处=旋转不变)的任务上,"数据增强 + 表示学习强制等价"能用单向数据高效学出全向目标条件策略。

## 核心贡献
1. 提出 **goal-conditioned batch RL** 设定:用"非目标条件策略"采的批数据离线学目标条件策略。
2. 利用运动的**旋转不变性**做数据增强(旋转初始朝向、重放动作生成等价轨迹)。
3. 用 **Siamese 编码器强制等价嵌入**,使等价 (s,g) 共享表示,从而对训练分布外目标泛化更好。
4. 在 Ant/Humanoid/Minitaur 上系统对比标准 RL、HER、及多种 batch 变体,验证两条贡献各自有效。

## 局限与我的质疑
1. **作者自述/隐含局限——强依赖"重放动作"能在环境里真跑出等价轨迹**:数据增强(Alg.2)不是几何变换,而是把旋转后的初始态放回环境、**重放原动作序列**。这要求环境对旋转严格不变且动力学确定;真实机器人有噪声、地形不平、接触随机时,"同样动作旋转后得到等价结果"会失真。论文只在理想化仿真里验证,未讨论随机/非平整环境下增强是否还成立。
2. **指标可疑、绝对意义不清**:唯一定量指标是"每回合离目标最近距离"的均值,但**未报成功率、到达时间、能耗**,也没给该距离的物理单位与"算到达"的阈值口径(正文 0.5、A.7 又出现 2–5 单位的目标距离)。"最近距离"会奖励"冲过目标又折返"或"摔倒前恰好擦边"这类无意义贴近;且正文说 100 runs、A.7 说 1000 episodes,**统计口径自相矛盾**,可复现性存疑。没有显著性检验,标准差还很大(如 Humanoid 0.98),三法名次是否稳健难说。
3. **目标空间被极度简化,夸大了"任意方向"**:测试目标只在 **±45° 扇区、2–5 单位近距**,输入还被换成"指向目标的单位向量"——这本质是"短程、近似正前方的方向跟随",离标题暗示的"walk in **any** direction(全 360°)"差很远。旋转不变性在 ±45° 内当然好用,但能否真覆盖背后/侧后方目标、能否连续转向避障,论文没测。
4. **Humanoid 的实验处理破坏公平性**:因为前 5M 步全是摔倒样本,作者冻结策略另采 10M、把对照组训到 15M——这是**为本文方法量身定制的数据流程**,三类方法吃到的数据质量/分布并不真正对等,"fair evaluation"的说法值得打折。
5. **HER 基线可能被弱化**:用"标准 RL 打败 HER"作为卖点,但 HER 对奖励设计、relabel 策略、采样比例极敏感,论文直接用现成超参、未为目标导向运动调参,可能让目标条件 RL 看起来不必要地差,从而抬高本文相对优势。
6. **与"RL 训练数字人与环境交互"主题的契合度有限**:本文的 Humanoid 只是"走到一个点",**没有任何与环境/物体的真实交互、操作、接触控制**,目标也只是 3-D 位置点。它属于纯运动(locomotion)与离线泛化技巧,对"数字人与环境/人交互"这一侧面只触及最底层的全身运动控制,且方法的核心假设(旋转不变 + 动作可重放)在有物体交互、接触力、非对称场景时基本失效,迁移价值偏弱。
7. **新颖性边界**:利用对称性学运动并非首创(作者自己引了 Abdolhosseini 2019、Mishra 2019),本文的差异是"把对称性用在 batch/离线 + Siamese 等价"上;但这是 ICLR 2020 **workshop** 短文(4 页正文)、零引用,缺乏更大规模、更长训练、与更强离线 RL(如 BCQ/CQL)对照的验证,结论更像 proof-of-concept 而非定论。
