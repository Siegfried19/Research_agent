# Reinforced Imitation in Heterogeneous Action Space
> Konrad Żołna, Negar Rostamzadeh, Yoshua Bengio, Sungjin Ahn, Pedro O. Pinheiro · 2019 · arXiv（预印本，未正式发表） · 引用数 0 · DOI 无

## 一句话
本文提出 RILO（Reinforced Imitation Learning from Observations）框架，在「专家只提供状态序列（无动作标签）、且专家与学习者的动作空间不同、环境只给稀疏奖励」这一困难设定下，把基于状态的对抗式模仿（GAIL 扩展）与稀疏环境奖励自动加权融合，让学习者既能学得快，又能借助稀疏奖励超越专家。

## 解决了什么问题
传统模仿学习（尤其是 GAIL）有两个强假设难以满足真实场景：
1. 需要专家的真实动作标签（state-action 对），但很多场景下动作标签昂贵甚至无法获取（只能观察到专家的状态/视频）。
2. 假设专家与学习者共享同一动作空间，但现实中两者「身体」可能不同（例如新版机器人向只有简化动作集的旧版机器人学习），导致最优策略本就不同。
此外当环境奖励稀疏时纯 RL 探索效率极低。本文要在「状态-only 观测 + 异构动作空间 + 稀疏奖励」三个条件同时成立时学到好策略，并且不被次优的专家所限制。

## 用什么方法解决的
在 GAIL 基础上改造为只比较状态对的对抗式模仿：判别器 D(s_i, s_j) 区分一对状态来自专家还是学习者，由此产生模仿奖励 r^imt；最终奖励为环境奖励与模仿奖励的组合 r_t = r^env_t + λ·r^imt_t（实验中 λ 恒为 1）。在此之上提出两个核心机制：
1. 多种「状态对输入策略」来构造模仿奖励（CSD/SSD/RTGD/ATD），解决「相邻状态对会泄露动作差异、从而被判别器轻易识破」的问题。
2. 「自探索（self-exploration）」机制：用一个伯努利变量 τ_k 决定本轮是否启用模仿奖励，τ_k ~ Bernoulli(1−υ_{k-1})，υ 是当前策略的成功率估计。训练早期成功率低、更依赖模仿引导；随着策略成熟成功率上升，逐渐脱离专家监督、更多靠环境奖励，从而能使用专家不具备的动作、超越专家。

## 动机 & 背景
作者以「幼儿观察大人开门」类比：学习者看不到专家的真实电机指令（动作标签），专家与学习者因身体发育不同动作能力也不同，但完成任务的稀疏信号（如语言/表情）廉价可得。模仿学习是稀疏奖励下 RL 的有效替代，但现有 ILO（imitation learning from observation）工作（如 Torabi 等的 GAIfO、Merel 等）多在纯模仿设定下、且未利用稀疏奖励；少数结合环境奖励与模仿奖励的工作（如 Zhu 等、Kang 等）仍需 state-action 对、假设共享动作空间、且用手工固定权重的凸组合。本文针对这三点不足提出可自动平衡、可处理异构动作空间的方法。

## 方法细节
- **对抗目标**：min_θ max_φ E_{πθ}[log(1−D_φ(s_i,s_j))] + E_{Te}[log(D_φ(s_i,s_j))]，判别器输入是「一对状态」而非 state-action 对。
- **四种模仿奖励构造（Table 1）**：
  - CSD（Consecutive States Discrimination）：用相邻状态对 (s_{t-1}, s_t)，类似 Torabi 等。缺点是相邻转移强烈泄露动作信息，动作空间不同时判别器太容易识破，失效。
  - SSD（Single State Discrimination）：只用单个当前状态 (s_t)，类似 Merel 等。缺点是丢失轨迹动态，需要大量专家观测。
  - RTGD（Random Time Gap Discrimination）：用随机时间间隔的状态对 (s_{ρ(t)}, s_t)，保留轨迹动态又避免短期转移泄露动作（实验中最小间隔超参设为 3）。
  - ATD（Average per Time Discrimination）：用某状态与所有其他状态构成的全部状态对，先取均值，再把「判别器最自信判为学习者」的低分对钳制（clamp）到均值（D*），不依赖超参数。假设这些易识别的低分对是动作空间不同所致而非长期策略差。
- **自探索**：r_t = r^env_t + λ·τ_k·r^imt_t，τ_k 是二元随机变量。关键点是把 τ_k 作为二元特征输入策略网络，使智能体「知道」当前是否处于模仿监督下，从而在「模仿」与「纯最大化环境奖励」两种模式下表现不同。υ_k 用成功率的滑动平均估计。
- **归一化模仿奖励（3.4）**：指出以往工作用未归一化的 r^imt = −log µ（恒为正）会导致训练极不稳定（智能体绕着目标走却不进目标）。本文将奖励归一化：要么减去固定值 −log 0.5，要么减去每个 batch 的动态均值。
- **网络与训练**：状态编码器为 5 层 CNN（kernel 3，残差连接）；F 地图用全连接策略头，P 地图（部分可观测）用 LSTM；策略用 A2C（ViZDoom 用 A3C）；判别器分别编码两状态后取差，经 2 层 MLP（256 隐元）输出 sigmoid 概率；Adam，学习率 1e-4；γ=0.9，ε=0.05。

## 数据集 & 实验设置
- **环境**：自建两个网格世界——F（全可观测，13×13）与 P（部分可观测，只见 agent 周围 5×5），边界与内部有陷阱，目标/agent/陷阱每个 episode 随机布置；导航任务，踩到目标 +1、踩陷阱或超步数 −1。另用 ViZDoom 引擎的 my way home 3D 地图（从原始 RGB 像素学习）验证泛化。
- **动作空间**：4-way、king（国际象棋王）、knight（马）、16-way 四种移动风格；其中 4-way 与 king 总走相邻格，与 knight/16-way（从不走相邻格）不相交；4-way⊂king、knight⊂16-way。由此构造「相同 / 不相交 / 学习者更强 / 专家更强」四类配对，共 16 对专家-学习者组合。
- **奖励**：sparse（仅 episode 终止给 ±1，纯 RL 必失败）与 dense（用于训练专家）。每组实验 5 个随机种子，报均值±标准差。
- **观测量**：P 地图用 1000 条专家状态轨迹、F 地图用 10000 条，比训练专家所需 dense 试验数低约 3 个数量级。还做了观测量减少（500/100/50/1000）的鲁棒性实验。
- **指标**：成功率（网格世界）；ViZDoom 因都近 100% 成功，改用到达目标的平均步数。

## 主要结果 & 结论
- **自探索普遍有效**：带自探索的学习者策略一致更好；即使在「动作空间相同」的简单情形也有几个百分点提升。
- **动作空间不相交时**：CSD 完全失效（成功率不超过 5%），而 SSD-SE 与 ATD-SE 表现最好。
- **学习者动作更强（Ae⊂Al）时**：自探索智能体更倾向使用专家没有的动作，平均少用约 15% 步数到达目标。
- **超越专家**：在 F 地图动作不相交的情形下，RTGD/ATD（尤其带 SE）可超过专家，接近用 dense 奖励训练的学习者上界。
- **观测量影响**：减少专家观测后差距更大、自探索优势更明显；有趣的是全可观测 F 地图反而比 P 地图需要更多观测——因为判别器能「记住」完整地图来作弊，使训练回路更难。
- **纯 IL 对照**：去掉稀疏奖励后所有方法都退化，且自探索无法使用、差距变小，说明环境稀疏奖励是性能与超越专家的关键来源。
- **ViZDoom**：结论一致，自探索对动作空间相同/更强/差异最大三档分别带来约 10%/20%/50% 的步数减少。
- 结论：通过自动平衡稀疏环境奖励与状态-only 模仿，并允许自探索，智能体可在异构动作空间下学得快且不被专家上限所困。

## 核心贡献
- 提出 RILO 框架与「自探索（self-exploration）」算法：在专家-学习者动作空间不同、仅有状态观测时，自动在模仿与环境奖励间加权，并让策略感知当前是否受监督。
- 系统分析了四种基于状态对的模仿奖励构造（CSD/SSD/RTGD/ATD），指出相邻状态对会泄露动作差异并导致失败，提出随机时间间隔与全状态对钳制两种鲁棒方案。
- 指出并修正了以往 GAIL+环境奖励工作中「未归一化模仿奖励恒为正导致训练不稳定」的问题，提出两种归一化方式。
- 通过 16 组配对的系统实验 + 3D 像素环境，实证「学习者性能不被专家上界所限」，可借稀疏奖励超越专家。

## 局限与我的质疑
- **作者自述局限较少**：文中坦承纯 IL 设定下自探索无法应用、优势变小；以及全可观测时判别器会「记住地图作弊」需要更多观测。但整体对适用边界的讨论偏弱。
- **实验域过于玩具化**：核心证据来自离散网格世界的导航任务（移动风格用国际象棋棋子类比），动作空间「异构」只是平移模式不同，远非真实身体形态/自由度差异。ViZDoom 也只是 3 个按钮的简单导航，且只用一个专家。结论「能处理异构动作空间」在如此低维、强结构化的设定下被证明，外推到高维连续控制的说服力不足。
- **与本主题（RL 训练数字人与环境交互）几乎不相关**：本文没有任何全身运动控制、物理仿真角色、连续高维动作或与物理环境的接触交互；它是抽象网格/像素导航的模仿+RL 方法。相关性仅停留在「模仿学习 + 稀疏奖励 + 不同动作空间」的方法论层面，对数字人全身交互的直接借鉴价值很有限（清单中也标注 relevance=38）。
- **方法稳健性与超参敏感**：λ 固定为 1、RTGD 的最小间隔固定为 3、成功率用滑动平均估计——这些选择缺乏系统的敏感性分析；ATD 声称「无超参数」但其钳制策略本身是一个强假设（低分对必由动作差异而非坏策略导致），文中仅以经验观察支撑，未严格验证。
- **「超越专家」的解读需谨慎**：所谓超越专家，本质是因为专家被人为限制为更弱的动作集（如 4-way），而学习者动作集更强（如 16-way 可跳过陷阱）。这更像是「专家本来就不是该任务最优者」，把环境奖励用好即可超过，并非模仿方法的内在突破；结论容易被过度解读为「模仿学习能普遍超越演示者」。
- **可复现性**：这是 2019 年的预印本（标注 work in progress），引用数为 0，未见正式发表；源代码承诺「接收后释放」，部分实现细节未给出，图表中还有 CTD/ATG 等疑似笔误，降低了可信度与可复现性。
