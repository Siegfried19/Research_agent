# Reinforcement Learning Approaches in Social Robotics
> Neziha Akalin · 2021 · MDPI (MDPI AG) · 引用 130 · DOI 10.3390/s21041292

## 一句话
一篇系统性综述,梳理了把强化学习(RL)用在**实体社交机器人**与真实人-机交互(HRI)上的研究,并按 RL 算法类型、奖励所用的沟通媒介、奖励函数性质、评估方法四个维度做了分类。

## 解决了什么问题
社交机器人领域此前缺一篇专门讲 RL 的综述。作者把散落的研究收拢起来,回答"做社交机器人 RL 时,针对不同用户群/应用场景/实验设定,该选什么算法、怎么设计奖励、怎么评估",给打算入坑的社交机器人研究者一份起步参考。

## 用什么方法解决的
文献综述 + 多维分类。作者**刻意限定范围**:只收"有物理实体机器人 + 真实用户参与"的研究,排除纯仿真、纯虚拟 agent、工业机器人、无人交互的工作(仿真训练但最终在实体机器人上做用户实验的算入)。从每篇里抽取输入数据/状态-动作空间、奖励函数、沟通媒介、主要实验结果、实验场景与验证五个要点,然后给出四套分类:①RL 类型(bandit/值/策略/深度);②奖励所用沟通媒介(言语/非言语/情感/触觉/额外接口/无媒介,以及参与度、注意力、舒适度等高层交互动态);③奖励性质三大主题——交互式 RL(人给反馈,分显式/隐式)、内在动机方法(以稳态/well-being 为主)、任务表现驱动(机器人/人/二者);④评估方法(算法视角/用户体验视角/二者结合)。最后用 Dulac-Arnold 等人提出的"真实世界 RL 九大挑战"框架,逐条对照社交机器人文献给了哪些应对方案。

## 动机 & 背景
社交机器人要做到自然、可长期陪伴的交互,需要能在线增量适应不同用户、且用户多为非专家。手写规则在面对不断演化的复杂交互模式时既费力又难覆盖。RL 作为"试错交互发现最优行为"的框架,与社交交互天然契合——很多社交 HRI 本就是序贯决策问题,目标是优化某种性能指标(如用户满意度)。作者强调社交机器人有两个核心属性:**物理实体性**与**交互/沟通能力**,因此把综述严格框在实体机器人 + 真实交互上,区别于机器人领域已有的通用 RL 综述。奖励设计被视为成败关键(所谓"目标规范化的诅咒"),这也是本文专设奖励分类的原因。

## 方法细节
- **RL 基础**:给了 MDP 五元组、Bellman 方程、值函数、SARSA(on-policy)/Q-learning(off-policy)更新式、策略梯度、actor-critic、DQN(经验回放 + 目标网络)等标准公式。
- **按 RL 类型分类**:
  - **Bandit**:对偶 bandit、k-臂、Exp3,常配按钮等物理接口学用户偏好(Schneider、Ritschel、Leite、Gao 等)。
  - **基于模型/无模型**:多数用无模型;少数用基于模型 + 奖励塑形处理延迟反馈(Tseng 用 gamma 分布建模人响应时间;Martins 用 POMDP + 基于熵的奖励塑形)。
  - **值方法**:Q-learning 及其变体(异步 Q、Object Q-learning、模糊推理 IDFFQ、MAXQ 分层、R-learning、SARSA、TD(λ))是社交机器人里最常用的。覆盖触觉反馈(AIBO 抚摸/拍打、Pepper 摸头)、GUI 训练、面部表情(Affectiva 软件取 valence/engagement)、参与度、注意力等大量子场景。
  - **深度 RL**:Qureshi 等人在 Pepper 握手场景做了多模态 DQN、加注意力的 MDARQN、以及用 Pnet 预测误差作内在奖励的版本;Cuayáhuitl 用改进 DQN 玩井字棋;Lathuilière 用 LSTM+Q 控视听融合的注视;Churamani 用 DDPG 让 Nico 表达共情。
  - **策略方法**:PGRL 调舒适度相关的交互参数(Mitsunaga 的 Robovie、Tapus 的 Pioneer)。
- **按奖励性质分类**:交互式 RL(显式反馈=GUI/按钮/触觉给的数值;隐式反馈=情绪/笑声/微笑/姿态等自然社交信号,有噪声需感知算法处理);内在动机(以稳态 homeostasis 为主,机器人维持 well-being,公式 16/17 定义 well-being 及其变化量作奖励);任务表现驱动(人/机器人/二者的任务完成度)。
- **真实世界 RL 九挑战对照**:离线训练、样本受限、高维连续空间、安全约束、部分可观测、奖励多目标、可解释策略、实时推理、动作/传感/奖励延迟——逐条列出社交机器人文献中的应对(两阶段训练、探索/利用分离、LfD 暖启、Object Q-learning/动作剪枝、POMDP、循环网络、加物理接口等)。

## 数据集 & 实验设置
这是综述,本身不做实验。涉及的机器人平台包括 Pepper、Nao、iCat、Maggie、Mini、Reeti、Tega、Brian/Brian 2.0、Furhat、Casper、AIBO、Leonardo、RoBoHoN、Nico、Robovie II 等;应用域覆盖治疗、养老、娱乐、导航、医疗、教育、康复等。少数研究用到公开数据集(如 Lathuilière 用 AVDIAR 视听数据集做离线训练)。多数原始研究在受控实验室里做小规模用户实验,状态/动作空间普遍较小。

## 主要结果 & 结论
- **交互式 RL + 隐式反馈是社交机器人里最主流的做法**,因为社交线索在交互中自然产生、无需额外采集成本;但社交线索变化慢 → 奖励稀疏、收敛慢。
- 作者建议把内在动机、隐式反馈 IRL、任务表现驱动三类奖励**组合**起来缓解稀疏奖励问题。
- IRL 的固有难题被反复点出:人类老师会随训练进行减少反馈(无聊/疲劳)、偏向给正反馈、训练存在透明度问题(机器人该用眼神/LED 等社交线索暴露内部状态以引导训练者)。
- 作者主张社交机器人恰好能靠社交线索缓解 RL 的"可解释性/透明度"挑战,是真实世界 RL 的独特试验台。
- 未探索方向:多任务而非单一奖励、更大的状态-动作空间、从冲突/模糊的隐式反馈生成奖励、技能跨机器人迁移。

## 核心贡献
1. 据作者所知,**首篇专门面向"实体社交机器人 + 真实 HRI"的 RL 综述**。
2. 提出按 RL 类型、沟通媒介、奖励性质、评估方法的**四维分类体系**,尤其是奖励函数的三大主题分类(交互式/内在动机/任务表现驱动)。
3. 用真实世界 RL 九大挑战框架把社交机器人文献的应对手段系统对照了一遍,给后来者一份选型与避坑指南。

## 局限与我的质疑
1. **作者自述局限**:综述指出现有研究几乎都是单目标单任务、状态-动作空间小、安全约束几乎无人认真处理(因为都在受控实验室、有研究者随时干预),且缺乏标准化评估方法。这些其实暴露了整个子领域还很"玩具化"——结论的外推性有限。
2. **覆盖与时效**:这是 2021 年的综述(arXiv 可追到 2020),正值大模型/具身智能爆发前夜。它几乎全是 Q-learning 及小变体,深度 RL 只占很小一块,完全没有触及后来主流的 PPO/SAC、模仿学习+RL、扩散策略、语言模型驱动的奖励等。作为"该选什么算法"的参考,今天看已明显过时。
3. **分类>洞见,缺定量比较**:文章是描述性归类,没有跨研究的统一基准或定量横评(各研究平台、任务、指标都不同,本也无法公平比)。所以"IRL+隐式反馈最主流"只是**频次统计**,不等于"最有效";读者拿不到"在 X 场景下 A 算法比 B 强多少"这种可操作结论。作者把组合奖励缓解稀疏奖励作为建议,但这只是构想,综述里并无证据支撑其优于现有做法。
4. **对"真实交互"的范围裁剪是双刃剑**:严格排除纯仿真/虚拟 agent 让样本量变小、且把大量在仿真里更成熟的 RL 进展挡在门外,可能造成"社交机器人 RL 很初级"的印象偏差——其实是筛选标准导致的。
5. **与本研究主题(RL 训练能与环境交互的数字人)的契合度有限**:本文的立论前提恰恰是**必须有物理实体**,明确把虚拟 agent/数字人排除在外。因此它对"数字人"几乎零直接覆盖——没有图形化身、动作生成、物理仿真交互、全身控制这些数字人关心的内容。可借鉴的是**奖励设计的分类框架**(交互式/内在动机/任务表现)和**用人类社交信号/隐式反馈做奖励**的思路,这些在训练与人交互的数字人时同样适用;但算法层面(只到 DQN)和落地经验(实体机器人硬件磨损、Duo/触觉传感)对数字人参考价值不大。把它当"奖励机制与人在环反馈的概念地图"读最合适,别指望拿到数字人可直接复用的方法。
